# Excel数据透视表与图表

## 定义

**Excel数据透视表**是一种交互式表格，用于快速汇总、分析、探索和呈现数据。**Excel图表**则是将数据可视化展示的工具。

对于数据分析师而言，掌握**数据透视表和图表**，是**快速分析数据、发现数据规律、呈现分析结果**的关键技能。

---

## 核心概念

### 1. 数据透视表

| 概念 | 说明 | 示例 |
|------|------|------|
| **行字段** | 决定透视表行的字段 | 将"地区"拖到行字段 |
| **列字段** | 决定透视表列的字段 | 将"季度"拖到列字段 |
| **值字段** | 需要汇总计算的字段 | 将"销售额"拖到值字段 |
| **筛选器** | 用于筛选数据的字段 | 将"年份"拖到筛选器 |

### 2. 图表类型

| 图表类型 | 说明 | 应用场景 |
|----------|------|----------|
| **柱状图** | 比较各类别之间的数值 | 比较各品类销售额 |
| **折线图** | 显示数据随时间变化的趋势 | 显示销售额随时间变化趋势 |
| **饼图** | 显示各部分占整体的比例 | 显示各品类销售额占比 |
| **散点图** | 显示两个变量之间的关系 | 显示广告投入与销售额关系 |
| **组合图** | 结合两种图表类型 | 柱状图+折线图显示销售额和增长率 |

## 详细内容

### 一、数据透视表

#### 1.1 创建数据透视表

**步骤**：
1. 选择数据源区域（包含标题行）
2. 点击"插入" → "数据透视表"
3. 选择放置位置（新工作表或现有工作表）
4. 点击"确定"
5. 在数据透视表字段窗格中，拖拽字段到对应区域

#### 1.2 数据透视表字段布局

**字段区域**：
- **筛选器**：用于筛选数据
- **列**：用于列标题
- **行**：用于行标题
- **值**：用于汇总计算

**值字段设置**：
- **汇总方式**：求和、计数、平均值、最大值、最小值、标准偏差、方差等
- **数字格式**：设置数字显示格式
- **显示方式**：占总计的百分比、占列总计的百分比等

#### 1.3 数据透视表刷新

**手动刷新**：
- 右键点击数据透视表 → "刷新"

**打开文件时自动刷新**：
- 右键点击数据透视表 → "数据透视表选项" → "数据" → 勾选"打开文件时刷新"

#### 1.4 数据透视表分组

**分组日期**：
1. 右键点击日期字段 → "分组"
2. 选择分组方式（按月、季度、年等）
3. 点击"确定"

**分组数值**：
1. 右键点击数值字段 → "分组"
2. 设置起始值、结束值、间隔
3. 点击"确定"

---

### 二、图表

#### 2.1 创建图表

**步骤**：
1. 选择数据源区域（包含标题行）
2. 点击"插入" → 选择图表类型
3. 图表插入到工作表中

**快捷键**：
- `F11`：创建默认图表（柱状图）
- `Alt + F1`：创建嵌入工作表的默认图表

#### 2.2 图表元素

**主要元素**：
- **图表标题**：描述图表内容
- **坐标轴标题**：描述坐标轴含义
- **图例**：解释数据系列含义
- **数据标签**：显示数据点的具体数值
- **网格线**：辅助读取数值
- **趋势线**：显示数据变化趋势

#### 2.3 图表格式化

**格式化图表元素**：
1. 右键点击图表元素 → "格式化..."
2. 在格式化窗格中设置格式

**常用格式化选项**：
- **填充与线条**：设置填充颜色、边框颜色、线条样式
- **效果**：设置阴影、发光、柔化边缘等效果
- **大小与属性**：设置元素大小和位置

#### 2.4 组合图

**创建组合图**：
1. 创建柱状图
2. 右键点击数据系列 → "更改系列图表类型"
3. 选择"组合图"
4. 为不同数据系列选择不同图表类型
5. 勾选"次坐标轴"（如需）
6. 点击"确定"

---

### 三、数据透视表与图表结合

#### 3.1 基于数据透视表创建图表

**步骤**：
1. 创建数据透视表
2. 点击数据透视表任意位置
3. 点击"插入" → 选择图表类型
4. 图表基于数据透视表数据创建

**优点**：
- 图表随数据透视表刷新而更新
- 可以利用数据透视表的筛选、分组功能
- 交互性强

#### 3.2 切片器与日程器

**切片器**：
1. 点击数据透视表任意位置
2. 点击"插入" → "切片器"
3. 选择字段
4. 点击"确定"
5. 使用切片器筛选数据透视表和图表

**日程器**：
1. 点击数据透视表任意位置
2. 点击"插入" → "日程器"
3. 选择日期字段
4. 点击"确定"
5. 使用日程器筛选日期

## 示例/应用场景

### 示例1：电商销售数据分析

**业务问题**：分析电商销售数据，按地区和品类汇总销售额。

**数据**：电商销售数据（地区、品类、月份、销售额）

**分析**：

**Excel操作**：
1. 创建数据透视表：
   - 行字段：地区
   - 列字段：品类
   - 值字段：销售额（求和）
2. 基于数据透视表创建柱状图：
   - 图表类型：簇状柱状图
   - 图表标题："各地区各品类销售额对比"
   - 添加数据标签

**洞察与建议**：
- 如果某地区某品类销售额高，说明该地区该品类受欢迎
- 可以针对高销售额地区和高销售额品类制定营销策略
- 可以分析低销售额地区和低销售额品类的原因，优化产品或营销

### 示例2：电商用户行为分析

**业务问题**：分析电商用户行为，按月份和用户类型统计访问量。

**数据**：电商用户行为数据（月份、用户类型、访问量）

**分析**：

**Excel操作**：
1. 创建数据透视表：
   - 行字段：月份
   - 列字段：用户类型
   - 值字段：访问量（求和）
2. 基于数据透视表创建折线图：
   - 图表类型：带数据标记的折线图
   - 图表标题："各月份各用户类型访问量趋势"
   - 添加趋势线

**洞察与建议**：
- 如果某月份访问量高，说明该月份用户活跃度高
- 如果某用户类型访问量高，说明该用户类型忠诚度高
- 可以针对高访问量月份和高忠诚度用户类型制定用户运营策略

### 示例3：电商商品价格分析

**业务问题**：分析电商商品价格，按品类和商品统计价格分布。

**数据**：电商商品价格数据（品类、商品、价格）

**分析**：

**Excel操作**：
1. 创建数据透视表：
   - 行字段：品类、商品
   - 值字段：价格（平均值、最大值、最小值）
2. 基于数据透视表创建箱线图：
   - 图表类型：箱线图
   - 图表标题："各品类商品价格分布"
   - 添加数据标签

**洞察与建议**：
- 如果某品类商品价格差异大，说明该品类商品价格策略不统一
- 可以针对价格差异大的品类制定统一的价格策略
- 可以分析价格差异的原因，优化产品定位

## 最佳实践

### 1. 根据分析目标，选择合适的数据透视表布局

**不推荐**（盲目使用默认布局）：

```
无论什么分析目标，都使用默认的数据透视表布局。
```

**推荐**（根据分析目标，选择合适的数据透视表布局）：

```
- 比较各类别之间的数值 → 行字段：类别字段，值字段：数值字段
- 显示数据随时间变化的趋势 → 行字段：时间字段，值字段：数值字段
- 显示各部分占整体的比例 → 行字段：类别字段，值字段：数值字段（设置为占总计的百分比）
```

### 2. 根据数据特征，选择合适的图表类型

**不推荐**（盲目使用柱状图）：

```
无论什么数据，都使用柱状图。
```

**推荐**（根据数据特征，选择合适的图表类型）：

```
- 比较各类别之间的数值 → 柱状图
- 显示数据随时间变化的趋势 → 折线图
- 显示各部分占整体的比例 → 饼图
- 显示两个变量之间的关系 → 散点图
- 结合两种数据类型 → 组合图
```

### 3. 使用切片器和日程器增强交互性

**不推荐**（不使用切片器和日程器）：

```
创建静态的数据透视表和图表，不提供交互式筛选功能。
```

**推荐**（使用切片器和日程器增强交互性）：

```
- 为数据透视表添加切片器，方便按字段筛选数据
- 为日期字段添加日程器，方便按日期筛选数据
- 使用切片器和日程器筛选数据透视表和图表
```

### 4. 结合业务场景解释分析结果

**不推荐**（只报告分析结果）：

```
数据透视表显示A地区销售额为100万。
```

**推荐**（结合业务场景解释分析结果）：

```
数据透视表显示A地区销售额为100万，说明A地区销售业绩好。可以针对A地区制定更多的营销策略，巩固市场地位。
```

## 常见错误

### 1. 盲目使用默认的数据透视表布局

**错误示例**：

```
无论什么分析目标，都使用默认的数据透视表布局。
```

**正确做法**：

```
根据分析目标，选择合适的数据透视表布局。
```

### 2. 盲目使用某种图表类型

**错误示例**：

```
无论什么数据，都使用柱状图。
```

**正确做法**：

```
根据数据特征，选择合适的图表类型。
```

### 3. 不使用切片器和日程器增强交互性

**错误示例**：

```
创建静态的数据透视表和图表，不提供交互式筛选功能。
```

**正确做法**：

```
使用切片器和日程器增强交互性。
```

### 4. 不结合业务场景解释分析结果

**错误示例**：

```
数据透视表显示A地区销售额为100万。
```

**正确做法**：

```
结合业务场景解释分析结果。
```

### 5. 数据透视表数据源未正确选择

**错误示例**：

```
选择数据源时，未包含标题行，或选择了空白行/列。
```

**正确做法**：

```
选择数据源时，确保包含标题行，且不包含空白行/列。
```
