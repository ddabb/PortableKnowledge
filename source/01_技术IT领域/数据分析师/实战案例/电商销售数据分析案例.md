# 电商销售数据分析案例

## 定义

**电商销售数据分析案例**通过**数据导入、数据清洗、数据探索、数据可视化、业务洞察**等完整分析流程，展示如何使用数据分析技能解决实际业务问题。

对于数据分析师而言，掌握**电商销售数据分析案例**，是**将理论知识应用于实际业务场景**的关键技能。

## 核心概念

### 1. 分析流程

| 步骤 | 说明 | 工具 |
|------|------|------|
| **数据导入** | 从各种数据源导入数据 | Excel、SQL、Python、Power BI、Tableau |
| **数据清洗** | 处理缺失值、异常值、重复值等 | Excel、SQL、Python |
| **数据探索** | 了解数据基本特征 | Excel、SQL、Python |
| **数据可视化** | 创建图表展示数据 | Excel、Python、Power BI、Tableau |
| **业务洞察** | 从数据中提取业务价值 | 所有工具 |

### 2. 业务指标

| 指标 | 说明 | 计算公式 |
|------|------|----------|
| **销售额** | 总销售金额 | SUM(销售额) |
| **销量** | 总销售数量 | SUM(销量) |
| **客单价** | 平均每个客户的购买金额 | 销售额 / 客户数 |
| **转化率** | 访问客户中购买的比例 | 购买客户数 / 访问客户数 |
| **复购率** | 重复购买客户的比例 | 重复购买客户数 / 总购买客户数 |

### 3. 分析维度

| 维度 | 说明 | 示例 |
|------|------|------|
| **时间维度** | 按时间分析销售数据 | 月度销售额趋势、季度销售额对比 |
| **品类维度** | 按品类分析销售数据 | 各品类销售额对比、各品类销量对比 |
| **地区维度** | 按地区分析销售数据 | 各省份销售额分布、各城市销量分布 |
| **客户维度** | 按客户分析销售数据 | 各客户类型购买行为、各客户价值分析 |

### 二、数据清洗

#### 2.1 处理缺失值

**Excel**：
- 使用筛选功能查找缺失值
- 使用替换功能填充缺失值

**Python**：
```python
# 查找缺失值
print(df.isnull().sum())

# 填充缺失值
df['销售额'].fillna(df['销售额'].mean(), inplace=True)

# 删除缺失值
df.dropna(inplace=True)
```

**SQL**：
```sql
-- 查找缺失值
SELECT * FROM sales_data WHERE sales_amount IS NULL;

-- 填充缺失值
UPDATE sales_data SET sales_amount = (SELECT AVG(sales_amount) FROM sales_data) WHERE sales_amount IS NULL;

-- 删除缺失值
DELETE FROM sales_data WHERE sales_amount IS NULL;
```

#### 2.2 处理异常值

**Excel**：
- 使用排序功能查找异常值
- 使用替换功能修正异常值

**Python**：
```python
# 使用箱线图识别异常值
import seaborn as sns
sns.boxplot(df['销售额'])

# 删除异常值
Q1 = df['销售额'].quantile(0.25)
Q3 = df['销售额'].quantile(0.75)
IQR = Q3 - Q1
df = df[~((df['销售额'] < (Q1 - 1.5 * IQR)) | (df['销售额'] > (Q3 + 1.5 * IQR)))]
```

**SQL**：
```sql
-- 使用四分位数识别异常值
WITH quartiles AS (
    SELECT 
        PERCENTILE_CONT(0.25) WITHIN GROUP (ORDER BY sales_amount) AS Q1,
        PERCENTILE_CONT(0.75) WITHIN GROUP (ORDER BY sales_amount) AS Q3
    FROM 
        sales_data
)
SELECT 
    * 
FROM 
    sales_data, 
    quartiles
WHERE 
    sales_amount < (Q1 - 1.5 * (Q3 - Q1)) 
    OR sales_amount > (Q3 + 1.5 * (Q3 - Q1));
```

#### 2.3 处理重复值

**Excel**：
- 使用"删除重复项"功能

**Python**：
```python
# 查找重复值
print(df.duplicated().sum())

# 删除重复值
df.drop_duplicates(inplace=True)
```

**SQL**：
```sql
-- 查找重复值
SELECT 
    order_id, 
    COUNT(*) 
FROM 
    sales_data 
GROUP BY 
    order_id 
HAVING 
    COUNT(*) > 1;

-- 删除重复值（保留第一条）
WITH cte AS (
    SELECT 
        *, 
        ROW_NUMBER() OVER (PARTITION BY order_id ORDER BY order_date) AS rn
    FROM 
        sales_data
)
DELETE FROM sales_data 
WHERE 
    order_id IN (SELECT order_id FROM cte WHERE rn > 1);
```

### 三、数据探索

#### 3.1 了解数据基本特征

**Python**：
```python
# 查看数据基本信息
print(df.info())

# 查看数据统计信息
print(df.describe())

# 查看各品类销售额
print(df.groupby('品类')['销售额'].sum())
```

**SQL**：
```sql
-- 查看数据总量
SELECT COUNT(*) FROM sales_data;

-- 查看各品类销售额
SELECT 
    category, 
    SUM(sales_amount) AS total_sales
FROM 
    sales_data
GROUP BY 
    category
ORDER BY 
    total_sales DESC;
```

#### 3.2 分析时间趋势

**Python**：
```python
# 将订单日期转换为日期类型
df['订单日期'] = pd.to_datetime(df['订单日期'])

# 按月份汇总销售额
monthly_sales = df.resample('M', on='订单日期')['销售额'].sum()

# 绘制折线图
import matplotlib.pyplot as plt
monthly_sales.plot()
plt.title('月度销售额趋势')
plt.show()
```

**SQL**：
```sql
-- 按月份汇总销售额
SELECT 
    DATE_FORMAT(order_date, '%Y-%m') AS month, 
    SUM(sales_amount) AS total_sales
FROM 
    sales_data
GROUP BY 
    month
ORDER BY 
    month;
```

#### 3.3 分析品类对比

**Python**：
```python

category_sales = df.groupby('品类')['销售额'].sum()

plt.show()
```

    sales_data

    category

### 五、业务洞察

#### 5.1 分析销售趋势

**洞察**：
- 如果某月份销售额高，说明该月份销售情况好
- 如果某月份销售额低，说明该月份销售情况差

**建议**：
- 分析销售情况好的月份的原因，优化其他月份销售策略
- 针对销售情况差的月份，制定促销活动

#### 5.2 分析品类表现

**洞察**：
- 如果某品类销售额高，说明该品类受欢迎
- 如果某品类销售额低，说明该品类不受欢迎

**建议**：
- 针对销售额高的品类，加大库存和营销投入
- 针对销售额低的品类，分析原因，优化产品或淘汰

#### 5.3 分析地区差异

**洞察**：
- 如果某地区销售额高，说明该地区市场好
- 如果某地区销售额低，说明该地区市场差

**建议**：
- 针对销售额高的地区，加大市场投入
- 针对销售额低的地区，分析市场差异，制定针对性策略

#### 5.4 分析客户行为

**洞察**：
- 如果某客户类型购买转化率高，说明该客户类型价值高
- 如果某客户类型购买转化率低，说明该客户类型价值低

**建议**：
- 针对购买转化率高的客户类型，制定用户运营策略
- 针对购买转化率低的客户类型，分析原因，优化产品或运营

## 最佳实践

### 1. 遵循完整的分析流程

**不推荐**（跳跃式分析）：
```text
直接进行数据可视化，跳过数据清洗和数据探索
```

**推荐**（遵循完整的分析流程）：
```text
数据导入 → 数据清洗 → 数据探索 → 数据可视化 → 业务洞察
```

### 2. 结合业务场景解释分析结果

**不推荐**（只报告分析结果）：
```text
销售额高的品类是A、B、C
```

**推荐**（结合业务场景解释分析结果）：
```text
销售额高的品类是A、B、C，说明这些品类受欢迎。可以针对这些品类加大库存和营销投入。
```

### 3. 使用合适的可视化图表

**不推荐**（盲目使用柱状图）：
```text
无论什么分析需求，都使用柱状图
```

**推荐**（根据分析需求，选择合适的可视化图表）：
```text
- 比较各类别数值 → 柱状图、条形图
- 显示数据随时间变化趋势 → 折线图
- 显示各部分占总体比例 → 饼图
- 显示两个变量之间的关系 → 散点图
- 显示地理数据 → 地图
```

### 4. 提出可执行的业务建议

**不推荐**（只报告分析结果，不提出业务建议）：
```text
销售额高的品类是A、B、C
```

**推荐**（报告分析结果，并提出业务建议）：
```text
销售额高的品类是A、B、C，说明这些品类受欢迎。建议：
1. 加大品类A、B、C的库存
2. 加大品类A、B、C的营销投入
3. 分析品类A、B、C的成功原因，复制到其它品类
```
