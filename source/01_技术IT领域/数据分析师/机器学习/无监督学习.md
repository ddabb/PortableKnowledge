# 无监督学习

## 定义

**无监督学习**是机器学习的重要分支，使用**不带标签的数据训练模型**。

对于数据分析师而言，掌握**无监督学习**，是**进行聚类分析、降维分析、关联规则分析**的关键技能。

---

## 核心概念

### 1. 无监督学习类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **聚类问题** | 将相似数据分组 | 用户分群、商品分群 |
| **降维问题** | 减少特征维度 | 特征选择、特征提取 |
| **关联规则问题** | 发现数据中的关联规则 | 购物篮分析、推荐系统 |

### 2. 无监督学习步骤

| 步骤 | 说明 | 工具 |
|------|------|------|
| **1. 收集数据** | 收集不带标签的数据 | Excel、SQL、Python |
| **2. 处理数据** | 清洗、转换、整合数据 | Excel、SQL、Python |
| **3. 选择模型** | 选择合适的无监督学习模型 | 业务理解、统计知识 |
| **4. 训练模型** | 使用数据训练模型 | Python（Scikit-learn、TensorFlow、PyTorch） |
| **5. 评估模型** | 评估模型效果 | Python（Scikit-learn、TensorFlow、PyTorch） |
| **6. 应用模型** | 将模型应用于实际业务场景 | 所有工具 |

### 3. 无监督学习应用场景

| 场景 | 说明 | 示例 |
|------|------|------|
| **聚类问题** | 将相似数据分组 | 用户分群、商品分群、文档分类 |
| **降维问题** | 减少特征维度 | 特征选择、特征提取、数据可视化 |
| **关联规则问题** | 发现数据中的关联规则 | 购物篮分析、推荐系统、异常检测 |

```python
import pandas as pd

# 读取CSV文件
df = pd.read_csv('data.csv')

# 查看数据
print(df.head())
```

**公开数据集**：
```python
from sklearn.datasets import load_iris
```

### 二、处理数据

#### 2.1 数据清洗

**Python代码**：
```python
# 处理缺失值
df = df.fillna(method='bfill')

# 处理异常值
Q1 = df['column'].quantile(0.25)
Q3 = df['column'].quantile(0.75)
IQR = Q3 - Q1
df = df[~((df['column'] < (Q1 - 1.5 * IQR)) | (df['column'] > (Q3 + 1.5 * IQR)))]

# 处理重复值
df = df.drop_duplicates()
```

#### 2.2 数据转换

**Python代码**：
```python
# 将分类变量转换为哑变量
df = pd.get_dummies(df, columns=['category'], prefix=['category'])

# 将连续变量离散化
df['age_group'] = pd.cut(df['age'], bins=[0, 18, 30, 50, 100], labels=['0-18', '19-30', '31-50', '51+'])
```

#### 2.3 特征缩放

**Python代码**：
```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 归一化
scaler = MinMaxScaler()
X_scaled = scaler.fit_transform(X)
```

### 三、选择模型

#### 3.1 聚类模型

| 模型 | 说明 | 适用场景 |
|------|------|----------|
| **K-means聚类** | 用于聚类问题，需要指定聚类数量 | 用户分群、商品分群 |
| **层次聚类** | 用于聚类问题，不需要指定聚类数量 | 用户分群、商品分群 |
| **DBSCAN聚类** | 用于聚类问题，能处理噪声点 | 用户分群、商品分群 |
| **高斯混合模型** | 用于聚类问题，基于概率模型 | 用户分群、商品分群 |

#### 3.2 降维模型

| 模型 | 说明 | 适用场景 |
|------|------|----------|
| **主成分分析（PCA）** | 用于降维问题，线性降维 | 特征选择、特征提取 |
| **线性判别分析（LDA）** | 用于降维问题，有监督降维 | 特征选择、特征提取 |
| **t-SNE** | 用于降维问题，非线性降维 | 数据可视化 |
| **自动编码器** | 用于降维问题，基于神经网络 | 特征选择、特征提取 |

#### 3.3 关联规则模型

| 模型 | 说明 | 适用场景 |
|------|------|----------|
| **Apriori算法** | 用于关联规则问题 | 购物篮分析、推荐系统 |
| **FP-Growth算法** | 用于关联规则问题，效率更高 | 购物篮分析、推荐系统 |

### 四、训练模型

#### 4.1 训练聚类模型

**Python代码（K-means聚类）**：
```python
from sklearn.cluster import KMeans

# 创建K-means聚类模型
model = KMeans(n_clusters=5, random_state=0)

```

**Python代码（DBSCAN聚类）**：
```python

# 创建DBSCAN聚类模型
model = DBSCAN(eps=0.5, min_samples=5)

# 训练模型
model.fit(X)
```

#### 4.2 训练降维模型

**Python代码（PCA）**：
```python
from sklearn.decomposition import PCA

# 创建PCA模型
model = PCA(n_components=2)

# 训练模型
X_pca = model.fit_transform(X)
```

**Python代码（t-SNE）**：
```python
from sklearn.manifold import TSNE

# 创建t-SNE模型
model = TSNE(n_components=2, random_state=0)

# 训练模型

```

#### 4.3 训练关联规则模型

**Python代码（Apriori算法）**：
```python
from mlxtend.frequent_patterns import apriori, association_rules

# 使用Apriori算法找到频繁项集
frequent_itemsets = apriori(df, min_support=0.5, use_colnames=True)

# 生成关联规则
rules = association_rules(frequent_itemsets, metric='confidence', min_threshold=0.7)

# 查看结果
print(rules)
```

## 示例/应用场景

### 示例1：用户分群

**业务问题**：将用户分为不同群体。

**数据**：用户数据（特征：年龄、性别、地域、消费金额等）

**分析**：

**Python代码**：
```python
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

# 读取数据
df = pd.read_csv('user_data.csv')

# 选择特征
X = df[['age', 'annual_income', 'spending_score']]

# 创建K-means聚类模型
model = KMeans(n_clusters=5, random_state=0)

# 训练模型
model.fit(X)

# 添加聚类结果到原数据
df['cluster'] = model.labels_

# 查看各聚类的特征
cluster_features = df.groupby('cluster').mean().reset_index()
print(cluster_features)

# 可视化聚类结果
plt.scatter(X[model.labels_ == 0, 0], X[model.labels_ == 0, 1], s=50, c='red', label='Cluster 1')
plt.scatter(X[model.labels_ == 1, 0], X[model.labels_ == 1, 1], s=50, c='blue', label='Cluster 2')
plt.scatter(X[model.labels_ == 2, 0], X[model.labels_ == 2, 1], s=50, c='green', label='Cluster 3')
plt.scatter(X[model.labels_ == 3, 0], X[model.labels_ == 3, 1], s=50, c='yellow', label='Cluster 4')
plt.scatter(X[model.labels_ == 4, 0], X[model.labels_ == 4, 1], s=50, c='purple', label='Cluster 5')
plt.scatter(model.cluster_centers_[:, 0], model.cluster_centers_[:, 1], s=200, c='black', label='Centroids')
plt.title('用户分群')
plt.xlabel('年龄')
plt.ylabel('年收入')
plt.legend()
plt.show()
```

**洞察与建议**：
- 如果各聚类特征明显，说明聚类效果好
- 可以针对不同聚类制定不同的营销策略

### 示例3：购物篮分析

**业务问题**：发现商品之间的关联规则。

**数据**：购物篮数据（事务数据，每列代表一个商品，每行代表一个事务）

**分析**：

**Python代码**：
```python

# 读取数据
df = pd.read_csv('market_basket_data.csv')

# 生成关联规则
rules = association_rules(frequent_itemsets, metric='confidence', min_threshold=0.7)

# 查看结果
print(rules[['antecedents', 'consequents', 'support', 'confidence', 'lift']])
```

**洞察与建议**：
- 如果关联规则的支持度、置信度、提升度高，说明关联规则强
- 可以根据关联规则进行商品推荐

## 最佳实践

### 1. 确保数据质量

**不推荐**（使用低质量数据）：
```text
使用缺失值多、异常值多、重复值多的数据训练模型
```

**推荐**（确保数据质量）：
```text
数据清洗：处理缺失值、异常值、重复值
数据转换：将分类变量转换为哑变量，将连续变量离散化
特征缩放：标准化或归一化
```

### 2. 选择合适的模型

**不推荐**（盲目使用一种模型）：
```text
无论什么业务场景，都使用相同的模型
```

**推荐**（根据业务场景，选择合适的模型）：
```text
- 聚类问题 → K-means聚类、层次聚类、DBSCAN聚类、高斯混合模型
- 降维问题 → PCA、LDA、t-SNE、自动编码器
- 关联规则问题 → Apriori算法、FP-Growth算法
```

### 3. 评估模型效果

**不推荐**（不评估模型效果）：
```text
训练模型后，不评估模型效果，直接应用
```

**推荐**（评估模型效果）：
```text
- 聚类问题 → 轮廓系数、Calinski-Harabasz指数、Davies-Bouldin指数
- 降维问题 → 解释方差比、累积解释方差比
- 关联规则问题 → 支持度、置信度、提升度
```

### 4. 调参优化模型

**不推荐**（使用默认参数）：
```text
使用模型默认参数，不调参
```

**推荐**（调参优化模型）：
```text
- 使用网格搜索（Grid Search）调参
- 使用随机搜索（Random Search）调参
- 使用交叉验证（Cross Validation）评估调参效果
```

## 常见错误

### 1. 使用低质量数据训练模型

**错误示例**：
```text
使用缺失值多、异常值多、重复值多的数据训练模型
```

**正确做法**：
```text
数据清洗：处理缺失值、异常值、重复值
数据转换：将分类变量转换为哑变量，将连续变量离散化
特征缩放：标准化或归一化
```

### 2. 盲目使用一种模型

**错误示例**：
```text
无论什么业务场景，都使用相同的模型
```

**正确做法**：
```text
根据业务场景，选择合适的模型
```

### 3. 不评估模型效果

**错误示例**：
```text
训练模型后，不评估模型效果，直接应用
```

**正确做法**：
```text
评估模型效果：
- 聚类问题 → 轮廓系数、Calinski-Harabasz指数、Davies-Bouldin指数
- 降维问题 → 解释方差比、累积解释方差比
- 关联规则问题 → 支持度、置信度、提升度
```

### 4. 使用默认参数

**错误示例**：
```python
# 使用默认参数
model = KMeans()
```

**正确做法**：
```python
# 调参优化模型
from sklearn.model_selection import GridSearchCV
parameters = {'n_clusters': [3, 5, 7, 9]}
model = GridSearchCV(KMeans(), parameters)
```

### 5. 聚类数量选择不当

**错误示例**：
```python
# 聚类数量选择不当
model = KMeans(n_clusters=10)
```

**正确做法**：
```python
# 使用肘部法则选择聚类数量
inertia = []
for k in range(1, 11):
    model = KMeans(n_clusters=k, random_state=0)
    model.fit(X)
    inertia.append(model.inertia_)

# 绘制肘部图
plt.plot(range(1, 11), inertia)
plt.title('肘部法则')
plt.xlabel('聚类数量')
plt.ylabel('惯性')
plt.show()
```
