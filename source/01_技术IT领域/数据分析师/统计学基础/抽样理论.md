# 抽样理论

## 定义

抽样理论是**从总体中抽取样本、根据样本推断总体**的统计理论。

对于数据分析师而言，抽样理论是**进行统计推断、设计实验、进行市场调研**的基础。

---

## 核心概念

### 1. 抽样基本概念

| 概念 | 说明 | 示例 |
|------|------|------|
| **总体** | 研究对象的全体 | 所有电商用户 |
| **样本** | 从总体中抽取的部分个体 | 1000个电商用户 |
| **参数** | 总体的数值特征 | 总体均值μ、总体方差σ² |
| **统计量** | 样本的数值特征 | 样本均值x̄、样本方差s² |

### 2. 抽样方法

| 方法 | 说明 | 优点 | 缺点 |
|------|------|------|------|
| **简单随机抽样** | 每个个体被抽中概率相等 | 简单、无偏 | 需要完整抽样框 |
| **分层抽样** | 先分层，再在各层内随机抽样 | 精度高、代表性好 | 需要分层信息 |
| **系统抽样** | 按固定间隔抽取样本 | 简单、快速 | 存在周期性偏差风险 |
| **整群抽样** | 随机抽取群体，调查群体内所有个体 | 成本低、易实施 | 精度较低 |

---

## 详细内容

### 一、简单随机抽样（Simple Random Sampling）

#### 1.1 定义

每个个体被抽中的概率相等，且每个样本的被抽中概率相等。

#### 1.2 抽样方法

**Excel操作**：
1. 使用`RAND()`函数生成随机数
2. 使用`SORT()`函数排序
3. 选择前n个作为样本

**Python操作**：
```python
import pandas as pd
import numpy as np

# 读取数据
df = pd.read_csv('population.csv')

# 简单随机抽样
sample = df.sample(n=1000, random_state=42)
```

#### 1.3 应用场景

- 总体同质性强
- 有完整抽样框
- 需要无偏估计

---

### 二、分层抽样（Stratified Sampling）

#### 2.1 定义

将总体按照某些特征分成若干层，然后在每层内独立进行简单随机抽样。

#### 2.2 抽样方法

**Python操作**：
```python
import pandas as pd
import numpy as np

# 读取数据
df = pd.read_csv('population.csv')

# 分层抽样
sample = df.groupby('stratum', group_keys=False).apply(
    lambda x: x.sample(n=min(100, len(x)), random_state=42)
)
```

#### 2.3 应用场景

- 总体异质性强
- 某些层个体少但重要
- 需要提高估计精度

---

### 三、系统抽样（Systematic Sampling）

#### 3.1 定义

将总体个体排序，随机确定起点，然后按照固定间隔抽取样本。

#### 3.2 抽样方法

**Python操作**：
```python
import pandas as pd
import numpy as np

# 读取数据
df = pd.read_csv('population.csv')

# 系统抽样
N = len(df)
n = 1000
k = N // n
start = np.random.randint(0, k)
sample_indices = range(start, N, k)
sample = df.iloc[sample_indices]
```

#### 3.3 应用场景

- 总体量大
- 需要快速抽样
- 不存在周期性偏差

---

### 四、整群抽样（Cluster Sampling）

#### 4.1 定义

将总体分成若干群，随机抽取部分群，调查群体内所有个体。

#### 4.2 抽样方法

**Python操作**：
```python
import pandas as pd
import numpy as np

# 读取数据
df = pd.read_csv('population.csv')

# 整群抽样
clusters = df['cluster'].unique()
selected_clusters = np.random.choice(clusters, size=10, replace=False)
sample = df[df['cluster'].isin(selected_clusters)]
```

#### 4.3 应用场景

- 总体地理分布广
- 调查成本高
- 精度要求不高

### 五、样本量计算

#### 5.1 估计总体均值时样本量

**公式**：
```
n = (Z² * σ²) / e²
```
其中：
- Z：置信水平对应的Z值（95% → 1.96）
- σ：总体标准差（未知时用样本标准差s估计）
- e：允许误差

**示例**：
```
要估计电商用户平均年龄，允许误差e=1岁，置信水平95%，
估计总体标准差σ=5岁。
n = (1.96² * 5²) / 1² = 96.04 ≈ 97
```

#### 5.2 估计总体比例时样本量

**公式**：
```
n = (Z² * p * (1-p)) / e²
```
其中：
- p：总体比例（未知时用0.5估计，最保守）

**示例**：
```
要估计电商用户购买转化率，允许误差e=0.02，置信水平95%，
估计总体比例p=0.1。
n = (1.96² * 0.1 * 0.9) / 0.02² = 864.36 ≈ 865
```

---

### 六、抽样误差

#### 6.1 定义

抽样误差是**样本统计量与总体参数之间的差异**。

#### 6.2 标准误（Standard Error）

**样本均值的标准误**：
```
SE(x̄) = σ / √n
```

**样本比例的标准误**：
```
SE(p̂) = √(p * (1-p) / n)
```

#### 6.3 置信区间

**总体均值的置信区间**：
```
x̄ ± Z * (σ / √n)
```

**总体比例的置信区间**：
```
p̂ ± Z * √(p̂ * (1-p̂) / n)
```

## 示例/应用场景

### 示例1：电商用户满意度调查

**业务问题**：估计电商用户的平均满意度评分。

**数据**：从100万用户中抽取1000个用户，调查满意度评分（1-5分）。

**分析**：

**Python操作**：
```python
import pandas as pd
import numpy as np
import scipy.stats as stats

# 读取样本数据
df = pd.read_csv('sample_satisfaction.csv')

# 计算样本均值和标准差
x_bar = df['satisfaction'].mean()
s = df['satisfaction'].std()

# 计算95%置信区间
n = len(df)
se = s / np.sqrt(n)
z = stats.norm.ppf(0.975)  # 95%置信水平

ci_lower = x_bar - z * se
ci_upper = x_bar + z * se

print(f"样本均值: {x_bar}")
print(f"95%置信区间: [{ci_lower}, {ci_upper}]")
```

**洞察与建议**：
- 如果置信区间较窄，说明估计精度高
- 如果置信区间较宽，说明估计精度低，需要增加样本量
- 可以根据置信区间制定用户满意度提升策略

### 示例2：电商用户购买转化率估计

**业务问题**：估计电商用户的购买转化率。

**数据**：从100万用户中抽取1000个用户，观察是否购买。

**分析**：

**Python操作**：
```python
import pandas as pd
import numpy as np
import scipy.stats as stats

# 读取样本数据
df = pd.read_csv('sample_conversion.csv')

# 计算样本转化率
p_hat = df['purchased'].mean()

# 计算95%置信区间
n = len(df)
se = np.sqrt(p_hat * (1 - p_hat) / n)
z = stats.norm.ppf(0.975)  # 95%置信水平

ci_lower = p_hat - z * se
ci_upper = p_hat + z * se

print(f"样本转化率: {p_hat}")
print(f"95%置信区间: [{ci_lower}, {ci_upper}]")
```

**洞察与建议**：
- 如果转化率置信区间不包含0.1，说明转化率显著不同于0.1
- 可以根据转化率置信区间制定营销策略
- 可以对比不同用户群体的转化率置信区间

### 示例3：电商商品差评率估计

**业务问题**：估计电商商品的差评率。

**数据**：从1万件商品中抽取500件商品，观察是否差评。

**分析**：

**Python操作**：
```python
import pandas as pd
import numpy as np
import scipy.stats as stats

# 读取样本数据
df = pd.read_csv('sample_negative_reviews.csv')

# 计算样本差评率
p_hat = df['negative'].mean()

# 计算95%置信区间
n = len(df)
se = np.sqrt(p_hat * (1 - p_hat) / n)
z = stats.norm.ppf(0.975)  # 95%置信水平

ci_lower = p_hat - z * se
ci_upper = p_hat + z * se

print(f"样本差评率: {p_hat}")
print(f"95%置信区间: [{ci_lower}, {ci_upper}]")
```

**洞察与建议**：
- 如果差评率置信区间不包含0.05，说明差评率显著不同于5%
- 可以根据差评率置信区间制定商品质量改进策略
- 可以对比不同商品类别的差评率置信区间

## 最佳实践

### 1. 根据总体特征，选择合适的抽样方法

**不推荐**（盲目使用简单随机抽样）：

```
无论什么总体，都使用简单随机抽样。
```

**推荐**（根据总体特征，选择合适的抽样方法）：

```
- 总体同质性强 → 简单随机抽样
- 总体异质性强 → 分层抽样
- 总体量大 → 系统抽样
- 总体地理分布广 → 整群抽样
```

### 2. 根据允许误差和置信水平，计算样本量

**不推荐**（随意确定样本量）：

```
随便抽1000个样本。
```

**推荐**（根据允许误差和置信水平，计算样本量）：

```
- 确定允许误差e
- 确定置信水平（通常95%）
- 估计总体标准差σ或总体比例p
- 使用公式计算样本量n
```

### 3. 使用置信区间进行统计推断

**不推荐**（只报告样本统计量）：

```
样本转化率5%。
```

**推荐**（使用置信区间进行统计推断）：

```
样本转化率5%，95%置信区间[4.2%, 5.8%]。
```

### 4. 考虑抽样框误差和非抽样误差

**不推荐**（只考虑抽样误差）：

```
抽样误差是唯一误差来源。
```

**推荐**（考虑抽样框误差和非抽样误差）：

```
- 抽样框误差：抽样框不完整或不准确
- 非抽样误差：无回答误差、测量误差等
- 需要采取相应措施减少这些误差
```

## 常见错误

### 1. 盲目使用简单随机抽样

**错误示例**：

```
总体异质性强，仍使用简单随机抽样。
```

**正确做法**：

```
总体异质性强，使用分层抽样提高精度。
```

### 2. 随意确定样本量

**错误示例**：

```
随便抽1000个样本。
```

**正确做法**：

```
根据允许误差和置信水平，计算样本量。
```

### 3. 只报告样本统计量，不报告置信区间

**错误示例**：

```
样本转化率5%。
```

**正确做法**：

```
样本转化率5%，95%置信区间[4.2%, 5.8%]。
```

### 4. 不考虑抽样框误差和非抽样误差

**错误示例**：

```
只考虑抽样误差，不考虑其他误差来源。
```

**正确做法**：

```
考虑抽样框误差和非抽样误差，并采取相应措施减少这些误差。
```

### 5. 混淆总体参数和样本统计量

**错误示例**：

```
使用样本均值x̄估计总体参数μ，但混淆两者概念。
```

**正确做法**：

```
明确区分总体参数和样本统计量，样本统计量用于估计总体参数。
```
