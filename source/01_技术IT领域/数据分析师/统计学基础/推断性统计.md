# 推断性统计

## 定义

推断性统计（Inferential Statistics）是指利用**样本数据**推断**总体特征**的统计方法。它包括两大核心内容：

1. **参数估计（Parameter Estimation）**：用样本统计量估计总体参数
2. **假设检验（Hypothesis Testing）**：检验关于总体的假设是否成立

推断性统计是数据分析师进行**统计推断**和**决策**的基础工具。

---

## 核心概念

### 1. 总体 vs 样本

| 概念 | 说明 | 符号 |
|------|------|------|
| **总体（Population）** | 研究对象的全体 | 均值 μ、方差 σ²、比例 p |
| **样本（Sample）** | 从总体中抽取的一部分 | 均值 x̄、方差 s²、比例 p̂ |

### 2. 抽样分布（Sampling Distribution）

**定义**：样本统计量（如均值 x̄）的概率分布。

**核心定理**：**中心极限定理（CLT）**

> 无论总体服从什么分布，只要样本量 n 足够大（通常 n≥30），样本均值 x̄ 的抽样分布近似服从**正态分布**。

**公式**：
```
x̄ ~ N(μ, σ²/n)
```

即：样本均值的均值 = 总体均值 μ，样本均值的方差 = 总体方差 σ²/n。

### 3. 标准误（Standard Error, SE）

**定义**：样本统计量的标准差（衡量抽样误差的大小）。

**公式**：
- 样本均值的标准误：SE(x̄) = σ / √n （总体标准差 σ 已知）
- 样本均值的标准误（估计）：SE(x̄) = s / √n （用样本标准差 s 估计）

## 详细内容

### 一、参数估计

#### 1.1 点估计（Point Estimation）

**定义**：用样本统计量直接估计总体参数。

**示例**：
- 用样本均值 x̄ 估计总体均值 μ
- 用样本比例 p̂ 估计总体比例 p

**优点**：简单直观

**缺点**：没有考虑抽样误差，无法知道估计的准确程度

#### 1.2 区间估计（Interval Estimation）

**定义**：给出一个区间（置信区间），并说明总体参数落在这个区间的可能性（置信水平）。

**置信区间的公式**（总体方差 σ 已知）：

```
置信区间 = x̄ ± z*(σ/√n)
```

其中：
- x̄：样本均值
- z*：临界值（如95%置信水平对应 z* = 1.96）
- σ/√n：标准误

**常用置信水平与临界值**：

| 置信水平 | 临界值 z* |
|----------|------------|
| 90% | 1.645 |
| 95% | 1.96 |
| 99% | 2.576 |

**示例**：

> 从某学校随机抽取100名学生，平均身高 x̄ = 170cm，总体标准差 σ = 10cm。求总体平均身高的95%置信区间。

**解**：
```
置信区间 = 170 ± 1.96*(10/√100)
         = 170 ± 1.96*(10/10)
         = 170 ± 1.96
         = [168.04, 171.96]
```

**解释**：我们有95%的把握认为，该校学生的平均身高在168.04cm到171.96cm之间。

### 二、假设检验

#### 2.1 假设检验的基本步骤

1. **提出假设**：
   - 原假设 H₀（Null Hypothesis）：通常是不存在差异、没有效果的假设
   - 备择假设 H₁（Alternative Hypothesis）：通常是存在差异、有效果的假设
2. **选择检验统计量**：根据数据类型和样本量选择合适的检验统计量（如 z 统计量、t 统计量）
3. **确定显著性水平 α**：通常取 α = 0.05
4. **计算 p 值**：在原假设成立的条件下，观察到当前样本或更极端情况的概率
5. **做出决策**：
   - 如果 p 值 < α，拒绝原假设 H₀
   - 如果 p 值 ≥ α，不拒绝原假设 H₀

#### 2.2 两类错误

| 决策 \ 真实情况 | H₀ 为真（原假设成立） | H₀ 为假（原假设不成立） |
|----------------|----------------------|------------------------|
| **拒绝 H₀** | 第一类错误（Type I Error） | 正确决策 |
| **不拒绝 H₀** | 正确决策 | 第二类错误（Type II Error） |

- **第一类错误（α）**：原假设为真时拒绝原假设（"假阳性"）
- **第二类错误（β）**：原假设为假时不拒绝原假设（"假阴性"）

**关系**：α 和 β 此消彼长（样本量固定时）。增大样本量可以同时降低 α 和 β。

#### 2.3 单样本均值检验（z 检验）

**条件**：总体标准差 σ 已知，或样本量 n 足够大（n≥30）

**检验统计量**：
```
z = (x̄ - μ₀) / (σ/√n)
```

其中 μ₀ 是原假设中的总体均值。

**示例**：

> 某品牌手机电池续航时间宣称平均为10小时。随机抽取50部手机测试，平均续航 x̄ = 9.5小时，总体标准差 σ = 2小时。在 α = 0.05 的显著性水平下，检验该品牌宣称是否成立。

**解**：
1. 提出假设：
   - H₀: μ = 10 （宣称成立）
   - H₁: μ ≠ 10 （宣称不成立）
2. 计算检验统计量：
   ```
   z = (9.5 - 10) / (2/√50) = -0.5 / 0.2828 ≈ -1.77
   ```
3. 确定 p 值：
   - 双侧检验，p 值 = 2 × P(Z < -1.77) ≈ 2 × 0.0384 = 0.0768
4. 做出决策：
   - p 值 = 0.0768 > α = 0.05，不拒绝原假设 H₀
5. 结论：样本数据没有提供足够证据否定该品牌的宣称。

#### 2.4 单样本均值检验（t 检验）

**条件**：总体标准差 σ 未知，样本量 n 较小（n<30）

**检验统计量**：
```
t = (x̄ - μ₀) / (s/√n)  ~ t(n-1)
```

其中 s 是样本标准差，t(n-1) 表示自由度为 n-1 的 t 分布。

#### 2.5 两个独立样本均值检验（双样本 t 检验）

**条件**：两个独立样本，总体标准差未知但假定相等

**检验统计量**：
```
t = (x̄₁ - x̄₂) / Sp√(1/n₁ + 1/n₂)  ~ t(n₁+n₂-2)
```

其中 Sp² 是合并方差（Pooled Variance）：
```
Sp² = [(n₁-1)s₁² + (n₂-1)s₂²] / (n₁+n₂-2)
```

#### 2.6 比例检验

**单样本比例检验**（z 检验）：

**检验统计量**：
```
z = (p̂ - p₀) / √(p₀(1-p₀)/n)
```

其中 p̂ 是样本比例，p₀ 是原假设中的总体比例。

## 示例/应用场景

### 示例1：电商订单分析

**需求**：某电商平台宣称平均订单金额为200元。随机抽取500个订单，平均订单金额为195元，样本标准差为50元。在 α = 0.05 的显著性水平下，检验该平台宣称是否成立。

**假设检验步骤**：

1. 提出假设：
   - H₀: μ = 200 （宣称成立）
   - H₁: μ ≠ 200 （宣称不成立）
2. 选择检验统计量（总体标准差未知，使用 t 检验）：
   ```
   t = (195 - 200) / (50/√500) = -5 / 2.236 ≈ -2.236
   ```
3. 确定 p 值：
   - 自由度 df = 500-1 = 499
   - 双侧检验，p 值 ≈ 0.026
4. 做出决策：
   - p 值 = 0.026 < α = 0.05，拒绝原假设 H₀
5. 结论：样本数据提供了足够证据否定该平台的宣称，平均订单金额显著低于200元。

### 示例2：员工薪资分析

**需求**：某公司男员工平均薪资为35万元，女员工平均薪资为32万元。随机抽取男员工100人，女员工80人，样本标准差分别为15万元和12万元。在 α = 0.05 的显著性水平下，检验该公司是否存在性别薪资差异。

**假设检验步骤**：

1. 提出假设：
   - H₀: μ₁ = μ₂ （不存在性别薪资差异）
   - H₁: μ₁ ≠ μ₂ （存在性别薪资差异）
2. 选择检验统计量（双样本 t 检验）：
   ```
   Sp² = [(100-1)×15² + (80-1)×12²] / (100+80-2)
        = [99×225 + 79×144] / 178
        = [22275 + 11376] / 178
        = 33651 / 178 ≈ 189.05
   
   t = (35 - 32) / √(189.05×(1/100 + 1/80))
     = 3 / √(189.05×0.0225)
     = 3 / √4.2536
     ≈ 3 / 2.062 ≈ 1.455
   ```
3. 确定 p 值：
   - 自由度 df = 100+80-2 = 178
   - 双侧检验，p 值 ≈ 0.148
4. 做出决策：
   - p 值 = 0.148 > α = 0.05，不拒绝原假设 H₀
5. 结论：样本数据没有提供足够证据说明该公司存在性别薪资差异。

### 示例3：用户转化率分析

**需求**：某App改版前转化率为10%，改版后随机抽取1000个用户，转化率为12%。在 α = 0.05 的显著性水平下，检验改版是否显著提升了转化率。

**假设检验步骤**：

1. 提出假设：
   - H₀: p = 0.10 （改版没有提升转化率）
   - H₁: p > 0.10 （改版提升了转化率）
2. 选择检验统计量（单样本比例检验，单侧检验）：
   ```
   z = (0.12 - 0.10) / √(0.10×(1-0.10)/1000)
     = 0.02 / √0.00009
     = 0.02 / 0.00949 ≈ 2.108
   ```
3. 确定 p 值：
   - 单侧检验，p 值 = P(Z > 2.108) ≈ 0.0175
4. 做出决策：
   - p 值 = 0.0175 < α = 0.05，拒绝原假设 H₀
5. 结论：样本数据提供了足够证据说明改版显著提升了转化率。

## 数据分析师考点

### 推断性统计常见考点

1. **参数估计 vs 假设检验**：参数估计是估计总体参数的值，假设检验是检验关于总体的假设是否成立
2. **点估计 vs 区间估计**：点估计没有给出估计的准确程度，区间估计给出了置信区间和置信水平
3. **置信水平的解读**：95%置信水平表示，如果重复抽样100次，大约95次计算出的置信区间会包含总体参数
4. **假设检验的步骤**：提出假设 → 选择检验统计量 → 确定显著性水平 → 计算 p 值 → 做出决策
5. **两类错误**：第一类错误（α，假阳性）、第二类错误（β，假阴性）
6. **p 值的解读**：p 值是在原假设成立的条件下，观察到当前样本或更极端情况的概率；p 值越小，拒绝原假设的证据越强
7. **z 检验 vs t 检验**：z 检验用于总体标准差已知或大样本，t 检验用于总体标准差未知且小样本
8. **单侧检验 vs 双侧检验**：单侧检验的备择假设是">"或"<"，双侧检验的备择假设是"≠"

### 实战考点

1. **样本量的确定**：
   - 样本量越大，标准误越小，估计越精确
   - 样本量越大，假设检验的功效（Power = 1-β）越大
2. **中心极限定理的应用**：
   - 无论总体分布如何，只要样本量 n≥30，样本均值近似服从正态分布
   - 这是很多统计推断方法的理论基础
3. **p 值的滥用**：
   - p 值小只能说明结果统计显著，不能说明结果实际显著（Effect Size 可能很小）
   - 不能只用 p 值做决策，还要考虑效应量（Effect Size）和实际应用背景
4. **多重比较问题**：
   - 同时进行多次假设检验会增加第一类错误的风险
   - 需要用 Bonferroni 校正等方法调整显著性水平

## 最佳实践

### 1. 明确业务问题，再选择统计方法

**不推荐**（盲目使用假设检验）：
```
拿到数据就做假设检验，没有明确的业务问题。
```

**推荐**（先明确业务问题）：
```
业务问题：改版是否显著提升了转化率？
统计方法：单样本比例检验（单侧检验）。
```

### 2. 同时报告效应量和 p 值

**不推荐**（只报告 p 值）：
```
改版后转化率显著提升（p = 0.02）。
```

**推荐**（同时报告效应量和 p 值）：
```
改版后转化率显著提升（p = 0.02，转化率的提升为2个百分点，效应量中等）。
```

**理由**：p 值小只能说明结果统计显著，不能说明结果实际显著。效应量可以说明实际显著性。

### 3. 合理选择显著性水平 α

**不推荐**（盲目使用 α = 0.05）：
```
所有假设检验都使用 α = 0.05。
```

**推荐**（根据业务背景选择 α）：
```
- 医疗试验（假阳性代价大）：α = 0.01
- 推荐算法优化（假阳性代价小）：α = 0.10
```

### 4. 注意样本量的影响

**问题**：样本量非常大时，即使效应量很小，p 值也会很小（统计显著但无实际意义）。

**解决方法**：同时报告效应量和置信区间，判断结果的实际意义。

## 常见错误

### 1. 混淆总体参数和样本统计量

**错误示例**：
```
用 μ 表示样本均值（错误！μ 是总体均值）。
```

**正确做法**：
```
- 总体均值：μ
- 样本均值：x̄
- 总体比例：p
- 样本比例：p̂
```

### 2. 错误解读 p 值

**错误解读**：
```
p = 0.03 表示原假设成立的概率是 3%（错误！）。
```

**正确解读**：
```
p = 0.03 表示在原假设成立的条件下，观察到当前样本或更极端情况的概率是 3%。
```

### 3. 混淆统计显著和实际显著

**错误示例**：
```
p 值很小（如 p < 0.001），就认为结果非常有意义（可能效应量很小，无实际意义）。
```

**正确做法**：
```
同时报告 p 值和效应量，判断结果的实际意义。
```

### 4. 忽略样本量的影响

**错误示例**：
```
样本量非常大（如 n=100,000），p 值很小（如 p < 0.001），就认为结果非常有意义（可能效应量很小，无实际意义）。
```

**正确做法**：
```
同时报告效应量和置信区间，判断结果的实际意义。
```

### 5. 错误选择单侧检验或双侧检验

**错误示例**：
```
业务问题是"改版是否提升了转化率"（应该用单侧检验），但使用了双侧检验（更难拒绝原假设）。
```

**正确做法**：
```
根据业务问题选择单侧检验或双侧检验：
- 业务问题关注"是否不同"（≠）→ 双侧检验
- 业务问题关注"是否大于"（>）或"是否小于"（<）→ 单侧检验
```

## 总结

推断性统计是数据分析师进行统计推断和决策的基础工具，核心要点包括：

1. **掌握参数估计**：点估计（简单但不考虑抽样误差）、区间估计（给出置信区间和置信水平）
2. **掌握假设检验的步骤**：提出假设 → 选择检验统计量 → 确定显著性水平 → 计算 p 值 → 做出决策
3. **理解两类错误**：第一类错误（α，假阳性）、第二类错误（β，假阴性）
4. **熟练使用常用检验方法**：z 检验（总体标准差已知或大样本）、t 检验（总体标准差未知且小样本）、比例检验
5. **正确解读 p 值**：p 值是在原假设成立的条件下，观察到当前样本或更极端情况的概率
6. **同时报告效应量和 p 值**：避免混淆统计显著和实际显著

推断性统计是数据分析师的必备技能，需要在实践中不断积累经验。

## 扩展阅读

### 高级主题

1. **方差分析（ANOVA）**：比较三个及以上总体均值是否存在显著差异
2. **卡方检验（Chi-square Test）**：检验分类变量之间是否独立
3. **非参数检验**：不依赖总体分布假设的检验方法（如 Wilcoxon 秩和检验）
4. **贝叶斯统计推断**：基于贝叶斯定理的统计推断（需要先验分布）

### 实战案例

1. **电商分析**：A/B 测试（改版是否提升转化率）
2. **金融分析**：投资组合收益率是否显著优于基准
3. **用户行为分析**：改版是否显著提升用户留存率
4. **医疗试验**：新药是否显著优于安慰剂
