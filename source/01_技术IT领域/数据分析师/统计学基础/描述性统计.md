# 描述性统计

## 定义

描述性统计是**通过图表和数值**来**描述、总结、展示数据基本特征**的统计方法。

对于数据分析师而言，描述性统计是**理解数据、发现规律、识别异常**的第一步。

---

## 核心概念

### 1. 数据类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **数值型数据** | 可以用数字表示的数据 | 年龄、收入、温度 |
| **分类型数据** | 表示类别或属性的数据 | 性别、地区、产品类别 |

### 2. 描述性统计核心指标

| 类别 | 指标 | 说明 |
|------|------|------|
| **集中趋势** | 均值（Mean） | 所有数据的平均值 |
|  | 中位数（Median） | 排序后位于中间的值 |
|  | 众数（Mode） | 出现频率最高的值 |
| **离散程度** | 方差（Variance） | 数据与均值之差的平方的平均值 |
|  | 标准差（Standard Deviation） | 方差的平方根 |
|  | 极差（Range） | 最大值与最小值之差 |
|  | 四分位距（IQR） | 上四分位数与下四分位数之差 |
| **分布形态** | 偏度（Skewness） | 分布不对称性 |
|  | 峰度（Kurtosis） | 分布尖锐程度 |

---

## 详细内容

### 一、集中趋势

#### 1.1 均值（Mean）

**定义**：所有数据的平均值

**公式**：
```
均值 = (x₁ + x₂ + ... + xₙ) / n
```

**示例**：
```
数据：1, 2, 3, 4, 5
均值 = (1+2+3+4+5)/5 = 3
```

**优点**：利用所有数据信息
**缺点**：受极端值影响大

#### 1.2 中位数（Median）

**定义**：排序后位于中间的值

**计算方法**：
- 数据个数为奇数：中位数为中间的值
- 数据个数为偶数：中位数为中间两个值的平均值

**示例**：
```
数据：1, 2, 3, 4, 5
中位数 = 3

数据：1, 2, 3, 4
中位数 = (2+3)/2 = 2.5
```

**优点**：不受极端值影响
**缺点**：未利用所有数据信息

#### 1.3 众数（Mode）

**定义**：出现频率最高的值

**示例**：
```
数据：1, 2, 2, 3, 4
众数 = 2
```

**优点**：适用于分类型数据
**缺点**：可能不存在或不唯一

---

### 二、离散程度

#### 2.1 方差（Variance）

**定义**：数据与均值之差的平方的平均值

**公式**：
```
方差 = Σ(xᵢ - 均值)² / (n-1)
```

**示例**：
```
数据：1, 2, 3, 4, 5
均值 = 3
方差 = [(1-3)² + (2-3)² + (3-3)² + (4-3)² + (5-3)²] / (5-1)
     = [4 + 1 + 0 + 1 + 4] / 4
     = 10/4 = 2.5
```

**优点**：利用所有数据信息
**缺点**：单位与原数据不一致（平方）

#### 2.2 标准差（Standard Deviation）

**定义**：方差的平方根

**公式**：
```
标准差 = √方差
```

**示例**（接上例）：
```
标准差 = √2.5 ≈ 1.58
```

**优点**：单位与原数据一致
**缺点**：受极端值影响

#### 2.3 极差（Range）

**定义**：最大值与最小值之差

**公式**：
```
极差 = 最大值 - 最小值
```

**示例**：
```
数据：1, 2, 3, 4, 5
极差 = 5 - 1 = 4
```

**优点**：计算简单
**缺点**：只利用两个极端值，受极端值影响大

#### 2.4 四分位距（IQR）

**定义**：上四分位数与下四分位数之差

**公式**：
```
IQR = Q₃ - Q₁
```

**示例**：
```
数据：1, 2, 3, 4, 5, 6, 7, 8, 9
Q₁ = 2.5（第25百分位数）
Q₃ = 7.5（第75百分位数）
IQR = 7.5 - 2.5 = 5
```

**优点**：不受极端值影响
**缺点**：未利用所有数据信息

---

### 三、分布形态

#### 3.1 偏度（Skewness）

**定义**：分布不对称性

**判断**：
- 偏度 > 0：右偏（正偏）
- 偏度 = 0：对称
- 偏度 < 0：左偏（负偏）

**示例**：
```
收入数据通常右偏（少数人收入极高）
```

#### 3.2 峰度（Kurtosis）

**定义**：分布尖锐程度

**判断**：
- 峰度 > 0：尖峰（比正态分布更尖）
- 峰度 = 0：正态分布
- 峰度 < 0：平峰（比正态分布更平）

## 示例/应用场景

### 示例1：电商用户年龄分析

**业务问题**：分析电商用户的年龄分布特征。

**数据**：用户年龄数据（数值型）

**分析**：

**Excel操作**：
1. 使用`AVERAGE()`函数计算均值
2. 使用`MEDIAN()`函数计算中位数
3. 使用`MODE()`函数计算众数
4. 使用`VAR.S()`函数计算方差
5. 使用`STDEV.S()`函数计算标准差
6. 使用`MAX()-MIN()`计算极差

**Python操作**：
```python
import pandas as pd
import numpy as np

# 读取数据
df = pd.read_csv('users.csv')

# 计算描述性统计
print(df['age'].mean())      # 均值
print(df['age'].median())    # 中位数
print(df['age'].mode())      # 众数
print(df['age'].var())       # 方差
print(df['age'].std())       # 标准差
print(df['age'].max() - df['age'].min())  # 极差
print(df['age'].quantile(0.75) - df['age'].quantile(0.25))  # IQR
```

**洞察与建议**：
- 如果均值 > 中位数，说明年龄分布右偏（存在高龄用户）
- 如果标准差大，说明用户年龄差异大
- 可以针对主要年龄段进行精准营销

### 示例2：电商商品价格分析

**业务问题**：分析电商商品的价格分布特征。

**数据**：商品价格数据（数值型）

**分析**：

**Excel操作**：
1. 创建直方图：插入 → 图表 → 直方图
2. 计算描述性统计：数据 → 数据分析 → 描述统计

**Python操作**：
```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 读取数据
df = pd.read_csv('products.csv')

# 绘制直方图
plt.hist(df['price'], bins=10)
plt.xlabel('Price')
plt.ylabel('Frequency')
plt.title('Price Distribution')
plt.show()

# 计算描述性统计
print(df['price'].describe())
```

**洞察与建议**：
- 如果价格分布右偏，说明存在高价商品
- 可以针对主流价格区间进行推荐
- 可以识别异常高价商品（可能是奢侈品或数据错误）

### 示例3：电商订单金额分析

**业务问题**：分析电商订单的金额分布特征。

**数据**：订单金额数据（数值型）

**分析**：

**Excel操作**：
1. 使用`SKEW()`函数计算偏度
2. 使用`KURT()`函数计算峰度
3. 绘制箱线图：插入 → 图表 → 箱线图

**Python操作**：
```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 读取数据
df = pd.read_csv('orders.csv')

# 计算偏度和峰度
print(df['amount'].skew())   # 偏度
print(df['amount'].kurt())   # 峰度

# 绘制箱线图
plt.boxplot(df['amount'])
plt.ylabel('Amount')
plt.title('Amount Boxplot')
plt.show()
```

**洞察与建议**：
- 如果订单金额右偏，说明大部分订单金额较小，少数订单金额较大
- 可以针对大额订单用户进行VIP服务
- 可以识别异常大额订单（可能是批发或数据错误）

## 最佳实践

### 1. 根据数据特征，选择合适的集中趋势指标

**不推荐**（盲目使用均值）：

```
无论什么数据，都使用均值作为集中趋势指标。
```

**推荐**（根据数据特征，选择合适的集中趋势指标）：

```
- 数据分布对称 → 使用均值
- 数据分布偏态或有极端值 → 使用中位数
- 分类型数据 → 使用众数
```

### 2. 同时报告集中趋势和离散程度

**不推荐**（只报告集中趋势）：

```
电商用户平均年龄30岁。
```

**推荐**（同时报告集中趋势和离散程度）：

```
电商用户平均年龄30岁，标准差5岁，说明大部分用户年龄在25-35岁之间。
```

### 3. 使用可视化辅助描述性统计

**不推荐**（只报告数值）：

```
电商用户平均年龄30岁，中位数28岁，标准差5岁。
```

**推荐**（使用可视化辅助描述性统计）：

```
电商用户平均年龄30岁，中位数28岁，标准差5岁。
[直方图显示年龄分布]
```

### 4. 结合业务场景解释描述性统计结果

**不推荐**（只报告统计结果）：

```
电商用户平均年龄30岁。
```

**推荐**（结合业务场景解释描述性统计结果）：

```
电商用户平均年龄30岁，说明主要用户群体是年轻人，可以针对年轻人喜欢的商品进行推荐。
```

## 常见错误

### 1. 盲目使用均值作为集中趋势指标

**错误示例**：

```
计算收入数据的均值，忽略极端高收入的影响。
```

**正确做法**：

```
收入数据通常右偏，使用中位数作为集中趋势指标更合适。
```

### 2. 只报告集中趋势，不报告离散程度

**错误示例**：

```
电商用户平均年龄30岁。
```

**正确做法**：

```
电商用户平均年龄30岁，标准差5岁，说明大部分用户年龄在25-35岁之间。
```

### 3. 不使用可视化辅助描述性统计

**错误示例**：

```
电商用户平均年龄30岁，中位数28岁，标准差5岁。
```

**正确做法**：

```
电商用户平均年龄30岁，中位数28岁，标准差5岁。
[直方图显示年龄分布]
```

### 4. 不结合业务场景解释描述性统计结果

**错误示例**：

```
电商用户平均年龄30岁。
```

**正确做法**：

```
电商用户平均年龄30岁，说明主要用户群体是年轻人，可以针对年轻人喜欢的商品进行推荐。
```

### 5. 混淆总体参数和样本统计量

**错误示例**：

```
使用`VAR.P()`函数计算样本方差。
```

**正确做法**：

```
- 总体方差 → 使用`VAR.P()`函数
- 样本方差 → 使用`VAR.S()`函数
```
