# 需求与供给

## 需求

### 需求的定义

需求是指消费者在一定时期内，在各种可能的价格水平下，愿意并且能够购买的商品或服务的数量。

### 需求的影响因素

1. **商品本身的价格**：价格越高，需求量越少；价格越低，需求量越多
2. **消费者的收入水平**：正常品的需求量与收入正相关；劣等品的需求量与收入负相关
3. **相关商品的价格**：替代品价格上升，需求量增加；互补品价格上升，需求量减少
4. **消费者的偏好**：偏好增强，需求量增加
5. **消费者对未来价格的预期**：预期价格上涨，当前需求量增加
6. **人口数量和结构**：人口增加，需求量增加

### 需求曲线

需求曲线是表示商品价格与需求量之间关系的曲线，向右下方倾斜，斜率为负。

### 需求函数

需求函数表示需求量与影响因素之间的关系，一般形式为：Qd = f(P, I, Pr, T, Pe, N)

其中，Qd为需求量，P为价格，I为收入，Pr为相关商品价格，T为偏好，Pe为预期价格，N为人口数量。

## 供给

### 供给的定义

供给是指生产者在一定时期内，在各种可能的价格水平下，愿意并且能够提供的商品或服务的数量。

### 供给的影响因素

1. **商品本身的价格**：价格越高，供给量越多；价格越低，供给量越少
2. **生产成本**：成本上升，供给量减少；成本下降，供给量增加
3. **生产技术**：技术进步，供给量增加
4. **相关商品的价格**：替代品价格上升，供给量减少；互补品价格上升，供给量增加
5. **生产者对未来价格的预期**：预期价格上涨，当前供给量减少
6. **政府政策**：税收增加，供给量减少；补贴增加，供给量增加

### 供给曲线

供给曲线是表示商品价格与供给量之间关系的曲线，向右上方倾斜，斜率为正。

### 供给函数

供给函数表示供给量与影响因素之间的关系，一般形式为：Qs = f(P, C, T, Pr, Pe, G)

其中，Qs为供给量，P为价格，C为成本，T为技术，Pr为相关商品价格，Pe为预期价格，G为政府政策。

## 市场均衡

### 均衡价格和均衡数量

均衡价格是指市场上供给量等于需求量时的价格，均衡数量是指均衡价格下的供给量和需求量。

### 市场均衡的形成

当市场价格高于均衡价格时，供给量大于需求量，出现过剩，价格会下降；当市场价格低于均衡价格时，需求量大于供给量，出现短缺，价格会上升。最终，市场会达到均衡状态。

### 均衡的变动

1. **需求变动对均衡的影响**：需求增加，均衡价格上升，均衡数量增加；需求减少，均衡价格下降，均衡数量减少
2. **供给变动对均衡的影响**：供给增加，均衡价格下降，均衡数量增加；供给减少，均衡价格上升，均衡数量减少
3. **需求和供给同时变动对均衡的影响**：取决于两者变动的方向和幅度

## 弹性

### 需求价格弹性

需求价格弹性是指需求量对价格变动的反应程度，计算公式为：

需求价格弹性 = 需求量变动的百分比 / 价格变动的百分比

### 需求价格弹性的类型

1. **富有弹性**：弹性系数大于1，需求量对价格变动反应敏感
2. **缺乏弹性**：弹性系数小于1，需求量对价格变动反应不敏感
3. **单位弹性**：弹性系数等于1，需求量变动的百分比等于价格变动的百分比
4. **完全弹性**：弹性系数无穷大，价格微小变动会导致需求量巨大变动
5. **完全无弹性**：弹性系数为0，价格变动不影响需求量

### 影响需求价格弹性的因素

1. **商品的可替代性**：替代品越多，弹性越大
2. **商品的用途广泛性**：用途越广泛，弹性越大
3. **商品对消费者生活的重要程度**：必需品弹性小，奢侈品弹性大
4. **商品的消费支出在消费者预算总支出中所占的比重**：比重越大，弹性越大
5. **消费者调整需求量的时间**：时间越长，弹性越大

### 供给价格弹性

供给价格弹性是指供给量对价格变动的反应程度，计算公式为：

供给价格弹性 = 供给量变动的百分比 / 价格变动的百分比

### 供给价格弹性的类型

1. **富有弹性**：弹性系数大于1，供给量对价格变动反应敏感
2. **缺乏弹性**：弹性系数小于1，供给量对价格变动反应不敏感
3. **单位弹性**：弹性系数等于1，供给量变动的百分比等于价格变动的百分比
4. **完全弹性**：弹性系数无穷大，价格微小变动会导致供给量巨大变动
5. **完全无弹性**：弹性系数为0，价格变动不影响供给量

### 影响供给价格弹性的因素

1. **时间因素**：时间越长，弹性越大
2. **生产周期和自然条件**：生产周期越长，弹性越小
3. **生产的难易程度**：生产越容易，弹性越大
4. **生产要素的供给弹性**：生产要素供给弹性越大，产品供给弹性越大
5. **生产的技术水平**：技术水平越高，弹性越大
