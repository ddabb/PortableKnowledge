# 建设工程经济

## 工程经济基础

### 资金时间价值的计算及应用
**资金时间价值的概念**：
- 资金随着时间的推移而产生的增值
- 不同时点的资金具有不同的价值

**利息和利率**：
- 单利计算：I = P × i × n
- 复利计算：F = P(1 + i)^n
- 名义利率和实际利率：i = (1 + r/m)^m - 1

**现金流量图**：
- 横轴表示时间轴
- 纵轴表示现金流量
- 箭头向上表示现金流入
- 箭头向下表示现金流出

**资金等值计算**：
- 一次支付终值计算：F = P(1 + i)^n
- 一次支付现值计算：P = F/(1 + i)^n
- 等额支付终值计算：F = A[(1 + i)^n - 1]/i
- 等额支付现值计算：P = A[1 - (1 + i)^-n]/i
- 资金回收计算：A = P[i(1 + i)^n]/[(1 + i)^n - 1]
- 偿债基金计算：A = F[i]/[(1 + i)^n - 1]

### 技术方案经济效果评价
**经济效果评价的内容**：
- 盈利能力分析
- 偿债能力分析
- 财务生存能力分析

**经济效果评价的方法**：
- 静态评价方法：投资收益率、静态投资回收期、偿债能力指标
- 动态评价方法：财务内部收益率（FIRR）、财务净现值（FNPV）、动态投资回收期

**基准收益率的确定**：
- 基准收益率的概念：企业或行业的最低可接受收益率
- 基准收益率的确定方法：资本资产定价模型、加权平均资本成本法等

### 技术方案不确定性分析
**不确定性分析的概念**：
- 技术方案评价中所采用的数据大部分来自预测和估算
- 有一定的不确定性和风险

**盈亏平衡分析**：
- 盈亏平衡点的计算
- 盈亏平衡分析的应用

**敏感性分析**：
- 单因素敏感性分析
- 多因素敏感性分析
- 敏感性分析的应用

### 技术方案现金流量表的编制
**现金流量表的分类**：
- 投资现金流量表：以技术方案建设所需的总投资作为计算基础
- 资本金现金流量表：以资本金作为计算基础
- 投资各方现金流量表：以投资各方出资额作为计算基础
- 财务计划现金流量表：反映技术方案计算期各年的投资、融资及经营活动所产生的现金流入和流出

**现金流量表的编制方法**：
- 直接法
- 间接法

## 工程财务

### 财务会计基础
**会计的职能**：
- 核算职能：确认、计量、记录、报告
- 监督职能：真实性、合法性、合理性监督

**会计核算的原则**：
- 客观性原则
- 相关性原则
- 可比性原则
- 一贯性原则
- 及时性原则
- 明晰性原则
- 权责发生制原则
- 配比原则
- 谨慎性原则
- 历史成本原则
- 划分收益性支出与资本性支出原则

**会计要素**：
- 资产：流动资产、长期资产
- 负债：流动负债、长期负债
- 所有者权益：实收资本、资本公积、盈余公积、未分配利润
- 收入：主营业务收入、其他业务收入
- 费用：生产成本、期间费用
- 利润：营业利润、利润总额、净利润

**会计等式**：
- 静态会计等式：资产 = 负债 + 所有者权益
- 动态会计等式：收入 - 费用 = 利润
- 综合会计等式：资产 = 负债 + 所有者权益 + (收入 - 费用)

### 成本与费用
**费用与成本的关系**：
- 费用是指企业在日常活动中发生的、会导致所有者权益减少的、与向所有者分配利润无关的经济利益的总流出
- 成本是指企业为生产产品、提供劳务而发生的各种耗费

**成本费用的计算**：
- 固定资产折旧：平均年限法、工作量法、双倍余额递减法、年数总和法
- 无形资产摊销
- 工程成本：直接费用、间接费用
- 期间费用：管理费用、财务费用

### 收入
**收入的概念**：
- 收入是指企业在日常活动中形成的、会导致所有者权益增加的、与所有者投入资本无关的经济利益的总流入

**收入的分类**：
- 按性质分类：销售商品收入、提供劳务收入、让渡资产使用权收入
- 按主次分类：主营业务收入、其他业务收入

**收入的确认**：
- 销售商品收入的确认
- 提供劳务收入的确认
- 让渡资产使用权收入的确认

### 利润和所得税费用
**利润的计算**：
- 营业利润 = 营业收入 - 营业成本 - 税金及附加 - 销售费用 - 管理费用 - 财务费用 - 信用减值损失 - 资产减值损失 + 公允价值变动收益 + 投资收益
- 利润总额 = 营业利润 + 营业外收入 - 营业外支出
- 净利润 = 利润总额 - 所得税费用

**所得税费用的计算**：
- 应纳税所得额 = 利润总额 + 纳税调整增加额 - 纳税调整减少额
- 所得税费用 = 应纳税所得额 × 所得税税率

### 企业财务报表
**财务报表的组成**：
- 资产负债表
- 利润表

- 所有者权益变动表

- 重要性
- 可比性
- 及时性
- 清晰性

### 财务分析
**财务分析的指标**：
- 偿债能力指标：资产负债率、流动比率、速动比率
- 营运能力指标：总资产周转率、流动资产周转率、存货周转率、应收账款周转率
- 盈利能力指标：净资产收益率、总资产报酬率、营业净利率
- 发展能力指标：营业增长率、资本积累率

**财务分析的方法**：
- 趋势分析法
- 比率分析法
- 因素分析法

### 筹资管理
**筹资的分类**：
- 按筹集资金使用期限长短：长期筹资、短期筹资
- 按筹资活动是否通过金融机构：直接筹资、间接筹资
- 按资金来源范围：内部筹资、外部筹资

**筹资的方式**：
- 短期借款
- 商业信用
- 长期借款
- 发行股票
- 发行债券
- 融资租赁

**资金成本的计算**：
- 个别资金成本
- 综合资金成本

### 流动资产财务管理
**现金管理**：
- 现金的使用范围
- 现金的库存限额
- 现金日常管理

**应收账款管理**：
- 应收账款的成本：机会成本、管理成本、坏账成本
- 信用政策的确定：信用期间、信用标准、现金折扣政策

**存货管理**：

### 建设项目总投资
**建设项目总投资的构成**：
- 建设投资：设备及工器具购置费、建筑安装工程费、工程建设其他费用、预备费、建设期利息

**设备及工器具购置费的组成**：
- 设备购置费：设备原价 + 设备运杂费

### 建设工程定额
**建设工程定额的分类**：
- 按生产要素内容分类：人工定额、材料消耗定额、施工机械台班使用定额
- 按编制程序和用途分类：施工定额、预算定额、概算定额、概算指标、投资估算指标
- 按编制单位和适用范围分类：国家定额、行业定额、地区定额、企业定额
- 按投资的费用性质分类：建筑工程定额、设备安装工程定额、建筑安装工程费用定额、工程建设其他费用定额

**材料消耗定额的编制**：

- 材料消耗定额的制定方法：观察法、试验法、统计法、理论计算法

- 施工机械台班使用定额的制定方法：技术测定法、统计分析法、比较类推法、经验估计法
