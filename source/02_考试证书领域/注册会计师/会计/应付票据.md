# 应付票据

## 应付票据的定义

应付票据是指企业购买材料、商品和接受劳务供应等而开出、承兑的商业汇票，包括商业承兑汇票和银行承兑汇票。

## 应付票据的分类

- **商业承兑汇票**：由付款人签发并承兑，或由收款人签发交由付款人承兑的汇票
- **银行承兑汇票**：由在承兑银行开立存款账户的存款人签发，由承兑银行承兑的汇票

## 应付票据的核算

### 开出应付票据

```
借：原材料（或库存商品等）
    应交税费——应交增值税（进项税额）
  贷：应付票据
```

### 支付银行承兑汇票手续费

```
借：财务费用
  贷：银行存款
```

### 应付票据到期

#### 到期支付票款

```
借：应付票据
  贷：银行存款
```

#### 到期无力支付票款

##### 商业承兑汇票

```
借：应付票据
  贷：应付账款
```

##### 银行承兑汇票

```
借：应付票据
  贷：短期借款
```

## 应付票据的账务处理示例

### 示例1：开出商业承兑汇票

1. 企业从A公司购入原材料一批，价款10,000元，增值税1,300元，开出一张3个月期限的商业承兑汇票。

   ```
   借：原材料 10,000
       应交税费——应交增值税（进项税额） 1,300
     贷：应付票据 11,300
   ```

2. 3个月后，票据到期，企业支付票款。

   ```
   借：应付票据 11,300
     贷：银行存款 11,300
   ```

### 示例2：开出银行承兑汇票

1. 企业从B公司购入商品一批，价款20,000元，增值税2,600元，开出一张6个月期限的银行承兑汇票，支付承兑手续费10元。

   ```
   借：库存商品 20,000
       应交税费——应交增值税（进项税额） 2,600
     贷：应付票据 22,600

   借：财务费用 10
     贷：银行存款 10
   ```

2. 6个月后，票据到期，企业无力支付票款。

   ```
   借：应付票据 22,600
     贷：短期借款 22,600
   ```

## 应付票据的列报

应付票据应当在资产负债表的流动负债部分列示。
