# 应付账款

## 应付账款的定义

应付账款是指企业因购买材料、商品或接受劳务供应等经营活动应支付的款项。

## 应付账款的确认

应付账款的确认时间通常以与所购买物资所有权有关的风险和报酬已经转移或劳务已经接受为标志。

## 应付账款的计量

应付账款一般按应付金额入账，而不按到期应付金额的现值入账。如果购入的资产在形成一笔应付账款时是带有现金折扣的，应付账款入账金额的确定按发票上记载的应付金额的总值（即不扣除折扣）记账。

## 应付账款的核算

### 发生应付账款

```
借：原材料（或库存商品等）
    应交税费——应交增值税（进项税额）
  贷：应付账款
```

### 偿还应付账款

```
借：应付账款
  贷：银行存款
```

### 转销应付账款

```
借：应付账款
  贷：营业外收入
```

## 现金折扣的处理

### 总价法

总价法是将未扣除现金折扣前的金额作为应付账款的入账价值。

#### 发生应付账款

```
借：原材料（或库存商品等）
    应交税费——应交增值税（进项税额）
  贷：应付账款（总价）
```

#### 享受现金折扣

```
借：应付账款（总价）
  贷：银行存款（实际支付金额）
    财务费用（现金折扣金额）
```

### 净价法

净价法是将扣除现金折扣后的金额作为应付账款的入账价值。

#### 发生应付账款

```
借：原材料（或库存商品等）
    应交税费——应交增值税（进项税额）
  贷：应付账款（净价）
```

#### 未享受现金折扣

```
借：应付账款（净价）
    财务费用（丧失的现金折扣金额）
  贷：银行存款（实际支付金额）
```

## 应付账款的账务处理示例

### 示例1：正常业务

1. 企业从C公司购入原材料一批，价款50,000元，增值税6,500元，材料已验收入库，款项尚未支付。

   ```
   借：原材料 50,000
       应交税费——应交增值税（进项税额） 6,500
     贷：应付账款 56,500
   ```

2. 企业以银行存款支付上述款项。

   ```
   借：应付账款 56,500
     贷：银行存款 56,500
   ```

### 示例2：现金折扣

1. 企业从D公司购入商品一批，价款100,000元，增值税13,000元，商品已验收入库，款项尚未支付，D公司给予的现金折扣条件为2/10，n/30。

   ```
   借：库存商品 100,000
       应交税费——应交增值税（进项税额） 13,000
     贷：应付账款 113,000
   ```

2. 企业在10天内支付款项，享受现金折扣。

   ```
   借：应付账款 113,000
     贷：银行存款 110,740（113,000×98%）
         财务费用 2,260（113,000×2%）
   ```

## 应付账款的列报

应付账款应当在资产负债表的流动负债部分列示。
