# 短期借款

## 短期借款的定义

短期借款是指企业向银行或其他金融机构等借入的期限在一年以下（含一年）的各种借款。

## 短期借款的核算

### 取得短期借款

```
借：银行存款
  贷：短期借款
```

### 计提短期借款利息

#### 预提方式

```
借：财务费用
  贷：应付利息
```

#### 直接支付方式

```
借：财务费用
  贷：银行存款
```

### 偿还短期借款

```
借：短期借款
    应付利息（已计提的利息）
    财务费用（未计提的利息）
  贷：银行存款
```

## 短期借款的账务处理示例

### 示例1：按月预提利息

1. 1月1日，企业向银行借入短期借款100,000元，年利率6%，期限3个月，按月预提利息，到期一次还本付息。

   ```
   借：银行存款 100,000
     贷：短期借款 100,000
   ```

2. 1月31日，计提1月份利息。

   ```
   借：财务费用 500（100,000×6%÷12）
     贷：应付利息 500
   ```

3. 2月28日，计提2月份利息。

   ```
   借：财务费用 500
     贷：应付利息 500
   ```

4. 3月31日，到期还本付息。

   ```
   借：短期借款 100,000
       应付利息 1,000
       财务费用 500
     贷：银行存款 101,500
   ```

### 示例2：到期一次支付利息

1. 4月1日，企业向银行借入短期借款50,000元，年利率8%，期限2个月，到期一次还本付息。

   ```
   借：银行存款 50,000
     贷：短期借款 50,000
   ```

2. 5月31日，到期还本付息。

   ```
   借：短期借款 50,000
       财务费用 666.67（50,000×8%÷12×2）
     贷：银行存款 50,666.67
   ```

## 短期借款的列报

短期借款应当在资产负债表的流动负债部分列示。
