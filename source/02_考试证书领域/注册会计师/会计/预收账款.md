# 预收账款

## 预收账款的定义

预收账款是指企业按照合同规定向购货单位预收的款项。

## 预收账款的核算

### 收到预收款项

```
借：银行存款
  贷：预收账款
```

### 销售实现

```
借：预收账款
  贷：主营业务收入
    应交税费——应交增值税（销项税额）
```

### 收到补付款项

```
借：银行存款
  贷：预收账款
```

### 退回多收款项

```
借：预收账款
  贷：银行存款
```

## 预收账款的账务处理示例

### 示例1：正常业务

1. 企业与E公司签订销售合同，约定销售商品一批，价款80,000元，增值税10,400元，E公司预付50,000元，剩余款项在商品发出后支付。

   ```
   借：银行存款 50,000
     贷：预收账款 50,000
   ```

2. 企业发出商品，E公司验收合格。

   ```
   借：预收账款 90,400
     贷：主营业务收入 80,000
         应交税费——应交增值税（销项税额） 10,400
   ```

3. 企业收到E公司支付的剩余款项。

   ```
   借：银行存款 40,400
     贷：预收账款 40,400
   ```

### 示例2：退回多收款项

1. 企业与F公司签订销售合同，约定销售商品一批，价款30,000元，增值税3,900元，F公司预付40,000元。

   ```
   借：银行存款 40,000
     贷：预收账款 40,000
   ```

2. 企业发出商品，F公司验收合格。

   ```
   借：预收账款 33,900
     贷：主营业务收入 30,000
         应交税费——应交增值税（销项税额） 3,900
   ```

3. 企业退回F公司多付的款项。

   ```
   借：预收账款 6,100
     贷：银行存款 6,100
   ```

## 预收账款的列报

预收账款应当在资产负债表的流动负债部分列示。如果预收账款出现借方余额，应当在资产负债表的流动资产部分以“应收账款”项目列示。
