# 心理学考研指南：五科备考策略与复习规划

## 一、心理学考研概述

### 考试科目

| 科目 | 分值 | 说明 |
|------|------|------|
| 政治 | 100分 | 全国统考 |
| 英语一/英语二 | 100分 | 学硕考英一，专硕考英二 |
| 心理学专业基础综合 | 300分 | 院校自主命题 |

### 心理学专业基础综合（312统考）

包含五个科目：
- 普通心理学（约85分）
- 发展与教育心理学（约70分）
- 实验心理学（约60分）
- 心理统计与测量（约70分）
- 社会心理学（约15分）

## 二、普通心理学

### 核心内容框架

**认知过程：**
- 感觉：感受器激活，基本知觉形成
- 知觉：整体性、选择性、理解性、恒常性
- 注意：无意注意、有意注意、有意后注意
- 记忆：编码、存储、提取；遗忘曲线
- 思维：概念、判断、推理；问题解决
- 语言：语音、语义、语法、语用

**情绪情感过程：** 情绪分类、情绪理论（詹姆斯-兰格、坎农-巴德、沙赫特三因素）

**意志过程：** 动机冲突类型（双趋、双避、趋避、多重趋避）

**个性心理：**
- 能力：流体智力与晶体智力
- 气质：胆汁质、多血质、粘液质、抑郁质
- 性格：特征分类

## 三、发展心理学

### 核心内容框架

**基本理论：**
| 理论 | 代表人物 | 核心观点 |
|------|---------|---------|
| 皮亚杰认知发展 | 皮亚杰 | 感知运动→前运算→具体运算→形式运算 |
| 埃里克森心理社会发展 | 埃里克森 | 8个阶段，每阶段有危机要解决 |
| 维果茨基最近发展区 | 维果茨基 | 实际水平与潜在水平之间 |

**婴儿期（0-1岁）：** 依恋形成、感知运动阶段

**幼儿期（1-3岁）：** 语言发展、依恋类型

**童年期（6-12岁）：** 具体运算、自我中心减弱

**青春期（12-18岁）：** 形式运算、自我同一性

## 四、实验心理学

### 实验设计要素

| 要素 | 说明 |
|------|------|
| 自变量 | 实验者操纵的因素 |
| 因变量 | 测量指标 |
| 控制变量 | 保持恒定的因素 |

### 实验设计类型

| 类型 | 特点 |
|------|------|
| 被试内设计 | 每个被试接受所有条件 |
| 被试间设计 | 不同被试分配到不同条件 |
| 混合设计 | 结合前两者 |

### 反应时法

- 简单反应时：刺激-反应时间
- 选择反应时：识别时间与选择数量成正比
- 减数法：区分认知加工阶段
- 加因素法：确定各因素是否独立

## 五、心理统计与测量

### 描述统计

| 指标 | 说明 |
|------|------|
| 集中量数 | 平均数、中数、众数 |
| 差异量数 | 方差、标准差 |
| 相关 | 皮尔逊相关、斯皮尔曼相关 |

### 推断统计

| 方法 | 适用场景 |
|------|---------|
| Z检验/T检验 | 两组均值比较 |
| 方差分析 | 多组均值比较 |
| 卡方检验 | 计数数据分析 |
| 回归分析 | 预测关系 |

### 心理测量

**信度：** 测量结果一致性程度（重测信度、分半信度、克隆巴赫α）

**效度：** 测量是否测量了想测的内容（内容效度、结构效度、效标效度）

## 六、复习策略

### 三阶段规划

| 阶段 | 时间 | 任务 |
|------|------|------|
| 基础阶段 | 3-6月 | 系统学习教材，理解基本概念和理论 |
| 强化阶段 | 7-9月 | 重点突破，构建知识框架 |
| 冲刺阶段 | 10-12月 | 模拟考试，查漏补缺 |

### 各科目复习重点

| 科目 | 复习重点 |
|------|---------|
| 普通心理学 | 概念理解、理论对比 |
| 发展心理学 | 发展阶段、重要实验 |
| 实验心理学 | 实验设计、变量控制 |
| 统计测量 | 公式运用、结果解释 |

### 应试技巧

- 合理分配答题时间，先做会的题
- 统计学部分公式要记牢
- 实验设计题要写出完整步骤
- 保持良好心态，从容应考
