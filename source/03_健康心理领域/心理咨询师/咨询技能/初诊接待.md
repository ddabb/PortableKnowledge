# 初诊接待

## 定义

**初诊接待**是心理咨询师与来访者第一次接触的过程，是建立咨询关系的起点，也是评估来访者问题、制定初步咨询计划的关键环节。

初诊接待的质量直接影响来访者对咨询师的信任度、咨询关系的建立、以及后续咨询的效果。在心理咨询师考试中，初诊接待是重点考查内容。

---

## 核心概念

### 1. 初诊接待的目标
- **建立信任关系**：让来访者感到安全、被接纳、被理解
- **收集基本信息**：了解来访者的基本信息、主诉问题、背景信息
- **初步评估**：评估来访者的心理问题性质、严重程度、咨询适宜性
- **建立咨询协议**：讨论咨询目标、过程、费用、保密原则等
- **制定初步咨询计划**：根据评估结果，制定初步咨询计划

### 2. 初诊接待的流程
- **准备工作**：环境准备、资料准备、自身准备
- **接待与寒暄**：热情接待、破冰寒暄
- **介绍与说明**：介绍咨询师的背景、咨询过程、保密原则等
- **收集信息**：通过倾听、提问、观察，收集信息
- **初步评估**：评估来访者的问题、严重程度、咨询适宜性
- **讨论咨询计划**：与来访者讨论咨询目标、过程、频率等
- **结束与安排**：总结本次接待、安排下次咨询时间

### 3. 初诊接待的注意事项
- **保密原则**：向来访者说明保密原则及其限制
- **中立与非评判**：保持中立、非评判的态度
- **共情与接纳**：表达共情、无条件接纳
- **避免双重关系**：避免与来访者建立双重关系（如朋友、商业伙伴）
- **必要时转介**：如果超出自己的能力范围，应及时转介

## 详细内容

### 一、初诊接待前的准备

#### 1. 环境准备
- **安静、私密的空间**：确保咨询环境安静、私密，不被打扰
- **舒适的布置**：舒适的座椅、适当的温度、柔和的灯光
- **必要的工具**：纸巾、饮用水、记录工具等

#### 2. 资料准备
- **来访者基本信息**：如果已有预约，提前了解来访者的基本信息
- **相关量表或问卷**：根据来访者的主诉问题，准备相关量表或问卷
- **咨询记录表**：准备咨询记录表，用于记录本次接待的信息

#### 3. 自身准备
- **调整状态**：调整自己的身体状态、情绪状态，以最佳状态迎接来访者
- **回顾知识**：回顾相关理论知识、咨询技巧
- **设定目标**：明确本次接待的目标（如建立关系、收集信息、初步评估）

### 二、初诊接待的流程与技巧

#### 1. 接待与寒暄
- **热情接待**：微笑、问候、请坐、提供饮用水等
- **破冰寒暄**：简单的寒暄（如"今天天气不错"、"路上还顺利吗？"），帮助来访者放松

#### 2. 介绍与说明
- **介绍自己**：简要介绍自己的背景、资质、咨询经验
- **说明咨询过程**：向来访者说明咨询的基本过程（如咨询目标、频率、每次时长）
- **说明保密原则**：向来访者详细说明保密原则及其限制（如自伤、伤人风险）
- **回答疑问**：回答来访者关于咨询的疑问

#### 3. 收集信息
- **倾听技巧**：
  - 专注倾听：眼神接触、身体前倾、点头回应
  - 积极倾听：通过"嗯"、"啊"、"然后呢？"等回应，鼓励来访者继续说
- **提问技巧**：
  - 开放式提问：如"你能说说具体发生了什么吗？"
  - 封闭式提问：如"你感到焦虑吗？"
  - 避免诱导性提问：如"你是不是因为...才这样的？"
- **观察技巧**：
  - 观察来访者的非言语行为（如表情、眼神、姿态、语调）
  - 观察来访者的情绪状态、精神状态

#### 4. 初步评估
- **评估心理问题性质**：是情绪问题、行为问题、认知问题，还是人际关系问题？
- **评估严重程度**：是轻度、中度，还是重度？
- **评估咨询适宜性**：是否适合心理咨询？是否需要转介精神科医生？
- **评估自杀/自伤风险**：如果存在自杀/自伤风险，需要制定安全计划

#### 5. 讨论咨询计划
- **讨论咨询目标**：与来访者讨论希望通过咨询达到什么目标
- **讨论咨询过程**：讨论咨询的频率、每次时长、咨询技术
- **讨论咨询费用**：明确咨询费用、支付方式
- **建立咨询协议**：与来访者建立口头或书面的咨询协议

#### 6. 结束与安排
- **总结本次接待**：简要总结本次接待所了解的信息、达成的共识
- **安排下次咨询**：与来访者约定下次咨询的时间、地点
- **给予希望与支持**：让来访者感到被理解、被支持，对咨询抱有希望

### 三、初诊接待中的常见问题与应对

#### 1. 来访者紧张、沉默
- **应对**：
  - 给予时间：不要急于打破沉默，给予来访者时间整理思绪
  - 共情回应："看起来你有些紧张，没关系，我们可以慢慢来"
  - 开放式提问："你能说说是什么让你决定来咨询的吗？"

#### 2. 来访者倾诉杂乱无章
- **应对**：
  - 倾听与共情：先倾听，表达共情
  - 结构化提问："你刚才提到了几个方面，能不能一个一个地说？我们先从...开始？"

#### 3. 来访者询问私人问题
- **应对**：
  - 设定边界：温和但坚定地设定边界，"很高兴你对我感兴趣，但作为咨询师，我需要保持专业关系"
  - 引导回主题："我们还是回到你刚才说的问题上..."

#### 4. 来访者要求保证咨询效果
- **应对**：
  - 诚实回应："我无法保证咨询效果，但我承诺会尽最大努力帮助你"
  - 强调合作："咨询效果是咱们双方共同努力的结果"

## 示例/应用场景

### 示例1：初诊接待中建立信任关系
**场景**：来访者第一次来咨询，显得紧张、拘谨。
**应用**：
1. 热情接待：微笑、问候、请坐、提供饮用水
2. 破冰寒暄："今天路上还顺利吗？"
3. 介绍与说明：介绍自己、说明咨询过程、保密原则
4. 共情回应："看起来你有些紧张，没关系，我们可以慢慢来"
5. 开放式提问："你能说说是什么让你决定来咨询的吗？"

### 示例2：初诊接待中收集信息
**场景**：来访者主诉"最近失眠、焦虑"。
**应用**：
1. 开放式提问："你能具体说说失眠和焦虑的情况吗？"
2. 追问细节："这种情况持续多久了？""什么情况下会加重？""什么情况下会减轻？"
3. 了解背景："最近生活中有什么变化吗？""工作/学习压力大吗？""人际关系怎么样？"
4. 观察非言语行为：注意来访者的表情、眼神、姿态、语调

### 示例3：初诊接待中初步评估与转介
**场景**：来访者主诉"情绪低落，不想活了"。
**应用**：
1. 评估自杀风险："你有没有想过结束生命？""有没有具体的计划？"
2. 如果存在自杀风险：
   - 制定安全计划：约定不打时期、联系他人、寻求专业帮助
   - 必要时转介精神科医生：如果风险高，需要转介精神科医生进行评估和治疗
3. 如果风险不高：
   - 继续咨询：与来访者讨论咨询目标、过程、频率
   - 建立咨询协议：明确咨询目标、过程、费用、保密原则等

## 常见错误

### 1. 在初诊接待中过于主动、主导
- **错误**：一直说话，不给来访者表达机会
- **纠正**：以来访者为中心，多倾听、少说话

### 2. 在初诊接待中忽视保密原则
- **错误**：不向来访者说明保密原则及其限制
- **纠正**：必须向来访者详细说明保密原则及其限制

### 3. 在初诊接待中承诺咨询效果
- **错误**："放心，我一定能帮你解决问题"
- **纠正**：不能承诺咨询效果，但可以说"我会尽最大努力帮助你"

### 4. 在初诊接待中建立双重关系
- **错误**：与来访者成为朋友、商业伙伴等
- **纠正**：必须避免双重关系，保持专业边界

### 5. 在初诊接待中忽视自杀/自伤风险
- **错误**：不评估自杀/自伤风险
- **纠正**：必须评估自杀/自伤风险，必要时制定安全计划或转介

## 总结

初诊接待是心理咨询师与来访者第一次接触的过程，是建立咨询关系的起点，也是评估来访者问题、制定初步咨询计划的关键环节。

**核心要点**：
1. **初诊接待的目标**：建立信任关系、收集基本信息、初步评估、建立咨询协议、制定初步咨询计划
2. **初诊接待的流程**：准备工作、接待与寒暄、介绍与说明、收集信息、初步评估、讨论咨询计划、结束与安排
3. **初诊接待的注意事项**：保密原则、中立与非评判、共情与接纳、避免双重关系、必要时转介
4. 初诊接待知识在心理咨询中**应用广泛**：初诊接待中的常见问题与应对

**实践指导**：
- 咨询师应在初诊接待中建立信任关系
- 有效收集信息
- 进行初步评估
- 建立专业边界

掌握初诊接待知识，不仅有助于通过心理咨询师考试，更能提升心理咨询的实践能力，帮助来访者建立信任、开启咨询之旅。
