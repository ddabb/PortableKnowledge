# 交通事故处理指南：事故后的正确做法

## 一、事故现场处理

### 1.1 发生事故后必做事项

| 步骤 | 具体操作 |
|------|---------|
| 1. 开启双闪 | 防止二次事故 |
| 2. 拨打110 | 有人伤必报警 |
| 3. 拍照留证 | 全方位记录现场 |
| 4. 挪车需知 | 拍照后可移动车辆 |

### 1.2 轻微事故快处

无人员伤亡、财产损失2万以内可通过**交通事故快处**处理：
- 交管12123APP拍照上传
- 责任认定书在线获取
- 维修理赔直接对接

## 二、责任认定

### 2.1 责任划分

| 责任类型 | 比例 |
|---------|------|
| 全部责任 | 100% |
| 主要责任 | 70% |
| 同等责任 | 50% |
| 次要责任 | 30% |
| 无责任 | 0% |

### 2.2 常见情形

| 情形 | 责任认定 |
|------|---------|
| 追尾 | 后车全责 |
| 逆行 | 逆行全责 |
| 闯红灯 | 闯红灯全责 |
| 转弯让直行 | 转弯车全责 |
| 掉头让行 | 掉头车全责 |

## 三、赔偿标准

### 3.1 人身损害赔偿

| 赔偿项目 | 计算方式 |
|---------|---------|
| 医疗费 | 实际支出 |
| 误工费 | 日收入×误工天数 |
| 护理费 | 护工标准×天数 |
| 交通费 | 实际支出 |
| 残疾赔偿金 | 伤残系数×当地标准 |
| 死亡赔偿金 | 当地居民收入×年限 |

### 3.2 城镇标准

2024年起，城乡统一适用**城镇居民标准**计算残疾/死亡赔偿金。

## 四、保险理赔

| 保险类型 | 赔偿范围 |
|---------|---------|
| 交强险 | 人伤12.2万限额 |
| 三者险 | 超交强险部分 |
| 车损险 | 车辆维修费 |
| 座位险 | 车上人员 |

**注意：** 商业险按责任比例赔付，交强险分项限额。

## 五、诉讼时效

- 人身损害：**1年**
- 财产损失：**3年**
- 特殊情形可延长

## 六、实用建议

1. **保留**所有单据发票
2. **及时**报案、报案
3. **了解**各项赔偿标准
4. **必要时**委托律师处理
