# 劳动合同法要点：签合同必知的权利义务

## 一、劳动合同的签订

### 1.1 劳动合同的法定形式

根据《劳动合同法》第十条，建立劳动关系应当订立书面劳动合同。口头协议在实践中难以举证，劳动者应坚持签订书面合同。

**要点：**
- 劳动关系自用工之日起建立
- 已建立劳动关系未同时订立书面合同应在一个月内签订
- 超过一个月未签合同可要求双倍工资

### 1.2 劳动合同的必备条款

劳动合同应当具备以下条款：

| 条款类型 | 内容要求 |
|---------|---------|
| 基本信息 | 用人单位名称、地址和法定代表人 |
| 合同期限 | 固定期限/无固定期限/以完成期限 |
| 工作内容 | 岗位名称、工作地点 |
| 报酬待遇 | 工资、奖金、福利 |
| 劳动保护 | 工作时间和休息休假 |
| 社会保险 | 五险一金 |

### 1.3 试用期的规定

| 合同期限 | 试用期上限 |
|---------|----------|
| 3个月-1年 | 1个月 |
| 1年-3年 | 2个月 |
| 3年以上/无固定期限 | 6个月 |

**重要提示：** 试用期工资不得低于合同约定工资的80%，也不得低于当地最低工资标准。

## 二、工资与工时

### 2.1 工资支付

- **支付日期：** 约定日期支付，最迟每月发放一次
- **支付形式：** 以货币形式发放，不得以实物或有价证券替代
- **加班工资：** 工作日加班不低于150%，休息日加班不低于200%，法定节假日加班不低于300%

### 2.2 年假与调休

- 工作满1年不满10年：年假5天
- 满10年不满20年：年假10天
- 满20年：年假15天

## 三、社保与公积金

- **强制缴纳：** 用人单位必须为劳动者缴纳五险一金
- **个人缴费：** 社保由单位和劳动者共同缴纳
- **公积金：** 买房、租房、装修、重大疾病均可提取

## 四、劳动合同的解除与终止

### 4.1 劳动者单方解除权

| 情形 | 用人单位是否支付经济补偿 |
|------|----------------------|
| 提前30日书面通知 | 否 |
| 单位违法在先 | 是 |
| 未缴社保/未发工资 | 是 |

### 4.2 经济补偿金计算

N = 工作年限 × 月工资

**常见情形：**
- 合同到期不续签
- 单位经济性裁员
- 协商解除（单位提出）
- 单位倒闭/解散

## 五、竞业限制

- **适用人员：** 高级管理人员、高级技术人员
- **期限：** 不超过2年
- **补偿：** 竞业限制期内按月支付经济补偿
- **违约金：** 不得超过用人单位损失

## 六、劳动争议解决途径

1. **协商** - 首选，成本最低
2. **调解** - 企业劳动争议调解委员会
3. **仲裁** - 劳动争议仲裁委员会（必经程序）
4. **诉讼** - 对仲裁不服可向法院起诉

**劳动仲裁时效：** 1年（知道或应当知道权利被侵害之日起）

## 七、注意事项

### 7.1 保留证据

- 劳动合同原件
- 工资条/银行流水
- 考勤记录
- 工作证/工牌
- 微信/邮件工作沟通记录

### 7.2 常见维权点

- 不签合同的双倍工资
- 不缴社保的被迫解除
- 违法解除的2N赔偿
- 未休年假的300%工资
- 加班费追讨
