# 软件工程过程

## 1. 软件工程定义

软件工程是指应用计算机科学、数学及管理科学等原理，以工程化的原则和方法来解决软件问题的工程，其目的是**提高软件生产率、提高软件质量、降低软件成本**。

IEEE对软件工程的定义：将系统的、规范的、可度量的工程化方法应用于软件开发、运行和维护的全过程。

## 2. 软件工程组成

软件工程由**方法、工具和过程**三个部分组成：

| 组成部分 | 说明 |
|---------|------|
| **方法** | 完成软件项目的技术手段，支持整个软件生命周期 |
| **工具** | 开发和管理的支撑，自动或半自动支持软件开发，生成文档 |
| **过程** | 贯穿软件开发各环节，由软件工程师在工具支持下完成一系列工程活动 |

## 3. 软件过程活动

管理人员在软件工程过程中需要对软件开发进行评估、管理和控制，主要活动包括：

- **人员组织**：项目团队的组建和管理
- **计划跟踪与控制**：项目计划的制定与执行监控
- **成本估算**：软件开发成本的评估
- **质量保证**：确保软件质量的活动
- **配置管理**：软件配置项的管理和变更控制

## 4. 软件生命周期

典型的软件生命周期包括：

1. **需求分析**：确定用户需求，形成需求规格说明书
2. **软件设计**：概要设计和详细设计
3. **编码实现**：程序代码的编写
4. **软件测试**：单元测试、集成测试、系统测试等
5. **部署交付**：软件安装、配置和发布
6. **运行维护**：支持系统正常运行，持续改进

## 5. 关键考点

- 软件工程由方法、工具、过程三要素组成
- 软件工程的目标：提高生产率、提高质量、降低成本
- 软件过程活动包括人员组织、计划跟踪、成本估算、质量保证、配置管理等
