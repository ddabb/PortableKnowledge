> 成本效益分析（CBA）是比较项目或方案成本与收益的系统方法。

---

## 一、成本效益分析概述

### 1.1 定义

成本效益分析（Cost-Benefit Analysis）是对项目或决策的成本和收益进行量化比较的系统方法。

### 1.2 核心公式

```
收益成本比（B/C）= 总收益 ÷ 总成本

净收益 = 总收益 - 总成本

ROI（投资回报率）= 净收益 ÷ 成本 × 100%
```

### 1.3 分析原则

| 原则 | 说明 |
|------|------|
| **量化货币化** | 将成本和收益转换为货币单位 |
| **全面性** | 考虑所有相关成本和收益 |
| **时间价值** | 考虑资金的时间价值 |
| **不确定性** | 考虑风险和不确定性 |

## 二、成本识别

### 2.1 成本类型

| 类型 | 示例 | 是否计入 |
|------|------|---------|
| **直接成本** | 开发人员工资 | ✅ |
| **间接成本** | 管理人员工资 | ✅ |
| **有形成本** | 硬件采购 | ✅ |
| **无形成本** | 员工培训时间 | ✅ |
| **可变成本** | 按需付费云服务 | ✅ |
| **固定成本** | 办公室租金 | ✅ |

### 2.2 项目成本构成

| 成本类别 | 内容 |
|---------|------|
| **人力成本** | 工资、外包费用 |
| **设备成本** | 硬件、软件采购 |
| **运营成本** | 电费、网费 |
| **维护成本** | 维保费、升级费 |
| **培训成本** | 培训费用 |
| **机会成本** | 放弃其他方案的价值 |

---

## 三、收益识别

### 3.1 收益类型

| 类型 | 示例 |
|------|------|
| **直接收益** | 收入增加、成本节约 |
| **间接收益** | 效率提升、品牌价值 |
| **有形收益** | 可直接量化的收益 |
| **无形成本** | 难以量化的收益 |

### 3.2 收益量化方法

| 收益类型 | 量化方法 |
|---------|---------|
| 收入增加 | 直接计算 |
| 成本节约 | 节约金额 |
| 时间节约 | 人员成本 × 时间 |
| 质量提升 | 减少损失 |
| 风险降低 | 风险敞口 × 概率 |

## 四、分析步骤

### 4.1 步骤概览

```
1. 确定分析范围
        ↓
2. 识别成本
        ↓
3. 识别收益
        ↓
4. 量化成本和收益
        ↓
5. 计算指标
        ↓
6. 进行敏感性分析
        ↓
7. 做出决策
```

### 4.2 详细步骤

#### 步骤1：确定分析范围

| 问题 | 答案 |
|------|------|
| 分析对象是什么？ | 新系统上线 |
| 分析周期多长？ | 5年 |
| 包含哪些成本？ | 全部相关成本 |

#### 步骤2：识别成本

- 列出所有成本项
- 区分有形成本和无形成本
- 区分直接成本和间接成本

#### 步骤3：识别收益

- 列出所有收益项
- 区分直接收益和间接收益
- 区分有形收益和无形收益

#### 步骤4：量化

| 量化方法 | 说明 |
|---------|------|
| 直接量化 | 直接计算金额 |
| 影子价格 | 估算机会成本 |
| 条件价值法 | 调查估算无形收益 |
| 参考价值法 | 参考类似项目 |

#### 步骤5：计算指标

| 指标 | 计算公式 | 决策标准 |
|------|----------|----------|
| 净现值（NPV）| 收益现值-成本现值 | NPV>0 可行 |
| 收益成本比 | 收益÷成本 | B/C>1 可行 |
| 投资回报率 | ROI=净收益/成本 | ROI>基准 可行 |
| 回收期 | 累计收益=成本时间 | 越短越好 |

## 五、折现计算

### 5.1 为什么要折现

资金有时间价值：今天的100元 ≠ 明年的100元

### 5.2 折现公式

```
现值（PV）= 未来值（FV）÷ (1+r)^n

其中：
r = 折现率
n = 年数
```

### 5.3 示例

```
折现率：10%
第1年收益：100万
第2年收益：120万

第1年现值 = 100 ÷ 1.1 = 90.9万
第2年现值 = 120 ÷ 1.1² = 99.2万
```

## 六、敏感性分析

### 6.1 什么是敏感性分析

评估当关键假设变化时，结果如何变化。

### 6.2 常用方法

| 方法 | 说明 |
|------|------|
| **单项敏感性** | 每次只变一个因素 |
| **多项敏感性** | 同时变化多个因素 |
| **情景分析** | 乐观/基准/悲观情景 |

### 6.3 敏感性分析示例

| 因素 | 基准 | 乐观 | 悲观 | 对NPV影响 |
|------|------|------|------|-----------|
| 开发成本 | 100万 | 90万 | 120万 | ±15万 |
| 用户增长率 | 10%/年 | 15%/年 | 5%/年 | ±30万 |
| 单用户价值 | 1000元 | 1200元 | 800元 | ±20万 |

## 八、注意事项

| 注意事项 | 说明 |
|---------|------|
| **避免遗漏** | 成本和收益要全面 |
| **一致性** | 成本和收益时间范围一致 |
| **合理性** | 假设要基于数据 |
| **不确定性** | 考虑风险，进行敏感性分析 |
| **定性补充** | 无形成本收益要定性说明 |

## 九、总结

### 成本效益分析口诀

```
成本要全面，莫遗漏
收益要量化，莫夸大
折现要考虑，时间价值
敏感性要分析，不确定性要评估
决策要谨慎，定性定量结合
```
