# 项目管理知识领域

## 概述

知识领域是指按所需知识内容来定义的项目管理领域，并用其所含过程、实践、输入、输出、工具和技术进行描述。

根据PMBOK第6版，大部分项目通常使用**10个知识领域**。

## 10个知识领域

### 1. 项目整合管理

**定义**：识别、定义、组合、统一和协调各项目管理过程组的各个过程和活动。

**核心作用**：确保项目各个要素协调一致

### 2. 项目范围管理

**定义**：确保项目做且只做所需的全部工作以成功完成项目。

**核心作用**：控制项目边界

### 3. 项目进度管理

**定义**：管理项目按时完成所需的各个过程。

**核心作用**：确保项目按期交付

### 4. 项目成本管理

**定义**：使项目在批准的预算内完成而对成本进行规划、估算、预算、融资、筹资、管理和控制。

**核心作用**：控制项目成本

### 5. 项目质量管理

**定义**：把组织的质量政策应用于规划、管理、控制项目和产品的质量，以满足干系人的期望。

**核心作用**：确保交付物满足质量要求

### 6. 项目资源管理

**定义**：识别、获取和管理所需资源以成功完成项目。

**核心作用**：确保有足够的资源支持项目

### 7. 项目沟通管理

**定义**：确保项目信息及时且恰当地规划、收集、生成、发布、存储、检索、管理、控制、监督和最终处置。

**核心作用**：确保信息流畅通

### 8. 项目风险管理

**定义**：规划风险管理、识别风险、开展风险分析、规划风险应对、实施风险应对和监督风险。

**核心作用**：识别和应对威胁，把握机会

### 9. 项目采购管理

**定义**：从项目团队外部采购或获取所需产品、服务或成果。

**核心作用**：管理外部采购活动

### 10. 项目干系人管理

**定义**：识别影响或受项目影响的人员、团队或组织，分析干系人对项目的期望和影响，制定合适的管理策略。

**核心作用**：有效调动干系人参与项目决策和执行

## 5个过程组

| 过程组 | 说明 |
|--------|------|
| 启动过程组 | 定义了新项目或现有项目的新阶段，授权开始 |
| 规划过程组 | 明确项目范围、优化目标，制订行动计划 |
| 执行过程组 | 完成项目管理计划中确定的工作，以满足项目要求 |
| 监控过程组 | 跟踪、审查和调整项目进展与绩效，识别变更并启动相应变更 |
| 收尾过程组 | 正式完成或结束项目、阶段或合同 |

## 过程组与知识领域矩阵

| 知识领域 | 启动 | 规划 | 执行 | 监控 | 收尾 |
|----------|------|------|------|------|------|
| **整合管理** | 制定项目章程 | 制订项目管理计划 | 指导与管理项目工作<br>管理项目知识 | 监控项目工作<br>实施整体变更控制 | 结束项目或阶段 |
| **范围管理** | - | 规划范围管理<br>收集需求<br>定义范围<br>创建WBS | - | 确认范围<br>控制范围 | - |
| **进度管理** | - | 规划进度管理<br>定义活动<br>排列活动顺序<br>估算活动持续时间<br>制订进度计划 | - | 控制进度 | - |
| **成本管理** | - | 规划成本管理<br>估算成本<br>制定预算 | - | 控制成本 | - |
| **质量管理** | - | 规划质量管理 | 管理质量 | 控制质量 | - |
| **资源管理** | - | 规划资源管理<br>估算活动资源 | 获取资源<br>建设团队<br>管理团队 | 控制资源 | - |
| **沟通管理** | - | 规划沟通管理 | 管理沟通 | 监督沟通 | - |
| **风险管理** | - | 规划风险管理<br>识别风险<br>实施定性风险分析<br>实施定量风险分析<br>规划风险应对 | 实施风险应对 | 监督风险 | - |
| **采购管理** | - | 规划采购管理 | 实施采购 | 控制采购 | - |
| **干系人管理** | 识别干系人 | 规划干系人参与 | 管理干系人参与 | 监督干系人参与 | - |

## 关键认知

1. **知识领域相互联系但分别定义**：每个知识领域有其特定的范围和目标
2. **某些项目可能需要额外的知识领域**：如建造项目可能需要财务管理或安全健康管理
3. **一个过程组的输出通常成为另一个过程组的输入**：例如规划过程组的输出成为执行过程组的输入

## 过程组与项目阶段的关系

- 过程组是针对项目管理过程进行的**逻辑上的划分**
- 项目阶段是项目从开始到结束所经历的一系列阶段
- 各过程组在项目阶段中相互作用，支持型活动贯穿始终
