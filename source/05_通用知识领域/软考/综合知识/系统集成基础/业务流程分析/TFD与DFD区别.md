# 业务流程图与数据流程图的区别

## 一、总览对比表

| 区别维度 | 业务流程图（TFD） | 数据流程图（DFD） |
|---------|----------------|----------------|
| **描述对象** | 业务处理过程和作业顺序 | 数据流本身 |
| **核心特征** | 面向业务、真实流水账 | 面向数据、抽象性+概括性 |
| **常用符号** | 角色、业务处理、文档、信息传递、判断 | 数据流、处理、数据存储、外部实体 |
| **功能作用** | 优化业务处理过程 | 分析数据流通问题 |
| **绘制方法** | 较简单，约束少 | 较复杂，需结合整个系统 |
| **关注重点** | 业务活动本身 | 信息和数据的流转 |

## 二、描述对象不同

### 业务流程图（TFD）

- 描述对象是**某一具体业务**
- 以业务处理过程为流程图中心
- 系统地描述业务流程
- 说明整个业务流程的逻辑
- 一般**没有数据概念**

### 数据流程图（DFD）

- 描述对象是**数据流**
- 具有两个核心特征：
  - **抽象性**：将具体的组织机构、工作场所、物质流去掉，只剩下信息和数据存储、流动、使用及加工情况
  - **概括性**：把系统对各种业务处理的过程联系起来考虑，形成一个总体
- 关注数据在全系统中的全貌

## 三、常用符号不同

### 业务流程图常用符号

| 符号 | 含义 |
|------|------|
| 角色 | 参与者（人员、部门） |
| 业务处理 | 具体的操作步骤 |
| 文档 | 输入/输出单据 |
| 信息传递 | 业务环节间的信息流向 |
| 业务判断 | 条件分支（菱形） |

### 数据流程图常用符号

| 符号 | 含义 |
|------|------|
| 外部实体 | 系统外部的相关方（矩形） |
| 处理过程 | 数据加工操作（圆/椭圆） |
| 数据流 | 数据传输流向（带箭头线段） |
| 数据存储 | 数据存放位置（开口矩形） |

**记忆技巧：** TFD 符号围绕"业务活动"，DFD 符号围绕"数据"。

## 四、功能作用不同

### 业务流程图的作用

主要用于业务的**实际处理过程**：
- 帮助绘制者理顺业务流程
- 优化合理的业务流程

改进具体处理过程：
1. **去掉**多余环节
2. **合并**重复环节
3. **增添**缺少的必须环节

### 数据流程图的作用

主要用于对信息中**流动、传递、处理、存储**等内容的分析：
- 目的：将数据流程直观化
- 作用：发现和解决数据流通中的问题
- 特点：去掉了一些业务流程图中的实体对象，相比业务流程图**更加抽象**

## 五、绘制过程不同

### 业务流程图绘制

- **方法较为简单**
- 根据业务实际处理过程结合流程符号绘制
- 绘制过程中**没有过多严格的约束**
- 只需将合理且真实的业务处理流程绘制出来即可

### 数据流程图绘制

- **方法较为复杂**
- 需要结合整个系统绘制出与之相关数据的过程
- 需遵循分层原则（顶层→0层→N层）
- 需保持父图与子图之间的平衡

## 六、软考答题框架

### 框架一：对比题（描述对象/符号/作用/绘制）

```
【题目】业务流程图与数据流程图有何区别？

【答题要点】（从四个维度回答）

1. 描述对象不同
   - TFD：描述某一具体业务，处理过程为中心
   - DFD：描述数据流，抽象性+概括性

2. 常用符号不同
   - TFD：角色、业务处理、文档、信息传递、判断
   - DFD：外部实体、处理、数据流、数据存储

3. 功能作用不同
   - TFD：优化业务处理过程（去/合/增环节）
   - DFD：分析数据流通问题（流动/传递/处理/存储）

4. 绘制过程不同
   - TFD：较简单，无严格约束
   - DFD：较复杂，需结合系统，分层绘制
```

### 框架二：应用场景选择

```
【题目】某企业需要对业务流程进行优化，应该使用哪种图？为什么？

【分析】
- 如果关注点是"业务处理是否合理"→ 使用业务流程图（TFD）
- 如果关注点是"数据传递是否有问题"→ 使用数据流程图（DFD）

【答案】
应采用业务流程图（TFD），因为：
1. 业务流程图以业务处理过程为中心，有助于发现业务环节的不合理流向
2. 业务流程图绘制方法较简单，能快速反映实际业务处理过程
3. TFD可以通过"去多余、合重复、增必要"来优化业务流程

（根据题干具体场景调整）
```
