# 网络安全

## 1. 网络安全概述

### 1.1 定义
网络安全是保护网络系统硬件、软件及其数据不因偶然或恶意原因遭受破坏、更改、泄露。

### 1.2 安全威胁类型

| 类型 | 说明 |
|-----|------|
| 被动攻击 | 窃听、流量分析 |
| 主动攻击 | 篡改、重放、拒绝服务 |
| 物理威胁 | 设备盗窃、环境灾害 |
| 社会工程 | 钓鱼、欺诈 |

## 2. 防火墙

### 2.1 定义
防火墙是位于不同网络安全域之间，通过预设安全策略对网络通信进行控制的安全设备。

### 2.2 防火墙类型

| 类型 | 说明 |
|-----|------|
| 包过滤防火墙 | 检查网络层IP包头 |
| 状态检测防火墙 | 跟踪连接状态 |
| 应用层网关 | 检查应用层数据 |
| 代理防火墙 | 代理客户端请求 |

### 2.3 部署位置
- 网络边界
- 内部网段之间
- 数据中心入口

### 2.4 防火墙规则
```
动作：允许/拒绝
源地址：IP或网段
目标地址：IP或网段
端口：协议端口
协议：TCP/UDP/ICMP
方向：入站/出站
```

## 3. IDS（入侵检测系统）

### 3.1 定义
对网络流量进行监控，发现可疑行为并告警。

### 3.2 分类

| 分类方式 | 类型 |
|---------|------|
| 检测方式 | 签名检测、异常检测 |
| 部署位置 | 网络IDS、主机IDS |
| 反应方式 | 被动检测、主动响应 |

### 3.3 IDS工作流程
```
采集数据 → 预处理 → 特征匹配 → 告警
```

## 4. IPS（入侵防御系统）

### 4.1 定义
不仅检测入侵，还能自动阻断攻击。

### 4.2 与IDS区别
| 对比 | IDS | IPS |
|-----|-----|-----|
| 位置 | 旁路 | 串联 |
| 响应 | 检测告警 | 检测并阻断 |
| 影响 | 不影响流量 | 可能影响性能 |

### 4.3 IPS类型
- 基于网络（NIPS）
- 基于主机（HIPS）

## 5. IDS/IPS部署策略

### 5.1 部署位置
- 边界入口
- DMZ区
- 核心交换
- 服务器前端

### 5.2 检测方法

| 方法 | 说明 |
|-----|------|
| 签名检测 | 匹配已知攻击特征 |
| 异常检测 | 建立正常行为模型 |
| 状态检测 | 跟踪协议状态 |

## 6. VPN（虚拟专用网络）

### 6.1 定义
在公共网络上建立加密隧道，实现安全通信。

### 6.2 VPN类型

| 类型 | 说明 |
|-----|------|
| 站点到站点VPN | 连接两个网络 |
| 远程访问VPN | 客户端到网关 |
| MPLS VPN | 基于运营商网络 |
| SSL VPN | 基于SSL/TLS |

### 6.3 VPN协议

| 协议 | 说明 |
|-----|------|
| IPSec | 网络层安全，加密+认证 |
| PPTP | 点对点隧道协议 |
| L2TP | 二层隧道协议 |
| SSL/TLS | 传输层安全 |

### 6.4 IPSec协议族

| 协议 | 功能 |
|-----|------|
| AH | 认证头部，数据完整性 |
| ESP | 封装安全载荷，加密 |
| IKE | 密钥交换 |

**工作模式：**
- 传输模式：保护载荷
- 隧道模式：保护整个IP包

## 7. 防病毒

### 7.1 防病毒技术
- 特征码扫描
- 启发式扫描
- 行为监控
- 云查杀

### 7.2 防病毒部署
- 网络防病毒网关
- 服务器防病毒
- 终端防病毒

## 8. 网络隔离

### 8.1 隔离技术
| 技术 | 说明 |
|-----|------|
| 物理隔离 | 完全物理断开 |
| 协议隔离 | 单向数据摆渡 |
| 网闸隔离 | 硬件隔离摆渡 |
| VLAN隔离 | 逻辑网络分段 |

### 8.2 DMZ
- 非军事区
- 放置对外服务
- 外部可访问

## 9. 安全防护体系

### 9.1 纵深防御
```
边界防护 → 网络分段 → 主机防护 → 应用防护 → 数据防护
```

### 9.2 WPDRRC模型

| 字母 | 含义 |
|-----|------|
| W | Warn（预警） |
| P | Protect（保护） |
| D | Detect（检测） |
| R | Response（响应） |
| R | Recover（恢复） |
| C | Counter-attack（反击） |

## 10. 关键考点

- 防火墙类型：包过滤、状态检测、应用层网关、代理
- IDS vs IPS：旁路vs串联，告警vs阻断
- IDS检测方法：签名、异常、状态检测
- VPN类型：站点到站点、远程访问、MPLS、SSL
- IPSec协议族：AH认证、ESP加密、IKE密钥交换
- IPSec工作模式：传输模式、隧道模式
- WPDRRC：预警、保护、检测、响应、恢复、反击
- 纵深防御：边界→网络→主机→应用→数据
