# IT审计基础

## IT审计定义

**IT审计**是指由独立的审计机构和审计人员，根据国家法律法规和标准规范，对信息系统及其相关业务的真实性、合法性、效益性进行审查和评价，并提出整改意见的一种监督活动。

## IT审计重要性

IT审计风险（固有风险、控制风险、检查风险）对组织影响的严重程度，包括：
- 财务损失
- 业务中断
- 失去客户信任
- 经济制裁等

## IT审计目的

1. 了解组织IT系统与IT活动的总体状况
2. 对组织是否实现IT目标进行审查和评价
3. 充分识别与评估相关IT风险
4. 提出评价意见及改进建议
5. 促进组织实现IT目标

> **流程口诀：** 了解状况→审查目标→识别风险→提出建议→促进目标

## IT审计目标

| 目标 | 说明 |
|------|------|
| **战略一致性** | 组织的IT战略应与业务战略保持一致 |
| **信息资产安全** | 保护信息资产的安全及数据的完整、可靠、有效 |
| **系统可靠性** | 提高信息系统的安全性、可靠性及有效性 |
| **系统合规** | 合理保证信息系统及其运用符合有关法律、法规及标准等的要求 |

> **口诀：** 战略安全、系统合规

## IT审计范围

| 范围类型 | 说明 |
|----------|------|
| **总体范围** | 根据审计目的和投入的审计成本确定 |
| **组织范围** | 明确审计涉及的组织结构、主要流程、活动及人员 |
| **物理范围** | 具体的物理地点与边界 |
| **逻辑范围** | 涉及的信息系统和逻辑边界 |

## IT审计人员要求

| 要求类型 | 内容 |
|----------|------|
| **职业道德** | 独立、客观、公正；正直、诚实和守信；正确履行职责；保密 |
| **知识技能资格** | 掌握IT相关专业知识；掌握审计和财务管理的通用知识；有IT审计相关基本技能、专业技能和软技能 |
| **专业胜任能力** | 具备IT审计专业胜任力；具有岗位对应的IT审计职业资格；定期参加持续的职业教育和培训 |
| **外部专家服务** | 对专业资格和经验、独立性、客观性、专业胜任力进行评价；签订书面协议 |

## 关键考点

1. IT审计**总体范围**需要根据审计目的和投入的审计成本来确定
2. IT审计目标：**战略一致性、信息资产安全、系统可靠性、系统合规**
3. IT审计流程：了解状况→审查目标→识别风险→提出建议→促进目标
