# IT治理基础

## IT治理定义

**IT治理**是描述组织采用有效的机制对信息技术和数据资源开发利用，平衡信息化发展和数字化转型过程中的风险，确保实现组织战略目标的过程。

## IT治理的目标

**三大目标：**
1. **与目标保持一致** - IT与业务目标一致
2. **有效利用信息与数据资源** - 确保IT投资有效
3. **风险管理** - 保护利益相关者的权益

> **口诀：** 野心、假果、棘手（目标一致、有效利用、风险管理）

## IT治理的管理层次

| 层级 | 职责 | 关键词 |
|------|------|--------|
| **最高管理层** | 证实IT战略与业务战略一致；指导IT战略、平衡投资；指导信息和数据资源分配 | 证实、指导 |
| **执行管理层** | 制定IT目标；分析机遇和风险；建设关键过程；分配责任、管理风险 | 制定、分析 |
| **业务/服务执行层** | 信息和数据的提供和支持；IT基础设施建设和维护；IT需求提出和响应 | 执行、响应 |

> **口诀：** 站脚平资源，标新立异靠保证，服务基础需求

## IT治理的核心内容

> **口诀：** 资战组价，风绩必达（资源管理、战略匹配、组织职责、价值交付、风险管理、绩效管理）

| 核心内容 | 说明 |
|----------|------|
| **组织职责** | 明确信息部门和业务部门的关系，正确划分所有者、建设者、管理者和监控者 |
| **战略匹配** | IT为组织贡献业务价值的重要驱动力 |
| **资源管理** | 优化IT投资和资源分配，做好人员培训和发展计划 |
| **价值交付** | 通过IT项目全生命周期管理，实现预期的业务价值 |
| **风险管理** | 确保IT资产安全、灾难恢复、信息资源安全和隐私安全 |
| **绩效管理** | 采用平衡计分卡等工具，将战略目标转化为具体业务活动目标 |

## IT治理主要问题

1. **信息孤岛** - 没有整合信息的措施
2. **知识密集、价值弹性大** - 需要好的价值管理
3. **新技术带来新发展空间** - 需要明确责任权利和明晰管理

## 关键考点

1. IT治理三大目标：**与目标一致、有效利用信息与数据资源、风险管理**
2. IT治理由**治理层或高管**负责
3. IT治理本质关心：**实现IT的业务价值**和**IT风险的规避**
