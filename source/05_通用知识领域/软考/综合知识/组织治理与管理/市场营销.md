# 市场营销

## 市场营销定义

**定义：** 组织为获得利益回报而为客户创造价值并与之建立稳固关系的过程。

### 核心概念

1. 需要、欲望和需求
2. 市场提供物
3. 客户价值和满意
4. 交换和关系
5. 市场

### 市场营销组合工具（4P）

| 组合 | 说明 |
|------|------|
| **Product** 产品 | 产品或服务的质量、功能等 |
| **Price** 定价 | 价格策略 |
| **Place** 渠道 | 分销渠道 |
| **Promotion** 促销 | 推广活动 |

## 营销环境分析

### 微观环境

| 要素 | 说明 |
|------|------|
| 组织 | 自身内部 |
| 供应商 | 原材料等供应方 |
| 营销中介 | 代理商等 |
| 客户 | 目标市场 |
| 竞争者 | 同类竞争对手 |
| 公众 | 社会公众 |

### 宏观环境

> **口诀：** 正经技术人，自然有文化

| 要素 | 说明 |
|------|------|
| **人口环境** | 人口数量、结构等 |
| **经济环境** | 收入水平、消费能力等 |
| **自然环境** | 自然资源、生态环境 |
| **技术环境** | 科技创新、技术进步 |
| **政治与社会** | 政策法规、社会文化 |
| **文化环境** | 价值观、传统习俗 |

## 营销管控

### 市场营销控制步骤

1. 设定具体的营销目标
2. 衡量市场业绩，找到预期与实际的差距
3. **采取纠偏措施**缩小目标与实际业绩之间的差距

> 当管理层采取纠偏措施时，正在执行的是**市场营销控制**阶段

### 整合营销沟通

1. 确定目标受众
2. 明确沟通目标
3. 设计信息
4. 选择沟通渠道和媒体
5. 选择信息来源
6. 收集反馈

### 销售管理步骤

1. 发掘潜在客户和核查资格
2. 销售准备
3. 接近客户
4. 介绍和示范
5. 处理异议
6. 成交
7. 跟进和维持

## 关键考点

1. 市场营销4P：**产品、定价、渠道、促销**
2. 宏观环境PEST：**人口、经济、自然、技术、政治与社会、文化**
3. 管理层采取纠偏措施缩小差距时，正在执行**市场营销控制**阶段
4. 销售管理七步骤：发掘→准备→接近→介绍→处理异议→成交→跟进
