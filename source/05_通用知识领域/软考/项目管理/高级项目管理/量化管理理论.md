# 量化管理理论

## 管理理论发展阶段

| 阶段 | 代表理论 | 核心特征 |
|------|----------|----------|
| 科学管理 | 科学管理理论 | 工时定额化、分工合理化、程序标准化、薪酬差额化、管理职能化 |
| 量化管理 | 量化管理理论 | 任务定额化、程序标准化、薪酬差额化 |

## 统计过程控制（SPC）

**定义：** 应用统计技术对工作过程中各个阶段进行分析、监控和评估，建立并保持工作过程处于可接受的、并且稳定的水平，从而确保产品与服务符合规格要求的一种管理技术。

### 核心特点

1. **预防性方法**，强调全程参与
2. 重点解决两个问题：
   - 工作过程运行状态是否稳定
   - 过程能力是否满足规格要求

### 过程能力波动

| 波动类型 | 说明 |
|----------|------|
| **正常波动** | 任何组织都会有一定的波动性，是正常的 |
| **异常波动** | 特殊成因造成的能力异常波动，需要识别并管理 |

### 正态分布与控制图

| 标准差范围 | 覆盖率 |
|------------|--------|
| ±1σ | 68.26%（或69%） |
| ±2σ | 95.46%（或95%） |
| ±3σ | 99.73% |
| **±3σ之外** | 小概率事件（0.27%） |

## 六西格玛（6σ）

基于DMAIC改进模式：

| 阶段 | 含义 |
|------|------|
| **D**efine 定义 | 确定问题和改进目标 |
| **M**easure 度量 | 收集数据，测量现状 |
| **A**nalyze 分析 | 分析数据，找出原因 |
| **I**mprove 改进 | 实施方案，解决问题 |
| **C**ontrol 控制 | 监控成果，防止回退 |

> **口诀：** 定测分改控

## CMMI高成熟度组织特征

1. 建立量化的目标管理机制
2. 建立过程能力量化监控机制
3. 建立目标的量化预测能力
4. 建立基于量化的持续优化机制

## 关键考点

1. SPC认为过程能力**存在波动性**，这是正常的
2. ±3σ之外属于小概率事件（0.27%）
3. 六西格玛采用**DMAIC**模式
4. 量化管理强调**预防**而非事后检查
