# 项目集管理绩效域

项目集管理包含五大绩效域，这些绩效域在整个项目集持续期间**同时存在、彼此交互**。

## 五大绩效域

### 1. 战略一致性

验证项目集的交付效益与组织战略保持一致。

**衡量方式：**
- 立项时：通过可行性研究和项目集评估验证效益
- 项目章程：衡量项目集成功与否的标准
- 规划时：项目集经理制订项目集路线图

### 2. 效益管理

效益管理是项目集定义、创建、最大化和交付效益的绩效域。

**效益管理五步法：**

| 阶段 | 关键活动 |
|------|----------|
| 效益识别 | 提取和优化效益；提取效益测量标准 |
| 效益分析和规划 | 制订效益管理计划；将效益映射到项目集管理计划 |
| 效益交付 | 监督组成部分；维护效益登记册；报告效益 |
| 效益移交 | 合并综合效益；移交持续责任 |
| 效益维持 | 监督效益绩效；确保效益持续实现 |

> 效益规划原则：初期自上而下，后期自下而上

### 3. 干系人参与

1. 项目集干系人识别
2. 项目集干系人分析
3. 项目集干系人参与规划
4. 项目集干系人参与
5. 项目集干系人沟通

### 4. 项目集治理

为项目集提供适当的治理框架：

1. 明确项目集治理的目标和结构
2. 批准、支持和启动项目集
3. 促进项目集干系人参与
4. 建立沟通处理风险的渠道和流程
5. 提供与组织治理一致的框架
6. 规划质量保证流程
7. 使组织能评估战略计划可行性
8. 对项目集变更管控提供治理
9. 选择、支持和促进项目集组件
10. 针对移交、终止或收尾做出决定

### 5. 生命周期管理

项目集经历三个阶段：

| 阶段 | 主要活动 |
|------|----------|
| **定义阶段** | 构建和批准项目集；制定项目线路图；制定项目评估和章程 |
| **交付阶段** | 组件授权与规划；组件监督与整合；组件移交与收尾 |
| **收尾阶段** | 项目集移交和收尾或提前终止；或将工作移交给另一个项目集 |

## 记忆口诀

**口诀：** 战略一致效益好，干系参与不能少，治理框架来保障，生命周期三阶段

## 关键考点

1. 效益管理活动只有**效益识别、分析规划、交付、移交、维持**五个，不包括"改进"
2. 生命周期管理**没有**执行阶段
3. 干系人参与是项目集治理的重要组成部分
