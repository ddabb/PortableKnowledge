## 三、「工具焦虑」的真相

### 1. 为什么我们喜欢「收集」？

大脑的多巴胺机制：

```
看到有用的信息 → 多巴胺分泌 → 感觉「以后用得上」 → 收藏
↓
收藏后 → 多巴胺消失 → 没有再看 → 遗忘
```

**「收藏」这个动作本身，已经给你带来了满足感。**

### 2. 为什么「收藏」后不用？

大脑的能量守恒原则：

```
收藏 → 花费能量 0.1
以后再看 → 花费能量 1.0
大脑选择 → 能量最低的路径 → 不看
```

**大脑会自动选择「最省力」的路径。**

### 3. 为什么「工具多」反而焦虑？

选择悖论：

```
有 5 个工具 → 容易选择 → 用 1 个 → 满足
有 57 个工具 → 难以选择 → 犹豫 → 不用 → 焦虑
```

**选择越多，决策越难，焦虑越强。**
