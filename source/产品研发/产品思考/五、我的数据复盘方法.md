## 五、我的数据复盘方法

### 每周必看的 3 个指标

```
1. DAU（日活）：有多少人在用
2. Top 10 工具：哪些功能最受欢迎
3. 分享转化：用户愿意分享吗
```

### 每月必做的 1 件事

```
淘汰分析：
- 哪些工具使用率低于 1%？
- 原因是什么？
- 值得保留吗？
```

### 每个版本必做的 1 件事

```
对比分析：
- 这个版本新增的工具，用的人多吗？
- 这个版本优化的功能，有正向提升吗？
- 没有的话，说明方向错了
```
