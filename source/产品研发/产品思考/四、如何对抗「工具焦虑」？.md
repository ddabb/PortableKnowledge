## 四、如何对抗「工具焦虑」？

### 1. 接受「记不住」的事实

**真相：**
- 你记不住所有工具
- 你也不需要记住所有工具
- 记住 5 个核心工具就够了

**接受：**
- 不是你记性不好
- 是你的大脑在保护你

### 2. 建立「工具使用原则」

**原则 1：一个需求只用一个工具**

```
需要计算日期 → 只用「日期计算器」
需要生成二维码 → 只用「二维码生成器」
```

**原则 2：搜索优于分类**

```
不要记住工具在哪
只需要搜索你想做什么
```

**原则 3：不收藏，直接用**

```
看到有用的工具 → 打开用 → 用完即走
不要「收藏以后用」→ 因为你不会看
```

### 3. 减少选择，增加行动

**方法 1：删掉不用的 App**

```
打开你的手机
删除最近 30 天没打开的 App
你会发现：你不需要那么多
```

**方法 2：精简收藏夹**

```
打开你的收藏
删除超过 3 个月没看的
你会发现：你根本不会看
```

**方法 3：一个工具用到底**

```
找到一个顺手的工具
用它 3 个月
形成习惯
不要换
```
