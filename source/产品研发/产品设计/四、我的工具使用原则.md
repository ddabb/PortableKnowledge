## 四、我的工具使用原则

### 原则 1：工具要「触手可及」

我选择工具的标准：
- **打开要快**：不用注册、不用登录
- **用完即走**：不纠结、不研究
- **能记住**：用多了自然就记住了

### 原则 2：一个需求只用一个工具

```
我需要计时 → 用秒表 App
我需要倒计时 → 用同一个秒表 App

我需要记笔记 → 用 Notion
我需要写文章 → 还是用 Notion

不要这个工具做 A，那个工具做 B
找到顺手的就一直用
```

### 原则 3：工具不是目的，解决问题才是

```
不要研究「如何高效使用 Notion」
而要思考「我需要记什么笔记」

不要研究「如何配置 VS Code」
而要思考「我要写什么代码」
```
