## 《中华人民共和国网络安全法》（2017年）

**核心制度**：

### 网络安全等级保护制度
- 国家对网络实行**等级保护制度**
- 网络运营者须按等级要求履行安全保护义务
- 关键信息基础设施在等保基础上实行**重点保护**

**等级保护五个等级**（由低到高）：
| 等级 | 说明 |
|------|------|
| 第一级 | 一般单位内部，损害仅影响公民权益 |
| 第二级 | 一般单位，损害影响公民、法人权益 |
| 第三级 | 重要机关，损害影响社会秩序和公共利益 |
| 第四级 | 关键基础设施，损害影响国家安全 |
| 第五级 | 最高级，影响国家根本利益（极少数） |

### 个人信息保护要求
- 收集使用须遵循**合法、正当、必要**原则
- 需用户**知情同意**
- 不得泄露、篡改、毁损、出售个人信息

### 网络安全事件报告
- 发生重大网络安全事件，须**立即启动应急预案**
- **24小时内**向有关主管部门报告

## 《电子签名法》（2004年）

**核心内容**：
- 可靠的电子签名与手写签名具有**同等法律效力**
- 可靠电子签名的要求：
  - 签名制作数据专有
  - 签名时由签名人控制
  - 签名后任何改动可被发现

**不适用范围**（不能用电子签名）：
- 涉及婚姻、收养、继承的
- 停止供水、供气、供暖、供电的通知
- 不动产权益转让
- 法律法规规定不适用的

## 《数据安全法》（2021年）

- 建立**数据分类分级保护制度**
- 重要数据的处理须进行**风险评估**
- 向境外提供重要数据需通过**安全评估**
- 数据交易中介须审核双方身份，留存审核、交易记录**不少于5年**

## 《个人信息保护法》（2021年）

- **敏感个人信息**：生物识别、宗教信仰、医疗健康、金融账户、行踪轨迹、未成年人信息
- 处理敏感个人信息须取得**单独同意**
- 未成年人（不满14周岁）个人信息须取得**监护人同意**

## IT相关标准规范

### 国家标准体系
| 类型 | 说明 |
|------|------|
| **GB/T**（推荐性国家标准） | 推荐执行，不强制 |
| **GB**（强制性国家标准） | 必须执行 |
| **YD/T**（行业标准） | 通信行业 |

### 常见信息化标准
- **GB/T 22239**：信息安全技术 网络安全等级保护基本要求
- **ISO/IEC 27001**：信息安全管理体系（ISMS）
- **ISO 9001**：质量管理体系
- **CMMI**：软件能力成熟度模型集成
  - 共5个等级，3级以上表示流程规范化

### CMMI等级
| 等级 | 名称 | 特征 |
|------|------|------|
| 1级 | 初始 | 过程不可预测，混乱 |
| 2级 | 已管理 | 项目级过程管理 |
| **3级** | 已定义 | 组织级标准过程（**通常要求达到**） |
| 4级 | 量化管理 | 统计方法控制过程 |
| 5级 | 优化 | 持续过程改进 |

## 监理相关规范

- 《信息系统工程监理暂行规定》：甲方可委托监理单位对项目进行监督
- 监理单位须独立于建设单位和承建单位
- 监理范围：**四控、三管、一协调**
  - 四控：质量控制、进度控制、投资控制、变更控制
  - 三管：合同管理、信息管理、安全管理
  - 一协调：组织协调
