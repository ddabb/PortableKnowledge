# 心理测量基础：信度效度与常用量表

## 一、心理测量的基本概念

### 什么是心理测量

心理测量是指依据心理学理论，用标准化工具对人的心理特质或行为进行定量描述的过程。

### 心理测量的基本要求

| 要求 | 说明 |
|------|------|
| 标准化 | 统一的施测说明、指导语、评分标准 |
| 客观化 | 减少主观因素的影响 |
| 数量化 | 用数字描述心理特质 |
| 间接性 | 测量的是外显行为或反应，而非心理本身 |

## 二、信度

### 信度的定义

信度是指测量结果的稳定性、一致性和可靠性。

### 信度的类型

| 类型 | 说明 | 常用方法 |
|------|------|---------|
| 重测信度 | 同一量表前后两次施测的相关 | 皮尔逊相关 |
| 分半信度 | 同一量表两半的相关 | 斯皮尔曼-布朗公式 |
| 克隆巴赫α | 所有题目间的一致性 | Cronbach's α |
| 评分者信度 | 不同评分者之间的一致性 | 组内相关系数ICC |

### 信度标准

- 能力测验：α > 0.90
- 人格测验：α > 0.70
- 态度测验：α > 0.60

## 三、效度

### 效度的定义

效度是指测量工具是否测量了想要测量的内容。

### 效度的类型

| 类型 | 说明 |
|------|------|
| 内容效度 | 题项是否代表测量内容的适当样本 |
| 结构效度 | 测量结果是否符合理论结构 |
| 效标效度 | 测量结果与外部标准的相关 |
| 表面效度 | 测量内容看起来是否相关 |

### 信度与效度的关系

- 信度是效度的必要条件：效度高的测量必然信度高
- 信度高不等于效度高（可能系统误差）
- 效度高要求信度也高

## 四、常用心理量表

### 人格测验

| 量表 | 说明 |
|------|------|
| MMPI（明尼苏达多相人格量表） | 临床最常用，566题，10个临床量表 |
| 16PF（卡特尔16种人格因素） | 16种独立人格特质 |
| EPQ（艾森克人格问卷） | 简版只有90题，E、N、P、L四量表 |
| SCL-90（症状自评量表） | 评估心理健康水平，90题 |
| 大五人格量表（NEO-PI-R） | 测量大五人格维度 |

### 智力测验

| 测验 | 说明 |
|------|------|
| 斯坦福-比奈量表 | 智商测验的经典 |
| 韦氏智力量表 | 包括言语智商和操作智商 |
| 瑞文推理测验 | 非文字推理测验 |

### 情绪与临床量表

| 量表 | 说明 |
|------|------|
| SAS（焦虑自评量表） | 评估焦虑水平 |
| SDS（抑郁自评量表） | 评估抑郁水平 |
| SCL-90 | 评估多种心理症状 |

### 投射测验

| 测验 | 说明 |
|------|------|
| 罗夏墨迹测验 | 通过对墨迹的反应评估人格 |
| TAT（主题统觉测验） | 通过讲故事评估内心需求 |

## 五、心理统计基础

### 描述统计

| 指标 | 说明 |
|------|------|
| 集中量数 | 平均数、中位数、众数 |
| 差异量数 | 方差、标准差 |
| 相关 | 皮尔逊相关系数（连续变量）、斯皮尔曼等级相关（等级变量） |

### 推断统计

| 方法 | 适用场景 |
|------|---------|
| Z检验/T检验 | 两组均值比较 |
| 方差分析（ANOVA） | 多组均值比较 |
| 卡方检验 | 计数数据分析 |
| 回归分析 | 预测关系 |
| 因素分析 | 降维，发现潜在结构 |

### 假设检验

1. 提出原假设H0和备择假设H1
2. 选择检验方法
3. 计算检验统计量
4. 确定显著性水平（通常α=0.05）
5. 得出结论：拒绝H0或不能拒绝H0

## 六、测量中常见问题

| 问题 | 说明 | 解决 |
|------|------|------|
| 社会赞许性 | 被试按社会期望作答 | 匿名施测、增加反向题 |
| 测量焦虑 | 被试紧张影响表现 | 标准化指导语，放松环境 |
| 测量误差 | 随机误差和系统误差 | 增加题量，标准化程序 |

## 七、总结

心理测量是心理学研究的重要工具。选择和使用测量工具时，需要关注：
- **信度**：结果是否稳定可靠
- **效度**：是否测量了想测的内容
- **适用性**：是否适合当前的测量对象和目的
