# 认知心理学：注意、记忆与决策的科学

## 一、认知心理学概述

认知心理学研究人类高级心理过程，特别是认知活动的信息加工过程。

**核心假设：** 人类是信息加工系统，类比计算机。

**研究方法：**
- 反应时法：通过反应时间推断加工过程
- 错误率法：分析任务中错误类型
- 口语报告法：出声思维法
- 认知神经科学方法：ERP、fMRI

## 二，注意

### 注意的定义

注意是心理活动对一定对象的指向和集中。

### 注意的品质

| 品质 | 说明 |
|------|------|
| 注意的广度 | 同一时间能把握对象的数量（约7±2） |
| 注意的稳定性 | 保持注意在对象上的时间 |
| 注意的分配 | 同时注意多个对象 |
| 注意的转移 | 主动转移注意焦点 |

### 注意的分类

| 类型 | 说明 |
|------|------|
| 无意注意 | 无预定目的，不需意志努力（被动） |
| 有意注意 | 有预定目的，需要意志努力（主动） |
| 有意后注意 | 有目的但不需要意志努力（高效） |

### 注意理论

| 理论 | 核心观点 |
|------|---------|
| 过滤器理论 | 注意是过滤器，只允许部分信息通过 |
| 衰减理论 | 未注意信息被衰减但仍可加工 |
| 资源分配理论 | 注意是有限资源，需合理分配 |

## 三，记忆

### 记忆的过程

| 过程 | 说明 |
|------|------|
| 编码 | 将信息转化为记忆可存储形式 |
| 存储 | 保持编码后的信息 |
| 提取 | 从记忆中检索信息 |

### 记忆系统

| 系统 | 容量 | 保持时间 |
|------|------|---------|
| 感觉记忆 | 大 | <1秒 |
| 短时记忆 | 7±2个组块 | 约20秒 |
| 长时记忆 | 无限 | 永久 |

### 记忆模型

**Atkinson-Shiffrin模型：**
感觉记忆→短时记忆→长时记忆

**工作记忆模型（Baddeley）：**
- 中央执行系统：控制注意力
- 语音环路：处理语音信息
- 视觉空间画板：处理视觉信息
- 情景缓冲器：整合多通道信息

### 遗忘

| 理论 | 说明 |
|------|------|
| 痕迹消退说 | 记忆痕迹随时间弱化 |
| 干扰说 | 前摄抑制和倒摄抑制 |
| 压抑说 | 因情绪动机被压抑 |
| 提取失败说 | 线索不充分 |

**遗忘曲线：** 艾宾浩斯曲线，先快后慢

## 四、思维与问题解决

### 思维的类型

| 分类标准 | 类型 |
|---------|------|
| 凭借物 | 动作思维、形象思维、抽象思维 |
| 方向 | 聚合思维、发散思维 |
| 创造性 | 常规思维、创造性思维 |

### 问题解决

**问题解决定义：** 从初始状态到目标状态的认知操作过程。

**问题解决步骤：**
1. 问题表征
2. 选择策略
3. 执行策略
4. 评估结果

**问题解决策略：**
| 策略 | 说明 |
|------|------|
| 算法 | 系统搜索所有可能方案 |
| 启发法 | 经验法则，更快但可能出错 |
| 手段-目的分析 | 缩小当前状态与目标状态差距 |
| 逆向搜索 | 从目标倒推 |
| 爬山法 | 逐步接近目标 |

**影响问题解决的因素：**
- 问题表征方式
- 心理定势
- 功能固着
- 原型启发
- 动机和情绪

## 五，决策与判断

### 启发式与偏差

| 启发式 | 偏差 |
|--------|------|
| 可得性启发 | 高估易回忆事件的发生率 |
| 代表性启发 | 忽视基础概率 |
| 锚定与调整 | 过度依赖初始信息 |

### 认知偏差

| 偏差类型 | 说明 |
|---------|------|
| 过度自信 | 高估自己的判断准确性 |
| 后见之明 | 事后认为当初可以预见 |
| 确认偏差 | 选择性注意支持自己观点的信息 |
| 损失厌恶 | 同样金额，损失带来的痛苦大于收益带来的快乐 |
