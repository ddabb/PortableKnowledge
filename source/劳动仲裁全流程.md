# 劳动仲裁全流程

> 劳动仲裁不收费，是劳动者维权的重要途径

---

## 一、什么情况下可以申请仲裁

| 争议类型 | 示例 |
|----------|------|
| 确认劳动关系 | 没签合同，但实际存在用工关系 |
| 追索劳动报酬 | 拖欠工资、加班费 |
| 经济补偿/赔偿金 | 被违法辞退要求2N赔偿 |
| 工伤待遇 | 公司不认可工伤或拒绝赔偿 |
| 社保/公积金 | 公司未依法缴纳 |
| 竞业限制/培训违约 | 公司主张违约金，劳动者不服 |
| 解除劳动合同争议 | 对解除理由有异议 |

---

## 二、申请条件

### 1. 仲裁时效

- 一般：自知道权利被侵害之日起 **1年**
- 拖欠劳动报酬：不受1年限制，但离职后要在1年内提出

### 2. 管辖地

可以选择以下任一地的仲裁委：
- **劳动合同履行地**（你实际工作的地方）
- **用人单位所在地**（公司注册地）

建议选择劳动合同履行地，举证更方便。

---

## 三、准备材料

### 1. 必备材料

| 材料 | 说明 |
|------|------|
| 仲裁申请书 | 一式两份（或按被申请人人数+1份） |
| 身份证复印件 | 正反面 |
| 被申请人信息 | 公司名称、地址、法定代表人 |
| 证据清单 | 列明证据名称和证明目的 |

### 2. 证据材料

**证明劳动关系的证据：**

- 劳动合同（最重要）
- 工资条/银行流水
- 社保缴纳记录
- 工作证/工牌
- 考勤记录
- 工作群聊天记录
- 邮件往来记录
- 工服照片

**证明被辞退的证据：**

- 解除劳动合同通知书
- 与HR/领导的沟通记录
- 最后工作日的打卡记录

**证明工资标准的证据：**

- 银行工资流水（至少近12个月）
- 工资条
- 年终奖/绩效发放记录

### 3. 仲裁申请书怎么写

**基本结构：**

```
申请人：姓名、身份证号、地址、电话
被申请人：公司全称、地址、法定代表人

仲裁请求：
1. 被申请人支付违法解除劳动合同赔偿金XXX元
2. 被申请人支付拖欠工资XXX元

事实与理由：
（简述入职时间、岗位、工资、发生争议的过程）

此致
XXX劳动人事争议仲裁委员会

申请人（签名）：_________
日期：_________
```

## 四、仲裁流程

### 1. 提交申请

- **方式**：现场提交或线上提交（部分地区支持）
- **受理时限**：5个工作日内决定是否受理
- **结果**：受理 → 通知书 / 不受理 → 可向法院起诉

### 2. 被申请人答辩

- 公司收到申请书后15日内提交答辩状
- 公司也需要举证

### 3. 庭前准备

- 确认开庭时间和地点
- 准备好所有证据原件
- 列出发言提纲
- 如有需要，可申请证人出庭

### 4. 开庭审理

**流程：**

1. **开庭陈述**：双方分别陈述请求和理由
2. **举证质证**：出示证据，对方进行质疑
3. **辩论**：双方围绕争议焦点发表意见
4. **最后陈述**：双方总结观点
5. **调解**：仲裁员可能组织调解
6. **休庭**：等待裁决

**注意事项：**

- 准时到庭，迟到可能按撤诉处理
- 携带所有证据原件
- 言语要冷静、客观，不要情绪化
- 不会说的可以请人代理（需要授权委托书）

### 5. 收到裁决

- 审限：45日，复杂案件可延长15日
- 不服裁决：可在收到裁决书 **15日** 内向法院起诉

## 五、仲裁结果

### 1. 可能的结果

| 结果 | 说明 |
|------|------|
| 支持全部请求 | 公司按裁决书执行 |
| 支持部分请求 | 按支持部分执行 |
| 不支持请求 | 可向法院起诉 |
| 调解成功 | 出具调解书，具有法律效力 |

### 2. 公司不执行怎么办

- 可向**人民法院申请强制执行**
- 公司财产可被查封、冻结、拍卖
- 公司法定代表人可能被限制高消费

### 3. 对一裁终局案件

以下案件一裁终局（裁决书自作出之日起生效）：
- 追索劳动报酬不超过当地月最低工资标准12个月
- 工伤待遇争议
- 因执行劳动标准产生的争议

但劳动者对终局裁决不服的，仍可向法院起诉。

## 六、常见问题

### Q1：仲裁要花钱吗？

**劳动仲裁不收费**，完全免费。

### Q2：需要请律师吗？

- 简单案件（金额小、事实清楚）：可以自己处理
- 复杂案件：建议咨询律师或申请法律援助
- 经济困难：可向当地**法律援助中心**申请免费法律援助

### Q3：公司注销了怎么办？

- 可将股东/出资人列为被申请人
- 工商档案中的注销材料是证据

### Q4：没有签劳动合同怎么办？

可以申请确认劳动关系。通过工资流水、社保记录、工作记录等证据证明。

**注意：** 未签书面合同超过1个月，还可以主张 **双倍工资**（最多11个月）。

### Q5：仲裁期间公司威胁我怎么办？

- 保留证据
- 不受威胁影响
- 可向劳动监察部门举报

## 七、仲裁 vs 诉讼

| 对比项 | 劳动仲裁 | 法院诉讼 |
|--------|----------|----------|
| 费用 | 免费 | 需要诉讼费（可减免） |
| 时限 | 45-60天 | 3-6个月 |
| 前置条件 | 无 | 需先经过仲裁 |
| 程序 | 相对简便 | 相对正式 |
| 结果 | 可向法院起诉 | 二审终审 |

---

## 八、维权小贴士

1. **证据为王**：平时养成保留工作证据的习惯
2. **不要超时**：1年仲裁时效一定要记住
3. **理性维权**：了解自己的合法权益，合理主张
4. **善用法律援助**：经济困难时可以申请免费法律帮助
5. **线上渠道**：部分地区支持网上申请仲裁，更方便

---
