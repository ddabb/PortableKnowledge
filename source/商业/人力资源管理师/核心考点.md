# 人力资源管理师核心考点

## 一、人力资源六大模块

### 1. 人力资源规划

**核心内容**：
- 人力资源需求预测与供给分析
- 人力资源规划编制流程
- 人力资源信息系统建设

**考试要点**：
- 定性预测法：德尔菲法、管理人员判断法
- 定量预测法：趋势分析法、回归分析法
- 人力资源供需平衡策略

### 2. 招聘与配置

**核心内容**：
- 招聘渠道选择与效果评估
- 面试技术与人才测评
- 人岗匹配与岗位分析

**考试要点**：
- 内部招聘 vs 外部招聘优缺点
- 结构化面试、非结构化面试、半结构化面试
- 情境模拟测试：公文筐测试、无领导小组讨论

### 3. 培训与开发

**核心内容**：
- 培训需求分析方法
- 培训计划设计与实施
- 培训效果评估（柯氏四级评估）

**考试要点**：
- 培训需求分析层次：组织层面、任务层面、个人层面
- 柯氏四级评估模型：反应层、学习层、行为层、结果层
- 在职培训方法：导师制、轮岗、学徒培训

### 4. 绩效管理

**核心内容**：
- 绩效考核方法选择
- 绩效反馈与面谈技巧
- 绩效结果应用

**考试要点**：
- 绩效考核方法：KPI、BSC、360度评估、目标管理法
- 绩效误差类型：晕轮效应、近因效应、刻板印象
- 绩效面谈原则：双向沟通、以事实为依据

### 5. 薪酬福利管理

**核心内容**：
- 薪酬体系设计
- 薪酬调查与岗位评价
- 福利项目管理

**考试要点**：
- 薪酬结构设计：基本薪酬、可变薪酬、间接薪酬
- 岗位评价方法：排序法、分类法、要素计点法、因素比较法
- 法定福利：五险一金、带薪年假、法定假期

### 6. 劳动关系管理

**核心内容**：
- 劳动合同管理
- 劳动争议处理
- 员工关系维护

**考试要点**：
- 劳动合同类型：固定期限、无固定期限、以完成一定任务为期限
- 劳动争议处理程序：协商、调解、仲裁、诉讼
- 解除劳动合同的经济补偿标准

## 二、劳动法规核心考点

### 劳动合同法

**劳动合同订立**：
- 建立劳动关系应当订立书面劳动合同
- 未签合同的后果：支付双倍工资（最多11个月）
- 无固定期限合同情形：连续工作满10年、连续订立两次固定期限合同

**劳动合同解除**：
- 协商解除：双方协商一致
- 单位单方解除：过失性辞退（无需补偿）、非过失性辞退（需补偿）
- 劳动者单方解除：提前30日书面通知、即时解除情形

**经济补偿标准**：
- 按劳动者在本单位工作年限计算
- 每满一年支付一个月工资
- 六个月以上不满一年按一年计算，不满六个月支付半个月工资
- 高工资者（三倍以上）按三倍支付，最高不超过12年

### 劳动争议调解仲裁法

**仲裁时效**：
- 一般时效：知道权利被侵害之日起一年
- 劳动报酬争议：劳动关系存续期间不受时效限制

**仲裁程序**：
- 劳动争议仲裁是诉讼的前置程序
- 仲裁庭在受理后45日内结案，可延长15日

### 社会保险法

**五险一金**：
| 险种 | 单位缴费比例 | 个人缴费比例 |
|------|-------------|-------------|
| 养老保险 | 16% | 8% |
| 医疗保险 | 8% | 2% |
| 失业保险 | 0.5-1% | 0.5% |
| 工伤保险 | 0.2-1.9% | — |
| 生育保险 | 合并至医疗险 | — |
| 住房公积金 | 5-12% | 5-12% |

## 三、备考建议

1. **重点章节**：绩效管理、薪酬管理、劳动关系管理是高频考点
2. **法规记忆**：劳动合同法、劳动争议调解仲裁法需精准记忆
3. **案例分析**：注重实务操作，特别是计算类题目（经济补偿金、加班工资等）
4. **刷题策略**：历年真题反复练习，理解出题规律
