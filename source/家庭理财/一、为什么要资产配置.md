## 一、为什么要资产配置

### 1.1 资产配置的目的

| 目的 | 说明 |
|------|------|
| 分散风险 | 不把鸡蛋放一个篮子 |
| 稳定收益 | 高低搭配，稳健为主 |
| 应对需求 | 不同资金有不同用途 |
| 长期增值 | 跑赢通胀，实现财务目标 |

### 1.2 核心原则

```
标准普尔家庭资产配置图
├── 10% 要花的钱（短期）
├── 20% 保命的钱（保障）
├── 30% 生钱的钱（投资）
└── 40% 保本的钱（储蓄）
```
