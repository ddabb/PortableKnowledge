## 一、信用卡基础

### 1.1 信用卡核心概念

| 术语 | 含义 |
|------|------|
| 账单日 | 每月生成账单的日期 |
| 还款日 | 必须还款的日期 |
| 免息期 | 不产生利息的时间段 |
| 额度 | 信用卡可消费的金额 |
| 最低还款 | 当月最少要还的钱 |

### 1.2 免息期计算

```
免息期 = 还款日 - 消费日

最长免息期 = 还款日 - 账单日次日
```

**举例：**
- 账单日：每月5日
- 还款日：每月25日
- 6月6日消费 → 7月25日还 = 49天免息
- 6月5日消费 → 6月25日还 = 20天免息

**技巧：在账单日后消费，免息期最长**
