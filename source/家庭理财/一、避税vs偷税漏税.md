## 避税、节税、逃税、偷税……一字之差，违法风险天壤之别

### 1.1 四个概念一次说清楚

| 类型 | 定义 | 性质 | 后果 |
|------|------|------|------|
| **避税** | 利用税收优惠政策合法降低税负 | ✅ 合法 | 无 |
| **节税** | 通过合理安排减少应税行为 | ✅ 合法 | 无 |
| **逃税** | 隐匿收入、虚假申报等 | ❌ 违法 | 补税+罚款+滞纳金 |
| **偷税** | 伪造、变造账簿，设置两套账 | ❌ 违法 | 补税+罚款+滞纳金+刑事责任 |

### 1.2 什么是合法的避税

**合法避税的本质：利用规则，不是违反规则。**

常见合法避税方式：

1. **专项附加扣除**：子女教育、继续教育、大病医疗、住房贷款利息、住房租金、赡养老人——这些是政策给的福利，不用白不用

2. **个人养老金账户**：每年最多存12000元，存入时税前扣除，领取时按3%征税。高收入者（税率20%以上）节税效果明显。

3. **税优健康险**：每年2400元额度，税前扣除，适合健康人群。

4. **公积金**：公司和个人缴的公积金都免税（12%以内），买房租房都可以提取。

5. **年终奖单独计税**：年终奖可以选择单独计税或合并计税，哪个少交税选哪个。

### 1.3 什么是违法的逃税/偷税

❌ **逃税行为：**
- 不申报收入（私账收款不入账）
- 虚假申报专项附加扣除
- 隐匿股息、红利所得
- 不申报财产转让所得
- 虚假列支成本费用

❌ **偷税行为：**
- 伪造、变造会计凭证和账簿
- 设置两套账（对内一套、对外一套）
- 隐匿会计凭证和账簿
- 进行虚假纳税申报

### 1.4 违法后果有多严重

**行政处罚：**
- 补缴税款
- 0.5-5倍罚款
- 按日加收万分之五滞纳金（年化约18%）

**刑事处罚（情节严重时）：**
- 逃避缴纳税款数额较大且占应纳税额10%以上：最高7年有期徒刑
- 数额巨大且占应纳税额30%以上：最高7年有期徒刑

### 1.5 2021年薇娅案：前车之鉴

**案例：** 网红主播薇娅，通过设立多家个人独资企业虚构业务，将劳务报酬转换为经营所得，虚假申报，最终被追缴税款+罚款+滞纳金共13.41亿元。

**教训：**
- 所谓"税收洼地""个人独资企业核定征收"不是避税神器
- 金税系统日益强大，异常数据会被预警
- 不要轻信"别人都这么做的"

### 1.6 合法节税的实用建议

1. **用足专项附加扣除**：6项专项附加扣除，每年可以省下几百到几千元税
2. **合理安排年终奖**：单独计税 vs 合并计税，算一算哪个更省
3. **投资个人养老金**：高收入者节税效果显著
4. **用好公积金**：公司缴的那部分也是你的钱
5. **大额支出提前规划**：比如买房、装修、教育等支出可以专项附加扣除

### 1.7 什么时候需要专业人士

| 情况 | 建议 |
|------|------|
| 年收入 < 20万 | 用好专项附加扣除就够了 |
| 年收入 20-100万 | 可以考虑个人养老金、公积金规划 |
| 年收入 > 100万 | 建议找税务师做全年规划 |
| 涉及股权/房产交易 | 必须找专业人士 |

---

**本节要点：**
- 避税和偷税只有一线之隔，一字之差后果天壤之别
- 合法避税：利用政策福利，不是伪造业务
- 违法逃税/偷税：隐匿收入、虚假申报、两套账
- 用足专项附加扣除是最简单有效的合法节税方式
