## 三、不同人群配置

### 3.1 成人（25-50岁）

| 险种 | 保额建议 | 年保费 |
|------|---------|--------|
| 医疗险 | 200万 | 200-500 |
| 意外险 | 50-100万 | 200-300 |
| 重疾险 | 50万 | 3000-8000 |
| 寿险 | 100万 | 1000-3000 |

### 3.2 儿童（0-18岁）

| 险种 | 说明 |
|------|------|
| 医疗险 | 必备 |
| 意外险 | 便宜，磕磕碰碰能报 |
| 重疾险 | 早买便宜，保障终身 |

**注意：** 不要买寿险（儿童不需要）

### 3.3 老人（50岁以上）

| 险种 | 说明 |
|------|------|
| 医疗险 | 能买则买，60岁内 |
| 意外险 | 老人骨折高发，必买 |
| 防癌险 | 买不了重疾险的替代 |
