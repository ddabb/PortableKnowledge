## 一、个税基础

### 1.1 个税计算公式

```
应纳税所得额 = 税前收入 - 免税收入 - 社保公积金 - 60000(起征点) - 专项附加扣除
应纳税额 = 应纳税所得额 × 税率 - 速算扣除数
```

### 1.2 税率表（综合所得）

| 级数 | 应纳税所得额 | 税率 |
|------|-------------|------|
| 1 | ≤36000 | 3% |
| 2 | 36000-144000 | 10% |
| 3 | 144000-300000 | 20% |
| 4 | 300000-420000 | 25% |
| 5 | 420000-660000 | 30% |
| 6 | 660000-960000 | 35% |
| 7 | >960000 | 45% |

### 1.3 个税改革要点

| 项目 | 变化 |
|------|------|
| 起征点 | 5000元/月（60000/年） |
| 税率级距 | 扩大，低税率覆盖更广 |
| 专项附加扣除 | 新增6项扣除 |

## 二、专项附加扣除（6项）

### 2.1 子女教育

| 项目 | 标准 |
|------|------|
| 扣除标准 | 每个子女1000元/月 |
| 年龄范围 | 3岁-学历教育（博士） |
| 适用范围 | 学前教育至博士研究生 |

**条件：**
- 子女在境内/境外正规学校就读
- 学籍在读即可

### 2.2 继续教育

| 类型 | 扣除标准 |
|------|---------|
| 学历教育 | 400元/月 |
| 技能人员职业资格 | 取得证书当年3600元 |
| 专业技术人员职业资格 | 取得证书当年3600元 |

### 2.3 大病医疗

| 项目 | 标准 |
|------|------|
| 扣除标准 | 医保报销后自付15000-80000元 |
| 时间 | 治疗年度次年3-6月汇算时扣除 |
| 扣除对象 | 本人、配偶、未成年子女 |

### 2.4 住房贷款利息

| 项目 | 标准 |
|------|------|
| 扣除标准 | 1000元/月 |
| 期限 | 最长240个月 |
| 条件 | 首套房贷，正在还贷 |
| 方式 | 婚后可约定由一方100%扣除 |

**注意：**
- 必须是首套住房贷款
- 婚后只能一方扣除
- 2023年起标准提高至1000元/月

### 2.5 住房租金

| 城市级别 | 扣除标准 |
|---------|---------|
| 省会/一线 | 1500元/月 |
| 市辖区人口>100万 | 1100元/月 |
| 市辖区人口≤100万 | 800元/月 |

**条件：**
- 在工作地无自有住房
- 租房合同在有效期

### 2.6 赡养老人

| 项目 | 标准 |
|------|------|
| 扣除标准 | 3000元/月 |
| 条件 | 60岁及以上父母 |
| 方式 | 独生子女3000，独生子女分摊3000 |

## 四、申报操作

### 4.1 专项附加扣除填报

**方式一：个税APP填报**

1. 下载「个人所得税」APP
2. 登录/注册账号
3. 点击「专项附加扣除填报」
4. 选择年度（如2024年）
5. 逐项填写信息
6. 选择扣除方式（本人/配偶）
7. 确认提交

**方式二：单位代扣代缴时扣除**

- 提交材料给HR
- 单位在发放工资时代扣

### 4.2 申报时间

| 类型 | 时间 |
|------|------|
| 每月工资预扣 | 当月 |
| 专项附加扣除确认 | 每年12月确认下一年度 |
| 汇算清缴 | 次年3-6月 |

## 五、年终奖计税

### 5.1 两种计税方式

| 方式 | 算法 | 适用情况 |
|------|------|---------|
| 单独计税 | 奖金÷12后找税率，单独计算 | 年收入< 综合所得税率区间 |
| 并入综合所得 | 奖金+工资一起计税 | 年收入> 综合所得税率区间 |

### 5.2 如何选择

**低收入者：** 单独计税更划算

**高收入者：** 并入综合所得更划算

**建议：** 两种方式都试，算出结果选低的

## 六、汇算清缴

### 6.1 哪些人需要

| 情况 | 是否需要汇算 |
|------|------------|
| 只有工资，无其他收入 | 不需要 |
| 有劳务报酬/稿酬/特许权使用费 | 需要 |
| 年收入>12万，补税>400元 | 必须汇算 |
| 预缴不足，需补税 | 需要 |

### 6.2 汇算清缴操作

1. 打开个税APP
2. 点击「综合所得年度汇算」
3. 选择年度
4. 确认收入和扣除信息
5. 查看应补/应退税额
6. 提交申请

### 6.3 常见补税原因

- 换工作导致税率跳档
- 年终奖单独计税导致
- 漏填专项附加扣除
- 有副业/兼职收入

## 七、省税技巧

### 7.1 充分利用专项附加扣除

| 技巧 | 说明 |
|------|------|
| 60岁前考驾照 | 可扣继续教育 |
| 继续教育拿证书 | 当年3600元扣除 |
| 夫妻合理分摊 | 租金/房贷约定扣除方 |
| 父母有一方满60岁 | 开始填报赡养老人 |

### 7.2 合理安排收入

- 年终奖可选择计税方式
- 副业收入可成立个体户享受优惠
- 公益捐赠可抵扣（需通过官方渠道）

### 7.3 常见误区

❌ **误区：** 年收入10万不用申报
✓ **真相：** 低于6万可能产生退税，值得申报

❌ **误区：** 夫妻各自扣子女教育
✓ **真相：** 可以约定一方扣100%

## 八、常见问题

### Q：换工作后如何处理？
A：在新单位重新填报，系统会自动累计

### Q：父母在外地可以填吗？
A：可以，赡养老人不看地域

### Q：房贷和租金可以同时扣吗？
A：不可以，只能选一个

### Q：个体工商户怎么交税？
A：按经营所得交税，税率5-35%
