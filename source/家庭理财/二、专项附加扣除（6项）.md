## 二、专项附加扣除（6项）

### 2.1 子女教育

| 项目 | 标准 |
|------|------|
| 扣除标准 | 每个子女1000元/月 |
| 年龄范围 | 3岁-学历教育（博士） |
| 适用范围 | 学前教育至博士研究生 |

**条件：**
- 子女在境内/境外正规学校就读
- 学籍在读即可

### 2.2 继续教育

| 类型 | 扣除标准 |
|------|---------|
| 学历教育 | 400元/月 |
| 技能人员职业资格 | 取得证书当年3600元 |
| 专业技术人员职业资格 | 取得证书当年3600元 |

### 2.3 大病医疗

| 项目 | 标准 |
|------|------|
| 扣除标准 | 医保报销后自付15000-80000元 |
| 时间 | 治疗年度次年3-6月汇算时扣除 |
| 扣除对象 | 本人、配偶、未成年子女 |

### 2.4 住房贷款利息

| 项目 | 标准 |
|------|------|
| 扣除标准 | 1000元/月 |
| 期限 | 最长240个月 |
| 条件 | 首套房贷，正在还贷 |
| 方式 | 婚后可约定由一方100%扣除 |

**注意：**
- 必须是首套住房贷款
- 婚后只能一方扣除
- 2023年起标准提高至1000元/月

### 2.5 住房租金

| 城市级别 | 扣除标准 |
|---------|---------|
| 省会/一线 | 1500元/月 |
| 市辖区人口>100万 | 1100元/月 |
| 市辖区人口≤100万 | 800元/月 |

**条件：**
- 在工作地无自有住房
- 租房合同在有效期

### 2.6 赡养老人

| 项目 | 标准 |
|------|------|
| 扣除标准 | 3000元/月 |
| 条件 | 60岁及以上父母 |
| 方式 | 独生子女3000，独生子女分摊3000 |
