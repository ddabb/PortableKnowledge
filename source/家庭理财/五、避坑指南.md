## 买保险最容易踩的5个坑，附正确做法

### 5.1 常见坑

| 坑 | 真相 |
|---|------|
| 返还型保险 | 保费贵，保障弱，实际年化收益可能不如银行存款 |
| 捆绑销售 | 把不需要的险种打包卖，拆开买能省30-50% |
| 过度保障 | 保额买太高，用不上就是浪费 |
| 保障不足 | 保额太低，出事时根本不够用 |
| 全家桶险 | 一个产品包所有，看着省心实则烧钱 |

### 5.2 正确选择

**买消费型保险：**
- 不返还保费，保障纯粹
- 杠杆更高：几百块换几十万保障
- 适合普通家庭

**定期 > 终身：**
- 定期保费便宜，50岁前家庭责任重更需要保障
- 50岁后孩子独立、经济责任减轻，可以不买
- 同样的钱，给孩子买更划算

### 5.3 哪些不需要买

| 保险 | 原因 |
|------|------|
| 终身寿险 | 等同龄买就行，孩子不需要 |
| 住院津贴险 | 百万医疗险已经覆盖 |
| 理财型保险 | 收益低，流动性差，不如自己理财 |
| 全家桶险 | 拆开买，保障更好还更便宜 |

### 5.4 一句话总结

> 消费型 + 定期 + 纯保障 = 普通人买保险的正确姿势

---

**本节要点：**
- 避开返还型、捆绑销售、全家桶
- 优先消费型 + 定期
- 保额要够用，但不必过度
