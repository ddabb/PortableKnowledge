---

## 一、为什么要买保险

### 1.1 保险的本质

保险 = 用小额确定支出，转移大额不确定损失

**核心逻辑：**
- 平时花小钱（保费）
- 换来大钱保障（保额）
- 防止意外摧毁家庭财务

### 1.2 不买保险的风险

| 风险场景 | 无保险后果 | 有保险后果 |
|---------|-----------|-----------|
| 患大病 | 积蓄归零 + 借钱治病 | 获赔数十万 |
| 意外身故 | 家庭失去收入 | 家人获赔百万 |
| 车祸 | 自己承担全部费用 | 保险公司赔付 |

## 二、保险类型

### 2.1 四大基础险种

| 险种 | 作用 | 优先级 |
|------|------|--------|
| **医疗险** | 报销医疗费用 | ⭐⭐⭐ 最高 |
| **意外险** | 意外伤残/身故赔付 | ⭐⭐⭐ 最高 |
| **重疾险** | 患大病一次性给付 | ⭐⭐⭐ 重要 |
| **寿险** | 身故赔付家人 | ⭐⭐ 家庭支柱 |

### 2.2 各险种详解

#### 医疗险

**报销看病费用：**
- **百万医疗：** 几百块/年，保额百万
- **小额医疗：** 1万以内门诊/住院
- **高端医疗：** 涵盖特需/VIP病房

**推荐：先买百万医疗险**

#### 意外险

**意外导致的伤残/身故：**
- 意外医疗报销
- 意外伤残按等级赔付（1-10级）
- 意外身故一次性赔付

**特点：** 便宜，杠杆高，200-300/年

#### 重疾险

**患约定大病一次性给钱：**
| 疾病类型 | 给付条件 |
|---------|---------|
| 确诊即赔 | 癌症、多个肢体缺失 |
| 做了手术 | 冠状动脉搭桥术 |
| 持续状态 | 脑中风后遗症、肾衰 |

**保额建议：** 3-5年年收入

#### 寿险

**身故/全残赔付：**
- 给家人的保障
- 家庭支柱必买
- 保额 = 家庭负债 + 10年年收入

## 三、不同人群配置

### 3.1 成人（25-50岁）

| 险种 | 保额建议 | 年保费 |
|------|---------|--------|
| 医疗险 | 200万 | 200-500 |
| 意外险 | 50-100万 | 200-300 |
| 重疾险 | 50万 | 3000-8000 |
| 寿险 | 100万 | 1000-3000 |

### 3.2 儿童（0-18岁）

| 险种 | 说明 |
|------|------|
| 医疗险 | 必备 |
| 意外险 | 便宜，磕磕碰碰能报 |
| 重疾险 | 早买便宜，保障终身 |

**注意：** 不要买寿险（儿童不需要）

### 3.3 老人（50岁以上）

| 险种 | 说明 |
|------|------|
| 医疗险 | 能买则买，60岁内 |
| 意外险 | 老人骨折高发，必买 |
| 防癌险 | 买不了重疾险的替代 |

## 四、配置原则

### 4.1 正确购买顺序

```
先保障后理财
先大人后小孩
先保额后期限
先产品后公司
```

### 4.2 保额计算

| 险种 | 保额计算 |
|------|---------|
| 重疾险 | 3-5年年收入 |
| 寿险 | 家庭负债 + 10年年收入 |
| 意外险 | 10年年收入 |
| 医疗险 | 越高越好 |

### 4.3 保费预算

**建议：** 家庭年收入的 **5-10%**

| 家庭年收入 | 保费预算 |
|-----------|---------|
| 10万 | 5000-10000 |
| 20万 | 10000-20000 |
| 30万 | 15000-30000 |

## 五、避坑指南

### 5.1 常见坑

| 坑 | 真相 |
|---|------|
| 返还型保险 | 保费贵，保障弱 |
| 捆绑销售 | 拆开买更便宜 |
| 过度保障 | 没必要买太高保额 |
| 保障不足 | 保额太低没意义 |

### 5.2 正确选择

**买消费型保险：**
- 不返还保费
- 保障纯粹
- 杠杆更高

**定期 > 终身：**
- 定期便宜
- 50岁后家庭责任减轻
- 留钱给孩子买更划算

### 5.3 不需要买的

| 保险 | 原因 |
|------|------|
| 终身寿险 | 孩子不需要 |
| 住院津贴 | 百万医疗就够了 |
| 理财险 | 收益低，流动性差 |
| 全家桶险 | 拆开买更便宜 |

## 七、实操建议

1. **先买医疗险：** 几百块保百万
2. **加意外险：** 200块保50万
3. **加重疾险：** 50万保额起步
4. **家庭支柱加寿险：** 留爱不留债
5. **定期检视：** 每3年调整一次
