## 一、信用卡基础

### 1.1 信用卡核心概念

| 术语 | 含义 |
|------|------|
| 账单日 | 每月生成账单的日期 |
| 还款日 | 必须还款的日期 |
| 免息期 | 不产生利息的时间段 |
| 额度 | 信用卡可消费的金额 |
| 最低还款 | 当月最少要还的钱 |

### 1.2 免息期计算

```
免息期 = 还款日 - 消费日

最长免息期 = 还款日 - 账单日次日
```

**举例：**
- 账单日：每月5日
- 还款日：每月25日
- 6月6日消费 → 7月25日还 = 49天免息
- 6月5日消费 → 6月25日还 = 20天免息

**技巧：在账单日后消费，免息期最长**

## 二、费用解析

### 2.1 费用类型

| 费用 | 说明 | 是否要避免 |
|------|------|----------|
| 年费 | 年费，部分卡免 | 看卡种 |
| 取现手续费 | 取现金额1-3% | ⚠️ 尽量不取现 |
| 分期手续费 | 分期还款手续费 | ⚠️ 谨慎分期 |
| 逾期利息 | 未还金额日息0.05% | ⚠️ 绝对不要逾期 |
| 违约金 | 逾期后的处罚 | ⚠️ 绝对不要逾期 |

### 2.2 逾期利息计算

**逾期利息 = 未还金额 × 0.05% × 天数**

| 未还金额 | 逾期30天利息 |
|---------|-------------|
| 10000元 | 150元 |
| 50000元 | 750元 |

⚠️ **逾期还会影响征信，影响贷款！**

## 三、还款技巧

### 3.1 正确还款方式

| 还款方式 | 优点 | 缺点 |
|---------|------|------|
| 全额还款 | 无利息 | 无 |
| 最低还款 | 不逾期 | 利息高 |
| 分期还款 | 分摊压力 | 手续费高 |

### 3.2 自动还款

**设置自动还款：**
- 绑定储蓄卡
- 确保储蓄卡有钱
- 设置还款日为还款日当天

**好处：** 不会忘记还款，避免逾期

### 3.3 分期还款

| 分期期数 | 手续费率（参考） |
|---------|----------------|
| 3期 | 2-3% |
| 6期 | 3-5% |
| 12期 | 5-8% |

**年化利率 ≈ 分期手续费 × 2**
- 分期6期手续费3% → 年化约6%
- 比信用贷款利率低

## 五、避坑指南

### 5.1 必须避免的坑

| 坑 | 后果 | 如何避免 |
|---|------|---------|
| 最低还款 | 利息按全额计算 | 全额还款 |
| 取现 | 高手续费+日息 | 不用信用卡取现 |
| 逾期 | 影响征信+利息 | 设置自动还款 |
| 分期提前还 | 可能收剩余手续费 | 选免提前还款费的分期 |
| 超限费 | 超出额度消费的手续费 | 控制消费不超额度 |

### 5.2 最低还款的陷阱

**错误理解：** 还最低还款不算逾期

**真相：** 
- 未还金额继续按日计息
- 按消费全额计算，不是剩余金额
- 利息从消费日起算

**举例：**
- 消费10000元，还最低1000元
- 9000元按日息0.05%计算
- 利息 = 9000 × 0.05% × 天数

### 5.3 征信误区

| 误解 | 真相 |
|------|------|
| 不激活不收费 | 部分卡即使不激活也收年费 |
| 不用就不上征信 | 申请就会查征信 |
| 销卡就清除记录 | 逾期记录保留5年 |

## 六、养卡提额

### 6.1 提额技巧

| 方法 | 说明 |
|------|------|
| 按时全额还款 | 银行最喜欢的用户 |
| 多元化消费 | 餐饮、超市、网购等 |
| 多刷小额 | 每月消费30%以上额度 |
| 偶尔分期 | 让银行赚点手续费 |
| 不要空卡 | 额度使用率不超80% |

### 6.2 降额封卡原因

| 原因 | 后果 |
|------|------|
| 逾期 | 可能降额封卡 |
| TX（套现） | 封卡风险 |
| 大进大出 | 触发风控 |
| 长期空卡 | 降额 |
| 多次最低还款 | 降额风险 |

## 七、多卡管理

### 7.1 卡片数量建议

**普通人：1-3张足够**
- 1张日常消费
- 1张特定权益（如加油）
- 1张备用

### 7.2 多卡还款管理

| 方法 | 工具 |
|------|------|
| 统一还款日 | 调整账单日 |
| 设置多个提醒 | 手机日历 |
| 绑定同一储蓄卡 | 自动扣款 |

### 7.3 销卡注意

1. 还清所有欠款
2. 积分类权益用完再销
3. 销卡后45天确认无欠款
4. 剪断磁条/芯片

## 八、安全使用

### 8.1 保护信用卡

| 安全措施 | 说明 |
|---------|------|
| 卡号遮住 | 消费时遮住卡号 |
| CVV保密 | 卡片背面3位数 |
| 设置交易密码 | 每次交易需密码 |
| 开通交易提醒 | 短信/微信通知 |
| 境外锁 | 出国前开启 |

### 8.2 被盗刷怎么办

1. **第一时间挂失**
2. **冻结卡片**
3. **联系银行**
4. **报警**
5. **保留证据**

**责任划分：**
- 凭密码交易 → 责任自担
- 凭签名交易（非本人签名）→ 银行赔偿
