## 信用卡被盗刷怎么办？保护信用卡安全的10条铁律

### 8.1 信用卡安全的10条铁律

**① 卡号要遮住**

- 消费时，遮挡卡面上的16位卡号
- 只在信任的网站输入卡号
- 不要把卡正反面拍照发给别人

**② CVV要保密**

- 卡片背面签名条上的3位数（CVV2）
- 这是信用卡的"第二密码"，泄露了相当于给了钥匙
- 网购时需要CVV2，线下刷卡不需要

**③ 设置交易密码**

- 国内信用卡默认需要密码+签名交易
- 不要设置太简单的密码（123456、生日等）
- 不同卡片用不同密码

**④ 开通交易提醒**

- 短信提醒（有些银行收费）
- 微信提醒（免费）
- 每笔交易都收到通知，及时发现异常

**⑤ 开启境外锁**

- 不出国时，关闭境外交易功能
- 出国前开启，回国后关闭
- 防止境外盗刷

**⑥ 定期查账单**

- 每月账单出来后仔细核对
- 发现异常交易及时联系银行
- 不要等到还款日才看账单

**⑦ 不点可疑链接**

- 收到"银行"短信/邮件，不要点链接
- 银行不会让你点击链接修改密码
- 登录银行APP或官网，不要通过链接进入

**⑧ 公共WiFi不交易**

- 咖啡馆、机场等公共WiFi不安全
- 涉及支付的操作，用手机网络
- 或者用VPN

**⑨ 旧卡要剪掉**

- 过期卡、注销卡，剪掉磁条和芯片
- 卡片上的信息还是完整的，不处理有风险

**⑩ 不把卡借给他人**

- 信用卡是实名制的，只能本人使用
- 借给别人，出了问题你要负责
- 代刷、套现都是违规行为

### 8.2 信用卡被盗刷后的紧急处理

**发现被盗刷后，立即按以下步骤处理：**

**Step 1：第一时间挂失**
- 拨打银行客服电话（信用卡背面）
- 告知"信用卡被盗刷，需要挂失"
- 客服会立即冻结卡片

**Step 2：冻结卡片**
- 通过银行APP紧急锁卡
- 或在APP里设置"一键锁卡"

**Step 3：联系银行**
- 详细说明被盗刷情况
- 提供交易时间、金额、商户信息
- 银行会启动调查流程

**Step 4：报警**
- 到附近派出所报案
- 拿到报警回执（银行调查需要）
- 保留好报警记录

**Step 5：保留证据**
- 保存被盗刷的短信/微信通知
- 保存账单截图
- 如果有监控录像，保存录像

### 8.3 责任划分

**被盗刷后，谁承担责任？**

| 情况 | 责任归属 |
|------|----------|
| 凭密码交易 | 持卡人责任（密码只有你知道） |
| 凭签名交易，非本人签名 | 银行责任 |
| 卡片丢失，未及时挂失 | 挂失前持卡人责任，挂失后银行责任 |
| 伪卡交易（复制卡） | 银行责任 |
| 网络盗刷（信息泄露） | 需要调查后判定 |

**持卡人可以免责的情况：**
- 卡片一直在身边，但被盗刷（伪卡交易）
- 银行系统安全漏洞导致信息泄露
- 在挂失后被盗刷

**持卡人需要承担责任的情况：**
- 密码设置的太简单，被猜到
- 卡片丢失，没有及时挂失
- 把卡借给他人使用
- 点击钓鱼网站泄露信息

### 8.4 境外盗刷特别提醒

**境外盗刷的特点：**
- 不需要密码，只需卡号+有效期+CVV
- 盗刷团伙往往在境外，追回难度大
- 非美元交易可能产生汇率损失

**预防境外盗刷：**
- 不出国时关闭境外交易功能
- 出国时只带必要的卡
- 回国后立即关闭境外交易

**境外被盗刷处理：**
- 立即挂失，防止进一步损失
- 联系银行发起拒付（Chargeback）
- 保留交易凭证，配合银行调查

### 8.5 常见诈骗手段

**① 假冒银行客服**

- 接到"银行"电话，说信用卡被盗刷，需要"验证"信息
- 真相：银行不会主动打电话要你的密码/CVV

**② 钓鱼网站**

- 收到"银行"短信，点进去是一个假网站
- 真相：银行不会让你点链接修改密码

**③ 代刷/套现**

- 有人让你帮忙刷卡，给你好处费
- 真相：这是违规行为，卡可能被复制

**④ 虚假pos机**

- 小商贩的POS机可能是假的
- 真相：尽量在正规商户刷卡

### 8.6 安全使用信用卡检查清单

**每月检查：**
- [ ] 核对账单，有无异常交易
- [ ] 检查短信/微信提醒是否正常

**每年检查：**
- [ ] 修改一次交易密码
- [ ] 检查是否开启了境外锁
- [ ] 清理不需要的副卡

**出国前后：**
- [ ] 出国前开启境外交易
- [ ] 回国后关闭境外交易
- [ ] 只带1-2张卡

**本节要点：**
- CVV是信用卡第二密码，绝对不要泄露
- 开通交易提醒，第一时间发现异常
- 被盗刷后立即挂失、冻结、报警
- 不出国时关闭境外交易功能
- 不要点"银行"发来的链接
