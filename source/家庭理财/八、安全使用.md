## 八、安全使用

### 8.1 保护信用卡

| 安全措施 | 说明 |
|---------|------|
| 卡号遮住 | 消费时遮住卡号 |
| CVV保密 | 卡片背面3位数 |
| 设置交易密码 | 每次交易需密码 |
| 开通交易提醒 | 短信/微信通知 |
| 境外锁 | 出国前开启 |

### 8.2 被盗刷怎么办

1. **第一时间挂失**
2. **冻结卡片**
3. **联系银行**
4. **报警**
5. **保留证据**

**责任划分：**
- 凭密码交易 → 责任自担
- 凭签名交易（非本人签名）→ 银行赔偿
