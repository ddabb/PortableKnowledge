## 六、养卡提额

### 6.1 提额技巧

| 方法 | 说明 |
|------|------|
| 按时全额还款 | 银行最喜欢的用户 |
| 多元化消费 | 餐饮、超市、网购等 |
| 多刷小额 | 每月消费30%以上额度 |
| 偶尔分期 | 让银行赚点手续费 |
| 不要空卡 | 额度使用率不超80% |

### 6.2 降额封卡原因

| 原因 | 后果 |
|------|------|
| 逾期 | 可能降额封卡 |
| TX（套现） | 封卡风险 |
| 大进大出 | 触发风控 |
| 长期空卡 | 降额 |
| 多次最低还款 | 降额风险 |
