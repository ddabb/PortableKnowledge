## 四、积分与权益

### 4.1 积分规则

| 卡种 | 积分政策 |
|------|---------|
| 普通卡 | 消费1元 = 1积分 |
| 金卡 | 消费1元 = 1-2积分 |
| 白金卡 | 消费1元 = 1-3积分 |

### 4.2 积分用途

| 用途 | 价值 |
|------|------|
| 兑换礼品 | 价值约0.1-0.2% |
| 兑换里程 | 较划算 |
| 抵扣还款 | 积分当钱用 |
| 兑换权益 | 机场贵宾厅等 |

### 4.3 高性价比卡权益

| 权益 | 适合人群 |
|------|---------|
| 加油返现 | 有车一族 |
| 超市购物返现 | 日常消费多 |
| 境外返现 | 经常出国 |
| 机场贵宾厅 | 出差频繁 |
| 延误险 | 经常坐飞机 |
