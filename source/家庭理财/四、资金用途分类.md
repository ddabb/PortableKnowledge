## 四、资金用途分类

### 4.1 紧急备用金

| 项目 | 说明 |
|------|------|
| 金额 | 3-6个月生活费 |
| 用途 | 失业/生病等应急 |
| 工具 | 货币基金/活期存款 |
| 特点 | 随存随取，安全第一 |

### 4.2 养老资金

| 项目 | 说明 |
|------|------|
| 开始时间 | 越早越好 |
| 目标 | 退休后维持生活 |
| 工具 | 社保+商业养老险+基金定投 |
| 原则 | 长期持有，复利增值 |

### 4.3 子女教育金

| 项目 | 说明 |
|------|------|
| 时间规划 | 大学费用倒推 |
| 工具 | 教育金保险+基金定投 |
| 特点 | 专款专用 |
| 注意 | 不要动用养老钱 |

### 4.4 梦想基金

| 项目 | 说明 |
|------|------|
| 用途 | 旅游/创业/学习等 |
| 金额 | 因人而异 |
| 工具 | 基金/理财 |
| 原则 | 闲钱投资 |
