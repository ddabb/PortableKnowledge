# 资产配置指南：标准普尔家庭资产配置

## 一、为什么要资产配置

资产配置 = 把钱分配到不同类型的资产中，降低风险、提高收益。

不是把钱全放银行，也不是全投股票。而是：银行存款 + 债券 + 股票 + 房产 + 保险 + 现金……

### 只做单一投资的风险

| 假如你 | 会出现什么问题？ |
|--------|-----------------|
| 全部存银行 | 跑不赢通胀，10年后购买力缩水30% |
| 全部买股票 | 股市暴跌50%，你可能血本无归 |
| 全部买房 | 流动性差，急需用钱时卖不掉 |
| 全买基金 | 没有应急备用金，一有急事只能割肉 |

**资产配置的核心：分散风险，让钱在不同方向增值。**

## 二、为什么不能只存银行

| 年份 | 一年期定存利率 | 通货膨胀率 | 实际收益率 |
|------|---------------|-----------|-----------|
| 2015年 | 2.5% | 1.6% | +0.9% |
| 2018年 | 1.5% | 2.1% | **-0.6%** |
| 2022年 | 1.65% | 2.0% | **-0.35%** |
| 2024年 | 1.45% | 约2.5% | **-1.05%** |

实际收益率 = 定存利率 - 通货膨胀率

**10年后100万变成多少钱？**

| 资产类型 | 年化收益 | 10年后 |
|----------|----------|--------|
| 银行定存 | 1.5% | 116万（名义） |
| 通货膨胀 | 2.5% | 78万购买力 |
| **实际损失** | - | **22万购买力缩水** |

## 三、标准普尔家庭资产配置图

全球公认的资产配置模型，把钱分成4份，各司其职：

```
标准普尔家庭资产配置图
├── 10% 要花的钱（短期消费）     → 现金、货币基金
├── 20% 保命的钱（保险保障）     → 重疾险、医疗险、意外险
├── 30% 生钱的钱（投资增值）     → 股票、基金、房产
└── 40% 保本的钱（稳健储蓄）     → 定期存款、债券、保险
```

| 类型 | 比例 | 用途 | 特点 |
|------|------|------|------|
| 日常消费（10%） | 应急备用 | 3-6个月生活费，流动性高 |
| 保险保障（20%） | 保命 | 应对意外、大病，转移大风险 |
| 投资增值（30%） | 生钱 | 高风险高收益，长期增值 |
| 稳健储蓄（40%） | 保本 | 低风险稳定收益，安全垫 |

## 四、不同人群的配置调整

标准普尔配置是基础模板，每个人情况不同需要微调：

| 人群 | 调整建议 |
|------|----------|
| 单身年轻人 | 提高投资比例至40%+，时间是你最大的优势 |
| 有房贷家庭 | 降低投资比例，增加保本比例，保证月供不断 |
| 临近退休 | 降低投资比例至20%以内，保本为主 |
| 高收入者 | 投资比例可提高，但保险也要配齐 |

### 经典法则：股票比例 = 100 - 年龄

- 25岁：股票75%，债券/现金25%
- 45岁：股票55%，债券/现金45%
- 65岁：股票35%，债券/现金65%

## 五、如何执行资产配置

### 第一步：评估现状

- 计算总资产（存款+股票+基金+房产+保险现金价值）
- 计算负债（房贷+车贷+其他贷款）
- 净资产 = 总资产 - 总负债

### 第二步：确定目标配置

- 根据年龄、收入、家庭情况确定比例
- 参考：标准普尔配置或"股票=100-年龄"法则

### 第三步：逐步调整

- 不要一次性大调整，分批执行
- 用新资金按目标配置买入
- 定期检视，每年调整一次

### 第四步：长期坚持

- 市场波动是常态，坚持计划
- 每季度检视配置比例
- 每年根据人生阶段微调

> 💡 资产配置最重要的不是找到最优比例，而是**长期坚持**。市场短期波动很正常，不要因为一两个月跌了就全盘推翻重来。
