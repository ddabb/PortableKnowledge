# 习得性无助

> "我做不到"往往不是能力问题，而是习得性无助

---

## 一、什么是习得性无助

习得性无助（Learned Helplessness）由美国心理学家马丁·塞利格曼于1967年提出。

**定义：** 个体在经历了反复的失败和挫折后，产生的一种对现实无望、放弃努力的心理状态。

**核心观点：** 无助感是"学来的"，不是天生的。当一个人发现自己的行为无法改变结果时，会学会"无助"。

---

## 二、经典实验

### 塞利格曼的电击实验

**第一阶段：分组电击**

| 组别 | 条件 | 反应 |
|------|------|------|
| A组 | 可以按开关停止电击 | 学会控制电击 |
| B组 | 无法控制电击 | 被动承受 |
| C组 | 无电击 | 正常状态 |

**第二阶段：穿梭箱测试**

所有狗被放入一个中间有隔板的箱子，电击时跳到另一边即可躲避。

**结果：**

| 组别 | 反应 |
|------|------|
| A组 | 很快学会跳到另一边躲避电击 |
| B组 | 躺在原地哀鸣，不尝试躲避 |
| C组 | 正常学习躲避 |

**解释：** B组的狗在第一阶段"学会"了自己的行为无法改变结果，因此在第二阶段即使可以躲避，也不会尝试。

## 三、习得性无助的表现

### 1. 三维度症状

塞利格曼提出习得性无助有三个维度：

| 维度 | 表现 |
|------|------|
| **普遍性** | "我在哪里都做不好" |
| **稳定性** | "我永远都做不好" |
| **内部性** | "是我自己的问题" |

### 2. 行为表现

| 表现 | 说明 |
|------|------|
| 放弃尝试 | 还没开始就认定会失败 |
| 拖延回避 | 害怕面对可能的失败 |
| 低成就感 | 即使成功也不认为是自己的能力 |
| 抑郁倾向 | 长期无助可能导致抑郁 |

### 3. 思维特点

- "反正也没用"
- "我就是不行"
- "努力也没意义"
- "这都是命"

## 四、习得性无助的形成

### 1. 形成条件

| 条件 | 说明 |
|------|------|
| 反复失败 | 多次努力都无法成功 |
| 结果不可控 | 行为与结果无关 |
| 归因错误 | 把失败归因于内部、稳定、普遍的因素 |

### 2. 常见场景

**教育场景：**

| 场景 | 形成过程 |
|------|----------|
| 数学学不好 | 多次考试失败 → 认为自己"不是学数学的料" → 放弃努力 |
| 被批评过多 | 总是被否定 → 认为自己"什么都不行" → 停止尝试 |

**职场场景：**

| 场景 | 形成过程 |
|------|----------|
| 提案总被否 | 多次提案不被采纳 → 认为提了也没用 → 不再提出建议 |
| 努力不被认可 | 加班工作无回报 → 认为努力无用 | 摸鱼混日子 |

**情感场景：**

| 场景 | 形成过程 |
|------|----------|
| 多次失恋 | 感情总是失败 → 认为自己"不值得被爱" → 不再尝试 |
| 被拒绝 | 表达需求总被忽视 → 学会不再表达 |

## 五、归因风格

塞利格曼发现，人们解释事件的方式决定了是否会产生习得性无助。

### 悲观归因 vs 乐观归因

| 事件 | 悲观归因 | 乐观归因 |
|------|----------|----------|
| 考试失败 | "我太笨了"（内部、稳定） | "这次题目太难"（外部、不稳定） |
| 工作出错 | "我总是这样"（稳定、普遍） | "只是这次疏忽"（不稳定、特定） |
| 感情失败 | "我不配被爱"（内部、稳定） | "我们不合适"（特定） |

**悲观归因的特点：**
- 内部归因："是我的问题"
- 稳定归因："一直都是这样"
- 普遍归因："所有事情都这样"

**乐观归因的特点：**
- 外部归因："是环境的原因"
- 不稳定归因："只是这一次"
- 特定归因："只是这件事"

## 六、如何克服习得性无助

### 1. 改变归因方式

**练习：**

| 原想法 | 新想法 |
|--------|--------|
| "我就是不行" | "我只是这次没做好" |
| "永远都这样" | "这只是暂时的困难" |
| "什么都做不好" | "这件事我还有其他方法可以尝试" |

### 2. 积累小成功

**步骤：**

1. 设定很小的目标
2. 确保能够完成
3. 逐步提高难度
4. 记录每一次成功

**示例：**

| 目标 | 难度 |
|------|------|
| 每天看1页书 | 极易完成 |
| 每天做1个俯卧撑 | 极易完成 |
| 每天写1句话 | 极易完成 |

**原理：** 小成功积累 → 重新建立"我能控制结果"的信念

### 3. 寻找可控因素

**问自己：**

- 这件事中，我能控制的是什么？
- 我可以做哪些微小的改变？
- 有哪些资源我可以利用？

**示例：**

| 不可控 | 可控 |
|--------|------|
| 别人的评价 | 自己的努力程度 |
| 考试题目 | 复习的范围 |
| 经济环境 | 自己的技能 |

### 4. 重构失败

**失败的积极意义：**

| 原看法 | 新看法 |
|--------|--------|
| 失败 = 我不行 | 失败 = 方法不对 |
| 失败 = 终点 | 失败 = 过程 |
| 失败 = 羞耻 | 失败 = 学习机会 |

### 5. 寻求支持

- 找到能提供正面反馈的人
- 加入支持性群体
- 必要时寻求专业帮助

## 七、习得性无助 vs 抑郁

| 对比项 | 习得性无助 | 抑郁症 |
|--------|------------|--------|
| 性质 | 心理状态 | 心理疾病 |
| 持续时间 | 可能短期 | 持续2周以上 |
| 影响范围 | 特定领域 | 广泛影响生活 |
| 治疗 | 认知调整、行为训练 | 可能需要药物+心理治疗 |

**注意：** 严重的习得性无助可能发展为抑郁症，如有需要请寻求专业帮助。

## 八、习得性无助的教育启示

### 对家长

| 做法不推荐 | 推荐做法 |
|------------|----------|
| 总批评，少表扬 | 关注进步，及时肯定 |
| 替孩子解决所有问题 | 让孩子体验成功 |
| 过高期望 | 设置可达成的目标 |
| 只看结果 | 肯定努力的过程 |

### 对教师

| 做法不推荐 | 推荐做法 |
|------------|----------|
| 公开排名羞辱 | 关注个体进步 |
| 贴标签"差生" | 发现每个学生的闪光点 |
| 题目太难没有阶梯 | 设置分层任务 |

## 九、习得性乐观

塞利格曼后来提出了"习得性乐观"的概念——乐观也是可以学会的。

### ABCDE法则

| 步骤 | 说明 | 示例 |
|------|------|------|
| A（Adversity） | 识别挫折 | 考试失败 |
| B（Belief） | 识别信念 | "我太笨了" |
| C（Consequence） | 识别后果 | 放弃学习 |
| D（Disputation） | 反驳消极信念 | "这次题目难，而且我复习不够" |
| E（Energization） | 激发积极行动 | "下次提前复习，找老师答疑" |

### 练习方法

1. 记录每天的消极事件
2. 写下自动产生的消极想法
3. 用证据反驳这些想法
4. 找出更合理的解释
5. 采取积极行动

## 十、总结

### 记住这几点

| 观点 | 说明 |
|------|------|
| 无助是学会的 | 既然能学会，就能改变 |
| 归因很重要 | 改变解释方式，改变结果 |
| 小成功有效 | 积累正向反馈，重建控制感 |
| 永远不晚 | 无论过去经历了什么，现在都可以重新开始 |

---

> 习得性无助告诉我们：放弃不是天生的，同样，希望和坚持也可以重新学会。
