## 一，自陈量表

### 1.1 原理

| 要点 | 说明 |
|------|------|
| 定义 | 被试自己报告自己的性格特点 |
| 形式 | 标准化问卷 |
| 优点 | 客观、可量化 |
| 局限 | 可能社会期许效应 |

### 1.2 常用量表

| 量表 | 全称 | 特点 |
|------|------|------|
| **MMPI** | 明尼苏达多项人格测验 | 562题，临床诊断 |
| **16PF** | 卡特尔16种人格因素 | 187题，因素分析 |
| **EPQ** | 艾森克人格问卷 | 成人/青少年版 |
| **大五人格量表** | NEO-PI-R | 开放性、尽责性、外向性、宜人性、神经质 |

### 1.3 MMPI详解

| 要点 | 说明 |
|------|------|
| 题数 | 566题（其中4题重复）|
| 效度量表 | L、F、K（测谎、伪装、修正）|
| 临床量表 | Hs、D、Hy、Pd、Mf、Pa、Pt、Sc、Ma、Si |
| 解释 | T分>70为异常 |

**效度量表：**
| 量表 | 说明 |
|------|------|
| L | 说谎分数，高分→不真实回答 |
| F | 伪装分数，高分→极端回答 |
| K | 修正分数，校正自我掩饰 |

### 1.4 社会期许效应

| 要点 | 说明 |
|------|------|
| 定义 | 被试按社会期望回答，而非真实情况 |
| 影响 | 使测量结果不准确 |
| 控制 | 使用强迫选择、效度量表 |

## 二，投射测验

### 2.1 原理

| 要点 | 说明 |
|------|------|
| 定义 | 无结构刺激→被试自由反应→推断人格 |
| 假设 | 对模糊刺激的反应反映内心世界 |
| 优点 | 避免社会期许效应 |
| 局限 | 主观性强、信效度低 |

### 2.2 主要投射测验

| 测验 | 刺激材料 | 评分 |
|------|----------|------|
| **罗夏墨迹** | 10张墨迹图 | 反应位置、内容、决定因素 |
| **TAT主题统觉** | 30张图片 | 故事主题、主角、情节 |
| **句子完成测验** | 未完成的句子 | 补全内容分析 |
| **画人测验** | 画人 | 图形特征分析 |

### 2.3 罗夏墨迹详解

| 内容 | 说明 |
|------|------|
| 刺激材料 | 5张黑白+5张彩色的对称墨迹 |
| 评分维度 | 反应位置、反应决定因素、内容、原创性 |
| 编码 | R（反应数）、W（整体反应）、D（局部反应）|

### 2.4 TAT详解

| 内容 | 说明 |
|------|------|
| 图片数 | 31张（含1张空白卡）|
| 施测 | 每次呈现1张，让被试讲1分钟故事 |
| 分析 | 主角、需求、结果、主题 |

## 三，行为观察与评价量表

### 3.1 行为观察法

| 要点 | 说明 |
|------|------|
| 定义 | 在自然或控制情境中观察行为 |
| 类型 | 自然观察、结构观察 |
| 优点 | 生态效度高 |
| 局限 | 费时、主观 |

### 3.2 评价量表

| 要点 | 说明 |
|------|------|
| 定义 | 由他人对被试人格打分 |
| 形式 | 5点或7点量表 |
| 优点 | 多视角、信息丰富 |
| 局限 | 评价者偏见 |

---

## 四，人格评估方法的比较

| 方法 | 客观性 | 信效度 | 优点 | 局限 |
|------|--------|--------|------|------|
| 自陈量表 | 高 | 中高 | 客观、省时 | 社会期许 |
| 投射测验 | 低 | 低-中 | 深度高 | 主观性 |
| 行为观察 | 中 | 中 | 生态效度高 | 费时 |
| 评价量表 | 中 | 中 | 多视角 | 偏见 |
