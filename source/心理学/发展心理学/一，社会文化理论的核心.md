## 一，社会文化理论的核心

### 1.1 基本观点

| 要点 | 说明 |
|------|------|
| 核心 | 认知发展是社会文化互动的产物 |
| 强调 | 社会互动在认知发展中的核心作用 |
| 与皮亚杰的区别 | 皮亚杰强调个体探索，维果茨基强调社会指导 |

### 1.2 关键概念

| 概念 | 说明 |
|------|------|
| 工具 | 认知工具（语言、符号系统）|
| 最近发展区 | 现有水平与潜在水平之间的区域 |
| 内化 | 社会互动→个体内部心理过程 |
| 脚手架 | 在最近发展区内提供临时支持 |
