## 三，脚手架（Scaffolding）

### 3.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 在ZPD内提供的临时性支持 |
| 特点 | 根据儿童表现动态调整 |
| 目标 | 逐渐撤除，使儿童独立完成任务 |

### 3.2 脚手架的特点

| 特点 | 说明 |
|------|------|
| 可调整 | 根据儿童表现增减支持 |
| 临时性 | 目的不是永久帮助 |
| 合作性 | 强调成人-儿童协作 |

### 3.3 脚手架的策略

| 策略 | 示例 |
|------|------|
| 示范 | 演示如何做 |
| 分解任务 | 将任务分成小步骤 |
| 提问引导 | 用问题引导思考 |
| 给予提示 | 在困难时提供线索 |
| 简化任务 | 降低任务难度 |
