## 一，依恋的定义

### 1.1 经典定义

| 要点 | 说明 |
|------|------|
| 定义 | 婴儿与主要照顾者之间形成的深层情感纽带 |
| Bowlby | 依恋是婴儿生存的本能需要 |
| 核心 | 安全感是依恋的核心 |

### 1.2 形成时期

| 时期 | 年龄 | 特点 |
|------|------|------|
| 前依恋期 | 0-6周 | 无差别反应 |
| 形成期 | 6周-6/8月 | 对熟悉的人反应更多 |
| 依恋明确期 | 6/8月-18/24月 | 明确依恋特定照顾者 |
| 目标纠正期 | 18/24月+ | 能理解照顾者会回来 |

## 二，Ainsworth陌生情境实验

### 2.1 实验程序

```
婴儿与母亲 → 加入陌生人 → 母亲离开 → 母亲回来
（观察婴儿反应）
```

### 2.2 三种依恋类型

| 类型 | 名称 | 比例 | 表现 |
|------|------|------|------|
| **A型** | 焦虑-回避型 | ~20% | 母亲在不在意，母亲走不在意 |
| **B型** | 安全型 | ~60% | 母亲在安心探索，母亲走会哭，回来后被安慰 |
| **C型** | 焦虑-抵抗型 | ~15% | 母亲在也焦虑，母亲走大哭，回来后也哭 |

### 2.3 三种类型详解

| 类型 | 内部工作模式 | 成人关系表现 |
|------|-------------|-------------|
| 安全型（A）| 别人靠不住 | 回避亲密 |
| 安全型（B）| 我值得被爱 | 健康亲密关系 |
| 焦虑-抵抗型（C）| 别人不可靠 | 过度依赖 |

## 三，依恋的形成机制

### 3.1 核心机制

| 机制 | 说明 |
|------|------|
| 敏感性 | 照顾者对婴儿信号的敏感性 |
| 反应性 | 照顾者及时、一致地回应 |
| 接触安慰 | 身体接触提供安全感 |

### 3.2 影响因素

| 因素 | 影响 |
|------|------|
| 照顾质量 | 敏感回应→安全依恋 |
| 母亲抑郁 | 抑郁→不安全依恋 |
| 分离 | 长期分离→不安全依恋 |
| 养育方式 | 一致性回应→安全依恋 |

## 四，依恋对后期发展的影响

### 4.1 对社会情绪发展

| 影响 | 说明 |
|------|------|
| 情绪调节 | 安全依恋→情绪调节更好 |
| 自我概念 | 安全依恋→更积极自我概念 |
| 同伴关系 | 安全依恋→更好的同伴关系 |

### 4.2 依恋的跨代传递

| 研究 | 发现 |
|------|------|
| van Ijzendoorn | 安全型母亲更可能有安全型婴儿 |
| 机制 | 内部工作模式影响养育行为 |
