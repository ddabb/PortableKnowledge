# 发展心理学

## 一、核心概念

### 1.1 核心机制

| 概念 | 定义 | 示例 |
|------|------|------|
| **图式** | 认知结构的基本单元 | "狗"的图式 |
| **同化** | 将新信息纳入已有图式 | 见到猫→"狗" |
| **顺应** | 改变图式以适应新信息 | 认识到猫≠狗 |
| **平衡** | 同化与顺应的平衡状态 | 不断追求平衡 |

### 1.2 平衡过程

```
平衡 → 不平衡（同化/顺应失效）→ 更高层次的平衡
```

## 二、最近发展区（ZPD）

### 2.1 定义

| 要点 | 说明 |
|------|------|
| 全称 | Zone of Proximal Development |
| 定义 | 儿童独立解决问题的水平与在成人指导下能解决问题的水平之间的距离 |
| 提出者 | 维果茨基 |

### 2.2 三个层次

```
最低点 → 独立解决问题的水平
   ↓
ZPD（最近发展区）
   ↓
最高点 → 在指导下能解决问题的水平
```

### 2.3 教学意义

| 意义 | 说明 |
|------|------|
| 教学要走在发展前面 | 在ZPD内教学最有效 |
| 因材施教 | 针对ZPD提供个性化指导 |
| 动态评估 | 评估儿童在帮助下的表现，而非仅独立表现 |

## 三、认知发展阶段

### 3.1 第一阶段：感觉运动期（0-2岁）

#### 3.1.1 时间与核心任务

| 要点 | 说明 |
|------|------|
| 时间 | 0-2岁 |
| 核心任务 | 建立客体永存 |

#### 3.1.2 六个亚阶段

| 亚阶段 | 年龄 | 特点 |
|--------|------|------|
| 反射练习 | 0-1月 | 吮吸、眨眼等先天反射 |
| 初级循环反应 | 1-4月 | 重复有利动作 |
| 二级循环反应 | 4-8月 | 重复有趣结果 |
| 二级图式协调 | 8-12月 | 有目的地协调动作 |
| 三级循环反应 | 12-18月 | 探索手段-目的关系 |
| 表象思维开始 | 18-24月 | 表象和语言出现 |

#### 3.1.3 关键成就：客体永存

| 要点 | 说明 |
|------|------|
| 定义 | 物体消失后仍然存在 |
| 实验 | Binet hiding toy实验 |
| 发展 | 8-12月逐渐发展 |
| 里程碑 | 9月前不会找，9月后会找 |

### 3.2 第二阶段：前运算期（2-7岁）

#### 3.2.1 时间与核心任务

| 要点 | 说明 |
|------|------|
| 时间 | 2-7岁 |
| 核心任务 | 语言和符号能力发展 |

#### 3.2.2 主要特点

| 特点 | 说明 | 示例 |
|------|------|------|
| 自我中心 | 无法从他人角度看问题 | 三山实验 |
| 中心化 | 只关注事物的一个方面 | 液体守恒实验 |
| 泛灵论 | 认为无生命物体有生命 | 给布娃娃盖被子 |
| 不可逆 | 无法理解可逆操作 | 2+3=5，但5-3=2困难 |

### 3.3 第三阶段：具体运算期（7-11岁）

#### 3.3.1 时间与核心任务

| 要点 | 说明 |
|------|------|
| 时间 | 7-11岁 |
| 核心任务 | 逻辑思维发展 |

#### 3.3.2 主要成就

| 成就 | 说明 | 示例 |
|------|------|------|
| 守恒能力 | 理解物质守恒 | 液体、数量、长度守恒 |
| 可逆性 | 理解可逆操作 | 2+3=5，5-3=2 |
| 去中心化 | 能考虑多个方面 | 同时考虑液体的高度和宽度 |
| 具体逻辑 | 能进行具体事物的逻辑推理 | 具体例子的推理 |

### 3.4 第四阶段：形式运算期（11岁+）

#### 3.4.1 时间与核心任务

| 要点 | 说明 |
|------|------|
| 时间 | 11岁以上 |
| 核心任务 | 抽象思维发展 |

#### 3.4.2 主要成就

| 成就 | 说明 | 示例 |
|------|------|------|
| 抽象思维 | 能思考抽象概念 | 思考正义、自由等概念 |
| 假设演绎推理 | 能提出假设并验证 | 科学实验中的假设检验 |
| 系统思维 | 能系统地解决问题 | 数学证明、逻辑推理 |
| 反思能力 | 能反思自己的思维过程 | 元认知能力 |

## 四、维果茨基 vs 皮亚杰

| 维度 | 维果茨基 | 皮亚杰 |
|------|----------|--------|
| 发展动力 | 社会文化因素 | 个体内部成熟 |
| 学习与发展 | 学习促进发展 | 发展先于学习 |
| 语言作用 | 语言是思维的工具 | 语言是思维的产物 |
| 教学建议 | 支架式教学 | 发现式学习 |
| 关注重点 | 社会互动 | 个体认知 |

## 五、高级心理机能

### 5.1 定义

高级心理机能是指人类特有的、由社会文化历史因素决定的心理能力，如语言、思维、记忆等。

### 5.2 特点

| 特点 | 说明 |
|------|------|
| 社会起源 | 起源于社会互动 |
| 中介性 | 通过符号系统（如语言）中介 |
| 内化过程 | 从外部活动内化为内部心理活动 |
| 有意识控制 | 受意识控制和调节 |

## 六、内化

### 6.1 定义

内化是指个体将外部的社会文化经验转化为内部心理结构的过程。

### 6.2 过程

| 阶段 | 说明 |
|------|------|
| 外部阶段 | 依赖他人的指导和帮助 |
| 半内化阶段 | 开始独立使用符号系统 |
| 完全内化阶段 | 符号系统成为内部思维工具 |

## 七、脚手架（Scaffolding）

### 7.1 定义

脚手架是指成人或更有能力的同伴为儿童提供的支持，帮助儿童完成他们当前无法独立完成的任务。

### 7.2 特点

| 特点 | 说明 |
|------|------|
| 动态调整 | 根据儿童的进展调整支持程度 |
| 逐渐撤去 | 随着儿童能力的发展逐渐减少支持 |
| 针对性 | 针对儿童的最近发展区提供支持 |
| 互动性 | 通过互动促进儿童的发展 |

## 八、相关概念：元认知与自我调节

### 8.1 元认知

| 概念 | 定义 | 组成 |
|------|------|------|
| 元认知 | 对自己认知过程的认知 | 元认知知识、元认知监控、元认知体验 |
| 元认知知识 | 关于自己认知能力的知识 | 个人、任务、策略知识 |
| 元认知监控 | 对认知过程的监控和调节 | 计划、监控、评估 |

### 8.2 自我调节

| 概念 | 定义 | 过程 |
|------|------|------|
| 自我调节 | 个体对自己行为和认知的调节 | 目标设定、自我监控、自我评估、自我强化 |

## 九、各阶段对比

| 阶段 | 年龄 | 核心任务 | 主要特点 |
|------|------|----------|----------|
| 感觉运动期 | 0-2岁 | 建立客体永存 | 感觉和动作探索 |
| 前运算期 | 2-7岁 | 语言和符号能力发展 | 自我中心、中心化 |
| 具体运算期 | 7-11岁 | 逻辑思维发展 | 守恒能力、可逆性 |
| 形式运算期 | 11岁+ | 抽象思维发展 | 抽象思维、假设演绎推理 |

## 十、总结

发展心理学是研究人类认知发展规律的重要学科，通过理解儿童认知发展的阶段和机制，我们可以：

- 更好地理解儿童的认知发展特点
- 为教育和教学提供科学依据
- 促进儿童的全面发展

希望本指南能够帮助你更好地理解发展心理学的核心概念和理论！
