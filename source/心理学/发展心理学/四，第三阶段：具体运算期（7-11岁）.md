## 四，第三阶段：具体运算期（7-11岁）

### 4.1 时间与核心特点

| 要点 | 说明 |
|------|------|
| 时间 | 7-11岁 |
| 核心 | 逻辑思维出现，但依赖具体事物 |

### 4.2 核心成就

| 成就 | 定义 |
|------|------|
| **去自我中心** | 能理解他人视角 |
| **守恒** | 理解数量不随外观变化 |
| **分类** | 能进行类包含推理 |
| **序列化** | 按某一维度排序 |
| **传递推理** | A>B, B>C → A>C |

### 4.3 去自我中心

| 要点 | 说明 |
|------|------|
| 定义 | 能从他人角度看待问题 |
| 与前运算的区别 | 前运算只能从自己视角 |
| 三山实验 | 7岁后能正确选择不同视角 |
