## 一，核心概念

### 1.1 核心机制

| 概念 | 定义 | 示例 |
|------|------|------|
| **图式** | 认知结构的基本单元 | "狗"的图式 |
| **同化** | 将新信息纳入已有图式 | 见到猫→"狗" |
| **顺应** | 改变图式以适应新信息 | 认识到猫≠狗 |
| **平衡** | 同化与顺应的平衡状态 | 不断追求平衡 |

### 1.2 平衡过程

```
平衡 → 不平衡（同化/顺应失效）→ 更高层次的平衡
```

## 二，第一阶段：感觉运动期（0-2岁）

### 2.1 时间与核心任务

| 要点 | 说明 |
|------|------|
| 时间 | 0-2岁 |
| 核心任务 | 建立客体永存 |

### 2.2 六个亚阶段

| 亚阶段 | 年龄 | 特点 |
|--------|------|------|
| 反射练习 | 0-1月 | 吮吸、眨眼等先天反射 |
| 初级循环反应 | 1-4月 | 重复有利动作 |
| 二级循环反应 | 4-8月 | 重复有趣结果 |
| 二级图式协调 | 8-12月 | 有目的地协调动作 |
| 三级循环反应 | 12-18月 | 探索手段-目的关系 |
| 表象思维开始 | 18-24月 | 表象和语言出现 |

### 2.3 关键成就：客体永存

| 要点 | 说明 |
|------|------|
| 定义 | 物体消失后仍然存在 |
| 实验 | Binet hiding toy实验 |
| 发展 | 8-12月逐渐发展 |
| 里程碑 | 9月前不会找，9月后会找 |

## 三，第二阶段：前运算期（2-7岁）

### 3.1 时间与核心特点

| 要点 | 说明 |
|------|------|
| 时间 | 2-7岁 |
| 核心 | 符号功能出现，但思维有局限 |

### 3.2 核心特点

| 特点 | 定义 | 实验 |
|------|------|------|
| **自我中心** | 无法区分自己与他人视角 | 三山实验 |
| **不可逆性** | 思维不能反向 | 3+4=7，7-3≠4 |
| **集中化** | 只注意一个维度 | 液体守恒失败 |
| ** 泛灵论** | 无生命物体有生命 | 太阳也会痛 |

### 3.3 三山实验（Piaget, 1929）

| 要点 | 说明 |
|------|------|
| 材料 | 三座山模型，不同颜色和特征 |
| 程序 | 让孩子从四个角度描述 |
| 结果 | 2-6岁孩子认为所有人都看到相同的视图 |
| 结论 | 幼儿自我中心 |

### 3.4 守恒实验

| 守恒类型 | 实验内容 | 前运算期表现 |
|----------|---------|-------------|
| 液体守恒 | 两杯等量水，一杯倒入更高更窄的杯子 | 认为水变多了 |
| 数量守恒 | 两排等量积木，一排间距更大 | 认为数量变了 |
| 长度守恒 | 两根等长绳子，一根弯曲 | 认为弯的短了 |

## 四，第三阶段：具体运算期（7-11岁）

### 4.1 时间与核心特点

| 要点 | 说明 |
|------|------|
| 时间 | 7-11岁 |
| 核心 | 逻辑思维出现，但依赖具体事物 |

### 4.2 核心成就

| 成就 | 定义 |
|------|------|
| **去自我中心** | 能理解他人视角 |
| **守恒** | 理解数量不随外观变化 |
| **分类** | 能进行类包含推理 |
| **序列化** | 按某一维度排序 |
| **传递推理** | A>B, B>C → A>C |

### 4.3 去自我中心

| 要点 | 说明 |
|------|------|
| 定义 | 能从他人角度看待问题 |
| 与前运算的区别 | 前运算只能从自己视角 |
| 三山实验 | 7岁后能正确选择不同视角 |

---

## 五，第四阶段：形式运算期（11岁+）

### 5.1 时间与核心特点

| 要点 | 说明 |
|------|------|
| 时间 | 11岁以后 |
| 核心 | 抽象逻辑思维 |

### 5.2 核心能力

| 能力 | 定义 | 示例 |
|------|------|------|
| **抽象思维** | 处理抽象概念 | 哲学问题讨论 |
| **假设-演绎推理** | 从假设推演结论 | 科学实验设计 |
| **系统性思维** | 多变量分析 | 排除法解决问题 |
| **反省思维** | 思考自己的思维过程 | 元认知 |

### 5.3 钟摆实验（Inhelder & Piaget）

| 要点 | 说明 |
|------|------|
| 材料 | 不同长度/重量的绳子，不同高度的挂钩 |
| 任务 | 找出什么决定钟摆速度 |
| 前运算表现 | 一次只能改变一个因素 |
| 形式运算 | 系统性改变多个因素 |

## 六，各阶段对比

| 阶段 | 年龄 | 核心特点 | 局限 |
|------|------|---------|------|
| 感觉运动 | 0-2岁 | 客体永存 | 无语言、表象 |
| 前运算 | 2-7岁 | 符号功能 | 自我中心、不可逆 |
| 具体运算 | 7-11岁 | 逻辑思维 | 依赖具体事物 |
| 形式运算 | 11+岁 | 抽象逻辑 | 无 |
