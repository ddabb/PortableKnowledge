## 一，核心概念

### 1.1 图式

| 要点 | 说明 |
|------|------|
| 定义 | 有组织的认知结构单元 |
| 来源 | 先天+后天经验 |
| 发展 | 通过经验不断丰富 |

### 1.2 同化与顺应

| 概念 | 定义 | 是否改变图式 |
|------|------|-------------|
| **同化** | 用现有图式解释新刺激 | 不改变 |
| **顺应** | 改变图式以适应新刺激 | 改变 |

### 1.3 平衡

平衡 = 同化与顺应之间的动态平衡

```
不平衡 → 同化/顺应 → 平衡 → 新的不平衡 → ...
```

## 二，四阶段论

### 2.1 感觉运动期（0-2岁）

| 阶段 | 年龄 | 核心成就 |
|------|------|---------|
| 反射阶段 | 0-1月 | 先天反射 |
| 初级循环反应 | 1-4月 | 重复自身动作 |
| 次级循环反应 | 4-8月 | 重复外部事件 |
| 协调性循环反应 | 8-12月 | 手段-目的协调 |
| 三级循环反应 | 12-18月 | 主动探索变化 |
| 表征开始 | 18-24月 | 延迟模仿 |

**核心成就：客体永存（9-12月）**
- 定义：物体从视野消失仍然存在
- 经典证据：B.B.追踪实验

### 2.2 前运算期（2-7岁）

| 特征 | 定义 | 示例/证据 |
|------|------|---------|
| 符号功能 | 用符号代表事物 | 语言、假装游戏 |
| 自我中心 | 不能理解他人视角 | 三山实验 |
| 泛灵论 | 认为无生命物也有生命 | 觉得石头会疼 |
| 不可逆性 | 不能反向思考 | 不理解"A的爸爸是B，B的爸爸是谁" |
| 集中化 | 只注意一个维度 | 不理解守恒 |

### 2.3 具体运算期（7-11岁）

| 特征 | 定义 | 证据 |
|------|------|------|
| 去自我中心 | 理解他人视角 | 能通过三山实验 |
| 守恒 | 量不随外形变化 | 水量不变即使杯子变了 |
| 分类 | 逻辑分类能力 | 能对事物分类 |
| 序列化 | 按顺序排列 | 按大小排列 |
| 具体逻辑 | 依赖具体事物推理 | 不能抽象推理 |

### 2.4 形式运算期（11岁+）

| 特征 | 说明 |
|------|------|
| 抽象思维 | 抽象概念推理 |
| 假设演绎推理 | 先假设再验证 |
| 命题思维 | 思考命题本身 |
| 系统思维 | 多变量分析 |

## 三，核心实验

### 3.1 三山实验

| 要点 | 说明 |
|------|------|
| 实验 | 从三个角度拍三山照片，让孩子从四方位描述 |
| 结果 | 前运算期儿童只描述自己看到的 |
| 结论 | 前运算期儿童自我中心 |

### 3.2 守恒实验

| 实验 | 说明 |
|------|------|
| 水量守恒 | 水倒入不同形状杯子，量不变 |
| 数量守恒 | 排列方式变了数量不变 |
| 长度守恒 | 排列方式变了长度不变 |
