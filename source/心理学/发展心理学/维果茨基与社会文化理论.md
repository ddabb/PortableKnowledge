## 一，社会文化理论的核心

### 1.1 基本观点

| 要点 | 说明 |
|------|------|
| 核心 | 认知发展是社会文化互动的产物 |
| 强调 | 社会互动在认知发展中的核心作用 |
| 与皮亚杰的区别 | 皮亚杰强调个体探索，维果茨基强调社会指导 |

### 1.2 关键概念

| 概念 | 说明 |
|------|------|
| 工具 | 认知工具（语言、符号系统）|
| 最近发展区 | 现有水平与潜在水平之间的区域 |
| 内化 | 社会互动→个体内部心理过程 |
| 脚手架 | 在最近发展区内提供临时支持 |

## 二，最近发展区（ZPD）

### 2.1 定义

| 要点 | 说明 |
|------|------|
| 全称 | Zone of Proximal Development |
| 定义 | 儿童独立解决问题的水平与在成人指导下能解决问题的水平之间的距离 |
| 提出者 | 维果茨基 |

### 2.2 三个层次

```
最低点 → 独立解决问题的水平
   ↓
ZPD（最近发展区）
   ↓
最高点 → 在指导下能解决问题的水平
```

### 2.3 教学意义

| 意义 | 说明 |
|------|------|
| 教学要走在发展前面 | 在ZPD内教学最有效 |
| 因材施教 | 针对ZPD提供个性化指导 |
| 动态评估 | 评估儿童在帮助下的表现，而非仅独立表现 |

## 三，脚手架（Scaffolding）

### 3.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 在ZPD内提供的临时性支持 |
| 特点 | 根据儿童表现动态调整 |
| 目标 | 逐渐撤除，使儿童独立完成任务 |

### 3.2 脚手架的特点

| 特点 | 说明 |
|------|------|
| 可调整 | 根据儿童表现增减支持 |
| 临时性 | 目的不是永久帮助 |
| 合作性 | 强调成人-儿童协作 |

### 3.3 脚手架的策略

| 策略 | 示例 |
|------|------|
| 示范 | 演示如何做 |
| 分解任务 | 将任务分成小步骤 |
| 提问引导 | 用问题引导思考 |
| 给予提示 | 在困难时提供线索 |
| 简化任务 | 降低任务难度 |

## 四，内化

### 4.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 社会互动过程转化为内部心理过程 |
| 过程 | 外部言语→内部言语→思维 |

### 4.2 自我言语（Private Speech）

| 要点 | 说明 |
|------|------|
| 定义 | 对自己说的言语 |
| 发展 | 外部言语→自言自语→内部言语 |
| 功能 | 引导和调节行为 |

## 五，高级心理机能

### 5.1 与低级心理机能的区别

| 对比 | 低级心理机能 | 高级心理机能 |
|------|-------------|-------------|
| 来源 | 生物成熟 | 社会文化 |
| 发展 | 自然发展 | 社会互动 |
| 控制 | 直接 | 间接（通过工具）|
| 例子 | 感觉、无意注意 | 有意注意、逻辑记忆 |

### 5.2 言语的中介作用

| 要点 | 说明 |
|------|------|
| 核心 | 言语是认知发展的核心工具 |
| 观点 | 思维即内化的言语 |

## 六，维果茨基 vs 皮亚杰

| 对比 | 维果茨基 | 皮亚杰 |
|------|---------|--------|
| 核心动力 | 社会互动 | 个体探索 |
| 发展阶段 | 连续，无明确阶段 | 有明确阶段 |
| 教学观 | 教学促进发展 | 发展先于教学 |
| 语言角色 | 语言是认知工具 | 语言是发展的结果 |
