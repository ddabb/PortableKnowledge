## 一，语言发展的阶段

### 1.1 时间线概览

| 阶段 | 年龄 | 典型表现 |
|------|------|---------|
| 前语言期 | 0-12月 | 咕咕声→咿呀学语 |
| 单词期 | 12-18月 | 说出第一批词 |
| 词汇爆发 | 18-24月 | 词汇快速增加 |
| 电报句期 | 18-24月 | 短句，无语法词 |
| 语法发展期 | 2-3岁+ | 语法规则掌握 |

## 二，前语言期

### 2.1 发展阶段

| 阶段 | 年龄 | 表现 |
|------|------|------|
| 反射性发声 | 0-2月 | 哭声 |
| 咕咕声 | 2-4月 | 元音"啊" |
| 咿呀学语 | 6-9月 | 重复音节"bababa" |
| 音韵调整 | 9-12月 | 发出的音与母语一致 |

### 2.2 前语言交流

| 能力 | 说明 |
|------|------|
| 共同注意 | 与照顾者关注同一事物 |
| 指向手势 | 用手指指向物体 |
| 意图理解 | 理解他人的意图 |

## 三，词汇发展

### 3.1 单词期

| 要点 | 说明 |
|------|------|
| 首次词 | 平均12-13个月 |
| 第一批词 | 通常10-50个词 |
| 类型 | 先名词→后动词→后形容词 |

### 3.2 词汇爆发

| 要点 | 说明 |
|------|------|
| 时间 | 18个月左右 |
| 速度 | 每周约9个新词 |
| 特点 | 词汇量从约50→200+词 |
| 原因 | 命名爆炸、统计学习 |

### 3.3 词汇学习策略

| 策略 | 说明 |
|------|------|
| 快速映射 | 听一次就学会 |
| 约束理论 | 假设→验证→调整 |
| 社会性学习 | 通过互动学习词义 |

## 四，语法发展

### 4.1 电报句

| 要点 | 说明 |
|------|------|
| 时间 | 18-24月 |
| 特点 | 短句，只有实词，缺少功能词 |
| 例子 | "妈妈糖糖"（妈妈给我糖）|

### 4.2 语法规则掌握

| 年龄 | 表现 |
|------|------|
| 2-2.5岁 | 双词句，出现"我的""你的" |
| 2.5-3岁 | 三词句，语序基本正确 |
| 3-4岁 | 语法基本正确 |
| 4-5岁 | 复杂句，会用连词 |
| 5岁+ | 接近成人水平 |

### 4.3 语法发展的错误

| 错误类型 | 示例 | 说明 |
|----------|------|------|
| 过度规则化 | "goed"代替"went" | 将规则过度应用 |
| 规则例外 | "break-broke" | 规则之外的不规则动词 |

## 六，影响语言发展的因素

| 因素 | 说明 |
|------|------|
| 遗传 | 特定语言能力有遗传基础 |
| 词汇量 | 词汇多→语法更好 |
| 照顾者语言输入 | 回应性语言→更好的语言发展 |
| 社会经济地位 | SES与语言发展相关 |
| 双语 | 双语可能延迟但不影响最终水平 |
