## 一、观察法

### 1.1 定义

在自然情境中对人的行为进行系统观察和记录的心理学研究方法

### 1.2 类型

| 类型 | 说明 |
|------|------|
| 自然观察 | 在自然情境中观察 |
| 控制观察 | 在实验室观察 |
| 参与观察 | 观察者参与其中 |
| 非参与观察 | 观察者不参与 |

### 1.3 优缺点

| 优点 | 缺点 |
|------|------|
| 真实自然 | 被动观察 |
| 适用范围广 | 难以重复 |
| 不干扰被试 | 观察者偏差 |

### 1.4 注意事项

- 观察前制定观察计划
- 观察记录要客观、及时
- 尽量减少观察者效应
