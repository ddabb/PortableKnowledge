## 三、调查法

### 3.1 定义

通过问卷或访谈收集大量被试自我报告数据的心理学研究方法

### 3.2 问卷调查

| 要素 | 说明 |
|------|------|
| 问卷结构 | 标题、前言、问题、结束语 |
| 问题类型 | 选择题、量表题、开放题 |
| 设计原则 | 清晰、具体、不暗示 |

### 3.3 访谈法

| 类型 | 说明 |
|------|------|
| 结构化访谈 | 按预设问卷提问 |
| 半结构化访谈 | 有大纲但可灵活调整 |
| 非结构化访谈 | 自由聊天式 |

### 3.4 优缺点

| 优点 | 缺点 |
|------|------|
| 方便快捷 | 样本偏差 |
| 可收集大量数据 | 社会期许效应 |
| 成本低 | 无法验证因果 |
