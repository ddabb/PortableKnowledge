## 三、韦伯定律

### 3.1 公式

```
K = ΔI / I

I = 原刺激量
ΔI = 差别阈限
K = 韦伯分数（常数）
```

### 3.2 韦伯分数

| 感觉道 | 韦伯分数（K）|
|---------|---------------|
| 重量 | 1/30 |
| 视觉 | 1/60 |
| 长度 | 1/100 |
| 音高 | 1/333 |

### 3.3 练习题

**例：重量100g，韦伯分数1/30，差别阈限是多少？**

```
ΔI = K × I = (1/30) × 100g = 3.33g
答案：需要增加3.33g才能感觉重量变化
```
