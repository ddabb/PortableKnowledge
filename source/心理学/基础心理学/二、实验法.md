## 二、实验法

### 2.1 定义

有目的地操纵自变量、控制无关变量、观测因变量的心理学研究方法

**核心：** 可验证因果关系

### 2.2 变量的类型

| 变量 | 定义 | 示例 |
|------|------|------|
| **自变量** | 研究者操纵的变量 | 光照强度 |
| **因变量** | 被测量的行为反应 | 正确率 |
| **控制变量** | 需要保持恒定的变量 | 室温 |
| **额外变量** | 可能干扰结果的变量 | 噪音 |

### 2.3 实验设计类型

| 设计 | 说明 | 优缺点 |
|------|------|--------|
| **被试内设计** | 同一组被试接受所有实验条件 | 节省人数，但有顺序效应 |
| **被试间设计** | 不同组被试接受不同条件 | 无顺序效应，但需人多 |

### 2.4 内部效度威胁

| 威胁 | 说明 |
|------|------|
| 历史 | 实验期间发生其他事件 |
| 成熟 | 被试身心发生变化 |
| 测试效应 | 前测影响后测 |
| 工具偏差 | 测量工具变化 |
| 统计回归 | 极端分数向平均回归 |
| 选择偏差 | 被试分组不随机 |
| 流失 | 被试中途退出 |

### 2.5 外部效度

| 类型 | 说明 |
|------|------|
| 生态效度 | 结果能否推广到现实情境 |
| 总体效度 | 结果能否推广到其他被试 |
