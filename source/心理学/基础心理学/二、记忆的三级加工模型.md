## 二、记忆的三级加工模型

### 2.1 三级记忆对比

| 类型 | 容量 | 时间 | 编码方式 |
|------|------|------|----------|
| 感觉记忆 | 大 | <1秒 | 图像/声像编码 |
| 短时记忆 | 7±2组块 | 1分钟内 | 听觉编码为主 |
| 长时记忆 | 无限 | 1分钟到终身 | 语义编码为主 |

### 2.2 感觉记忆

| 特点 | 说明 |
|------|------|
| 容量 | 很大 |
| 时间 | 0.25-2秒 |
| 编码 | 图像记忆（图像）、声像记忆（声音）|

### 2.3 短时记忆

| 特点 | 说明 |
|------|------|
| 容量 | 7±2个组块 |
| 时间 | 1分钟内 |
| 编码 | 听觉编码为主 |
| 复述 | 维持性复述→精细复述 |

**组块：** 将孤立信息组合成有意义单元
例：CSB → C-S-B → "CSB"（3个变1个组块）

### 2.4 长时记忆

| 类型 | 定义 |
|------|------|
| 陈述性记忆 | 能说出来（知识）|
| 程序性记忆 | 会做不会说（技能）|
| 情景记忆 | 个人经历 |
| 语义记忆 | 概念事实 |
