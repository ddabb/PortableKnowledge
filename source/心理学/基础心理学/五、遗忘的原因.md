## 五、遗忘的原因

### 5.1 消退说

| 内容 | 说明 |
|------|------|
| 理论 | 记忆痕迹随时间衰退 |
| 代表 | 桑代克 |
| 证据 | 不复习会遗忘 |

### 5.2 干扰说

| 类型 | 定义 | 示例 |
|------|------|------|
| 前摄抑制 | 先学材料干扰后学 | 学英语后学法语更难 |
| 倒摄抑制 | 后学材料干扰先学 | 学法语后回忆英语更难 |

### 5.3 压抑说（动机说）

| 内容 | 说明 |
|------|------|
| 理论 | 因痛苦情绪而遗忘 |
| 代表 | 弗洛伊德 |
| 证据 | 创伤事件的遗忘 |

### 5.4 提取失败说

| 内容 | 说明 |
|------|------|
| 理论 | 记忆存在但提取线索不足 |
| 代表 | Tulving |
| 证据 | 舌尖效应（话到嘴边说不出）|
