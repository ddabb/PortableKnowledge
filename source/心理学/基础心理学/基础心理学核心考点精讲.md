## 第一部分：心理学的研究对象

### 1.1 心理学的定义

心理学 = 研究人的心理现象及其发生、发展规律的科学

**心理现象包括：**
| 心理过程 | 心理结构 |
|---------|---------|
| 认知过程（感觉、知觉、记忆、思维）| 个性倾向性（需要、动机、兴趣、信念）|
| 情绪情感过程 | 个性心理特征（能力、气质、性格）|
| 意志过程 | |

### 1.2 心理学的研究任务

| 任务 | 说明 |
|------|------|
| 描述心理现象 | 是什么 |
| 解释心理现象 | 为什么 |
| 预测心理现象 | 将怎样 |
| 控制心理现象 | 如何改变 |

### 1.3 心理学的研究方法

| 方法 | 特点 | 优点 | 缺点 |
|------|------|------|------|
| **观察法** | 自然状态下观察行为 | 真实、自然 | 被动、难以重复 |
| **实验法** | 操纵变量，控变量 | 可重复、可验证因果 | 人为情境 |
| **调查法** | 问卷/访谈收集数据 | 量大、方便 | 样本偏差 |
| **测验法** | 用标准化量表测量 | 客观、可比 | 受工具限制 |
| **个案法** | 对单个案例深入研究 | 深入 | 代表性差 |

### 1.4 实验法的变量

| 变量类型 | 说明 | 示例 |
|---------|------|------|
| **自变量** | 研究者操纵的变量 | 灯光亮度 |
| **因变量** | 被测量的反应 | 反应时 |
| **控制变量** | 需保持恒定的变量 | 室温 |
| **额外变量** | 影响结果的干扰因素 | 噪音 |

**实验设计类型：**
- 被试内设计：同一组被试接受所有条件
- 被试间设计：不同组被试接受不同条件

## 第二部分：感知觉

### 2.1 感觉概述

**感觉的定义：** 人脑对直接作用于感觉器官的客观事物个别属性的反映

**感觉的种类：**

| 类型 | 外部感觉 | 内部感觉 |
|------|---------|---------|
| 视觉 | 颜色、明度 | - |
| 听觉 | 声音 | - |
| 嗅觉 | 气味 | - |
| 味觉 | 味道 | - |
| 肤觉 | 触压温痛 | - |
| 运动觉 | - | 身体运动 |
| 平衡觉 | - | 平衡 |
| 机体觉 | - | 内脏感觉 |

### 2.2 感觉的基本规律

| 规律 | 定义 | 示例 |
|------|------|------|
| **感受性** | 感官对刺激的敏感程度 | 盲人听觉灵敏 |
| **感觉阈限** | 引起感觉的刺激量 | 刚能听到的声音 |
| **绝对阈限** | 刚能引起感觉的最小刺激量 | 安静中听到脚步声 |
| **差别阈限** | 刚能引起差别感觉的最小变化量 | 100g+3g才感觉变重 |

**韦伯定律：**
```
K = ΔI / I

K为韦伯常数
I为原刺激量
ΔI为差别阈限

例：重量韦伯常数0.03，100g物体需3g变化才感知
```

### 2.3 视觉

| 要素 | 内容 |
|------|------|
| 视觉基本单位 | 视紫红质 |
| 视觉感受器 | 棒体细胞（暗光）、锥体细胞（亮光/颜色）|
| 视觉理论 | Young-Helmholtz三原色说、Hering对立过程说 |
| 颜色混合 | 加色法（光）、减色法（颜料）|

**视敏度：** 分辨细小物体的能力

### 2.4 知觉概述

**知觉的定义：** 人脑对直接作用于感觉器官的客观事物整体属性的反映

**知觉的基本特征：**

| 特征 | 定义 | 示例 |
|------|------|------|
| 选择性 | 有选择地加工刺激 | 鸡尾酒会效应 |
| 理解性 | 用已有知识经验理解 | 看云像动物 |
| 整体性 | 整体优先于部分 | 整体先于局部 |
| 恒常性 | 条件变化时知觉稳定 | 门开关时仍知觉为矩形 |

### 2.5 知觉的种类

| 类型 | 定义 | 示例 |
|------|------|------|
| 空间知觉 | 物体的大小、形状、方位 | 远近、深浅 |
| 时间知觉 | 事件持续性、顺序性 | 快慢、先后 |
| 运动知觉 | 物体在空间的位移 | 运动速度 |
| 错觉 | 不正确的知觉 | 月亮错觉 |

## 第三部分：注意

### 3.1 注意的定义

注意 = 心理活动对一定对象的指向和集中

**注意的功能：**
| 功能 | 说明 |
|------|------|
| 选择功能 | 选择有意义刺激 |
| 维持功能 | 保持觉醒状态 |
| 调节功能 | 监督控制活动 |

### 3.2 注意的分类

| 类型 | 定义 | 示例 |
|------|------|------|
| **无意注意** | 无预定目的，不需意志努力 | 突然的巨响 |
| **有意注意** | 有预定目的，需要意志努力 | 听课 |
| **有意后注意** | 有目的但不需要意志努力 | 熟练后的工作 |

### 3.3 注意的品质

| 品质 | 定义 | 训练方法 |
|------|------|---------|
| **注意广度** | 一瞬间把握对象的数量 | 速读训练 |
| **注意稳定性** | 保持在同一对象的时间 | 抗干扰训练 |
| **注意分配** | 同时进行多种活动 | 双任务训练 |
| **注意转移** | 从一对象转向另一对象 | 灵活切换 |

### 3.4 注意的生理机制

| 机制 | 说明 |
|------|------|
| 朝向反射 | 新异刺激引起的反射 |
| 脑干网状结构 | 维持觉醒状态 |
| 边缘系统 | 情绪性注意 |
| 大脑皮层 | 选择性注意 |

## 第四部分：记忆

### 4.1 记忆的定义

记忆 = 过去经验在人脑中的反映

**记忆过程：**
```
编码 → 存储 → 提取
```

### 4.2 记忆的分类

| 分类标准 | 类型 | 说明 |
|---------|------|------|
| **按内容** | 形象记忆 | 事物的具体形象 |
| | 情景记忆 | 个人经历 |
| | 语义记忆 | 概念、事实 |
| | 情绪记忆 | 体验过的情绪 |
| **按时间** | 感觉记忆 | 0.25-2秒 |
| | 短时记忆 | 1分钟内，7±2组块 |
| | 长时记忆 | 1分钟以上，终身 |

### 4.3 遗忘规律

**遗忘曲线（艾宾浩斯）：**

| 时间 | 遗忘率 |
|------|--------|
| 20分钟 | 42% |
| 1小时 | 56% |
| 1天 | 74% |
| 6天 | 67% |
| 1个月 | 79% |

**遗忘规律：**
- 先快后慢
- 不均衡
- 干扰抑制（前摄/倒摄）

### 4.4 遗忘的原因

| 理论 | 说明 |
|------|------|
| 消退说 | 记忆痕迹衰退 |
| 干扰说 | 其他信息干扰 |
| 动机说 | 压抑理论 |
| 提取失败说 | 线索不足 |

## 第五部分：思维

### 5.1 思维概述

**思维的定义：** 人脑对客观事物的本质属性和规律的间接、概括的反映

**思维的特征：**
- 间接性：通过已知推断未知
- 概括性：归纳共同本质特征

### 5.2 思维的种类

| 类型 | 定义 | 示例 |
|------|------|------|
| 动作思维 | 伴随动作 | 修机器 |
| 形象思维 | 借助表象 | 画画 |
| 抽象思维 | 概念推理 | 数学证明 |

| 类型 | 定义 | 示例 |
|------|------|------|
| 聚合思维 | 收敛到一个答案 | 解答数学题 |
| 发散思维 | 多方向求答案 | 头脑风暴 |

### 5.3 思维的过程

| 过程 | 说明 |
|------|------|
| 分析 | 整体分解为部分 |
| 综合 | 部分结合为整体 |
| 比较 | 找异同点 |
| 抽象 | 抽共同本质 |
| 概括 | 归为一般 |

### 5.4 问题解决

| 策略 | 说明 |
|------|------|
| 算法策略 | 尝试所有可能 |
| 启发法 | 经验法则 |
| - 手段目的分析 | 缩小差距 |
| - 逆推法 | 从目标倒推 |
| - 类比迁移 | 用类似经验 |

**影响问题解决的因素：**

| 促进因素 | 阻碍因素 |
|---------|---------|
| 迁移 | 定势 |
| 知识经验 | 功能固着 |
| 原型启发 | 情绪 |
| 问题情境 | 动机过强/过弱 |
