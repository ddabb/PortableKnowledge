## 一、观察法

### 1.1 定义

在自然情境中对人的行为进行系统观察和记录的心理学研究方法

### 1.2 类型

| 类型 | 说明 |
|------|------|
| 自然观察 | 在自然情境中观察 |
| 控制观察 | 在实验室观察 |
| 参与观察 | 观察者参与其中 |
| 非参与观察 | 观察者不参与 |

### 1.3 优缺点

| 优点 | 缺点 |
|------|------|
| 真实自然 | 被动观察 |
| 适用范围广 | 难以重复 |
| 不干扰被试 | 观察者偏差 |

### 1.4 注意事项

- 观察前制定观察计划
- 观察记录要客观、及时
- 尽量减少观察者效应

## 二、实验法

### 2.1 定义

有目的地操纵自变量、控制无关变量、观测因变量的心理学研究方法

**核心：** 可验证因果关系

### 2.2 变量的类型

| 变量 | 定义 | 示例 |
|------|------|------|
| **自变量** | 研究者操纵的变量 | 光照强度 |
| **因变量** | 被测量的行为反应 | 正确率 |
| **控制变量** | 需要保持恒定的变量 | 室温 |
| **额外变量** | 可能干扰结果的变量 | 噪音 |

### 2.3 实验设计类型

| 设计 | 说明 | 优缺点 |
|------|------|--------|
| **被试内设计** | 同一组被试接受所有实验条件 | 节省人数，但有顺序效应 |
| **被试间设计** | 不同组被试接受不同条件 | 无顺序效应，但需人多 |

### 2.4 内部效度威胁

| 威胁 | 说明 |
|------|------|
| 历史 | 实验期间发生其他事件 |
| 成熟 | 被试身心发生变化 |
| 测试效应 | 前测影响后测 |
| 工具偏差 | 测量工具变化 |
| 统计回归 | 极端分数向平均回归 |
| 选择偏差 | 被试分组不随机 |
| 流失 | 被试中途退出 |

### 2.5 外部效度

| 类型 | 说明 |
|------|------|
| 生态效度 | 结果能否推广到现实情境 |
| 总体效度 | 结果能否推广到其他被试 |

## 三、调查法

### 3.1 定义

通过问卷或访谈收集大量被试自我报告数据的心理学研究方法

### 3.2 问卷调查

| 要素 | 说明 |
|------|------|
| 问卷结构 | 标题、前言、问题、结束语 |
| 问题类型 | 选择题、量表题、开放题 |
| 设计原则 | 清晰、具体、不暗示 |

### 3.3 访谈法

| 类型 | 说明 |
|------|------|
| 结构化访谈 | 按预设问卷提问 |
| 半结构化访谈 | 有大纲但可灵活调整 |
| 非结构化访谈 | 自由聊天式 |

### 3.4 优缺点

| 优点 | 缺点 |
|------|------|
| 方便快捷 | 样本偏差 |
| 可收集大量数据 | 社会期许效应 |
| 成本低 | 无法验证因果 |

## 四、测验法

### 4.1 定义

用标准化工具对人的心理特质进行定量描述的方法

### 4.2 标准化

| 要素 | 说明 |
|------|------|
| 标准化施测 | 统一指导语、时间 |
| 标准化评分 | 统一评分标准 |
| 标准化解释 | 以常模为参照 |

### 4.3 信度与效度

| 概念 | 定义 |
|------|------|
| 信度 | 测量结果的稳定性 |
| 效度 | 测量结果的准确性 |

（详见心理测量专题）

## 五、个案法

### 5.1 定义

对单个被试进行深入、详尽研究的方法

### 5.2 优缺点

| 优点 | 缺点 |
|------|------|
| 深入详尽 | 代表性差 |
| 发现新现象 | 难以推广 |
| 适合稀有案例 | 研究者偏差 |

## 六、研究方法的选择

| 方法 | 适合研究 | 适合问题 |
|------|----------|----------|
| 观察法 | 自然行为 | 描述现象 |
| 实验法 | 因果关系 | 验证假设 |
| 调查法 | 大样本 | 描述和预测 |
| 测验法 | 心理特质 | 评估个体差异 |
| 个案法 | 稀有情况 | 深入探索 |
