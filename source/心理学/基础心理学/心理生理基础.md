## 一，神经元

### 1.1 基本结构

| 结构 | 功能 |
|------|------|
| 细胞体 | 维持神经元代谢 |
| 树突 | 接收其他神经元的信号 |
| 轴突 | 传递神经冲动到其他神经元 |
| 轴突末梢 | 与下一神经元形成突触 |

### 1.2 信息传递

| 过程 | 说明 |
|------|------|
| 电传导 | 沿轴突传递（动作电位）|
| 化学传递 | 突触处释放神经递质 |

### 1.3 主要神经递质

| 递质 | 功能 |
|------|------|
| 多巴胺 | 奖赏、运动 |
| 血清素 | 情绪、睡眠 |
| 去甲肾上腺素 | 警觉、应激 |
| 乙酰胆碱 | 记忆、学习 |
| GABA | 抑制焦虑 |
| 内啡肽 | 镇痛、愉悦 |

## 二，神经系统

### 2.1 分类

```
神经系统
├── 中枢神经系统
│   ├── 脑
│   │   ├── 大脑（皮层）
│   │   ├── 间脑
│   │   ├── 脑干
│   │   └── 小脑
│   └── 脊髓
└── 周围神经系统
    ├── 躯体神经
    └── 自主神经（植物神经）
        ├── 交感神经（兴奋）
        └── 副交感神经（抑制）
```

## 三，大脑皮层功能区

### 3.1 四个脑叶

| 脑叶 | 主要功能 |
|------|----------|
| **额叶** | 运动、计划、执行、言语（Broca区）|
| **顶叶** | 感觉加工、空间认知、触觉 |
| **颞叶** | 听觉、言语理解（Wernicke区）、记忆 |
| **枕叶** | 视觉加工 |

### 3.2 重要功能区

| 区域 | 位置 | 功能 |
|------|------|------|
| 布洛卡区 | 左额叶 | 言语产生 |
| 韦尼克区 | 左颞叶 | 言语理解 |
| 听觉皮层 | 颞叶 | 听觉加工 |
| 视觉皮层 | 枕叶 | 视觉加工 |
| 运动皮层 | 中央前回 | 身体运动 |
| 感觉皮层 | 中央后回 | 身体感觉 |

### 3.3 割裂脑研究（Sperry）

| 发现 | 说明 |
|------|------|
| 左右半球功能分工 | 左语言，右空间 |
| 半球各自独立 | 割裂后仍能工作 |
| 连合部功能 | 胼胝体连接两侧 |

## 四，内分泌系统

### 4.1 主要腺体

| 腺体 | 激素 | 功能 |
|------|------|------|
| 垂体 | 生长激素等 | 调节其他腺体 |
| 甲状腺 | 甲状腺素 | 代谢调节 |
| 肾上腺 | 皮质醇、肾上腺素 | 应激反应 |
| 胰腺 | 胰岛素、胰高血糖素 | 血糖调节 |
| 性腺 | 雌激素、睾酮 | 性别特征 |

### 4.2 HPA轴（应激系统）

```
下丘脑 → 垂体 → 肾上腺 → 皮质醇
```
