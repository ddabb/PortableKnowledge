# 感觉与知觉心理学

## 一、感觉概述

### 1.1 定义

感觉 = 人脑对直接作用于感觉器官的客观事物个别属性的反映

### 1.2 感觉的种类

| 外部感觉 | 内部感觉 |
|---------|----------|
| 视觉 | 运动觉 |
| 听觉 | 平衡觉 |
| 嗅觉 | 机体觉 |
| 味觉 | |
| 肤觉 | |

## 二、感受性与感觉阈限

### 2.1 基本概念

| 概念 | 定义 | 关系 |
|------|------|------|
| **感受性** | 感官对刺激的敏感程度 | E |
| **感觉阈限** | 引起感觉的刺激量 | S |

**关系：感受性越高，感觉阈限越低**

### 2.2 绝对阈限

| 概念 | 定义 |
|------|------|
| **绝对阈限** | 刚能引起感觉的最小刺激量 |
| **下阈** | 刚能引起感觉的最小刺激 |
| **上阈** | 刚能引起感觉的最大刺激 |

### 2.3 差别阈限

| 概念 | 定义 |
|------|------|
| **差别阈限（ΔI）** | 刚能引起差别感觉的最小刺激变化量 |
| **韦伯分数（K）** | ΔI/I为常数 |

## 三、韦伯定律

### 3.1 公式

```
K = ΔI / I

I = 原刺激量
ΔI = 差别阈限
K = 韦伯分数（常数）
```

### 3.2 韦伯分数

| 感觉道 | 韦伯分数（K）|
|---------|---------------|
| 重量 | 1/30 |
| 视觉 | 1/60 |
| 长度 | 1/100 |
| 音高 | 1/333 |

### 3.3 练习题

**例：重量100g，韦伯分数1/30，差别阈限是多少？**

```
ΔI = K × I = (1/30) × 100g = 3.33g
答案：需要增加3.33g才能感觉重量变化
```

## 四、费希纳定律（对数定律）

### 4.1 公式

```
S = K × log(I)

S = 心理量（感觉强度）
I = 刺激量
K = 常数
```

### 4.2 意义

- 心理强度与刺激强度的对数成正比
- 刺激强度成倍增加，心理量才成比例增加

## 五、知觉概述

### 5.1 定义

知觉 = 人脑对直接作用于感觉器官的客观事物整体属性的反映

### 5.2 感觉 vs 知觉

| 对比 | 感觉 | 知觉 |
|------|------|------|
| 对象 | 个别属性 | 整体属性 |
| 加工 | 单一感官 | 多种感官整合 |
| 经验作用 | 依赖性小 | 依赖经验 |

## 六、知觉的四大特性

### 6.1 选择性

| 要点 | 说明 |
|------|------|
| 定义 | 有选择地把某些刺激作为知觉对象 |
| 机制 | 对象清晰，背景模糊 |
| 经典实验 | 图形-背景关系 |

**应用：广告设计、重点标注**

### 6.2 理解性

| 要点 | 说明 |
|------|------|
| 定义 | 用已有知识经验理解知觉对象 |
| 机制 | 言语指导、思维参与 |
| 表现 | 理解速度不同、理解深度不同 |

**应用：经验丰富的医生更能发现问题**

### 6.3 整体性

| 要点 | 说明 |
|------|------|
| 定义 | 整体先于部分被知觉 |
| 机制 | 整体制约部分的知觉 |
| 表现 | 部分服从整体，整体不等于部分之和 |

**应用：品牌设计中整体形象的统一**

### 6.4 恒常性

| 类型 | 定义 | 示例 |
|------|------|------|
| 大小恒常 | 距离变化时仍知觉为同样大小 | 远处的成年人看起来小但仍知觉为成年人 |
| 形状恒常 | 观察角度变化仍知觉为原形 | 门开着看是长方形但仍知觉为矩形 |
| 颜色恒常 | 光照变化时仍知觉为原色 | 白纸在黄光下仍知觉为白色 |
| 明度恒常 | 光照变化时明度不变 | 煤炭在强光下仍知觉为黑 |

## 七、知觉的种类

| 种类 | 定义 | 特点 |
|------|------|------|
| **空间知觉** | 对物体空间特性的知觉 | 形状、大小、距离、方位 |
| **时间知觉** | 对客观现象延续性和顺序性的知觉 | 时间估计、时间分辨 |
| **运动知觉** | 对物体空间位移的知觉 | 真动知觉、似动知觉 |
| **错觉** | 对客观事物的歪曲知觉 | 常见的有大小错觉、形状错觉、方向错觉等 |

## 八、感觉与知觉的应用

### 8.1 在教育中的应用

- 利用感觉和知觉的规律优化教学环境
- 根据学生的感知特点设计教学方法
- 培养学生的观察力和感知能力

### 8.2 在设计中的应用

- 利用知觉的选择性设计广告和界面
- 利用知觉的整体性设计品牌标识
- 利用知觉的恒常性设计产品包装

### 8.3 在生活中的应用

- 了解感觉阈限，合理调整环境刺激
- 利用知觉的理解性，提高学习和工作效率
- 认识错觉，避免被误导

## 九、总结

感觉与知觉是人类认识世界的基础，通过理解它们的机制和规律，我们可以：

- 更好地理解人类的认知过程
- 优化学习和工作环境
- 提高设计和沟通的效果
- 避免感知错误和错觉的影响
