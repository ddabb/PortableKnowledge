## 一、注意的定义

注意 = 心理活动对一定对象的指向和集中

**注意的功能：**
| 功能 | 说明 |
|------|------|
| 选择功能 | 选择有意义刺激 |
| 维持功能 | 保持觉醒状态 |
| 调节功能 | 监督控制活动 |

---

## 二、注意的分类

### 2.1 无意注意

| 要点 | 说明 |
|------|------|
| 定义 | 无预定目的，不需要意志努力 |
| 产生条件 | 刺激本身特点 |
| 示例 | 突然的巨响 |

**引起无意注意的条件：**
| 条件 | 说明 |
|------|------|
| 刺激强度 | 强烈刺激 |
| 刺激新异性 | 新奇事物 |
| 刺激对比 | 差异大 |
| 刺激变化 | 不断变化 |

### 2.2 有意注意

| 要点 | 说明 |
|------|------|
| 定义 | 有预定目的，需要意志努力 |
| 产生条件 | 任务要求 |
| 示例 | 听课、复习考试 |

**维持有意注意的条件：**
| 条件 | 说明 |
|------|------|
| 加深对目的的理解 | 知道为什么学 |
| 合理组织活动 | 边听边记 |
| 培养间接兴趣 | 对结果的兴趣 |
| 排除干扰 | 减少分心 |

### 2.3 有意后注意

| 要点 | 说明 |
|------|------|
| 定义 | 有预定目的但不需要意志努力 |
| 来源 | 熟练后形成 |
| 示例 | 熟练打字后的工作 |

### 2.4 三种注意的关系

```
无意注意 → 有意注意 → 有意后注意
（自然产生） （目的+意志） （目的+自动化）
```

## 三、注意的品质

### 3.1 注意广度

| 要点 | 说明 |
|------|------|
| 定义 | 一瞬间把握对象的数量 |
| 影响因素 | 对象特点、经验 |
| 训练 | 速读训练 |

**经典实验：** 速示器实验，一眼看6-8个点

### 3.2 注意稳定性

| 要点 | 说明 |
|------|------|
| 定义 | 保持在同一对象上的时间 |
| 表现 | 长时间专注 |
| 相反 | 注意动摇（周期性波动）|
| 训练 | 抗干扰训练 |

### 3.3 注意分配

| 要点 | 说明 |
|------|------|
| 定义 | 同时进行两种以上活动 |
| 条件 | 同时进行的活动必须熟练 |
| 示例 | 边听边记笔记 |

### 3.4 注意转移

| 要点 | 说明 |
|------|------|
| 定义 | 从一对象主动转向另一对象 |
| 特点 | 有目的，有意识控制 |
| 相反 | 注意惰性（难以转移）|
