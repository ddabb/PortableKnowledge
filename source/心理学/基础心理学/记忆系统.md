## 二、记忆的三级加工模型

### 2.1 三级记忆对比

| 类型 | 容量 | 时间 | 编码方式 |
|------|------|------|----------|
| 感觉记忆 | 大 | <1秒 | 图像/声像编码 |
| 短时记忆 | 7±2组块 | 1分钟内 | 听觉编码为主 |
| 长时记忆 | 无限 | 1分钟到终身 | 语义编码为主 |

### 2.2 感觉记忆

| 特点 | 说明 |
|------|------|
| 容量 | 很大 |
| 时间 | 0.25-2秒 |
| 编码 | 图像记忆（图像）、声像记忆（声音）|

### 2.3 短时记忆

| 特点 | 说明 |
|------|------|
| 容量 | 7±2个组块 |
| 时间 | 1分钟内 |
| 编码 | 听觉编码为主 |
| 复述 | 维持性复述→精细复述 |

**组块：** 将孤立信息组合成有意义单元
例：CSB → C-S-B → "CSB"（3个变1个组块）

### 2.4 长时记忆

| 类型 | 定义 |
|------|------|
| 陈述性记忆 | 能说出来（知识）|
| 程序性记忆 | 会做不会说（技能）|
| 情景记忆 | 个人经历 |
| 语义记忆 | 概念事实 |

## 三、工作记忆模型

### 3.1 Baddeley模型（1974）

```
          中央执行系统
              ↓
    ┌─────────┼─────────┐
    ↓         ↓         ↓
语音环路  视空画板  情景缓冲器
```

| 成分 | 功能 | 特点 |
|------|------|------|
| 中央执行 | 注意控制，资源分配 | 最核心 |
| 语音环路 | 言语存储与复述 | 语音相似性干扰 |
| 视空画板 | 视觉空间信息 | 视觉干扰干扰 |
| 情景缓冲器 | 整合多通道信息 | 接口长时记忆 |

## 四、遗忘规律

### 4.1 艾宾浩斯遗忘曲线

| 时间 | 遗忘率 |
|------|--------|
| 20分钟 | 42% |
| 1小时 | 56% |
| 1天 | 74% |
| 6天 | 67% |
| 1个月 | 79% |

**规律：** 先快后慢，先多后少

### 4.2 影响遗忘的因素

| 因素 | 影响 |
|------|------|
| 时间 | 越长遗忘越多 |
| 材料性质 | 无意义材料遗忘快 |
| 学习程度 | 学习程度越深遗忘越少 |
| 记忆内容 | 有意义的遗忘慢 |

## 五、遗忘的原因

### 5.1 消退说

| 内容 | 说明 |
|------|------|
| 理论 | 记忆痕迹随时间衰退 |
| 代表 | 桑代克 |
| 证据 | 不复习会遗忘 |

### 5.2 干扰说

| 类型 | 定义 | 示例 |
|------|------|------|
| 前摄抑制 | 先学材料干扰后学 | 学英语后学法语更难 |
| 倒摄抑制 | 后学材料干扰先学 | 学法语后回忆英语更难 |

### 5.3 压抑说（动机说）

| 内容 | 说明 |
|------|------|
| 理论 | 因痛苦情绪而遗忘 |
| 代表 | 弗洛伊德 |
| 证据 | 创伤事件的遗忘 |

### 5.4 提取失败说

| 内容 | 说明 |
|------|------|
| 理论 | 记忆存在但提取线索不足 |
| 代表 | Tulving |
| 证据 | 舌尖效应（话到嘴边说不出）|

### 论述题模板

**试述记忆的三级加工模型：**
```
1. 感觉记忆：容量大，时间<1秒，图像/声像编码
2. 短时记忆：容量7±2组块，时间1分钟内，听觉编码为主
3. 长时记忆：容量无限，时间1分钟到终身，语义编码为主
4. 三者相互联系：感觉记忆→短时记忆→长时记忆
```
