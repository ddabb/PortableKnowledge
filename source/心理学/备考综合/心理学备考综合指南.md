## 第三部分：答题技巧

### 3.1 选择题技巧

| 技巧 | 说明 |
|------|------|
| 排除法 | 先排除明显错误选项 |
| 关键词法 | 找准题目关键词 |
| 正向思维 | 选最符合定义的 |
| 逆向思维 | 排除最不符合的 |
| 过度联想 | 不选超出题意的 |

### 3.2 简答题模板

**答题结构：**
```
1. 概念定义（核心概念）
2. 主要内容（列出要点）
3. 举例说明（如有）
```

**示例：简述知觉的基本特性**
> 知觉是人脑对直接作用于感觉器官的客观事物整体属性的反映。其基本特性包括：
> （1）选择性：有选择地加工刺激
> （2）理解性：用已有知识经验理解事物
> （3）整体性：整体优先于部分
> （4）恒常性：条件变化时知觉保持相对稳定

### 3.3 论述题模板

**答题结构：**
```
1. 提出理论/概念（是什么）
2. 详细阐述理论内容
3. 举例说明
4. 评价/意义/应用
5. 小结
```

**示例：试述皮亚杰认知发展阶段理论**
> 一、理论概述
> 皮亚杰将儿童认知发展分为四个阶段...
> 二、详细阐述（每阶段）
> 三、评价
> 四、启示

### 3.4 辨析题模板

**答题结构：**
```
1. 判断正误
2. 解释相关概念
3. 辨析题目观点
4. 总结
```

**示例："强化和惩罚都能减少行为"**
> 此说法错误。
> 强化（包括正强化和负强化）的作用是**增加**行为频率；
> 惩罚（包括正惩罚和负惩罚）的作用是**减少**行为频率。
> 因此，题中说"强化减少行为"是错误的。

## 第五部分：常见易错点

### 5.1 概念混淆

| 易混淆 | 区别 |
|--------|------|
| 同化 vs 顺应 | 顺应改变图式，同化不改变 |
| 再认 vs 再现 | 再认能认出，再现能回忆 |
| 从众 vs 服从 | 从众无命令，服从有命令 |
| 正强化 vs 正惩罚 | 强化增行为，惩罚减行为 |
| 信度 vs 效度 | 信度是稳定性，效度是准确性 |
| 经典 vs 操作 | 刺激在先vs行为在先 |

### 5.2 常见错误

| 错误 | 正确理解 |
|------|----------|
| "强化就是奖励" | 强化≠奖励，负强化也是强化 |
| "从众就是服从" | 从众无权威命令，服从有 |
| "遗忘就是记忆消退" | 遗忘还有干扰说等 |
| "情商就是会说话" | 情商是多维能力 |

## 第七部分：真题资源

### 7.1 真题使用策略

1. **限时做** — 按考试时间限时
2. **模拟考** — 营造考试氛围
3. **认真改** — 错题必须弄懂
4. **反复做** — 做过的真题再做

### 7.2 高质量题目特征

- 有明确知识点指向
- 干扰选项有迷惑性
- 与真题风格接近
- 有详细解析
