## 第五部分：高频简答模板

### 简答：皮亚杰认知发展阶段
```
皮亚杰将儿童认知发展分为四个阶段：
（1）感觉运动期（0-2岁）：客体永存
（2）前运算期（2-7岁）：自我中心、不可逆
（3）具体运算期（7-11岁）：守恒、去自我中心
（4）形式运算期（11+岁）：抽象逻辑思维
```

### 简答：增加从众的方法
```
（1）群体一致性：一致性越高，从众越多
（2）群体规模：规模越大，从众越多（但5人后趋于稳定）
（3）凝聚力：群体凝聚力越高，从众越多
（4）公开反应：公开比匿名从众更多
（5）自我卷入：低自我卷入者更多从众
```

### 简答：观察学习四过程
```
（1）注意过程：选择性地观察示范
（2）保持过程：将观察转化为符号表征
（3）再现过程：将符号转化为行为
（4）动机过程：有强化才会表现行为
```
