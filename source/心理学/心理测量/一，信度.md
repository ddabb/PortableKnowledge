## 一，信度

### 1.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 测量结果的稳定性、一致性和可靠性 |
| 核心 | 多次测量结果的一致程度 |
| 公式 | r = σ²T / σ²X |

### 1.2 主要类型

| 类型 | 定义 | 公式/特点 |
|------|------|-----------|
| **重测信度** | 同一量表不同时间测两次的相关 | r = 两次测量的相关 |
| **复本信度** | 两个等值复本的相关 | r = 两个版本的相关 |
| **分半信度** | 同一量表两半的相关 | r = 两半题目的相关 |
| **同质性信度** | 各题目间的一致性 | r = 各题目相关均值 |
| **评分者信度** | 不同评分者的一致性 | r = 评分者间相关 |

### 1.3 信度系数

| 系数范围 | 解释 |
|----------|------|
| r ≥ 0.90 | 优秀 |
| 0.80 ≤ r < 0.90 | 良好 |
| 0.70 ≤ r < 0.80 | 可接受 |
| 0.60 ≤ r < 0.70 | 勉强接受 |
| r < 0.60 | 需修改 |

### 1.4 影响信度的因素

| 因素 | 影响 |
|------|------|
| 测试长度 | 题越多，信度越高 |
| 题目的同质性 | 越同质，信度越高 |
| 被试的变异性 | 越同质，信度越低 |
| 测试的难度 | 太难或太易，信度低 |
| 时间限制 | 时间越紧，信度越低 |
