## 三，信度与效度的关系

### 3.1 基本关系

| 关系 | 说明 |
|------|------|
| 高信度 → 高效度 | 信度高是高效度的必要条件 |
| 高效度 → 高信度 | 高效度必然要求高信度 |
| 低信度 → 低效度 | 信度低，效度必然低 |
| 低效度 → 信度不确定 | 效度低，信度可能高 |

### 3.2 信度与效度关系图

```
        高信度
       /      \
 高效度          低效度
 (理想)        (浪费)
 低效度          高效度
 (糟糕)        (不可能)
```

### 3.3 经典真分数理论

| 概念 | 公式 | 说明 |
|------|------|------|
| 真分数 | T = X - E | 实际分数中的真实部分 |
| 误差分数 | E | 测量误差 |
| 观察分数 | X = T + E | 实际测到的分数 |
| 信度系数 | r_xx = σ²T/σ²X | 真分数方差占比 |
