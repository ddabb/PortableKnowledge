## 一，信度

### 1.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 测量结果的稳定性、一致性和可靠性 |
| 核心 | 多次测量结果的一致程度 |
| 公式 | r = σ²T / σ²X |

### 1.2 主要类型

| 类型 | 定义 | 公式/特点 |
|------|------|-----------|
| **重测信度** | 同一量表不同时间测两次的相关 | r = 两次测量的相关 |
| **复本信度** | 两个等值复本的相关 | r = 两个版本的相关 |
| **分半信度** | 同一量表两半的相关 | r = 两半题目的相关 |
| **同质性信度** | 各题目间的一致性 | r = 各题目相关均值 |
| **评分者信度** | 不同评分者的一致性 | r = 评分者间相关 |

### 1.3 信度系数

| 系数范围 | 解释 |
|----------|------|
| r ≥ 0.90 | 优秀 |
| 0.80 ≤ r < 0.90 | 良好 |
| 0.70 ≤ r < 0.80 | 可接受 |
| 0.60 ≤ r < 0.70 | 勉强接受 |
| r < 0.60 | 需修改 |

### 1.4 影响信度的因素

| 因素 | 影响 |
|------|------|
| 测试长度 | 题越多，信度越高 |
| 题目的同质性 | 越同质，信度越高 |
| 被试的变异性 | 越同质，信度越低 |
| 测试的难度 | 太难或太易，信度低 |
| 时间限制 | 时间越紧，信度越低 |

## 二，效度

### 2.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 测量结果的准确性 |
| 核心 | 是否测量到了想测的东西 |

### 2.2 主要类型

| 类型 | 定义 | 说明 |
|------|------|------|
| **内容效度** | 题目对内容领域的代表性 | 专家判断 |
| **效标效度** | 与外部效标的相关 | 同时/预测效度 |
| **结构效度** | 与理论结构的一致性 | 因素分析 |
| **表面效度** | 题目看起来是否相关 | 非正式 |

### 2.3 效标效度细分

| 类型 | 定义 | 示例 |
|------|------|------|
| 同时效度 | 与现有标准的同时相关 | 笔试与面试成绩相关 |
| 预测效度 | 对未来行为的预测力 | 入学成绩与在校成绩 |

### 2.4 效度系数

| 系数范围 | 解释 |
|----------|------|
| r ≥ 0.40 | 效度较高 |
| 0.20 ≤ r < 0.40 | 效度中等 |
| r < 0.20 | 效度较低 |

## 三，信度与效度的关系

### 3.1 基本关系

| 关系 | 说明 |
|------|------|
| 高信度 → 高效度 | 信度高是高效度的必要条件 |
| 高效度 → 高信度 | 高效度必然要求高信度 |
| 低信度 → 低效度 | 信度低，效度必然低 |
| 低效度 → 信度不确定 | 效度低，信度可能高 |

### 3.2 信度与效度关系图

```
        高信度
       /      \
 高效度          低效度
 (理想)        (浪费)
 低效度          高效度
 (糟糕)        (不可能)
```

### 3.3 经典真分数理论

| 概念 | 公式 | 说明 |
|------|------|------|
| 真分数 | T = X - E | 实际分数中的真实部分 |
| 误差分数 | E | 测量误差 |
| 观察分数 | X = T + E | 实际测到的分数 |
| 信度系数 | r_xx = σ²T/σ²X | 真分数方差占比 |

### 辨析题模板

**"测量工具的效度高，信度一定高"**
```
此说法错误。
效度高不一定信度高。因为：
- 效度：测量结果的准确性（是否测到想测的）
- 信度：测量结果的稳定性（多次测量是否一致）
如果每次都用错误的方式稳定测量，则效度低但信度高。
因此效度高→信度高（成立），但信度高→效度高（不成立）。
```
