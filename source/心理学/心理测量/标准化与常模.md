## 一，标准化

### 1.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 统一、规范的施测和评分过程 |
| 目的 | 确保测量结果的公平性和可比性 |

### 1.2 标准化施测程序

| 要素 | 内容 |
|------|------|
| 统一的指导语 | 相同的解释和说明 |
| 统一的时间限制 | 相同的答题时间 |
| 统一的测试环境 | 相同的物理条件 |
| 统一的评分标准 | 客观、公正的评分 |
| 统一的实施程序 | 相同的操作步骤 |

## 二，常模参照分数

### 2.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 将被试分数与常模团体比较得出的分数 |
| 作用 | 了解被试在群体中的相对位置 |

### 2.2 常模类型

| 类型 | 定义 | 示例 |
|------|------|------|
| **百分位常模** | 用百分等级表示位置 | 百分位90%=超过了90%的人 |
| **年龄常模** | 按年龄建立的常模 | 某年龄段的平均分 |
| **年级常模** | 按年级建立的常模 | 某年级的平均分 |
| **标准分常模** | Z分数、T分数等 | Z=1.5 |

### 2.3 百分位

| 要点 | 说明 |
|------|------|
| 定义 | 超过某百分比被试的分数 |
| 计算 | 百分位 = (NP/R) × 100% |
| NP | 分数低于某值的被试数 |
| R | 总被试数 |

### 2.4 标准分数

| 分数 | 公式 | 特点 |
|------|------|------|
| Z分数 | Z = (X - X̄) / SD | 平均数为0，标准差为1 |
| T分数 | T = 10Z + 50 | 平均数为50，标准差为10 |
| 离差智商 | IQ = 15Z + 100 | 平均数为100，标准差为15 |

### 2.5 分数解释

| 解释类型 | 参照标准 | 说明 |
|----------|----------|------|
| 常模参照 | 常模团体 | 与他人比较 |
| 准则参照 | 绝对标准 | 与目标比较 |
| 自参参照 | 个人历史 | 与自己过去比较 |

## 三，常模的编制

### 3.1 常模团体

| 要点 | 要求 |
|------|------|
| 代表性 | 需代表目标群体 |
| 规模 | 足够大的样本 |
| 标准化 | 标准化取样过程 |

### 3.2 编制步骤

| 步骤 | 说明 |
|------|------|
| 1. 确定目标群体 | 明确测验的使用范围 |
| 2. 标准化取样 | 按比例从目标群体中抽取样本 |
| 3. 施测样本团体 | 对样本施测 |
| 4. 建立常模表 | 计算百分位或标准分 |
| 5. 定期更新常模 | 随着时间推移更新 |

---

## 四，使用常模的注意事项

| 注意事项 | 说明 |
|----------|------|
| 参照群体要匹配 | 用与被试相同群体的常模 |
| 避免单一分数 | 结合多个指标综合判断 |
| 定期更新 | 常模随时间可能过时 |
| 解释要谨慎 | 避免绝对化 |
