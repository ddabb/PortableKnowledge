## 一，难度

### 1.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 测验题目的难易程度 |
| 公式 | P = R / N × 100% |
| P | 难度值（通过率） |
| R | 通过该题的人数 |
| N | 总人数 |

### 1.2 难度等级

| P值范围 | 难度等级 | 适用 |
|---------|---------|------|
| P ≥ 0.80 | 较易 | 基础题 |
| 0.50 ≤ P < 0.80 | 中等 | 理想难度 |
| 0.30 ≤ P < 0.50 | 较难 | 选拔性考试 |
| P < 0.30 | 很难 | 高难度题 |

### 1.3 理想难度

**P ≈ 0.50** 时，题目区分力最强

### 1.4 计算示例

**例：50人中40人通过某题，难度是多少？**

```
P = R/N = 40/50 = 0.80
难度值P = 0.80（较易）
```

### 1.5 难度对测验的影响

| 难度 | 效果 |
|------|------|
| 太难（P低）| 分数集中在低分区，区分度低 |
| 太易（P高）| 分数集中在高分区，区分度低 |
| 中等（P≈0.50）| 分数分布广，区分度高 |

## 二，区分度

### 2.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 题目对不同水平被试的区分能力 |
| 范围 | -1 ≤ D ≤ 1 |
| 理想值 | D ≥ 0.40 |

### 2.2 区分度等级

| D值范围 | 区分度等级 | 说明 |
|---------|-----------|------|
| D ≥ 0.40 | 优秀 | 非常好 |
| 0.30 ≤ D < 0.40 | 良好 | 可以接受 |
| 0.20 ≤ D < 0.30 | 尚可 | 需修改 |
| D < 0.20 | 差 | 需淘汰 |

### 2.3 计算方法

#### 方法一：极端组比较法

```
D = PH - PL

PH = 高分组通过率
PL = 低分组通过率
```

**步骤：**
1. 按总分排序，取前后27%为高分组和低分组
2. 计算高分组通过率PH
3. 计算低分组通过率PL
4. D = PH - PL

#### 方法二：相关法

```
D = r = 题目分数与总分的相关
```

使用点二列相关或二列相关。

### 2.4 区分度与难度的关系

| 关系 | 说明 |
|------|------|
| P ≈ 0.50时 | D最大 |
| P趋近0或1时 | D趋近0 |
| 倒U型关系 | 中等难度区分度最高 |

## 三，难度与信效度的关系

### 3.1 对信度的影响

| 难度 | 信度 |
|------|------|
| 太难或太易 | 信度降低 |
| 中等难度 | 信度最高 |

### 3.2 对效度的影响

| 难度 | 效度 |
|------|------|
| 中等难度 | 效度最高 |
| 题目区分度越高 | 效度越高 |
