## 一，压力的定义

### 1.1 Lazarus定义

| 要点 | 说明 |
|------|------|
| 定义 | 个人与环境之间失衡时产生的主观感受 |
| 核心 | 压力是一种认知评价过程 |

### 1.2 压力的类型

| 类型 | 定义 | 示例 |
|------|------|------|
| **急性压力** | 短时间内的压力反应 | 考试前的紧张 |
| **慢性压力** | 长时间持续的压力 | 长期工作压力 |
| **创伤性压力** | 严重创伤事件 | 车祸、自然灾害 |

## 二，压力源

### 2.1 分类

| 类型 | 来源 | 示例 |
|------|------|------|
| 工作压力源 | 工作本身 | 工作量大、截止日期 |
| 生活压力源 | 生活事件 | 离婚、搬家 |
| 社会压力源 | 人际关系 | 冲突、歧视 |
| 环境压力源 | 物理环境 | 噪音、温度 |

### 2.2 生活事件量表

| 量表 | 说明 |
|------|------|
| SRRS | Holmes & Rahe社会再适应量表 |
| LCU | 生活变化单位，累积压力预测健康 |

## 三，压力反应

### 3.1 生理反应

| 系统 | 机制 | 激素 |
|------|------|------|
| 交感神经 | 战斗或逃跑 | 肾上腺素 |
| 下丘脑-垂体-肾上腺轴 | HPA轴 | 皮质醇 |

**GAS模型（Selye）：**
```
警觉期 → 抵抗期 → 衰竭期
（激活）  （适应）  （崩溃）
```

### 3.2 心理反应

| 反应 | 说明 |
|------|------|
| 焦虑 | 担忧、紧张 |
| 抑郁 | 无助、绝望 |
| 认知损害 | 注意力下降 |

### 3.3 行为反应

| 反应 | 说明 |
|------|------|
| 回避 | 逃避压力源 |
| 攻击 | 对压力源的敌意 |
| 物质滥用 | 饮酒、吸烟 |

## 四，应对策略

### 4.1 应对策略分类

| 类型 | 定义 | 策略 |
|------|------|------|
| **问题聚焦应对** | 直接解决问题 | 制定计划、寻求帮助、行动 |
| **情绪聚焦应对** | 处理情绪反应 | 寻求支持、积极重评、接受 |

### 4.2 Lazarus评价理论

| 评价类型 | 定义 | 应对倾向 |
|----------|------|----------|
| 无关 | 事件与己无关 | 无需应对 |
| 良性 | 挑战或收益 | 关注收益 |
| 压力性 | 有危害或损失 | 采取应对 |

### 4.3 有效应对

| 方法 | 说明 |
|------|------|
| 问题聚焦 | 当问题可控时有效 |
| 情绪聚焦 | 当问题不可控时更有效 |
| 寻求社会支持 | 缓冲压力 |
| 积极重评 | 认知重评改变感受 |

## 五，压力管理

| 方法 | 说明 |
|------|------|
| 放松训练 | 深呼吸、冥想、瑜伽 |
| 时间管理 | 减少时间压力 |
| 社会支持 | 家人、朋友支持 |
| 运动 | 身体活动缓解压力 |
| 认知重构 | 改变不合理的信念 |
