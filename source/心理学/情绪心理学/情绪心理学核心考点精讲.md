## 第一部分：情绪概述

### 1.1 情绪的成分

| 成分 | 说明 |
|------|------|
| 主观体验 | 个体的内心感受 |
| 生理唤醒 | 心跳加快、呼吸变化等 |
| 外部表现 | 表情、姿态、语调 |
| 认知评估 | 对情境的解释和评价 |

### 1.2 基本情绪

| 情绪 | 特点 |
|------|------|
| 快乐 | 目标实现后的愉悦感 |
| 愤怒 | 目标受阻 |
| 悲伤 | 丧失 |
| 恐惧 | 危险威胁 |
| 惊讶 | 意外事件 |
| 厌恶 | 厌恶刺激 |

### 1.3 情绪的维度

| 维度 | 说明 |
|------|------|
| 效价 | 积极/消极 |
| 唤醒度 | 高/低唤醒 |
| 支配度 | 支配/服从 |

## 第二部分：情绪理论

### 2.1 詹姆斯-兰格理论（外周理论）

> 情绪 = 对身体变化的感知

**观点：** 先有生理反应（心跳加快、肌肉紧张），然后才有情绪体验

**评价：** 忽视了认知在情绪中的作用

### 2.2 坎农-巴德理论（丘脑理论）

**观点：** 情绪刺激→丘脑→同时到达皮层（产生情绪）和身体（产生生理反应）

**创新：** 生理反应和情绪体验同时发生

### 2.3 沙赫特-辛格理论（认知理论）

**公式：** 情绪 = 生理唤醒 + 认知解释

**实验：**
- 三组被试注射肾上腺素（引起心跳加快）
- 告知"正常药物反应"（认知错误引导）→无明显情绪
- 告知"会兴奋"（错误引导）→体验到快乐
- 不告知任何信息（正常反应）→体验到愤怒

### 2.4 拉扎勒斯的认知评价理论

**观点：** 情绪源于认知评价**

| 评价类型 | 说明 |
|---------|------|
| 初级评价 | 是否与自身相关 |
| 次级评价 | 能否应对 |
| 再评价 | 评价结果调整 |

## 第三部分：情绪调节

### 3.1 情绪调节过程模型（Gross, 1998）

| 阶段 | 策略 | 发生时间 |
|------|------|----------|
| 选择情境 | 接近/回避情境 | 情境选择 |
| 情境修正 | 改变情境 | 情境修正 |
| 注意部署 | 关注什么 | 注意部署 |
| 认知改变 | 改变认知 | 认知重评 |
| 反应调节 | 调节反应倾向 | 反应调节 |

### 3.2 情绪调节策略

| 策略 | 定义 | 示例 |
|------|------|------|
| 认知重评 | 改变对情境的认知 | 挫折是成长机会 |
| 表达抑制 | 抑制情绪表达 | 忍住不哭 |
| 问题聚焦应对 | 直接解决问题 | 制定计划解决 |
| 情绪聚焦应对 | 处理情绪感受 | 向人倾诉 |

### 3.3 情绪智力的定义

**情绪智力（Salovey & Mayer, 1990）：**
| 能力 | 说明 |
|------|------|
| 情绪觉知 | 感知自己和他人的情绪 |
| 情绪理解 | 理解情绪及其原因 |
| 情绪管理 | 调节情绪 |
| 情绪应用 | 利用情绪促进思维 |

**Goleman的情商模型：**
- 自我觉察
- 自我管理
- 社会觉察
- 人际关系管理

## 第四部分：压力与应对

### 4.1 压力的定义

压力 = 个体对威胁性情境或事件的反应

### 4.2 压力的生理反应

| 系统 | 反应 |
|------|------|
| 交感神经激活 | 肾上腺素分泌 |
| HPA轴 | 皮质醇分泌 |
| 心血管 | 心跳加快、血压升高 |
| 免疫 | 短期增强，长期抑制 |

### 4.3 塞利的应激理论

| 阶段 | 说明 |
|------|------|
| 警觉期 | 身体被激活 |
| 抵抗期 | 身体适应 |
| 衰竭期 | 资源耗尽，出现疾病 |

### 4.4 压力的来源

| 来源 | 示例 |
|------|------|
| 工作压力 | deadline、绩效 |
| 生活压力 | 经济、家庭 |
| 社会压力 | 人际关系 |
| 内在压力 | 自我期待 |

### 4.5 应对策略

| 类型 | 策略 | 示例 |
|------|------|------|
| 问题聚焦 | 直接解决压力源 | 制定计划解决问题 |
| 情绪聚焦 | 管理情绪反应 | 倾诉、运动 |
| 逃避 | 回避问题 | 酗酒、沉迷游戏 |

### 4.6 压力管理方法

| 方法 | 说明 |
|------|------|
| 放松训练 | 深呼吸、冥想、瑜伽 |
| 时间管理 | 优先级、计划 |
| 社会支持 | 家人、朋友、同事 |
| 认知重构 | 改变对压力的看法 |
| 运动 | 规律运动释放压力 |

### 名词解释

- 情绪调节：为达到目标，对情绪体验、情绪表达进行监控和调整的过程
- 认知重评：通过改变对情境的认知来调节情绪
- 情绪智力：感知、理解、管理和应用情绪的能力
- 压力：个体对威胁性情境或事件的反应

### 论述题模板

**试述沙赫特-辛格的实验及理论意义：**
> 1. 实验：三组被试注射肾上腺素（引起生理唤醒），告知不同信息
> 2. 结果：被告知信息引导了情绪体验
> 3. 理论：情绪 = 生理唤醒 + 认知解释
> 4. 意义：证明了认知在情绪中的重要作用，批判了纯生理理论
