## 一，亲社会行为的定义

### 1.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 对他人有益的行为，不期望回报 |
| 目的 | 旨在帮助他人 |

### 1.2 亲社会行为的类型

| 类型 | 定义 | 示例 |
|------|------|------|
| 利他行为 | 以帮助他人为唯一目的 | 捐款 |
| 合作 | 与他人共同完成目标 | 团队项目 |
| 共享 | 与他人分享资源 | 分食物 |
| 安慰 | 减轻他人痛苦 | 安慰朋友 |

## 二，旁观者效应

### 2.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 他人在场时，个体助人行为减少 |
| 又名 | Darley & Latane旁观者效应 |

### 2.2 经典实验

| 实验 | 研究者 | 发现 |
|------|--------|------|
| 癫痫发作 | Latane & Darley | 房间人数越多，报告越少 |
| 紧急情况模拟 | Latane & Rodin | 单独时70%帮助，群体中40% |

### 2.3 原因分析

| 原因 | 说明 |
|------|------|
| 责任分散 | 人多→个人感到的责任小 |
| 多元无知 | 人多→认为其他人会觉得不紧急 |
| 评价恐惧 | 在他人面前帮助→怕被评价 |
| 情境模糊 | 不知道是否真的是紧急情况 |

### 2.4 减少旁观者效应的方法

| 方法 | 说明 |
|------|------|
| 明确求助 | 指向特定人求助 |
| 强调紧急性 | 明确说明是紧急情况 |
| 增加可控性 | 明确说明需要什么帮助 |

## 三，亲社会行为的理论

### 3.1 社会规范理论

| 规范 | 内容 |
|------|------|
| 社会责任规范 | 应该帮助有需要的人 |
| 互惠规范 | 帮助他人，他人也会帮助你 |
| 平等规范 | 帮助应该公平 |

### 3.2 社会进化理论

| 要点 | 说明 |
|------|------|
| 观点 | 亲社会行为是进化的结果 |
| 亲缘选择 | 帮助基因相关的亲属 |
| 互惠利他 | 期望未来回报 |

### 3.3 移情-利他假说

| 要点 | 说明 |
|------|------|
| 观点 | 移情（理解他人情绪）→利他动机 |
| 移情 | 设身处地理解他人感受 |
| 效果 | 移情越强→助人动机越强 |

## 四，影响助人行为的因素

### 4.1 环境因素

| 因素 | 影响 |
|------|------|
| 他人在场 | 人多助人少 |
| 环境特点 | 城市冷漠感 |
| 时间压力 | 时间紧张助人少 |

### 4.2 被助者因素

| 因素 | 影响 |
|------|------|
| 外貌吸引力 | 吸引人者更易获助 |
| 相似性 | 相似者更易获助 |
| 责任归因 | 认为是自己的错时助人少 |

### 4.3 助人者因素

| 因素 | 影响 |
|------|------|
| 内疚感 | 内疚→更可能助人 |
| 移情能力 | 移情→更多助人 |
| 人格特质 | 宜人性高→更多助人 |
| 价值观 | 亲社会价值观 |
