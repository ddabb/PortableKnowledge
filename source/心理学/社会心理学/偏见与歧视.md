> 1. 掌握偏见、歧视、刻板印象的概念
> 2. 理解偏见产生的原因
> 3. 掌握减少偏见的方法

---

## 一，基本概念

### 1.1 刻板印象

| 要点 | 说明 |
|------|------|
| 定义 | 对某个群体的固定、概括的看法 |
| 特点 | 简化和过度概括 |
| 自动加工 | 无意识、快速形成 |

### 1.2 偏见

| 要点 | 说明 |
|------|------|
| 定义 | 对特定群体不合理的负面态度 |
| 成分 | 认知（刻板印象）+情感（厌恶）+行为（歧视）|

### 1.3 歧视

| 要点 | 说明 |
|------|------|
| 定义 | 对特定群体的不公平行为 |
| 表现 | 就业歧视、教育歧视 |

### 1.4 三者关系

```
刻板印象（认知）
      ↓
    偏见（情感）
      ↓
   歧视（行为）
```

## 二，偏见产生的原因

### 2.1 社会原因

| 原因 | 说明 |
|------|------|
| 社会学习 | 从父母、媒体习得 |
| 社会规范 | 群体内的偏见文化 |
| 现实冲突 | 竞争资源时产生偏见 |
| 不平等地位 | 支配群体对从属群体的偏见 |

### 2.2 认知原因

| 原因 | 说明 |
|------|------|
| 归因偏差 | 基本归因错误 |
| 分类效应 | 将人分类处理 |
| 独特性效应 | 对独特的人过度关注 |

### 2.3 动机原因

| 原因 | 说明 |
|------|------|
| 自我提升 | 通过贬低他人提升自尊 |
| ingroup偏见 | 偏爱内群体 |
| 替罪羊理论 | 将挫折归咎于特定群体 |

---

## 三，偏见的影响

| 影响 | 说明 |
|------|------|
| 自我实现预言 | 偏见导致被偏见对象表现符合预期 |
| 歧视行为 | 直接影响被偏见群体 |
| 心理伤害 | 低自尊、焦虑、抑郁 |

---

## 四，减少偏见的方法

### 4.1 接触假说（Allport, 1954）

| 条件 | 说明 |
|------|------|
| 平等地位 | 双方地位平等 |
| 共同目标 | 有共同目标 |
| 合作而非竞争 | 需合作完成任务 |
| 权威支持 | 有制度或权威支持 |

### 4.2 其他方法

| 方法 | 说明 |
|------|------|
| 去偏见培训 | 培养认知共情 |
| 重新分类 | 改变分类方式 |
| 普遍性关注 | 关注共同人类特征 |
| 消除不平等 | 改变结构性不平等 |
