## 一，印象形成的线索

### 1.1 印象形成

| 要点 | 说明 |
|------|------|
| 定义 | 根据有限信息形成对他人的整体评价 |
| 特点 | 快速、自动、整体性 |

### 1.2 印象形成的信息线索

| 线索 | 说明 | 重要性 |
|------|------|--------|
| 热情 | 友好、善良、幽默 | 最重要 |
| 能力 | 聪明、技能 | 高 |
| 社会角色 | 身份、地位 | 中 |
| 外貌 | 吸引力、穿着 | 低 |

**热情 vs 能力的顺序：**
> 热情优先于能力（热情更影响第一印象）

## 二，印象形成效应

### 2.1 光环效应

| 要点 | 说明 |
|------|------|
| 定义 | 某个特征泛化到其他特征 |
| 又名 | 晕轮效应 |
| 例子 | 好看的人被认为也更聪明 |

### 2.2 负性效应

| 要点 | 说明 |
|------|------|
| 定义 | 负面信息比正面信息影响更大 |
| 原因 | 负面信息更突出、记忆更深 |
| 例子 | 一个缺点掩盖多个优点 |

### 2.3 宽大效应

| 要点 | 说明 |
|------|------|
| 定义 | 评价他人时偏向正面 |
| 表现 | 大多数人给自己3-4分（满分5分）|
| 例外 | 低自尊者、抑郁者可能相反 |

## 三，首因效应与近因效应

### 3.1 首因效应

| 要点 | 说明 |
|------|------|
| 定义 | 首先获得的信息对印象形成影响最大 |
| 条件 | 信息连续呈现，第一信息最重要 |
| 适用于 | 陌生人、不熟悉的情境 |

### 3.2 近因效应

| 要点 | 说明 |
|------|------|
| 定义 | 最近获得的信息对印象形成影响最大 |
| 条件 | 信息之间有间隔 |
| 适用于 | 熟悉的人、系列信息 |

### 3.3 对比

| 对比 | 首因效应 | 近因效应 |
|------|----------|----------|
| 时间 | 最初信息 | 最近信息 |
| 条件 | 信息连续 | 信息有间隔 |
| 适用 | 陌生人 | 熟悉的人 |

## 四，社会认知偏差

### 4.1 归因偏差

| 偏差 | 定义 | 例子 |
|------|------|------|
| 基本归因错误 | 高估内因、低估外因 | 别人失败→归因于能力，不归因于运气 |
| 行动者-观察者偏差 | 对他人归因内因，对自己归因外因 | 别人迟到→懒，我迟到→堵车 |
| 自利偏差 | 成功归内因，失败归外因 | 我成功→能力强，我失败→环境差 |
| 归因于不变性 | 过度简化因果关系 | 过度简化"因为A所以B" |

### 4.2 确认偏差

| 要点 | 说明 |
|------|------|
| 定义 | 寻找证实而非证伪自己观点的信息 |
| 影响 | 固化偏见 |

### 4.3 后见之明偏差

| 要点 | 说明 |
|------|------|
| 定义 | 事后认为结果"早就预料到" |
| 影响 | 高估事前预测能力 |

### 4.4 虚假一致性

| 要点 | 说明 |
|------|------|
| 定义 | 高估他人与自己相似的程度 |
| 例子 | "大家都这么想"（其实不是）|

---

## 五，减少社会认知偏差的方法

| 方法 | 说明 |
|------|------|
| 换位思考 | 考虑他人视角 |
| 寻求反面证据 | 主动寻找不支持自己观点的信息 |
| 延迟判断 | 不急于下结论 |
| 意识到偏差 | 认识常见偏差 |
