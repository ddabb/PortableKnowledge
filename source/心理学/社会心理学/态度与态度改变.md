## 一，态度的定义

### 1.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 对人、事物或观念的持久性评价 |
| 特点 | 认知+情感+行为倾向 |

### 1.2 ABC成分模型

| 成分 | 全称 | 说明 |
|------|------|------|
| **A** | Affect（情感）| 对态度对象的情绪感受 |
| **B** | Behavior（行为倾向）| 行为意图 |
| **C** | Cognition（认知）| 对态度对象的信念和看法 |

---

## 二，态度与行为的关系

### 2.1 经典观点

| 观点 | 理论 |
|------|------|
| 态度→行为 | 态度决定行为 |
| 行为→态度 | 行为改变态度 |

### 2.2 影响态度-行为一致性的因素

| 因素 | 影响 |
|------|------|
| 态度的强度 | 强烈态度→更一致 |
| 态度的可达性 | 易提取→更一致 |
| 社会压力 | 规范压力→降低一致性 |
| 稳定性 | 稳定态度→更一致 |

## 三，说服（态度改变）

### 3.1 说服的要素

| 要素 | 说明 |
|------|------|
| 传达者 | 谁在说（可信度、吸引力）|
| 信息 | 说了什么（内容、方式）|
| 渠道 | 怎么传播（面对面、媒体）|
| 接受者 | 谁在听（人格、动机）|

### 3.2 传达者因素

| 因素 | 说明 |
|------|------|
| 专业性 | 越专业越有效 |
| 可信度 | 权威+可信赖 |
| 吸引力 | 相似、有魅力 |
| 受欢迎程度 | 被喜欢的程度 |

### 3.3 信息因素

| 因素 | 说明 |
|------|------|
| 双方差距 | 中等差距最有效 |
| 恐惧诉求 | 适度恐惧最有效 |
| 观点表达 | 温和表达更有效 |

## 四，精细加工可能性模型（ELM）

### 4.1 核心观点

| 路径 | 条件 | 受众特点 |
|------|------|----------|
| **中心路径** | 高卷入+高认知能力 | 积极思考 |
| **边缘路径** | 低卷入+低认知能力 | 依赖简单线索 |

### 4.2 两条路径对比

| 对比 | 中心路径 | 边缘路径 |
|------|----------|----------|
| 加工深度 | 深加工 | 浅加工 |
| 关注点 | 信息内容 | 说服者、信息背景 |
| 效果持久性 | 持久 | 短暂 |
| 条件 | 需要认知动机 | 需要简单线索 |

### 4.3 ELM的应用

| 情境 | 路径 |
|------|------|
| 重要决策 | 中心路径 |
| 低介入度产品 | 边缘路径 |
| 教育培训 | 中心路径 |
