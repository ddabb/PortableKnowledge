## 一，攻击行为的定义

### 1.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 有意伤害他人或破坏物体的行为 |
| 特征 | 有意性、伤害性 |
| 区分 | 敌意性攻击 vs 工具性攻击 |

### 1.2 两种攻击类型

| 类型 | 定义 | 示例 |
|------|------|------|
| **敌意性攻击** | 以伤害对方为目的 | 因愤怒而打人 |
| **工具性攻击** | 以达到其他目的为主，伤害是手段 | 抢钱时打人 |

## 二，攻击的理论

### 2.1 挫折-攻击理论（Dollard, 1939）

| 要点 | 说明 |
|------|------|
| 核心 | 挫折→攻击 |
| 挫折 | 阻碍目标实现的行为 |
| 观点 | 挫折总是导致某种形式的攻击 |

**修正后的观点：**
| 要点 | 说明 |
|------|------|
| 挫折→攻击是间接的 | 需通过愤怒唤醒状态 |
| 攻击目标可转移 | 可能转向替罪羊 |
| 环境线索 | 攻击线索可引发攻击 |

### 2.2 社会学习理论（Bandura）

| 要点 | 说明 |
|------|------|
| 核心 | 攻击行为可以通过观察习得 |
| 实验 | 波波玩偶实验（Bobo doll） |
| 机制 | 观察→记忆→表现 |

**影响因素：**
| 因素 | 说明 |
|------|------|
| 媒体暴力 | 接触暴力内容增加攻击性 |
| 游戏暴力 | 暴力游戏增加攻击性 |
| 榜样特征 | 有权力、成功的榜样影响更大 |

### 2.3 认知新联想理论

| 要点 | 说明 |
|------|------|
| 核心 | 攻击是个人与环境互动的结果 |
| 线索 | 攻击相关线索（武器）激活攻击脚本 |
| 脚本 | 个体从经验中习得的攻击行为模式 |

## 三，攻击的影响因素

### 3.1 个体因素

| 因素 | 影响 |
|------|------|
| 敌意归因偏向 | 将他人行为归因为恶意→攻击 |
| 自我控制 | 自我控制低→更多攻击 |
| 性别 | 男性攻击性更高 |
| 人格特质 | 神经质、反社会人格 |

### 3.2 情境因素

| 因素 | 影响 |
|------|------|
| 高温 | 温度升高→攻击增加 |
| 酒精 | 酒精降低抑制→攻击增加 |
| 拥挤 | 过度拥挤→攻击增加 |
| 噪音 | 噪音→唤醒增加→攻击 |

### 3.3 社会因素

| 因素 | 影响 |
|------|------|
| 暴力媒体 | 接触→攻击性增加 |
| 暴力游戏 | 玩→攻击性增加 |
| 社会学习 | 父母/同伴暴力→儿童攻击性 |
| 去个体化 | 匿名→攻击增加 |

## 四，减少攻击的方法

| 方法 | 说明 |
|------|------|
| **惩罚** | 惩罚可抑制攻击，但需及时、确定、一致 |
| **降低挫折** | 减少挫折感 |
| **减少线索** | 减少攻击相关环境线索 |
| **培养共情** | 培养对他人痛苦的感受 |
| **示范亲社会** | 通过榜样学习亲社会行为 |
| **自我控制训练** | 提高自我调节能力 |
| **认知重构** | 改变对挑衅的解读 |
