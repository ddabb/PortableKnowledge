## 一，沟通的基本要素

### 1.1 沟通模型

| 要素 | 说明 |
|------|------|
| 信息源 | 发送信息的人 |
| 编码 | 将想法转化为信息符号 |
| 通道 | 信息传递的媒介 |
| 解码 | 接收者理解信息 |
| 接收者 | 接收信息的人 |
| 反馈 | 接收者对信息的回应 |
| 噪声 | 干扰信息传递的因素 |

### 1.2 沟通类型

| 类型 | 定义 | 示例 |
|------|------|------|
| 言语沟通 | 使用语言符号 | 说话、写信 |
| 非言语沟通 | 不使用语言符号 | 表情、手势 |
| 人际沟通 | 两人或多人的直接交流 | 对话、会议 |
| 大众传播 | 通过媒体面向大众 | 电视、网络 |

## 二，言语沟通

### 2.1 有效言语沟通原则

| 原则 | 说明 |
|------|------|
| 清晰 | 用词准确、避免歧义 |
| 简洁 | 简洁明了 |
| 具体 | 提供具体信息 |
| 相关 | 紧扣主题 |
| 有礼貌 | 尊重对方 |

### 2.2 沟通风格

| 风格 | 特点 |
|------|------|
| 直接型 | 开门见山，直接表达 |
| 委婉型 | 间接表达，含蓄 |
| 分析型 | 注重数据和逻辑 |
| 个人型 | 注重情感和个人关系 |

## 三，非言语沟通

### 3.1 非言语沟通的渠道

| 渠道 | 内容 | 信息量 |
|------|------|--------|
| 面部表情 | 高兴、悲伤、惊讶等 | 55% |
| 身体姿势 | 站姿、坐姿、手势 | 20% |
| 目光接触 | 注视时长、注视模式 | 15% |
| 语音特征 | 语调、语速、音量 | 38%* |
| 空间距离 | 近距离vs远距离 | 10% |

*语音特征信息量包含在言语中

### 3.2 面部表情

| 要点 | 说明 |
|------|------|
| 基本情绪 | 高兴、悲伤、惊讶、恐惧、愤怒、厌恶 |
| 普遍性 | 跨文化基本一致（Ekman）|
| 微表情 | 短暂的、难以控制的面部运动 |

### 3.3 空间语言

| 距离类型 | 适用范围 |
|----------|---------|
| 亲密距离（0-45cm）| 亲密关系 |
| 个人距离（45-120cm）| 朋友 |
| 社会距离（1.2-3.5m）| 正式交往 |
| 公共距离（3.5m+）| 演讲 |

### 3.4 触摸

| 类型 | 说明 |
|------|------|
| 功能性-职业性触摸 | 医生检查 |
| 礼貌性触摸 | 握手 |
| 友谊性触摸 | 朋友间拍肩 |
| 情欲性触摸 | 亲密关系 |

## 四，沟通障碍

### 4.1 常见障碍

| 障碍类型 | 说明 |
|----------|------|
| 语义障碍 | 用词不当、理解差异 |
| 心理障碍 | 害羞、恐惧、偏见 |
| 物理障碍 | 噪音、环境干扰 |
| 文化障碍 | 文化差异导致误解 |
| 地位障碍 | 权力差异抑制表达 |

### 4.2 改善方法

| 方法 | 说明 |
|------|------|
| 积极倾听 | 全神贯注地听 |
| 反馈确认 | 复述对方内容确认理解 |
| 表达感受 | 用"我"开头的陈述 |
| 避免假设 | 不假设对方意图 |
| 尊重差异 | 承认和尊重差异 |
| 选择时机 | 选择适当的沟通时间和场合 |
