# 社会心理学：理解社会中的自我与他人

## 一、社会认知

### 定义

社会认知是指个体在社会环境中对他人、自己和社会现象的感知、理解、判断和推论的过程。

### 归因理论

| 理论 | 内容 |
|------|------|
| 海德的归因理论 | 内部归因（性格）vs外部归因（情境） |
| 韦纳的归因理论 | 归因三维度：稳定性、内外在、可控性 |
| 凯利的三维归因 | 共同性、一致性、特异性 |

**归因误差：**
- 基本归因错误：低估情境因素，高估个人因素
- 行动者-观察者效应：对自己的行为外部归因，对他人的行为内部归因
- 自利偏差：把成功归因自己，失败归因情境

### 印象形成

| 效应 | 说明 |
|------|------|
| 首因效应 | 第一印象影响后续判断 |
| 近因效应 | 最近的信息影响更大 |
| 晕轮效应 | 以偏概全 |
| 社会刻板印象 | 对群体的固定化认知 |

## 二、社会影响

### 从众

| 类型 | 特征 |
|------|------|
| 规范性影响 | 避免被拒绝，获得社会认可 |
| 信息性影响 | 参考他人行为作为信息来源 |

**影响从众的因素：**
- 群体规模：3-5人时从众显著增加
- 群体一致性：一致性越高从众越强
- 群体凝聚力：越团结越有影响力
- 地位高低：地位高者影响更大
- 文化差异：集体主义文化更易从众

### 服从

米尔格拉姆电击实验：65%的被试服从权威指示

**影响服从的因素：**
- 权威的直接性
- 权威的正当性
- 受害者的接近性
- 制度支持

### 社会促进与社会懈怠

| 现象 | 说明 |
|------|------|
| 社会促进 | 他人在场时简单任务表现更好 |
| 社会懈怠 | 群体中个人努力减少（搭便车） |

## 三、态度与态度改变

### 态度的ABC模型

| 成分 | 说明 |
|------|------|
| 认知成分 | 对事物的信念和看法 |
| 情感成分 | 情绪反应 |
| 行为成分 | 行为意向 |

### 说服与态度改变

| 因素 | 影响 |
|------|------|
| 信息来源可信度 | 专业性、可靠性、吸引力 |
| 信息本身特点 | 理性说服 vs 情感说服 |
| 接受者特点 | 已有态度、人格特征 |

### 认知失调理论

费斯廷格提出：当认知元素之间不一致时，会产生不适感，个体会通过改变态度或行为来减少失调。

## 四、人际关系

### 人际吸引的条件

| 条件 | 说明 |
|------|------|
| 熟悉性 | 曝光效应 |
| 相似性 | 物以类聚 |
| 互补性 | 需求互补 |
| 外貌吸引力 | 首因效应 |
| 互惠性 | 喜欢喜欢自己的人 |

### 亲密关系

**斯滕伯格的三角理论：**
- 激情：浪漫、兴奋
- 亲密：亲近、连接
- 承诺：决定维持关系

**依恋类型：**

| 类型 | 特征 |
|------|------|
| 安全型 | 信任他人，容易亲近 |
| 焦虑型 | 担心被抛弃 |
| 回避型 | 难以信任他人 |

## 五、群体心理

### 去个体化

群体中个体自我意识下降，行为更受群体规范支配。

**促进因素：**
- 匿名性
- 群体规模
- 分散责任

### 群体极化

讨论后群体观点比讨论前更极端。

### 群体思维

高凝聚力群体在决策时追求一致，忽视不同意见。

### 社会助长

他人在场会提高熟练任务的作业水平。

## 六、亲社会行为与攻击行为

### 亲社会行为

**理论解释：**
- 社会生物学：亲缘选择
- 社会学习：观察学习
- 社会交换：成本-收益分析

**影响因素：**
- 个性特征（移情能力）
- 情境因素（旁观者效应）
- 文化背景

### 攻击行为

| 理论 | 说明 |
|------|------|
| 本能论 | 弗洛伊德：死本能 |
| 挫折-攻击理论 | 挫折导致攻击 |
| 社会学习理论 | 观察习得攻击行为 |

**减少攻击的方法：**
- 惩罚（但要注意副作用）
- 学会非攻击性解决冲突
- 减少暴力媒体暴露

## 七、偏见与歧视

### 定义

| 概念 | 说明 |
|------|------|
| 偏见 | 对特定群体的态度倾向 |
| 歧视 | 基于偏见的负面行为 |
| 刻板印象 | 对群体的过度概括化认知 |

### 减少偏见的方法

- 接触假说：平等地位、共同目标、群体合作
- 重新归因：把偏见归因于情境而非个人
- 自我监测：提高对偏见的意识
