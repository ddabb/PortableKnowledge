## 第一部分：社会认知

### 1.1 社会认知的定义

社会认知 = 个体对社会信息的感知、编码、存储和加工

### 1.2 基本归因理论

| 理论 | 代表人物 | 核心观点 |
|------|----------|----------|
| 归因理论 | Heider | 内/外部归因 |
| 归因错误 | Jones & Harris | 基本归因错误 |
| 折扣原则 | Kelley | 多原因时弱化非主导原因 |
| 协变原理 | Kelley | 三维信息协变分析 |

### 1.3 基本归因错误

| 错误 | 定义 | 示例 |
|------|------|------|
| 基本归因错误 | 高估内部因素 | 他迟到是因为他不负责 |
| 行动者-观察者效应 | 自我外归因，他人内归因 | 我迟到是堵车，他迟到是不负责 |
| 自我服务偏差 | 成功内归因，失败外归因 | 考好是我努力，考差是题目难 |

### 1.4 归因维度

| 维度 | 内部归因 | 外部归因 |
|------|----------|----------|
| 稳定性 | 能力、努力 | 运气、任务难度 |
| 可控性 | 努力 | 运气、他人帮助 |

## 第二部分：社会影响

### 2.1 从众

**从众的定义：** 群体压力下，个体改变行为/信念以与群体一致

**从众的原因：**
| 原因 | 说明 |
|------|------|
| 信息性社会影响 | 想获取正确信息 |
| 规范性社会影响 | 想被接纳、被喜欢 |

**从众的影响因素：**

| 因素 | 促进从众 | 减少从众 |
|------|---------|----------|
| 群体特征 | 群体一致、凝聚力高 | 群体小、少数派 |
| 个人特征 | 自信低、服从型 | 自信高、专业 |
| 情境特征 | 公开反应 | 匿名 |

### 2.2 服从

**服从的定义：** 在权威或命令下改变行为

**经典实验：Milgram电击实验（1963）**

| 发现 | 说明 |
|------|------|
| 65%被试服从到最高电击 | 高服从率 |
| 接近权力权威服从更高 | 参与者>旁观者 |
| 接近受害者降低服从 | 远程命令服从更高 |

**服从的影响因素：**
| 因素 | 影响 |
|------|------|
| 命令者权威性 | 权威越高越服从 |
| 距离 | 接近命令者/受害者影响服从 |
| 机构支持 | 机构背书增加服从 |
| 群体支持 | 有反对者降低服从 |

### 2.3 顺从

**顺从的定义：** 为回应直接请求而改变行为

**增加顺从的策略：**

| 策略 | 说明 | 示例 |
|------|------|------|
| 登门槛效应 | 小请求→大请求 | 先借小再借大 |
| 留面子效应 | 大请求→小请求 | 先开高价再降价 |
| 稀缺原则 | 强调稀缺 | 限时优惠 |
| 互惠原则 | 礼尚往来 | 免费试用 |
| 权威原则 | 利用权威 | 名人代言 |

## 第三部分：社会关系

### 3.1 人际吸引

| 因素 | 说明 |
|------|------|
| 熟悉性 | 接触越多越喜欢 |
| 相似性 | 相似的人互相吸引 |
| 互补性 | 需求互补也吸引 |
| 外貌 | 长相吸引 |
| 能力 | 能力强但有小缺点更吸引 |

**吸引的回报理论：** 我们喜欢能带来回报的人

### 3.2 偏见与歧视

| 概念 | 定义 | 层面 |
|------|------|------|
| 刻板印象 | 对群体的概括化信念 | 认知 |
| 偏见 | 对群体的情感性态度 | 情感 |
| 歧视 | 对群体的不公平行为 | 行为 |

**偏见产生原因：**
| 原因 | 说明 |
|------|------|
| 社会化 | 从小习得 |
| 社会身份认同 | 群体内偏好 |
| 资源竞争 | 零和博弈 |
| 合理化 | 为偏见找理由 |

### 3.3 助人行为

**助人的原因：**

| 理论 | 说明 |
|------|------|
| 社会交换 | 助人为了回报 |
| 社会规范 | 责任规范、互惠规范 |
| 移情-利他假设 | 移情引发纯利他 |

**影响助人的因素：**

| 因素 | 说明 |
|------|------|
| 旁观者效应 | 旁观者越多，助人率越低 |
| 时间压力 | 匆忙时助人减少 |
| 相似性 | 相似的人优先获助 |
| 环境特征 | 偏僻环境助人减少 |

## 第四部分：群体心理

### 4.1 群体极化

| 现象 | 定义 |
|------|------|
| 群体极化 | 讨论后群体观点比讨论前更极端 |

**原因：**
- 信息性社会影响（听到更多支持论据）
- 规范性社会影响（想被喜欢，加剧立场）

### 4.2 群体思维

| 特征 | 说明 |
|------|------|
| 无懈可击的错觉 | 高估群体正确性 |
| 合理性 | 忽视道德/伦理 |
| 对群体外一致性 | 不接受异议 |
| 自我审查 | 不提反对意见 |
| 一致性错觉 | 沉默强化共识 |
| 自我任命的卫道士 | 阻止异见 |

### 4.3 社会懈怠

| 现象 | 定义 |
|------|------|
| 社会懈怠 | 群体中个人努力减少 |

**原因：** 个人贡献无法识别，责任分散

### 名词解释

- 从众：群体压力下改变行为/信念以与群体一致
- 服从：在权威命令下改变行为
- 偏见：对群体的负面评价和情感倾向
- 群体极化：群体讨论后观点比讨论前更极端
- 社会懈怠：群体中个人努力减少的现象

### 论述题模板

**试述Milgram服从实验及其启示：**
> 1. 实验：参与者被要求对学习者施加电击（最高450V），65%服从到最高电击
> 2. 原因：权威命令、渐进式要求、去个性化
> 3. 启示：普通人可能在权威下做出极端行为，需要培养独立思考能力
