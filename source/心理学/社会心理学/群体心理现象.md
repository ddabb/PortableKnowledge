## 一，群体极化

### 1.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 群体讨论后，倾向变得更极端 |
| 方向 | 更冒险或更保守 |

**例子：**
- 原来谨慎的人→更保守
- 原来激进的人→更冒险

### 1.2 原因

| 原因 | 说明 |
|------|------|
| **信息性社会影响** | 讨论中听到更多支持极端立场的理由 |
| **规范性社会影响** | 想被群体认可，表现得更极端 |

### 1.3 经典实验

| 研究者 | 实验内容 |
|--------|----------|
| Moscovici | 颜色判断实验，极端组更极端 |
| Stoner | 风险决策实验，群体比个人更冒险 |

## 二，群体思维

### 2.1 Janis定义

| 要点 | 说明 |
|------|------|
| 定义 | 高凝聚力群体中，为求一致而忽视现实方案的决策倾向 |
| 发生条件 | 群体压力、领导倾向 |

### 2.2 群体思维的表现

| 表现 | 说明 |
|------|------|
| 错觉统一 | 认为群体一致，无不同意见 |
| 合理化 | 为已有方案找理由 |
| 从众压力 | 压制异议 |
| 自我审查 | 不说出异议 |
| 思想保镖 | 不让领导听到反对意见 |
| 一致性错觉 | 认为无人反对 |

### 2.3 克服方法

| 方法 | 说明 |
|------|------|
| 领导保持公正 | 不先表态 |
| 鼓励批评 | 欢迎不同意见 |
| 设置反对派 | 分组讨论 |
| 延后决定 | 避免仓促决策 |
| 专家评估 | 引入外部专家 |

## 三，去个体化

### 3.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 群体中个体丧失自我意识和责任感 |
| 表现 | 平时不会做的事，群体中会做 |

### 3.2 原因

| 原因 | 说明 |
|------|------|
| 匿名性 | 群体中个体身份被掩盖 |
| 唤醒状态 | 群体引起生理唤醒 |
| 责任分散 | 认为群体共同负责 |

### 3.3 经典实验

| 实验 | 研究者 | 发现 |
|------|--------|------|
| 穿异装实验 | Zimbardo | 匿名使攻击性增加 |
| 迪斯科球迷骚乱 | Diener | 高唤醒+匿名→破坏行为 |

### 3.4 与群体极化的区别

| 对比 | 群体极化 | 去个体化 |
|------|----------|----------|
| 核心 | 讨论使观点更极端 | 群体中丧失自我 |
| 表现 | 观点更偏向原有方向 | 平时行为规范消失 |
| 原因 | 信息影响+规范影响 | 匿名+唤醒+责任分散 |

## 四，社会懈怠

### 4.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 群体中个人努力程度降低 |
| 原因 | 个人贡献被淹没，责任分散 |

### 4.2 经典实验

| 实验 | 研究者 | 结果 |
|------|--------|------|
| 拔河实验 | Ringelmann | 个人拉力<群体拉力和 |
| 鼓掌实验 | Ingham | 实际鼓掌声音<理论值 |

### 4.3 克服方法

| 方法 | 说明 |
|------|------|
| 明确责任 | 每人负责具体任务 |
| 增加评估 | 公开每个人的贡献 |
| 提高参与感 | 让成员感到自己是独特的 |
