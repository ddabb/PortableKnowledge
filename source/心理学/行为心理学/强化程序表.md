## 一，基本概念

### 1.1 强化类型

| 类型 | 定义 | 示例 |
|------|------|------|
| 连续强化 | 每次行为都强化 | 每按一次杠杆都给食物 |
| 间隔强化 | 不是每次行为都强化 | 抽查式考试 |

---

## 二，四种强化程序表

### 2.1 概览

| 程序表 | 简称 | 定义 | 行为特点 |
|--------|------|------|---------|
| 固定比率 | FR | 固定次数后强化 | 高而稳定，暂停后恢复快 |
| 变动比率 | VR | 不固定次数后强化 | 最高、最难消退 |
| 固定时距 | FI | 固定时间后强化 | 期末考试效应，速度递减 |
| 变动时距 | VI | 不固定时间后强化 | 最稳定，最难消退 |

### 2.2 固定比率（FR）

| 要点 | 说明 |
|------|------|
| 定义 | 每隔固定次数强化一次 |
| 特点 | 高而稳定的行为频率 |
| 弱点 | 比率结束后频率下降（暂停效应）|
| 例子 | 计件工资（做10件发一次工资）|

### 2.3 变动比率（VR）

| 要点 | 说明 |
|------|------|
| 定义 | 强化次数随机变化 |
| 特点 | 最高的行为频率 |
| 优势 | 极难消退 |
| 例子 | 老虎机（赌博）|

### 2.4 固定时距（FI）

| 要点 | 说明 |
|------|------|
| 定义 | 固定时间间隔后强化 |
| 特点 | 期末考试效应 |
| 行为表现 | 接近强化时间时行为增加 |
| 例子 | 每月发工资 |

### 2.5 变动时距（VI）

| 要点 | 说明 |
|------|------|
| 定义 | 变化的时间间隔后强化 |
| 特点 | 最稳定的低频率行为 |
| 优势 | 难以消退 |
| 例子 | 不定期的抽查考试 |

---

## 三，四种程序表的对比

### 3.1 行为频率排序

```
最高 ← 变动比率 > 固定比率 > 变动时距 > 固定时距 → 最低
```

### 3.2 消退难度排序

```
最难 ← 变动比率 > 变动时距 > 固定比率 > 固定时距 → 最易
```

### 3.2 对比表

| 程序表 | 频率 | 消退速度 | 典型场景 |
|--------|------|---------|---------|
| FR | 高 | 中等 | 计件工资 |
| VR | 最高 | 最慢 | 赌博、老虎机 |
| FI | 中等偏低 | 中等 | 月薪 |
| VI | 中等 | 最慢 | 不定期抽查 |

## 四，在教育中的应用

| 程序表 | 教育应用 |
|--------|---------|
| FR | 频繁的小测验 |
| VR | 不固定的小测验 |
| FI | 期中期末考试 |
| VI | 不定期抽查 |
| 连续强化 | 初期学习新技能 |
| 间隔强化 | 保持和迁移 |
