## 一，巴甫洛夫的经典实验

### 1.1 实验装置

```
狗 → 分泌唾液（自然反应）
```

### 1.2 实验过程

| 阶段 | 刺激 | 结果 |
|------|------|------|
| 实验前 | 铃声 → 无反应 | 中性刺激 |
| 实验中 | 铃声 + 肉 → 分泌唾液 | 形成联结 |
| 实验后 | 铃声（单独）→ 分泌唾液 | 条件反射形成 |

## 二，基本概念

### 2.1 四种反射要素

| 要素 | 全称 | 定义 | 在实验中 |
|------|------|------|--------|
| **UCS** | 无条件刺激 | 天然引起反应的刺激 | 肉 |
| **UCR** | 无条件反应 | UCS引起的自然反应 | 分泌唾液 |
| **CS** | 条件刺激 | 中性刺激与UCS反复配对后 | 铃声 |
| **CR** | 条件反应 | CS单独引起的反应 | 听到铃声分泌唾液 |

### 2.2 关系图

```
无条件刺激（UCS）→ 无条件反应（UCR）
     ↑
     └─────→ 条件刺激（CS）→ 条件反应（CR）
```

## 三，经典条件反射的规律

### 3.1 习得

| 要点 | 说明 |
|------|------|
| 定义 | CS与UCS反复配对 |
| 条件 | 需多次配对 |
| 注意 | CS应先于或同时于UCS出现 |

### 3.2 消退

| 要点 | 说明 |
|------|------|
| 定义 | CS出现后不给UCS强化 |
| 过程 | CR逐渐减弱直至消失 |
| 关键 | 无强化才消退 |

### 3.3 自然恢复

| 要点 | 说明 |
|------|------|
| 定义 | 消退后休息一段时间，CR重新出现 |
| 意义 | 消退≠完全消失 |

### 3.4 泛化

| 要点 | 说明 |
|------|------|
| 定义 | 对类似CS也产生CR |
| 示例 | 铃声→CR → 响板声也引发CR |
| 规律 | 相似性越高，泛化越强 |

### 3.5 分化

| 要点 | 说明 |
|------|------|
| 定义 | 只对特定CS产生CR |
| 方法 | 选择性强化特定CS |
| 相反 | 消退泛化 |
