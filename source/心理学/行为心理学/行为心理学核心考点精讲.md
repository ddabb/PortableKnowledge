## 第一部分：经典条件反射

### 1.1 巴甫洛夫的实验

**实验情境：**
- 狗 → 铃声（CS）+ 肉（UCS）→ 流唾液（UCR/CR）

**基本概念：**

| 概念 | 定义 | 在实验中 |
|------|------|---------|
| 无条件刺激（UCS）| 天然引起反应的刺激 | 肉 |
| 无条件反应（UCR）| 无条件刺激引起的自然反应 | 分泌唾液 |
| 条件刺激（CS）| 中性刺激与UCS配对后 | 铃声 |
| 条件反应（CR）| CS单独引起的反应 | 听到铃声分泌唾液 |

### 1.2 经典条件反射的规律

| 规律 | 定义 | 示例 |
|------|------|------|
| 习得 | CS与UCS反复配对 | 铃声+肉多次 |
| 消退 | CS单独出现无强化 | 只给铃声不给肉 |
| 自然恢复 | 休息后再次出现CR | 休息后再给铃声 |
| 泛化 | 对类似刺激也产生CR | 铃声→响板 |
| 分化 | 只对特定CS产生CR | 只对原铃声 |

### 1.3 经典条件反射的应用

| 领域 | 应用 |
|------|------|
| 心理治疗 | 系统脱敏（对抗条件反射）|
| 医学 | 条件化免疫反应 |
| 教育 | 建立学习习惯 |
| 广告 | 品牌与愉悦感受配对 |

## 第二部分：操作性条件反射

### 2.1 桑代克的实验

**试误学习（箱子实验）：**
- 猫放入迷笼
- 偶然碰到踏板逃出
- 多次后学会直接踏板
- **效果率：满意（强化）→行为增加**

### 2.2 斯金纳的操作性条件反射

**实验：**
- 老鼠按杠杆→获得食物（强化）

**基本概念：**

| 概念 | 定义 | 示例 |
|------|------|------|
| 强化物 | 增加行为频率的刺激 | 食物、赞扬 |
| 惩罚物 | 减少行为频率的刺激 | 批评、疼痛 |
| 正强化 | 呈现愉快刺激增加行为 | 奖励小红花 |
| 负强化 | 移除厌恶刺激增加行为 | 做完作业免除家务 |
| 正惩罚 | 呈现厌恶刺激减少行为 | 迟到罚站 |
| 负惩罚 | 移除愉快刺激减少行为 | 取消玩游戏 |
| 消退 | 停止强化减少行为 | 不理睬发脾气 |

### 2.3 强化的程序

| 程序 | 定义 | 效果 |
|------|------|------|
| 连续强化 | 每次行为都强化 | 快速建立，消退快 |
| 间隔强化 | 按时间间隔强化 | 消退慢 |
| 比率强化 | 按次数间隔强化 | 效率高 |
| 固定比率 | 固定次数后强化 | 稳定高反应 |
| 变动比率 | 不固定次数强化 | 最强，最难消退 |
| 固定时距 | 固定时间后强化 | 期末考试效应 |
| 变动时距 | 不固定时间后强化 | 最稳定 |

### 2.4 强化与惩罚的比较

| 类型 | 增加行为 | 减少行为 |
|------|----------|----------|
| 强化 | ✅ 正强化 | ✅ 负强化 |
| 惩罚 | ❌ 正惩罚 | ❌ 负惩罚 |

**惩罚的注意事项：**
- 惩罚要及时
- 一致性（每次都惩罚）
- 配合强化（指出正确行为）
- 注意副作用（可能产生恐惧）

## 第三部分：社会学习理论

### 3.1 班杜拉的观察学习

**观察学习的四个过程：**

| 过程 | 定义 |
|------|------|
| 注意过程 | 选择性观察示范 |
| 保持过程 | 将观察转化为表象/言语 |
| 再现过程 | 将符号转化为行为 |
| 动机过程 | 有强化动机才会行动 |

### 3.2 观察学习的类型

| 类型 | 说明 | 结果 |
|------|------|------|
| 直接获得 | 亲历体验 | 直接经验 |
| 间接获得 | 观察他人 | 替代经验 |

### 3.3 强化的类型

| 类型 | 说明 |
|------|------|
| 直接强化 | 自己做自己获益 |
| 替代强化 | 看别人做别人获益 |
| 自我强化 | 自己设定标准自我评估 |

### 辨析题模板

**"强化和惩罚都能减少行为"：**
> 此说法错误。
> 强化（无论正负）的作用是**增加**行为频率；
> 惩罚（无论正负）的作用是**减少**行为频率。
> 正强化增加行为，负惩罚减少行为，两者作用方向不同。

### 论述题模板

**试述经典条件反射与操作性条件反射的区别：**
> 1. 经典条件反射：先有刺激（CS+UCS），后有反应（CR）
>    适用于解释应激反应、情绪反应
> 2. 操作性条件反射：先有行为，后有强化（结果决定行为）
>    适用于解释操作性行为、技能学习
> 3. 两者区别：反应类型不同、强化来源不同
