## 一，元认知的定义

### 1.1 Flavell（1979）定义

| 要点 | 说明 |
|------|------|
| 定义 | 对自己认知过程的知识和调节 |
| 核心 | "关于思考的思考" |
| 提出者 | Flavell |

### 1.2 元认知的构成

```
元认知
├── 元认知知识
│   ├── 主体知识（我对学习的了解）
│   ├── 任务知识（任务难度的了解）
│   └── 策略知识（学习策略的了解）
├── 元认知体验
│   └── 伴随认知活动的意识体验
└── 元认知调节
    ├── 计划
    ├── 监控
    └── 评估
```

## 二，元认知知识

### 2.1 三类知识

| 类型 | 定义 | 示例 |
|------|------|------|
| **主体知识** | 关于自己认知能力 | "我的记忆力不太好" |
| **任务知识** | 关于任务特点 | "数学比语文难" |
| **策略知识** | 关于策略有效性 | "画图有助于理解" |

### 2.2 主体知识的发展

| 年龄 | 特点 |
|------|------|
| 学前 | 元认知知识极少 |
| 小学 | 逐渐了解自己的认知能力 |
| 中学+ | 比较准确地评估自己的认知水平 |

## 三，元认知监控

### 3.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 在认知活动进行过程中对其进行监控 |
| 核心 | 知道自己是否在正确轨道上 |

### 3.2 监控的内容

| 内容 | 说明 |
|------|------|
| 理解监控 | 是否真正理解？ |
| 提取监控 | 能否回忆起来？ |
| 时间监控 | 时间是否足够？ |

---

## 四，元认知调节

### 4.1 三大环节

| 环节 | 定义 | 示例 |
|------|------|------|
| **计划** | 制定学习策略和时间安排 | 制定复习计划 |
| **监控** | 评估学习进展 | 检查是否理解 |
| **评估** | 评估效果和调整策略 | 反思这次学习效果 |

### 4.2 常见元认知策略

| 策略 | 说明 |
|------|------|
| 自我提问 | "我真的理解了吗？" |
| 自我解释 | 学习时出声解释自己 |
| 监控理解 | 边读边检查理解程度 |
| 总结 | 读完后自己总结要点 |

## 五，元认知在学习中的作用

### 5.1 优秀学习者的特征

| 特征 | 说明 |
|------|------|
| 知道自己不知道什么 | 准确的知识边界 |
| 会选择策略 | 根据任务调整方法 |
| 会监控自己的理解 | 知道是否理解 |
| 会调整策略 | 理解失败时换方法 |

### 5.2 元认知培训

| 方法 | 说明 |
|------|------|
| 出声思维 | 教师示范思维过程 |
| 自我提问训练 | 教会学生自我提问 |
| 反思日志 | 定期反思学习过程 |
