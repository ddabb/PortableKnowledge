## 一，判断的启发法

### 1.1 可得性启发

| 要点 | 说明 |
|------|------|
| 定义 | 用容易想到的信息来判断事件的可能性 |
| 偏差 | 媒体曝光多的事件→高估发生率 |
| 例子 | 觉得飞机比汽车危险（实际上汽车更危险）|

### 1.2 代表性启发

| 要点 | 说明 |
|------|------|
| 定义 | 用"A像不像B的典型成员"来判断 |
| 偏差 | 忽视基础概率 |
| 例子 | "小王爱看书，很害羞，他更可能是？"<br>→ 多数人选"图书管理员"而非"农民" |

### 1.3 锚定与调整启发

| 要点 | 说明 |
|------|------|
| 定义 | 以最初信息（锚）为起点调整判断 |
| 偏差 | 调整不足，仍接近锚点 |
| 例子 | 先看价格再判断价值，价格影响判断 |

---

## 二，确认偏差

| 要点 | 说明 |
|------|------|
| 定义 | 倾向于寻找支持自己观点的信息 |
| 表现 | 忽视反驳证据 |
| 影响 | 固化错误信念 |

**例子：**
- 相信某只股票会涨→只关注利好消息
- 讨厌某个人→只注意其缺点

---

## 三，后见之明偏差

| 要点 | 说明 |
|------|------|
| 定义 | 事后认为结果"早就预料到" |
| 别称 | "马后炮"偏差 |
| 影响 | 高估事前预测的准确性 |

**例子：**
- 考试后："我就知道会考这个！"
- 股价下跌后："早就该卖掉！"

---

## 四，过度自信

| 要点 | 说明 |
|------|------|
| 定义 | 过高估计自己的判断准确性 |
| 来源 | 确认偏差+选择性搜索 |
| 领域差异 | 专业领域比日常判断更易过度自信 |

---

## 五，框架效应

| 要点 | 说明 |
|------|------|
| 定义 | 表述方式不同导致不同决策 |
| 例子 | "存活率90%"vs"死亡率10%" |

---

## 六，事后偏见与锚定效应的区别

| 偏差 | 核心 | 时间 |
|------|------|------|
| 锚定效应 | 初始值影响后续判断 | 判断前 |
| 后见之明 | 事后认为可预测 | 判断后 |
