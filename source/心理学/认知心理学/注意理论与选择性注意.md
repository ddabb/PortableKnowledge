## 一，注意的定义

### 1.1 定义

| 要点 | 说明 |
|------|------|
| 定义 | 对信息的选择性加工 |
| 核心 | 有限的认知资源→选择性 |

### 1.2 注意的类型

| 类型 | 定义 | 示例 |
|------|------|------|
| **选择性注意** | 选择性关注某些信息 | 鸡尾酒会效应 |
| **分配性注意** | 同时关注多个任务 | 边开车边说话 |
| **持续性注意** | 长时间保持注意 | 监控工作 |

## 二，选择性注意理论

### 2.1 过滤器理论（Broadbent, 1958）

| 要点 | 说明 |
|------|------|
| 核心 | 感觉记忆→过滤器→工作记忆 |
| 过滤器作用 | 选择性通过部分信息 |
| 选择依据 | 物理特征（声调、位置）|

### 2.2 衰减理论（Trevors, 1963）

| 要点 | 说明 |
|------|------|
| 核心 | 所有信息都进入，但未注意的被衰减 |
| 衰减内容 | 非注意信息的强度下降 |
| 关键信息 | 被衰减但仍可被识别 |

### 2.3 晚期选择理论（Deutsch & Deutsch, 1963）

| 要点 | 说明 |
|------|------|
| 核心 | 所有信息都进入晚期再选择 |
| 选择依据 | 重要性而非物理特征 |
| 观点 | 认知资源决定加工深度 |

### 2.4 对比

| 理论 | 选择阶段 | 选择依据 |
|------|---------|---------|
| 过滤器理论 | 早期 | 物理特征 |
| 衰减理论 | 中期 | 强度衰减 |
| 晚期选择 | 晚期 | 重要性 |

## 三，注意的资源分配理论

### 3.1 Kahneman资源理论

| 要点 | 说明 |
|------|------|
| 核心 | 注意是一种认知资源池 |
| 资源总量 | 有限但可变 |
| 分配原则 | 根据任务需求和个体状态 |

**影响资源分配的因素：**

| 因素 | 影响 |
|------|------|
| 任务难度 | 难度↑→资源↑ |
| 个人状态 | 疲劳→资源少 |
| 自动化程度 | 自动化→资源少 |

### 3.2 认知负荷

| 类型 | 定义 |
|------|------|
| 内在认知负荷 | 由任务本身的复杂性决定 |
| 外在认知负荷 | 由任务呈现方式决定 |
| 关联认知负荷 | 与已有知识结构建立联系 |

## 四，注意分配

### 4.1 单双作业范式

| 任务 | 结果 |
|------|------|
| 两个简单任务 | 可同时进行 |
| 两个复杂任务 | 互相干扰 |

### 4.2 自动化

| 要点 | 说明 |
|------|------|
| 定义 | 技能达到自动化后几乎不消耗资源 |
| 例子 | 走路、开车（熟练后）|
| 培养 | 大量练习 |
