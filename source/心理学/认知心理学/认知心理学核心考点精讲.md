## 第一部分：认知概述

### 1.1 认知的定义

认知 = 信息加工的过程，包括感觉输入的编码、存储和提取

### 1.2 认知心理学的研究取向

| 取向 | 代表理论 | 核心观点 |
|------|----------|----------|
| 认知取向 | 信息加工理论 | 心理是计算机式的符号操作系统 |
| 连接取向 | 神经网络理论 | 神经元联结网络 |
| 生态取向 | 情境认知理论 | 认知嵌入在环境中 |

## 第三部分：记忆模型

### 3.1 信息加工模型（Atkinson & Shiffrin, 1968）

```
感觉记忆 → 短时记忆 → 长时记忆
    ↓            ↓           ↓
  衰减编码    工作记忆     精细编码
```

### 3.2 记忆的三级加工

| 阶段 | 容量 | 时间 | 编码方式 |
|------|------|------|----------|
| 感觉记忆 | 大 | <1秒 | 视觉/听觉编码 |
| 短时记忆 | 7±2组块 | 1分钟内 | 听觉/视觉编码 |
| 长时记忆 | 无限 | 1分钟-终身 | 语义编码 |

### 3.3 工作记忆模型（Baddeley, 1974）

```
          中央执行系统
              ↓
    ┌─────────┼─────────┐
    ↓         ↓         ↓
语音环路  视觉空间画板  情景缓冲器
```

| 成分 | 功能 |
|------|------|
| 中央执行 | 注意控制，资源分配 |
| 语音环路 | 言语存储与复述 |
| 视空画板 | 视觉空间信息存储 |
| 情景缓冲器 | 整合多通道信息 |

### 3.4 长时记忆的类型

| 分类标准 | 类型 | 说明 |
|---------|------|------|
| 性质 | 陈述性记忆 | 能说出来 |
| | 程序性记忆 | 会做不会说 |
| 内容 | 情景记忆 | 个人经历 |
| | 语义记忆 | 概念事实 |

### 3.5 内隐记忆与外显记忆

| 类型 | 定义 | 特点 |
|------|------|------|
| 外显记忆 | 有意识提取 | 需要努力 |
| 内隐记忆 | 无意识提取 | 不需努力 |

## 第六部分：推理

### 6.1 推理的种类

| 类型 | 定义 | 示例 |
|------|------|------|
| 演绎推理 | 从一般到特殊 | 三段论 |
| 归纳推理 | 从特殊到一般 | 概括规律 |
| 概率推理 | 概率判断 | 天气预报 |

### 6.2 三段论推理

**三段论结构：**
```
大前提：所有M是P
小前提：所有S是M
结论：  所有S是P
```

**常见错误：**
| 错误 | 示例 |
|------|------|
| 气氛效应 | 更多肯定前提→肯定结论 |
| 换位不换质 | 偷换主谓关系 |

### 6.3 概率推理

**基本概率法则：**

| 法则 | 公式 |
|------|------|
| 加法法则 | P(A或B) = P(A) + P(B) - P(AB) |
| 乘法法则 | P(A且B) = P(A)×P(B|A) |
| 贝叶斯定理 | 后验概率 = 似然比 × 先验概率 |

## 第七部分：决策

### 7.1 决策框架

| 框架 | 说明 |
|------|------|
| 确定性决策 | 已知结果 |
| 风险性决策 | 知道概率 |
| 不确定性决策 | 不知道概率 |

### 7.2 期望效用理论

```
EU = Σ P(i) × U(i)

EU = 期望效用
P(i) = 结果i的概率
U(i) = 结果i的效用
```

### 7.3 行为决策的偏差

| 偏差 | 定义 | 示例 |
|------|------|------|
| 确定性效应 | 高确定性权重过高 | 选95%赢1000 vs 100%赢900 |
| 反射效应 | 损失域风险寻求 | 亏损时赌一把 |
| 锚定效应 | 初始值影响判断 | 房价锚定 |
| 框架效应 | 表述方式影响 | 存活率 vs 死亡率 |
