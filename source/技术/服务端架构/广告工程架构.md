# 广告工程架构

## 定义

广告工程架构是指设计能够支持广告投放、竞价、展示、计费、效果分析等全流程的系统架构。广告系统通常涉及广告主、媒体方、用户三方，是一个典型的双边市场。

广告工程架构的核心目标是：提高广告投放效率、优化广告效果、支持高并发访问、保证计费准确性。

## 核心概念

### 1. 广告投放（Ad Vertising Delivery）

广告投放是指广告主通过广告平台，将广告展示给目标用户的过程。广告投放通常包括：广告计划创建、广告创意设计、广告定向设置、广告出价策略等。

### 2. 竞价（Bidding）与扣费（Charging）

竞价是指多个广告主对同一广告位进行出价竞争，平台根据出价、广告质量等因素决定谁能获得广告位。常见的竞价策略包括：GFP（Generalized First Price）、GSP（Generalized Second Price）、VCG（Vickrey-Clarke-Groves）等。

扣费是指当用户触发广告计费动作（如点击、展示、转化）时，平台从广告主账户扣除相应费用的过程。常见的计费模式包括：CPM（Cost Per Mille，按展示付费）、CPC（Cost Per Click，按点击付费）、CPA（Cost Per Action，按转化付费）等。

### 3. 广告定向（Ad Targeting）

广告定向是指根据用户的属性、行为、兴趣等信息，将广告展示给最有可能感兴趣的用户。常见的定向方式包括：地域定向、人群定向、兴趣定向、行为定向、相似人群扩展（Look-alike）等。

### 4. 广告效果衡量（Ad Performance Measurement）

广告效果衡量是指通过一系列指标（如曝光量、点击率、转化率、ROI 等）评估广告投放效果的过程。广告效果衡量是优化广告投放策略的重要依据。

## 详细内容

### 广告系统架构设计

一个典型的广告系统通常包含以下子系统：

1. **广告主平台**：负责广告主账户管理、广告计划创建、广告创意上传、广告投放配置等。
2. **媒体方平台**：负责媒体方账户管理、广告位管理、广告代码生成、收益报表等。
3. **广告检索系统**：负责根据用户画像和广告定向条件，从海量广告库中检索出符合条件的广告。
4. **广告竞价系统**：负责根据出价、广告质量等因素，对检索出的广告进行竞价排序。
5. **广告投放系统**：负责将竞价胜出的广告投放到媒体的广告位上。
6. **广告计费系统**：负责记录广告曝光、点击、转化等计费事件，并从广告主账户扣除相应费用。
7. **广告效果分析系统**：负责收集广告投放数据，分析广告效果，生成报表和可视化图表。

### 广告系统关键技术

1. **倒排索引**：使用倒排索引（Inverted Index）提高广告检索效率，支持复杂的定向条件过滤。
2. **实时竞价（RTB）**：通过实时竞价协议（如 OpenRTB），支持在 100ms 内完成竞价决策。
3. **分布式计算**：使用分布式计算框架（如 Spark、Flink）处理海量广告日志，生成实时报表。
4. **机器学习**：使用机器学习模型（如 CTR 预估、CVR 预估）优化广告投放效果。
5. **计费一致性**：使用分布式事务或最终一致性方案，保证计费准确性，避免资损。

### 广告系统优化策略

1. **提高广告相关性**：通过优化 CTR 预估模型，提高广告与用户兴趣的相关性，提高点击率。
2. **优化出价策略**：通过智能出价（如 oCPC、oCPM），自动优化出价策略，提高 ROI。
3. **减少广告欺诈**：通过反作弊系统（如识别虚假点击、虚假转化），减少广告欺诈，保护广告主利益。
4. **提高系统性能**：通过缓存、异步处理、并行计算等手段，提高广告检索和竞价速度，降低延迟。

## 示例/应用场景

### 搜索引擎广告系统架构

一个典型的搜索引擎广告系统可能采用以下架构：

1. **用户搜索**：用户在搜索引擎输入查询词，搜索引擎返回自然搜索结果。
2. **广告检索**：广告检索系统根据查询词，从广告库中检索出相关的广告。
3. **广告竞价**：广告竞价系统根据出价、质量得分等因素，对检索出的广告进行竞价排序。
4. **广告投放**：广告投放系统将竞价胜出的广告投放到搜索结果页的广告位上。
5. **广告计费**：当用户点击广告时，广告计费系统从广告主账户扣除相应费用（CPC 模式）。

### 社交网络广告系统架构

一个典型的社交网络广告系统可能采用以下架构：

1. **用户浏览**：用户在社交网络浏览动态，系统记录用户行为（如点赞、评论、分享、点击）。
2. **用户画像**：用户画像系统根据用户的属性、行为、兴趣等信息，生成用户画像。
3. **广告检索**：广告检索系统根据用户画像和广告定向条件，从广告库中检索出符合条件的广告。
4. **广告竞价**：广告竞价系统根据出价、广告质量等因素，对检索出的广告进行竞价排序。
5. **广告投放**：广告投放系统将竞价胜出的广告投放到用户的动态流中。
6. **广告计费**：当用户点击广告或完成转化（如安装 APP、填写表单）时，广告计费系统从广告主账户扣除相应费用（CPC 或 CPA 模式）。

## 【对应领域考点】

1. **广告系统架构**：广告主平台、媒体方平台、广告检索、广告竞价、广告投放、广告计费、广告效果分析
2. **竞价策略**：GFP、GSP、VCG 的原理、优缺点、应用场景
3. **计费模式**：CPM、CPC、CPA 的原理、计算公式、适用场景
4. **广告定向技术**：地域定向、人群定向、兴趣定向、行为定向、Look-alike 的原理、实现方式
5. **广告效果衡量**：曝光量、点击率、转化率、ROI 的计算公式、优化方法

## 最佳实践

1. **保证计费准确性**：计费系统是广告系统的核心，必须保证计费准确性，避免资损。
2. **优化广告相关性**：通过优化 CTR 预估模型，提高广告与用户兴趣的相关性，提高用户体验和广告效果。
3. **防范广告欺诈**：建立反作弊系统，识别虚假点击、虚假转化等欺诈行为，保护广告主利益。
4. **支持灵活出价**：支持多种出价策略（如手动出价、智能出价），满足不同广告主的需求。
5. **提供详细报表**：提供详细的广告效果报表（如曝光量、点击率、转化率、ROI 等），帮助广告主优化投放策略。

## 【常见错误】

1. **计费不准确**：计费系统有 bug，导致多扣或少扣广告主费用，引发客诉或资损。
2. **广告相关性差**：CTR 预估模型不准确，导致展示的广告与用户兴趣不相关，降低用户体验和广告效果。
3. **忽视广告欺诈**：没有反作弊系统，被黑产刷爆，导致广告主损失。
4. **系统性能低**：广告检索和竞价速度慢，导致广告投放延迟高，影响用户体验。
5. **报表不详细**：广告效果报表不详细，广告主无法优化投放策略，降低广告主满意度。

## 总结

广告工程架构是互联网广告的核心技术，需要综合考虑广告投放、竞价、展示、计费、效果分析等多个方面。

关键要点：
1. 广告投放、竞价与扣费、广告定向、广告效果衡量是四大核心概念
2. 广告主平台、媒体方平台、广告检索、广告竞价、广告投放、广告计费、广告效果分析是七大子系统
3. 倒排索引、实时竞价、分布式计算、机器学习、计费一致性是五大关键技术
4. 保证计费准确性、优化广告相关性、防范广告欺诈、支持灵活出价、提供详细报表是最佳实践
5. 避免计费不准确、广告相关性差、忽视广告欺诈、系统性能低、报表不详细等常见错误

广告工程架构不是一成不变的，需要随着业务发展、技术进步不断迭代优化。只有不断实践、不断反思，才能设计出真正优秀的广告工程架构。
