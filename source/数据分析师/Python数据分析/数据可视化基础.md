# 数据可视化基础

## 定义

数据可视化（Data Visualization）是指通过图表、图形等视觉方式展示数据，帮助理解数据特征、发现规律、传达洞察。

对于数据分析师而言，数据可视化是**探索性数据分析（EDA）**和**结果展示**的重要工具。

Python中两个核心可视化库：
1. **Matplotlib**：基础绘图库，灵活但语法较繁琐
2. **Seaborn**：基于Matplotlib的高级库，语法简洁，默认样式美观

---

## 核心概念

### 1. 图表类型选择

| 分析目标 | 推荐图表类型 |
|----------|--------------|
| 展示趋势（随时间变化） | 折线图（Line Plot） |
| 比较各类别数值 | 柱状图（Bar Plot） |
| 展示组成部分占比 | 饼图（Pie Chart）、堆叠柱状图 |
| 展示分布 | 直方图（Histogram）、箱线图（Box Plot）、小提琴图（Violin Plot） |
| 展示关系 | 散点图（Scatter Plot）、成对关系图（Pair Plot） |
| 展示地理分布 | 地图（Map） |
| 展示流程 | 桑基图（Sankey Diagram） |

### 2. Matplotlib 基本结构

```python
import matplotlib.pyplot as plt

# 创建画布和子图
fig, ax = plt.subplots()

# 绘制图形
ax.plot(x, y)

# 设置标题、标签
ax.set_title('标题')
ax.set_xlabel('X轴标签')
ax.set_ylabel('Y轴标签')

# 显示图形
plt.show()
```

### 3. Seaborn 基本结构

```python
import seaborn as sns
import matplotlib.pyplot as plt

# 设置样式
sns.set_style('whitegrid')

# 绘制图形
sns.lineplot(data=df, x='x', y='y')

# 显示图形
plt.show()
```

## 详细内容

### 一、Matplotlib 基础

#### 1.1 折线图（Line Plot）

**用途**：展示趋势（随时间变化）

```python
import matplotlib.pyplot as plt
import pandas as pd

# 示例数据
df = pd.DataFrame({
    'month': ['Jan', 'Feb', 'Mar', 'Apr', 'May'],
    'sales': [100, 150, 200, 180, 250]
})

# 绘制折线图
plt.figure(figsize=(10, 6))
plt.plot(df['month'], df['sales'], marker='o')
plt.title('Monthly Sales Trend')
plt.xlabel('Month')
plt.ylabel('Sales')
plt.grid(True)
plt.show()
```

#### 1.2 柱状图（Bar Plot）

**用途**：比较各类别数值

```python
# 绘制柱状图
plt.figure(figsize=(10, 6))
plt.bar(df['month'], df['sales'])
plt.title('Monthly Sales')
plt.xlabel('Month')
plt.ylabel('Sales')
plt.show()
```

#### 1.3 直方图（Histogram）

**用途**：展示数值变量的分布

```python
# 示例数据
import numpy as np
data = np.random.normal(0, 1, 1000)

# 绘制直方图
plt.figure(figsize=(10, 6))
plt.hist(data, bins=30, edgecolor='black')
plt.title('Distribution of Data')
plt.xlabel('Value')
plt.ylabel('Frequency')
plt.show()
```

#### 1.4 散点图（Scatter Plot）

**用途**：展示两个数值变量之间的关系

```python
# 示例数据
x = np.random.rand(100)
y = 2 * x + np.random.rand(100) * 0.5

# 绘制散点图
plt.figure(figsize=(10, 6))
plt.scatter(x, y, alpha=0.6)
plt.title('Scatter Plot')
plt.xlabel('X')
plt.ylabel('Y')
plt.show()
```

### 二、Seaborn 基础

#### 2.1 折线图（Line Plot）

```python
import seaborn as sns
import matplotlib.pyplot as plt

# 示例数据
df = pd.DataFrame({
    'month': ['Jan', 'Feb', 'Mar', 'Apr', 'May'],
    'sales': [100, 150, 200, 180, 250]
})

# 绘制折线图
sns.lineplot(data=df, x='month', y='sales', marker='o')
plt.title('Monthly Sales Trend')
plt.show()
```

#### 2.2 柱状图（Bar Plot）

```python
# 绘制柱状图
sns.barplot(data=df, x='month', y='sales')
plt.title('Monthly Sales')
plt.show()
```

#### 2.3 直方图（Histogram）和密度图（KDE Plot）

```python
# 绘制直方图和密度图
sns.histplot(data=df, x='sales', kde=True)
plt.title('Distribution of Sales')
plt.show()
```

#### 2.4 箱线图（Box Plot）

**用途**：展示数值变量的分布（中位数、四分位数、异常值）

```python
# 示例数据
df = pd.DataFrame({
    'category': ['A'] * 100 + ['B'] * 100,
    'value': np.random.normal(0, 1, 100).tolist() + np.random.normal(2, 1, 100).tolist()
})

# 绘制箱线图
sns.boxplot(data=df, x='category', y='value')
plt.title('Box Plot by Category')
plt.show()
```

#### 2.5 小提琴图（Violin Plot）

**用途**：结合箱线图和密度图，展示分布形状

```python
# 绘制小提琴图
sns.violinplot(data=df, x='category', y='value')
plt.title('Violin Plot by Category')
plt.show()
```

#### 2.6 散点图（Scatter Plot）

```python
# 示例数据
x = np.random.rand(100)
y = 2 * x + np.random.rand(100) * 0.5

# 绘制散点图
sns.scatterplot(x=x, y=y, alpha=0.6)
plt.title('Scatter Plot')
plt.show()
```

#### 2.7 成对关系图（Pair Plot）

**用途**：展示多个数值变量之间的成对关系

```python
# 示例数据
df = pd.DataFrame({
    'x1': np.random.rand(100),
    'x2': np.random.rand(100),
    'x3': np.random.rand(100),
    'category': ['A'] * 50 + ['B'] * 50
})

# 绘制成对关系图
sns.pairplot(df, hue='category')
plt.show()
```

### 三、高级技巧

#### 3.1 子图（Subplot）

```python
# 创建子图
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# 第一个子图：折线图
axes[0, 0].plot(df['month'], df['sales'], marker='o')
axes[0, 0].set_title('Line Plot')

# 第二个子图：柱状图
axes[0, 1].bar(df['month'], df['sales'])
axes[0, 1].set_title('Bar Plot')

# 第三个子图：直方图
axes[1, 0].hist(np.random.normal(0, 1, 1000), bins=30)
axes[1, 0].set_title('Histogram')

# 第四个子图：散点图
x = np.random.rand(100)
y = 2 * x + np.random.rand(100) * 0.5
axes[1, 1].scatter(x, y, alpha=0.6)
axes[1, 1].set_title('Scatter Plot')

plt.tight_layout()
plt.show()
```

#### 3.2 样式设置

```python
# Matplotlib 样式
plt.style.use('ggplot')  # 使用ggplot样式

# Seaborn 样式
sns.set_style('whitegrid')  # 设置样式
sns.set_palette('viridis')  # 设置调色板
```

#### 3.3 保存图表

```python
# 保存图表为图片
plt.savefig('chart.png', dpi=300, bbox_inches='tight')
```

## 示例/应用场景

### 示例1：电商订单分析

**需求**：分析某电商平台2024年1月的订单金额分布，并展示每日订单金额趋势。

**代码**：

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 读取订单数据
df = pd.read_csv('orders.csv')

# 转换订单日期为日期类型
df['order_date'] = pd.to_datetime(df['order_date'])

# 筛选2024年1月的数据
df_jan = df[(df['order_date'] >= '2024-01-01') & (df['order_date'] < '2024-02-01')]

# 1. 订单金额分布（直方图）
plt.figure(figsize=(10, 6))
sns.histplot(df_jan['order_amount'], kde=True)
plt.title('Distribution of Order Amount (Jan 2024)')
plt.xlabel('Order Amount')
plt.ylabel('Frequency')
plt.show()

# 2. 每日订单金额趋势（折线图）
daily_sales = df_jan.groupby('order_date')['order_amount'].sum().reset_index()
plt.figure(figsize=(12, 6))
plt.plot(daily_sales['order_date'], daily_sales['order_amount'], marker='o')
plt.title('Daily Order Amount Trend (Jan 2024)')
plt.xlabel('Date')
plt.ylabel('Order Amount')
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```

### 示例2：员工薪资分析

**需求**：分析某公司各部门的平均工资，并展示工资分布。

**代码**：

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 读取员工数据
df = pd.read_excel('employees.xlsx')

# 1. 各部门平均工资（柱状图）
dept_salary = df.groupby('department')['salary'].mean().reset_index()
plt.figure(figsize=(10, 6))
sns.barplot(data=dept_salary, x='department', y='salary')
plt.title('Average Salary by Department')
plt.xlabel('Department')
plt.ylabel('Average Salary')
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()

# 2. 各部门工资分布（箱线图）
plt.figure(figsize=(10, 6))
sns.boxplot(data=df, x='department', y='salary')
plt.title('Salary Distribution by Department')
plt.xlabel('Department')
plt.ylabel('Salary')
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```

### 示例3：用户留存分析

**需求**：分析某App用户的留存率趋势，并展示不同渠道用户的留存率对比。

**代码**：

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 读取留存数据
df = pd.read_csv('retention.csv')

# 1. 整体留存率趋势（折线图）
plt.figure(figsize=(10, 6))
sns.lineplot(data=df, x='day', y='retention_rate', marker='o')
plt.title('Overall Retention Rate Trend')
plt.xlabel('Day')
plt.ylabel('Retention Rate')
plt.tight_layout()
plt.show()

# 2. 不同渠道留存率对比（折线图）
plt.figure(figsize=(10, 6))
sns.lineplot(data=df, x='day', y='retention_rate', hue='channel', marker='o')
plt.title('Retention Rate by Channel')
plt.xlabel('Day')
plt.ylabel('Retention Rate')
plt.tight_layout()
plt.show()
```

## 最佳实践

### 1. 根据分析目标选择合适的图表类型

**不推荐**（使用饼图展示趋势）：
```python
# 饼图不适合展示趋势
plt.pie(df['sales'], labels=df['month'])
```

**推荐**（使用折线图展示趋势）：
```python
# 折线图适合展示趋势
plt.plot(df['month'], df['sales'], marker='o')
```

### 2. 使用清晰的标题和轴标签

**不推荐**（没有标题和轴标签）：
```python
plt.plot(df['month'], df['sales'])
plt.show()
```

**推荐**（添加标题和轴标签）：
```python
plt.plot(df['month'], df['sales'])
plt.title('Monthly Sales Trend')
plt.xlabel('Month')
plt.ylabel('Sales')
plt.show()
```

### 3. 使用合适的样式和调色板

**不推荐**（使用默认样式，不够美观）：
```python
sns.barplot(data=df, x='month', y='sales')
```

**推荐**（使用合适的样式和调色板）：
```python
sns.set_style('whitegrid')
sns.set_palette('viridis')
sns.barplot(data=df, x='month', y='sales')
```

### 4. 避免图表过于复杂

**不推荐**（在一个图表中展示太多信息）：
```python
# 在一个图表中展示10条折线，难以阅读
for i in range(10):
    plt.plot(df['month'], df[f'sales_{i}'])
```

**推荐**（使用子图或分面展示）：
```python
# 使用子图展示多条折线
fig, axes = plt.subplots(2, 5, figsize=(20, 8))
for i, ax in enumerate(axes.flatten()):
    ax.plot(df['month'], df[f'sales_{i}'])
    ax.set_title(f'Sales {i}')
```

## 常见错误

### 1. 使用错误的图表类型

**错误示例**：
```python
# 使用饼图展示随时间变化的趋势（错误！）
plt.pie(df['sales'], labels=df['month'])
```

**正确做法**：
```python
# 使用折线图展示趋势
plt.plot(df['month'], df['sales'], marker='o')
```

### 2. 忽略图表元素

**错误示例**：
```python
# 没有标题、轴标签，难以理解
plt.plot(df['month'], df['sales'])
plt.show()
```

**正确做法**：
```python
# 添加标题、轴标签
plt.plot(df['month'], df['sales'])
plt.title('Monthly Sales Trend')
plt.xlabel('Month')
plt.ylabel('Sales')
plt.show()
```

### 3. 图表过于复杂

**错误示例**：
```python
# 在一个图表中展示太多信息，难以阅读
for i in range(10):
    plt.plot(df['month'], df[f'sales_{i}'])
```

**正确做法**：
```python
# 使用子图或分面展示
fig, axes = plt.subplots(2, 5, figsize=(20, 8))
for i, ax in enumerate(axes.flatten()):
    ax.plot(df['month'], df[f'sales_{i}'])
    ax.set_title(f'Sales {i}')
```

### 4. 使用不合适的颜色

**错误示例**：
```python
# 使用红绿配色（色盲不友好）
plt.plot(df['month'], df['sales_A'], color='red')
plt.plot(df['month'], df['sales_B'], color='green')
```

**正确做法**：
```python
# 使用色盲友好的调色板
sns.set_palette('viridis')
plt.plot(df['month'], df['sales_A'])
plt.plot(df['month'], df['sales_B'])
```

### 5. 忽略数据量级差异

**错误示例**：
```python
# 在一个图表中展示量级差异很大的数据，难以阅读
plt.plot(df['month'], df['sales'])  # 销售额，量级10000
plt.plot(df['month'], df['profit'])  # 利润，量级100
```

**正确做法**：
```python
# 使用双Y轴
fig, ax1 = plt.subplots()
ax1.plot(df['month'], df['sales'], color='blue')
ax1.set_ylabel('Sales', color='blue')

ax2 = ax1.twinx()
ax2.plot(df['month'], df['profit'], color='red')
ax2.set_ylabel('Profit', color='red')
```
