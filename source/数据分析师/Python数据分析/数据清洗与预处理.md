# 数据清洗与预处理

## 定义

数据清洗与预处理是**处理脏数据、缺失数据、异常数据**的过程，是数据分析师**保证数据质量**的关键技能。

对于数据分析师而言，数据清洗与预处理是**数据分析的前提**，大多数真实数据集都存在缺失值、异常值、重复值等问题。

---

## 核心概念

### 1. 数据质量问题类型

| 问题类型 | 说明 | 示例 |
|----------|------|------|
| **缺失值** | 数据为空 | 用户年龄缺失 |
| **异常值** | 数据明显偏离正常范围 | 用户年龄=200岁 |
| **重复值** | 数据重复出现 | 同一用户出现多次 |
| **数据类型错误** | 数据类型不正确 | 年龄存储为字符串 |
| **数据格式不一致** | 数据格式不统一 | 日期格式有YYYY-MM-DD和MM/DD/YYYY两种 |

### 2. 数据清洗步骤

| 步骤 | 说明 |
|------|------|
| **1. 数据审查** | 查看数据基本信息和统计信息 |
| **2. 缺失值处理** | 删除或填充缺失值 |
| **3. 异常值处理** | 识别和处理异常值 |
| **4. 重复值处理** | 删除重复值 |
| **5. 数据类型转换** | 转换数据类型 |
| **6. 数据格式统一** | 统一数据格式 |

### 3. 缺失值处理方法

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| **删除** | 删除缺失值所在行或列 | 缺失值比例很小 |
| **填充（均值）** | 用均值填充缺失值 | 数值型数据，分布近似正态 |
| **填充（中位数）** | 用中位数填充缺失值 | 数值型数据，分布有偏态 |
| **填充（众数）** | 用众数填充缺失值 | 分类数据 |
| **填充（前值/后值）** | 用前一个或后一个值填充 | 时间序列数据 |
| **插值** | 用插值方法填充缺失值 | 连续型数据 |

### 二、缺失值处理

#### 2.1 删除缺失值

```python
import pandas as pd

# 读取数据
df = pd.read_csv('data.csv')

# 删除包含缺失值的行
df_dropped_rows = df.dropna()

# 删除包含缺失值的列
df_dropped_cols = df.dropna(axis=1)

# 删除缺失值比例超过阈值的列
threshold = 0.5  # 缺失值比例超过50%的列
df_dropped_threshold = df.dropna(axis=1, thresh=len(df) * threshold)
```

#### 2.2 填充缺失值

```python
import pandas as pd

# 读取数据
df = pd.read_csv('data.csv')

# 填充为0
df_filled_zero = df.fillna(0)

# 填充为均值
df_filled_mean = df.fillna(df.mean())

# 填充为中位数
df_filled_median = df.fillna(df.median())

# 填充为众数
df_filled_mode = df.fillna(df.mode().iloc[0])

# 填充为前一个值（前向填充）
df_filled_ffill = df.fillna(method='ffill')

# 填充为后一个值（后向填充）
df_filled_bfill = df.fillna(method='bfill')

# 插值填充
df_interpolated = df.interpolate()
```

### 三、异常值处理

#### 3.1 识别异常值（Z-Score方法）

```python
import pandas as pd
import numpy as np

# 读取数据
df = pd.read_csv('data.csv')

# 计算Z-Score
z_scores = np.abs((df['age'] - df['age'].mean()) / df['age'].std())

# 识别异常值（Z-Score > 3）
outliers = z_scores > 3
print(f'异常值数量: {outliers.sum()}')

# 查看异常值
print(df[outliers])
```

#### 3.2 识别异常值（IQR方法）

```python
import pandas as pd

# 读取数据
df = pd.read_csv('data.csv')

# 计算IQR
Q1 = df['age'].quantile(0.25)
Q3 = df['age'].quantile(0.75)
IQR = Q3 - Q1

# 识别异常值（小于Q1-1.5*IQR或大于Q3+1.5*IQR）
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
outliers = (df['age'] < lower_bound) | (df['age'] > upper_bound)
print(f'异常值数量: {outliers.sum()}')

# 查看异常值
print(df[outliers])
```

#### 3.3 处理异常值

```python
import pandas as pd

# 读取数据
df = pd.read_csv('data.csv')

# 计算IQR
Q1 = df['age'].quantile(0.25)
Q3 = df['age'].quantile(0.75)
IQR = Q3 - Q1

# 识别异常值
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
outliers = (df['age'] < lower_bound) | (df['age'] > upper_bound)

# 方法1：删除异常值
df_no_outliers = df[~outliers]

# 方法2：替换异常值为上下限
df['age'] = df['age'].clip(lower=lower_bound, upper=upper_bound)
```

```python
df_deduplicated = df.drop_duplicates()

df_deduplicated_last = df.drop_duplicates(keep='last')

# 基于特定列删除重复行
df_deduplicated_subset = df.drop_duplicates(subset=['user_id', 'product_id'])
```

### 五、数据类型转换

#### 5.1 转换数据类型

## 示例/应用场景

### 示例1：电商用户数据清洗

**业务问题**：清洗电商用户数据（处理缺失值、异常值、重复值等）。

**分析**：

```python
import pandas as pd
import numpy as np

# 读取数据
df = pd.read_csv('users.csv')

# 1. 数据审查
print(df.info())
print(df.describe())
print(df.isnull().sum())

# 2. 缺失值处理（填充年龄的缺失值为均值）
df['age'] = df['age'].fillna(df['age'].mean())

# 3. 异常值处理（用IQR方法识别和处理年龄异常值）
Q1 = df['age'].quantile(0.25)
Q3 = df['age'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
df['age'] = df['age'].clip(lower=lower_bound, upper=upper_bound)

# 4. 重复值处理（删除重复的用户）
df = df.drop_duplicates(subset=['user_id'])

# 5. 数据类型转换（转换注册时间为日期类型）
df['register_time'] = pd.to_datetime(df['register_time'])

# 6. 数据格式统一（统一性别格式为小写）
df['gender'] = df['gender'].str.lower()

# 保存清洗后的数据
df.to_csv('users_cleaned.csv', index=False)
```

**洞察与建议**：
- 清洗后的数据质量更高，分析结果更可靠
- 可以基于清洗后的数据进行分析和建模

### 2. 根据数据特征，选择合适的缺失值处理方法

**不推荐**（盲目使用一种缺失值处理方法）：


**推荐**（根据数据特征，选择合适的缺失值处理方法）：

```python
import pandas as pd

# 读取数据
df = pd.read_csv('data.csv')

# 对于数值型数据，分布近似正态，使用填充均值
```

## 常见错误

### 1. 不审查数据，直接处理

**错误示例**：

```python
import pandas as pd

# 读取数据
df = pd.read_csv('data.csv')

# 直接填充缺失值
df = df.fillna(0)
```

**正确做法**：

```python
import pandas as pd

# 读取数据
df = pd.read_csv('data.csv')

# 数据审查
print(df.info())
print(df.describe())
print(df.isnull().sum())

# 根据审查结果，选择合适的处理方法
df = df.fillna(df.mean())
```

## 总结

数据清洗与预处理是数据分析师的关键技能，关键要点包括：

1. **掌握数据质量问题类型**：缺失值、异常值、重复值、数据类型错误、数据格式不一致
2. **掌握数据清洗步骤**：数据审查、缺失值处理、异常值处理、重复值处理、数据类型转换、数据格式统一
3. **熟练使用缺失值处理方法**：删除、填充（均值、中位数、众数、前值/后值）、插值
4. **熟练使用异常值识别方法**：Z-Score方法、IQR方法
5. **熟练使用异常值处理方法**：删除、替换
6. **熟练使用重复值处理方法**：删除
7. **熟练使用数据类型转换方法**：`astype()`、`pd.to_datetime()`
8. **熟练使用数据格式统一方法**：字符串格式统一、日期格式统一
9. **注意最佳实践**：先进行数据审查再进行处理、根据数据特征选择合适的缺失值处理方法、根据业务需求选择合适的异常值处理方法、记录数据清洗过程保证可复现性
10. **避免常见错误**：不审查数据直接处理、盲目使用一种缺失值处理方法、盲目使用一种异常值处理方法、不记录数据清洗过程导致不可复现、不验证清洗后的数据质量

数据清洗与预处理是数据分析师的必备技能，需要在实践中不断积累经验。
