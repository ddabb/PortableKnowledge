# 同期群分析

## 定义

**同期群分析**是用户行为分析的重要方法，用于**将用户按时间周期分组，分析不同组别的行为差异**。

对于数据分析师而言，掌握**同期群分析**，是**进行用户留存分析、用户生命周期分析、用户价值分析**的关键技能。

---

## 核心概念

### 1. 同期群定义

| 概念 | 说明 | 示例 |
|------|------|------|
| **同期群** | 在同一时间段内发生某一行为的用户群体 | 2024年1月注册的用户 |
| **同期群分析** | 将用户按时间周期分组，分析不同组别的行为差异 | 分析不同月份注册用户的留存率 |

### 2. 同期群分析步骤

| 步骤 | 说明 | 工具 |
|------|------|------|
| **1. 定义同期群** | 确定分组的时间周期 | 业务理解 |
| **2. 收集数据** | 收集用户行为数据 | Excel、SQL、Python |
| **3. 计算指标** | 计算各同期群的指标（留存率、转化率等） | Excel、SQL、Python |
| **4. 绘制同期群表** | 绘制同期群分析表（热力图） | Excel、Python、Power BI、Tableau |
| **5. 分析行为差异** | 分析不同同期群的行为差异 | 所有工具 |

### 3. 同期群分析应用场景

| 场景 | 说明 | 示例 |
|------|------|------|
| **用户留存分析** | 分析不同同期群的用户留存率 | 电商用户留存分析 |
| **用户转化分析** | 分析不同同期群的用户转化率 | 电商用户转化分析 |
| **用户价值分析** | 分析不同同期群的用户价值 | 电商用户价值分析 |

### 二、收集数据

#### 2.1 使用Excel收集数据

**步骤**：
1. 将用户ID、注册月份、行为月份、行为类型放在不同列
2. 使用透视表功能汇总数据

#### 2.2 使用SQL收集数据

**SQL代码**：
```sql
-- 按注册月份分组，计算各月份注册用户在后续各月份的留存人数
SELECT 
    DATE_FORMAT(registration_date, '%Y-%m') AS registration_month,
    DATE_FORMAT(activity_date, '%Y-%m') AS activity_month,
    COUNT(DISTINCT user_id) AS retained_users
FROM 
    user_activity_data
GROUP BY 
    registration_month, 
    activity_month
ORDER BY 
    registration_month, 
    activity_month;
```

#### 2.3 使用Python收集数据

**Python代码**：
```python
import pandas as pd

# 读取数据
df = pd.read_csv('user_activity_data.csv')

# 将注册日期和活动日期转换为日期类型
df['注册日期'] = pd.to_datetime(df['注册日期'])
df['活动日期'] = pd.to_datetime(df['活动日期'])

# 提取年份和月份
df['注册月份'] = df['注册日期'].dt.to_period('M')
df['活动月份'] = df['活动日期'].dt.to_period('M')

# 按注册月份和活动月份分组，计算留存用户数
cohort_data = df.groupby(['注册月份', '活动月份'])['用户ID'].nunique().reset_index()
cohort_data.columns = ['注册月份', '活动月份', '留存用户数']

# 查看结果
print(cohort_data.head())
```

### 三、计算指标

#### 3.1 计算留存率

**留存率计算公式**：
```
留存率 = 后续月份活跃用户数 / 初始月份用户数
```

**Python代码**：
```python
# 计算各同期群的初始用户数
initial_users = cohort_data[cohort_data['注册月份'] == cohort_data['活动月份']][['注册月份', '留存用户数']]
initial_users.columns = ['注册月份', '初始用户数']

# 合并初始用户数
cohort_data = cohort_data.merge(initial_users, on='注册月份')

# 计算留存率
cohort_data['留存率'] = cohort_data['留存用户数'] / cohort_data['初始用户数']

# 查看结果
print(cohort_data.head())
```

#### 3.2 计算转化率

**转化率计算公式**：
```
转化率 = 后续月份转化用户数 / 初始月份用户数
```

**Python代码**：
```python
# 计算各同期群的初始用户数
initial_users = cohort_data[cohort_data['注册月份'] == cohort_data['活动月份']][['注册月份', '转化用户数']]
initial_users.columns = ['注册月份', '初始用户数']

# 合并初始用户数
cohort_data = cohort_data.merge(initial_users, on='注册月份')

# 计算转化率
cohort_data['转化率'] = cohort_data['转化用户数'] / cohort_data['初始用户数']

# 查看结果
print(cohort_data.head())
```

#### 3.3 计算平均订单金额

**平均订单金额计算公式**：
```
平均订单金额 = 后续月份订单总金额 / 后续月份订单总数
```

**Python代码**：
```python
# 计算各同期群的平均订单金额
cohort_data['平均订单金额'] = cohort_data['订单总金额'] / cohort_data['订单总数']

# 查看结果
print(cohort_data.head())
```

## 示例/应用场景

### 示例1：电商用户留存分析

**业务问题**：分析不同月份注册用户的留存率差异。

**数据**：电商用户活动数据表（用户ID、注册日期、活动日期）

**分析**：

**Python代码**：
```python
# 读取数据
df = pd.read_csv('user_activity_data.csv')

# 将注册日期和活动日期转换为日期类型
df['注册日期'] = pd.to_datetime(df['注册日期'])
df['活动日期'] = pd.to_datetime(df['活动日期'])

# 提取年份和月份
df['注册月份'] = df['注册日期'].dt.to_period('M')
df['活动月份'] = df['活动日期'].dt.to_period('M')

# 按注册月份和活动月份分组，计算留存用户数
cohort_data = df.groupby(['注册月份', '活动月份'])['用户ID'].nunique().reset_index()
cohort_data.columns = ['注册月份', '活动月份', '留存用户数']

# 计算各同期群的初始用户数
initial_users = cohort_data[cohort_data['注册月份'] == cohort_data['活动月份']][['注册月份', '留存用户数']]
initial_users.columns = ['注册月份', '初始用户数']

# 合并初始用户数
cohort_data = cohort_data.merge(initial_users, on='注册月份')

# 计算留存率
cohort_data['留存率'] = cohort_data['留存用户数'] / cohort_data['初始用户数']

# 创建透视表
cohort_pivot = cohort_data.pivot(index='注册月份', columns='活动月份', values='留存率')

# 绘制热力图
plt.figure(figsize=(12, 8))
sns.heatmap(cohort_pivot, annot=True, fmt='.2%', cmap='YlGnBu')
plt.title('同期群分析表（留存率）')
plt.xlabel('活动月份')
plt.ylabel('注册月份')
plt.show()

# 分析留存率差异
print(cohort_data.groupby('注册月份')['留存率'].mean().sort_values(ascending=False))
```

**洞察与建议**：
- 如果某同期群留存率高，说明该同期群用户质量高
- 可以分析该同期群的用户特征，复制到其他同期群
- 如果某同期群留存率低，说明该同期群用户质量低
- 可以分析该同期群的问题，优化用户获取策略

```python
# 读取数据
df = pd.read_csv('user_order_data.csv')
```

## 最佳实践

### 1. 根据业务场景，定义合适的同期群

**不推荐**（盲目定义同期群）：
```text
无论什么业务场景，都使用相同的同期群定义
```

**推荐**（根据业务场景，定义合适的同期群）：
```text
- 用户留存分析 → 按注册月份分组
- 用户转化分析 → 按首次购买月份分组
- 用户价值分析 → 按首次访问月份分组
```

### 2. 结合业务场景解释同期群分析结果

**不推荐**（只报告同期群分析结果）：
```text
2024年1月同期群的留存率最高
```

**推荐**（结合业务场景解释同期群分析结果）：
```text
2024年1月同期群的留存率最高，说明该同期群用户质量高。可以分析该同期群的用户特征（如获取渠道、注册流程、首单体验等），复制到其他同期群。
```

### 3. 提出可执行的业务建议

**不推荐**（只报告同期群分析结果，不提出业务建议）：
```text
2024年1月同期群的留存率最高
```

**推荐**（报告同期群分析结果，并提出业务建议）：
```text
2024年1月同期群的留存率最高，说明该同期群用户质量高。建议：
1. 分析该同期群的用户特征（如获取渠道、注册流程、首单体验等）
2. 将成功经验复制到其他同期群
3. 优化用户获取策略，提升整体留存率
```

### 4. 定期更新同期群分析

**不推荐**（只进行一次同期群分析）：
```text
只进行一次同期群分析，不更新
```

**推荐**（定期更新同期群分析）：
```text
- 每月更新一次同期群分析
- 根据最新数据调整同期群定义
- 根据最新分析结果调整业务策略
```

```text

```

**错误示例**：
```text
2024年1月同期群的留存率最高
```
