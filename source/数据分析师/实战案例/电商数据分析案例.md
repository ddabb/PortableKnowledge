# 电商数据分析案例

## 定义

电商数据分析是指通过对电商平台产生的**用户行为数据**、**商品数据**、**订单数据**等进行系统分析，从而获取业务洞察、优化运营策略、提升销售业绩的过程。

对于数据分析师而言，电商数据分析是**最典型、最常见**的实战场景之一。

---

## 核心概念

### 1. 电商数据分析的核心维度

| 维度 | 说明 | 关键指标 |
|------|------|----------|
| **用户分析** | 分析用户特征、行为、价值 | 用户数、新增用户、留存率、流失率、LTV |
| **商品分析** | 分析商品销售情况、库存 | 销售额、销量、客单价、库存周转率 |
| **订单分析** | 分析订单生成、支付、退款 | 订单数、订单金额、支付率、退款率 |
| **流量分析** | 分析访问来源、页面浏览 | PV、UV、跳出率、转化率 |
| **营销分析** | 分析营销活动效果 | ROI、CTR、CVR、获客成本 |

### 2. 电商数据分析的流程

```
业务问题定义 → 数据收集 → 数据清洗 → 数据探索 → 数据分析 → 洞察与建议 → 报告展示
```

### 3. 常用数据表结构

| 表名 | 主要字段 |
|------|----------|
| **用户表（users）** | user_id, username, register_date, city, age, gender |
| **商品表（products）** | product_id, product_name, category, price, cost, stock |
| **订单表（orders）** | order_id, user_id, order_date, order_amount, payment_status |
| **订单明细表（order_items）** | order_id, product_id, quantity, unit_price |
| **用户行为表（user_behavior）** | user_id, event_type, product_id, timestamp |

## 详细内容

### 一、用户分析

#### 1.1 用户增长分析

**分析目标**：了解用户增长趋势、渠道效果

**关键指标**：
- 新增用户数
- 活跃用户数（DAU/WAU/MAU）
- 用户留存率（次日留存、7日留存、30日留存）
- 用户流失率

**SQL示例**（计算每日新增用户数）：

```sql
SELECT 
    DATE(register_date) AS reg_date,
    COUNT(*) AS new_users
FROM users
WHERE register_date >= '2024-01-01'
GROUP BY DATE(register_date)
ORDER BY reg_date;
```

**Python示例**（计算用户留存率）：

```python
import pandas as pd

# 读取用户登录数据
df = pd.read_csv('user_login.csv')

# 转换登录日期为日期类型
df['login_date'] = pd.to_datetime(df['login_date'])

# 计算每次登录距注册日期的天数
df['days_since_reg'] = (df['login_date'] - pd.to_datetime(df['register_date'])).dt.days

# 计算留存率
retention = df[df['days_since_reg'].isin([1, 7, 30])].groupby('days_since_reg')['user_id'].nunique() / df['user_id'].nunique()
print(retention)
```

#### 1.2 用户价值分析（RFM模型）

**RFM模型**：
- **R（Recency）**：最近一次购买时间（越小越好）
- **F（Frequency）**：购买频率（越大越好）
- **M（Monetary）**：购买金额（越大越好）

**分析步骤**：
1. 计算每个用户的R、F、M值
2. 将R、F、M分别划分为高/低两档（或更多档）
3. 组合成8类用户（如"重要价值用户"、"重要发展用户"等）

**Python示例**：

```python
import pandas as pd

# 读取订单数据
df = pd.read_csv('orders.csv')

# 计算R、F、M
snapshot_date = pd.to_datetime('2024-12-31')
rfm = df.groupby('user_id').agg({
    'order_date': lambda x: (snapshot_date - x.max()).days,  # R
    'order_id': 'count',                                     # F
    'order_amount': 'sum'                                    # M
})
rfm.columns = ['recency', 'frequency', 'monetary']

# 划分高/低档（以中位数为界）
rfm['R'] = rfm['recency'].apply(lambda x: '低' if x <= rfm['recency'].median() else '高')
rfm['F'] = rfm['frequency'].apply(lambda x: '高' if x >= rfm['frequency'].median() else '低')
rfm['M'] = rfm['monetary'].apply(lambda x: '高' if x >= rfm['monetary'].median() else '低')

# 组合用户类型
rfm['user_type'] = rfm['R'] + rfm['F'] + rfm['M']
print(rfm['user_type'].value_counts())
```

### 二、商品分析

#### 2.1 商品销售分析

**分析目标**：了解商品销售情况、识别畅销/滞销商品

**关键指标**：
- 销售额（GMV）
- 销量
- 客单价
- 库存周转率

**SQL示例**（计算各类商品销售额）：

```sql
SELECT 
    p.category,
    SUM(o.order_amount) AS total_sales,
    COUNT(DISTINCT o.order_id) AS order_count,
    SUM(o.order_amount) / COUNT(DISTINCT o.order_id) AS avg_order_value
FROM orders o
INNER JOIN products p ON o.product_id = p.product_id
WHERE o.order_date >= '2024-01-01'
GROUP BY p.category
ORDER BY total_sales DESC;
```

#### 2.2 商品关联分析（购物篮分析）

**分析目标**：发现商品之间的关联关系（如"购买A的用户 also 购买B"）

**关键指标**：
- 支持度（Support）：A和B同时购买的概率
- 置信度（Confidence）：购买A的用户中，也购买B的概率
- 提升度（Lift）：置信度 / B的购买概率

**Python示例**（使用mlxtend库）：

```python
import pandas as pd
from mlxtend.frequent_patterns import apriori, association_rules

# 读取订单明细数据
df = pd.read_csv('order_items.csv')

# 转换为购物篮格式（每行一个订单，每列一个商品，值为0/1）
basket = df.groupby(['order_id', 'product_name'])['quantity'].sum().unstack().fillna(0)
basket = basket.applymap(lambda x: 1 if x > 0 else 0)

# 使用Apriori算法找出频繁项集
frequent_itemsets = apriori(basket, min_support=0.01, use_colnames=True)

# 生成关联规则
rules = association_rules(frequent_itemsets, metric='lift', min_threshold=1)
print(rules[['antecedents', 'consequents', 'support', 'confidence', 'lift']])
```

### 三、订单分析

#### 3.1 订单转化分析（漏斗分析）

**分析目标**：了解用户从浏览到支付的转化情况

**关键指标**：
- 浏览商品用户数
- 加购用户数
- 下单用户数
- 支付用户数
- 转化率（相邻步骤的比值）

**SQL示例**：

```sql
-- 计算各步骤用户数
SELECT 
    '浏览' AS step, COUNT(DISTINCT user_id) AS user_count
FROM user_behavior
WHERE event_type = 'view'
UNION ALL
SELECT 
    '加购' AS step, COUNT(DISTINCT user_id) AS user_count
FROM user_behavior
WHERE event_type = 'add_to_cart'
UNION ALL
SELECT 
    '下单' AS step, COUNT(DISTINCT user_id) AS user_count
FROM orders
UNION ALL
SELECT 
    '支付' AS step, COUNT(DISTINCT user_id) AS user_count
FROM orders
WHERE payment_status = 'paid';
```

#### 3.2 订单金额分析

**分析目标**：了解订单金额分布、识别高价值订单

**关键指标**：
- 平均订单金额（AOV）
- 订单金额分布（直方图）
- 中位订单金额

**Python示例**：

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 读取订单数据
df = pd.read_csv('orders.csv')

# 计算平均订单金额
avg_order_value = df['order_amount'].mean()
print(f'平均订单金额: {avg_order_value:.2f}')

# 绘制订单金额分布（直方图）
sns.histplot(df['order_amount'], kde=True)
plt.title('Order Amount Distribution')
plt.xlabel('Order Amount')
plt.ylabel('Frequency')
plt.show()

# 计算中位订单金额
median_order_value = df['order_amount'].median()
print(f'中位订单金额: {median_order_value:.2f}')
```

### 四、流量分析

#### 4.1 流量来源分析

**分析目标**：了解各渠道流量质量、转化率

**关键指标**：
- 各渠道访问量（PV/UV）
- 各渠道转化率
- 各渠道获客成本（CAC）
- 各渠道投资回报率（ROI）

**SQL示例**：

```sql
SELECT 
    traffic_source,
    COUNT(DISTINCT user_id) AS uv,
    COUNT(DISTINCT CASE WHEN event_type = 'purchase' THEN user_id END) AS purchase_users,
    COUNT(DISTINCT CASE WHEN event_type = 'purchase' THEN user_id END) / COUNT(DISTINCT user_id) AS conversion_rate
FROM user_behavior
WHERE event_date >= '2024-01-01'
GROUP BY traffic_source
ORDER BY uv DESC;
```

#### 4.2 页面转化分析

**分析目标**：了解各页面的转化情况、识别流失点

**关键指标**：
- 页面访问量（PV）
- 页面跳出率
- 页面平均停留时间

**SQL示例**：

```sql
SELECT 
    page_url,
    COUNT(*) AS pv,
    COUNT(DISTINCT user_id) AS uv,
    AVG(dwell_time) AS avg_dwell_time
FROM page_view
WHERE visit_date >= '2024-01-01'
GROUP BY page_url
ORDER BY pv DESC;
```

## 示例/应用场景

### 示例1：用户留存分析

**业务问题**：某电商平台2024年1月的新用户，次日留存率、7日留存率、30日留存率分别是多少？

**分析步骤**：

1. **数据收集**：
   - 用户表（users）：user_id, register_date
   - 用户登录表（user_login）：user_id, login_date

2. **数据清洗**：
   - 确保register_date和login_date格式正确
   - 去除异常数据（如登录日期早于注册日期）

3. **数据分析**（使用Python）：

```python
import pandas as pd

# 读取数据
users = pd.read_csv('users.csv')
login = pd.read_csv('user_login.csv')

# 转换日期类型
users['register_date'] = pd.to_datetime(users['register_date'])
login['login_date'] = pd.to_datetime(login['login_date'])

# 合并数据
df = pd.merge(login, users, on='user_id')

# 计算每次登录距注册日期的天数
df['days_since_reg'] = (df['login_date'] - df['register_date']).dt.days

# 计算留存率
retention_1 = df[df['days_since_reg'] == 1]['user_id'].nunique() / df['user_id'].nunique()
retention_7 = df[df['days_since_reg'] == 7]['user_id'].nunique() / df['user_id'].nunique()
retention_30 = df[df['days_since_reg'] == 30]['user_id'].nunique() / df['user_id'].nunique()

print(f'次日留存率: {retention_1:.2%}')
print(f'7日留存率: {retention_7:.2%}')
print(f'30日留存率: {retention_30:.2%}')
```

4. **洞察与建议**：
   - 如果次日留存率低于20%，说明产品吸引力不足，需要优化新手引导
   - 如果7日留存率低于10%，说明用户粘性不足，需要优化产品功能或运营活动

### 示例2：商品销售分析

**业务问题**：某电商平台2024年第一季度，各类商品的销售额、销量、客单价分别是多少？哪个类别表现最好？

**分析步骤**：

1. **数据收集**：
   - 订单表（orders）：order_id, product_id, order_amount, order_date
   - 商品表（products）：product_id, category

2. **数据分析**（使用SQL）：

```sql
SELECT 
    p.category,
    SUM(o.order_amount) AS total_sales,
    COUNT(DISTINCT o.order_id) AS order_count,
    SUM(o.order_amount) / COUNT(DISTINCT o.order_id) AS avg_order_value,
    SUM(o.quantity) AS total_quantity
FROM orders o
INNER JOIN products p ON o.product_id = p.product_id
WHERE o.order_date BETWEEN '2024-01-01' AND '2024-03-31'
GROUP BY p.category
ORDER BY total_sales DESC;
```

3. **洞察与建议**：
   - 销售额最高的类别可能是平台的主打类别，应加大投入
   - 客单价高的类别可能是高利润类别，应重点推广
   - 销量高但销售额低的类别可能是引流类别，应优化供应链降低成本

### 示例3：订单转化分析

**业务问题**：某电商平台2024年1月，用户从浏览到支付的转化率是多少？哪个步骤流失最严重？

**分析步骤**：

1. **数据收集**：
   - 用户行为表（user_behavior）：user_id, event_type, timestamp
   - 订单表（orders）：order_id, user_id, payment_status

2. **数据分析**（使用SQL）：

```sql
-- 计算各步骤用户数
WITH funnel AS (
    SELECT 
        '浏览' AS step, COUNT(DISTINCT user_id) AS user_count
    FROM user_behavior
    WHERE event_type = 'view'
      AND event_date >= '2024-01-01'
    UNION ALL
    SELECT 
        '加购' AS step, COUNT(DISTINCT user_id) AS user_count
    FROM user_behavior
    WHERE event_type = 'add_to_cart'
      AND event_date >= '2024-01-01'
    UNION ALL
    SELECT 
        '下单' AS step, COUNT(DISTINCT user_id) AS user_count
    FROM orders
    WHERE order_date >= '2024-01-01'
    UNION ALL
    SELECT 
        '支付' AS step, COUNT(DISTINCT user_id) AS user_count
    FROM orders
    WHERE order_date >= '2024-01-01'
      AND payment_status = 'paid'
)
SELECT 
    step,
    user_count,
    user_count / LAG(user_count) OVER (ORDER BY 
        CASE step 
            WHEN '浏览' THEN 1
            WHEN '加购' THEN 2
            WHEN '下单' THEN 3
            WHEN '支付' THEN 4
        END) AS conversion_rate
FROM funnel
ORDER BY 
    CASE step 
        WHEN '浏览' THEN 1
        WHEN '加购' THEN 2
        WHEN '下单' THEN 3
        WHEN '支付' THEN 4
    END;
```

3. **洞察与建议**：
   - 如果"浏览→加购"转化率低，说明商品详情页不够吸引人，需要优化商品图片、描述等
   - 如果"加购→下单"转化率低，说明购物车页面有问题，需要优化结算流程
   - 如果"下单→支付"转化率低，说明支付流程有问题，需要优化支付方式、支付体验

## 最佳实践

### 1. 从业务问题出发，而不是从数据出发

**不推荐**（盲目分析数据）：
```
拿到电商数据，就开始计算各种指标，没有明确的业务问题。
```

**推荐**（从业务问题出发）：
```
业务问题：某电商平台2024年1月销售额同比下降10%，原因是什么？
分析思路：
1. 分解销售额 = 流量 × 转化率 × 客单价
2. 分别分析流量、转化率、客单价的变化
3. 找出导致销售额下降的主要因素
```

### 2. 使用合适的图表展示分析结果

**不推荐**（使用不合适的图表）：
```
使用饼图展示销售额随时间变化的趋势（错误！饼图适合展示占比，不适合展示趋势）。
```

**推荐**（使用合适的图表）：
```
使用折线图展示销售额随时间变化的趋势，使用柱状图比较各类别销售额，使用漏斗图展示订单转化。
```

### 3. 同时报告绝对值和相对值

**不推荐**（只报告绝对值）：
```
某商品销售额100万元。
```

**推荐**（同时报告绝对值和相对值）：
```
某商品销售额100万元，同比增长20%，在各类别中排名第2。
```

### 4. 考虑外部因素的影响

**不推荐**（忽略外部因素）：
```
某商品销售额同比下降10%，就认为是商品不受欢迎（可能实际上是受季节性因素影响）。
```

**推荐**（考虑外部因素）：
```
某商品销售额同比下降10%，但考虑到季节性因素（去年同期是旺季），实际表现符合预期。
```

## 常见错误

### 1. 混淆相关关系和因果关系

**错误示例**：
```
发现用户购买次数与用户满意度评分正相关，就认为增加购买次数会提高用户满意度（可能实际上是用户满意度高导致购买次数多）。
```

**正确做法**：
```
发现用户购买次数与用户满意度评分正相关，需要进一步分析（如A/B测试）才能确定因果关系。
```

### 2. 忽略数据质量

**错误示例**：
```
直接使用原始数据进行分析，不进行数据清洗（可能包含异常值、缺失值、重复值等）。
```

**正确做法**：
```
先对数据进行清洗（处理缺失值、异常值、重复值等），再进行数据分析。
```

### 3. 过度解读数据

**错误示例**：
```
某商品销售额同比增长5%，就认为该商品非常受欢迎（可能实际上是受促销活动影响，活动结束后销售额会回落）。
```

**正确做法**：
```
综合分析各种因素（如促销活动、季节性因素、竞争情况等），再得出结论。
```

### 4. 忽略细分分析

**错误示例**：
```
只分析整体销售额，不按类别、渠道、地区等维度进行细分分析（可能某些类别/渠道/地区表现很好，但被整体平均掩盖了）。
```

**正确做法**：
```
进行多维度细分分析（按类别、渠道、地区等），找出表现好/差的部分，再深入分析。
```

### 5. 混淆指标定义

**错误示例**：
```
将"客单价"理解为"每位用户的平均购买金额"（实际上"客单价"是指"每个订单的平均金额"）。
```

**正确做法**：
```
明确指标定义：
- 客单价 = 销售额 / 订单数
- 用户平均购买金额 = 销售额 / 用户数
```

电商数据分析是数据分析师的核心实战技能，关键要点包括：

1. **掌握电商数据分析的核心维度**：用户分析、商品分析、订单分析、流量分析、营销分析
2. **掌握电商数据分析的流程**：业务问题定义 → 数据收集 → 数据清洗 → 数据探索 → 数据分析 → 洞察与建议 → 报告展示
3. **熟练使用数据分析工具**：SQL（数据提取）、Python（数据分析）、Excel（报表制作）
4. **掌握常用指标**：DAU/WAU/MAU、留存率、转化率、客单价、GMV、ROI、LTV
5. **能够将数据洞察转化为业务建议**：数据分析的最终目的是驱动业务增长

电商数据分析是数据分析师的必备技能，需要在实践中不断积累经验。
