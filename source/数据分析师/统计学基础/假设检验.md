# 假设检验

## 定义

假设检验（Hypothesis Testing）是统计推断的核心内容，用于**判断样本数据是否支持某个关于总体的假设**。

基本思想：先对总体参数提出一个假设（原假设），然后利用样本数据判断是否有足够证据拒绝这个假设。

---

## 核心概念

### 1. 假设检验的基本步骤

```
1. 提出原假设（H0）和备择假设（H1）
2. 选择适当的检验统计量
3. 确定显著性水平（α）
4. 计算检验统计量的值和P值
5. 做出统计决策（拒绝或不拒绝H0）
```

### 2. 两类错误

| 错误类型 | 定义 | 概率 |
|----------|------|------|
| **第一类错误（Type I Error）** | 原假设为真时拒绝原假设（弃真） | α（显著性水平） |
| **第二类错误（Type II Error）** | 原假设为假时不拒绝原假设（取伪） | β |

### 3. 显著性水平（α）

- 通常取α=0.05（5%）或α=0.01（1%）
- α越小，拒绝原假设的标准越严格
- α=0.05表示：如果原假设为真，我们有5%的可能性错误地拒绝它

### 4. P值（P-value）

- P值是在原假设为真的前提下，观察到当前样本或更极端情况的概率
- **决策规则**：如果P值 ≤ α，则拒绝原假设；否则不拒绝原假设

## 详细内容

### 一、假设检验的类型

#### 1.1 单样本均值检验（One-Sample t-test）

**用途**：检验单个总体的均值是否等于某个特定值

** example**：
- 检验某班级学生的平均成绩是否为80分

**Python示例**：

```python
import scipy.stats as stats
import numpy as np

# 样本数据
scores = [78, 82, 85, 70, 88, 92, 75, 80, 85, 90]
mu0 = 80  # 假设的总体均值

# 单样本t检验
t_stat, p_value = stats.ttest_1samp(scores, mu0)

print(f't统计量: {t_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：平均成绩不等于80分')
else:
    print('不拒绝原假设：没有足够证据表明平均成绩不等于80分')
```

#### 1.2 两独立样本均值检验（Independent Two-Sample t-test）

**用途**：检验两个独立总体的均值是否相等

** example**：
- 检验男性和女性的平均成绩是否有显著差异

**Python示例**：

```python
import scipy.stats as stats

# 样本数据
male_scores = [78, 82, 85, 70, 88]
female_scores = [92, 75, 80, 85, 90]

# 两独立样本t检验
t_stat, p_value = stats.ttest_ind(male_scores, female_scores)

print(f't统计量: {t_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：男性和女性的平均成绩有显著差异')
else:
    print('不拒绝原假设：没有足够证据表明男性和女性的平均成绩有显著差异')
```

#### 1.3 配对样本均值检验（Paired t-test）

**用途**：检验同一组对象在两种条件下的均值是否有显著差异

** example**：
- 检验学生在培训前后的成绩是否有显著提高

**Python示例**：

```python
import scipy.stats as stats
import numpy as np

# 样本数据（同一组学生培训前后的成绩）
before = [70, 75, 80, 85, 90]
after = [78, 82, 85, 88, 92]

# 配对样本t检验
t_stat, p_value = stats.ttest_rel(before, after)

print(f't统计量: {t_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：培训前后的成绩有显著提高')
else:
    print('不拒绝原假设：没有足够表明培训前后的成绩有显著提高')
```

#### 1.4 单样本比例检验（One-Sample Proportion Test）

**用途**：检验单个总体的比例是否等于某个特定值

** example**：
- 检验某产品的购买率是否为30%

**Python示例**：

```python
import statsmodels.stats.proportion as proportion

# 样本数据
n = 100  # 样本量
x = 35   # 成功次数（购买人数）
p0 = 0.3  # 假设的购买率

# 单样本比例检验
z_stat, p_value = proportion.proportions_ztest(x, n, p0)

print(f'Z统计量: {z_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：购买率不等于30%')
else:
    print('不拒绝原假设：没有足够证据表明购买率不等于30%')
```

#### 1.5 方差齐性检验（Levene's Test）

**用途**：检验两个或多个总体的方差是否相等

** example**：
- 检验男性和女性的成绩方差是否相等（在进行t检验前需要检验方差齐性）

**Python示例**：

```python
import scipy.stats as stats

# 样本数据
male_scores = [78, 82, 85, 70, 88]
female_scores = [92, 75, 80, 85, 90]

# 方差齐性检验（Levene检验）
levene_stat, p_value = stats.levene(male_scores, female_scores)

print(f'Levene统计量: {levene_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：男性和女性的成绩方差不相等')
else:
    print('不拒绝原假设：没有足够证据表明男性和女性的成绩方差不相等')
```

### 二、非参数检验

#### 2.1 曼-惠特尼U检验（Mann-Whitney U Test）

**用途**：当两个总体不满足正态分布假设时，检验两个独立样本的中位数是否相等（非参数替代t检验）

** example**：
- 检验两种治疗方法的效果是否有显著差异（数据不满足正态分布）

**Python示例**：

```python
import scipy.stats as stats

# 样本数据
treatment_A = [78, 82, 85, 70, 88]
treatment_B = [92, 75, 80, 85, 90]

# 曼-惠特尼U检验
u_stat, p_value = stats.mannwhitneyu(treatment_A, treatment_B)

print(f'U统计量: {u_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：两种治疗方法的效果有显著差异')
else:
    print('不拒绝原假设：没有足够证据表明两种治疗方法的效果有显著差异')
```

#### 2.2 威尔科克森符号秩检验（Wilcoxon Signed-Rank Test）

**用途**：当两个总体不满足正态分布假设时，检验配对样本的中位数是否有显著差异（非参数替代配对t检验）

** example**：
- 检验培训前后的成绩是否有显著提高（数据不满足正态分布）

**Python示例**：

```python
import scipy.stats as stats

# 样本数据（同一组学生培训前后的成绩）
before = [70, 75, 80, 85, 90]
after = [78, 82, 85, 88, 92]

# 威尔科克森符号秩检验
w_stat, p_value = stats.wilcoxon(before, after)

print(f'Wilcoxon统计量: {w_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：培训前后的成绩有显著提高')
else:
    print('不拒绝原假设：没有足够表明培训前后的成绩有显著提高')
```

## 示例/应用场景

### 示例1：A/B测试（电商场景）

**业务问题**：某电商平台测试新的推荐算法是否能显著提高点击率（CTR）。

**假设**：
- 原假设（H0）：新算法和旧算法的点击率相等（p_new = p_old）
- 备择假设（H1）：新算法的点击率显著高于旧算法（p_new > p_old）

**数据**：
- 旧算法：展示1000次，点击50次，CTR=5%
- 新算法：展示1200次，点击78次，CTR=6.5%

**分析**：

```python
import statsmodels.stats.proportion as proportion

# 样本数据
x = [50, 78]   # 成功次数（点击次数）
n = [1000, 1200]  # 样本量（展示次数）

# 两样本比例检验
z_stat, p_value = proportion.proportions_ztest(x, n, alternative='larger')

print(f'Z统计量: {z_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：新算法的点击率显著高于旧算法')
else:
    print('不拒绝原假设：没有足够证据表明新算法的点击率显著高于旧算法')
```

**洞察与建议**：
- 如果拒绝原假设，说明新算法确实能显著提高点击率，可以全量上线
- 如果不拒绝原假设，说明新算法没有明显优势，需要继续优化

### 示例2：用户满意度调查（产品场景）

**业务问题**：某App升级后，用户满意度是否有显著提高？

**假设**：
- 原假设（H0）：升级前后用户满意度相等（μ_before = μ_after）
- 备择假设（H1）：升级后用户满意度显著提高（μ_after > μ_before）

**数据**：
- 升级前：用户满意度评分（1-10分）=[7, 8, 6, 7, 8, 9, 7, 8, 6, 7]
- 升级后：用户满意度评分（1-10分）=[8, 9, 7, 8, 9, 10, 8, 9, 7, 8]

**分析**：

```python
import scipy.stats as stats

# 样本数据
before = [7, 8, 6, 7, 8, 9, 7, 8, 6, 7]
after = [8, 9, 7, 8, 9, 10, 8, 9, 7, 8]

# 配对样本t检验
t_stat, p_value = stats.ttest_rel(before, after)

print(f't统计量: {t_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：升级后用户满意度显著提高')
else:
    print('不拒绝原假设：没有足够表明升级后用户满意度显著提高')
```

**洞察与建议**：
- 如果拒绝原假设，说明升级确实提高了用户满意度，可以继续推广
- 如果不拒绝原假设，说明升级没有明显效果，需要继续优化产品

### 示例3：广告投放效果评估（营销场景）

**业务问题**：某公司在两个渠道（渠道A和渠道B）投放广告，评估哪个渠道的转化率更高。

**假设**：
- 原假设（H0）：两个渠道的转化率相等（p_A = p_B）
- 备择假设（H1）：两个渠道的转化率不相等（p_A ≠ p_B）

**数据**：
- 渠道A：展示2000次，转化100次，转化率=5%
- 渠道B：展示1800次，转化120次，转化率=6.67%

**分析**：

```python
import statsmodels.stats.proportion as proportion

# 样本数据
x = [100, 120]   # 成功次数（转化次数）
n = [2000, 1800]  # 样本量（展示次数）

# 两样本比例检验
z_stat, p_value = proportion.proportions_ztest(x, n, alternative='two-sided')

print(f'Z统计量: {z_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：两个渠道的转化率有显著差异')
else:
    print('不拒绝原假设：没有足够证据表明两个渠道的转化率有显著差异')
```

**洞察与建议**：
- 如果拒绝原假设，说明两个渠道的转化率有显著差异，可以将预算向转化率高的渠道倾斜
- 如果不拒绝原假设，说明两个渠道的转化率没有显著差异，可以平均分配预算

## 数据分析师考点

### 假设检验常见考点

1. **假设检验的基本步骤**：提出假设、选择检验统计量、确定显著性水平、计算P值、做出决策
2. **两类错误**：第一类错误（弃真）、第二类错误（取伪）
3. **显著性水平（α）**：通常取0.05或0.01
4. **P值**：在原假设为真的前提下，观察到当前样本或更极端情况的概率
5. **常用假设检验方法**：
   - 单样本均值检验（t检验）
   - 两独立样本均值检验（t检验）
   - 配对样本均值检验（t检验）
   - 单样本比例检验（z检验）
   - 方差齐性检验（Levene检验）
   - 非参数检验（曼-惠特尼U检验、威尔科克森符号秩检验）
6. **假设检验的应用场景**：A/B测试、用户满意度调查、广告投放效果评估等

## 最佳实践

### 1. 根据数据类型和分布选择合适的检验方法

**不推荐**（盲目使用t检验）：

```
无论数据是否满足正态分布，都使用t检验。
```

**推荐**（根据数据类型和分布选择合适的检验方法）：

```
- 数据满足正态分布 → 使用t检验
- 数据不满足正态分布 → 使用非参数检验（如曼-惠特尼U检验、威尔科克森符号秩检验）
```

### 2. 同时报告统计显著性和业务显著性

**不推荐**（只报告统计显著性）：

```
P值 < 0.05，所以拒绝原假设。
```

**推荐**（同时报告统计显著性和业务显著性）：

```
P值 < 0.05，统计上显著。但实际差异很小（如点击率从5.00%提高到5.01%），业务上可能不显著。
```

### 3. 控制第一类错误（多重比较问题）

**不推荐**（进行多次检验但不调整α）：

```
进行10次假设检验，每次都使用α=0.05。
```

**推荐**（进行多次检验时调整α，如使用Bonferroni校正）：

```
进行10次假设检验，使用Bonferroni校正，调整后的α=0.05/10=0.005。
```

### 4. 报告效应量（Effect Size）

**不推荐**（只报告P值）：

```
P值 < 0.05，所以拒绝原假设。
```

**推荐**（同时报告P值和效应量）：

```
P值 < 0.05，效应量（Cohen's d）= 0.8，说明差异很大。
```

## 常见错误

### 1. 混淆"不拒绝原假设"和"接受原假设"

**错误示例**：

```
P值 > 0.05，所以接受原假设（认为原假设为真）。
```

**正确做法**：

```
P值 > 0.05，所以不拒绝原假设（没有足够证据拒绝原假设，但不代表原假设一定为真）。
```

### 2. 忽略两类错误

**错误示例**：

```
只关注第一类错误（α），忽略第二类错误（β）。
```

**正确做法**：

```
同时关注两类错误，并根据业务场景权衡（如医疗场景更关注第二类错误，宁愿误报也不漏报）。
```

### 3. 盲目追求统计显著性

**错误示例**：

```
只要P值 < 0.05，就认为结果有实际意义。
```

**正确做法**：

```
同时考虑统计显著性和业务显著性（如点击率从5.00%提高到5.01%，统计上显著但业务上可能不显著）。
```

### 4. 忽略效应量

**错误示例**：

```
只报告P值，不报告效应量。
```

**正确做法**：

```
同时报告P值和效应量（如Cohen's d、相关系数r等），以评估差异的实际大小。
```

### 5. 进行多次检验但不调整α

**错误示例**：

```
进行10次假设检验，每次都使用α=0.05，不考虑多重比较问题。
```

**正确做法**：

```
进行多次检验时调整α，如使用Bonferroni校正（α/n）、False Discovery Rate（FDR）等方法。
```

## 总结

假设检验是统计推断的核心内容，关键要点包括：

1. **掌握假设检验的基本步骤**：提出假设、选择检验统计量、确定显著性水平、计算P值、做出决策
2. **理解两类错误**：第一类错误（弃真）、第二类错误（取伪）
3. **熟练使用常用假设检验方法**：t检验、z检验、非参数检验等
4. **掌握假设检验的应用场景**：A/B测试、用户满意度调查、广告投放效果评估等
5. **注意最佳实践**：根据数据类型和分布选择合适的检验方法、同时报告统计显著性和业务显著性、控制第一类错误、报告效应量
6. **避免常见错误**：混淆"不拒绝原假设"和"接受原假设"、忽略两类错误、盲目追求统计显著性、忽略效应量、进行多次检验但不调整α

假设检验是数据分析师的必备技能，需要在实践中不断积累经验。

### 高级主题

1. **方差分析（ANOVA）**：用于比较三个或更多总体的均值是否有显著差异
2. **卡方检验（Chi-Square Test）**：用于检验两个分类变量是否独立
3. **多元回归分析**：用于控制混淆变量，评估多个自变量对因变量的影响
4. **贝叶斯假设检验**：基于贝叶斯定理的假设检验方法

### 实战案例

1. **A/B测试**：电商推荐算法优化、App界面设计优化、广告创意优化
2. **用户满意度调查**：产品升级效果评估、客户服务满意度评估
3. **广告投放效果评估**：不同渠道转化率对比、不同创意点击率对比
4. **医疗实验**：新药疗效评估、治疗方法效果对比
