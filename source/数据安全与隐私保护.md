# 数据安全与隐私保护

## 1. 数据安全概述

### 1.1 定义
数据安全是指保护数据免受未授权访问、泄露、篡改、破坏。

### 1.2 CIA原则
| 要素 | 说明 |
|-----|------|
| 保密性 | 防止未授权访问 |
| 完整性 | 防止未授权修改 |
| 可用性 | 确保合法访问 |

## 2. 数据安全法

### 2.1 《数据安全法》
2021年9月1日施行

**主要内容：**
- 数据分类分级保护
- 数据安全保护义务
- 数据交易管理制度
- 数据跨境流动规则
- 政务数据开放

### 2.2 关键制度

| 制度 | 说明 |
|-----|------|
| 数据分类分级 | 按重要程度分级保护 |
| 数据安全评估 | 重要数据出境评估 |
| 数据交易规范 | 合法合规交易 |
| 应急响应 | 安全事件处置 |

## 3. 个人信息保护

### 3.1 《个人信息保护法》
2021年11月1日施行

**基本原则：**
- 合法性
- 正当性
- 必要性
- 最小必要
- 目的限制
- 透明性

### 3.2 个人信息的权利

| 权利 | 说明 |
|-----|------|
| 知情权 | 了解信息处理目的方式 |
| 决定权 | 限制或拒绝处理 |
| 查阅复制权 | 获取本人信息 |
| 更正权 | 要求更正错误信息 |
| 删除权 | 要求删除信息 |
| 可携带权 | 获取结构化信息 |

### 3.3 处理者义务
- 制定内部管理制度
- 分类管理
- 加密存储
- 访问控制
- 安全评估
- 应急响应

### 4.1 数据分类
| 类型 | 说明 |
|-----|------|
| 公共数据 | 政府公共管理数据 |
| 商业数据 | 企业经营数据 |
| 个人数据 | 自然人信息 |

### 4.2 数据分级

| 等级 | 名称 | 保护要求 |
|-----|------|---------|
| 一般数据 | 低敏感 | 基本保护 |
| 重要数据 | 中敏感 | 加强保护 |
| 核心数据 | 高敏感 | 最高保护 |

### 4.3 敏感数据识别
- 个人身份信息
- 财务信息
- 健康信息
- 教育信息
- 生物特征信息

## 5. 数据脱敏

### 5.1 脱敏原则

| 原则 | 说明 |
|-----|------|
| 不可逆 | 防止重建原始数据 |
| 保持特征 | 保留分布、格式 |
| 引用完整 | 主键关联保持 |
| 规避融合 | 防止多源推导 |

### 5.2 脱敏方法

| 方法 | 说明 |
|-----|------|
| 替换 | 用假数据替换 |
| 掩码 | 部分字符隐藏 |
| 泛化 | 模糊具体数值 |
| 加密 | 可逆加密 |
| 随机化 | 添加噪声 |

### 5.3 脱敏场景
- 开发测试环境
- 数据分析共享
- 第三方外包
- 数据发布

## 11. 关键考点

- 数据安全法核心：分类分级、交易规范、跨境规则
- 个人信息保护原则：合法性、正当性、必要性
- 个人信息权利：知情、决定、查阅、删除
- 数据分级：一般、重要、核心
- 脱敏原则：不可逆、保持特征、引用完整、规避融合
- 备份策略：完全、增量、差异
- DLP类型：终端、网络、存储
- 合规框架：ISO27001、SOC2、GDPR
- 个人信息跨境：评估、认证、合同
