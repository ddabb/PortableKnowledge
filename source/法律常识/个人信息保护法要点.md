# 个人信息保护法要点：你的数据谁说了算？

## 一、敏感个人信息

### 1.1 敏感信息范围

| 信息类型 | 具体内容 |
|---------|---------|
| 生物识别 | 人脸、指纹、虹膜 |
| 宗教信仰 | 宗教信仰、政治立场 |
| 医疗健康 | 健康信息、就医记录 |
| 金融账户 | 银行账户、征信 |
| 精准位置 | 行踪轨迹、定位 |
| 未成年人 | 14岁以下儿童信息 |

### 1.2 处理敏感信息的特别要求

- 取得单独同意
- 告知处理敏感信息的必要性
- 制定专项处理规则

## 二、平台的信息保护义务

### 2.1 平台必须做到的

| 义务类型 | 具体要求 |
|---------|---------|
| 告知义务 | 清晰告知收集信息的目的、方式、范围 |
| 最小必要 | 只收集实现功能所必需的信息 |
| 存储限制 | 保存期限最短必要 |
| 安全措施 | 加密存储、访问控制 |

### 2.2 大数据杀熟的禁止

平台不得在交易价格等方面实行**差异待遇**，同一交易条件下不同人的价格应相同。

## 三、个人的权利

### 3.1 法定权利

| 权利 | 内容 |
|------|------|
| 知情权 | 了解平台如何处理你的信息 |
| 决定权 | 限制或拒绝处理 |
| 查阅复制 | 获取你的信息副本 |
| 更正补充 | 要求更正错误信息 |
| 删除权 | 要求删除违规信息 |
| 撤回同意 | 随时撤回授权 |

### 3.2 投诉举报

**投诉渠道：**
- 网信办12377
- 消费者协会12315
- 市场监管12345

## 四、违规处罚

| 违规情形 | 处罚力度 |
|---------|---------|
| 一般违规 | 100万以下罚款 |
| 情节严重 | 5000万以下或年营业额5% |
| 禁止提供产品 | 责令停业整顿 |
| 责任人员 | 个人罚款10-100万 |

## 五、实用建议

1. **定期检查**平台隐私设置
2. **关闭**不必要的权限授权
3. **关注**个人信息保护设置
4. **警惕**来源不明的收集要求
