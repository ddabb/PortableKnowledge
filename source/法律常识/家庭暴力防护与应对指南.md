> 家庭暴力不是家务事，是违法行为。本文提供识别、应对和求助的实用指南。

---

## 一、家庭暴力的类型

### 1.1 暴力类型

| 暴力类型 | 具体表现 |
|---------|---------|
| 身体暴力 | 殴打、伤害、限制人身自由 |
| 精神暴力 | 侮辱、恐吓、冷暴力 |
| 经济控制 | 控制财产、限制消费 |
| 性暴力 | 强迫性行为 |

### 1.2 精神暴力的识别

- 反复贬低、辱骂
- 威胁伤害本人或家人
- 跟踪、监视行踪
- 强迫看手机、汇报行踪

---

## 二、证据收集

### 2.1 及时就医

| 证据类型 | 获取方式 |
|---------|---------|
| 伤情照片 | 立即拍摄受伤部位 |
| 就诊记录 | 医院诊断证明 |
| 报警记录 | 110报警回执 |
| 证人证言 | 邻居、物业人员 |
| 威胁信息 | 微信、短信、录音 |

### 2.2 报警要点

拨打110报警并明确要求：
- 出具报警回执
- 要求做笔录
- 要求验伤

## 三、求助渠道

| 求助对象 | 联系方式 | 处理方式 |
|---------|---------|---------|
| 公安 | 110 | 出警制止、治安处罚 |
| 妇联 | 12338 | 法律援助、心理辅导 |
| 居委会 | 街道办 | 调解、庇护 |
| 法院 | 申请人身保护令 | 民事裁定 |
| 公益律师 | 法律援助中心 | 免费法律咨询 |

---

## 四、紧急避险

遭遇家暴时：
1. 躲进有锁的屋子
2. 拨打110或邻居求助
3. 带着孩子迅速离开
4. 提前准备紧急包（证件、现金、手机充电宝）
