## 一、年终奖

### 1.1 年终奖的法律性质

年终奖属于**工资**组成部分，受劳动法保护。

### 1.2 发放规则

| 情形 | 是否应发 |
|------|---------|
| 劳动合同写明 | 必须发放 |
| 公司规章制度规定 | 按制度执行 |
| 口头承诺 | 需举证，可主张 |
| 离职前未到期 | 按实际工作月份折算 |

### 1.3 年终奖争议

- **提前离职：** 工作满一年可按比例主张
- **被辞退：** 应包含在离职前12个月平均工资
- **未写明：** 需通过仲裁/诉讼主张

## 二、经济补偿金

### 2.1 N的含义

N = 工作年限 × 月工资

| 工作年限 | 计算方式 |
|---------|---------|
| 6个月以下 | 0.5个月 |
| 6个月以上 | 1个月 |
| 每满1年 | 1个月 |

### 2.2 常见补偿情形

| 情形 | 补偿 |
|------|------|
| 合同到期不续（单位提出） | N |
| 协商解除（单位提出） | N |
| 单位经济性裁员 | N |
| 单位违法解除 | 2N |
| 未缴社保被迫离职 | N |

### 2.3 月工资计算

**离职前12个月平均工资包括：**
- 基本工资
- 绩效工资
- 加班费
- 奖金
- 补贴

**上限：** 当地上年度职工月平均工资3倍
**年限上限：** 不超过12年

## 三、2N赔偿

### 3.1 违法解除的情形

| 违法解除类型 | 后果 |
|------------|------|
| 无故辞退 | 2N |
| 试用期不符合条件辞退 | 证据不足 = 2N |
| 孕期/产期/哺乳期辞退 | 2N |
| 职业病工伤期间辞退 | 2N |
| 医疗期内辞退 | 2N |

### 3.2 赔偿计算示例

月薪1万，工作3年：
- 合法解除：N = 3万
- 违法解除：2N = 6万

## 四、期权与股权

### 4.1 期权归属

| 阶段 | 归属规则 |
|------|---------|
| 成熟期前离职 | 通常不归属 |
| 成熟期内离职 | 按比例归属 |
| 公司被收购 | 依协议确定 |

### 4.2 劳动仲裁时效

- **1年**（知道或应当知道权利被侵害之日起）
- 追索工资/补偿金：**无金额限制**

---

## 五、维权要点

1. **保留证据：** 劳动合同、工资流水、offer
2. **计算清楚：** 用公式算出应得金额
3. **先协商：** 成本最低
4. **再仲裁：** 免费，15日内受理
5. **最后诉讼：** 对仲裁不服可起诉
