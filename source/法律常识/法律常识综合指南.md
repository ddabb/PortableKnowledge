# 法律常识综合指南

## 一、个人信息保护法

### 1. 敏感个人信息

#### 1.1 敏感信息范围

| 信息类型 | 具体内容 |
|---------|---------|
| 生物识别 | 人脸、指纹、虹膜 |
| 宗教信仰 | 宗教信仰、政治立场 |
| 医疗健康 | 健康信息、就医记录 |
| 金融账户 | 银行账户、征信 |
| 精准位置 | 行踪轨迹、定位 |
| 未成年人 | 14岁以下儿童信息 |

#### 1.2 处理敏感信息的特别要求

- 取得单独同意
- 告知处理敏感信息的必要性
- 制定专项处理规则

### 2. 平台的信息保护义务

#### 2.1 平台必须做到的

| 义务类型 | 具体要求 |
|---------|---------|
| 告知义务 | 清晰告知收集信息的目的、方式、范围 |
| 最小必要 | 只收集实现功能所必需的信息 |
| 存储限制 | 保存期限最短必要 |
| 安全措施 | 加密存储、访问控制 |

#### 2.2 大数据杀熟的禁止

平台不得在交易价格等方面实行**差异待遇**，同一交易条件下不同人的价格应相同。

### 3. 个人的权利

#### 3.1 法定权利

| 权利 | 内容 |
|------|------|
| 知情权 | 了解平台如何处理你的信息 |
| 决定权 | 限制或拒绝处理 |
| 查阅复制 | 获取你的信息副本 |
| 更正补充 | 要求更正错误信息 |
| 删除权 | 要求删除违规信息 |
| 撤回同意 | 随时撤回授权 |

#### 3.2 投诉举报

**投诉渠道：**
- 网信办12377
- 消费者协会12315
- 市场监管12345

### 4. 违规处罚

| 违规情形 | 处罚力度 |
|---------|---------|
| 一般违规 | 100万以下罚款 |
| 情节严重 | 5000万以下或年营业额5% |
| 禁止提供产品 | 责令停业整顿 |
| 责任人员 | 个人罚款10-100万 |

### 5. 实用建议

1. **定期检查**平台隐私设置
2. **关闭**不必要的权限授权
3. **关注**个人信息保护设置
4. **警惕**来源不明的收集要求

## 二、交通事故处理

### 1. 事故现场处理

#### 1.1 发生事故后必做事项

| 步骤 | 具体操作 |
|------|---------|
| 1. 开启双闪 | 防止二次事故 |
| 2. 拨打110 | 有人伤必报警 |
| 3. 拍照留证 | 全方位记录现场 |
| 4. 挪车需知 | 拍照后可移动车辆 |

#### 1.2 轻微事故快处

无人员伤亡、财产损失2万以内可通过**交通事故快处**处理：
- 交管12123APP拍照上传
- 责任认定书在线获取
- 维修理赔直接对接

| 责任类型 | 比例 |

| 主要责任 | 70% |

| 次要责任 | 30% |
| 无责任 | 0% |

#### 2.2 常见情形

| 情形 | 责任认定 |
|------|---------|
| 追尾 | 后车全责 |
| 逆行 | 逆行全责 |
| 闯红灯 | 闯红灯全责 |
| 转弯让直行 | 转弯车全责 |
| 掉头让行 | 掉头车全责 |

### 3. 赔偿标准

#### 3.1 人身损害赔偿

| 赔偿项目 | 计算方式 |
|---------|---------|
| 医疗费 | 实际支出 |
| 误工费 | 日收入×误工天数 |
| 护理费 | 护工标准×天数 |
| 交通费 | 实际支出 |
| 残疾赔偿金 | 伤残系数×当地标准 |
| 死亡赔偿金 | 当地居民收入×年限 |

#### 3.2 城镇标准

2024年起，城乡统一适用**城镇居民标准**计算残疾/死亡赔偿金。

### 4. 保险理赔

|---------|---------|

| 三者险 | 超交强险部分 |

| 座位险 | 车上人员 |

**注意：** 商业险按责任比例赔付，交强险分项限额。

### 5. 诉讼时效

- 人身损害：**1年**
- 财产损失：**3年**
- 特殊情形可延长

### 6. 实用建议

4. **必要时**委托律师处理

## 三、劳动合同法

### 1. 劳动合同的签订

#### 1.1 劳动合同的法定形式

根据《劳动合同法》第十条，建立劳动关系应当订立书面劳动合同。口头协议在实践中难以举证，劳动者应坚持签订书面合同。

**要点：**
- 劳动关系自用工之日起建立
- 已建立劳动关系未同时订立书面合同应在一个月内签订
- 超过一个月未签合同可要求双倍工资

#### 1.2 劳动合同的必备条款

劳动合同应当具备以下条款：

| 条款类型 | 内容要求 |
|---------|---------|
| 基本信息 | 用人单位名称、地址和法定代表人 |
| 合同期限 | 固定期限/无固定期限/以完成期限 |
| 工作内容 | 岗位名称、工作地点 |
| 报酬待遇 | 工资、奖金、福利 |
| 劳动保护 | 工作时间和休息休假 |
| 社会保险 | 五险一金 |

#### 1.3 试用期的规定

| 合同期限 | 试用期上限 |
|---------|----------|
| 3个月-1年 | 1个月 |
| 1年-3年 | 2个月 |
| 3年以上/无固定期限 | 6个月 |

**重要提示：** 试用期工资不得低于合同约定工资的80%，也不得低于当地最低工资标准。

### 2. 工资与工时

#### 2.1 工资支付

- **支付日期：** 约定日期支付，最迟每月发放一次
- **支付形式：** 以货币形式发放，不得以实物或有价证券替代
- **加班工资：** 工作日加班不低于150%，休息日加班不低于200%，法定节假日加班不低于300%

#### 2.2 年假与调休

- 工作满1年不满10年：年假5天
- 满10年不满20年：年假10天
- 满20年：年假15天

### 3. 社保与公积金

- **强制缴纳：** 用人单位必须为劳动者缴纳五险一金
- **个人缴费：** 社保由单位和劳动者共同缴纳
- **公积金：** 买房、租房、装修、重大疾病均可提取

### 4. 劳动合同的解除与终止

#### 4.1 劳动者单方解除权

| 情形 | 用人单位是否支付经济补偿 |
|------|----------------------|
| 提前30日书面通知 | 否 |
| 单位违法在先 | 是 |
| 未缴社保/未发工资 | 是 |

#### 4.2 经济补偿金计算

N = 工作年限 × 月工资

**常见情形：**
- 合同到期不续签
- 单位经济性裁员
- 协商解除（单位提出）
- 单位倒闭/解散

### 5. 竞业限制

- **适用人员：** 高级管理人员、高级技术人员
- **期限：** 不超过2年
- **补偿：** 竞业限制期内按月支付经济补偿
- **违约金：** 不得超过用人单位损失

### 6. 劳动争议解决途径

1. **协商** - 首选，成本最低
2. **调解** - 企业劳动争议调解委员会
3. **仲裁** - 劳动争议仲裁委员会（必经程序）
4. **诉讼** - 对仲裁不服可向法院起诉

**劳动仲裁时效：** 1年（知道或应当知道权利被侵害之日起）

### 7. 注意事项

#### 7.1 保留证据

- 劳动合同原件
- 工资条/银行流水
- 考勤记录
- 工作证/工牌
- 微信/邮件工作沟通记录

#### 7.2 常见维权点

- 不签合同的双倍工资
- 不缴社保的被迫解除
- 违法解除的2N赔偿
- 未休年假的300%工资
- 加班费追讨

## 四、消费者权益保护法

### 1. 消费者的权利

| 权利 | 内容 |
|------|------|
| 安全权 | 购买的商品或服务安全可靠 |
| 知情权 | 了解商品或服务的真实情况 |
| 选择权 | 自主选择商品或服务 |
| 公平交易权 | 获得公平交易条件 |
| 求偿权 | 因购买商品或服务受到损害时获得赔偿 |
| 结社权 | 依法成立维护自身合法权益的社会组织 |
| 获得知识权 | 获得有关消费和消费者权益保护方面的知识 |
| 受尊重权 | 人格尊严和民族风俗习惯得到尊重 |
| 监督权 | 对商品和服务以及保护消费者权益工作进行监督 |

### 2. 经营者的义务

- 提供真实信息
- 保证商品和服务的质量
- 标明真实名称和标记
- 出具购货凭证或服务单据
- 承担“三包”责任
- 不得侵犯消费者的人格尊严

### 3. 常见消费陷阱

- 虚假宣传
- 霸王条款
- 价格欺诈
- 虚假促销
- 以次充好
- 强制消费

### 4. 维权途径

1. 与经营者协商和解
2. 请求消费者协会调解
3. 向有关行政部门申诉
4. 根据与经营者达成的仲裁协议提请仲裁机构仲裁
5. 向人民法院提起诉讼

### 5. 惩罚性赔偿

- 经营者提供商品或者服务有欺诈行为的，应当按照消费者的要求增加赔偿其受到的损失，增加赔偿的金额为消费者购买商品的价款或者接受服务的费用的三倍；增加赔偿的金额不足五百元的，为五百元。
- 经营者明知商品或者服务存在缺陷，仍然向消费者提供，造成消费者或者其他受害人死亡或者健康严重损害的，受害人有权要求经营者依照本法第四十九条、第五十一条等法律规定赔偿损失，并有权要求所受损失二倍以下的惩罚性赔偿。

## 五、人身安全保护令

### 1. 适用情形

- 遭受家庭暴力或者面临家庭暴力的现实危险
- 家庭成员之间的身体、精神等侵害行为

### 2. 申请条件

- 有明确的被申请人
- 有具体的请求
- 有遭受家庭暴力或者面临家庭暴力现实危险的情形

### 3. 申请方式

- 向人民法院书面申请
- 口头申请，由人民法院记入笔录

### 4. 保护措施

- 禁止被申请人实施家庭暴力
- 禁止被申请人骚扰、跟踪、接触申请人及其相关近亲属
- 责令被申请人迁出申请人住所
- 保护申请人人身安全的其他措施

### 5. 有效期

- 人身安全保护令的有效期不超过六个月
- 自作出之日起生效
- 失效前，人民法院可以根据申请人的申请撤销、变更或者延长

## 六、家庭暴力防护与应对

### 1. 家庭暴力的定义

家庭成员之间以殴打、捆绑、残害、限制人身自由以及经常性谩骂、恐吓等方式实施的身体、精神等侵害行为。

### 2. 受害者的权利

- 向公安机关报案
- 向居民委员会、村民委员会、妇女联合会等单位投诉、反映或者求助
- 向人民法院申请人身安全保护令
- 提起离婚诉讼
- 要求损害赔偿

### 3. 应对措施

- 立即报警，保留证据
- 及时就医，保存病历
- 向相关组织寻求帮助
- 申请人身安全保护令
- 考虑离婚，维护自身权益

### 4. 法律责任

- 民事责任：赔偿损失、赔礼道歉等
- 行政责任：警告、罚款、拘留等
- 刑事责任：故意伤害罪、虐待罪等

## 七、年终奖与经济补偿金

### 1. 年终奖

- 年终奖的发放通常由用人单位根据自身经营状况和员工表现决定
- 如果劳动合同或规章制度中明确约定了年终奖的发放条件和标准，用人单位应当按照约定执行
- 年终奖的计算方式和发放时间应当明确

### 2. 经济补偿金

- **计算标准：** 经济补偿按劳动者在本单位工作的年限，每满一年支付一个月工资的标准向劳动者支付。六个月以上不满一年的，按一年计算；不满六个月的，向劳动者支付半个月工资的经济补偿。
- **月工资：** 指劳动者在劳动合同解除或者终止前十二个月的平均工资。
- **上限：** 劳动者月工资高于用人单位所在直辖市、设区的市级人民政府公布的本地区上年度职工月平均工资三倍的，向其支付经济补偿的标准按职工月平均工资三倍的数额支付，向其支付经济补偿的年限最高不超过十二年。

### 3. 常见情形

| 情形 | 是否支付经济补偿金 |
|------|----------------|
| 协商解除（单位提出） | 是 |
| 劳动者被迫解除 | 是 |
| 单位违法解除 | 否（应支付赔偿金） |
| 合同到期不续签（单位原因） | 是 |
| 合同到期不续签（个人原因） | 否 |
| 单位经济性裁员 | 是 |
| 单位倒闭/解散 | 是 |

## 八、总结

法律常识是我们日常生活和工作中不可或缺的知识。通过了解和掌握这些法律知识，我们可以：

1. **维护自身权益**：在遇到侵权行为时，能够依法维权
2. **规避法律风险**：避免因无知而违法
3. **促进社会和谐**：通过法律手段解决纠纷，维护社会秩序
4. **提高法律意识**：培养法治观念，营造良好的法治环境

希望这份指南能帮助你更好地了解和应用法律常识，在遇到法律问题时能够从容应对。记住，法律是保护我们合法权益的有力武器，我们应当学法、懂法、用法。
