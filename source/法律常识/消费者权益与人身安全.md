# 消费者权益与人身安全：维权必备知识

## 一、消费者的权利

| 权利 | 内容 |
|------|------|
| 安全权 | 购买的商品或服务安全可靠 |
| 知情权 | 了解商品或服务的真实情况 |
| 选择权 | 自主选择商品或服务 |
| 公平交易权 | 获得公平交易条件 |
| 求偿权 | 因购买商品或服务受到损害时获得赔偿 |
| 结社权 | 依法成立维护自身合法权益的社会组织 |
| 获得知识权 | 获得有关消费和消费者权益保护方面的知识 |
| 受尊重权 | 人格尊严和民族风俗习惯得到尊重 |
| 监督权 | 对商品和服务以及保护消费者权益工作进行监督 |

## 二、经营者的义务

- 提供真实信息
- 保证商品和服务的质量
- 标明真实名称和标记
- 出具购货凭证或服务单据
- 承担"三包"责任
- 不得侵犯消费者的人格尊严

## 三、常见消费陷阱

- 虚假宣传
- 霸王条款
- 价格欺诈
- 虚假促销
- 以次充好
- 强制消费

## 四、维权途径

1. 与经营者协商和解
2. 请求消费者协会调解
3. 向有关行政部门申诉
4. 根据与经营者达成的仲裁协议提请仲裁机构仲裁
5. 向人民法院提起诉讼

## 五、惩罚性赔偿

- 经营者提供商品或者服务有欺诈行为的，应当按照消费者的要求增加赔偿其受到的损失，增加赔偿的金额为消费者购买商品的价款或者接受服务的费用的三倍；增加赔偿的金额不足五百元的，为五百元。
- 经营者明知商品或者服务存在缺陷，仍然向消费者提供，造成消费者或者其他受害人死亡或者健康严重损害的，受害人有权要求经营者依照本法第四十九条、第五十一条等法律规定赔偿损失，并有权要求所受损失二倍以下的惩罚性赔偿。

## 六、人身安全保护令

### 6.1 适用情形

- 遭受家庭暴力或者面临家庭暴力的现实危险
- 家庭成员之间的身体、精神等侵害行为

### 6.2 申请条件

- 有明确的被申请人
- 有具体的请求
- 有遭受家庭暴力或者面临家庭暴力现实危险的情形

### 6.3 申请方式

- 向人民法院书面申请
- 口头申请，由人民法院记入笔录

### 6.4 保护措施

- 禁止被申请人实施家庭暴力
- 禁止被申请人骚扰、跟踪、接触申请人及其相关近亲属
- 责令被申请人迁出申请人住所
- 保护申请人人身安全的其他措施

### 6.5 有效期

- 人身安全保护令的有效期不超过六个月
- 自作出之日起生效
- 失效前，人民法院可以根据申请人的申请撤销、变更或者延长

## 七、家庭暴力防护与应对

### 7.1 家庭暴力的定义

家庭成员之间以殴打、捆绑、残害、限制人身自由以及经常性谩骂、恐吓等方式实施的身体、精神等侵害行为。

### 7.2 受害者的权利

- 向公安机关报案
- 向居民委员会、村民委员会、妇女联合会等单位投诉、反映或者求助
- 向人民法院申请人身安全保护令
- 提起离婚诉讼
- 要求损害赔偿

### 7.3 应对措施

- 立即报警，保留证据
- 及时就医，保存病历
- 向相关组织寻求帮助
- 申请人身安全保护令
- 考虑离婚，维护自身权益

### 7.4 法律责任

- 民事责任：赔偿损失、赔礼道歉等
- 行政责任：警告、罚款、拘留等
- 刑事责任：故意伤害罪、虐待罪等

## 八、年终奖与经济补偿金

### 8.1 年终奖

- 年终奖的发放通常由用人单位根据自身经营状况和员工表现决定
- 如果劳动合同或规章制度中明确约定了年终奖的发放条件和标准，用人单位应当按照约定执行
- 年终奖的计算方式和发放时间应当明确

### 8.2 经济补偿金

- **计算标准：** 经济补偿按劳动者在本单位工作的年限，每满一年支付一个月工资的标准向劳动者支付。六个月以上不满一年的，按一年计算；不满六个月的，向劳动者支付半个月工资的经济补偿。
- **月工资：** 指劳动者在劳动合同解除或者终止前十二个月的平均工资。
- **上限：** 劳动者月工资高于用人单位所在直辖市、设区的市级人民政府公布的本地区上年度职工月平均工资三倍的，向其支付经济补偿的标准按职工月平均工资三倍的数额支付，向其支付经济补偿的年限最高不超过十二年。

### 8.3 常见情形

| 情形 | 是否支付经济补偿金 |
|------|----------------|
| 协商解除（单位提出） | 是 |
| 劳动者被迫解除 | 是 |
| 单位违法解除 | 否（应支付赔偿金） |
| 合同到期不续签（单位原因） | 是 |
| 合同到期不续签（个人原因） | 否 |
| 单位经济性裁员 | 是 |
| 单位倒闭/解散 | 是 |
