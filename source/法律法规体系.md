## 法律基础知识

### 法的本质与特征

**法的本质**：统治阶级意志的体现，由特定社会的物质生活条件决定。

**法的四大基本特征**：
1. 法是调整人的行为或社会关系的规范
2. 法是由国家制定或认可，并具有普遍约束力的社会规范
3. 法是以国家强制力保证实施的社会规范
4. 法是规定权利和义务的社会规范

### 世界主要法系

| 法系 | 特点 |
|-----|------|
| **大陆法系**（Civil Law） | 又名罗马法系、民法法系，沿袭罗马法，重视法典编纂，强调法官严格按照法条审判 |
| **英美法系**（Common Law） | 又名普通法系、海洋法系，遵循先例，判例法为主，注重当事人主义和陪审团制度 |

### 中国特色社会主义法律体系

以**宪法**为统帅，以**法律**为主干，以行政法规、地方性法规为重要组成部分。

**七大法律部门**：

| 法律部门 | 调整对象 |
|---------|---------|
| **宪法相关法** | 国家机构的产生、组织、职权和基本工作原则；民族区域自治；特别行政区；基层群众自治 |
| **民法商法** | 平等主体之间的财产关系和人身关系；商事主体之间的商事关系 |
| **行政法** | 行政机关与行政管理相对人之间的行政管理关系 |
| **经济法** | 国家对经济活动实行干预、管理或调控所产生的关系 |
| **社会法** | 劳动关系、社会保障、社会福利和特殊群体权益保障 |
| **刑法** | 犯罪与刑罚 |
| **诉讼与非诉讼程序法** | 解决社会纠纷的诉讼活动与非诉讼活动 |

## 法的效力

### 三种效力类型

| 效力类型 | 说明 |
|---------|------|
| **对象效力** | 法律对谁有效力，适用于哪些人 |
| **空间效力** | 法律在哪些地域有效力，适用于哪些地区 |
| **时间效力** | 法律何时生效、何时终止效力以及溯及力 |

### 法律法规效力层级

**纵向效力层级**（由高到低）：
```
宪法 > 法律 > 行政法规 > 地方性法规 > 规章
```

**特殊情况处理**：
- 法律之间新的一般规定与旧的特别规定不一致 → 全国人大常委会裁决
- 地方性法规与部门规章之间规定不一致 → 国务院提意见或提请全国人大常委会裁决
- 部门规章之间不一致 → 国务院裁决

## 常用法律法规

### 民法典（合同编）

- 合同是民事主体之间设立、变更、终止民事法律关系的协议
- 依法成立的合同受法律保护，仅对当事人具有法律约束力
- 当事人对合同条款理解有争议时，应依法确定争议条款含义

### 招标投标法

- 规范招标投标活动，调整招标投标过程中产生的各种关系
- 与《招标投标法实施条例》配套使用

### 政府采购法

- 规范政府采购行为，提高政府采购资金使用效益
- 政府采购：指各级国家机关、事业单位和团体组织，使用财政性资金采购依法制定的集中采购目录以内或限额标准以上的货物、工程和服务的行为

### 知识产权法

| 法律 | 主要内容 |
|-----|---------|
| **专利法** | 发明、实用新型、外观设计三类；发明是指产品、方法或其改进提出的新技术方案 |
| **著作权法** | 保护文学、艺术和科学作品作者的著作权及相关权益 |
| **商标法** | 经商标局核准注册的商标为注册商标，商标注册人享有商标专用权 |

### 网络安全法（2017年）

- 我国第一部全面规范网络空间安全管理的基础性法律
- 定义了网络、网络安全、网络数据等用语
- 明确了部门、企业、社会组织和个人的权利、义务和责任

### 数据安全法（2021年）

- 从数据安全与发展、制度、保护义务、政务数据安全与开放角度规定
- 与网络安全法一起补充了国家安全法框架下的安全治理法律体系

## 标准规范

### 标准化基本概念

**标准**：通过标准化活动，按照规定程序经协商一致制定，为各种活动或其结果提供规则、指南或特性，供共同使用和重复使用的文件。

**标准化**：为在既定范围内获得最佳秩序，促进共同效益，对现实问题确立共同使用和重复使用条款以及编制、发布和应用文件的活动。

### 主要标准化机构

| 机构 | 说明 |
|-----|------|
| **ISO** | 国际标准化组织，世界上最大、最有权威性的国际标准化专门机构 |
| **IEC** | 国际电工委员会，电气工程和电子工程领域国际标准化 |
| **ITU** | 国际电信联盟，联合国专门机构 |
| **SAC** | 国家标准化管理委员会，统一管理国家标准 |
| **CITS** | 全国信息技术标准化技术委员会，信息技术领域标准化 |

### 标准分级

根据《标准化法》，标准分为**五个级别**：

| 级别 | 制定部门 |
|-----|---------|
| **国家标准** | 国务院标准化行政主管部门 |
| **行业标准** | 国务院有关行政主管部门 |
| **地方标准** | 省、自治区、直辖市标准化行政主管部门 |
| **团体标准** | 依法成立的社会团体 |
| **企业标准** | 企业 |

### 标准类型

- **强制性标准**：保障人身健康和生命财产安全、国家安全、生态环境安全必须执行
- **推荐性标准**：基础通用、与强制性标准配套、行业起引领作用

### 标准有效期

- **国家标准**：一般5年
- **行业标准**：一般不超过5年
- **地方标准**：一般不超过5年
- **企业标准**：一般不超过3年
