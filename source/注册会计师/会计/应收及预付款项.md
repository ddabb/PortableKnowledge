# 应收及预付款项

## 应收账款

### 应收账款的确认

应收账款是指企业因销售商品、提供劳务等经营活动，应向购货单位或接受劳务单位收取的款项，主要包括企业销售商品或提供劳务等应向有关债务人收取的价款及代购货单位垫付的包装费、运杂费等。

### 应收账款的计量

#### 初始计量
应收账款应当按照公允价值计量，通常为实际发生的交易价格。

#### 后续计量
应收账款应当按照摊余成本计量。

### 应收账款的核算

#### 销售商品或提供劳务
```
借：应收账款
  贷：主营业务收入
    应交税费——应交增值税（销项税额）

借：应收账款
  贷：银行存款（代垫的包装费、运杂费等）
```

#### 收到款项
```
借：银行存款
  贷：应收账款
```

### 应收账款的减值

企业应当在资产负债表日对应收账款的账面价值进行检查，有客观证据表明应收账款发生减值的，应当计提坏账准备。

#### 坏账准备的计提方法
- **余额百分比法**：根据应收账款余额的一定百分比计提坏账准备
- **账龄分析法**：根据应收账款账龄的长短计提不同比例的坏账准备
- **个别认定法**：根据单笔应收账款的可收回性计提坏账准备

#### 坏账准备的核算

##### 计提坏账准备
```
借：资产减值损失
  贷：坏账准备
```

##### 发生坏账
```
借：坏账准备
  贷：应收账款
```

##### 已确认坏账又收回
```
借：应收账款
  贷：坏账准备

借：银行存款
  贷：应收账款
```

## 应收票据

### 应收票据的分类

- **商业承兑汇票**：由付款人签发并承兑，或由收款人签发交由付款人承兑的汇票
- **银行承兑汇票**：由在承兑银行开立存款账户的存款人签发，由承兑银行承兑的汇票

### 应收票据的核算

#### 收到应收票据
```
借：应收票据
  贷：主营业务收入
    应交税费——应交增值税（销项税额）
```

#### 应收票据贴现
```
借：银行存款（实际收到的金额）
    财务费用（贴现息）
  贷：应收票据（面值）
```

#### 应收票据到期

##### 到期收回
```
借：银行存款
  贷：应收票据
```

##### 到期未收回
```
借：应收账款
  贷：应收票据
```

## 预付账款

### 预付账款的确认

预付账款是指企业按照合同规定预付的款项。

### 预付账款的核算

#### 预付货款
```
借：预付账款
  贷：银行存款
```

#### 收到货物
```
借：原材料（或其他科目）
    应交税费——应交增值税（进项税额）
  贷：预付账款
```

#### 补付货款
```
借：预付账款
  贷：银行存款
```

#### 收回多余款项
```
借：银行存款
  贷：预付账款
```

## 其他应收款

### 其他应收款的内容

其他应收款是指企业除应收账款、应收票据、预付账款等以外的其他各种应收及暂付款项，主要包括：
- 应收的各种赔款、罚款
- 应收的出租包装物租金
- 应向职工收取的各种垫付款项
- 存出保证金
- 其他各种应收、暂付款项

### 其他应收款的核算

#### 发生其他应收款
```
借：其他应收款
  贷：银行存款（或其他科目）
```

#### 收回其他应收款
```
借：银行存款（或其他科目）
  贷：其他应收款
```

### 其他应收款的减值

企业应当在资产负债表日对其他应收款的账面价值进行检查，有客观证据表明其他应收款发生减值的，应当计提坏账准备。
