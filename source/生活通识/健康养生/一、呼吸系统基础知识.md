## 一、呼吸系统基础知识

### 1.1 呼吸系统组成

| 器官 | 功能 |
|------|------|
| 鼻腔/口腔 | 过滤、加温、加湿空气 |
| 咽喉 | 气体通道 |
| 气管/支气管 | 气体传导 |
| 肺 | 气体交换 |
| 肺泡 | 氧气进入血液 |

### 1.2 常见呼吸系统疾病

| 类型 | 常见疾病 |
|------|----------|
| 感染性疾病 | 感冒、流感、肺炎、肺结核 |
| 慢性疾病 | 哮喘、慢阻肺（COPD）|
| 过敏性疾病 | 过敏性鼻炎、花粉症 |
| 肿瘤 | 肺癌 |
| 其他 | 支气管扩张、肺纤维化 |
