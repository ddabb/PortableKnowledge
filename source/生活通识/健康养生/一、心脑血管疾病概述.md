## 一、心脑血管疾病概述

### 1.1 常见类型

| 疾病 | 说明 |
|------|------|
| **冠心病** | 心脏血管堵塞 |
| **脑卒中** | 脑血管堵塞或破裂 |
| **高血压** | 血压持续升高 |
| **心律失常** | 心脏跳动不规律 |
| **心力衰竭** | 心脏泵血功能下降 |

### 1.2 中国现状

| 数据 | 说明 |
|------|------|
| 患病人数 | 3.3亿+ |
| 死亡率 | 占总死亡40%以上 |
| 发病年龄 | 越来越年轻化 |
