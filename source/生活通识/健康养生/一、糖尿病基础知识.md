## 一、糖尿病基础知识

### 1.1 糖尿病类型

| 类型 | 说明 | 占比 |
|------|------|------|
| 1型糖尿病 | 胰岛素分泌不足 | 5-10% |
| 2型糖尿病 | 胰岛素抵抗 | 90%以上 |
| 妊娠糖尿病 | 孕期血糖升高 | 孕期 |
| 特殊类型 | 其他原因引起 | 少数 |

### 1.2 诊断标准

| 指标 | 正常 | 糖尿病前期 | 糖尿病 |
|------|------|------------|--------|
| 空腹血糖 | <6.1 | 6.1-7.0 | ≥7.0 |
| 餐后2h血糖 | <7.8 | 7.8-11.1 | ≥11.1 |
| 糖化血红蛋白 | <5.7% | 5.7-6.5% | ≥6.5% |

### 1.3 危害

| 急性危害 | 慢性危害 |
|-----------|-----------|
| 低血糖 | 心脏病/中风 |
| 酮症酸中毒 | 肾衰竭 |
| 高渗昏迷 | 失明 |
| | 截肢 |
| | 神经病变 |
