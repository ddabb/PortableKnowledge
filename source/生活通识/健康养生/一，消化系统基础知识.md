## 一，消化系统基础知识

### 1.1 消化系统组成

| 器官 | 主要功能 |
|------|----------|
| 口腔 | 咀嚼、初步消化 |
| 食管 | 传输食物 |
| 胃 | 储存、初步消化 |
| 小肠 | 主要消化和吸收 |
| 大肠 | 水分吸收、排便 |
| 肝脏 | 代谢、解毒 |
| 胆囊 | 储存胆汁 |
| 胰腺 | 分泌消化酶 |

### 1.2 常见消化系统疾病

| 部位 | 常见疾病 |
|------|----------|
| 口腔 | 口腔溃疡、牙周炎 |
| 胃 | 胃炎、胃溃疡、胃癌 |
| 肠 | 肠炎、肠易激综合征、肠癌 |
| 肝 | 肝炎、脂肪肝、肝硬化 |
| 胆 | 胆囊炎、胆结石 |
| 胰腺 | 胰腺炎 |
