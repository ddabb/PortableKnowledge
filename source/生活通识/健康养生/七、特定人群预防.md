## 七、特定人群预防

### 7.1 有家族史

| 建议 | 说明 |
|------|------|
| 提前筛查 | 比家族发病年龄早10年开始 |
| 遗传咨询 | 评估遗传风险 |
| 基因检测 | 部分癌症可做 |

### 7.2 高危职业

| 职业 | 防护措施 |
|------|----------|
| 矿工 | 防尘、防氡 |
| 化工业 | 防护装备 |
| 放射科 | 辐射防护 |
| 装修业 | 防甲醛 |
