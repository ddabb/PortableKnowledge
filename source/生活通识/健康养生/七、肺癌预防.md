## 七、肺癌预防

### 7.1 危险因素

| 因素 | 风险 |
|------|------|
| 吸烟 | 增加20倍风险 |
| 二手烟 | 增加30%风险 |
| 空气污染 | PM2.5 |
| 职业暴露 | 石棉、氡 |
| 家族史 | 遗传因素 |

### 7.2 预防措施

| 措施 | 说明 |
|------|------|
| 戒烟 | 最有效预防 |
| 避免二手烟 | 同样重要 |
| 职业防护 | 高危职业戴口罩 |
| 空气污染防护 | 雾霾天减少外出 |
| 健康饮食 | 多吃蔬果 |
| 早期筛查 | 高危人群做CT |

### 7.3 早期筛查

| 筛查方法 | 低剂量螺旋CT |
|----------|--------------|
| 适用人群 | 50岁以上，吸烟≥20包/年 |
| 频率 | 每年1次 |
| 效果 | 降低20%死亡率 |
