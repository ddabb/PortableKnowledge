## 七、饮食习惯养护

### 7.1 正确饮食习惯

| 习惯 | 说明 |
|------|------|
| 定时定量 | 规律饮食 |
| 细嚼慢咽 | 减轻胃负担 |
| 七八分饱 | 不过饱 |
| 温度适宜 | 不过烫过凉 |
| 荤素搭配 | 均衡营养 |

### 7.2 养胃时间表

| 时间 | 建议 |
|------|------|
| 7:00-9:00 | 吃早餐（养胃黄金时间）|
| 12:00-13:00 | 午餐，七八分饱 |
| 18:00-19:00 | 晚餐，宜清淡 |
| 21:00后 | 不再进食 |

### 7.3 伤胃饮食习惯

| 习惯 | 危害 |
|------|------|
| 不吃早餐 | 胃酸损伤黏膜 |
| 暴饮暴食 | 急性胃扩张 |
| 重口味 | 高盐/辛辣刺激 |
| 边吃边喝 | 稀释胃液 |
| 饭后立即运动 | 影响消化 |
