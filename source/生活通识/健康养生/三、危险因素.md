## 三、危险因素

### 3.1 不可改变因素

| 因素 | 说明 |
|------|------|
| 年龄 | ≥45岁风险增加 |
| 家族史 | 直系亲属患病风险增加 |
| 种族 | 亚洲人风险较高 |
| 妊娠糖尿病史 | 产后血糖异常风险增加 |

### 3.2 可改变因素

| 因素 | 影响 |
|------|------|
| 超重/肥胖 | 最大危险因素 |
| 腹型肥胖 | 危害更大 |
| 缺乏运动 | 胰岛素敏感性下降 |
| 高脂饮食 | 增加胰岛素抵抗 |
| 高糖饮食 | 加重胰岛负担 |
| 睡眠不足 | 影响血糖代谢 |
| 长期压力 | 升高血糖 |

### 3.3 风险自测

| 问题 | 是=1分 |
|------|--------|
| 年龄≥45岁 | 1 |
| BMI≥24 | 1 |
| 腰围男≥90/女≥85cm | 1 |
| 父母/兄弟姐妹有糖尿病 | 1 |
| 妊娠糖尿病或巨大儿分娩史 | 1 |
| 高血压 | 1 |
| 缺乏运动 | 1 |

**≥3分：** 高危人群，需筛查
**≥5分：** 极高危人群，立即干预
