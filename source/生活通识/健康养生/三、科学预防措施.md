## 三、科学预防措施

### 3.1 一级预防（病因预防）

#### 戒烟

| 戒烟好处 | 说明 |
|----------|------|
| 肺癌风险 | 戒烟10年后降至不吸烟者水平 |
| 心脑血管 | 戒烟1年后风险减半 |
| 其他癌症 | 口腔癌、食管癌风险降低 |

#### 限酒

| 饮酒量 | 风险 |
|--------|------|
| 0 | 无风险 |
| <25g/天 | 低风险 |
| 25-50g/天 | 中风险 |
| >50g/天 | 高风险 |

#### 健康饮食

| 推荐 | 限制 |
|------|------|
| 新鲜蔬菜水果 | 腌制食品 |
| 全谷物 | 加工肉制品 |
| 深海鱼 | 霉变食物 |
| 绿茶 | 65°C以上热饮 |

### 3.2 二级预防（早发现）

**核心理念：早发现=早治疗=高治愈率**

| 筛查方法 | 适用人群 |
|----------|----------|
| 低剂量CT | 50岁以上吸烟者 |
| 乳腺钼靶 | 40岁以上女性 |
| 宫颈TCT+HPV | 有性生活女性 |
| 肠镜 | 50岁以上人群 |
| 胃镜 | 高危人群 |
| AFP+肝脏超声 | 乙肝患者 |

### 3.3 疫苗预防

| 疫苗 | 预防癌症 |
|------|----------|
| 乙肝疫苗 | 肝癌 |
| HPV疫苗 | 宫颈癌等 |
