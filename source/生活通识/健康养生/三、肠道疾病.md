## 三、肠道疾病

### 3.1 常见肠道疾病

| 疾病 | 说明 |
|------|------|
| 急性胃肠炎 | 感染或饮食不当 |
| 肠易激综合征 | 功能性疾病 |
| 炎症性肠病 | 克罗恩、溃疡性结肠炎 |
| 大肠息肉 | 可癌前病变 |
| 大肠癌 | 高发癌症之一 |

### 3.2 肠道健康要素

| 要素 | 说明 |
|------|------|
| 膳食纤维 | 每天25-30克 |
| 益生菌 | 维护肠道菌群 |
| 充足饮水 | 每天1500-1700ml |
| 规律排便 | 每天1-2次 |
| 适度运动 | 促进肠蠕动 |

### 3.3 护肠食物

| 食物 | 功效 |
|------|------|
| 蔬菜水果 | 提供纤维 |
| 全谷物 | 益生元 |
| 酸奶 | 益生菌 |
| 发酵食品 | 纳豆、泡菜 |
| 坚果 | 优质脂肪 |

### 3.4 伤肠食物

| 食物 | 危害 |
|------|------|
| 加工肉制品 | 增加肠癌风险 |
| 红肉过多 | 适量 |
| 高脂饮食 | 扰乱菌群 |
| 甜饮料 | 促进炎症 |
