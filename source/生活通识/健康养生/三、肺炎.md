## 三、肺炎

### 3.1 肺炎类型

| 类型 | 说明 |
|------|------|
| 细菌性肺炎 | 肺炎链球菌最常见 |
| 病毒性肺炎 | 流感病毒等 |
| 支原体肺炎 | 儿童/青年多见 |
| 真菌性肺炎 | 免疫低下人群 |

### 3.2 高危人群

| 高危人群 | 风险 |
|----------|------|
| 65岁以上老人 | 免疫力下降 |
| 5岁以下儿童 | 免疫系统不完善 |
| 慢性病患者 | 心肺功能差 |
| 免疫低下者 | 抵抗力差 |
| 住院患者 | 交叉感染 |

### 3.3 预防措施

| 措施 | 说明 |
|------|------|
| 接种疫苗 | 流感疫苗+肺炎疫苗 |
| 勤洗手 | 减少病原体接触 |
| 戒烟 | 吸烟损害呼吸道防御 |
| 避免聚集 | 减少感染机会 |
| 增强体质 | 均衡饮食、适度运动 |
| 治疗基础病 | 控制慢阻肺等 |

### 3.4 警惕信号

| 信号 | 需就医 |
|------|--------|
| 高热>3天 | ✅ |
| 咳痰黄/绿 | ✅ |
| 呼吸困难 | ✅立即就医 |
| 胸痛 | ✅ |
| 意识模糊 | ✅立即就医 |
