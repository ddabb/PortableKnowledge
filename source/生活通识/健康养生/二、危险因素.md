## 二、危险因素

### 2.1 不可改变因素

| 因素 | 说明 |
|------|------|
| **年龄** | 55岁以上风险增加 |
| **性别** | 男性风险更高 |
| **家族史** | 父母有病史风险增加 |

### 2.2 可改变因素

| 因素 | 影响 |
|------|------|
| **高血压** | 最大危险因素 |
| **高血脂** | 堵塞血管 |
| **高血糖** | 损伤血管 |
| **吸烟** | 直接损伤血管 |
| **肥胖** | 增加心脏负担 |
| **缺乏运动** | 心肺功能下降 |
| **高盐饮食** | 升高血压 |
| **酗酒** | 损伤心肌 |
