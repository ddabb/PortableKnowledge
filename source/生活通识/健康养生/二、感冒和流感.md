## 二、感冒和流感

### 2.1 感冒 vs 流感

| 对比 | 普通感冒 | 流感 |
|------|----------|------|
| 病原体 | 鼻病毒等 | 流感病毒 |
| 症状 | 鼻塞、流涕、咽痛 | 高热、肌肉酸痛、乏力 |
| 发热 | 低热或不发热 | 高热（38-40°C）|
| 全身症状 | 轻 | 重 |
| 病程 | 5-7天 | 7-10天 |
| 并发症 | 少 | 可有肺炎等 |

### 2.2 预防措施

| 措施 | 说明 |
|------|------|
| 勤洗手 | 用肥皂或含酒精消毒剂 |
| 戴口罩 | 尤其在人群密集处 |
| 避免触摸面部 | 不用手揉眼抠鼻 |
| 通风换气 | 每天开窗通风 |
| 增强免疫力 | 均衡饮食、规律作息 |
| 疫苗 | 接种流感疫苗 |

### 2.3 疫苗接种

| 疫苗 | 适用人群 | 频率 |
|------|----------|------|
| 流感疫苗 | 6月龄以上所有人 | 每年1次 |
| 肺炎疫苗 | 65岁以上、高危人群 | 按程序 |
