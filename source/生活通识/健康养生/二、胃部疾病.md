## 二、胃部疾病

### 2.1 常见胃病

| 疾病 | 特点 |
|------|------|
| 急性胃炎 | 短期刺激引起 |
| 慢性胃炎 | 长期损伤，常见 |
| 胃溃疡 | 黏膜破损，可癌变 |
| 胃癌 | ，早期症状隐匿 |

### 2.2 胃病的危险因素

| 因素 | 影响 |
|------|------|
| 幽门螺杆菌 | 最大致病因素 |
| 非甾体抗炎药 | 损伤胃黏膜 |
| 吸烟 | 降低胃黏膜保护 |
| 酗酒 | 直接损伤胃黏膜 |
| 高盐饮食 | 增加胃癌风险 |
| 压力 | 加重胃病 |

### 2.3 养胃措施

| 措施 | 说明 |
|------|------|
| 规律饮食 | 三餐定时 |
| 细嚼慢咽 | 每口咀嚼20-30次 |
| 温度适宜 | 不烫不凉 |
| 七八分饱 | 减轻胃负担 |
| 戒烟限酒 | 减少损伤 |
| 根除幽门螺杆菌 | 需药物治疗 |

### 2.4 胃癌早期信号

| 信号 | 说明 |
|------|------|
| 持续胃痛 | 不缓解 |
| 食欲不振 | 不想吃东西 |
| 体重下降 | 不明原因 |
| 黑便 | 可能有出血 |
| 吞咽困难 | 需警惕 |
