## 二、致癌因素

### 2.1 一级致癌物

| 物质 | 来源 |
|------|------|
| 烟草 | 主动/被动吸烟 |
| 酒精 | 饮酒 |
| 黄曲霉素 | 霉变食物 |
| 亚硝胺 | 腌制食品 |
| 苯并芘 | 烧烤/油炸 |
| PM2.5 | 空气污染 |
| 甲醛 | 装修材料 |

### 2.2 生活方式危险因素

| 因素 | 影响 |
|------|------|
| 吸烟 | 导致肺癌、喉癌等 |
| 酗酒 | 导致肝癌、食管癌 |
| 高脂饮食 | 导致结直肠癌 |
| 腌制食品 | 导致胃癌 |
| 肥胖 | 多种癌症风险增加 |
| 缺乏运动 | 增加癌症风险 |

### 2.3 感染相关癌症

| 病原体 | 相关癌症 |
|--------|----------|
| 乙肝/丙肝 | 肝癌 |
| HPV | 宫颈癌、肛门癌 |
| 幽门螺杆菌 | 胃癌 |
| EB病毒 | 鼻咽癌 |
