## 五、哮喘

### 5.1 什么是哮喘

哮喘 = 气道慢性炎症+可逆性气流受限

| 特点 | 说明 |
|------|------|
| 发作性 | 时好时坏 |
| 可逆性 | 可自行缓解或用药缓解 |
| 过敏性 | 常与过敏原相关 |
| 夜间加重 | 凌晨多发 |

### 5.2 常见诱因

| 类型 | 诱因 |
|------|------|
| 过敏原 | 尘螨、花粉、宠物皮屑 |
| 感染 | 感冒、流感 |
| 环境 | 冷空气、雾霾 |
| 运动 | 运动性哮喘 |
| 情绪 | 压力、紧张 |

### 5.3 预防措施

| 措施 | 说明 |
|------|------|
| 远离过敏原 | 识别并避免 |
| 规范用药 | 吸入糖皮质激素 |
| 监测峰流速 | 了解控制情况 |
| 定期复查 | 按医嘱随访 |
| 预防感染 | 接种疫苗 |
| 健康生活 | 增强体质 |
