## 五、早期信号识别

### 5.1 心脏求救信号

| 信号 | 说明 |
|------|------|
| 胸闷胸痛 | 活动后加重 |
| 呼吸困难 | 平躺加重 |
| 心悸 | 心脏乱跳 |
| 乏力 | 活动耐力下降 |
| 水肿 | 下肢浮肿 |

### 5.2 脑卒中信号（FAST原则）

| 信号 | 说明 |
|------|------|
| **F - Face** | 面部歪斜 |
| **A - Arm** | 手臂无力 |
| **S - Speech** | 说话不清 |
| **T - Time** | 时间紧迫，立即就医 |

### 5.3 黄金时间窗

| 情况 | 时间窗 |
|------|--------|
| 溶栓治疗 | 发病4.5小时内 |
| 取栓治疗 | 发病6-24小时内 |
| 就近就医 | 不要等不要拖 |
