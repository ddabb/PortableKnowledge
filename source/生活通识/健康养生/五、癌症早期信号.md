## 五、癌症早期信号

### 5.1 常见报警信号

| 信号 | 需警惕的癌症 |
|------|--------------|
| 原因不明的体重下降 | 多种癌症 |
| 不明原因的发热 | 淋巴瘤等 |
| 持续性疼痛 | 骨癌等 |
| 异常出血 | 宫颈癌、肠癌等 |
| 长期不愈合的溃疡 | 皮肤癌等 |
| 肿块 | 乳腺癌、淋巴瘤等 |
| 吞咽困难 | 食管癌 |
| 排便习惯改变 | 结直肠癌 |

### 5.2 七大报警信号

1. 身体任何部位出现肿块
2. 疣或痣明显变化
3. 持续性消化不良
4. 吞咽时哽咽感
5. 持续性嘶哑干咳
6. 原因不明的大便/小便带血
7. 原因不明的出血
