## 五、胆囊和胰腺

### 5.1 胆结石预防

| 危险因素 | 说明 |
|----------|------|
| 女性 | 雌激素增加结石 |
| 肥胖 | 胆固醇代谢异常 |
| 高脂饮食 | 胆固醇过饱和 |
| 快速减肥 | 胆汁成分改变 |
| 不吃早餐 | 胆汁淤积 |

**预防措施：**

| 措施 | 说明 |
|------|------|
| 规律饮食 | 吃早餐 |
| 控制体重 | 避免肥胖 |
| 适度脂肪 | 不过度低脂 |
| 多运动 | 促进胆汁排泄 |

### 5.2 胰腺炎预防

| 类型 | 主要原因 |
|------|----------|
| 急性胰腺炎 | 胆结石、酗酒 |
| 慢性胰腺炎 | 长期饮酒 |

**预防措施：**

| 措施 | 说明 |
|------|------|
| 戒酒 | 最关键 |
| 控制血脂 | 高血脂可致胰腺炎 |
| 规律饮食 | 不过饱 |
| 及时治疗胆结石 | 防止逆行感染 |
