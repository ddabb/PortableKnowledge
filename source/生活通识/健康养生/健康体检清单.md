# 健康体检清单：你需要做哪些检查？

定期体检是预防疾病的第一道防线。很多人不知道该查什么、什么时候查，这份清单帮你理清思路。

## 一、基础健康评估

### 1. 身体指标测量

| 项目 | 意义 | 正常范围 |
|------|------|----------|
| **BMI** | 评估体重是否健康 | 18.5-24 |
| **腰围** | 评估腹部脂肪堆积 | 男性<90cm，女性<85cm |
| **血压** | 筛查高血压 | <140/90mmHg |
| **静息心率** | 评估心脏健康 | 60-100次/分 |

### 2. 必查项目

- **血常规**：评估血液系统健康
- **尿常规**：筛查肾脏疾病和尿路感染
- **肝功能**：评估肝脏健康
- **肾功能**：评估肾脏功能
- **血脂**：筛查高血脂
- **空腹血糖**：筛查糖尿病
- **心电图**：筛查心脏问题

### 3. 了解自己的健康档案

- 记录家族病史（父母、祖父母的疾病）
- 整理既往病史和手术史
- 记录过敏史（药物、食物）
- 了解自己的血型

## 二、年龄相关筛查项目

### 20-30岁

| 项目 | 频率 | 说明 |
|------|------|------|
| 常规体检 | 每2年 | 基础项目 |
| 血压 | 每年 | 排查高血压 |
| 视力、听力 | 每2年 | 关注变化 |
| 口腔检查 | 每年 | 预防口腔疾病 |
| 性传播疾病筛查 | 视情况 | 有不安全性行为时 |

### 30-40岁

| 项目 | 频率 | 说明 |
|------|------|------|
| 常规体检 | 每年 | 基础项目 |
| 血压、血糖、血脂 | 每年 | 排查三高 |
| 乙肝五项 | 每3-5年 | 检查抗体 |
| 宫颈涂片（女性） | 每3年 | 21岁开始 |
| HPV检测（女性） | 每5年 | 30岁开始 |

### 40-50岁

| 项目 | 频率 | 说明 |
|------|------|------|
| 常规体检 | 每年 | 基础项目 |
| 眼底检查 | 每2年 | 筛查眼部疾病 |
| 肺部低剂量CT | 视情况 | 长期吸烟者 |
| 乳腺钼靶（女性） | 每1-2年 | 40岁开始 |
| 胃肠镜 | 视情况 | 有症状或家族史 |

### 50岁以上

| 项目 | 频率 | 说明 |
|------|------|------|
| 常规体检 | 每年 | 基础项目 |
| 肠镜 | 每5-10年 | 筛查肠癌 |
| 骨密度 | 每2年 | 筛查骨质疏松 |
| 前列腺特异抗原（男性） | 每年 | 筛查前列腺问题 |
| 肺炎疫苗 | 一次性 | 65岁以上 |
| 带状疱疹疫苗 | 一次性 | 50岁以上建议接种 |

## 三、预防接种建议

| 疫苗 | 适用人群 | 频率 |
|------|----------|------|
| **乙肝疫苗** | 所有人 | 查抗体后补种 |
| **HPV疫苗** | 9-45岁女性 | 共3针 |
| **流感疫苗** | 所有人 | 每年 |
| **肺炎疫苗** | 65岁以上、慢性病患者 | 一次性 |
| **带状疱疹疫苗** | 50岁以上 | 一次性 |

## 四、疾病早期信号识别

### 心血管疾病信号

- 胸闷、胸痛
- 活动后气短
- 心悸、心跳不规则
- 头晕、晕厥
- 下肢水肿

### 糖尿病信号

- 多饮、多尿、多食
- 体重不明原因下降
- 视力模糊
- 伤口愈合慢
- 手脚麻木

### 癌症信号

- 不明原因的体重下降
- 持续疲劳
- 异常出血
- 肿块或增厚
- 持续咳嗽或声音嘶哑
- 排便习惯改变

## 五、体检前后注意事项

### 体检前

- 空腹8-12小时（肝功能、血糖等需要）
- 体检前3天清淡饮食
- 体检前一天避免剧烈运动
- 女性避开月经期
- 携带既往体检报告

### 体检后

- 认真阅读报告
- 关注异常指标
- 遵医嘱复查
- 建立健康档案
- 制定改善计划

## 小结

体检不是万能的，但不体检是万万不能的。记住：

- **每年至少一次**全面体检
- **根据年龄**做相应筛查
- **学会识别**疾病早期信号
- **建立健康档案**，追踪变化

**投资体检，就是投资健康。** 早发现、早治疗，省钱又省心。
