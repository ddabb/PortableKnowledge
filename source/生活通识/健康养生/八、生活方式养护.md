## 八、生活方式养护

### 8.1 规律作息

| 习惯 | 说明 |
|------|------|
| 充足睡眠 | 7-8小时 |
| 23点前睡 | 肝脏修复时间 |
| 规律排便 | 晨起或早餐后 |

### 8.2 情绪管理

| 情绪 | 对消化系统影响 |
|------|----------------|
| 压力 | 加重胃炎/肠易激 |
| 焦虑 | 影响食欲 |
| 抑郁 | 胃肠功能紊乱 |

**调节方法：** 运动、冥想、倾诉

### 8.3 运动养护

| 运动 | 功效 |
|------|------|
| 快走 | 促进肠蠕动 |
| 慢跑 | 增强消化功能 |
| 瑜伽 | 缓解腹胀 |
| 太极 | 调理脾胃 |
