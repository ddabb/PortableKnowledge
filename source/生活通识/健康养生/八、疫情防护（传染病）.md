## 八、疫情防护（传染病）

### 8.1 通用防护措施

| 措施 | 说明 |
|------|------|
| 勤洗手 | 肥皂+流水，>20秒 |
| 戴口罩 | 人多/密闭场所 |
| 保持距离 | 1-2米 |
| 勤通风 | 每2-3小时一次 |
| 避免聚集 | 减少传播 |
| 及时就医 | 有症状早就诊 |

### 8.2 手卫生

| 场景 | 时机 |
|------|------|
| 饭前便后 | 必须 |
| 外出回家 | 必须 |
| 接触公共物品 | 洗手 |
| 咳嗽喷嚏后 | 洗手 |
| 接触病人 | 洗手 |

### 8.3 口罩选择

| 口罩类型 | 防护效果 |
|-----------|----------|
| N95/KN95 | 最高 |
| 医用外科口罩 | 日常足够 |
| 棉布口罩 | 防尘但不防病毒 |
