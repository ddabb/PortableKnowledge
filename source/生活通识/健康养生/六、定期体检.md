## 六、定期体检

### 6.1 必查项目

| 项目 | 频率 |
|------|------|
| 血压 | 每月 |
| 血糖 | 每季度 |
| 血脂 | 每年 |
| 心电图 | 每年 |
| 心脏彩超 | 40岁后每年 |

### 6.2 高危人群

| 人群 | 检查频率 |
|------|----------|
| 有家族史 | 35岁起每年体检 |
| 三高患者 | 按医嘱定期检查 |
| 吸烟者 | 40岁起每年检查 |
| 肥胖者 | 每年全面检查 |
