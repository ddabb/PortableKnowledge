## 六、提高免疫力

### 6.1 睡眠

| 睡眠建议 | 说明 |
|----------|------|
| 时长 | 7-8小时 |
| 时间 | 固定作息 |
| 质量 | 深睡眠充足 |

### 6.2 运动

| 运动建议 | 说明 |
|----------|------|
| 类型 | 有氧+力量 |
| 频率 | 每周5次 |
| 时长 | 每次30-60分钟 |

### 6.3 心态

| 心态建议 | 说明 |
|----------|------|
| 减少压力 | 长期压力抑制免疫 |
| 积极乐观 | 免疫功能更强 |
| 社交支持 | 有益免疫系统 |
