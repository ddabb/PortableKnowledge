## 六、过敏性鼻炎

### 6.1 症状

| 症状 | 说明 |
|------|------|
| 鼻痒 | 难以忍受 |
| 连续喷嚏 | 一次多个 |
| 流清水鼻涕 | 量多 |
| 鼻塞 | 双侧交替 |
| 眼痒 | 常伴过敏性结膜炎 |

### 6.2 常见过敏原

| 类型 | 过敏原 |
|------|--------|
| 常年性 | 尘螨、霉菌、宠物 |
| 季节性 | 花粉、树木 |

### 6.3 预防措施

| 措施 | 说明 |
|------|------|
| 避免过敏原 | 最有效方法 |
| 鼻腔冲洗 | 生理盐水冲洗 |
| 药物治疗 | 抗组胺药、鼻喷剂 |
| 免疫治疗 | 脱敏治疗 |
| 保持清洁 | 勤晒被褥 |
