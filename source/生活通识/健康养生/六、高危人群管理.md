## 六、高危人群管理

### 6.1 谁是高危人群

| 高危因素 | 说明 |
|----------|------|
| 糖尿病前期 | 最重要的高危人群 |
| 超重/肥胖 | BMI≥24 |
| 年龄≥45岁 | 随年龄增加 |
| 妊娠糖尿病史 | 产后风险持续 |
| 心血管疾病 | 常与糖尿病并存 |
| 多囊卵巢综合征 | 增加糖尿病风险 |

### 6.2 高危人群行动

| 行动 | 说明 |
|------|------|
| 筛查 | 每6-12个月测血糖 |
| 生活方式 | 立即开始干预 |
| 控制体重 | 减重5-10% |
| 定期复查 | 每3-6个月 |
