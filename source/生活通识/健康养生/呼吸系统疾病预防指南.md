> 呼吸系统疾病是最常见的疾病之一，从感冒到肺癌，本文讲解常见呼吸疾病的预防。

---

## 一、呼吸系统基础知识

### 1.1 呼吸系统组成

| 器官 | 功能 |
|------|------|
| 鼻腔/口腔 | 过滤、加温、加湿空气 |
| 咽喉 | 气体通道 |
| 气管/支气管 | 气体传导 |
| 肺 | 气体交换 |
| 肺泡 | 氧气进入血液 |

### 1.2 常见呼吸系统疾病

| 类型 | 常见疾病 |
|------|----------|
| 感染性疾病 | 感冒、流感、肺炎、肺结核 |
| 慢性疾病 | 哮喘、慢阻肺（COPD）|
| 过敏性疾病 | 过敏性鼻炎、花粉症 |
| 肿瘤 | 肺癌 |
| 其他 | 支气管扩张、肺纤维化 |

## 二、感冒和流感

### 2.1 感冒 vs 流感

| 对比 | 普通感冒 | 流感 |
|------|----------|------|
| 病原体 | 鼻病毒等 | 流感病毒 |
| 症状 | 鼻塞、流涕、咽痛 | 高热、肌肉酸痛、乏力 |
| 发热 | 低热或不发热 | 高热（38-40°C）|
| 全身症状 | 轻 | 重 |
| 病程 | 5-7天 | 7-10天 |
| 并发症 | 少 | 可有肺炎等 |

### 2.2 预防措施

| 措施 | 说明 |
|------|------|
| 勤洗手 | 用肥皂或含酒精消毒剂 |
| 戴口罩 | 尤其在人群密集处 |
| 避免触摸面部 | 不用手揉眼抠鼻 |
| 通风换气 | 每天开窗通风 |
| 增强免疫力 | 均衡饮食、规律作息 |
| 疫苗 | 接种流感疫苗 |

### 2.3 疫苗接种

| 疫苗 | 适用人群 | 频率 |
|------|----------|------|
| 流感疫苗 | 6月龄以上所有人 | 每年1次 |
| 肺炎疫苗 | 65岁以上、高危人群 | 按程序 |

## 三、肺炎

### 3.1 肺炎类型

| 类型 | 说明 |
|------|------|
| 细菌性肺炎 | 肺炎链球菌最常见 |
| 病毒性肺炎 | 流感病毒等 |
| 支原体肺炎 | 儿童/青年多见 |
| 真菌性肺炎 | 免疫低下人群 |

### 3.2 高危人群

| 高危人群 | 风险 |
|----------|------|
| 65岁以上老人 | 免疫力下降 |
| 5岁以下儿童 | 免疫系统不完善 |
| 慢性病患者 | 心肺功能差 |
| 免疫低下者 | 抵抗力差 |
| 住院患者 | 交叉感染 |

### 3.3 预防措施

| 措施 | 说明 |
|------|------|
| 接种疫苗 | 流感疫苗+肺炎疫苗 |
| 勤洗手 | 减少病原体接触 |
| 戒烟 | 吸烟损害呼吸道防御 |
| 避免聚集 | 减少感染机会 |
| 增强体质 | 均衡饮食、适度运动 |
| 治疗基础病 | 控制慢阻肺等 |

### 3.4 警惕信号

| 信号 | 需就医 |
|------|--------|
| 高热>3天 | ✅ |
| 咳痰黄/绿 | ✅ |
| 呼吸困难 | ✅立即就医 |
| 胸痛 | ✅ |
| 意识模糊 | ✅立即就医 |

## 四、慢阻肺（COPD）

### 4.1 什么是慢阻肺

慢阻肺 = 气流受限、进行性发展的慢性气道炎症

| 病因 | 说明 |
|------|------|
| 吸烟 | 最主要病因（80-90%）|
| 空气污染 | PM2.5、工业粉尘 |
| 职业暴露 | 粉尘、化学气体 |
| 遗传因素 | α1-抗胰蛋白酶缺乏 |

### 4.2 症状

| 症状 | 说明 |
|------|------|
| 慢性咳嗽 | 晨起明显 |
| 咳痰 | 白色粘液痰 |
| 进行性呼吸困难 | 爬楼、走路时加重 |
| 急性加重 | 感染后症状加重 |

### 4.3 预防措施

| 措施 | 最重要 |
|------|--------|
| 戒烟 | 最有效措施 |
| 避免二手烟 | 同样有害 |
| 避免空气污染 | 雾霾戴口罩 |
| 职业防护 | 戴防护面具 |
| 疫苗接种 | 流感+肺炎疫苗 |
| 锻炼身体 | 改善肺功能 |

## 五、哮喘

### 5.1 什么是哮喘

哮喘 = 气道慢性炎症+可逆性气流受限

| 特点 | 说明 |
|------|------|
| 发作性 | 时好时坏 |
| 可逆性 | 可自行缓解或用药缓解 |
| 过敏性 | 常与过敏原相关 |
| 夜间加重 | 凌晨多发 |

### 5.2 常见诱因

| 类型 | 诱因 |
|------|------|
| 过敏原 | 尘螨、花粉、宠物皮屑 |
| 感染 | 感冒、流感 |
| 环境 | 冷空气、雾霾 |
| 运动 | 运动性哮喘 |
| 情绪 | 压力、紧张 |

### 5.3 预防措施

| 措施 | 说明 |
|------|------|
| 远离过敏原 | 识别并避免 |
| 规范用药 | 吸入糖皮质激素 |
| 监测峰流速 | 了解控制情况 |
| 定期复查 | 按医嘱随访 |
| 预防感染 | 接种疫苗 |
| 健康生活 | 增强体质 |

## 六、过敏性鼻炎

### 6.1 症状

| 症状 | 说明 |
|------|------|
| 鼻痒 | 难以忍受 |
| 连续喷嚏 | 一次多个 |
| 流清水鼻涕 | 量多 |
| 鼻塞 | 双侧交替 |
| 眼痒 | 常伴过敏性结膜炎 |

### 6.2 常见过敏原

| 类型 | 过敏原 |
|------|--------|
| 常年性 | 尘螨、霉菌、宠物 |
| 季节性 | 花粉、树木 |

### 6.3 预防措施

| 措施 | 说明 |
|------|------|
| 避免过敏原 | 最有效方法 |
| 鼻腔冲洗 | 生理盐水冲洗 |
| 药物治疗 | 抗组胺药、鼻喷剂 |
| 免疫治疗 | 脱敏治疗 |
| 保持清洁 | 勤晒被褥 |

## 七、肺癌预防

### 7.1 危险因素

| 因素 | 风险 |
|------|------|
| 吸烟 | 增加20倍风险 |
| 二手烟 | 增加30%风险 |
| 空气污染 | PM2.5 |
| 职业暴露 | 石棉、氡 |
| 家族史 | 遗传因素 |

### 7.2 预防措施

| 措施 | 说明 |
|------|------|
| 戒烟 | 最有效预防 |
| 避免二手烟 | 同样重要 |
| 职业防护 | 高危职业戴口罩 |
| 空气污染防护 | 雾霾天减少外出 |
| 健康饮食 | 多吃蔬果 |
| 早期筛查 | 高危人群做CT |

### 7.3 早期筛查

| 筛查方法 | 低剂量螺旋CT |
|----------|--------------|
| 适用人群 | 50岁以上，吸烟≥20包/年 |
| 频率 | 每年1次 |
| 效果 | 降低20%死亡率 |

## 八、疫情防护（传染病）

### 8.1 通用防护措施

| 措施 | 说明 |
|------|------|
| 勤洗手 | 肥皂+流水，>20秒 |
| 戴口罩 | 人多/密闭场所 |
| 保持距离 | 1-2米 |
| 勤通风 | 每2-3小时一次 |
| 避免聚集 | 减少传播 |
| 及时就医 | 有症状早就诊 |

### 8.2 手卫生

| 场景 | 时机 |
|------|------|
| 饭前便后 | 必须 |
| 外出回家 | 必须 |
| 接触公共物品 | 洗手 |
| 咳嗽喷嚏后 | 洗手 |
| 接触病人 | 洗手 |

### 8.3 口罩选择

| 口罩类型 | 防护效果 |
|-----------|----------|
| N95/KN95 | 最高 |
| 医用外科口罩 | 日常足够 |
| 棉布口罩 | 防尘但不防病毒 |
