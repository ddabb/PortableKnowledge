## 四、常见癌症筛查

### 4.1 肺癌

| 项目 | 说明 |
|------|------|
| 筛查方法 | 低剂量螺旋CT |
| 适用人群 | 50-74岁，吸烟≥20包/年 |
| 筛查频率 | 每年1次 |
| 治愈率 | 早期发现>90% |

### 4.2 乳腺癌

| 项目 | 说明 |
|------|------|
| 筛查方法 | 乳腺钼靶+超声 |
| 适用人群 | 40岁以上女性 |
| 频率 | 每年1次 |
| 自检 | 每月月经后7天 |

### 4.3 结直肠癌

| 项目 | 说明 |
|------|------|
| 筛查方法 | 肠镜/便潜血 |
| 适用人群 | 50岁以上 |
| 频率 | 肠镜10年1次 |
| 癌前病变 | 息肉，早发现可切除 |

### 4.4 胃癌

| 项目 | 说明 |
|------|------|
| 筛查方法 | 胃镜 |
| 适用人群 | 40岁以上高危 |
| 高危因素 | 幽门螺杆菌、胃癌家族史 |
| 频率 | 1-2年1次 |

### 4.5 肝癌

| 项目 | 说明 |
|------|------|
| 筛查方法 | 肝脏超声+AFP |
| 适用人群 | 乙肝/丙肝患者 |
| 频率 | 6个月1次 |

### 4.6 宫颈癌

| 项目 | 说明 |
|------|------|
| 筛查方法 | TCT+HPV检测 |
| 适用人群 | 25-65岁女性 |
| 频率 | 3-5年1次 |
| 预防 | HPV疫苗 |
