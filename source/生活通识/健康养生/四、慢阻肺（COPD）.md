## 四、慢阻肺（COPD）

### 4.1 什么是慢阻肺

慢阻肺 = 气流受限、进行性发展的慢性气道炎症

| 病因 | 说明 |
|------|------|
| 吸烟 | 最主要病因（80-90%）|
| 空气污染 | PM2.5、工业粉尘 |
| 职业暴露 | 粉尘、化学气体 |
| 遗传因素 | α1-抗胰蛋白酶缺乏 |

### 4.2 症状

| 症状 | 说明 |
|------|------|
| 慢性咳嗽 | 晨起明显 |
| 咳痰 | 白色粘液痰 |
| 进行性呼吸困难 | 爬楼、走路时加重 |
| 急性加重 | 感染后症状加重 |

### 4.3 预防措施

| 措施 | 最重要 |
|------|--------|
| 戒烟 | 最有效措施 |
| 避免二手烟 | 同样有害 |
| 避免空气污染 | 雾霾戴口罩 |
| 职业防护 | 戴防护面具 |
| 疫苗接种 | 流感+肺炎疫苗 |
| 锻炼身体 | 改善肺功能 |
