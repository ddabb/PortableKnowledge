## 四、控制三高

### 4.1 高血压

| 指标 | 目标 |
|------|------|
| 理想血压 | <120/80 mmHg |
| 正常高值 | 120-139/80-89 mmHg |
| 高血压 | ≥140/90 mmHg |

**管理要点：**
- 定期监测血压
- 低盐饮食
- 按时服药
- 避免情绪激动

### 4.2 高血脂

| 指标 | 目标 |
|------|------|
| 总胆固醇 | <5.2 mmol/L |
| 甘油三酯 | <1.7 mmol/L |
| LDL（坏胆固醇）| <3.4 mmol/L |
| HDL（好胆固醇）| >1.0 mmol/L |

### 4.3 高血糖

| 指标 | 目标 |
|------|------|
| 空腹血糖 | 4.4-7.0 mmol/L |
| 餐后2小时血糖 | <10.0 mmol/L |
| 糖化血红蛋白 | <7.0% |
