## 四、科学预防措施

### 4.1 饮食预防

#### 总体原则

| 原则 | 说明 |
|------|------|
| 控制总热量 | 维持理想体重 |
| 均衡营养 | 碳水50-60%，蛋白15-20%，脂肪20-30% |
| 低GI饮食 | 选择低升糖指数食物 |
| 规律进餐 | 定时定量 |

#### 食物选择

| 推荐食物 | 限制食物 |
|----------|----------|
| 全谷物 | 白米饭 |
| 蔬菜水果 | 甜饮料 |
| 豆类 | 糖果糕点 |
| 鱼/鸡胸肉 | 肥肉 |
| 坚果 | 油炸食品 |

#### 升糖指数（GI）

| 分类 | GI值 | 食物举例 |
|------|------|----------|
| 低GI | <55 | 燕麦、荞麦、绿叶菜 |
| 中GI | 55-70 | 糙米饭、全麦面包 |
| 高GI | >70 | 白米饭、白面包、西瓜 |

#### 饮食口诀

```
先吃菜，后吃肉，最后吃主食
少放油，少放盐，多吃蔬菜
用粗粮，代替精米精面
用白肉，代替部分红肉
用茶，代替甜饮料
```

### 4.2 运动干预

#### 运动处方

| 项目 | 建议 |
|------|------|
| 类型 | 有氧运动+力量训练 |
| 频率 | 每周5次 |
| 时长 | 每次30-60分钟 |
| 强度 | 中等强度（微微出汗）|

#### 推荐运动

| 运动类型 | 示例 |
|----------|------|
| 有氧运动 | 快走、游泳、骑车、跳舞 |
| 力量训练 | 哑铃、弹力带、深蹲 |
| 柔韧性训练 | 瑜伽、太极 |

#### 运动注意事项

| 注意事项 | 说明 |
|----------|------|
| 餐后运动 | 餐后1-2小时 |
| 循序渐进 | 从低强度开始 |
| 坚持不懈 | 每周至少150分钟 |
| 安全第一 | 避免低血糖 |

### 4.3 体重管理

#### BMI计算

```
BMI = 体重(kg) ÷ 身高²(m²)

理想BMI：18.5-24
超重：24-28
肥胖：≥28
```

#### 减重目标

| 初始体重 | 目标 |
|----------|------|
| 超重 | 减重5-10% |
| 肥胖 | 减重10-15% |

#### 减重策略

```
减少热量摄入 + 增加热量消耗 = 持续减重

每天减少500kcal = 每周减重0.5kg
```

### 4.4 作息管理
