## 四、肝脏疾病

### 4.1 常见肝病

| 疾病 | 说明 |
|------|------|
| 乙肝/丙肝 | 病毒性肝炎 |
| 酒精肝 | 长期饮酒 |
| 脂肪肝 | 代谢相关 |
| 肝硬化 | 晚期肝病 |
| 肝癌 | 死亡率高的癌症 |

### 4.2 肝炎预防

| 类型 | 传播途径 | 预防 |
|------|---------|------|
| 甲肝 | 粪口传播 | 饮食卫生、疫苗 |
| 乙肝 | 血液/母婴/性 | 疫苗、避免血液接触 |
| 丙肝 | 血液传播 | 避免血液接触 |

### 4.3 脂肪肝预防

| 脂肪肝类型 | 说明 |
|------------|------|
| 酒精性脂肪肝 | 饮酒导致 |
| 非酒精性脂肪肝 | 代谢相关 |

**预防措施：**

| 措施 | 说明 |
|------|------|
| 戒酒 | 最有效 |
| 控制体重 | 减重5-10%可逆转 |
| 健康饮食 | 低糖低脂 |
| 规律运动 | 每周150分钟 |
| 控制血糖血脂 | 代谢综合征管理 |

### 4.4 伤肝行为

| 行为 | 危害 |
|------|------|
| 酗酒 | 直接损伤肝细胞 |
| 滥用药物 | 药物性肝炎 |
| 高脂饮食 | 脂肪肝 |
| 熬夜 | 影响肝代谢 |
| 情绪抑郁 | 影响肝功能 |

### 4.5 护肝措施

| 措施 | 说明 |
|------|------|
| 均衡饮食 | 多蔬果少油腻 |
| 规律运动 | 每周至少5次 |
| 充足睡眠 | 23点前入睡 |
| 控制体重 | BMI<24 |
| 定期体检 | 肝功能检查 |
| 接种疫苗 | 乙肝疫苗 |
