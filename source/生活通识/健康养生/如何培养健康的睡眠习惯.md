## 一，睡眠的重要性

### 1.1 睡眠的作用

| 作用 | 说明 |
|------|------|
| 恢复身体 | 修复组织，生长激素分泌 |
| 整理记忆 | 巩固白天学习的知识 |
| 清除废物 | 大脑清除代谢废物 |
| 调节情绪 | 稳定情绪，减少焦虑 |
| 增强免疫 | 提高免疫力 |

### 1.2 睡眠不足的危害

| 短期 | 长期 |
|------|------|
| 注意力下降 | 心血管疾病 |
| 反应迟钝 | 糖尿病风险 |
| 情绪不稳 | 肥胖风险 |
| 记忆力下降 | 免疫力下降 |
| 车祸风险增加 | 预期寿命缩短 |

## 二，睡眠知识

### 2.1 成人睡眠需求

| 年龄 | 推荐睡眠 | 备注 |
|------|----------|------|
| 18-64岁 | 7-9小时 | 足够就好 |
| 65岁以上 | 7-8小时 | 可适当减少 |

### 2.2 睡眠周期

| 周期 | 阶段 | 时长 | 特点 |
|------|------|------|------|
| 1个周期 | 浅睡眠 | 20分钟 | 入睡期 |
| | 深睡眠 | 40分钟 | 修复期 |
| | 快速眼动期(REM) | 20分钟 | 梦境期 |

每晚4-6个完整周期即可

## 三，睡眠卫生

### 3.1 作息规律

| 要点 | 说明 |
|------|------|
| 固定时间睡 | 每天同一时间上床 |
| 固定时间起 | 每天同一时间起床 |
| 周末不补觉 | 最多1小时 |
| 午睡适度 | 20-30分钟，下午3点前 |

### 3.2 睡前习惯

| 禁忌 | 推荐 |
|------|------|
| 手机/电脑 | 提前1小时放下 |
| 咖啡/茶 | 下午2点后不喝 |
| 剧烈运动 | 睡前3小时停止 |
| 饱餐 | 睡前3小时吃完 |
| 饮酒 | 虽然助眠但降低睡眠质量 |

### 3.3 睡眠环境

| 要素 | 理想状态 |
|------|----------|
| 温度 | 18-22°C |
| 湿度 | 40-60% |
| 光线 | 完全黑暗 |
| 声音 | 安静或白噪音 |
| 床品 | 舒适、支撑好 |

## 四，快速入睡方法

### 4.1 4-7-8呼吸法

```
吸气4秒 → 屏住呼吸7秒 → 呼气8秒
重复3-4次
```

### 4.2 身体扫描

```
从脚趾到头顶
依次感受每个部位
放松每块肌肉
```

### 4.3 478法则

| 步骤 | 动作 |
|------|------|
| 4 | 舌尖抵上颚，呼气发出"呼"声 |
| 7 | 屏住呼吸7秒 |
| 8 | 呼气8秒 |
