# 心脑血管疾病预防：从风险评估到生活方式

心脑血管疾病是我国居民死亡的"头号杀手"。但好消息是，大部分心脑血管疾病是可以预防的。

## 一、认识心脑血管疾病

### 什么是心脑血管疾病？

- **心血管疾病**：冠心病、心肌梗死、心力衰竭等
- **脑血管疾病**：脑梗死、脑出血等

### 为什么可怕？

- 发病突然，可能致命
- 致残率高，影响生活质量
- 越来越年轻化
- 很多早期无症状

## 二、评估你的风险

### 高危人群

| 风险因素 | 说明 |
|----------|------|
| **高血压** | 血压≥140/90mmHg |
| **高血脂** | LDL-C升高 |
| **糖尿病** | 血糖控制不佳 |
| **吸烟** | 吸烟或二手烟 |
| **肥胖** | BMI≥28或腰围超标 |
| **家族史** | 直系亲属有早发心脑血管病 |
| **年龄** | 男性≥45岁，女性≥55岁 |
| **缺乏运动** | 久坐不动 |

### 自测问题

- 你吸烟吗？
- 你的血压正常吗？
- 你的血脂正常吗？
- 你有糖尿病吗？
- 你的体重超标吗？
- 你每周运动少于3次吗？
- 你有心血管病家族史吗？

**如果≥3个"是"，你就是高危人群。**

## 三、生活方式调整

### 1. 戒烟限酒

- **戒烟**：吸烟者心梗风险是不吸烟者的2-6倍
- **限酒**：男性每天酒精不超过25g，女性不超过15g
- 戒烟1年后，心梗风险降低50%

### 2. 健康饮食

| 建议 | 具体做法 |
|------|----------|
| **低盐** | 每天盐<5g，少吃腌制食品 |
| **低脂** | 减少动物脂肪，选择植物油 |
| **高纤维** | 每天蔬菜300-500g，水果200-350g |
| **适量蛋白质** | 鱼类、禽类优于红肉 |
| **控制热量** | 避免肥胖 |

### 3. 规律运动

- **目标**：每周150分钟中等强度有氧运动
- **方式**：快走、慢跑、游泳、骑车等
- **强度**：运动时能说话但不能唱歌
- **注意**：循序渐进，避免突然剧烈运动

### 4. 控制体重

- 目标BMI：18.5-24
- 目标腰围：男性<90cm，女性<85cm
- 每减重5-10%，心血管风险显著降低

## 四、监测与治疗

### 定期监测指标

| 指标 | 目标值 | 监测频率 |
|------|--------|----------|
| **血压** | <140/90mmHg | 每月 |
| **空腹血糖** | <6.1mmol/L | 每3-6个月 |
| **血脂LDL-C** | <2.6mmol/L | 每6-12个月 |
| **体重** | BMI 18.5-24 | 每月 |

### 已确诊患者的注意事项

- **遵医嘱服药**：不可自行停药或减量
- **定期复查**：监测药物效果和副作用
- **控制危险因素**：血压、血糖、血脂达标
- **学会急救**：识别心梗、脑卒中信号

### 心梗信号

- 持续胸痛>15分钟
- 胸痛伴大汗、恶心
- 疼痛放射到左肩、左臂、下巴
- 立即拨打120，不要自己开车

### 脑卒中信号（FAST原则）

- **F（Face）**：面部不对称
- **A（Arm）**：手臂无力
- **S（Speech）**：说话不清
- **T（Time）**：立即拨打120

## 五、常见误区与真相

| 误区 | 真相 |
|------|------|
| "我年轻不会得心脑血管病" | 心脑血管疾病越来越年轻化，三四十岁发病很常见 |
| "我没有症状就没问题" | 高血压、高血脂早期往往无症状，等有症状可能已晚期 |
| "只有胖人才会得心脑血管病" | 瘦人也可能有高血压、高血脂 |
| "保健品能预防心脑血管病" | 不能替代健康生活方式和正规治疗 |
| "心脑血管病治不好" | 早期干预可以有效控制，预防进展 |
| "血压正常就能停药" | 高血压需要长期管理，停药会反弹 |

## 小结

预防心脑血管疾病，记住这几点：

- **定期体检**，了解自己的血压、血糖、血脂
- **健康生活**，戒烟限酒、合理饮食、规律运动
- **控制体重**，保持BMI和腰围在正常范围
- **遵医嘱治疗**，不要自行停药
- **学会急救**，关键时刻能救命

**心脑血管疾病可防可控，关键是行动起来。**
