> 心脑血管疾病是威胁中国人健康的第一杀手，本文讲解如何科学预防。

---

## 一、心脑血管疾病概述

### 1.1 常见类型

| 疾病 | 说明 |
|------|------|
| **冠心病** | 心脏血管堵塞 |
| **脑卒中** | 脑血管堵塞或破裂 |
| **高血压** | 血压持续升高 |
| **心律失常** | 心脏跳动不规律 |
| **心力衰竭** | 心脏泵血功能下降 |

### 1.2 中国现状

| 数据 | 说明 |
|------|------|
| 患病人数 | 3.3亿+ |
| 死亡率 | 占总死亡40%以上 |
| 发病年龄 | 越来越年轻化 |

---

## 二、危险因素

### 2.1 不可改变因素

| 因素 | 说明 |
|------|------|
| **年龄** | 55岁以上风险增加 |
| **性别** | 男性风险更高 |
| **家族史** | 父母有病史风险增加 |

### 2.2 可改变因素

| 因素 | 影响 |
|------|------|
| **高血压** | 最大危险因素 |
| **高血脂** | 堵塞血管 |
| **高血糖** | 损伤血管 |
| **吸烟** | 直接损伤血管 |
| **肥胖** | 增加心脏负担 |
| **缺乏运动** | 心肺功能下降 |
| **高盐饮食** | 升高血压 |
| **酗酒** | 损伤心肌 |

---

## 三、科学预防措施

### 3.1 饮食预防

| 推荐食物 | 限制食物 |
|----------|----------|
| 蔬菜水果 | 腌制食品 |
| 全谷物 | 高盐食品 |
| 深海鱼 | 动物内脏 |
| 坚果 | 油炸食品 |
| 橄榄油 | 甜饮料 |

**每日盐摄入：** <6克
**每日油摄入：** 25-30克
**蔬菜水果：** 每天5份以上

### 3.2 运动处方

| 指标 | 建议 |
|------|------|
| 运动频率 | 每周5次 |
| 运动时长 | 每次30-60分钟 |
| 运动强度 | 中等强度（微微出汗）|
| 推荐运动 | 快走、游泳、骑车 |

### 3.3 体重管理

| 指标 | 目标 |
|------|------|
| BMI | 18.5-24 |
| 腰围（男） | <90cm |
| 腰围（女） | <85cm |

### 3.4 戒烟限酒

| 戒烟 | 限酒 |
|------|------|
| 完全戒烟 | 男性<25g/天 |
| 避免二手烟 | 女性<15g/天 |
| 电子烟也有害 | 最好戒酒 |

## 四、控制三高

### 4.1 高血压

| 指标 | 目标 |
|------|------|
| 理想血压 | <120/80 mmHg |
| 正常高值 | 120-139/80-89 mmHg |
| 高血压 | ≥140/90 mmHg |

**管理要点：**
- 定期监测血压
- 低盐饮食
- 按时服药
- 避免情绪激动

### 4.2 高血脂

| 指标 | 目标 |
|------|------|
| 总胆固醇 | <5.2 mmol/L |
| 甘油三酯 | <1.7 mmol/L |
| LDL（坏胆固醇）| <3.4 mmol/L |
| HDL（好胆固醇）| >1.0 mmol/L |

### 4.3 高血糖

| 指标 | 目标 |
|------|------|
| 空腹血糖 | 4.4-7.0 mmol/L |
| 餐后2小时血糖 | <10.0 mmol/L |
| 糖化血红蛋白 | <7.0% |

## 五、早期信号识别

### 5.1 心脏求救信号

| 信号 | 说明 |
|------|------|
| 胸闷胸痛 | 活动后加重 |
| 呼吸困难 | 平躺加重 |
| 心悸 | 心脏乱跳 |
| 乏力 | 活动耐力下降 |
| 水肿 | 下肢浮肿 |

### 5.2 脑卒中信号（FAST原则）

| 信号 | 说明 |
|------|------|
| **F - Face** | 面部歪斜 |
| **A - Arm** | 手臂无力 |
| **S - Speech** | 说话不清 |
| **T - Time** | 时间紧迫，立即就医 |

### 5.3 黄金时间窗

| 情况 | 时间窗 |
|------|--------|
| 溶栓治疗 | 发病4.5小时内 |
| 取栓治疗 | 发病6-24小时内 |
| 就近就医 | 不要等不要拖 |

## 六、定期体检

### 6.1 必查项目

| 项目 | 频率 |
|------|------|
| 血压 | 每月 |
| 血糖 | 每季度 |
| 血脂 | 每年 |
| 心电图 | 每年 |
| 心脏彩超 | 40岁后每年 |

### 6.2 高危人群

| 人群 | 检查频率 |
|------|----------|
| 有家族史 | 35岁起每年体检 |
| 三高患者 | 按医嘱定期检查 |
| 吸烟者 | 40岁起每年检查 |
| 肥胖者 | 每年全面检查 |

## 七、紧急情况处理

### 7.1 胸痛急救

```
1. 立即停止活动
2. 拨打120
3. 舌下含服硝酸甘油（如果有）
4. 保持冷静，等待救援
5. 不要自行前往医院
```

### 7.2 脑卒中急救

```
1. 保持患者平躺
2. 拨打120
3. 不要喂水喂药
4. 清理口腔异物
5. 记录发病时间
```

## 八、常见误区

| 误区 | 真相 |
|------|------|

| "保健品能替代药" | 不能替代正规治疗 |
