# 心脑血管疾病预防指南

## 一、心脑血管疾病概述

### 1.1 常见类型

| 疾病 | 说明 |
|------|------|
| **冠心病** | 心脏血管堵塞 |
| **脑卒中** | 脑血管堵塞或破裂 |
| **高血压** | 血压持续升高 |
| **心律失常** | 心脏跳动不规律 |
| **心力衰竭** | 心脏泵血功能下降 |

### 1.2 中国现状

| 数据 | 说明 |
|------|------|
| 患病人数 | 3.3亿+ |
| 死亡率 | 占总死亡40%以上 |
| 发病年龄 | 越来越年轻化 |

## 二、危险因素

### 2.1 不可改变因素

| 因素 | 说明 |
|------|------|
| **年龄** | 55岁以上风险增加 |
| **性别** | 男性风险更高 |
| **家族史** | 父母有病史风险增加 |

### 2.2 可改变因素

| 因素 | 影响 |
|------|------|
| **高血压** | 最大危险因素 |
| **高血脂** | 堵塞血管 |
| **高血糖** | 损伤血管 |
| **吸烟** | 直接损伤血管 |
| **肥胖** | 增加心脏负担 |
| **缺乏运动** | 心肺功能下降 |
| **高盐饮食** | 升高血压 |
| **酗酒** | 损伤心肌 |

## 三、科学预防措施

### 3.1 一级预防（病因预防）

#### 戒烟

| 戒烟好处 | 说明 |
|----------|------|
| 肺癌风险 | 戒烟10年后降至不吸烟者水平 |
| 心脑血管 | 戒烟1年后风险减半 |
| 其他癌症 | 口腔癌、食管癌风险降低 |

#### 限酒

| 饮酒量 | 风险 |
|--------|------|
| 0 | 无风险 |
| <25g/天 | 低风险 |
| 25-50g/天 | 中风险 |
| >50g/天 | 高风险 |

#### 健康饮食

| 推荐 | 限制 |
|------|------|
| 新鲜蔬菜水果 | 腌制食品 |
| 全谷物 | 加工肉制品 |
| 深海鱼 | 霉变食物 |
| 绿茶 | 65°C以上热饮 |

### 3.2 二级预防（早发现）

**核心理念：早发现=早治疗=高治愈率**

| 筛查方法 | 适用人群 |
|----------|----------|
| 低剂量CT | 50岁以上吸烟者 |
| 乳腺钼靶 | 40岁以上女性 |
| 宫颈TCT+HPV | 有性生活女性 |
| 肠镜 | 50岁以上人群 |
| 胃镜 | 高危人群 |
| AFP+肝脏超声 | 乙肝患者 |

### 3.3 疫苗预防

| 疫苗 | 预防癌症 |
|------|----------|
| 乙肝疫苗 | 肝癌 |
| HPV疫苗 | 宫颈癌等 |

## 四、控制三高

### 4.1 高血压

| 指标 | 目标 |
|------|------|
| 理想血压 | <120/80 mmHg |
| 正常高值 | 120-139/80-89 mmHg |
| 高血压 | ≥140/90 mmHg |

**管理要点：**
- 定期监测血压
- 低盐饮食
- 按时服药
- 避免情绪激动

### 4.2 高血脂

| 指标 | 目标 |
|------|------|
| 总胆固醇 | <5.2 mmol/L |
| 甘油三酯 | <1.7 mmol/L |
| LDL（坏胆固醇）| <3.4 mmol/L |
| HDL（好胆固醇）| >1.0 mmol/L |

### 4.3 高血糖

| 指标 | 目标 |
|------|------|
| 空腹血糖 | 4.4-7.0 mmol/L |
| 餐后2小时血糖 | <10.0 mmol/L |
| 糖化血红蛋白 | <7.0% |

## 五、定期体检

### 5.1 必查项目

| 项目 | 频率 |
|------|------|
| 血压 | 每月 |
| 血糖 | 每季度 |
| 血脂 | 每年 |
| 心电图 | 每年 |
| 心脏彩超 | 40岁后每年 |

### 5.2 高危人群

| 人群 | 检查频率 |
|------|----------|
| 有家族史 | 35岁起每年体检 |
| 三高患者 | 按医嘱定期检查 |
| 吸烟者 | 40岁起每年检查 |
| 肥胖者 | 每年全面检查 |

## 六、紧急情况处理

### 6.1 胸痛急救

```
1. 立即停止活动
2. 拨打120
3. 舌下含服硝酸甘油（如果有）
4. 保持冷静，等待救援
5. 不要自行前往医院
```

### 6.2 脑卒中急救

```
1. 保持患者平躺
2. 拨打120
3. 不要喂水喂药
4. 清理口腔异物
5. 记录发病时间
```

## 七、总结

心脑血管疾病是我国居民的主要死亡原因，通过采取科学的预防措施，我们可以有效降低患病风险：

- 控制可改变的危险因素
- 保持健康的生活方式
- 定期体检，早发现早治疗
- 掌握紧急情况的处理方法

希望本指南能够帮助你更好地预防心脑血管疾病，保持健康的生活！
