> 癌症1/3可预防，1/3可治愈，1/3可延长生命。关键在于早预防、早发现、早治疗。

---

## 一、癌症基础知识

### 1.1 什么是癌症

癌症 = 正常细胞异常增生形成恶性肿瘤

| 特点 | 说明 |
|------|------|
| 异常增生 | 细胞不受控制地分裂 |
| 侵袭性 | 可以侵入周围组织 |
| 转移 | 可以扩散到全身 |
| 可预防 | 多数与生活方式相关 |

### 1.2 中国高发癌症

| 排名 | 男性 | 女性 |
|------|------|------|
| 1 | 肺癌 | 乳腺癌 |
| 2 | 肝癌 | 肺癌 |
| 3 | 胃癌 | 结直肠癌 |
| 4 | 食管癌 | 胃癌 |
| 5 | 结直肠癌 | 肝癌 |

## 二、致癌因素

### 2.1 一级致癌物

| 物质 | 来源 |
|------|------|
| 烟草 | 主动/被动吸烟 |
| 酒精 | 饮酒 |
| 黄曲霉素 | 霉变食物 |
| 亚硝胺 | 腌制食品 |
| 苯并芘 | 烧烤/油炸 |
| PM2.5 | 空气污染 |
| 甲醛 | 装修材料 |

### 2.2 生活方式危险因素

| 因素 | 影响 |
|------|------|
| 吸烟 | 导致肺癌、喉癌等 |
| 酗酒 | 导致肝癌、食管癌 |
| 高脂饮食 | 导致结直肠癌 |
| 腌制食品 | 导致胃癌 |
| 肥胖 | 多种癌症风险增加 |
| 缺乏运动 | 增加癌症风险 |

### 2.3 感染相关癌症

| 病原体 | 相关癌症 |
|--------|----------|
| 乙肝/丙肝 | 肝癌 |
| HPV | 宫颈癌、肛门癌 |
| 幽门螺杆菌 | 胃癌 |
| EB病毒 | 鼻咽癌 |

## 三、科学预防措施

### 3.1 一级预防（病因预防）

#### 戒烟

| 戒烟好处 | 说明 |
|----------|------|
| 肺癌风险 | 戒烟10年后降至不吸烟者水平 |
| 心脑血管 | 戒烟1年后风险减半 |
| 其他癌症 | 口腔癌、食管癌风险降低 |

#### 限酒

| 饮酒量 | 风险 |
|--------|------|
| 0 | 无风险 |
| <25g/天 | 低风险 |
| 25-50g/天 | 中风险 |
| >50g/天 | 高风险 |

#### 健康饮食

| 推荐 | 限制 |
|------|------|
| 新鲜蔬菜水果 | 腌制食品 |
| 全谷物 | 加工肉制品 |
| 深海鱼 | 霉变食物 |
| 绿茶 | 65°C以上热饮 |

### 3.2 二级预防（早发现）

**核心理念：早发现=早治疗=高治愈率**

| 筛查方法 | 适用人群 |
|----------|----------|
| 低剂量CT | 50岁以上吸烟者 |
| 乳腺钼靶 | 40岁以上女性 |
| 宫颈TCT+HPV | 有性生活女性 |
| 肠镜 | 50岁以上人群 |
| 胃镜 | 高危人群 |
| AFP+肝脏超声 | 乙肝患者 |

### 3.3 疫苗预防

| 疫苗 | 预防癌症 |
|------|----------|
| 乙肝疫苗 | 肝癌 |
| HPV疫苗 | 宫颈癌等 |

## 四、常见癌症筛查

### 4.1 肺癌

| 项目 | 说明 |
|------|------|
| 筛查方法 | 低剂量螺旋CT |
| 适用人群 | 50-74岁，吸烟≥20包/年 |
| 筛查频率 | 每年1次 |
| 治愈率 | 早期发现>90% |

### 4.2 乳腺癌

| 项目 | 说明 |
|------|------|
| 筛查方法 | 乳腺钼靶+超声 |
| 适用人群 | 40岁以上女性 |
| 频率 | 每年1次 |
| 自检 | 每月月经后7天 |

### 4.3 结直肠癌

| 项目 | 说明 |
|------|------|
| 筛查方法 | 肠镜/便潜血 |
| 适用人群 | 50岁以上 |
| 频率 | 肠镜10年1次 |
| 癌前病变 | 息肉，早发现可切除 |

### 4.4 胃癌

| 项目 | 说明 |
|------|------|
| 筛查方法 | 胃镜 |
| 适用人群 | 40岁以上高危 |
| 高危因素 | 幽门螺杆菌、胃癌家族史 |
| 频率 | 1-2年1次 |

### 4.5 肝癌

| 项目 | 说明 |
|------|------|
| 筛查方法 | 肝脏超声+AFP |
| 适用人群 | 乙肝/丙肝患者 |
| 频率 | 6个月1次 |

### 4.6 宫颈癌

| 项目 | 说明 |
|------|------|
| 筛查方法 | TCT+HPV检测 |
| 适用人群 | 25-65岁女性 |
| 频率 | 3-5年1次 |
| 预防 | HPV疫苗 |

## 五、癌症早期信号

### 5.1 常见报警信号

| 信号 | 需警惕的癌症 |
|------|--------------|
| 原因不明的体重下降 | 多种癌症 |
| 不明原因的发热 | 淋巴瘤等 |
| 持续性疼痛 | 骨癌等 |
| 异常出血 | 宫颈癌、肠癌等 |
| 长期不愈合的溃疡 | 皮肤癌等 |
| 肿块 | 乳腺癌、淋巴瘤等 |
| 吞咽困难 | 食管癌 |
| 排便习惯改变 | 结直肠癌 |

### 5.2 七大报警信号

1. 身体任何部位出现肿块
2. 疣或痣明显变化
3. 持续性消化不良
4. 吞咽时哽咽感
5. 持续性嘶哑干咳
6. 原因不明的大便/小便带血
7. 原因不明的出血

## 八、常见误区

| 误区 | 真相 |
|------|------|
| "癌症=死亡" | 早期癌症很多可治愈 |
| "我没症状就不会得" | 早期往往没症状 |
| "体检正常就没问题" | 普通体检不等于癌症筛查 |
| "癌症会遗传" | 只有部分癌症遗传 |
| "吃保健品能防癌" | 没有证据支持 |
| "我年轻不会得" | 癌症越来越年轻化 |
