# 癌症预防指南：风险评估与早期筛查

"谈癌色变"是很多人的心态。其实，癌症可防可治，关键在于科学预防和早期发现。

## 一、认识癌症风险

### 什么人容易得癌症？

| 风险因素 | 说明 |
|----------|------|
| **年龄** | 年龄越大风险越高，但年轻化趋势明显 |
| **家族史** | 有癌症家族史者风险增加 |
| **吸烟** | 与多种癌症相关（肺癌、喉癌、膀胱癌等） |
| **饮酒** | 增加肝癌、食管癌、乳腺癌风险 |
| **肥胖** | 与多种癌症相关 |
| **病毒感染** | HPV（宫颈癌）、乙肝（肝癌）、幽门螺杆菌（胃癌） |
| **环境污染** | 空气污染、职业暴露 |
| **不健康饮食** | 高盐、高脂、低纤维饮食 |

### 自测你的癌症风险

- 你吸烟或长期暴露二手烟吗？
- 你有癌症家族史吗？
- 你经常饮酒吗？
- 你的BMI超过24吗？
- 你很少吃蔬菜水果吗？
- 你有慢性病毒感染（如乙肝、HPV）吗？

**如果≥3个"是"，建议加强筛查。**

## 二、生活方式防癌

### 1. 戒烟限酒

- **戒烟**：戒烟10年后，肺癌风险降低50%
- **限酒**：最好不饮酒，如果饮酒要适量

### 2. 健康饮食

| 建议 | 说明 |
|------|------|
| **多吃蔬菜水果** | 每天500g以上，降低多种癌症风险 |
| **减少红肉** | 每周不超过500g |
| **避免加工肉制品** | 香肠、火腿、腊肉等 |
| **控制盐摄入** | 每天不超过5g |
| **少吃油炸烧烤** | 高温烹饪产生致癌物 |

### 3. 控制体重

- 目标BMI：18.5-24
- 肥胖与乳腺癌、结直肠癌、胰腺癌等多种癌症相关

### 4. 规律运动

- 每周至少150分钟中等强度运动
- 运动可降低多种癌症风险

### 5. 接种疫苗

| 疫苗 | 预防癌症 | 适用人群 |
|------|----------|----------|
| **HPV疫苗** | 宫颈癌 | 9-45岁女性 |
| **乙肝疫苗** | 肝癌 | 未感染者 |

## 三、癌症筛查建议

### 肺癌筛查

| 项目 | 建议 |
|------|------|
| **人群** | 50-74岁，吸烟≥20包/年 |
| **方法** | 低剂量CT |
| **频率** | 每年1次 |

### 乳腺癌筛查

| 项目 | 建议 |
|------|------|
| **人群** | 40岁以上女性 |
| **方法** | 乳腺钼靶+超声 |
| **频率** | 每1-2年1次 |

### 宫颈癌筛查

| 项目 | 建议 |
|------|------|
| **人群** | 21岁以上女性 |
| **方法** | 宫颈涂片、HPV检测 |
| **频率** | 每3-5年1次 |

### 结直肠癌筛查

| 项目 | 建议 |
|------|------|
| **人群** | 45岁以上 |
| **方法** | 肠镜、粪便潜血试验 |
| **频率** | 肠镜每5-10年，粪便每年 |

### 胃癌筛查

| 项目 | 建议 |
|------|------|
| **人群** | 40岁以上高危人群 |
| **方法** | 胃镜 |
| **频率** | 视情况 |

### 肝癌筛查

| 项目 | 建议 |
|------|------|
| **人群** | 乙肝/丙肝携带者、肝硬化患者 |
| **方法** | 超声+甲胎蛋白 |
| **频率** | 每6个月 |

## 四、癌症早期信号

### 10个警示信号

1. **不明原因的体重下降**：半年内体重下降10%以上
2. **持续疲劳**：休息后不缓解
3. **异常出血**：咳血、便血、尿血、不规则阴道出血
4. **肿块**：身体任何部位出现肿块
5. **持续疼痛**：不明原因的持续疼痛
6. **伤口不愈合**：皮肤伤口长期不愈合
7. **排便习惯改变**：腹泻、便秘交替，便血
8. **吞咽困难**：进食时感觉堵塞
9. **持续咳嗽**：超过2周的咳嗽
10. **皮肤变化**：痣的颜色、形状改变

**出现以上症状，及时就医，但不必恐慌。**

## 五、常见误区与真相

| 误区 | 真相 |
|------|------|
| "癌症=死亡" | 早期癌症很多可治愈，5年生存率可达90% |
| "我没症状就不会得" | 早期往往没症状，定期筛查很重要 |
| "体检正常就没问题" | 普通体检≠癌症筛查，要做针对性检查 |
| "癌症会遗传" | 只有5-10%的癌症是遗传性的 |
| "吃保健品能防癌" | 没有证据支持，不如健康饮食 |
| "我年轻不会得" | 癌症越来越年轻化，不要掉以轻心 |
| "穿刺会扩散癌细胞" | 不会，穿刺是诊断的重要手段 |

## 小结

癌症预防记住这几点：

- **定期筛查**：根据年龄和风险做相应检查
- **健康生活**：戒烟限酒、合理饮食、规律运动
- **接种疫苗**：HPV、乙肝疫苗
- **关注信号**：身体异常变化及时就医
- **不要恐慌**：癌症可防可治，早发现早治疗

**癌症不可怕，可怕的是忽视预防和筛查。**
