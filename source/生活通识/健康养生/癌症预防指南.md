# 癌症预防指南

## 一、癌症基础知识

### 1.1 什么是癌症

癌症 = 正常细胞异常增生形成恶性肿瘤

| 特点 | 说明 |
|------|------|
| 异常增生 | 细胞不受控制地分裂 |
| 侵袭性 | 可以侵入周围组织 |
| 转移 | 可以扩散到全身 |
| 可预防 | 多数与生活方式相关 |

### 1.2 中国高发癌症

| 排名 | 男性 | 女性 |
|------|------|------|
| 1 | 肺癌 | 乳腺癌 |
| 2 | 肝癌 | 肺癌 |
| 3 | 胃癌 | 结直肠癌 |
| 4 | 食管癌 | 胃癌 |
| 5 | 结直肠癌 | 肝癌 |

## 二、致癌因素

### 2.1 一级致癌物

| 物质 | 来源 |
|------|------|
| 烟草 | 主动/被动吸烟 |
| 酒精 | 饮酒 |
| 黄曲霉素 | 霉变食物 |
| 亚硝胺 | 腌制食品 |
| 苯并芘 | 烧烤/油炸 |
| PM2.5 | 空气污染 |
| 甲醛 | 装修材料 |

### 2.2 生活方式危险因素

| 因素 | 影响 |
|------|------|
| 吸烟 | 导致肺癌、喉癌等 |
| 酗酒 | 导致肝癌、食管癌 |
| 高脂饮食 | 导致结直肠癌 |
| 腌制食品 | 导致胃癌 |
| 肥胖 | 多种癌症风险增加 |
| 缺乏运动 | 增加癌症风险 |

### 2.3 感染相关癌症

| 病原体 | 相关癌症 |
|--------|----------|
| 乙肝/丙肝 | 肝癌 |
| HPV | 宫颈癌、肛门癌 |
| 幽门螺杆菌 | 胃癌 |
| EB病毒 | 鼻咽癌 |

## 三、癌症早期信号

### 3.1 常见报警信号

| 信号 | 需警惕的癌症 |
|------|--------------|
| 原因不明的体重下降 | 多种癌症 |
| 不明原因的发热 | 淋巴瘤等 |
| 持续性疼痛 | 骨癌等 |
| 异常出血 | 宫颈癌、肠癌等 |
| 长期不愈合的溃疡 | 皮肤癌等 |
| 肿块 | 乳腺癌、淋巴瘤等 |
| 吞咽困难 | 食管癌 |
| 排便习惯改变 | 结直肠癌 |

### 3.2 七大报警信号

1. 身体任何部位出现肿块
2. 疣或痣明显变化
3. 持续性消化不良
4. 吞咽时哽咽感
5. 持续性嘶哑干咳
6. 原因不明的大便/小便带血
7. 原因不明的出血

## 四、消化道癌症早筛

### 4.1 胃癌筛查

| 方法 | 胃镜 |
|------|------|
| 高危人群 | 40岁以上，有家族史/幽门螺杆菌感染 |
| 频率 | 1-2年1次 |

### 4.2 大肠癌筛查

| 方法 | 肠镜或便潜血 |
|------|--------------|
| 人群 | 50岁以上 |
| 频率 | 肠镜10年1次，便潜血每年1次 |

### 4.3 肝癌筛查

| 方法 | 肝脏超声+AFP |
|------|--------------|
| 高危人群 | 乙肝/丙肝患者、肝硬化 |
| 频率 | 6个月1次 |

### 5.3 宫颈癌筛查

|------|-----------|

## 六、癌症预防措施

### 6.1 生活方式调整

- **戒烟限酒**：避免烟草使用，限制酒精摄入
- **健康饮食**：多吃蔬菜水果，减少红肉和加工肉制品摄入
- **适量运动**：每周至少150分钟中等强度运动
- **保持健康体重**：避免肥胖
- **充足睡眠**：每天7-8小时睡眠
- **减少压力**：学会放松和减压

### 6.2 环境因素控制

- **避免暴露**：减少接触致癌物质
- **室内通风**：保持室内空气流通
- **防晒**：避免过度日晒，使用防晒霜
- **安全装修**：选择环保装修材料

### 6.3 疫苗接种

- **乙肝疫苗**：预防肝癌
- **HPV疫苗**：预防宫颈癌等

## 七、总结

癌症是可以预防的，通过采取以下措施，我们可以有效降低癌症风险：

- 了解癌症基础知识和早期信号
- 避免致癌因素，保持健康生活方式
- 定期进行癌症筛查，早发现早治疗
- 接种相关疫苗，预防感染相关癌症

希望本指南能够帮助你更好地预防癌症，保持健康的生活！
