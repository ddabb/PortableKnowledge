# 糖尿病管理：从预防到控制

中国是糖尿病大国，患者超过1亿人。更可怕的是，还有很多人不知道自己已经患病。

## 一、认识糖尿病

### 什么是糖尿病？

- 血糖持续升高
- 胰岛素分泌不足或作用障碍
- 导致多种并发症

### 糖尿病类型

| 类型 | 特点 | 占比 |
|------|------|------|
| **1型** | 多见于儿童青少年，必须用胰岛素 | 约5% |
| **2型** | 与生活方式相关，中老年多见 | 约90% |
| **妊娠糖尿病** | 孕期发生 | 约5% |

### 诊断标准

| 指标 | 正常 | 糖尿病前期 | 糖尿病 |
|------|------|------------|--------|
| **空腹血糖** | <6.1 | 6.1-6.9 | ≥7.0 |
| **餐后2小时血糖** | <7.8 | 7.8-11.0 | ≥11.1 |
| **糖化血红蛋白** | <5.7% | 5.7-6.4% | ≥6.5% |

## 二、评估你的风险

### 高危人群

| 风险因素 | 说明 |
|----------|------|
| **年龄** | ≥40岁 |
| **家族史** | 父母或兄弟姐妹有糖尿病 |
| **肥胖** | BMI≥24，或腰围超标 |
| **缺乏运动** | 久坐不动 |
| **高血压** | 血压≥140/90mmHg |
| **血脂异常** | HDL-C低或TG高 |
| **妊娠糖尿病史** | 生过巨大儿（>4kg） |
| **多囊卵巢综合征** | 女性特有 |

### 自测问题

- 你年龄超过40岁吗？
- 你有糖尿病家族史吗？
- 你的体重超标吗？
- 你很少运动吗？
- 你有高血压或高血脂吗？

**如果≥3个"是"，建议查血糖。**

## 三、糖尿病前期：最后的干预机会

### 什么是糖尿病前期？

- 血糖高于正常但未达到糖尿病诊断标准
- 是糖尿病的"前奏"
- 每年有5-10%进展为糖尿病

### 逆转的机会

- **生活方式干预**：可降低58%的发病风险
- **减重**：减重5-10%可显著改善
- **运动**：每周150分钟中等强度运动
- **饮食**：控制碳水化合物，增加膳食纤维

## 四、糖尿病管理

### 1. 血糖监测

| 监测方式 | 频率 | 说明 |
|----------|------|------|
| **空腹血糖** | 每天（用药者） | 评估基础血糖 |
| **餐后血糖** | 每天（用药者） | 评估餐后血糖 |
| **糖化血红蛋白** | 每3个月 | 评估近3个月平均血糖 |
| **动态血糖监测** | 视情况 | 全面了解血糖波动 |

### 2. 饮食管理

| 建议 | 具体做法 |
|------|----------|
| **控制总量** | 根据身高体重计算每日热量 |
| **选择低GI食物** | 全谷物优于精制米面 |
| **增加膳食纤维** | 蔬菜每天300-500g |
| **定时定量** | 少食多餐，避免暴饮暴食 |
| **限制甜食** | 少吃含糖饮料和甜点 |

### 3. 运动建议

- **有氧运动**：每周至少150分钟
- **力量训练**：每周2-3次
- **避免久坐**：每小时起身活动
- **注意**：运动前后监测血糖，避免低血糖

### 4. 药物治疗

- 遵医嘱用药
- 不可自行停药
- 了解药物作用和副作用
- 定期复查

## 五、预防并发症

### 糖尿病的危害

| 并发症 | 危害 |
|----------|------|
| **心血管疾病** | 心梗、脑卒中 |
| **肾病** | 糖尿病肾病，可导致尿毒症 |
| **视网膜病变** | 可导致失明 |
| **神经病变** | 手脚麻木、疼痛 |
| **足病** | 糖尿病足，可导致截肢 |

### 预防并发症

| 措施 | 目标 |
|------|------|
| **控制血糖** | 糖化血红蛋白<7% |
| **控制血压** | <140/90mmHg |
| **控制血脂** | LDL-C<2.6mmol/L |
| **定期筛查** | 眼底、尿微量白蛋白、足部检查 |

## 六、常见误区与真相

| 误区 | 真相 |
|------|------|
| "我没症状就没有糖尿病" | 糖尿病早期往往无症状 |
| "血糖高一点点没关系" | 正常高值也要干预，否则会进展 |
| "糖尿病是吃糖引起的" | 多因素综合作用，遗传+生活方式 |
| "糖尿病前期不用管" | 这是最后的干预机会 |
| "保健品能降血糖" | 不能替代正规治疗 |
| "血糖正常就能停药" | 需遵医嘱调整，自行停药会反弹 |
| "胰岛素会上瘾" | 不会，胰岛素是正常激素 |
| "打了胰岛素就说明病情严重" | 只是一种治疗方式 |

## 小结

糖尿病管理记住这几点：

- **定期检测**：高危人群每年查血糖
- **抓住前期**：糖尿病前期可以逆转
- **综合管理**：血糖、血压、血脂都要达标
- **预防并发症**：定期筛查眼、肾、足
- **遵医嘱治疗**：不要自行停药

**糖尿病不可怕，可怕的是不重视。**
