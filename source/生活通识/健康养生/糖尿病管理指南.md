# 糖尿病管理指南

## 一、糖尿病基础知识

### 1.1 糖尿病类型

| 类型 | 说明 | 占比 |
|------|------|------|
| 1型糖尿病 | 胰岛素分泌不足 | 5-10% |
| 2型糖尿病 | 胰岛素抵抗 | 90%以上 |
| 妊娠糖尿病 | 孕期血糖升高 | 孕期 |
| 特殊类型 | 其他原因引起 | 少数 |

### 1.2 诊断标准

| 指标 | 正常 | 糖尿病前期 | 糖尿病 |
|------|------|------------|--------|
| 空腹血糖 | <6.1 | 6.1-7.0 | ≥7.0 |
| 餐后2h血糖 | <7.8 | 7.8-11.1 | ≥11.1 |
| 糖化血红蛋白 | <5.7% | 5.7-6.5% | ≥6.5% |

### 1.3 危害

| 急性危害 | 慢性危害 |
|-----------|-----------|
| 低血糖 | 心脏病/中风 |
| 酮症酸中毒 | 肾衰竭 |
| 高渗昏迷 | 失明 |
| | 截肢 |
| | 神经病变 |

## 二、糖尿病前期

### 2.1 什么是糖尿病前期

糖尿病前期 = 血糖高于正常但未达糖尿病标准

| 类型 | 空腹血糖 | 餐后2h血糖 |
|------|----------|-------------|
| 空腹血糖受损 | 6.1-7.0 | 正常 |
| 糖耐量减低 | 正常 | 7.8-11.1 |

### 2.2 糖尿病前期的意义

| 事实 | 说明 |
|------|------|
| 里程碑 | 是糖尿病的必经阶段 |
| 可逆 | 通过干预可恢复正常 |
| 高风险 | 每年约5-10%转为糖尿病 |

### 2.3 干预效果

| 干预方式 | 糖尿病发病减少 |
|-----------|----------------|
| 生活方式干预 | 40-70% |
| 二甲双胍 | 30% |
| 无干预 | 自然进程 |

## 三、糖尿病的预防

### 3.1 危险因素

| 不可控因素 | 可控因素 |
|------------|----------|
| 年龄 | 肥胖 |
| 家族史 | 缺乏运动 |
| 种族 | 不健康饮食 |
| 妊娠糖尿病史 | 高血压 |
| 多囊卵巢综合征 | 高血脂 |

### 3.2 预防措施

| 措施 | 说明 |
|------|------|
| 健康饮食 | 控制总热量，均衡营养 |
| 适量运动 | 每周150分钟中等强度运动 |
| 控制体重 | BMI保持在18.5-23.9 |
| 定期体检 | 检测血糖、血压、血脂 |
| 早期干预 | 糖尿病前期积极干预 |

## 四、糖尿病的治疗

### 4.1 治疗目标

| 指标 | 目标值 |
|------|--------|
| 空腹血糖 | 4.4-7.0 mmol/L |
| 餐后2小时 | <10.0 mmol/L |
| 糖化血红蛋白 | <7.0% |
| 血压 | <130/80 mmHg |
| LDL | <2.6 mmol/L |

### 4.2 治疗方法

| 方法 | 说明 |
|------|------|
| 生活方式干预 | 饮食控制、运动、戒烟限酒 |
| 口服降糖药 | 二甲双胍、磺脲类、DPP-4抑制剂等 |
| 胰岛素 | 1型糖尿病必须使用，2型糖尿病必要时使用 |
| 其他治疗 | 减重手术、GLP-1受体激动剂等 |

### 4.3 血糖监测

| 人群 | 监测频率 |
|------|----------|
| 糖尿病前期 | 每6-12个月 |
| 2型糖尿病 | 按医嘱 |
| 血糖控制不稳定 | 每天多次 |

| 时间点 | 意义 |
|--------|------|
| 空腹 | 基础血糖水平 |
| 餐后2小时 | 反映饮食影响 |
| 睡前 | 预防夜间低血糖 |

## 五、糖尿病的日常管理

### 5.1 饮食管理

| 原则 | 说明 |
|------|------|
| 控制总热量 | 根据体重和活动量计算 |
| 均衡营养 | 碳水化合物50-60%，蛋白质15-20%，脂肪20-30% |
| 合理分配 | 三餐定时定量，少量多餐 |
| 选择低GI食物 | 避免高糖、高脂食物 |
| 控制盐的摄入 | 每天不超过5g |

### 5.2 运动管理

| 原则 | 说明 |
|------|------|
| 适量运动 | 每周150分钟中等强度运动 |
| 选择合适运动 | 散步、慢跑、游泳、太极拳等 |
| 运动时间 | 餐后1-2小时为宜 |
| 运动前准备 | 监测血糖，携带糖果 |
| 循序渐进 | 逐渐增加运动强度和时间 |

### 5.3 药物管理

| 原则 | 说明 |
|------|------|
| 遵医嘱用药 | 按时按量服药 |
| 了解药物 | 了解药物的作用、副作用 |
| 定期复查 | 监测血糖、糖化血红蛋白 |
| 调整方案 | 根据血糖情况调整治疗方案 |

### 5.4 并发症管理

| 并发症 | 预防措施 |
|----------|----------|
| 心血管疾病 | 控制血压、血脂，抗血小板治疗 |
| 糖尿病肾病 | 控制血糖、血压，低蛋白饮食 |
| 糖尿病视网膜病变 | 定期眼底检查 |
| 糖尿病神经病变 | 控制血糖，改善循环 |
| 糖尿病足 | 足部护理，定期检查 |

## 六、糖尿病的自我管理

### 6.1 血糖监测

- **频率**：根据病情和治疗方案确定
- **记录**：记录血糖值、饮食、运动等情况
- **分析**：分析血糖波动的原因，调整治疗方案

### 6.2 低血糖管理

| 症状 | 处理措施 |
|------|----------|
| 轻度 | 立即进食15-20g含糖食物 |
| 中度 | 进食更多含糖食物 |
| 重度 | 静脉注射葡萄糖 |

### 6.3 糖尿病教育

- **学习知识**：了解糖尿病的相关知识
- **技能培训**：掌握血糖监测、胰岛素注射等技能
- **心理支持**：保持积极心态，避免焦虑、抑郁

## 七、特殊人群的糖尿病管理

### 7.1 老年人

| 特点 | 管理要点 |
|------|----------|
| 血糖控制目标适当放宽 | 避免低血糖 |
| 综合管理 | 关注心脑血管疾病 |
| 药物选择 | 避免低血糖风险高的药物 |

### 7.2 儿童和青少年

| 特点 | 管理要点 |
|------|----------|
| 生长发育 | 保证营养，避免营养不良 |
| 血糖控制 | 严格控制血糖，减少并发症 |
| 心理支持 | 帮助孩子适应疾病 |

### 7.3 孕妇

| 特点 | 管理要点 |
|------|----------|
| 血糖控制 | 严格控制血糖，减少胎儿风险 |
| 饮食管理 | 保证胎儿营养，控制总热量 |
| 产后随访 | 定期检测血糖，预防2型糖尿病 |

## 八、总结

糖尿病是一种慢性疾病，需要长期管理。通过采取以下措施，我们可以有效控制糖尿病，减少并发症的发生：

- 了解糖尿病的基础知识和预防措施
- 保持健康的饮食和生活习惯
- 定期监测血糖，遵医嘱用药
- 积极预防和管理并发症
- 接受糖尿病教育，提高自我管理能力

希望本指南能够帮助你更好地管理糖尿病，享受高质量的生活！
