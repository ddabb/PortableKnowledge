> 中国糖尿病患者超过1.4亿，糖尿病前期人群更多。糖尿病可防可控，关键在于早期干预。

---

## 一、糖尿病基础知识

### 1.1 糖尿病类型

| 类型 | 说明 | 占比 |
|------|------|------|
| 1型糖尿病 | 胰岛素分泌不足 | 5-10% |
| 2型糖尿病 | 胰岛素抵抗 | 90%以上 |
| 妊娠糖尿病 | 孕期血糖升高 | 孕期 |
| 特殊类型 | 其他原因引起 | 少数 |

### 1.2 诊断标准

| 指标 | 正常 | 糖尿病前期 | 糖尿病 |
|------|------|------------|--------|
| 空腹血糖 | <6.1 | 6.1-7.0 | ≥7.0 |
| 餐后2h血糖 | <7.8 | 7.8-11.1 | ≥11.1 |
| 糖化血红蛋白 | <5.7% | 5.7-6.5% | ≥6.5% |

### 1.3 危害

| 急性危害 | 慢性危害 |
|-----------|-----------|
| 低血糖 | 心脏病/中风 |
| 酮症酸中毒 | 肾衰竭 |
| 高渗昏迷 | 失明 |
| | 截肢 |
| | 神经病变 |

## 二、糖尿病前期

### 2.1 什么是糖尿病前期

糖尿病前期 = 血糖高于正常但未达糖尿病标准

| 类型 | 空腹血糖 | 餐后2h血糖 |
|------|----------|-------------|
| 空腹血糖受损 | 6.1-7.0 | 正常 |
| 糖耐量减低 | 正常 | 7.8-11.1 |

### 2.2 糖尿病前期的意义

| 事实 | 说明 |
|------|------|
| 里程碑 | 是糖尿病的必经阶段 |
| 可逆 | 通过干预可恢复正常 |
| 高风险 | 每年约5-10%转为糖尿病 |

### 2.3 干预效果

| 干预方式 | 糖尿病发病减少 |
|-----------|----------------|
| 生活方式干预 | 40-70% |
| 二甲双胍 | 30% |
| 无干预 | 自然进程 |

## 三、危险因素

### 3.1 不可改变因素

| 因素 | 说明 |
|------|------|
| 年龄 | ≥45岁风险增加 |
| 家族史 | 直系亲属患病风险增加 |
| 种族 | 亚洲人风险较高 |
| 妊娠糖尿病史 | 产后血糖异常风险增加 |

### 3.2 可改变因素

| 因素 | 影响 |
|------|------|
| 超重/肥胖 | 最大危险因素 |
| 腹型肥胖 | 危害更大 |
| 缺乏运动 | 胰岛素敏感性下降 |
| 高脂饮食 | 增加胰岛素抵抗 |
| 高糖饮食 | 加重胰岛负担 |
| 睡眠不足 | 影响血糖代谢 |
| 长期压力 | 升高血糖 |

### 3.3 风险自测

| 问题 | 是=1分 |
|------|--------|
| 年龄≥45岁 | 1 |
| BMI≥24 | 1 |
| 腰围男≥90/女≥85cm | 1 |
| 父母/兄弟姐妹有糖尿病 | 1 |
| 妊娠糖尿病或巨大儿分娩史 | 1 |
| 高血压 | 1 |
| 缺乏运动 | 1 |

**≥3分：** 高危人群，需筛查
**≥5分：** 极高危人群，立即干预

## 四、科学预防措施

### 4.1 饮食预防

#### 总体原则

| 原则 | 说明 |
|------|------|
| 控制总热量 | 维持理想体重 |
| 均衡营养 | 碳水50-60%，蛋白15-20%，脂肪20-30% |
| 低GI饮食 | 选择低升糖指数食物 |
| 规律进餐 | 定时定量 |

#### 食物选择

| 推荐食物 | 限制食物 |
|----------|----------|
| 全谷物 | 白米饭 |
| 蔬菜水果 | 甜饮料 |
| 豆类 | 糖果糕点 |
| 鱼/鸡胸肉 | 肥肉 |
| 坚果 | 油炸食品 |

#### 升糖指数（GI）

| 分类 | GI值 | 食物举例 |
|------|------|----------|
| 低GI | <55 | 燕麦、荞麦、绿叶菜 |
| 中GI | 55-70 | 糙米饭、全麦面包 |
| 高GI | >70 | 白米饭、白面包、西瓜 |

#### 饮食口诀

```
先吃菜，后吃肉，最后吃主食
少放油，少放盐，多吃蔬菜
用粗粮，代替精米精面
用白肉，代替部分红肉
用茶，代替甜饮料
```

### 4.2 运动干预

#### 运动处方

| 项目 | 建议 |
|------|------|
| 类型 | 有氧运动+力量训练 |
| 频率 | 每周5次 |
| 时长 | 每次30-60分钟 |
| 强度 | 中等强度（微微出汗）|

#### 推荐运动

| 运动类型 | 示例 |
|----------|------|
| 有氧运动 | 快走、游泳、骑车、跳舞 |
| 力量训练 | 哑铃、弹力带、深蹲 |
| 柔韧性训练 | 瑜伽、太极 |

#### 运动注意事项

| 注意事项 | 说明 |
|----------|------|
| 餐后运动 | 餐后1-2小时 |
| 循序渐进 | 从低强度开始 |
| 坚持不懈 | 每周至少150分钟 |
| 安全第一 | 避免低血糖 |

### 4.3 体重管理

#### BMI计算

```
BMI = 体重(kg) ÷ 身高²(m²)

理想BMI：18.5-24
超重：24-28
肥胖：≥28
```

#### 减重目标

| 初始体重 | 目标 |
|----------|------|
| 超重 | 减重5-10% |
| 肥胖 | 减重10-15% |

#### 减重策略

```
减少热量摄入 + 增加热量消耗 = 持续减重

每天减少500kcal = 每周减重0.5kg
```

### 4.4 作息管理

| 睡眠建议 | 说明 |
|----------|------|
| 时长 | 7-8小时 |
| 时间 | 固定作息 |
| 质量 | 提高睡眠质量 |

## 五、血糖监测

### 5.1 监测频率

| 人群 | 监测频率 |
|------|----------|
| 糖尿病前期 | 每6-12个月 |
| 2型糖尿病 | 按医嘱 |
| 血糖控制不稳定 | 每天多次 |

### 5.2 监测时间点

| 时间点 | 意义 |
|--------|------|
| 空腹 | 基础血糖水平 |
| 餐后2小时 | 反映饮食影响 |
| 睡前 | 预防夜间低血糖 |

### 5.3 达标标准

| 指标 | 目标值 |
|------|--------|
| 空腹血糖 | 4.4-7.0 mmol/L |
| 餐后2小时 | <10.0 mmol/L |
| 糖化血红蛋白 | <7.0% |
| 血压 | <130/80 mmHg |
| LDL | <2.6 mmol/L |

## 六、高危人群管理

### 6.1 谁是高危人群

| 高危因素 | 说明 |
|----------|------|
| 糖尿病前期 | 最重要的高危人群 |
| 超重/肥胖 | BMI≥24 |
| 年龄≥45岁 | 随年龄增加 |
| 妊娠糖尿病史 | 产后风险持续 |
| 心血管疾病 | 常与糖尿病并存 |
| 多囊卵巢综合征 | 增加糖尿病风险 |

### 6.2 高危人群行动

| 行动 | 说明 |
|------|------|
| 筛查 | 每6-12个月测血糖 |
| 生活方式 | 立即开始干预 |
| 控制体重 | 减重5-10% |
| 定期复查 | 每3-6个月 |

## 七、常见误区

| 误区 | 真相 |
|------|------|
| "我没症状就没有糖尿病" | 糖尿病前期往往无症状 |
| "血糖高一点点没关系" | 正常高值也要干预 |
| "糖尿病是吃糖引起的" | 多因素综合作用 |
| "糖尿病前期不用管" | 是糖尿病的最后干预机会 |
| "保健品能降血糖" | 不能替代正规治疗 |
| "血糖正常就能停药" | 需遵医嘱调整 |
