## 一、毒品防范

### 1. 认识毒品

**什么是毒品？**

毒品是指鸦片、海洛因、甲基苯丙胺（冰毒）、吗啡、大麻、可卡因以及国家规定管制的其他能够使人形成瘾癖的麻醉药品和精神药品。

**毒品的分类：**

| 类型 | 代表性毒品 | 危害 |
|------|------------|------|
| 鸦片类 | 鸦片、海洛因 | 严重损害身体，导致死亡 |
| 兴奋剂 | 冰毒、麻古 | 损坏神经系统，产生幻觉 |
| 致幻剂 | 摇头丸、K他命 | 导致精神障碍 |
| 大麻类 | 大麻、麻烟 | 损害大脑功能 |

### 2. 毒品危害

**对个人的危害：**
- 身体：器官损害、免疫力下降、死亡
- 精神：幻觉、焦虑、抑郁
- 生活：倾家荡产、家庭破裂

**对家庭的危害：**
- 经济负担沉重
- 家人受到伤害
- 家庭支离破碎

**对社会的危害：**
- 犯罪率上升
- 社会风气败坏
- 公共安全受到威胁

### 3. 如何远离毒品

**防范要点：**

| 场景 | 正确做法 |
|------|----------|
| 娱乐场所 | 不接受陌生人递给的饮料/香烟 |
| 聚会 | 离开视线的饮品不再喝 |
| 求职 | 警惕高薪诱惑，了解用工单位 |
| 上网 | 不点击陌生链接，不下载未知软件 |

**遇到毒品侵害：**

1. 坚决拒绝："我不碰这个"
2. 迅速离开现场
3. 及时告诉信任的人
4. 拨打110报警

### 4. 相关法律

**《中华人民共和国刑法》规定：**

- 制造、贩卖、运输毒品：最高可判处死刑
- 持有毒品：处三年以下有期徒刑
- 容留他人吸毒：处三年以下有期徒刑
