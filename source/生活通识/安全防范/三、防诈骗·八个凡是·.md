## 三、防诈骗"八个凡是"

| 只要符合以下条件，就是诈骗 |
|----------------------------|
| 1. 凡是自称公检法要求转账的 |
| 2. 凡是让你转账到"安全账户"的 |
| 3. 凡是通知中奖、领奖让你先交钱的 |
| 4. 凡是自称熟人/领导要求汇款的 |
| 5. 凡是要求你提供验证码的 |
| 6. 凡是要求你先交钱的网络兼职 |
| 7. 凡是陌生人让你点击链接的 |
| 8. 凡是陌生网站要登记银行卡信息的 |
