## 二、可以提取的情形

### 1. 购房提取

| 情形 | 说明 |
|------|------|
| 购买商品房 | 提取金额不超过房价 |
| 购买二手房 | 提取金额不超过房价 |
| 购买公有住房 | 提取金额不超过房价 |

### 2. 还贷提取

- 偿还公积金贷款
- 偿还商业住房贷款
- 可按年提取或按月冲还贷

### 3. 租房提取

- 无房职工可提取公积金支付房租
- 提取限额各地不同（如每年 1.5-2 万元）

### 4. 其他情形

| 情形 | 说明 |
|------|------|
| 离退休 | 可全额提取 |
| 完全丧失劳动能力 | 可全额提取 |
| 出境定居 | 可全额提取 |
| 死亡 | 继承人可提取 |
| 重大疾病 | 部分地区支持 |
| 装修 | 部分地区支持 |
