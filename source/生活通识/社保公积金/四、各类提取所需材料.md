## 四、各类提取所需材料

### 购房提取

| 材料 | 说明 |
|------|------|
| 身份证 | 原件 |
| 购房合同/房产证 | 原件或复印件 |
| 购房发票/契税发票 | 原件 |
| 银行卡 | 本人名下 |
| 配偶提取需结婚证 | 原件 |

### 租房提取

| 材料 | 说明 |
|------|------|
| 身份证 | 原件 |
| 无房证明 | 线上可查 |
| 银行卡 | 本人名下 |

*部分地区租房提取无需材料，直接线上申请*

### 还贷提取

| 材料 | 说明 |
|------|------|
| 身份证 | 原件 |
| 贷款合同 | 首次需提供 |
| 还款明细 | 近期还款记录 |
| 银行卡 | 本人名下 |

### 离退休提取

| 材料 | 说明 |
|------|------|
| 身份证 | 原件 |
| 退休证/退休审批表 | 原件 |
| 银行卡 | 本人名下 |
