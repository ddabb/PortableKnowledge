# 住房公积金提取全攻略

# 公积金提取全攻略

> 公积金是你的钱，合法合规都能取

---

## 一、公积金是什么

住房公积金是单位和职工共同缴存的长期住房储金，属于职工个人所有。

**缴存比例：**
- 单位缴存：工资的 5%-12%
- 个人缴存：工资的 5%-12%
- 合计：工资的 10%-24%

---

## 二、可以提取的情形

### 1. 购房提取

| 情形 | 说明 |
|------|------|
| 购买商品房 | 提取金额不超过房价 |
| 购买二手房 | 提取金额不超过房价 |
| 购买公有住房 | 提取金额不超过房价 |

### 2. 还贷提取

- 偿还公积金贷款
- 偿还商业住房贷款
- 可按年提取或按月冲还贷

### 3. 租房提取

- 无房职工可提取公积金支付房租
- 提取限额各地不同（如每年 1.5-2 万元）

### 4. 其他情形

| 情形 | 说明 |
|------|------|
| 离退休 | 可全额提取 |
| 完全丧失劳动能力 | 可全额提取 |
| 出境定居 | 可全额提取 |
| 死亡 | 继承人可提取 |
| 重大疾病 | 部分地区支持 |
| 装修 | 部分地区支持 |

---

## 三、提取方式

### 1. 线上提取（推荐）

**渠道：**
- 公积金中心APP或小程序
- 政务服务平台（如"浙里办"、"粤省事"）
- 支付宝/微信城市服务

**流程：**
1. 登录公积金账户
2. 选择提取类型
3. 填写信息、上传材料
4. 审核通过后到账

### 2. 线下提取

**流程：**
1. 携带材料到公积金中心
2. 填写提取申请表
3. 提交材料审核
4. 审核通过后转账

---

### 购房提取

| 材料 | 说明 |

| 购房发票/契税发票 | 原件 |

### 租房提取

| 无房证明 | 线上可查 |
| 银行卡 | 本人名下 |

*部分地区租房提取无需材料，直接线上申请*

### 还贷提取

| 材料 | 说明 |
|------|------|
| 身份证 | 原件 |
| 贷款合同 | 首次需提供 |
| 还款明细 | 近期还款记录 |
| 银行卡 | 本人名下 |

### 离退休提取

| 材料 | 说明 |
|------|------|
| 身份证 | 原件 |
| 退休证/退休审批表 | 原件 |
| 银行卡 | 本人名下 |

---

## 五、提取额度

### 1. 购房提取

- 提取金额不超过购房总价
- 可多次提取，累计不超过房价

### 2. 租房提取

- 每年提取限额各地不同
- 如北京：每年最高 24000 元
- 如上海：每月最高 3000 元

### 3. 还贷提取

- 每年提取金额不超过年还款额
- 可按月冲还贷（自动扣款）

---

## 六、常见问题

### Q1：离职后公积金怎么处理？

- 可提取（部分地区需封存满6个月）
- 可转移至新单位继续缴存
- 可保留账户，等退休后提取

### Q2：公积金贷款和提取冲突吗？

- 账户余额可用于还贷
- 申请贷款时余额会影响贷款额度
- 部分地区贷款后不能提取全部余额

### Q3：异地购房可以提取吗？

可以。异地购房提取公积金需要：
- 购房所在地本人或配偶户籍地
- 或本人工作地
- 部分地区放宽至全国

### Q4：夫妻可以互提吗？

可以。夫妻双方可提取各自的公积金用于：
- 共同购房
- 共同还贷
- 需提供结婚证

### Q5：提取后影响贷款额度吗？

会影响。公积金贷款额度通常与账户余额挂钩：
- 如上海：贷款额度 = 余额 × 30
- 如北京：贷款额度与余额和缴存年限相关

---

## 七、公积金贷款优势

| 对比项 | 公积金贷款 | 商业贷款 |
|--------|------------|----------|
| 利率 | 2.85%（5年以上） | 约 4.2% |
| 首付比例 | 较低 | 较高 |
| 贷款年限 | 最长30年 | 最长30年 |
| 提前还款 | 无违约金 | 可能有 |

**省钱示例：**
- 贷款100万，30年等额本息
- 公积金贷款月供：约 4135 元
- 商业贷款月供：约 4890 元
- 30年省利息：约 27 万元

---

## 八、实用技巧

| 技巧 | 说明 |
|------|------|
| 定期提取 | 租房提取每年一次，别错过 |
| 冲还贷 | 选择月冲，减轻还款压力 |
| 用足额度 | 夫妻双方都用足提取额度 |
| 关注政策 | 各地政策可能调整 |
| 线上办理 | 省时省力，推荐线上提取 |

---

> 公积金是你的合法财产，符合条件就可以提取，别让它"睡大觉"。

# 医疗保险报销指南

# 医保报销指南

> 医保是国家给的基本医疗保障，看病省钱的关键

---

## 一、医保是什么

医保是**基本医疗保险**的简称，分为两类：

| 类型 | 参保对象 | 特点 |
|------|----------|------|
| 职工医保 | 在职员工、灵活就业人员 | 报销比例高，有个人账户 |
| 居民医保 | 学生、儿童、无业居民 | 缴费低，无个人账户 |

---

## 二、医保报销范围

### 1. 能报销的

- 门诊看病
- 住院治疗
- 特殊病种门诊（如高血压、糖尿病门诊用药）
- 购药（定点药店）

### 2. 不能报销的

| 类型 | 说明 |
|------|------|
| 自费药品 | 医保目录外的药 |
| 自费诊疗项目 | 如美容、矫正牙齿、体检 |
| 非定点医院 | 未在医保定点医院就诊 |
| 工伤 | 走工伤保险 |
| 第三方责任 | 如车祸由肇事方赔偿 |

### 3. 医保目录

医保药品分为三类：

| 类别 | 说明 | 报销 |
|------|------|------|
| 甲类药品 | 临床必需、价格合理 | 100%纳入报销范围 |
| 乙类药品 | 可供选择、价格略高 | 部分纳入报销范围（如80%） |
| 丙类药品 | 价格较高或非必需 | 不纳入报销范围 |

---

## 三、报销流程

### 1. 门诊报销

**持卡就医：**
1. 带医保卡/医保电子凭证去定点医院
2. 挂号时出示医保卡
3. 看病、检查、开药
4. 结算时自动报销，只需支付个人部分

**注意事项：**
- 门诊有起付线（如在职人员每年1800元）
- 超过起付线的部分按比例报销
- 每年有报销限额

### 2. 住院报销

**流程：**
1. 办理住院时出示医保卡
2. 缴纳预交金
3. 治疗期间费用记账
4. 出院结算时自动报销

**注意：**
- 住院起付线（如三级医院1300元）
- 超过起付线的部分按比例报销
- 有年度最高支付限额

### 3. 异地就医报销

**步骤：**
1. 在参保地办理**异地就医备案**（可通过APP或医保窗口）
2. 持医保卡在异地定点医院就医
3. 结算时直接报销（部分地区需先垫付再回参保地报销）

**备案方式：**
- 国家医保服务平台APP
- 各地医保局微信公众号
- 线下医保窗口

---

## 四、报销比例（以职工医保为例）

### 门诊报销

| 医院等级 | 起付线 | 报销比例 |
|----------|--------|----------|
| 社区医院 | 1800元/年 | 90% |
| 二级医院 | 1800元/年 | 80% |
| 三级医院 | 1800元/年 | 70% |

*注：具体比例各地略有差异*

### 住院报销

| 医院等级 | 起付线 | 报销比例 |
|----------|--------|----------|
| 一级医院 | 300元 | 90% |
| 二级医院 | 600元 | 87% |
| 三级医院 | 1300元 | 85% |

*注：起付线可多次住院累计计算*

---

## 五、医保个人账户

### 1. 职工医保有个人账户

每月医保缴费的一部分进入个人账户，可以用于：
- 门诊看病
- 药店买药
- 住院自付部分

### 2. 居民医保无个人账户

但可以享受门诊和住院报销。

### 3. 个人账户余额

- 可以累积，不会清零
- 可以给家人使用（部分地区支持家庭共济）
- 异地转移时可以转移

---

## 六、医保常见问题

### Q1：换了城市工作，医保怎么办？

**医保转移接续：**
1. 在新参保地开始缴纳医保
2. 办理医保关系转移
3. 原参保地的缴费年限累计计算

### Q2：离职后医保断了怎么办？

- 断缴期间无法享受医保待遇
- 重新参保后需等待期（如3个月）
- 职工医保断缴可转居民医保

### Q3：医保卡丢了怎么办？

1. 挂失：拨打12333或到医保窗口
2. 补办：携带身份证到医保中心
3. 临时使用：使用医保电子凭证（微信/支付宝可激活）

### Q4：看病没带医保卡怎么办？

可以使用**医保电子凭证**：
- 微信搜索"医保电子凭证"
- 支付宝搜索"医保"
- 激活后可扫码结算

### Q5：医保报销后还能用商业保险报销吗？

可以。医保报销后的个人自付部分，符合商业保险条款的可以再报销。

---

## 七、省钱小技巧

| 技巧 | 说明 |
|------|------|
| 选对医院 | 小病去社区医院，报销比例更高 |
| 用甲类药 | 甲类药全额纳入报销 |
| 异地就医要备案 | 不备案可能报销比例降低 |
| 关注大病保险 | 超过医保限额可进入大病保险 |
| 门诊特殊病种 | 申请后门诊治疗按住院报销 |

---

## 八、医保缴费标准（参考）

### 职工医保

- 单位缴费：工资总额的 6%-10%
- 个人缴费：工资的 2%

### 居民医保

- 各地标准不同
- 一般每年 300-500 元（政府补贴后）
- 每年 9-12 月集中缴费

---

> 医保是基本保障，一定要按时缴纳，断缴后果很严重。
