# 公积金提取全攻略

> 公积金是你的钱，合法合规都能取

---

## 一、公积金是什么

住房公积金是单位和职工共同缴存的长期住房储金，属于职工个人所有。

**缴存比例：**
- 单位缴存：工资的 5%-12%
- 个人缴存：工资的 5%-12%
- 合计：工资的 10%-24%

---

## 二、可以提取的情形

### 1. 购房提取

| 情形 | 说明 |
|------|------|
| 购买商品房 | 提取金额不超过房价 |
| 购买二手房 | 提取金额不超过房价 |
| 购买公有住房 | 提取金额不超过房价 |

### 2. 还贷提取

- 偿还公积金贷款
- 偿还商业住房贷款
- 可按年提取或按月冲还贷

### 3. 租房提取

- 无房职工可提取公积金支付房租
- 提取限额各地不同（如每年 1.5-2 万元）

### 4. 其他情形

| 情形 | 说明 |
|------|------|
| 离退休 | 可全额提取 |
| 完全丧失劳动能力 | 可全额提取 |
| 出境定居 | 可全额提取 |
| 死亡 | 继承人可提取 |
| 重大疾病 | 部分地区支持 |
| 装修 | 部分地区支持 |

---

## 三、提取方式

### 1. 线上提取（推荐）

**渠道：**
- 公积金中心APP或小程序
- 政务服务平台（如"浙里办"、"粤省事"）
- 支付宝/微信城市服务

**流程：**
1. 登录公积金账户
2. 选择提取类型
3. 填写信息、上传材料
4. 审核通过后到账

### 2. 线下提取

**流程：**
1. 携带材料到公积金中心
2. 填写提取申请表
3. 提交材料审核
4. 审核通过后转账

## 五、提取额度

### 1. 购房提取

- 提取金额不超过购房总价
- 可多次提取，累计不超过房价

### 2. 租房提取

- 每年提取限额各地不同
- 如北京：每年最高 24000 元
- 如上海：每月最高 3000 元

### 3. 还贷提取

- 每年提取金额不超过年还款额
- 可按月冲还贷（自动扣款）

## 六、常见问题

### Q1：离职后公积金怎么处理？

- 可提取（部分地区需封存满6个月）
- 可转移至新单位继续缴存
- 可保留账户，等退休后提取

### Q2：公积金贷款和提取冲突吗？

- 账户余额可用于还贷
- 申请贷款时余额会影响贷款额度
- 部分地区贷款后不能提取全部余额

### Q3：异地购房可以提取吗？

可以。异地购房提取公积金需要：
- 购房所在地本人或配偶户籍地
- 或本人工作地
- 部分地区放宽至全国

### Q4：夫妻可以互提吗？

可以。夫妻双方可提取各自的公积金用于：
- 共同购房
- 共同还贷
- 需提供结婚证

### Q5：提取后影响贷款额度吗？

会影响。公积金贷款额度通常与账户余额挂钩：
- 如上海：贷款额度 = 余额 × 30
- 如北京：贷款额度与余额和缴存年限相关

## 七、公积金贷款优势

| 对比项 | 公积金贷款 | 商业贷款 |
|--------|------------|----------|
| 利率 | 2.85%（5年以上） | 约 4.2% |
| 首付比例 | 较低 | 较高 |
| 贷款年限 | 最长30年 | 最长30年 |
| 提前还款 | 无违约金 | 可能有 |

**省钱示例：**
- 贷款100万，30年等额本息
- 公积金贷款月供：约 4135 元
- 商业贷款月供：约 4890 元
- 30年省利息：约 27 万元

## 八、实用技巧

| 技巧 | 说明 |
|------|------|
| 定期提取 | 租房提取每年一次，别错过 |
| 冲还贷 | 选择月冲，减轻还款压力 |
| 用足额度 | 夫妻双方都用足提取额度 |
| 关注政策 | 各地政策可能调整 |
| 线上办理 | 省时省力，推荐线上提取 |
