# 租房避坑指南

> 租房水很深，学会避坑很重要

---

## 一、看房阶段

### 1. 必须核实的信息

| 信息 | 核实方式 |
|------|----------|
| 房东身份 | 要求看房产证原件 |
| 房东本人 | 核对身份证与房产证姓名 |
| 房屋状态 | 有无抵押、查封 |
| 物业费 | 是否欠费 |
| 水电气费 | 抄表数，确认无欠费 |

### 2. 实地检查清单

**房屋设施：**
- 门窗是否完好
- 水压是否正常
- 电器能否正常使用
- 网络信号如何
- 墙面有无渗水
- 马桶是否通畅

**周边环境：**
- 通勤距离
- 是否吵闹
- 安保情况
- 停车是否方便

### 3. 警惕这些情况

| 情况 | 风险 |
|------|------|
| 房价明显低于市场 | 可能是骗局 |
| 房东不让看房证 | 可能是二房东 |
| 催促立即签约 | 可能有猫腻 |
| 中介费不明确 | 后续可能乱收费 |

---

## 二、签约阶段

### 1. 合同必备条款

**必须写清楚：**

| 条款 | 内容 |
|------|------|
| 租赁期限 | 起止日期 |
| 租金金额 | 每月租金、支付方式 |
| 押金 | 金额、退还条件 |
| 水电气费 | 单价、缴费方式 |
| 维修责任 | 谁负责维修、费用谁承担 |
| 解约条件 | 提前解约的违约金 |
| 转租约定 | 能否转租 |

### 2. 押金条款要明确

**常见押金类型：**

| 类型 | 说明 |
|------|------|
| 押一付三 | 押金1个月，预付3个月租金 |
| 押一付一 | 押金1个月，预付1个月租金 |

**退还条件要写清：**
- 合同到期退还
- 房屋无损坏退还
- 无欠费退还
- 明确退还时间（如退房后7日内）

### 3. 这些条款要警惕

| 条款 | 问题 |
|------|------|
| "违约押金不退" | 不合理，可协商修改 |
| "可随时解约" | 对租客不利 |
| "房屋维修费由租客承担" | 应区分人为损坏和自然损耗 |
| "水电费按人头算" | 应按实际用量计费 |

## 三、常见陷阱

### 1. 二房东陷阱

**什么是二房东？**
- 房客把房子转租出去
- 不是真正的产权人

**风险：**
- 大房东不同意转租，合同无效
- 二房东跑路，押金和租金打水漂

**如何避免：**
- 坚持看房产证原件
- 看房东身份证
- 如果是二房东，要求出示大房东的转租授权书

### 2. 黑中介陷阱

| 套路 | 应对 |
|------|------|
| 看房收费 | 正规中介看房免费 |
| 虚假房源 | 先看房再交中介费 |
| 收费后消失 | 选择正规中介公司 |
| 阴阳合同 | 坚持合同一式两份 |

### 3. 合同陷阱

| 套路 | 应对 |
|------|------|
| 模糊条款 | 逐条确认，写清楚 |
| 口头承诺 | 全部写进合同 |
| 附加条款 | 仔细阅读每一行 |
| 空白条款 | 不签空白合同 |

## 四、入住后的注意事项

### 1. 入住当天要做的事

- 抄录水电气表数
- 拍照/视频记录房屋现状
- 列出设施清单，双方签字确认
- 索要钥匙、门禁卡等

### 2. 日常维护

- 人为损坏自己修
- 自然损耗找房东
- 大问题及时通知房东
- 保留沟通记录

### 3. 合同期间维权

| 问题 | 解决方式 |
|------|----------|
| 房东随意涨租 | 按合同约定，不能随意涨 |
| 房东提前收回房屋 | 要求赔偿违约金 |
| 房屋设施损坏房东不修 | 可自行维修，费用从租金扣除（需通知房东） |
| 押金不退 | 协商不成可起诉 |

## 五、退租阶段

### 1. 提前退租

- 提前通知房东（一般30天）
- 按合同支付违约金
- 协商可能降低违约金

### 2. 合同到期退租

**流程：**
1. 提前通知房东退租时间
2. 清理房屋，恢复原状
3. 结清水电气费
4. 与房东一起验房
5. 交接钥匙
6. 当场退还押金或约定退还时间

### 3. 押金纠纷处理

**房东不退押金的常见理由：**

| 理由 | 是否合理 |
|------|----------|
| 房屋有损坏 | 人为损坏才合理，自然损耗不合理 |
| 需要等下个租客入住才退 | 不合理，应约定时间退还 |
| 墙面脏了 | 正常使用痕迹不合理扣费 |
| 电器坏了 | 需证明是租客损坏 |

**应对方式：**
1. 协商，保留沟通记录
2. 向居委会/街道调解
3. 向住建部门投诉
4. 向法院起诉（小额诉讼程序，简易快捷）

## 六、租客的权利

| 权利 | 说明 |
|------|------|
| 安宁权 | 房东不能随意进入 |
| 使用权 | 正常使用房屋不受干扰 |
| 优先承租权 | 租期届满可优先续租 |
| 优先购买权 | 房东卖房时租客可优先购买 |
| 买卖不破租赁 | 房东卖房不影响租赁合同 |

---

## 七、实用建议

### 1. 签约前

- 看房不少于2次
- 晚上看一次（了解噪音情况）
- 要求见房东本人
- 查验房产证原件

### 2. 签约时

- 合同逐条阅读
- 口头承诺写进合同
- 拍照保留合同
- 一式两份，各执一份

### 3. 入住后

- 保留所有支付凭证
- 记录房屋现状
- 与房东保持良好沟通
- 遇到问题及时书面通知

### 4. 维权渠道

| 渠道 | 适用情况 |
|------|----------|
| 协商 | 一般纠纷首选 |
| 居委会调解 | 社区层面调解 |
| 12345热线 | 投诉举报 |
| 住建部门 | 投诉黑中介 |
| 法院起诉 | 最后手段 |
