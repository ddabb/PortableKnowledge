# 信息安全基础

## 1. 信息安全概念

**定义：** 信息安全是保护信息免受未授权访问、泄露、破坏、修改，保证信息的保密性、完整性和可用性。

**现代特点：**
- 信息价值超过处理设施价值
- 组织对信息和设施依赖程度增大
- 信息安全内涵不断延伸

## 2. CIA三要素

| 要素 | 说明 |
|-----|------|
| **保密性（Confidentiality）** | 信息不被未授权者访问 |
| **完整性（Integrity）** | 信息不被未授权修改或破坏 |
| **可用性（Availability）** | 合法用户需要时可访问 |

## 3. 信息安全管理体系

### 3.1 五大原则

1. 总体策划，确定安全总体目标和原则
2. 建立组织机构，明确责任部门
3. 资产分类与控制
4. 技术方法支撑
5. 检查审计

### 3.2 三大保障要求

| 保障 | 说明 |
|-----|------|
| 安全运行组织 | 主管领导、信息中心、业务部门 |
| 安全管理制度 | 多人负责、任期有限、职责分离 |
| 应急响应机制 | 应急计划、技术支持、通告培训 |

## 5. 等级保护制度

### 5.1 安全保护等级（5级）

| 等级 | 损害对象 | 监管部门 |
|-----|---------|---------|
| 第一级 | 合法权益 | - |
| 第二级 | 合法权益、社会秩序 | 指导 |
| 第三级 | 社会秩序、国家安全 | 监督 |
| 第四级 | 社会秩序、国家安全 | 强制监督 |
| 第五级 | 国家安全 | 专门监督 |

### 5.2 安全保护能力（5级）

| 等级 | 防护能力 |
|-----|---------|
| 第一级 | 防护个人攻击、自然灾害 |
| 第二级 | 防护小型组织攻击、发现漏洞 |
| 第三级 | 防护有组织攻击、监测响应 |
| 第四级 | 防护国家级攻击、快速恢复 |
| 第五级 | 最高防护能力 |

### 5.3 等保2.0核心内容
- 风险评估、安全监测、通报预警
- 案事件调查、数据防护、应急处置
- 自主可控、供应链安全
- 覆盖云计算、物联网、工控系统等

### 5.4 技术体系架构
- 物理环境安全防护
- 通信网络安全防护
- 网络边界安全防护
- 计算环境安全防护
- 安全管理中心

## 6. 安全运行组织

| 角色 | 职责 |
|-----|------|
| 主管领导 | 核心领导 |
| 信息中心 | 实体支撑 |
| 业务部门 | 使用者 |

## 7. 关键考点

- CIA三要素：保密性、完整性、可用性
- 安全管理五大原则：总体策划、组织机构、资产分类、技术方法、检查审计
- 安全管理四大内容：组织、人员、物理、技术
- 等级保护5级：公民合法权益→国家安全
- 等保2.0覆盖：云、物联网、工控系统
- 安全体系架构：物理→通信→边界→计算→管理
