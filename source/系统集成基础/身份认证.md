# 身份认证

## 1. 认证概述

### 1.1 定义
身份认证是验证通信实体真实身份的过程。

### 1.2 认证三要素

| 要素 | 说明 |
|-----|------|
| 知道什么 | 密码、口令 |
| 拥有什么 | 智能卡、令牌、手机 |
| 是什么 | 指纹、虹膜、面部识别 |

### 1.3 认证层次

| 类型 | 说明 |
|-----|------|
| 单因素认证 | 只用一种因素 |
| 双因素认证 | 两种因素组合 |
| 多因素认证 | 多种因素组合 |

## 2. 认证技术

### 2.1 密码认证
- 最常用的认证方式
- 静态密码
- 可配合锁定策略使用

### 2.2 动态密码

| 类型 | 说明 |
|-----|------|
| 短信验证码 | 发送到手机 |
| 时间同步令牌 | 每分钟变化 |
| 挑战应答 | 服务端挑战+客户端应答 |

### 2.3 生物认证

| 技术 | 说明 |
|-----|------|
| 指纹识别 | 应用最广泛 |
| 虹膜识别 | 准确性高 |
| 面部识别 | 非接触式 |
| 声纹识别 | 远程认证 |
| 静脉识别 | 高安全性 |

### 2.4 数字证书认证
- 基于PKI体系
- 存储在USB Key或智能卡

### 2.5 零知识证明
- 证明者不泄露秘密
- 只证明知道该秘密

## 3. 认证协议

### 3.1 Kerberos协议

**概述：** 基于信任第三方（KDC）的网络认证协议

**特点：**
- 票据机制
- 双向认证
- 票据具有生命周期

**认证流程：**
```
1. 客户端向AS认证服务器请求票据
2. AS返回票据和会话密钥
3. 客户端向TGS票据授予服务器请求服务票据
4. TGS返回服务票据
5. 客户端使用票据访问服务
```

### 3.2 SSL/TLS协议

**位置：** 位于传输层之上

**功能：**
- 服务器认证
- 客户端认证（可选）
- 加密通信
- 完整性保护

**握手过程：**
```
1. 客户端hello
2. 服务器hello + 证书
3. 密钥交换
4. 完成握手
5. 开始加密通信
```

### 3.3 OAuth 2.0协议

**用途：** 开放平台授权

**授权流程：**
```
1. 用户授权
2. 获取授权码
3. 用授权码换令牌
4. 用令牌访问资源
```

### 3.4 SAML协议
- 安全断言标记语言
- XML标准
- SSO单点登录

### 3.5 OpenID Connect
- 基于OAuth 2.0的身份层
- JWT令牌格式

## 5. 单点登录（SSO）

### 5.1 定义
一次登录，多系统访问

### 5.2 实现方式
- 基于Cookie
- 基于Token
- 基于SAML
- 基于OAuth/OIDC

### 5.3 优点
- 用户体验提升
- 密码管理简化
- 安全风险降低

## 7. 多因素认证场景

| 场景 | 认证方式 |
|-----|---------|
| 网上银行 | 密码+短信验证码+令牌 |
| 企业系统 | 密码+智能卡/证书 |
| 政务系统 | 密码+人脸/指纹 |

## 8. 关键考点

- 认证三要素：知道、拥有、是
- Kerberos：基于KDC的票据机制
- SSL/TLS：传输层安全协议，握手认证
- OAuth 2.0：开放授权，授权码流程
- 身份管理：生命周期管理
- SSO：一次登录，多系统访问
- 密码策略：长度、复杂度、定期更换
