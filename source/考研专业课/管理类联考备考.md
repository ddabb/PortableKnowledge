# 管理类联考备考：数学逻辑写作三科攻略

## 一、数学基础

管理类联考的数学基础主要考查运算能力、逻辑推理能力、空间想象能力和数据处理能力。

### 算术

- 整数：整数及其运算、整除、公倍数、公约数、奇数、偶数、质数、合数
- 分数、小数、百分数
- 比与比例
- 数轴与绝对值

### 代数

| 模块 | 内容 |
|------|------|
| 整式 | 整式及其运算、因式与因式分解 |
| 函数 | 集合、一元二次函数及其图像、指数函数、对数函数 |
| 代数方程 | 一元一次方程、一元二次方程、二元一次方程组 |
| 不等式 | 不等式性质、均值不等式、不等式求解 |
| 数列 | 等差数列、等比数列 |

### 几何

| 模块 | 内容 |
|------|------|
| 平面图形 | 三角形、四边形、圆与扇形 |
| 空间几何体 | 长方体、圆柱体、球体 |
| 平面解析几何 | 平面直角坐标系、直线方程与圆方程、两点间距离公式 |

### 数据分析

| 模块 | 内容 |
|------|------|
| 计数原理 | 加法原理、乘法原理、排列与排列数、组合与组合数 |
| 数据描述 | 平均值、方差与标准差、数据的图表表示 |
| 概率 | 事件运算、加法公式、乘法公式、古典概型、伯努利概型 |

## 二、逻辑推理

管理类联考的逻辑推理主要考查理解、分析、判断和综合信息的能力，以及推理、论证、比较、评价等逻辑思维能力。

### 形式逻辑

| 模块 | 内容 |
|------|------|
| 概念 | 概念的种类、概念间关系、定义、划分 |
| 判断 | 直言判断、复合判断、模态判断 |
| 推理 | 演绎推理、归纳推理、类比推理、综合推理 |
| 论证 | 论证的结构、论证的方法、论证有效性分析 |

### 非形式逻辑题型

| 题型 | 考查重点 |
|------|---------|
| 削弱型 | 指出论证的漏洞 |
| 加强型 | 支持论证的成立 |
| 解释型 | 说明现象的原因 |
| 评价型 | 评价论证的方法 |
| 结论型 | 推出最可能结论 |

### 综合推理

排序问题、匹配问题、分组问题、数字相关问题、组合问题

## 三、写作

管理类联考写作考查分析论证能力和文字表达能力，通过两种形式测试。

### 论证有效性分析

**核心任务：** 分析一段论证的有效性，指出其中存在的问题并说明理由。

**常见逻辑错误：**

| 错误类型 | 说明 |
|---------|------|
| 概念混淆 | 前后概念不一致 |
| 论据不足 | 理由不充分 |
| 类比不当 | 类比的前提不具备可比性 |
| 因果错误 | 把相关性当成因果性 |
| 以偏概全 | 用个别代替一般 |
| 自相矛盾 | 论据之间相互矛盾 |
| 非黑即白 | 忽略了中间地带 |

### 论说文

**核心任务：** 根据材料提出观点并进行论证。

**常见类型：** 观点型、话题型、材料型

**写作结构：**

```
开头：引出话题，提出论点
分论点1：第一个论据+分析
分论点2：第二个论据+分析
分论点3：第三个论据+分析
结尾：总结升华
```

### 应试注意事项

- 论证有效性分析：字数600字左右，重点在指出逻辑漏洞
- 论说文：字数700字左右，观点要明确，论证要充分
- 字体工整，卷面整洁
- 合理分配时间，两篇作文控制在50-60分钟
