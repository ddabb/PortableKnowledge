# 财政基础知识

## 财政的定义

财政是国家为了实现其职能，凭借政治权力参与社会产品分配的活动。

## 财政的职能

### 资源配置职能

资源配置职能是指财政通过对资源的分配，实现资源的合理配置，提高资源利用效率。

### 收入分配职能

收入分配职能是指财政通过对收入的再分配，实现社会公平，缩小收入差距。

### 经济稳定与发展职能

经济稳定与发展职能是指财政通过调节经济运行，实现经济的稳定增长和发展。

### 监督管理职能

监督管理职能是指财政通过对财政资金的使用和管理，监督和规范经济活动。

## 财政支出

### 财政支出的分类

1. **按经济性质分类**：
   - 购买性支出：政府直接购买商品和服务的支出
   - 转移性支出：政府无偿转移给个人和企业的支出

2. **按功能分类**：
   - 一般公共服务支出
   - 国防支出
   - 公共安全支出
   - 教育支出
   - 科学技术支出
   - 文化体育与传媒支出
   - 社会保障和就业支出
   - 医疗卫生与计划生育支出
   - 节能环保支出
   - 城乡社区支出
   - 农林水支出
   - 交通运输支出
   - 资源勘探信息等支出
   - 商业服务业等支出
   - 金融支出
   - 援助其他地区支出
   - 国土海洋气象等支出
   - 住房保障支出
   - 粮油物资储备支出
   - 预备费
   - 其他支出

### 财政支出的规模

财政支出规模是指财政支出占国内生产总值（GDP）的比重。

### 财政支出的结构

财政支出结构是指各类财政支出占总财政支出的比重。

### 财政支出的效益

财政支出的效益是指财政支出所带来的社会效益和经济效益。

## 财政收入

### 财政收入的分类

1. **税收收入**：国家凭借政治权力强制征收的收入
2. **非税收入**：包括政府性基金收入、专项收入、行政事业性收费收入、罚没收入、国有资本经营收入、国有资源（资产）有偿使用收入等
3. **债务收入**：政府通过发行国债等方式取得的收入
4. **其他收入**：包括捐赠收入等

### 税收的特征

1. **强制性**：国家凭借政治权力强制征收
2. **无偿性**：国家取得税收收入不需要偿还
3. **固定性**：税收的征收对象、税率等都是固定的

### 税收的分类

1. **按课税对象分类**：
   - 流转税：如增值税、消费税、关税
   - 所得税：如企业所得税、个人所得税
   - 财产税：如房产税、车船税
   - 资源税：如资源税、土地增值税
   - 行为税：如印花税、城市维护建设税

2. **按税负能否转嫁分类**：
   - 直接税：税负不能转嫁，如所得税、财产税
   - 间接税：税负可以转嫁，如流转税

3. **按税收管理权限分类**：
   - 中央税：由中央政府征收和管理的税收
   - 地方税：由地方政府征收和管理的税收
   - 中央地方共享税：由中央和地方政府共同分享的税收

### 税收的原则

1. **公平原则**：税收应该公平地分配税负
2. **效率原则**：税收应该提高资源配置效率
3. **适度原则**：税收规模应该适度
4. **法治原则**：税收应该依法征收

## 财政预算

### 财政预算的定义

财政预算是指政府在一定时期内的财政收支计划。

### 财政预算的类型

1. **增量预算**：以上一年度的预算为基础，增加一定的数额
2. **零基预算**：不考虑上一年度的预算，重新编制预算

### 财政预算的程序

1. **编制**：政府部门编制预算草案
2. **审批**：立法机关审批预算
3. **执行**：政府部门执行预算
4. **监督**：立法机关和审计机关监督预算执行

## 财政赤字

### 财政赤字的定义

财政赤字是指财政支出大于财政收入的差额。

### 财政赤字的弥补方式

1. **发行国债**：政府通过发行国债来弥补财政赤字
2. **向中央银行借款**：政府向中央银行借款来弥补财政赤字
3. **增加税收**：政府通过增加税收来弥补财政赤字
4. **减少支出**：政府通过减少支出来弥补财政赤字

### 财政赤字的影响

1. **积极影响**：财政赤字可以刺激经济增长，增加就业
2. **消极影响**：财政赤字可能导致通货膨胀，增加政府债务负担

## 财政政策

### 财政政策的定义

财政政策是指政府通过调整财政收入和支出，来影响宏观经济运行的政策。

### 财政政策的类型

1. **扩张性财政政策**：增加政府支出、减少税收，以刺激经济增长
2. **紧缩性财政政策**：减少政府支出、增加税收，以抑制通货膨胀
3. **中性财政政策**：保持财政收支平衡，不对经济产生明显的刺激或抑制作用

### 财政政策的工具

1. **税收**：调整税率和税收结构
2. **政府购买**：调整政府购买的规模和结构
3. **转移支付**：调整转移支付的规模和结构
4. **国债**：调整国债的发行规模和期限结构

### 财政政策的效果

财政政策的效果取决于政策的实施力度、实施时机和经济环境等因素。
