# 面试礼仪

## 定义

**面试礼仪**是公务员面试的重要环节，**直接影响考官对考生的第一印象**。

对于参加公务员考试的考生而言，掌握**面试礼仪**，是**成功通过公务员面试、获得公务员职位**的关键技能。

---

## 核心概念

### 1. 面试礼仪类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **仪表礼仪** | 考生的穿着打扮 | 正装、发型、妆容 |
| **举止礼仪** | 考生的行为举止 | 坐姿、站姿、手势 |
| **言语礼仪** | 考生的言语表达 | 礼貌用语、语气、语速 |
| **考场礼仪** | 考生在考场内的礼仪 | 进门、问候、退场 |

### 2. 面试礼仪核心要点

| 要点 | 说明 | 重要性 |
|------|------|--------|
| **仪表得体** | 穿着正装，干净整洁 | 高 |
| **举止大方** | 坐姿、站姿端正 | 高 |
| **言语礼貌** | 使用礼貌用语 | 高 |
| **态度自信** | 保持自信，不卑不亢 | 中 |
| **尊重考官** | 尊重考官，认真倾听 | 中 |

### 3. 面试礼仪扣分点

| 扣分点 | 说明 | 避免方法 |
|--------|------|----------|
| **仪表不当** | 穿着随意，不整洁 | 穿着正装 |
| **举止不当** | 坐姿、站姿不端正 | 保持端正 |
| **言语不当** | 不使用礼貌用语 | 使用礼貌用语 |
| **态度不当** | 紧张、不自信 | 保持自信 |
| **不尊重考官** | 打断考官，不认真倾听 | 尊重考官 |

## 详细内容

### 一、仪表礼仪

#### 1.1 男士仪表礼仪

**要点**：
- 西装：深色西装（黑色、深蓝色、深灰色）
- 衬衫：白色或浅蓝色衬衫
- 领带：颜色协调，不要太花哨
- 鞋子：黑色皮鞋，干净光亮
- 头发：干净整齐，不要过长
- 面部：干净，不要留胡须

#### 1.2 女士仪表礼仪

**要点**：
- 西装：深色西装或套裙
- 衬衫：白色或浅色衬衫
- 鞋子：黑色中跟皮鞋，干净光亮
- 头发：干净整齐，扎起来或盘起来
- 妆容：淡妆，不要浓妆艳抹
- 配饰：简单配饰，不要夸张

---

### 二、举止礼仪

#### 2.1 坐姿礼仪

**要点**：
- 坐椅子的三分之二
- 上身挺直，不要靠在椅背上
- 双手放在桌子上或大腿上
- 不要抖腿、不要转笔

#### 2.2 站姿礼仪

**要点**：
- 上身挺直，不要弯腰驼背
- 双手自然下垂或放在身前
- 不要双手抱胸、不要双手插兜

#### 2.3 手势礼仪

**要点**：
- 手势自然，不要过多
- 不要指指点点
- 不要双手交叉抱胸

---

### 三、言语礼仪

#### 3.1 礼貌用语

**要点**：
- 进门：考官好，我是XX号考生。
- 回答：谢谢考官提问，我开始回答。
- 结束：谢谢考官，我回答完毕。
- 退场：谢谢考官，再见。

#### 3.2 语气语速

**要点**：
- 语气：平和、自信
- 语速：适中，不要过快或过慢
- 音量：适中，不要过大或过小

---

### 四、考场礼仪

#### 4.1 进门礼仪

**要点**：
- 敲门：轻轻敲门三下
- 进门：轻轻进门，不要用力关门
- 问候：考官好，我是XX号考生。
- 站立：站在考生席旁边，等待考官指示

#### 4.2 退场礼仪

**要点**：
- 致谢：谢谢考官，我回答完毕。
- 起身：轻轻起身，不要用力推椅子
- 退场：谢谢考官，再见。
- 关门：轻轻关门，不要用力关门

## 示例/应用场景

### 示例1：男士面试礼仪

**场景**：男士参加公务员面试。

**正确做法**：
- 仪表：穿着深色西装、白色衬衫、深色领带、黑色皮鞋
- 举止：坐姿端正，双手放在桌子上
- 言语：使用礼貌用语，语气平和，语速适中
- 考场：轻轻敲门，轻轻进门，轻轻退场

**错误做法**：
- 仪表：穿着牛仔裤、运动鞋
- 举止：坐姿不端正，抖腿
- 言语：不使用礼貌用语，语气生硬
- 考场：不敲门，用力关门

### 示例2：女士面试礼仪

**场景**：女士参加公务员面试。

**正确做法**：
- 仪表：穿着深色套裙、白色衬衫、黑色中跟皮鞋、淡妆
- 举止：坐姿端正，双手放在桌子上
- 言语：使用礼貌用语，语气平和，语速适中
- 考场：轻轻敲门，轻轻进门，轻轻退场

**错误做法**：
- 仪表：穿着超短裙、浓妆艳抹
- 举止：坐姿不端正，双手抱胸
- 言语：不使用礼貌用语，语气生硬
- 考场：不敲门，用力关门

## 最佳实践

### 1. 提前准备面试礼仪

**不推荐**（不准备面试礼仪）：
```text
不准备面试礼仪，导致面试时礼仪不当，给考官留下不好的印象
```

**推荐**（提前准备）：
```text
- 提前了解面试礼仪类型
- 提前了解面试礼仪核心要点
- 提前了解面试礼仪扣分点
```

### 2. 提前练习面试礼仪

**不推荐**（不练习面试礼仪）：
```text
不练习面试礼仪，导致面试时礼仪不当
```

**推荐**（提前练习）：
```text
- 对着镜子练习仪表礼仪
- 对着镜子练习举止礼仪
- 找朋友或家人练习言语礼仪和考场礼仪
```

### 3. 进行模拟面试

**不推荐**（不进行模拟面试）：
```text
不进行模拟面试，导致面试时紧张、礼仪不当
```

**推荐**（进行模拟面试）：
```text
- 找朋友或家人进行模拟面试
- 录制自己的模拟面试，回看并改进
- 参加面试培训班进行模拟面试
```

### 4. 注意细节

**不推荐**（不注意细节）：
```text
不注意细节，导致面试时礼仪不当
```

**推荐**（注意细节）：
```text
- 注意仪表细节（如：头发、面部、配饰）
- 注意举止细节（如：坐姿、站姿、手势）
- 注意言语细节（如：礼貌用语、语气、语速）
- 注意考场细节（如：进门、退场）
```

### 5. 保持自信

**不推荐**（不自信）：
```text
面试时不自信，影响礼仪表现
```

**推荐**（保持自信）：
```text
- 面试前充分休息
- 面试时进行深呼吸
- 面试时保持自信
```
