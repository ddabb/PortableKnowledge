# Excel公式与函数进阶

## 定义

Excel公式与函数进阶是**使用Excel进行复杂数据分析**的技能，包括逻辑函数、查找函数、文本函数、日期函数等。

对于数据分析师而言，Excel是**快速验证思路、处理小型数据集**的常用工具。

---

## 核心概念

### 1. 逻辑函数

| 函数 | 说明 | 语法 |
|------|------|------|
| **IF** | 条件判断 | `IF(条件, 真值, 假值)` |
| **IFS** | 多条件判断（Excel 2016+） | `IFS(条件1, 值1, 条件2, 值2, ...)` |
| **AND** | 逻辑与 | `AND(条件1, 条件2, ...)` |
| **OR** | 逻辑或 | `OR(条件1, 条件2, ...)` |
| **NOT** | 逻辑非 | `NOT(条件)` |

### 2. 查找函数

| 函数 | 说明 | 语法 |
|------|------|------|
| **VLOOKUP** | 垂直查找 | `VLOOKUP(查找值, 表格区域, 列号, [匹配模式])` |
| **HLOOKUP** | 水平查找 | `HLOOKUP(查找值, 表格区域, 行号, [匹配模式])` |
| **INDEX** | 返回指定位置的值 | `INDEX(区域, 行号, [列号])` |
| **MATCH** | 返回指定值的位置 | `MATCH(查找值, 区域, [匹配模式])` |
| **XLOOKUP** | 高级查找（Excel 2021+） | `XLOOKUP(查找值, 查找区域, 返回区域, [未找到], [匹配模式])` |

### 3. 文本函数

| 函数 | 说明 | 语法 |
|------|------|------|
| **LEFT** | 从左截取字符串 | `LEFT(文本, 字符数)` |
| **RIGHT** | 从右截取字符串 | `RIGHT(文本, 字符数)` |
| **MID** | 从中间截取字符串 | `MID(文本, 起始位置, 字符数)` |
| **LEN** | 计算字符串长度 | `LEN(文本)` |
| **TEXT** | 格式化文本 | `TEXT(值, 格式代码)` |
| **TRIM** | 去除空格 | `TRIM(文本)` |
| **SUBSTITUTE** | 替换字符串 | `SUBSTITUTE(文本, 旧文本, 新文本, [实例号])` |

### 4. 日期函数

| 函数 | 说明 | 语法 |
|------|------|------|
| **TODAY** | 返回当前日期 | `TODAY()` |
| **NOW** | 返回当前日期和时间 | `NOW()` |
| **YEAR** | 返回年份 | `YEAR(日期)` |
| **MONTH** | 返回月份 | `MONTH(日期)` |
| **DAY** | 返回天数 | `DAY(日期)` |
| **DATE** | 创建日期 | `DATE(年, 月, 日)` |
| **DATEDIF** | 计算日期差 | `DATEDIF(开始日期, 结束日期, 单位)` |
| **EDATE** | 计算几个月后/前的日期 | `EDATE(日期, 月数)` |

## 详细内容

### 一、逻辑函数

#### 1.1 IF函数

**功能**：条件判断

**示例**：
```
=IF(A1>60, "及格", "不及格")
```
**解释**：如果A1单元格的值大于60，返回"及格"，否则返回"不及格"。

#### 1.2 IFS函数

**功能**：多条件判断

**示例**：
```
=IFS(A1>90, "优秀", A1>80, "良好", A1>60, "及格", TRUE, "不及格")
```
**解释**：如果A1>90，返回"优秀"；如果A1>80，返回"良好"；如果A1>60，返回"及格"；否则返回"不及格"。

#### 1.3 AND、OR、NOT函数

**功能**：逻辑运算

**示例**：
```
=IF(AND(A1>60, B1>60), "及格", "不及格")
```
**解释**：如果A1>60且B1>60，返回"及格"，否则返回"不及格"。

```
=IF(OR(A1>60, B1>60), "及格", "不及格")
```
**解释**：如果A1>60或B1>60，返回"及格"，否则返回"不及格"。

```
=IF(NOT(A1>60), "不及格", "及格")
```
**解释**：如果A1不大于60，返回"不及格"，否则返回"及格"。

### 二、查找函数

#### 2.1 VLOOKUP函数

**功能**：垂直查找

**示例**：
```
=VLOOKUP(D2, A:B, 2, FALSE)
```
**解释**：在A列中查找D2单元格的值，找到后返回B列对应位置的值，FALSE表示精确匹配。

**注意**：
- VLOOKUP只能从左向右查找
- 如果需要从右向左查找，可以使用INDEX+MATCH组合

#### 2.2 INDEX+MATCH组合

**功能**：灵活查找（可从左到右、从右到左）

**示例**：
```
=INDEX(B:B, MATCH(D2, A:A, 0))
```
**解释**：
- MATCH(D2, A:A, 0)：在A列中查找D2单元格的值，返回位置
- INDEX(B:B, 位置)：返回B列对应位置的值

**注意**：INDEX+MATCH组合比VLOOKUP更灵活，但语法更复杂。

#### 2.3 XLOOKUP函数

**功能**：高级查找（Excel 2021+）

**示例**：
```
=XLOOKUP(D2, A:A, B:B, "未找到", 0)
```
**解释**：在A列中查找D2单元格的值，找到后返回B列对应位置的值，如果未找到返回"未找到"，0表示精确匹配。

**注意**：XLOOKUP比VLOOKUP和INDEX+MATCH更强大，但只有Excel 2021及以上版本支持。

### 三、文本函数

#### 3.1 LEFT、RIGHT、MID函数

**功能**：截取字符串

**示例**：
```
=LEFT(A1, 3)   // 从左边截取3个字符
=RIGHT(A1, 4)  // 从右边截取4个字符
=MID(A1, 2, 3)  // 从左边第2个字符开始，截取3个字符
```

#### 3.2 LEN函数

**功能**：计算字符串长度

**示例**：
```
=LEN(A1)  // 返回A1单元格的字符串长度
```

#### 3.3 TEXT函数

**功能**：格式化文本

**示例**：
```
=TEXT(A1, "yyyy-mm-dd")  // 将A1单元格的日期格式化为yyyy-mm-dd格式
=TEXT(A1, "0.00")  // 将A1单元格的数字格式化为保留两位小数的文本
```

#### 3.4 TRIM函数

**功能**：去除空格

**示例**：
```
=TRIM(A1)  // 去除A1单元格文本前后的空格（保留中间单个空格）
```

#### 3.5 SUBSTITUTE函数

**功能**：替换字符串

**示例**：
```
=SUBSTITUTE(A1, " ", "")  // 去除A1单元格文本中的所有空格
=SUBSTITUTE(A1, "apple", "orange")  // 将A1单元格文本中的"apple"替换为"orange"
```

### 四、日期函数

#### 4.1 TODAY、NOW函数

**功能**：返回当前日期/日期和时间

**示例**：
```
=TODAY()  // 返回当前日期
=NOW()    // 返回当前日期和时间
```

#### 4.2 YEAR、MONTH、DAY函数

**功能**：提取日期部分

**示例**：
```
=YEAR(A1)   // 返回A1单元格的年份
=MONTH(A1)  // 返回A1单元格的月份
=DAY(A1)    // 返回A1单元格的天数
```

#### 4.3 DATE函数

**功能**：创建日期

**示例**：
```
=DATE(2023, 12, 31)  // 创建日期2023-12-31
```

#### 4.4 DATEDIF函数

**功能**：计算日期差

**示例**：
```
=DATEDIF(A1, B1, "d")  // 计算A1和B1之间的天数差
=DATEDIF(A1, B1, "m")  // 计算A1和B1之间的月数差
=DATEDIF(A1, B1, "y")  // 计算A1和B1之间的年数差
```

#### 4.5 EDATE函数

**功能**：计算几个月后/前的日期

**示例**：
```
=EDATE(A1, 3)   // 计算A1日期3个月后的日期
=EDATE(A1, -3)  // 计算A1日期3个月前的日期
```

## 示例/应用场景

### 示例1：电商用户分析 - 用户年龄段划分

**业务问题**：根据用户年龄划分年龄段（<18、18-30、30-50、50+）。

**分析**：

在Excel中，使用IF或IFS函数：

```
=IFS(A2<18, "<18", AND(A2>=18, A2<=30), "18-30", AND(A2>30, A2<=50), "30-50", A2>50, "50+")
```

**洞察与建议**：
- 可以统计各年龄段的用户数
- 可以分析各年龄段的购买行为差异

### 示例2：电商销售分析 - 根据用户ID查找用户姓名

**业务问题**：根据订单表中的用户ID，查找用户表中的用户姓名。

**分析**：

在Excel中，使用VLOOKUP或XLOOKUP函数：

```
=VLOOKUP(B2, 用户表!A:B, 2, FALSE)
```
或（Excel 2021+）
```
=XLOOKUP(B2, 用户表!A:A, 用户表!B:B, "未找到", 0)
```

**洞察与建议**：
- 可以将用户姓名合并到订单表中
- 可以分析用户的购买行为

### 示例3：电商商品分析 - 从商品名称中提取品牌

**业务问题**：从商品名称中提取品牌（假设品牌在商品名称的最前面，用空格分隔）。

**分析**：

在Excel中，使用LEFT、FIND、LEN等函数组合：

```
=LEFT(A2, FIND(" ", A2)-1)
```

**解释**：
- FIND(" ", A2)：查找A2单元格中第一个空格的位置
- LEFT(A2, 位置-1)：从左边截取品牌名称

**洞察与建议**：
- 可以统计各品牌的商品数
- 可以分析各品牌的销售情况

## 最佳实践

### 1. 使用合适的函数，提高效率

**不推荐**（使用复杂公式，效率低）：

```
=IF(VLOOKUP(D2, A:B, 2, FALSE)>60, "及格", "不及格")
```

**推荐**（使用合适的函数，效率高）：

```
=IF(XLOOKUP(D2, A:A, B:B, "未找到", 0)>60, "及格", "不及格")
```

### 2. 使用函数组合，解决复杂问题

**不推荐**（使用单一函数，无法解决复杂问题）：

```
=VLOOKUP(D2, A:B, 2, FALSE)  // 只能从左向右查找
```

**推荐**（使用函数组合，解决复杂问题）：

```
=INDEX(B:B, MATCH(D2, A:A, 0))  // 可以灵活查找
```

### 3. 使用错误处理函数，避免公式错误

**不推荐**（不使用错误处理函数，公式可能出错）：

```
=VLOOKUP(D2, A:B, 2, FALSE)  // 如果未找到，返回#N/A错误
```

**推荐**（使用错误处理函数，避免公式错误）：

```
=IFERROR(VLOOKUP(D2, A:B, 2, FALSE), "未找到")
```

### 4. 使用命名区域，提高公式可读性

**不推荐**（不使用命名区域，公式可读性差）：

```
=VLOOKUP(D2, Sheet2!A1:B100, 2, FALSE)
```

**推荐**（使用命名区域，公式可读性好）：

```
=VLOOKUP(D2, 用户表, 2, FALSE)  // 先将Sheet2!A1:B100命名为"用户表"
```

## 常见错误

### 1. 使用错误的函数，导致结果错误

**错误示例**：

```
=VLOOKUP(D2, A:B, 2, TRUE)  // 使用模糊匹配，可能导致结果错误
```

**正确做法**：

```
=VLOOKUP(D2, A:B, 2, FALSE)  // 使用精确匹配
```

### 2. 函数参数错误，导致公式错误

**错误示例**：

```
=VLOOKUP(D2, A:B, 3, FALSE)  // A:B只有2列，第3列不存在
```

**正确做法**：

```
=VLOOKUP(D2, A:B, 2, FALSE)  // A:B的第2列
```

### 3. 不使用错误处理函数，导致公式错误

**错误示例**：

```
=VLOOKUP(D2, A:B, 2, FALSE)  // 如果未找到，返回#N/A错误
```

**正确做法**：

```
=IFERROR(VLOOKUP(D2, A:B, 2, FALSE), "未找到")
```

### 4. 不使用命名区域，导致公式可读性差

**错误示例**：

```
=VLOOKUP(D2, Sheet2!A1:B100, 2, FALSE)
```

**正确做法**：

```
=VLOOKUP(D2, 用户表, 2, FALSE)  // 先将Sheet2!A1:B100命名为"用户表"
```

### 5. 使用复杂的嵌套函数，导致公式难以维护

**错误示例**：

```
=IF(VLOOKUP(D2, A:B, 2, FALSE)>60, IF(VLOOKUP(D2, A:B, 2, FALSE)>80, "良好", "及格"), "不及格")
```

**正确做法**：

```
=IFS(VLOOKUP(D2, A:B, 2, FALSE)>80, "良好", VLOOKUP(D2, A:B, 2, FALSE)>60, "及格", TRUE, "不及格")
```
