# Excel高级公式应用

## 定义

**Excel高级公式**包括**数组公式、动态数组、LET函数、LAMBDA函数**等高级功能。

对于数据分析师而言，掌握这些**高级公式**，是**提升Excel数据分析效率、解决复杂数据问题**的关键。

---

## 核心概念

### 1. 数组公式

| 概念 | 说明 | 示例 |
|------|------|------|
| **数组公式** | 对数组进行计算的公式 | `{=SUM(A1:A10*B1:B10)}` |
| **CSE公式** | 需要用Ctrl+Shift+Enter输入的公式 | `{=SUM(IF(A1:A10>5, B1:B10))}` |
| **动态数组** | 自动填充相邻单元格的数组 | `=FILTER(A1:B10, A1:A10>5)` |

### 2. LET函数

| 概念 | 说明 | 示例 |
|------|------|------|
| **LET函数** | 定义变量并重复使用 | `=LET(x, A1, y, B1, x+y)` |
| **优点** | 提高公式可读性、减少重复计算 | `=LET(total, SUM(A1:A10), total*0.1)` |

### 3. LAMBDA函数

| 概念 | 说明 | 示例 |
|------|------|------|
| **LAMBDA函数** | 创建自定义函数 | `=LAMBDA(x, y, x+y)` |
| **优点** | 创建可重用、可组合的函数 | `=LAMBDA(x, x^2)` |

## 详细内容

### 一、数组公式

#### 1.1 传统数组公式（CSE公式）

**示例1：条件求和**
```excel
{=SUM(IF(A1:A10>5, B1:B10))}
```
**说明**：对A1:A10中大于5的对应B1:B10值求和。

**示例2：多条件计数**
```excel
{=SUM((A1:A10="男")*(B1:B10>30))}
```
**说明**：统计A1:A10中性别为"男"且B1:B10中年龄大于30的人数。

#### 1.2 动态数组公式

**示例1：FILTER函数**
```excel
=FILTER(A1:C10, B1:B10>5000)
```
**说明**：筛选B1:B10中值大于5000的整行数据。

**示例2：UNIQUE函数**
```excel
=UNIQUE(A1:A10)
```
**说明**：返回A1:A10中的唯一值。

**示例3：SORT函数**
```excel
=SORT(A1:B10, 2, -1)
```
**说明**：按第二列降序排序A1:B10。

**示例4：SEQUENCE函数**
```excel
=SEQUENCE(10, 1, 1, 1)
```
**说明**：生成1到10的序列。

---

### 二、LET函数

#### 2.1 基本用法

**示例1：简单计算**
```excel
=LET(x, A1, y, B1, x+y)
```
**说明**：定义变量x=A1，y=B1，计算x+y。

**示例2：减少重复计算**
```excel
=LET(total, SUM(A1:A10), average, AVERAGE(A1:A10), total*average)
```
**说明**：定义变量total=SUM(A1:A10)，average=AVERAGE(A1:A10)，计算total*average。

#### 2.2 复杂用法

**示例1：嵌套LET**
```excel
=LET(x, A1, y, B1, z, LET(a, x+y, b, a*2, a+b))
```
**说明**：定义变量x=A1，y=B1，在内部LET中定义a=x+y，b=a*2，计算a+b。

**示例2：结合动态数组**
```excel
=LET(data, FILTER(A1:C10, B1:B10>5000), SUM(INDEX(data,,3)))
```
**说明**：定义变量data=FILTER(A1:C10, B1:B10>5000)，计算data第三列的和。

---

### 三、LAMBDA函数

#### 3.1 基本用法

**示例1：简单函数**
```excel
=LAMBDA(x, y, x+y)
```
**说明**：创建加法函数。

**示例2：结合LET**
```excel
=LAMBDA(x, LET(y, x^2, y+1))
```
**说明**：创建函数，计算x²+1。

#### 3.2 高级用法

**示例1：递归函数**
```excel
=LAMBDA(n, IF(n<=1, 1, n*RECURSION(n-1)))
```
**说明**：创建递归函数计算阶乘（需要定义名称并使用）。

**示例2：结合MAP**
```excel
=MAP(A1:A10, LAMBDA(x, x^2))
```
**说明**：对A1:A10中的每个值计算平方。

**示例3：结合REDUCE**
```excel
=REDUCE(0, A1:A10, LAMBDA(acc, x, acc+x))
```
**说明**：对A1:A10中的值求和。

---

### 四、高级公式组合

#### 4.1 动态数组 + LET + LAMBDA

**示例：复杂数据分析**
```excel
=LET(
    data, FILTER(A1:C10, B1:B10>5000),
    calculate, LAMBDA(x, INDEX(x,,1)*INDEX(x,,2)/INDEX(x,,3)),
    MAP(data, calculate)
)
```
**说明**：筛选数据，定义计算函数，对筛选后的数据应用计算函数。

#### 4.2 多条件动态数组

**示例：复杂筛选**
```excel
=LET(
    condition1, A1:A10>5,
    condition2, B1:B10<10,
    FILTER(A1:C10, condition1*condition2)
)
```
**说明**：多条件筛选数据。

## 示例/应用场景

### 示例1：电商销售数据分析

**业务问题**：分析电商销售数据，计算各品类销售额和平均订单金额。

**数据**：电商销售数据（品类、订单金额、订单量）

**分析**：

**Excel公式**：
```excel
=LET(
    data, A1:C100,
    categories, UNIQUE(INDEX(data,,1)),
    sales, MAP(categories, LAMBDA(x, SUMIFS(INDEX(data,,2), INDEX(data,,1), x))),
    avg_order, MAP(categories, LAMBDA(x, AVERAGEIFS(INDEX(data,,2), INDEX(data,,1), x))),
    HSTACK(categories, sales, avg_order)
)
```

**洞察与建议**：
- 如果某品类销售额高，说明该品类销售业绩好
- 如果某品类平均订单金额高，说明该品类客单价高
- 可以根据分析结果优化品类策略

### 示例2：电商用户行为分析

**业务问题**：分析电商用户行为，计算用户转化率。

**数据**：电商用户行为数据（用户ID、行为类型、时间戳）

**分析**：

**Excel公式**：
```excel
=LET(
    data, A1:C1000,
    users, UNIQUE(INDEX(data,,1)),
    view_count, MAP(users, LAMBDA(x, COUNTIFS(INDEX(data,,1), x, INDEX(data,,2), "view"))),
    purchase_count, MAP(users, LAMBDA(x, COUNTIFS(INDEX(data,,1), x, INDEX(data,,2), "purchase"))),
    conversion, purchase_count/view_count,
    HSTACK(users, view_count, purchase_count, conversion)
)
```

**洞察与建议**：
- 如果某用户转化率高，说明该用户是高质量用户
- 可以针对高转化率用户进行精准营销
- 可以分析高转化率用户的行为特征，优化产品推荐策略

### 示例3：电商商品价格分析

**业务问题**：分析电商商品价格，计算价格波动系数。

**数据**：电商商品价格数据（商品ID、日期、价格）

**分析**：

**Excel公式**：
```excel
=LET(
    data, A1:C100,
    products, UNIQUE(INDEX(data,,1)),
    avg_price, MAP(products, LAMBDA(x, AVERAGEIFS(INDEX(data,,3), INDEX(data,,1), x))),
    std_price, MAP(products, LAMBDA(x, STDEVIFS(INDEX(data,,3), INDEX(data,,1), x))),
    volatility, std_price/avg_price,
    FILTER(HSTACK(products, avg_price, std_price, volatility), volatility>0.1)
)
```

**洞察与建议**：
- 如果某商品价格波动系数高，说明该商品价格不稳定
- 可以针对价格波动大的商品进行价格优化
- 可以分析价格波动的原因，优化定价策略

## 最佳实践

### 1. 根据数据特征，选择合适的高级公式

**不推荐**（盲目使用数组公式）：

```
无论什么数据，都使用数组公式。
```

**推荐**（根据数据特征，选择合适的高级公式）：

```
- 需要条件计算 → 数组公式
- 需要定义变量 → LET函数
- 需要创建自定义函数 → LAMBDA函数
```

### 2. 使用LET函数提高公式可读性

**不推荐**（重复计算）：

```
=SUM(A1:A10)*0.1 + SUM(A1:A10)*0.2
```

**推荐**（使用LET函数）：

```
=LET(total, SUM(A1:A10), total*0.1 + total*0.2)
```

### 3. 使用LAMBDA函数创建可重用函数

**不推荐**（重复编写复杂公式）：

```
在多个单元格中编写相同的复杂公式。
```

**推荐**（使用LAMBDA函数创建可重用函数）：

```
创建LAMBDA函数，在多个单元格中重复使用。
```

### 4. 结合业务场景解释公式结果

**不推荐**（只报告公式结果）：

```
公式计算结果为100。
```

**推荐**（结合业务场景解释公式结果）：

```
公式计算结果为100万，说明总销售额为100万。可以根据此结果制定销售策略。
```

## 常见错误

### 1. 盲目使用某种高级公式

**错误示例**：

```
无论什么数据，都使用数组公式。
```

**正确做法**：

```
根据数据特征，选择合适的高级公式。
```

### 2. 不使用LET函数提高公式可读性

**错误示例**：

```
=SUM(A1:A10)*0.1 + SUM(A1:A10)*0.2
```

**正确做法**：

```
使用LET函数提高公式可读性。
```

### 3. 不使用LAMBDA函数创建可重用函数

**错误示例**：

```
在多个单元格中编写相同的复杂公式。
```

**正确做法**：

```
使用LAMBDA函数创建可重用函数。
```

### 4. 不结合业务场景解释公式结果

**错误示例**：

```
公式计算结果为100。
```

**正确做法**：

```
结合业务场景解释公式结果。
```

### 5. 动态数组溢出错误

**错误示例**：

```
动态数组公式相邻单元格有数据，导致溢出错误。
```

**正确做法**：

```
确保动态数组公式相邻单元格为空。
```
