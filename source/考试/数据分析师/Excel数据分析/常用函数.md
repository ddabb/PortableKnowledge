# Excel常用函数

## 定义

Excel函数是预置的公式，用于执行特定的计算或操作。对于数据分析师而言，熟练掌握常用函数是处理、清洗、分析数据的基础技能。

Excel函数按功能可分为：文本函数、逻辑函数、查找与引用函数、统计函数、日期时间函数、数学与三角函数等。

---

## 核心概念

### 1. 函数的基本语法

```
=函数名(参数1, 参数2, ...)
```

**示例**：
```
=SUM(A1:A10)           # 求和
=VLOOKUP(A1, B:C, 2, 0)  # 垂直查找
=IF(A1>10, "大", "小")   # 条件判断
```

### 2. 函数参数的类型

| 参数类型 | 说明 | 示例 |
|---------|------|------|
| 数值 | 数字或数值单元格 | `=SUM(1, 2, 3)` |
| 文本 | 用双引号括起来的文本 | `=LEN("Hello")` |
| 单元格引用 | 单个单元格或区域 | `=SUM(A1:A10)` |
| 逻辑值 | TRUE 或 FALSE | `=IF(A1>10, TRUE, FALSE)` |
| 错误值 | #N/A、#VALUE! 等 | `=IFERROR(VLOOKUP(...), 0)` |

### 3. 相对引用 vs 绝对引用

| 引用类型 | 语法 | 说明 |
|---------|------|------|
| 相对引用 | `A1` | 公式复制时，引用会随位置变化 |
| 绝对引用 | `$A$1` | 公式复制时，引用固定不变 |
| 混合引用 | `$A1` 或 `A$1` | 锁定列或锁定行 |

**示例**：
```
=SUM(A1:A10)      # 相对引用，复制公式时区域会变化
=SUM($A$1:$A$10) # 绝对引用，复制公式时区域不变
=SUM($A1:A$10)    # 混合引用，锁定A列和第10行
```

## 详细内容

### 一、文本函数

#### 1.1 文本长度与提取

| 函数 | 说明 | 示例 |
|------|------|------|
| `LEN(text)` | 返回文本字符数 | `=LEN("Hello")` → 5 |
| `LEFT(text, num_chars)` | 从左侧提取指定字符数 | `=LEFT("Hello", 2)` → "He" |
| `RIGHT(text, num_chars)` | 从右侧提取指定字符数 | `=RIGHT("Hello", 2)` → "lo" |
| `MID(text, start_num, num_chars)` | 从指定位置提取指定字符数 | `=MID("Hello", 2, 3)` → "ell" |

**应用场景**：从身份证号中提取出生日期、性别

```
# 假设身份证号在A1，提取出生日期（第7-14位）
=MID(A1, 7, 8)  # 返回"19900101"格式
```

#### 1.2 文本清洗

| 函数 | 说明 | 示例 |
|------|------|------|
| `TRIM(text)` | 去除首尾空格，中间多个空格变为一个 | `=TRIM("  Hello  World  ")` → "Hello World" |
| `CLEAN(text)` | 清除不可打印字符（如换行符） | `=CLEAN(A1)` |
| `SUBSTITUTE(text, old_text, new_text)` | 替换指定文本 | `=SUBSTITUTE("Hello", "H", "J")` → "Jello" |

**应用场景**：清洗用户导入的脏数据（有多余空格、不可见字符）

#### 1.3 文本转换

| 函数 | 说明 | 示例 |
|------|------|------|
| `UPPER(text)` | 转为大写 | `=UPPER("hello")` → "HELLO" |
| `LOWER(text)` | 转为小写 | `=LOWER("HELLO")` → "hello" |
| `PROPER(text)` | 每个单词首字母大写 | `=PROPER("hello world")` → "Hello World" |
| `TEXT(value, format_text)` | 将数值转为指定格式的文本 | `=TEXT(1234.5, "¥#,##0.00")` → "¥1,234.50" |

**应用场景**：统一客户姓名格式（首字母大写）

### 二、逻辑函数

#### 2.1 条件判断

| 函数 | 说明 | 示例 |
|------|------|------|
| `IF(logical_test, value_if_true, value_if_false)` | 条件判断 | `=IF(A1>10, "大", "小")` |
| `IFERROR(value, value_if_error)` | 如果出错则返回指定值 | `=IFERROR(VLOOKUP(...), 0)` |
| `IFNA(value, value_if_na)` | 如果是#N/A错误则返回指定值 | `=IFNA(VLOOKUP(...), "未找到")` |
| `AND(logical1, logical2, ...)` | 逻辑与（全部为TRUE才返回TRUE） | `=AND(A1>10, B1<20)` |
| `OR(logical1, logical2, ...)` | 逻辑或（任意一个为TRUE即返回TRUE） | `=OR(A1>10, B1<20)` |
| `NOT(logical)` | 逻辑非（取反） | `=NOT(A1>10)` |

**应用场景**：根据销售额计算提成档次

```
=IF(A1>=10000, "A档", IF(A1>=5000, "B档", "C档"))
```

#### 2.2 多条件判断（IFS函数，Excel 2016+）

```
=IFS(A1>=90, "优秀", A1>=80, "良好", A1>=60, "及格", TRUE, "不及格")
```

**说明**：IFS函数可以按顺序判断多个条件，返回第一个满足条件的结果。

### 三、查找与引用函数

#### 3.1 VLOOKUP（垂直查找）

**语法**：
```
=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
```

**参数说明**：
- `lookup_value`：要查找的值
- `table_array`：查找区域（必须包含查找列和返回列）
- `col_index_num`：返回第几列的值（从1开始）
- `range_lookup`：可选，TRUE为模糊匹配（需排序），FALSE为精确匹配

**示例**：
```
# 在B:C区域中查找A1的值，返回第2列（精确匹配）
=VLOOKUP(A1, B:C, 2, FALSE)
```

**局限性**：
- 只能从左向右查找（查找列必须在返回列的左侧）
- 插入列后，col_index_num不会自动更新
- 大数据量时性能较差

#### 3.2 INDEX + MATCH（替代VLOOKUP的最佳组合）

**语法**：
```
=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))
```

**参数说明**：
- `INDEX(return_range, row_num)`：返回指定区域中第row_num行的值
- `MATCH(lookup_value, lookup_range, 0)`：返回查找值在查找区域中的位置（行号或列号）

**示例**：
```
# 在B列中查找A1的值，返回对应C列的值
=INDEX(C:C, MATCH(A1, B:B, 0))
```

**优势**：
- 可以从右向左查找（克服VLOOKUP的局限性）
- 插入列后，公式不会出错（MATCH自动找到正确的列）
- 性能优于VLOOKUP（尤其是大数据量）

#### 3.3 XLOOKUP（Excel 365+，推荐）

**语法**：
```
=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])
```

**示例**：
```
# 在B列中查找A1的值，返回对应C列的值，找不到则返回"未找到"
=XLOOKUP(A1, B:B, C:C, "未找到")
```

**优势**：
- 可以从右向左查找
- 可以指定找不到时的返回值（不需要嵌套IFERROR）
- 性能优于VLOOKUP和INDEX+MATCH

### 四、统计函数

#### 4.1 基础统计

| 函数 | 说明 | 示例 |
|------|------|------|
| `SUM(range)` | 求和 | `=SUM(A1:A10)` |
| `AVERAGE(range)` | 求平均值 | `=AVERAGE(A1:A10)` |
| `COUNT(range)` | 统计数值单元格个数 | `=COUNT(A1:A10)` |
| `COUNTA(range)` | 统计非空单元格个数 | `=COUNTA(A1:A10)` |
| `COUNTBLANK(range)` | 统计空单元格个数 | `=COUNTBLANK(A1:A10)` |
| `MAX(range)` | 求最大值 | `=MAX(A1:A10)` |
| `MIN(range)` | 求最小值 | `=MIN(A1:A10)` |

#### 4.2 条件统计

| 函数 | 说明 | 示例 |
|------|------|------|
| `SUMIF(range, criteria, [sum_range])` | 单条件求和 | `=SUMIF(A:A, ">10", B:B)` |
| `SUMIFS(sum_range, criteria_range1, criteria1, ...)` | 多条件求和 | `=SUMIFS(C:C, A:A, ">10", B:B, "华北")`|
| `COUNTIF(range, criteria)` | 单条件计数 | `=COUNTIF(A:A, ">10")` |
| `COUNTIFS(criteria_range1, criteria1, ...)` | 多条件计数 | `=COUNTIFS(A:A, ">10", B:B, "华北")` |
| `AVERAGEIF(range, criteria, [average_range])` | 单条件平均值 | `=AVERAGEIF(A:A, ">10", B:B)` |
| `AVERAGEIFS(average_range, criteria_range1, criteria1, ...)` | 多条件平均值 | `=AVERAGEIFS(C:C, A:A, ">10", B:B, "华北")` |

**应用场景**：统计华北地区销售额大于10,000的订单总金额

```
=SUMIFS(C:C, A:A, ">10000", B:B, "华北")
```

### 五、日期与时间函数

#### 5.1 日期函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `TODAY()` | 返回当前日期 | `=TODAY()` → 2024-01-01 |
| `NOW()` | 返回当前日期和时间 | `=NOW()` → 2024-01-01 14:30:00 |
| `DATE(year, month, day)` | 根据年、月、日生成日期 | `=DATE(2024, 1, 1)` → 2024-01-01 |
| `YEAR(date)` | 返回年份 | `=YEAR(A1)` → 2024 |
| `MONTH(date)` | 返回月份 | `=MONTH(A1)` → 1 |
| `DAY(date)` | 返回天数 | `=DAY(A1)` → 1 |
| `EOMONTH(start_date, months)` | 返回指定月数之后的月末日期 | `=EOMONTH(A1, 1)` → 2024-02-29 |
| `DATEDIF(start_date, end_date, unit)` | 计算两个日期的差（隐藏函数，需手动输入） | `=DATEDIF(A1, B1, "d")` → 天数差 |

**应用场景**：计算员工工龄

```
=DATEDIF(C2, TODAY(), "y") & "年" & DATEDIF(C2, TODAY(), "ym") & "个月"
```

#### 5.2 工作日函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `WORKDAY(start_date, days, [holidays])` | 返回指定工作日数之后的日期（排除周末和假期） | `=WORKDAY(A1, 10)` |
| `NETWORKDAYS(start_date, end_date, [holidays])` | 返回两个日期之间的工作日数（排除周末和假期） | `=NETWORKDAYS(A1, B1)` |

## 示例/应用场景

### 示例1：电商订单分析

**需求**：从订单表中计算每个客户的订单总金额、订单数、平均订单金额

**数据**：
- A列：客户ID
- B列：订单金额

**公式**：
```
# 客户ID在D1，计算该客户的订单总金额
=SUMIF(A:A, D1, B:B)

# 计算该客户的订单数
=COUNTIF(A:A, D1)

# 计算该客户的平均订单金额
=AVERAGEIF(A:A, D1, B:B)

# 或者直接用SUMIF/COUNTIF计算平均值
=SUMIF(A:A, D1, B:B) / COUNTIF(A:A, D1)
```

### 示例2：员工信息分析

**需求**：根据员工出生日期计算年龄，根据入职日期计算工龄

**数据**：
- C列：出生日期
- D列：入职日期

**公式**：
```
# 计算年龄（精确到年）
=DATEDIF(C2, TODAY(), "y")

# 计算工龄（精确到年和月）
=DATEDIF(D2, TODAY(), "y") & "年" & DATEDIF(D2, TODAY(), "ym") & "个月"
```

### 示例3：业绩考核

**需求**：根据销售额计算提成，规则：<5,000无提成，5,000-10,000提成5%，>10,000提成8%

**数据**：
- A列：销售额

**公式**：
```
=IF(A1<5000, 0, IF(A1<=10000, A1*5%, A1*8%))
```

## 数据分析师考点

### Excel常用函数常见考点

1. **VLOOKUP的局限性**：只能从左向右查找，插入列后公式易出错
2. **INDEX+MATCH的优势**：可以从右向左查找，插入列后公式不会出错
3. **XLOOKUP的功能**：Excel 365新增函数，克服VLOOKUP的所有局限性
4. **绝对引用与相对引用**：`$A$1`（绝对）、`A1`（相对）、`$A1`（混合）
5. **条件统计函数**：SUMIF/SUMIFS、COUNTIF/COUNTIFS、AVERAGEIF/AVERAGEIFS
6. **日期计算**：DATEDIF函数（隐藏函数）、WORKDAY、NETWORKDAYS
7. **文本清洗**：TRIM、CLEAN、SUBSTITUTE
8. **错误处理**：IFERROR、IFNA

### 实战考点

1. **嵌套函数的层数限制**：Excel 2016及以前版本最多嵌套7层，Excel 2019+无限制
2. **数组公式**：某些函数需要按Ctrl+Shift+Enter输入（Excel 365已支持动态数组，不需要）
3. **函数性能**：VLOOKUP大数据量时性能较差，建议用INDEX+MATCH或XLOOKUP
4. **日期的真正本质**：Excel中日期是序列号（如2024-01-01=45292），可以用`=VALUE(A1)`查看
5. **浮点数误差**：Excel使用IEEE 754浮点数标准，可能导致0.1+0.2≠0.3，比较时应使用`ROUND()`或`ABS(a-b)<0.0001`

## 最佳实践

### 1. 函数选择原则

- **优先使用新函数**：Excel 365用户应优先使用XLOOKUP、IFS等新函数，功能更强且不易出错
- **避免使用易出错的函数**：VLOOKUP在插入列后易出错，建议用INDEX+MATCH或XLOOKUP替代
- **简化嵌套**：嵌套超过3层的公式难以阅读和维护，建议拆分为多个辅助列

### 2. 公式可读性

- **使用换行和缩进**：在公式编辑栏按Alt+Enter可以换行，提升可读性
- **添加注释**：复杂的公式可以添加注释（单元格备注或文本注释）
- **使用命名区域**：将常用的区域命名为有意义的名称（如`=SUM(销售额)`比`=SUM(A:A)`更易读）

### 3. 性能优化

- **避免使用整列引用**：`=SUM(A:A)`会计算整列1,048,576行，影响性能，建议指定具体区域（如`=SUM(A1:A10000)`）
- **避免使用易失函数**：TODAY()、NOW()、RAND()、OFFSET()等函数会在每次工作表计算时重新计算，影响性能
- **使用手动计算模式**：大数据量工作簿可以设置为手动计算（公式 → 计算选项 → 手动）

### 4. 错误处理

- **使用IFERROR或IFNA**：避免公式返回#N/A、#VALUE!等错误值
- **检查数据类型**：文本和数字不能直接计算，需用`--`（双负号）或`VALUE()`转换
- **使用ISERROR或ISNA判断错误**：可以用`=IF(ISERROR(...), 0, ...)`处理错误

## 常见错误

### 1. VLOOKUP的col_index_num写错

**错误示例**：
```
=VLOOKUP(A1, B:D, 4, FALSE)  # B:D只有3列，col_index_num=4会报错#REF!
```

**正确做法**：
```
=VLOOKUP(A1, B:D, 3, FALSE)  # B:D的第3列是D列
```

### 2. 忘记锁定区域（相对引用 vs 绝对引用）

**错误示例**：
```
=VLOOKUP(A1, B:C, 2, FALSE)  # 复制公式时，B:C会变成C:D
```

**正确做法**：
```
=VLOOKUP(A1, $B:$C, 2, FALSE)  # 锁定B:C区域
```

### 3. 日期被识别为文本

**错误表现**：日期左对齐（文本左对齐，数值右对齐），或用`=ISNUMBER(A1)`返回FALSE

**解决方法**：
- 用`=DATEVALUE(A1)`将文本日期转为真正的日期
- 用分列功能（数据 → 分列 → 日期格式）批量转换

### 4. 浮点数比较错误

**错误示例**：
```
=IF(A1+B1=0.3, "相等", "不相等")  # 可能返回"不相等"（0.1+0.2≠0.3）
```

**正确做法**：
```
=IF(ABS(A1+B1-0.3)<0.0001, "相等", "不相等")  # 用误差范围判断
```

### 5. 忘记 Ctrl+Shift+Enter（数组公式）

**错误示例**（Excel 2019及以前）：
```
=SUM(IF(A:A>10, B:B))  # 普通回车，可能返回错误结果
```

**正确做法**：
- Excel 2019及以前：按Ctrl+Shift+Enter输入（公式两端会出现大括号`{}`）
- Excel 365：直接回车即可（支持动态数组）

### 6. 文本和数字混用

**错误示例**：
```
=A1+B1  # A1是文本"100"，B1是数字200，返回#VALUE!错误
```

**正确做法**：
```
=VALUE(A1)+B1  # 用VALUE()将文本转为数字
# 或者
=--A1+B1  # 用双负号将文本转为数字
```

## 总结

Excel常用函数是数据分析师处理数据的基础工具，核心要点包括：

1. **文本函数**：LEN、LEFT、RIGHT、MID、TRIM、CLEAN、SUBSTITUTE、UPPER、LOWER、PROPER
2. **逻辑函数**：IF、IFERROR、IFNA、AND、OR、NOT、IFS（Excel 2016+）
3. **查找与引用函数**：VLOOKUP、INDEX+MATCH、XLOOKUP（Excel 365+）
4. **统计函数**：SUM、AVERAGE、COUNT、COUNTA、MAX、MIN、SUMIF、SUMIFS、COUNTIF、COUNTIFS
5. **日期与时间函数**：TODAY、NOW、DATE、YEAR、MONTH、DAY、EOMONTH、DATEDIF、WORKDAY、NETWORKDAYS

熟练掌握这些函数，能够大幅提升数据处理的效率和准确性。

## 扩展阅读

### 高级函数

1. **数组函数**：FILTER、UNIQUE、SORT、SORTBY（Excel 365新增）
2. **动态数组**：Excel 365支持动态数组，一个公式可以返回多个结果
3. **Power Query**：用于复杂的数据清洗和转换（替代复杂的函数组合）
4. **Power Pivot**：用于大数据分析（替代SUMIFS等函数的多条件汇总）

### 实战案例

1. **电商数据分析**：用VLOOKUP/XLOOKUP关联订单表和用户表
2. **员工信息分析**：用DATEDIF计算工龄，用IFERROR处理错误
3. **业绩考核**：用IFS或嵌套IF计算提成档次
4. **日期分析**：用NETWORKDAYS计算工作日数
