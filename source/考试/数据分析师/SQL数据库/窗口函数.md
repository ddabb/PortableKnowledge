# SQL窗口函数

## 定义

窗口函数（Window Functions）是SQL中的一类特殊函数，可以在**保留原始行**的同时，对一组相关的行进行计算。与`GROUP BY`不同，窗口函数不会对行进行分组汇总（不会减少行数），而是为每一行添加一个计算结果列。

窗口函数是数据分析师进行复杂数据分析的利器，能够实现排名、同比环比、累计求和、移动平均等高级分析。

---

## 核心概念

### 1. 窗口函数的语法

```sql
函数名(列名) OVER (
  [PARTITION BY 分组列]
  [ORDER BY 排序列 [ASC|DESC]]
  [ROWS | RANGE 窗口框架]
)
```

**关键部分**：
- `函数名(列名)`：聚合函数或专用窗口函数
- `OVER`：标识这是一个窗口函数
- `PARTITION BY`：可选，类似`GROUP BY`，将行分组后独立计算
- `ORDER BY`：可选，指定窗口内的排序方式
- `ROWS | RANGE`：可选，指定窗口框架（计算范围）

### 2. 窗口函数的分类

| 分类 | 函数 | 说明 |
|------|------|------|
| **聚合窗口函数** | `SUM()`、`AVG()`、`COUNT()`、`MAX()`、`MIN()` | 在窗口内做聚合计算 |
| **排名窗口函数** | `ROW_NUMBER()`、`RANK()`、`DENSE_RANK()` | 为每行分配排名 |
| **取值窗口函数** | `LAG()`、`LEAD()`、`FIRST_VALUE()`、`LAST_VALUE()` | 获取窗口内其他行的值 |
| **分布窗口函数** | `PERCENT_RANK()`、`CUME_DIST()` | 计算百分位 |

### 3. 窗口框架（Window Frame）

| 语法 | 说明 |
|------|------|
| `ROWS BETWEEN 2 PRECEDING AND CURRENT ROW` | 当前行及前2行 |
| `ROWS BETWEEN CURRENT ROW AND 2 FOLLOWING` | 当前行及后2行 |
| `ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW` | 从第一行到当前行（累计） |
| `ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING` | 所有行 |

## 详细内容

### 一、聚合窗口函数

#### 1.1 累计求和

**场景**：查询员工工资，并显示从工资最低到当前员工的累计工资总和

```sql
SELECT 
    first_name,
    salary,
    SUM(salary) OVER (ORDER BY salary) AS cumulative_sum
FROM employees;
```

**说明**：
- `ORDER BY salary`：按工资排序
- `SUM(salary) OVER (...)`：计算从第一行到当前行的累计求和
- 默认窗口框架是`ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`（从第一行到当前行）

#### 1.2 分组累计

**场景**：查询每个部门的员工工资，并显示每个部门内的累计工资总和

```sql
SELECT 
    department_id,
    first_name,
    salary,
    SUM(salary) OVER (
        PARTITION BY department_id 
        ORDER BY salary
    ) AS dept_cumulative_sum
FROM employees;
```

**说明**：
- `PARTITION BY department_id`：按部门分组，每个部门独立计算
- `ORDER BY salary`：在每个部门内按工资排序
- 结果：每个部门的员工按工资排序，并显示部门内累计工资

#### 1.3 移动平均

**场景**：查询员工工资，并显示当前员工及前2名员工的平均工资（移动平均）

```sql
SELECT 
    first_name,
    salary,
    AVG(salary) OVER (
        ORDER BY salary
        ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
    ) AS moving_avg
FROM employees;
```

**说明**：
- `ROWS BETWEEN 2 PRECEDING AND CURRENT ROW`：窗口框架为当前行及前2行
- 结果：每个员工显示自己及前2名员工的平均工资

### 二、排名窗口函数

#### 2.1 ROW_NUMBER()（连续不重复排名）

**场景**：查询员工工资排名（无并列，排名连续不重复）

```sql
SELECT 
    first_name,
    salary,
    ROW_NUMBER() OVER (ORDER BY salary DESC) AS rank
FROM employees;
```

**说明**：
- 按工资降序排名，工资最高的排第1，次高的排第2，以此类推
- 如果工资相同，排序不确定（除非增加第二排序条件）

#### 2.2 RANK()（有并列，排名跳跃）

**场景**：查询员工工资排名（有并列，排名跳跃）

```sql
SELECT 
    first_name,
    salary,
    RANK() OVER (ORDER BY salary DESC) AS rank
FROM employees;
```

**说明**：
- 工资相同的员工排名相同
- 下一个排名会跳跃（如两个第1名，下一个是第3名）

#### 2.3 DENSE_RANK()（有并列，排名不跳跃）

**场景**：查询员工工资排名（有并列，排名不跳跃）

```sql
SELECT 
    first_name,
    salary,
    DENSE_RANK() OVER (ORDER BY salary DESC) AS rank
FROM employees;
```

**说明**：
- 工资相同的员工排名相同
- 下一个排名不会跳跃（如两个第1名，下一个是第2名）

#### 2.4 排名函数的对比

| 函数 | 并列处理 | 排名是否跳跃 | 示例（工资：100, 100, 90） |
|------|----------|--------------|------------------------------|
| `ROW_NUMBER()` | 无并列 | 不跳跃 | 1, 2, 3 |
| `RANK()` | 有并列 | 跳跃 | 1, 1, 3 |
| `DENSE_RANK()` | 有并列 | 不跳跃 | 1, 1, 2 |

### 三、取值窗口函数

#### 3.1 LAG()（获取前一行的值）

**场景**：查询员工工资，并显示该员工的前一名员工的工资（用于计算环比）

```sql
SELECT 
    first_name,
    salary,
    LAG(salary, 1) OVER (ORDER BY salary DESC) AS prev_salary
FROM employees;
```

**说明**：
- `LAG(salary, 1)`：获取前1行的工资
- 第一行的`prev_salary`为NULL（没有前一行）

#### 3.2 LEAD()（获取后一行的值）

**场景**：查询员工工资，并显示该员工的后一名员工的工资

```sql
SELECT 
    first_name,
    salary,
    LEAD(salary, 1) OVER (ORDER BY salary DESC) AS next_salary
FROM employees;
```

**说明**：
- `LEAD(salary, 1)`：获取后1行的工资
- 最后一行的`next_salary`为NULL（没有后一行）

#### 3.3 FIRST_VALUE()（获取窗口内第一行的值）

**场景**：查询员工工资，并显示部门内工资最低的员工工资

```sql
SELECT 
    department_id,
    first_name,
    salary,
    FIRST_VALUE(salary) OVER (
        PARTITION BY department_id 
        ORDER BY salary
    ) AS min_salary_in_dept
FROM employees;
```

**说明**：
- `FIRST_VALUE(salary)`：获取窗口内第一行的工资
- `PARTITION BY department_id`：按部门分组
- `ORDER BY salary`：在每个部门内按工资升序排序，第一行就是工资最低的员工

#### 3.4 LAST_VALUE()（获取窗口内最后一行的值）

**场景**：查询员工工资，并显示部门内工资最高的员工工资

```sql
SELECT 
    department_id,
    first_name,
    salary,
    LAST_VALUE(salary) OVER (
        PARTITION BY department_id 
        ORDER BY salary
        ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
    ) AS max_salary_in_dept
FROM employees;
```

**说明**：
- `LAST_VALUE(salary)`：获取窗口内最后一行的工资
- 需要显式指定窗口框架为`ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING`，否则默认框架是`ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`，最后一行的`LAST_VALUE`就是当前行

### 四、实用案例

#### 4.1 同比环比计算

**场景**：查询2024年每个月的销售额，以及环比增长率

```sql
SELECT 
    month,
    sales,
    LAG(sales, 1) OVER (ORDER BY month) AS prev_month_sales,
    ROUND(
        (sales - LAG(sales, 1) OVER (ORDER BY month)) / LAG(sales, 1) OVER (ORDER BY month) * 100, 
        2
    ) AS mom_growth_rate
FROM monthly_sales
WHERE year = 2024;
```

**说明**：
- `LAG(sales, 1) OVER (ORDER BY month)`：获取上个月的销售额
- 环比增长率 = (本月销售额 - 上月销售额) / 上月销售额 × 100%

#### 4.2 Top N 查询

**场景**：查询每个部门工资最高的前3名员工

```sql
SELECT *
FROM (
    SELECT 
        department_id,
        first_name,
        salary,
        ROW_NUMBER() OVER (
            PARTITION BY department_id 
            ORDER BY salary DESC
        ) AS rank
    FROM employees
) t
WHERE rank <= 3;
```

**说明**：
- 子查询中用`ROW_NUMBER()`为每个部门的员工按工资降序排名
- 外层查询筛选排名≤3的员工

#### 4.3 累计占比分析

**场景**：查询员工工资，并显示累计工资占总工资的比例

```sql
SELECT 
    first_name,
    salary,
    SUM(salary) OVER (ORDER BY salary) AS cumulative_sum,
    ROUND(
        SUM(salary) OVER (ORDER BY salary) / SUM(salary) OVER () * 100, 
        2
    ) AS cumulative_pct
FROM employees;
```

**说明**：
- `SUM(salary) OVER (ORDER BY salary)`：累计工资
- `SUM(salary) OVER ()`：总工资（窗口为所有行）
- 累计占比 = 累计工资 / 总工资 × 100%

## 示例/应用场景

### 示例1：电商订单分析

**需求**：查询2024年1月每个用户的订单金额排名，并找出每个用户的订单金额与上一个订单的差值

**涉及的表**：
- `orders`：订单表（用户ID、订单金额、订单日期）

**SQL语句**：

```sql
SELECT 
    user_id,
    order_amount,
    order_date,
    ROW_NUMBER() OVER (
        PARTITION BY user_id 
        ORDER BY order_amount DESC
    ) AS order_rank,
    order_amount - LAG(order_amount, 1) OVER (
        PARTITION BY user_id 
        ORDER BY order_date
    ) AS amount_diff
FROM orders
WHERE order_date BETWEEN '2024-01-01' AND '2024-01-31';
```

### 示例2：员工薪资分析

**需求**：查询每个部门工资最高的前3名员工，并显示该部门的平均工资和最高工资

**涉及的表**：
- `employees`：员工表（部门ID、姓名、工资）

**SQL语句**：

```sql
SELECT *
FROM (
    SELECT 
        department_id,
        first_name,
        salary,
        ROW_NUMBER() OVER (
            PARTITION BY department_id 
            ORDER BY salary DESC
        ) AS rank,
        AVG(salary) OVER (
            PARTITION BY department_id
        ) AS dept_avg_salary,
        MAX(salary) OVER (
            PARTITION BY department_id
        ) AS dept_max_salary
    FROM employees
) t
WHERE rank <= 3;
```

### 示例3：用户留存分析

**需求**：查询每个用户的首次登录日期和最后一次登录日期，以及登录天数

**涉及的表**：
- `user_login`：用户登录表（用户ID、登录日期）

**SQL语句**：

```sql
SELECT 
    user_id,
    FIRST_VALUE(login_date) OVER (
        PARTITION BY user_id 
        ORDER BY login_date
    ) AS first_login,
    LAST_VALUE(login_date) OVER (
        PARTITION BY user_id 
        ORDER BY login_date
        ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
    ) AS last_login,
    COUNT(login_date) OVER (
        PARTITION BY user_id
    ) AS login_days
FROM user_login;
```

## 数据分析师考点

### SQL窗口函数常见考点

1. **窗口函数 vs GROUP BY的区别**：窗口函数保留原始行，GROUP BY会汇总行
2. **窗口函数的执行顺序**：FROM → WHERE → GROUP BY → HAVING → 窗口函数 → SELECT → ORDER BY → LIMIT
3. **排名函数的区别**：ROW_NUMBER()（连续不重复）、RANK()（有并列，跳跃）、DENSE_RANK()（有并列，不跳跃）
4. **窗口框架的语法**：ROWS BETWEEN ... AND ...
5. **LAG()和LEAD()的用途**：获取前一行/后一行的值，用于环比、同比计算
6. **FIRST_VALUE()和LAST_VALUE()的用途**：获取窗口内第一行/最后一行的的值
7. **PARTITION BY的作用**：类似GROUP BY，将行分组后独立计算

### 实战考点

1. **性能优化**：
   - 窗口函数可能会导致性能问题（需要排序和窗口计算）
   - 尽量避免在大表上使用窗口函数，可以先过滤再计算
2. **数据库兼容性**：
   - MySQL 8.0+ 支持窗口函数
   - PostgreSQL、Oracle、SQL Server 都支持窗口函数
   - MySQL 5.7 及以前版本不支持窗口函数（需要用变量模拟）
3. **窗口框架的默认值**：
   - 如果有ORDER BY，默认框架是`ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`
   - 如果没有ORDER BY，默认框架是`ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING`
4. **NULL值的处理**：
   - 窗口函数会忽略NULL值（如SUM、AVG）
   - 但NULL值会参与排序（在升序中排在最前，降序排在最后）

## 最佳实践

### 1. 明确分析目标

- **先思考业务问题**：明确是要排名、累计、移动平均，还是环比同比
- **选择合适的窗口函数**：排名用ROW_NUMBER/RANK/DENSE_RANK，累计用SUM/AVG，环比用LAG/LEAD

### 2. 注意性能影响

- **先过滤再计算**：用WHERE过滤掉不需要的数据，减少窗口函数的计算量
- **避免在大表上使用窗口函数**：如果数据量很大，可以考虑先用GROUP BY汇总，再使用窗口函数
- **创建合适的索引**：PARTITION BY和ORDER BY的列应有索引

### 3. 处理NULL值

- **用COALESCE处理NULL**：如`LAG(COALESCE(salary, 0), 1) OVER (...)`
- **注意NULL值的排序位置**：升序时NULL排在最前，降序排在最后

### 4. 验证结果的正确性

- **检查排名是否正确**：如果有并列情况，确认使用的是RANK()还是DENSE_RANK()
- **检查累计求和是否正确**：确认窗口框架是否设置正确
- **检查环比计算是否正确**：确认分母不为0（可以用NULLIF处理）

## 常见错误

### 1. 混淆窗口函数和GROUP BY

**错误理解**：认为窗口函数和GROUP BY功能相同

**正确理解**：
- `GROUP BY`：分组汇总，减少行数
- `窗口函数`：保留原始行，为每行添加计算结果列

```sql
-- GROUP BY：每个部门一行（汇总）
SELECT department_id, AVG(salary)
FROM employees
GROUP BY department_id;

-- 窗口函数：每个员工一行（保留明细）
SELECT 
    department_id,
    first_name,
    salary,
    AVG(salary) OVER (PARTITION BY department_id) AS dept_avg_salary
FROM employees;
```

### 2. 忘记指定窗口框架

**错误示例**：
```sql
-- 想查询累计工资，但忘记指定窗口框架
SELECT 
    first_name,
    salary,
    SUM(salary) OVER (ORDER BY salary) AS cumulative_sum
FROM employees;
```

**问题**：默认窗口框架是`ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`，确实是累计求和，但如果没有ORDER BY，默认框架是`ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING`，结果就不是累计求和了。

**正确做法**：
```sql
-- 显式指定窗口框架（推荐）
SELECT 
    first_name,
    salary,
    SUM(salary) OVER (
        ORDER BY salary
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS cumulative_sum
FROM employees;
```

### 3. 在WHERE中使用窗口函数

**错误示例**：
```sql
-- 错误：WHERE中不能使用窗口函数
SELECT 
    first_name,
    salary,
    ROW_NUMBER() OVER (ORDER BY salary DESC) AS rank
FROM employees
WHERE ROW_NUMBER() OVER (ORDER BY salary DESC) <= 10;
```

**正确做法**：
```sql
-- 用子查询或CTE
SELECT *
FROM (
    SELECT 
        first_name,
        salary,
        ROW_NUMBER() OVER (ORDER BY salary DESC) AS rank
    FROM employees
) t
WHERE rank <= 10;
```

### 4. 混淆ROW_NUMBER()、RANK()、DENSE_RANK()

**错误选择**：在有并列情况下，错误地使用了ROW_NUMBER()

**正确选择**：
- 如果不需要并列，用ROW_NUMBER()
- 如果需要并列且排名跳跃，用RANK()
- 如果需要并列且排名不跳跃，用DENSE_RANK()

### 5. 忽略NULL值的处理

**错误示例**：
```sql
-- 如果salary有NULL，LAG(salary)可能返回NULL，导致计算错误
SELECT 
    first_name,
    salary,
    salary - LAG(salary, 1) OVER (ORDER BY salary DESC) AS diff
FROM employees;
```

**正确做法**：
```sql
-- 用COALESCE处理NULL
SELECT 
    first_name,
    salary,
    salary - COALESCE(LAG(salary, 1) OVER (ORDER BY salary DESC), 0) AS diff
FROM employees;
```

## 总结

SQL窗口函数是数据分析师进行复杂数据分析的利器，核心要点包括：

1. **掌握窗口函数的语法**：`函数名(列名) OVER (PARTITION BY ... ORDER BY ... ROWS BETWEEN ... AND ...)`
2. **理解窗口函数 vs GROUP BY的区别**：窗口函数保留原始行，GROUP BY会汇总行
3. **熟练使用排名窗口函数**：ROW_NUMBER()、RANK()、DENSE_RANK()
4. **熟练使用取值窗口函数**：LAG()、LEAD()、FIRST_VALUE()、LAST_VALUE()
5. **掌握窗口框架**：ROWS BETWEEN ... AND ...
6. **注意性能影响**：先过滤再计算，避免在大表上使用窗口函数

窗口函数是SQL高级功能，需要在实践中不断积累经验。
