# 帕累托分析

## 定义

**帕累托分析**是基于**二八法则**的重要分析方法，用于**找出影响业务的关键因素**。

对于数据分析师而言，掌握**帕累托分析**，是**进行关键因素分析、资源优化配置**的关键技能。

---

## 核心概念

### 1. 二八法则

| 概念 | 说明 | 示例 |
|------|------|------|
| **二八法则** | 80%的结果来自20%的原因 | 80%的销售额来自20%的客户 |
| **帕累托图** | 按影响因素从大到小排序的柱状图 + 累积百分比折线图 | 用于找出关键因素 |

### 2. 帕累托分析步骤

| 步骤 | 说明 | 工具 |
|------|------|------|
| **1. 收集数据** | 收集影响业务的因素及其数值 | Excel、SQL、Python |
| **2. 排序** | 按影响因素从大到小排序 | Excel、SQL、Python |
| **3. 计算累积百分比** | 计算各影响因素的累积百分比 | Excel、SQL、Python |
| **4. 绘制帕累托图** | 绘制柱状图 + 累积百分比折线图 | Excel、Python、Power BI、Tableau |
| **5. 找出关键因素** | 找出累积百分比80%以内的因素 | 所有工具 |

### 3. 帕累托分析应用场景

| 场景 | 说明 | 示例 |
|------|------|------|
| **销售额分析** | 找出贡献80%销售额的20%客户/商品 | 电商销售额分析 |
| **质量问题分析** | 找出导致80%质量问题的20%原因 | 制造业质量分析 |
| **客户投诉分析** | 找出导致80%客户投诉的20%问题 | 电商客户投诉分析 |

## 详细内容

### 一、收集数据

#### 1.1 数据准备

**数据字段**：
- 影响因素（客户、商品、质量问题等）
- 数值（销售额、质量问题数量、客户投诉数量等）

**示例数据**：
| 客户ID | 销售额 |
|--------|--------|
| 客户A | 1000 |
| 客户B | 800 |
| 客户C | 600 |
| ... | ... |

#### 1.2 使用Excel收集数据

**步骤**：
1. 将客户ID放在A列，销售额放在B列
2. 使用`SUM`函数计算总销售额
3. 使用`排序`功能按销售额从大到小排序

#### 1.3 使用SQL收集数据

**SQL代码**：
```sql
-- 收集客户销售额数据
SELECT 
    customer_id, 
    SUM(sales_amount) AS total_sales
FROM 
    sales_data
GROUP BY 
    customer_id
ORDER BY 
    total_sales DESC;
```

#### 1.4 使用Python收集数据

**Python代码**：
```python
import pandas as pd

# 读取数据
df = pd.read_csv('sales_data.csv')

# 按客户ID汇总销售额
customer_sales = df.groupby('客户ID')['销售额'].sum().reset_index()

# 按销售额从大到小排序
customer_sales = customer_sales.sort_values('销售额', ascending=False)

# 查看结果
print(customer_sales.head())
```

### 三、计算累积百分比

#### 3.1 使用Excel计算累积百分比

**步骤**：
1. 在C列计算累积销售额：在C2单元格输入`=B2`，在C3单元格输入`=C2+B3`，然后向下填充
2. 在D列计算累积百分比：在D2单元格输入`=C2/SUM($B$2:$B$100)`，然后向下填充

#### 3.2 使用SQL计算累积百分比

**SQL代码**：
```sql
-- 计算累积销售额和累积百分比
WITH customer_sales AS (
    SELECT 
        customer_id, 
        SUM(sales_amount) AS total_sales
    FROM 
        sales_data
    GROUP BY 
        customer_id
),
total_sales AS (
    SELECT 
        SUM(total_sales) AS total
    FROM 
        customer_sales
)
SELECT 
    cs.customer_id, 
    cs.total_sales,
    SUM(cs.total_sales) OVER (ORDER BY cs.total_sales DESC) AS cumulative_sales,
    SUM(cs.total_sales) OVER (ORDER BY cs.total_sales DESC) / ts.total AS cumulative_percentage
FROM 
    customer_sales cs,
    total_sales ts
ORDER BY 
    cs.total_sales DESC;
```

#### 3.3 使用Python计算累积百分比

**Python代码**：
```python
# 计算累积销售额
customer_sales['累积销售额'] = customer_sales['销售额'].cumsum()

# 计算总销售额
total_sales = customer_sales['销售额'].sum()

# 计算累积百分比
customer_sales['累积百分比'] = customer_sales['累积销售额'] / total_sales

# 查看结果
print(customer_sales.head())
```

### 五、找出关键因素

#### 5.1 找出累积百分比80%以内的因素

**Excel**：
- 查看累积百分比列，找出第一个超过80%的客户

**Python代码**：
```python
# 找出累积百分比80%以内的客户
key_customers = customer_sales[customer_sales['累积百分比'] <= 0.8]

# 查看关键客户数量
print("关键客户数量：", len(key_customers))

# 查看关键客户销售额占比
key_customer_sales_percentage = key_customers['销售额'].sum() / total_sales
print("关键客户销售额占比：", key_customer_sales_percentage)
```

**SQL代码**：
```sql
-- 找出累积百分比80%以内的客户
WITH customer_sales AS (
    SELECT 
        customer_id, 
        SUM(sales_amount) AS total_sales
    FROM 
        sales_data
    GROUP BY 
        customer_id
),
total_sales AS (
    SELECT 
        SUM(total_sales) AS total
    FROM 
        customer_sales
),
cumulative_sales AS (
    SELECT 
        cs.customer_id, 
        cs.total_sales,
        SUM(cs.total_sales) OVER (ORDER BY cs.total_sales DESC) AS cumulative_sales,
        SUM(cs.total_sales) OVER (ORDER BY cs.total_sales DESC) / ts.total AS cumulative_percentage
    FROM 
        customer_sales cs,
        total_sales ts
)
SELECT 
    COUNT(customer_id) AS key_customer_count,
    SUM(total_sales) / (SELECT total FROM total_sales) AS key_customer_sales_percentage
FROM 
    cumulative_sales
WHERE 
    cumulative_percentage <= 0.8;
```

## 示例/应用场景

### 示例1：电商销售额分析

**业务问题**：找出贡献80%销售额的20%客户。

**数据**：电商销售数据表（客户ID、销售额）

**分析**：

**Python代码**：
```python
# 按客户ID汇总销售额
customer_sales = df.groupby('客户ID')['销售额'].sum().reset_index()

# 按销售额从大到小排序
customer_sales = customer_sales.sort_values('销售额', ascending=False)

# 计算累积销售额
customer_sales['累积销售额'] = customer_sales['销售额'].cumsum()

# 计算总销售额
total_sales = customer_sales['销售额'].sum()

# 计算累积百分比
customer_sales['累积百分比'] = customer_sales['累积销售额'] / total_sales

# 找出累积百分比80%以内的客户
key_customers = customer_sales[customer_sales['累积百分比'] <= 0.8]

# 查看关键客户数量
print("关键客户数量：", len(key_customers))

# 查看关键客户销售额占比
key_customer_sales_percentage = key_customers['销售额'].sum() / total_sales
print("关键客户销售额占比：", key_customer_sales_percentage)

# 绘制帕累托图
plt.figure(figsize=(12, 6))
plt.bar(customer_sales['客户ID'], customer_sales['销售额'], color='blue', label='销售额')
plt.xticks(rotation=45)
plt.twinx()
plt.plot(customer_sales['客户ID'], customer_sales['累积百分比'], color='red', label='累积百分比')
plt.title('帕累托图（销售额）')
plt.xlabel('客户ID')
plt.ylabel('累积百分比')
plt.show()
```

**洞察与建议**：
- 如果关键客户销售额占比高，说明少数客户贡献了大部分销售额
- 可以针对关键客户制定VIP服务策略，保持销售额增长

**业务问题**：找出导致80%质量问题的20%原因。

# 绘制帕累托图

plt.bar(quality_issues['质量问题原因'], quality_issues['质量问题数量'], color='blue', label='质量问题数量')
plt.xticks(rotation=45)

plt.xlabel('质量问题原因')
plt.ylabel('累积百分比')
plt.show()

**洞察与建议**：
- 如果关键质量问题原因占比高，说明少数原因导致了大部分质量问题
- 可以针对关键质量问题原因制定改进措施，提升产品质量

## 最佳实践

### 1. 根据业务场景，选择合适的帕累托分析对象

**不推荐**（盲目使用帕累托分析）：
```text
无论什么业务场景，都使用帕累托分析
```

**推荐**（根据业务场景，选择合适的帕累托分析对象）：
```text
- 销售额分析 → 找出贡献80%销售额的20%客户/商品
- 质量问题分析 → 找出导致80%质量问题的20%原因
- 客户投诉分析 → 找出导致80%客户投诉的20%问题
```

### 2. 结合业务场景解释帕累托分析结果

**不推荐**（只报告帕累托分析结果）：
```text
关键客户销售额占比80%
```

**推荐**（结合业务场景解释帕累托分析结果）：
```text
关键客户销售额占比80%，说明少数客户贡献了大部分销售额。可以针对关键客户制定VIP服务策略，保持销售额增长。
```

### 3. 制定可执行的业务建议

**不推荐**（只报告帕累托分析结果，不制定业务建议）：
```text
关键客户销售额占比80%
```

**推荐**（报告帕累托分析结果，并制定业务建议）：
```text
关键客户销售额占比80%，说明少数客户贡献了大部分销售额。建议：
1. 针对关键客户制定VIP服务策略
2. 针对关键客户制定专属优惠策略
3. 针对关键客户制定定期回访策略
```

### 4. 定期更新帕累托分析

**不推荐**（只进行一次帕累托分析）：
```text
只进行一次帕累托分析，不更新
```

**推荐**（定期更新帕累托分析）：
```text
- 每月更新一次帕累托分析
- 根据最新数据调整关键因素
- 根据最新关键因素调整业务策略
```

2. **掌握帕累托分析步骤**：收集数据、排序、计算累积百分比、绘制帕累托图、找出关键因素

6. **避免常见错误**：盲目使用帕累托分析、不结合业务场景解释帕累托分析结果、不制定可执行的业务建议、不定期更新帕累托分析、帕累托图绘制错误
