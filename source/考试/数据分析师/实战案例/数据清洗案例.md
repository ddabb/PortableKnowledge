# 数据清洗案例

## 定义

数据清洗（Data Cleaning）是指识别并纠正（或删除）数据集中**错误、不完整、格式不正确、重复**等问题的过程。

数据清洗是数据分析的**前提**（Garbage In, Garbage Out），通常占据数据分析师**60%以上的工作时间**。

---

## 核心概念

### 1. 数据常见问题

| 问题类型 | 说明 | 处理方法 |
|----------|------|----------|
| **缺失值** | 数据中存在空值（NULL、NaN） | 删除、填充（均值、中位数、众数、前向/后向填充） |
| **异常值** | 数据中存在明显偏离正常值的数据 | 删除、盖帽（Winsorize）、转换（对数转换） |
| **重复值** | 数据中存在重复的记录 | 删除重复记录（保留第一条或最后一条） |
| **格式不一致** | 同一字段存在多种格式（如日期格式不一致） | 标准化格式（统一日期格式、统一大小写等） |
| **逻辑错误** | 数据中存在逻辑上不可能的值（如年龄=200） | 删除、修正（根据业务逻辑） |

### 2. 数据清洗的流程

```
识别问题 → 评估影响 → 选择处理方法 → 执行清洗 → 验证清洗结果
```

### 3. 数据清洗的原则

1. **尽可能保留数据**：删除数据是最后手段
2. **记录清洗操作**：记录所有清洗步骤，保证可复现
3. **结合业务逻辑**：不能只看统计指标，还要结合业务理解
4. **分步骤清洗**：每次只处理一个问题，避免引入新问题

## 详细内容

### 一、缺失值处理

#### 1.1 识别缺失值

**Python示例**：

```python
import pandas as pd
import numpy as np

# 创建示例数据
df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Charlie', None],
    'age': [25, np.nan, 35, 40],
    'city': ['Beijing', 'Shanghai', None, 'Guangzhou']
})

# 识别缺失值
print(df.isnull())        # 返回布尔值DataFrame
print(df.isnull().sum()) # 每列缺失值数量
```

#### 1.2 处理缺失值

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| **删除** | 删除缺失值所在的行或列 | 缺失值比例很小（<5%） |
| **填充（均值）** | 用均值填充缺失值 | 数值变量，分布近似正态 |
| **填充（中位数）** | 用中位数填充缺失值 | 数值变量，分布偏态 |
| **填充（众数）** | 用众数填充缺失值 | 分类变量 |
| **前向填充（Forward Fill）** | 用上一个非缺失值填充 | 时间序列数据 |
| **后向填充（Backward Fill）** | 用下一个非缺失值填充 | 时间序列数据 |
| **插值（Interpolation）** | 用线性插值等方法填充 | 时间序列数据 |

**Python示例**：

```python
# 删除缺失值所在的行
df_dropped = df.dropna()

# 用均值填充年龄
df['age'].fillna(df['age'].mean(), inplace=True)

# 用众数填充城市
df['city'].fillna(df['city'].mode()[0], inplace=True)

# 前向填充
df['city'].fillna(method='ffill', inplace=True)

# 后向填充
df['city'].fillna(method='bfill', inplace=True)
```

### 二、异常值处理

#### 2.1 识别异常值

**方法1：箱线图法（IQR方法）**

```python
import pandas as pd
import matplotlib.pyplot as plt

# 创建示例数据
df = pd.DataFrame({
    'salary': [3000, 3500, 4000, 4500, 5000, 10000]  # 10000可能是异常值
})

# 计算IQR
Q1 = df['salary'].quantile(0.25)
Q3 = df['salary'].quantile(0.75)
IQR = Q3 - Q1

# 定义异常值阈值
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

# 识别异常值
outliers = df[(df['salary'] < lower_bound) | (df['salary'] > upper_bound)]
print(outliers)

# 可视化（箱线图）
df.boxplot(column='salary')
plt.show()
```

**方法2：Z-score方法**

```python
from scipy import stats

# 计算Z-score
z_scores = np.abs(stats.zscore(df['salary']))

# 识别异常值（Z-score > 3）
outliers = df[z_scores > 3]
print(outliers)
```

#### 2.2 处理异常值

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| **删除** | 删除异常值所在的行 | 异常值明显是错误（如年龄=200） |
| **盖帽（Winsorize）** | 将异常值替换为上下阈值 | 异常值存在但可能是真实值 |
| **转换** | 对数据进行对数转换等 | 数据右偏严重 |
| **分箱** | 将连续变量离散化 | 减少异常值影响 |

**Python示例**：

```python
# 方法1：删除异常值
df_filtered = df[(df['salary'] >= lower_bound) & (df['salary'] <= upper_bound)]

# 方法2：盖帽（Winsorize）
from scipy.stats.mstats import winsorize
df['salary_winsorized'] = winsorize(df['salary'], limits=[0.05, 0.05])  # 上下各盖帽5%

# 方法3：对数转换
df['salary_log'] = np.log(df['salary'])
```

### 三、重复值处理

#### 3.1 识别重复值

**Python示例**：

```python
# 创建示例数据（包含重复行）
df = pd.DataFrame({
    'user_id': [1, 2, 2, 3, 4, 4],
    'name': ['Alice', 'Bob', 'Bob', 'Charlie', 'David', 'David']
})

# 识别重复行
print(df.duplicated())        # 返回布尔值Series
print(df[df.duplicated()])   # 查看重复行

# 识别基于某些列的重复（如user_id重复）
print(df[df.duplicated(subset=['user_id'])])
```

#### 3.2 处理重复值

**Python示例**：

```python
# 删除重复行（保留第一条）
df_dedup = df.drop_duplicates()

# 删除基于某些列的重复（保留第一条）
df_dedup = df.drop_duplicates(subset=['user_id'])

# 删除基于某些列的重复（保留最后一条）
df_dedup = df.drop_duplicates(subset=['user_id'], keep='last')
```

### 四、格式不一致处理

#### 4.1 日期格式不一致

**问题示例**：

```
2024-01-01
2024/01/01
01-01-2024
```

**处理方法**：

```python
# 统一日期格式
df['date'] = pd.to_datetime(df['date'], format='%Y-%m-%d')
```

#### 4.2 大小写不一致

**问题示例**：

```
Beijing
BEIJING
beijing
```

**处理方法**：

```python
# 统一转换为小写
df['city'] = df['city'].str.lower()

# 或者统一转换为大写
df['city'] = df['city'].str.upper()
```

#### 4.3 单位不一致

**问题示例**：

```
身高：170cm、1.7m、1700mm
```

**处理方法**：

```python
# 统一单位（如全部转换为cm）
def standardize_height(height):
    if 'm' in height:
        return float(height.replace('m', '')) * 100
    elif 'mm' in height:
        return float(height.replace('mm', '')) / 10
    else:
        return float(height.replace('cm', ''))

df['height_cm'] = df['height'].apply(standardize_height)
```

## 示例/应用场景

### 示例1：电商订单数据清洗

**业务场景**：某电商平台订单数据存在缺失值、异常值、重复值等问题，需要清洗后再进行分析。

**数据问题描述**：

| 问题类型 | 具体描述 |
|----------|----------|
| 缺失值 | 部分订单的"订单金额"字段为空 |
| 异常值 | 部分订单的"订单金额"为负数或远大于正常值 |
| 重复值 | 部分订单被重复记录 |

**清洗步骤**：

1. **缺失值处理**：删除"订单金额"为空的订单（缺失值比例<5%）
2. **异常值处理**：删除"订单金额"为负数或大于10000元的订单（业务规定订单金额上限为10000元）
3. **重复值处理**：根据"订单ID"删除重复订单（保留第一条）

**Python代码**：

```python
import pandas as pd

# 读取订单数据
df = pd.read_csv('orders.csv')

# 1. 缺失值处理：删除"订单金额"为空的订单
df = df.dropna(subset=['order_amount'])

# 2. 异常值处理：删除"订单金额"为负数或大于10000元的订单
df = df[(df['order_amount'] >= 0) & (df['order_amount'] <= 10000)]

# 3. 重复值处理：根据"订单ID"删除重复订单
df = df.drop_duplicates(subset=['order_id'], keep='first')

# 保存清洗后的数据
df.to_csv('orders_cleaned.csv', index=False)
```

### 示例2：用户数据清洗

**业务场景**：某App用户注册数据存在格式不一致、逻辑错误等问题，需要清洗后再进行分析。

**数据问题描述**：

| 问题类型 | 具体描述 |
|----------|----------|
| 格式不一致 | 日期格式不一致（如"2024-01-01"和"2024/01/01"） |
| 逻辑错误 | 年龄字段存在负值或过大值（如年龄=200） |

**清洗步骤**：

1. **格式不一致处理**：统一日期格式为"YYYY-MM-DD"
2. **逻辑错误处理**：删除年龄<0或年龄>120的用户（业务规定年龄范围0-120岁）

**Python代码**：

```python
import pandas as pd

# 读取用户数据
df = pd.read_csv('users.csv')

# 1. 格式不一致处理：统一日期格式
df['register_date'] = pd.to_datetime(df['register_date'], errors='coerce')

# 2. 逻辑错误处理：删除年龄<0或年龄>120的用户
df = df[(df['age'] >= 0) & (df['age'] <= 120)]

# 保存清洗后的数据
df.to_csv('users_cleaned.csv', index=False)
```

### 示例3：员工薪资数据清洗

**业务场景**：某公司员工薪资数据存在缺失值、异常值等问题，需要清洗后再进行分析。

**数据问题描述**：

| 问题类型 | 具体描述 |
|----------|----------|
| 缺失值 | 部分员工的"薪资"字段为空 |
| 异常值 | 部分员工的"薪资"远低于或远高于行业水平 |

**清洗步骤**：

1. **缺失值处理**：用同行业同职位的平均薪资填充缺失值
2. **异常值处理**：用盖帽法（Winsorize）处理异常薪资

**Python代码**：

```python
import pandas as pd
from scipy.stats.mstats import winsorize

# 读取员工薪资数据
df = pd.read_csv('employees.csv')

# 1. 缺失值处理：用同行业同职位的平均薪资填充
df['salary'] = df.groupby(['industry', 'job_title'])['salary'].transform(
    lambda x: x.fillna(x.mean())
)

# 2. 异常值处理：盖帽法（上下各盖帽5%）
df['salary_winsorized'] = winsorize(df['salary'], limits=[0.05, 0.05])

# 保存清洗后的数据
df.to_csv('employees_cleaned.csv', index=False)
```

## 数据分析师考点

### 数据清洗常见考点

1. **数据常见问题**：缺失值、异常值、重复值、格式不一致、逻辑错误
2. **缺失值处理方法**：删除、填充（均值、中位数、众数、前向/后向填充、插值）
3. **异常值识别方法**：箱线图法（IQR方法）、Z-score方法
4. **异常值处理方法**：删除、盖帽（Winsorize）、转换（对数转换）、分箱
5. **重复值处理方法**：根据全部列或部分列删除重复值
6. **格式不一致处理方法**：统一日期格式、统一大小写、统一单位等
7. **数据清洗原则**：尽可能保留数据、记录清洗操作、结合业务逻辑、分步骤清洗

### 实战考点

1. **结合业务逻辑**：
   - 不能只看统计指标，还要结合业务理解（如订单金额上限、年龄范围等）
2. **记录清洗操作**：
   - 记录所有清洗步骤，保证可复现
   - 最好使用脚本（如Python）进行清洗，而不是手动修改
3. **评估清洗效果**：
   - 清洗前后数据质量对比（如缺失值比例、异常值数量等）
   - 清洗后数据分析结果是否合理

## 最佳实践

### 1. 分步骤清洗，每次只处理一个问题

**不推荐**（一次性处理所有问题，容易引入新问题）：

```python
# 一次性处理缺失值、异常值、重复值
df = df.dropna().drop_duplicates()
df = df[(df['salary'] >= 0) & (df['salary'] <= 10000)]
```

**推荐**（分步骤清洗，每次只处理一个问题）：

```python
# 步骤1：处理缺失值
df = df.dropna(subset=['order_amount'])

# 步骤2：处理异常值
df = df[(df['order_amount'] >= 0) & (df['order_amount'] <= 10000)]

# 步骤3：处理重复值
df = df.drop_duplicates(subset=['order_id'], keep='first')
```

### 2. 记录清洗操作，保证可复现

**不推荐**（手动修改数据，无法追溯）：

```
在Excel中手动删除某些行、修改某些值。
```

**推荐**（使用脚本清洗，记录所有操作）：

```python
import pandas as pd

# 读取原始数据
df = pd.read_csv('data.csv')

# 记录清洗操作
print(f'原始数据行数: {len(df)}')
df = df.dropna()
print(f'删除缺失值后行数: {len(df)}')
df = df.drop_duplicates()
print(f'删除重复值后行数: {len(df)}')

# 保存清洗后的数据
df.to_csv('data_cleaned.csv', index=False)
```

### 3. 尽可能保留数据，删除是最后手段

**不推荐**（遇到缺失值就删除）：

```python
# 删除所有缺失值所在的行
df = df.dropna()
```

**推荐**（根据情况选择处理方法）：

```python
# 如果缺失值比例很小（<5%），可以删除
if df['column'].isnull().mean() < 0.05:
    df = df.dropna(subset=['column'])
else:
    # 否则用均值/中位数/众数填充
    df['column'].fillna(df['column'].mean(), inplace=True)
```

### 4. 结合业务逻辑，不能只看统计指标

**不推荐**（只看统计指标，不考虑业务逻辑）：

```python
# 用Z-score方法识别异常值（可能将业务上的合理值误判为异常值）
z_scores = np.abs(stats.zscore(df['order_amount']))
df = df[z_scores <= 3]
```

**推荐**（结合业务逻辑）：

```python
# 结合业务逻辑（如订单金额上限为10000元）
df = df[(df['order_amount'] >= 0) & (df['order_amount'] <= 10000)]
```

## 常见错误

### 1. 不检查就直接删除缺失值

**错误示例**：

```python
# 不检查缺失值比例，直接删除
df = df.dropna()
```

**正确做法**：

```python
# 先检查缺失值比例
missing_ratio = df.isnull().mean()
print(missing_ratio)

# 根据缺失值比例选择处理方法
if missing_ratio < 0.05:
    df = df.dropna()
else:
    df = df.fillna(df.mean())
```

### 2. 不结合业务逻辑就直接删除异常值

**错误示例**：

```python
# 用箱线图法识别异常值，不结合业务逻辑
Q1 = df['order_amount'].quantile(0.25)
Q3 = df['order_amount'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
df = df[(df['order_amount'] >= lower_bound) & (df['order_amount'] <= upper_bound)]
```

**正确做法**：

```python
# 结合业务逻辑（如订单金额上限为10000元）
df = df[(df['order_amount'] >= 0) & (df['order_amount'] <= 10000)]
```

### 3. 清洗后不验证结果

**错误示例**：

```python
# 清洗后直接进行分析，不验证清洗结果
df = df.dropna()
# 直接进行下一步分析...
```

**正确做法**：

```python
# 清洗后验证结果
print(f'清洗后缺失值数量: {df.isnull().sum()}')
print(f'清洗后异常值数量: {len(df[(df["order_amount"] < 0) | (df["order_amount"] > 10000)])}')
# 确认清洗效果后再进行下一步分析
```

### 4. 手动修改数据，无法追溯

**错误示例**：

```
在Excel中手动删除某些行、修改某些值，无法追溯修改过程。
```

**正确做法**：

```python
# 使用脚本清洗，记录所有操作
import pandas as pd

df = pd.read_csv('data.csv')
# 记录清洗操作
print(f'原始数据行数: {len(df)}')
df = df.dropna()
print(f'删除缺失值后行数: {len(df)}')
df.to_csv('data_cleaned.csv', index=False)
```

### 5. 过度清洗，删除太多数据

**错误示例**：

```python
# 过度清洗，删除太多数据（如删除所有异常值，可能删除了业务上的合理值）
df = df[(df['order_amount'] >= lower_bound) & (df['order_amount'] <= upper_bound)]
```

**正确做法**：

```python
# 结合业务逻辑，避免过度清洗
df = df[(df['order_amount'] >= 0) & (df['order_amount'] <= 10000)]
```

## 总结

数据清洗是数据分析的前提，关键要点包括：

1. **掌握数据常见问题**：缺失值、异常值、重复值、格式不一致、逻辑错误
2. **熟练使用处理方法**：缺失值处理（删除、填充）、异常值处理（删除、盖帽、转换）、重复值处理（删除）、格式不一致处理（标准化）
3. **遵循数据清洗原则**：尽可能保留数据、记录清洗操作、结合业务逻辑、分步骤清洗
4. **注意最佳实践**：分步骤清洗、记录清洗操作、尽可能保留数据、结合业务逻辑
5. **避免常见错误**：不检查就直接删除缺失值、不结合业务逻辑就直接删除异常值、清洗后不验证结果、手动修改数据无法追溯、过度清洗删除太多数据

数据清洗是数据分析师的必备技能，需要在实践中不断积累经验。
