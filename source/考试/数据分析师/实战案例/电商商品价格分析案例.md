## 核心概念

### 1. 分析流程

| 步骤 | 说明 | 工具 |
|------|------|------|
| **数据导入** | 从各种数据源导入数据 | Excel、SQL、Python、Power BI、Tableau |

| **业务洞察** | 从数据中提取业务价值 | 所有工具 |

### 2. 价格分析指标

| 指标 | 说明 | 计算公式 |
|------|------|----------|
| **平均价格** | 商品平均价格 | AVG(价格) |
| **价格区间** | 最高价格与最低价格之差 | MAX(价格) - MIN(价格) |
| **价格标准差** | 价格离散程度 | STDEV(价格) |
| **价格中位数** | 价格中间值 | MEDIAN(价格) |
| **价格波动系数** | 价格稳定性 | 价格标准差 / 平均价格 |

### 3. 分析维度

| 维度 | 说明 | 示例 |
|------|------|------|
| **品类维度** | 按品类分析价格数据 | 各品类平均价格、各品类价格分布 |
| **时间维度** | 按时间分析价格数据 | 月度价格趋势、季度价格波动 |
| **品牌维度** | 按品牌分析价格数据 | 各品牌平均价格、各品牌价格分布 |

### 二、数据清洗

#### 2.1 处理缺失值

**Excel**：
- 使用筛选功能查找缺失值
- 使用替换功能填充缺失值

**Python**：
```python
# 查找缺失值
print(df.isnull().sum())

# 填充缺失值
df['价格'].fillna(df['价格'].mean(), inplace=True)

# 删除缺失值
df.dropna(inplace=True)
```

**SQL**：
```sql
-- 查找缺失值
SELECT * FROM product_price_data WHERE price IS NULL;

-- 填充缺失值
UPDATE product_price_data SET price = (SELECT AVG(price) FROM product_price_data) WHERE price IS NULL;

-- 删除缺失值
DELETE FROM product_price_data WHERE price IS NULL;
```

#### 2.2 处理异常值

**Excel**：
- 使用排序功能查找异常值
- 使用替换功能修正异常值

**Python**：
```python
# 使用箱线图识别异常值
import seaborn as sns
sns.boxplot(df['价格'])

# 删除异常值
Q1 = df['价格'].quantile(0.25)
Q3 = df['价格'].quantile(0.75)
IQR = Q3 - Q1
df = df[~((df['价格'] < (Q1 - 1.5 * IQR)) | (df['价格'] > (Q3 + 1.5 * IQR)))]
```

**SQL**：
```sql
-- 使用四分位数识别异常值
WITH quartiles AS (
    SELECT 
        PERCENTILE_CONT(0.25) WITHIN GROUP (ORDER BY price) AS Q1,
        PERCENTILE_CONT(0.75) WITHIN GROUP (ORDER BY price) AS Q3
    FROM 
        product_price_data
)
SELECT 
    * 
FROM 
    product_price_data, 
    quartiles
WHERE 
    price < (Q1 - 1.5 * (Q3 - Q1)) 
    OR price > (Q3 + 1.5 * (Q3 - Q1));
```

#### 2.3 处理重复值

**Excel**：
- 使用"删除重复项"功能

**Python**：
```python
# 查找重复值
print(df.duplicated().sum())

# 删除重复值
df.drop_duplicates(inplace=True)
```

**SQL**：
```sql
-- 查找重复值
SELECT 
    product_id, 
    COUNT(*) 
FROM 
    product_price_data 
GROUP BY 
    product_id 
HAVING 
    COUNT(*) > 1;

-- 删除重复值（保留第一条）
WITH cte AS (
    SELECT 
        *, 
        ROW_NUMBER() OVER (PARTITION BY product_id ORDER BY listing_date) AS rn
    FROM 
        product_price_data
)
DELETE FROM product_price_data 
WHERE 
    product_id IN (SELECT product_id FROM cte WHERE rn > 1);
```

### 三、数据探索

#### 3.1 了解数据基本特征

**Python**：
```python
# 查看数据基本信息
print(df.info())

# 查看数据统计信息
print(df.describe())

print(df.groupby('品类')['价格'].mean())
```


#### 3.2 分析价格分布

**Python**：
```python
# 各品类价格分布
import matplotlib.pyplot as plt
import seaborn as sns

# 箱线图
sns.boxplot(data=df, x='品类', y='价格')
plt.title('各品类价格分布')
plt.xticks(rotation=45)
plt.show()

# 直方图
sns.histplot(df['价格'], kde=True)
plt.title('价格分布直方图')
plt.show()
```

**SQL**：
```sql
-- 各品类价格分布（使用窗口函数）
SELECT 
    category,
    price,
    PERCENT_RANK() OVER (PARTITION BY category ORDER BY price) AS price_percentile
FROM 
    product_price_data
ORDER BY 
    category, price;
```

#### 3.3 分析价格波动

**Python**：
```python
# 将上架日期转换为日期类型
df['上架日期'] = pd.to_datetime(df['上架日期'])

# 按月份汇总平均价格
monthly_avg_price = df.resample('M', on='上架日期')['价格'].mean()

# 绘制折线图
monthly_avg_price.plot()
plt.title('月度平均价格趋势')
plt.show()
```

**SQL**：
```sql
-- 按月份汇总平均价格
SELECT 
    DATE_FORMAT(listing_date, '%Y-%m') AS month, 
    AVG(price) AS avg_price
FROM 
    product_price_data
GROUP BY 
    month
ORDER BY 
    month;
```

### 五、业务洞察

#### 5.1 分析价格分布

**洞察**：
- 如果某品类价格区间大，说明该品类价格差异大
- 如果某品类价格区间小，说明该品类价格差异小

**建议**：
- 针对价格差异大的品类，制定统一的价格策略
- 针对价格差异小的品类，保持价格稳定

#### 5.2 分析价格波动

**洞察**：
- 如果某月份价格高，说明该月份价格行情好
- 如果某月份价格低，说明该月份价格行情差

**建议**：
- 分析价格高的月份的原因，优化其他月份价格策略
- 针对价格低的月份，制定促销活动

#### 5.3 分析品类差异

**洞察**：
- 如果某品类平均价格高，说明该品类定位高端
- 如果某品类平均价格低，说明该品类定位低端

**建议**：
- 针对平均价格高的品类，保持高端定位
- 针对平均价格低的品类，优化产品定位或淘汰

#### 5.4 分析品牌差异

**洞察**：
- 如果某品牌平均价格高，说明该品牌定位高端
- 如果某品牌平均价格低，说明该品牌定位低端

**建议**：
- 针对平均价格高的品牌，保持高端定位
- 针对平均价格低的品牌，优化品牌定位或淘汰

## 最佳实践

### 1. 遵循完整的分析流程

**不推荐**（跳跃式分析）：
```text
直接进行数据可视化，跳过数据清洗和数据探索
```

**推荐**（遵循完整的分析流程）：
```text
数据导入 → 数据清洗 → 数据探索 → 数据可视化 → 业务洞察
```

### 2. 结合业务场景解释分析结果

**不推荐**（只报告分析结果）：
```text
品类A的价格区间最大
```

**推荐**（结合业务场景解释分析结果）：
```text
品类A的价格区间最大，说明该品类价格差异大。可以针对该品类制定统一的价格策略。
```

### 3. 使用合适的可视化图表

**不推荐**（盲目使用柱状图）：
```text
无论什么分析需求，都使用柱状图
```

**推荐**（根据分析需求，选择合适的可视化图表）：
```text
- 比较各类别数值 → 柱状图、条形图
- 显示数据随时间变化趋势 → 折线图
- 显示数据分布 → 箱线图、直方图
- 显示数据密度 → 热力图
```

### 4. 提出可执行的业务建议

**不推荐**（只报告分析结果，不提出业务建议）：
```text
品类A的价格区间最大
```

**推荐**（报告分析结果，并提出业务建议）：
```text
品类A的价格区间最大，说明该品类价格差异大。建议：
1. 制定统一的价格策略
2. 分析价格差异的原因
3. 优化产品定位
```
