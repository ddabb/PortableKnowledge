# Power BI基础

## 定义

**Power BI**是微软推出的商业智能工具，通过**数据连接、报表创建、可视化图表、仪表板**等功能，帮助用户进行数据分析和可视化。

对于数据分析师而言，掌握**Power BI基础**，是**进行数据可视化、制作专业报表**的关键技能。

---

## 核心概念

### 1. 数据连接

| 概念 | 说明 | 示例 |
|------|------|------|
| **数据连接** | 连接各种数据源 | 连接Excel、CSV、数据库等 |
| **数据转换** | 清洗和转换数据 | 删除列、筛选行、添加列等 |
| **数据建模** | 创建表之间的关系 | 创建一对一、一对多关系 |
| **数据刷新** | 刷新数据源数据 | 定时刷新或手动刷新 |

### 2. 报表

| 概念 | 说明 | 示例 |
|------|------|------|
| **报表** | 创建可视化图表的基本单位 | 创建报表，添加字段和可视化对象 |
| **字段** | 数据表中的列 | 拖拽字段到报表画布 |
| **可视化对象** | 报表中的图表 | 柱状图、折线图、饼图等 |
| **筛选器** | 筛选报表数据 | 页面筛选器、报表筛选器、视觉对象筛选器 |

### 3. 可视化图表

| 概念 | 说明 | 示例 |
|------|------|------|
| **柱状图** | 比较各类别数值 | 不同品类销售额对比 |
| **折线图** | 显示数据随时间变化趋势 | 月度销售额趋势 |
| **饼图** | 显示各部分占总体比例 | 各品类销售额占比 |
| **散点图** | 显示两个变量之间的关系 | 销售额与利润关系 |
| **地图** | 显示地理数据 | 各省份销售额分布 |
| **表格** | 显示详细数据 | 各商品销售明细 |

### 4. 仪表板

| 概念 | 说明 | 示例 |
|------|------|------|
| **仪表板** | 组合多个报表页面 | 创建销售仪表板 |
| **磁贴** | 仪表板上的可视化对象 | 将报表可视化对象固定到仪表板 |
| **仪表板操作** | 仪表板交互操作 | 筛选器、钻取、工具提示等 |
| **仪表板共享** | 共享和发布仪表板 | 共享给同事、发布到Web等 |

## 详细内容

### 一、数据连接

#### 1.1 连接数据源

**连接Excel文件**：
1. 打开Power BI Desktop，点击"主页" → "获取数据"
2. 选择"Excel"
3. 选择Excel文件，点击"打开"
4. 选择工作表，点击"转换数据"或"加载"

**连接CSV文件**：
1. 打开Power BI Desktop，点击"主页" → "获取数据"
2. 选择"文本/CSV"
3. 选择CSV文件，点击"打开"
4. 预览数据，设置分隔符等，点击"加载"

**连接数据库**：
1. 打开Power BI Desktop，点击"主页" → "获取数据"
2. 选择数据库类型（如SQL Server、MySQL等）
3. 输入服务器、数据库、用户名、密码等
4. 点击"连接"，选择表，点击"加载"

#### 1.2 数据转换

**打开Power Query编辑器**：
1. 点击"主页" → "转换数据"
2. 打开Power Query编辑器

**常用转换操作**：
- **删除列**：选择列，右键 → "删除"
- **筛选行**：点击列标题下拉箭头，设置筛选条件
- **添加列**：点击"添加列" → "自定义列"，输入公式
- **更改数据类型**：选择列，点击"数据类型"下拉菜单，选择类型
- **替换值**：选择列，点击"替换值"，输入查找值和替换值
- **分组依据**：点击"分组依据"，选择分组列和聚合函数

#### 1.3 数据建模

**创建表关系**：
1. 切换到"模型"视图
2. 拖拽一个表的字段到另一个表的字段
3. 设置关系类型（一对一、一对多、多对多）
4. 设置交叉筛选方向（单向、双向）

**管理关系**：
1. 点击"模型" → "管理关系"
2. 查看、编辑、删除关系

#### 1.4 数据刷新

**手动刷新**：
1. 点击"主页" → "刷新"
2. 刷新所有数据

**定时刷新**：
1. 点击"文件" → "选项和设置" → "数据源设置"
2. 设置数据刷新频率和时间

### 二、报表创建

#### 2.1 创建报表

**步骤**：
1. 切换到"报表"视图
2. 在"字段"窗格中，拖拽字段到报表画布
3. 自动生成可视化对象

#### 2.2 添加可视化对象

**添加柱状图**：
1. 在"可视化对象"窗格中，选择"柱状图"
2. 拖拽字段到"轴"、"值"、"图例"等 bucket
3. 自动生成柱状图

**添加折线图**：
1. 在"可视化对象"窗格中，选择"折线图"
2. 拖拽字段到"轴"、"值"、"图例"等 bucket
3. 自动生成折线图

**添加饼图**：
1. 在"可视化对象"窗格中，选择"饼图"
2. 拖拽字段到"图例"、"值"等 bucket
3. 自动生成饼图

#### 2.3 设置筛选器

**页面筛选器**：
1. 在"筛选器"窗格中，选择"页面级别筛选器"
2. 拖拽字段到"页面级别筛选器"区域
3. 设置筛选条件

**报表筛选器**：
1. 在"筛选器"窗格中，选择"报表级别筛选器"
2. 拖拽字段到"报表级别筛选器"区域
3. 设置筛选条件

**视觉对象筛选器**：
1. 选择可视化对象
2. 在"筛选器"窗格中，选择"视觉对象级别筛选器"
3. 拖拽字段到"视觉对象级别筛选器"区域
4. 设置筛选条件

---

### 三、可视化图表

#### 3.1 柱状图

**创建柱状图**：
1. 在"可视化对象"窗格中，选择"柱状图"
2. 将类别字段（如"品类"）拖到"轴" bucket
3. 将度量字段（如"销售额"）拖到"值" bucket
4. 自动生成柱状图

**柱状图类型**：
- **垂直柱状图**：类别在轴，度量在值
- **水平柱状图**：类别在轴，度量在值（条形图）
- **堆叠柱状图**：将另一个类别字段拖到"图例" bucket

#### 3.2 折线图

**创建折线图**：
1. 在"可视化对象"窗格中，选择"折线图"
2. 将时间字段（如"月份"）拖到"轴" bucket
3. 将度量字段（如"销售额"）拖到"值" bucket
4. 自动生成折线图

**折线图类型**：
- **单线折线图**：一个度量
- **多线折线图**：将另一个类别字段拖到"图例" bucket

#### 3.3 饼图

**创建饼图**：
1. 在"可视化对象"窗格中，选择"饼图"
2. 将类别字段（如"品类"）拖到"图例" bucket
3. 将度量字段（如"销售额"）拖到"值" bucket
4. 自动生成饼图

#### 3.4 散点图

**创建散点图**：
1. 在"可视化对象"窗格中，选择"散点图"
2. 将度量字段1（如"销售额"）拖到"X轴" bucket
3. 将度量字段2（如"利润"）拖到"Y轴" bucket
4. 将类别字段（如"品类"）拖到"图例" bucket
5. 自动生成散点图

#### 3.5 地图

**创建地图**：
1. 在"可视化对象"窗格中，选择"地图"
2. 将地理字段（如"省份"、"城市"）拖到"位置" bucket
3. 将度量字段（如"销售额"）拖到"大小"或"颜色" bucket
4. 自动生成地图

#### 3.6 表格

**创建表格**：
1. 在"可视化对象"窗格中，选择"表格"
2. 将字段拖到"值" bucket
3. 自动生成表格

### 四、仪表板

#### 4.1 创建仪表板

**发布到Power BI服务**：
1. 在Power BI Desktop中，点击"文件" → "发布到Power BI"
2. 选择工作区，点击"选择"
3. 发布成功

**创建仪表板**：
1. 在Power BI服务中，点击"新建" → "仪表板"
2. 输入仪表板名称，点击"创建"

#### 4.2 添加磁贴

**将报表可视化对象固定到仪表板**：
1. 打开报表
2. 将鼠标悬停在可视化对象上，点击"固定视觉对象"
3. 选择仪表板，点击"固定"

**添加磁贴**：
1. 打开仪表板
2. 点击"添加磁贴"
3. 选择磁贴类型（可视化对象、图像、文本框、视频等）
4. 配置磁贴，点击"应用"

#### 4.3 仪表板操作

**筛选器**：
1. 在仪表板上添加筛选器
2. 设置筛选器类型和选项
3. 筛选器可以作用于多个磁贴

**钻取**：
1. 在报表中设置钻取
2. 在仪表板中，点击磁贴，钻取到详细报表

**工具提示**：
1. 在报表中设置工具提示
2. 在仪表板中，将鼠标悬停在磁贴上，显示工具提示

#### 4.4 仪表板共享

**共享给同事**：
1. 打开仪表板
2. 点击"共享"
3. 输入同事邮箱，点击"共享"

**发布到Web**：
1. 打开仪表板
2. 点击"文件" → "发布到Web"
3. 获取嵌入代码，点击"发布"

## 示例/应用场景

### 示例1：电商销售数据分析

**业务问题**：分析电商销售数据，制作销售仪表板。

**数据**：电商销售数据表（订单ID、商品ID、品类、销售额、销量、订单日期）

**分析**：

**Power BI操作**：
1. **连接数据**：连接电商销售数据Excel文件
2. **转换数据**：删除不需要的列，筛选有效数据
3. **创建报表**：
   - 各品类销售额柱状图
   - 月度销售额折线图
   - 各品类销售额占比饼图
   - 销售额与销量散点图
4. **创建仪表板**：将以上报表可视化对象固定到仪表板
5. **添加筛选器**：添加日期筛选器、品类筛选器
6. **共享仪表板**：共享给同事或发布到Web

**洞察与建议**：
- 如果某品类销售额高，说明该品类受欢迎
- 可以针对高销售额品类制定营销策略
- 可以分析高销售额品类的特征，优化商品推荐

### 示例2：电商用户行为分析

**业务问题**：分析电商用户行为，制作用户行为仪表板。

**数据**：电商用户行为数据表（用户ID、用户类型、访问量、购买次数、注册日期）

**分析**：

**Power BI操作**：
1. **连接数据**：连接电商用户行为数据Excel文件
2. **转换数据**：删除不需要的列，筛选有效数据
3. **创建报表**：
   - 各用户类型访问量柱状图
   - 月度访问量折线图
   - 各用户类型购买转化率柱状图
   - 访问量与购买次数散点图
4. **创建仪表板**：将以上报表可视化对象固定到仪表板
5. **添加筛选器**：添加日期筛选器、用户类型筛选器
6. **共享仪表板**：共享给同事或发布到Web

**洞察与建议**：
- 如果某用户类型购买转化率高，说明该用户类型价值高
- 可以针对高转化率用户类型制定用户运营策略
- 可以分析低转化率用户类型的原因，优化产品或运营

### 示例3：电商商品价格分析

**业务问题**：分析电商商品价格，制作商品价格仪表板。

**数据**：电商商品价格数据表（商品ID、品类、价格、上架日期）

**分析**：

**Power BI操作**：
1. **连接数据**：连接电商商品价格数据Excel文件
2. **转换数据**：删除不需要的列，筛选有效数据

   - 各品类平均价格柱状图
   - 各品类价格区间柱状图

   - 价格与销量散点图

5. **添加筛选器**：添加品类筛选器、价格区间筛选器

## 最佳实践

### 1. 根据分析需求，选择合适的数据源

**不推荐**（盲目连接数据源）：
```text
无论什么分析需求，都连接同一个数据源
```

**推荐**（根据分析需求，选择合适的数据源）：
```text
- 分析销售数据 → 连接销售数据表
- 分析用户行为 → 连接用户行为数据表
- 分析商品价格 → 连接商品价格数据表
```

### 2. 使用字段和可视化对象创建报表

**不推荐**（不使用字段和可视化对象）：
```text
随意拖拽字段，不区分字段类型
```

**推荐**（使用字段和可视化对象创建报表）：
```text
- 将类别字段拖到轴 bucket
- 将度量字段拖到值 bucket
- 根据分析需求，选择合适的可视化对象类型
```

### 3. 创建仪表板组合多个报表页面

**不推荐**（只创建报表，不创建仪表板）：
```text
只创建报表，不固定到仪表板
```

**推荐**（创建仪表板组合多个报表页面）：
```text
- 创建多个报表页面，分析不同维度
- 创建仪表板，将报表可视化对象固定到仪表板
- 添加筛选器、钻取、工具提示等交互操作
```

### 4. 结合业务场景解释可视化结果

**不推荐**（只展示可视化图表）：
```text
只展示可视化图表，不解释分析结果
```

**推荐**（结合业务场景解释可视化结果）：
```text
- 展示可视化图表
- 解释图表含义，分析业务洞察
- 根据分析结果，提出业务建议
```

## 常见错误

### 1. 盲目连接数据源

**错误示例**：
```text
无论什么分析需求，都连接同一个数据源
```

**正确做法**：
```text
根据分析需求，选择合适的数据源
```

### 2. 不使用字段和可视化对象创建报表

**错误示例**：
```text
随意拖拽字段，不区分字段类型
```

**正确做法**：
```text
使用字段和可视化对象创建报表
```

### 3. 只创建报表，不创建仪表板

**错误示例**：
```text
只创建报表，不固定到仪表板
```

**正确做法**：
```text
创建仪表板组合多个报表页面
```

### 4. 不结合业务场景解释可视化结果

**错误示例**：
```text
只展示可视化图表，不解释分析结果
```

**正确做法**：
```text
结合业务场景解释可视化结果
```

### 5. 仪表板布局混乱

**错误示例**：
```text
仪表板布局混乱，磁贴重叠，大小不一
```

**正确做法**：
```text
合理布局仪表板，调整磁贴大小和位置
```

## 总结

Power BI基础是数据分析师进行数据可视化、制作专业报表的关键技能，关键要点包括：

1. **掌握数据连接**：数据连接、数据转换、数据建模、数据刷新
2. **掌握报表创建**：报表、字段、可视化对象、筛选器
3. **掌握可视化图表**：柱状图、折线图、饼图、散点图、地图、表格
4. **掌握仪表板**：仪表板、磁贴、仪表板操作、仪表板共享
5. **熟练应用Power BI基础**：电商销售数据分析、电商用户行为分析、电商商品价格分析
6. **注意最佳实践**：根据分析需求选择合适的数据源、使用字段和可视化对象创建报表、创建仪表板组合多个报表页面、结合业务场景解释可视化结果
7. **避免常见错误**：盲目连接数据源、不使用字段和可视化对象创建报表、只创建报表不创建仪表板、不结合业务场景解释可视化结果、仪表板布局混乱

Power BI基础是数据分析师的核心技能，需要在实践中不断积累经验。
