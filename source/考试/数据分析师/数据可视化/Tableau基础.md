# Tableau基础

## 定义

**Tableau**是主流数据可视化工具，通过**数据连接、工作表创建、可视化图表、仪表板**等功能，帮助用户进行数据分析和可视化。

对于数据分析师而言，掌握**Tableau基础**，是**进行数据可视化、制作专业报表**的关键技能。

---

## 核心概念

### 1. 数据连接

| 概念 | 说明 | 示例 |
|------|------|------|
| **数据连接** | 连接各种数据源 | 连接Excel、CSV、数据库等 |
| **数据提取** | 从数据源提取数据 | 创建数据提取文件(.hyper) |
| **数据刷新** | 刷新数据源数据 | 定时刷新或手动刷新 |
| **数据联接** | 合并多个数据表 | 内联接、左联接、右联接、全外联接 |

### 2. 工作表

| 概念 | 说明 | 示例 |
|------|------|------|
| **工作表** | 创建可视化图表的基本单位 | 创建工作表，添加维度和度量 |
| **维度** | 定性数据，用于分组和筛选 | 类别、地区、时间等 |
| **度量** | 定量数据，用于计算和聚合 | 销售额、利润、数量等 |
| **标记** | 控制标记卡的显示方式 | 颜色、大小、标签、工具提示等 |

### 3. 可视化图表

| 概念 | 说明 | 示例 |
|------|------|------|
| **条形图** | 比较各类别数值 | 不同品类销售额对比 |
| **折线图** | 显示数据随时间变化趋势 | 月度销售额趋势 |
| **饼图** | 显示各部分占总体比例 | 各品类销售额占比 |
| **散点图** | 显示两个变量之间的关系 | 销售额与利润关系 |
| **地图** | 显示地理数据 | 各省份销售额分布 |
| **热图** | 用颜色表示数据密度 | 各品类各月份销售热图 |

### 4. 仪表板

| 概念 | 说明 | 示例 |
|------|------|------|
| **仪表板** | 组合多个工作表和数据可视化 | 创建销售仪表板 |
| **仪表板操作** | 仪表板交互操作 | 筛选器、超链接、高亮等 |
| **仪表板布局** | 仪表板布局和格式 | 平铺、浮动、大小调整等 |
| **仪表板发布** | 发布和共享仪表板 | 发布到Tableau Server、Tableau Online等 |

## 详细内容

### 一、数据连接

#### 1.1 连接数据源

**连接Excel文件**：
1. 打开Tableau，点击"连接到数据"
2. 选择"Microsoft Excel"
3. 选择Excel文件，点击"打开"
4. 预览数据，点击"确定"

**连接CSV文件**：
1. 打开Tableau，点击"连接到数据"
2. 选择"文本文件"
3. 选择CSV文件，点击"打开"
4. 预览数据，设置分隔符等，点击"确定"

**连接数据库**：
1. 打开Tableau，点击"连接到数据"
2. 选择数据库类型（如MySQL、PostgreSQL等）
3. 输入服务器、端口、数据库、用户名、密码等
4. 点击"连接"，选择表，点击"确定"

#### 1.2 数据提取和刷新

**创建数据提取**：
1. 在数据连接界面，选择"数据提取"
2. 点击"提取"，选择保存位置，点击"保存"
3. 数据提取文件(.hyper)创建完成

**刷新数据提取**：
1. 右键点击数据源，选择"刷新数据提取"
2. 选择数据提取文件，点击"打开"
3. 数据提取刷新完成

#### 1.3 数据联接

**创建数据联接**：
1. 在数据连接界面，将两个表拖到画布上
2. 点击表之间的联接图标，选择联接类型
3. 设置联接条件，点击"确定"

**联接类型**：
- **内联接**：只保留两个表中匹配的行
- **左联接**：保留左表所有行，右表只保留匹配的行
- **右联接**：保留右表所有行，左表只保留匹配的行
- **全外联接**：保留两个表所有行

### 二、工作表创建

#### 2.1 创建工作表

**步骤**：
1. 点击"新建工作表"
2. 将维度拖到行或列功能区
3. 将度量拖到行或列功能区
4. 自动生成可视化图表

#### 2.2 使用维度和度量

**维度**：
- 拖到行或列功能区，用于分组和筛选
- 拖到标记卡的颜色、标签等，用于区分数据

**度量**：
- 拖到行或列功能区，用于计算和聚合
- 拖到标记卡的大小、标签等，用于表示数值大小

#### 2.3 设置标记卡

**标记卡选项**：
- **颜色**：设置标记颜色
- **大小**：设置标记大小
- **标签**：显示标记标签
- **工具提示**：设置鼠标悬停提示内容
- **形状**：设置标记形状（适用于散点图等）

---

### 三、可视化图表

#### 3.1 条形图

**创建条形图**：
1. 将维度（如"品类"）拖到行功能区
2. 将度量（如"销售额"）拖到列功能区
3. 自动生成条形图

**条形图类型**：
- **水平条形图**：维度在行，度量在列
- **垂直条形图**：维度在列，度量在行
- **堆叠条形图**：将另一个维度拖到颜色标记

#### 3.2 折线图

**创建折线图**：
1. 将时间维度（如"月份"）拖到列功能区
2. 将度量（如"销售额"）拖到行功能区
3. 自动生成折线图

**折线图类型**：
- **单线折线图**：一个度量
- **多线折线图**：将另一个维度拖到颜色标记

#### 3.3 饼图

**创建饼图**：
1. 将度量（如"销售额"）拖到标记卡的角度
2. 将维度（如"品类"）拖到标记卡的颜色
3. 自动生成饼图

#### 3.4 散点图

**创建散点图**：
1. 将度量1（如"销售额"）拖到列功能区
2. 将度量2（如"利润"）拖到行功能区
3. 将维度（如"品类"）拖到标记卡的颜色或标签
4. 自动生成散点图

#### 3.5 地图

**创建地图**：
1. 双击地理维度（如"国家"、"省份"、"城市"）
2. 自动生成地图
3. 将度量（如"销售额"）拖到标记卡的大小或颜色
4. 地图显示数据分布

#### 3.6 热图

**创建热图**：
1. 将维度1（如"品类"）拖到行功能区
2. 将维度2（如"月份"）拖到列功能区
3. 将度量（如"销售额"）拖到标记卡的颜色
4. 自动生成热图

---

### 四、仪表板

#### 4.1 创建仪表板

**步骤**：
1. 点击"新建仪表板"
2. 将工作表拖到仪表板画布上
3. 调整工作表大小和位置
4. 添加仪表板标题、文本、图像等

#### 4.2 仪表板操作

**筛选器**：
1. 在仪表板上添加筛选器
2. 设置筛选器类型和选项
3. 筛选器可以作用于多个工作表

**超链接**：
1. 在仪表板上添加超链接
2. 设置超链接目标和URL
3. 点击超链接跳转到目标

**高亮**：
1. 在仪表板上添加高亮操作
2. 设置高亮源和目标
3. 鼠标悬停时高亮相关数据

#### 4.3 仪表板布局

**平铺布局**：
- 工作表按顺序平铺在仪表板上
- 调整工作表大小时，其他工作表会自动调整

**浮动布局**：
- 工作表可以自由拖动和重叠
- 调整工作表大小时，其他工作表不会自动调整

#### 4.4 仪表板发布

**发布到Tableau Server**：
1. 点击"服务器" → "发布工作簿"
2. 输入Tableau Server地址、用户名、密码
3. 选择项目，点击"发布"

**发布到Tableau Online**：
1. 点击"服务器" → "发布工作簿"
2. 选择"Tableau Online"
3. 输入Tableau Online地址、用户名、密码
4. 选择项目，点击"发布"

**发布到Tableau Public**：
1. 点击"服务器" → "发布工作簿"
2. 选择"Tableau Public"
3. 输入Tableau Public用户名、密码
4. 点击"发布"

## 示例/应用场景

### 示例1：电商销售数据分析

**业务问题**：分析电商销售数据，制作销售仪表板。

**数据**：电商销售数据表（订单ID、商品ID、品类、销售额、销量、订单日期）

**分析**：

**Tableau操作**：
1. **连接数据**：连接电商销售数据Excel文件
2. **创建工作表**：
   - 各品类销售额条形图
   - 月度销售额折线图
   - 各品类销售额占比饼图
   - 销售额与销量散点图
3. **创建仪表板**：将以上工作表组合到仪表板
4. **添加筛选器**：添加日期筛选器、品类筛选器
5. **发布仪表板**：发布到Tableau Server

**洞察与建议**：
- 如果某品类销售额高，说明该品类受欢迎
- 可以针对高销售额品类制定营销策略
- 可以分析高销售额品类的特征，优化商品推荐

### 示例2：电商用户行为分析

**业务问题**：分析电商用户行为，制作用户行为仪表板。

**数据**：电商用户行为数据表（用户ID、用户类型、访问量、购买次数、注册日期）

**分析**：

**Tableau操作**：
1. **连接数据**：连接电商用户行为数据Excel文件
2. **创建工作表**：
   - 各用户类型访问量条形图
   - 月度访问量折线图
   - 各用户类型购买转化率条形图
   - 访问量与购买次数散点图
3. **创建仪表板**：将以上工作表组合到仪表板
4. **添加筛选器**：添加日期筛选器、用户类型筛选器
5. **发布仪表板**：发布到Tableau Server

**洞察与建议**：
- 如果某用户类型购买转化率高，说明该用户类型价值高
- 可以针对高转化率用户类型制定用户运营策略
- 可以分析低转化率用户类型的原因，优化产品或运营

### 示例3：电商商品价格分析

**业务问题**：分析电商商品价格，制作商品价格仪表板。

**数据**：电商商品价格数据表（商品ID、品类、价格、上架日期）

**分析**：

**Tableau操作**：
1. **连接数据**：连接电商商品价格数据Excel文件
2. **创建工作表**：
   - 各品类平均价格条形图
   - 各品类价格区间条形图
   - 各品类价格分布饼图
   - 价格与销量散点图
3. **创建仪表板**：将以上工作表组合到仪表板
4. **添加筛选器**：添加品类筛选器、价格区间筛选器
5. **发布仪表板**：发布到Tableau Server

**洞察与建议**：
- 如果某品类价格区间大，说明该品类价格差异大
- 可以针对价格差异大的品类制定统一的价格策略
- 可以分析价格差异的原因，优化产品定位

## 最佳实践

### 1. 根据分析需求，选择合适的数据源

**不推荐**（盲目连接数据源）：
```text
无论什么分析需求，都连接同一个数据源
```

**推荐**（根据分析需求，选择合适的数据源）：
```text
- 分析销售数据 → 连接销售数据表
- 分析用户行为 → 连接用户行为数据表
- 分析商品价格 → 连接商品价格数据表
```

### 2. 使用维度和度量创建可视化图表

**不推荐**（不使用维度和度量）：
```text
随意拖拽字段，不区分维度和度量
```

**推荐**（使用维度和度量创建可视化图表）：
```text
- 维度拖到行或列功能区，用于分组和筛选
- 度量拖到行或列功能区，用于计算和聚合
- 根据分析需求，选择合适的可视化图表类型
```

### 3. 创建仪表板组合多个工作表

**不推荐**（只创建工作表，不创建仪表板）：
```text
只创建工作表，不组合到仪表板
```

**推荐**（创建仪表板组合多个工作表）：
```text
- 创建多个工作表，分析不同维度
- 创建仪表板，组合多个工作表
- 添加筛选器、超链接、高亮等交互操作
```

### 4. 结合业务场景解释可视化结果

**不推荐**（只展示可视化图表）：
```text
只展示可视化图表，不解释分析结果
```

**推荐**（结合业务场景解释可视化结果）：
```text
- 展示可视化图表
- 解释图表含义，分析业务洞察
- 根据分析结果，提出业务建议
```

## 常见错误

### 1. 盲目连接数据源

**错误示例**：
```text
无论什么分析需求，都连接同一个数据源
```

**正确做法**：
```text
根据分析需求，选择合适的数据源
```

### 2. 不使用维度和度量创建可视化图表

**错误示例**：
```text
随意拖拽字段，不区分维度和度量
```

**正确做法**：
```text
使用维度和度量创建可视化图表
```

### 3. 只创建工作表，不创建仪表板

**错误示例**：
```text
只创建工作表，不组合到仪表板
```

**正确做法**：
```text
创建仪表板组合多个工作表
```

### 4. 不结合业务场景解释可视化结果

**错误示例**：
```text
只展示可视化图表，不解释分析结果
```

**正确做法**：
```text
结合业务场景解释可视化结果
```

### 5. 仪表板布局混乱

**错误示例**：
```text
仪表板布局混乱，工作表重叠，大小不一
```

**正确做法**：
```text
合理布局仪表板，调整工作表大小和位置
```

1. **掌握数据连接**：数据连接、数据提取、数据刷新、数据联接
2. **掌握工作表创建**：工作表、维度、度量、标记
3. **掌握可视化图表**：条形图、折线图、饼图、散点图、地图、热图
