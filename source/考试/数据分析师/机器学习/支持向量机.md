# 支持向量机

## 定义

**支持向量机（SVM）**是常用的监督学习算法，用于**分类和回归问题**。

对于数据分析师而言，掌握**支持向量机**，是**进行分类分析、回归分析、非线性分类**的关键技能。

---

## 核心概念

### 1. 支持向量机原理

| 概念 | 说明 | 示例 |
|------|------|------|
| **支持向量** | 距离超平面最近的样本点 | 距离决策边界最近的样本 |
| **超平面** | 用于分隔不同类别的平面 | 二维空间中的直线、三维空间中的平面 |
| **间隔** | 支持向量到超平面的距离 | 最大化间隔 |
| **核函数** | 用于将非线性问题映射到高维空间 | 线性核、多项式核、径向基核 |

### 2. 支持向量机类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **线性支持向量机** | 用于线性可分问题 | 二维空间中线性可分的数据 |
| **非线性支持向量机** | 用于非线性可分问题 | 二维空间中非线性可分的数据 |
| **支持向量回归** | 用于回归问题 | 预测连续数值 |

| **1. 收集数据** | 收集带标签的数据 | Excel、SQL、Python |

| **3. 选择核函数** | 选择合适的核函数 | 业务理解、统计知识 |

## 详细内容

### 一、支持向量机原理

#### 1.1 线性支持向量机

**线性支持向量机**用于线性可分问题，目标是找到一个超平面，使得两类数据之间的间隔最大。

**数学表达**：
```
超平面：w^T x + b = 0
间隔：2 / ||w||
目标：最小化 ||w||^2
约束条件：y_i (w^T x_i + b) >= 1
```

#### 1.2 非线性支持向量机

**非线性支持向量机**用于非线性可分问题，通过核函数将原始数据映射到高维空间，使其在高维空间中线性可分。

**核函数**：
- 线性核：K(x, y) = x^T y
- 多项式核：K(x, y) = (x^T y + c)^d
- 径向基核（RBF）：K(x, y) = exp(-gamma ||x - y||^2)

#### 1.3 支持向量回归

**支持向量回归（SVR）**用于回归问题，目标是找到一个函数，使得预测值与真实值之间的误差在一个阈值范围内。

**数学表达**：
```
目标：最小化 (1/2) w^T w + C Σ (ξ_i + ξ_i^*)
约束条件：|y_i - (w^T x_i + b)| <= epsilon + ξ_i
```

### 二、使用Python训练支持向量机

#### 2.1 训练分类模型

**Python代码（线性核）**：
```python
from sklearn.svm import SVC

# 创建支持向量机分类模型（线性核）
model = SVC(kernel='linear')

# 训练模型
model.fit(X_train, y_train)
```

**Python代码（径向基核）**：
```python
from sklearn.svm import SVC

# 创建支持向量机分类模型（径向基核）
model = SVC(kernel='rbf', gamma='scale')

# 训练模型
model.fit(X_train, y_train)
```

#### 2.2 训练回归模型

**Python代码**：
```python
from sklearn.svm import SVR

# 创建支持向量回归模型
model = SVR(kernel='rbf', gamma='scale')

# 训练模型
model.fit(X_train, y_train)
```

### 三、评估模型

#### 3.1 评估分类模型

**Python代码**：
```python
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, confusion_matrix, classification_report

# 预测测试集
y_pred = model.predict(X_test)

# 计算准确率
accuracy = accuracy_score(y_test, y_pred)
print("准确率：", accuracy)

# 计算精确率
precision = precision_score(y_test, y_pred, average='weighted')
print("精确率：", precision)

# 计算召回率
recall = recall_score(y_test, y_pred, average='weighted')
print("召回率：", recall)

# 计算F1分数
f1 = f1_score(y_test, y_pred, average='weighted')
print("F1分数：", f1)

# 计算混淆矩阵
conf_matrix = confusion_matrix(y_test, y_pred)
print("混淆矩阵：\n", conf_matrix)

# 分类报告
class_report = classification_report(y_test, y_pred)
print("分类报告：\n", class_report)
```

#### 3.2 评估回归模型

**Python代码**：
```python
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

# 预测测试集
y_pred = model.predict(X_test)

# 计算均方误差
mse = mean_squared_error(y_test, y_pred)
print("均方误差：", mse)

# 计算均方根误差
rmse = mean_squared_error(y_test, y_pred, squared=False)
print("均方根误差：", rmse)

# 计算平均绝对误差
mae = mean_absolute_error(y_test, y_pred)
print("平均绝对误差：", mae)

# 计算R2分数
r2 = r2_score(y_test, y_pred)
print("R2分数：", r2)
```

### 四、调参优化模型

#### 4.1 调参分类模型

**Python代码**：
```python
from sklearn.model_selection import GridSearchCV

# 定义参数网格
param_grid = {

    'gamma': ['scale', 'auto', 0.1, 0.01, 0.001],

# 查看最佳参数
print("最佳参数：", grid_search.best_params_)
```

## 示例/应用场景

### 示例1：图像分类

**业务问题**：预测图像是否为猫。

**数据**：图像数据（特征：像素值，标签：是否为猫）

**分析**：

**Python代码**：
```python
from sklearn.model_selection import train_test_split
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score, classification_report

# 读取数据
df = pd.read_csv('image_data.csv')

# 分割数据集
X = df.drop('is_cat', axis=1)
y = df['is_cat']
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

# 创建支持向量机分类模型（径向基核）
model = SVC(kernel='rbf', gamma='scale')

# 训练模型
model.fit(X_train, y_train)

# 预测测试集
y_pred = model.predict(X_test)

# 计算准确率
accuracy = accuracy_score(y_test, y_pred)
print("准确率：", accuracy)

# 分类报告
class_report = classification_report(y_test, y_pred)
print("分类报告：\n", class_report)
```

**洞察与建议**：
- 如果准确率高，说明模型效果好
- 可以应用模型预测新图像是否为猫

### 示例2：文本分类

**业务问题**：预测文本是否为垃圾邮件。

**数据**：文本数据（特征：TF-IDF值，标签：是否为垃圾邮件）

**分析**：

**Python代码**：
```python
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score, classification_report

# 读取数据
df = pd.read_csv('text_data.csv')

# 分割数据集
X = df['text']
y = df['is_spam']
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

# 特征提取
vectorizer = TfidfVectorizer()

X_test = vectorizer.transform(X_test)

# 创建支持向量机分类模型（线性核）
model = SVC(kernel='linear')

# 训练模型
model.fit(X_train, y_train)

# 预测测试集
y_pred = model.predict(X_test)

# 计算准确率
accuracy = accuracy_score(y_test, y_pred)
print("准确率：", accuracy)

# 分类报告
class_report = classification_report(y_test, y_pred)
print("分类报告：\n", class_report)
```

**洞察与建议**：
- 如果准确率高，说明模型效果好
- 可以应用模型预测新文本是否为垃圾邮件

## 最佳实践

### 1. 确保数据质量

**不推荐**（使用低质量数据）：
```text
使用缺失值多、异常值多、重复值多的数据训练模型
```

**推荐**（确保数据质量）：
```text
数据清洗：处理缺失值、异常值、重复值
数据转换：将分类变量转换为哑变量，将连续变量离散化
数据分割：将数据集分割为训练集和测试集
特征缩放：支持向量机对特征缩放敏感，需要进行标准化
```

### 2. 选择合适的核函数

**不推荐**（盲目使用一种核函数）：
```text
无论什么业务场景，都使用相同的核函数
```

**推荐**（根据业务场景，选择合适的核函数）：
```text
- 线性可分问题 → 线性核
- 非线性可分问题 → 径向基核（RBF）
- 多项式问题 → 多项式核
```

### 3. 评估模型效果

**不推荐**（不评估模型效果）：
```text
训练模型后，不评估模型效果，直接应用
```

**推荐**（评估模型效果）：
```text
- 分类问题 → 准确率、精确率、召回率、F1分数、混淆矩阵、分类报告
- 回归问题 → 均方误差、均方根误差、平均绝对误差、R2分数
```

### 4. 调参优化模型

**不推荐**（使用默认参数）：
```text
使用模型默认参数，不调参
```

**推荐**（调参优化模型）：
```text
- 使用网格搜索（GridSearchCV）调参
- 使用随机搜索（RandomSearchCV）调参
- 使用交叉验证（Cross Validation）评估调参效果
```

## 常见错误

### 1. 使用低质量数据训练模型

**错误示例**：
```text
使用缺失值多、异常值多、重复值多的数据训练模型
```

**正确做法**：
```text
数据清洗：处理缺失值、异常值、重复值
数据转换：将分类变量转换为哑变量，将连续变量离散化
数据分割：将数据集分割为训练集和测试集
特征缩放：支持向量机对特征缩放敏感，需要进行标准化
```

### 2. 盲目使用一种核函数

**错误示例**：
```text
无论什么业务场景，都使用相同的核函数
```

**正确做法**：
```text
根据业务场景，选择合适的核函数：
- 线性可分问题 → 线性核
- 非线性可分问题 → 径向基核（RBF）
- 多项式问题 → 多项式核
```

### 3. 不评估模型效果

**错误示例**：
```text
训练模型后，不评估模型效果，直接应用
```

**正确做法**：
```text
评估模型效果：
- 分类问题 → 准确率、精确率、召回率、F1分数、混淆矩阵、分类报告
- 回归问题 → 均方误差、均方根误差、平均绝对误差、R2分数
```

### 4. 使用默认参数

**错误示例**：
```python
# 使用默认参数
model = SVC()
```

**正确做法**：
```python
# 调参优化模型
from sklearn.model_selection import GridSearchCV
parameters = {'C': [0.1, 1, 10, 100], 'gamma': ['scale', 'auto', 0.1, 0.01, 0.001], 'kernel': ['rbf', 'poly', 'sigmoid']}
model = GridSearchCV(SVC(), parameters)
```

### 5. 不进行特征缩放

**错误示例**：
```python
# 不进行特征缩放
model = SVC()
model.fit(X_train, y_train)
```

**正确做法**：
```python
# 进行特征缩放
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)
model = SVC()
model.fit(X_train, y_train)
```
