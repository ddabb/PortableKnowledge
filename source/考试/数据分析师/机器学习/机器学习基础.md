# 机器学习基础

## 定义

**机器学习**是数据分析的高级技能，通过**算法让计算机从数据中学习规律**。

对于数据分析师而言，掌握**机器学习基础**，是**进行预测分析、分类分析、聚类分析**的关键技能。

---

## 核心概念

### 1. 机器学习类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **监督学习** | 使用带标签的数据训练模型 | 分类、回归 |
| **无监督学习** | 使用不带标签的数据训练模型 | 聚类、降维 |
| **半监督学习** | 使用部分带标签、部分不带标签的数据训练模型 | 半监督分类 |
| **强化学习** | 通过与环境交互学习最优策略 | 游戏AI、机器人控制 |

### 2. 机器学习步骤

| 步骤 | 说明 | 工具 |
|------|------|------|
| **1. 收集数据** | 收集用于机器学习的数据 | Excel、SQL、Python |
| **2. 处理数据** | 清洗、转换、整合数据 | Excel、SQL、Python |
| **3. 选择模型** | 选择合适的机器学习模型 | 业务理解、统计知识 |
| **4. 训练模型** | 使用训练数据训练模型 | Python（Scikit-learn、TensorFlow、PyTorch） |
| **5. 评估模型** | 使用测试数据评估模型 | Python（Scikit-learn、TensorFlow、PyTorch） |
| **6. 应用模型** | 将模型应用于实际业务场景 | 所有工具 |

### 3. 机器学习应用场景

| 场景 | 说明 | 示例 |
|------|------|------|
| **分类问题** | 预测类别标签 | 垃圾邮件分类、客户流失预测 |
| **回归问题** | 预测连续数值 | 房价预测、销售额预测 |
| **聚类问题** | 将相似数据分组 | 用户分群、商品分群 |
| **降维问题** | 减少特征维度 | 特征选择、特征提取 |

### 二、处理数据

#### 2.1 数据清洗

**Python代码**：
```python
# 处理缺失值
df = df.fillna(method='bfill')

# 处理异常值
Q1 = df['column'].quantile(0.25)
Q3 = df['column'].quantile(0.75)
IQR = Q3 - Q1
df = df[~((df['column'] < (Q1 - 1.5 * IQR)) | (df['column'] > (Q3 + 1.5 * IQR)))]

# 处理重复值
df = df.drop_duplicates()
```

#### 2.2 数据转换

**Python代码**：
```python
# 将分类变量转换为哑变量
df = pd.get_dummies(df, columns=['category'], prefix=['category'])

# 将连续变量离散化
df['age_group'] = pd.cut(df['age'], bins=[0, 18, 30, 50, 100], labels=['0-18', '19-30', '31-50', '51+'])
```

#### 2.3 数据分割

**Python代码**：
```python
from sklearn.model_selection import train_test_split

# 分割数据集为训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
```

### 三、选择模型

#### 3.1 分类模型

| 模型 | 说明 | 适用场景 |
|------|------|----------|
| **逻辑回归** | 用于二分类问题 | 垃圾邮件分类、客户流失预测 |
| **决策树** | 用于分类和回归问题 | 客户分群、风险评级 |
| **随机森林** | 集成学习方法，用于分类和回归问题 | 客户分群、风险评级 |
| **支持向量机** | 用于分类和回归问题 | 图像分类、文本分类 |
| **朴素贝叶斯** | 用于分类问题 | 垃圾邮件分类、文本分类 |

#### 3.2 回归模型

| 模型 | 说明 | 适用场景 |
|------|------|----------|
| **线性回归** | 用于回归问题 | 房价预测、销售额预测 |
| **多项式回归** | 用于回归问题 | 非线性关系预测 |
| **岭回归** | 用于回归问题，处理多重共线性 | 房价预测、销售额预测 |
| **Lasso回归** | 用于回归问题，进行特征选择 | 房价预测、销售额预测 |

#### 3.3 聚类模型

| 模型 | 说明 | 适用场景 |
|------|------|----------|
| **K-means聚类** | 用于聚类问题 | 用户分群、商品分群 |
| **层次聚类** | 用于聚类问题 | 用户分群、商品分群 |
| **DBSCAN聚类** | 用于聚类问题，能处理噪声点 | 用户分群、商品分群 |

### 五、评估模型

#### 5.1 评估分类模型

**Python代码**：
```python
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

# 预测测试集
y_pred = model.predict(X_test)

# 计算准确率
accuracy = accuracy_score(y_test, y_pred)
print("准确率：", accuracy)

# 计算精确率
precision = precision_score(y_test, y_pred, average='weighted')
print("精确率：", precision)

# 计算召回率
recall = recall_score(y_test, y_pred, average='weighted')
print("召回率：", recall)

# 计算F1分数
f1 = f1_score(y_test, y_pred, average='weighted')
print("F1分数：", f1)
```

#### 5.2 评估回归模型

**Python代码**：
```python
from sklearn.metrics import mean_squared_error, r2_score

# 预测测试集
y_pred = model.predict(X_test)

# 计算均方误差
mse = mean_squared_error(y_test, y_pred)
print("均方误差：", mse)

# 计算R2分数
r2 = r2_score(y_test, y_pred)
print("R2分数：", r2)
```

#### 5.3 评估聚类模型

**Python代码**：
```python
from sklearn.metrics import silhouette_score

# 计算轮廓系数
silhouette = silhouette_score(X, model.labels_)
print("轮廓系数：", silhouette)
```

## 示例/应用场景

### 示例1：垃圾邮件分类

**业务问题**：预测邮件是否为垃圾邮件。

**数据**：邮件数据（特征：邮件内容、发件人、主题等，标签：是否为垃圾邮件）

**分析**：

**Python代码**：
```python
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score

# 读取数据
df = pd.read_csv('email_data.csv')

# 分割数据集
X = df['email_content']
y = df['is_spam']
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

# 特征提取
vectorizer = TfidfVectorizer()
X_train = vectorizer.fit_transform(X_train)
X_test = vectorizer.transform(X_test)

# 创建逻辑回归模型
model = LogisticRegression()

# 训练模型
model.fit(X_train, y_train)

# 预测测试集
y_pred = model.predict(X_test)

# 计算准确率
accuracy = accuracy_score(y_test, y_pred)
print("准确率：", accuracy)
```

**洞察与建议**：
- 如果准确率高，说明模型效果好
- 可以应用模型预测新邮件是否为垃圾邮件

### 示例2：房价预测

**业务问题**：预测房价。

**数据**：房价数据（特征：面积、卧室数量、卫生间数量等，标签：房价）

**分析**：

**Python代码**：
```python
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# 读取数据
df = pd.read_csv('house_price_data.csv')

# 分割数据集
X = df[['area', 'bedrooms', 'bathrooms']]
y = df['price']
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

# 创建线性回归模型
model = LinearRegression()

# 训练模型
model.fit(X_train, y_train)

# 预测测试集
y_pred = model.predict(X_test)

# 计算均方误差
mse = mean_squared_error(y_test, y_pred)
print("均方误差：", mse)

# 计算R2分数
r2 = r2_score(y_test, y_pred)
print("R2分数：", r2)
```

**洞察与建议**：
- 如果R2分数高，说明模型效果好
- 可以应用模型预测新房价

### 示例3：用户分群

**业务问题**：将用户分为不同群体。

**数据**：用户数据（特征：年龄、性别、地域、消费金额等）

**分析**：

**Python代码**：
```python
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

# 读取数据
df = pd.read_csv('user_data.csv')

# 选择特征
X = df[['age', 'annual_income', 'spending_score']]

# 创建K-means聚类模型
model = KMeans(n_clusters=5, random_state=0)

# 训练模型
model.fit(X)

# 添加聚类结果到原数据
df['cluster'] = model.labels_

# 查看各聚类的特征
cluster_features = df.groupby('cluster').mean().reset_index()
print(cluster_features)

# 可视化聚类结果
plt.scatter(X[model.labels_ == 0, 0], X[model.labels_ == 0, 1], s=50, c='red', label='Cluster 1')
plt.scatter(X[model.labels_ == 1, 0], X[model.labels_ == 1, 1], s=50, c='blue', label='Cluster 2')
plt.scatter(X[model.labels_ == 2, 0], X[model.labels_ == 2, 1], s=50, c='green', label='Cluster 3')
plt.scatter(X[model.labels_ == 3, 0], X[model.labels_ == 3, 1], s=50, c='yellow', label='Cluster 4')
plt.scatter(X[model.labels_ == 4, 0], X[model.labels_ == 4, 1], s=50, c='purple', label='Cluster 5')
plt.scatter(model.cluster_centers_[:, 0], model.cluster_centers_[:, 1], s=200, c='black', label='Centroids')
plt.title('用户分群')
plt.xlabel('年龄')
plt.ylabel('年收入')
plt.legend()
plt.show()
```

**洞察与建议**：
- 如果各聚类特征明显，说明聚类效果好
- 可以针对不同聚类制定不同的营销策略

## 最佳实践

### 1. 确保数据质量

**不推荐**（使用低质量数据）：
```text
使用缺失值多、异常值多、重复值多的数据训练模型
```

**推荐**（确保数据质量）：
```text
数据清洗：处理缺失值、异常值、重复值
数据转换：将分类变量转换为哑变量，将连续变量离散化
数据分割：将数据集分割为训练集和测试集
```

### 2. 选择合适的模型

**不推荐**（盲目使用一种模型）：
```text
无论什么业务场景，都使用相同的模型
```

**推荐**（根据业务场景，选择合适的模型）：
```text
- 分类问题 → 逻辑回归、决策树、随机森林、支持向量机、朴素贝叶斯
- 回归问题 → 线性回归、多项式回归、岭回归、Lasso回归
- 聚类问题 → K-means聚类、层次聚类、DBSCAN聚类
```

### 3. 评估模型效果

**不推荐**（不评估模型效果）：
```text
训练模型后，不评估模型效果，直接应用
```

**推荐**（评估模型效果）：
```text
- 分类问题 → 准确率、精确率、召回率、F1分数
- 回归问题 → 均方误差、R2分数
- 聚类问题 → 轮廓系数
```

### 4. 调参优化模型

**不推荐**（使用默认参数）：
```text
使用模型默认参数，不调参
```

**推荐**（调参优化模型）：
```text
- 使用网格搜索（Grid Search）调参
- 使用随机搜索（Random Search）调参
- 使用交叉验证（Cross Validation）评估调参效果
```

## 常见错误

### 1. 使用低质量数据训练模型

**错误示例**：
```text
使用缺失值多、异常值多、重复值多的数据训练模型
```

**正确做法**：
```text
数据清洗：处理缺失值、异常值、重复值
数据转换：将分类变量转换为哑变量，将连续变量离散化
数据分割：将数据集分割为训练集和测试集
```

### 2. 盲目使用一种模型

**错误示例**：
```text
无论什么业务场景，都使用相同的模型
```

**正确做法**：
```text
根据业务场景，选择合适的模型
```

### 3. 不评估模型效果

**错误示例**：
```text
训练模型后，不评估模型效果，直接应用
```

**正确做法**：
```text
评估模型效果：
- 分类问题 → 准确率、精确率、召回率、F1分数
- 回归问题 → 均方误差、R2分数
- 聚类问题 → 轮廓系数
```

### 4. 使用默认参数

**错误示例**：
```python
# 使用默认参数
model = LogisticRegression()
```

**正确做法**：
```python
# 调参优化模型
from sklearn.model_selection import GridSearchCV
parameters = {'C': [0.1, 1, 10, 100]}
model = GridSearchCV(LogisticRegression(), parameters)
```

### 5. 过拟合

**错误示例**：
```python
# 过拟合：模型在训练集上表现很好，但在测试集上表现很差
model = DecisionTreeClassifier(max_depth=None)
```

**正确做法**：
```python
# 避免过拟合：限制模型复杂度
model = DecisionTreeClassifier(max_depth=5)
```
