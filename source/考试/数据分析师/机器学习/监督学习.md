# 监督学习

## 定义

**监督学习**是机器学习的重要分支，使用**带标签的数据训练模型**。

对于数据分析师而言，掌握**监督学习**，是**进行分类分析、回归分析、预测分析**的关键技能。

### 二、处理数据

#### 2.1 数据清洗

**Python代码**：
```python
# 处理缺失值
df = df.fillna(method='bfill')

# 处理异常值
Q1 = df['column'].quantile(0.25)
Q3 = df['column'].quantile(0.75)
IQR = Q3 - Q1
df = df[~((df['column'] < (Q1 - 1.5 * IQR)) | (df['column'] > (Q3 + 1.5 * IQR)))]

# 处理重复值
df = df.drop_duplicates()
```

#### 2.2 数据转换

**Python代码**：
```python
# 将分类变量转换为哑变量
df = pd.get_dummies(df, columns=['category'], prefix=['category'])

# 将连续变量离散化
df['age_group'] = pd.cut(df['age'], bins=[0, 18, 30, 50, 100], labels=['0-18', '19-30', '31-50', '51+'])
```

#### 2.3 数据分割

**Python代码**：
```python
from sklearn.model_selection import train_test_split

# 分割数据集为训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
```

### 三、选择模型

#### 3.1 分类模型

| 模型 | 说明 | 适用场景 |
|------|------|----------|
| **逻辑回归** | 用于二分类问题 | 垃圾邮件分类、客户流失预测 |
| **决策树** | 用于分类和回归问题 | 客户分群、风险评级 |
| **随机森林** | 集成学习方法，用于分类和回归问题 | 客户分群、风险评级 |
| **支持向量机** | 用于分类和回归问题 | 图像分类、文本分类 |
| **朴素贝叶斯** | 用于分类问题 | 垃圾邮件分类、文本分类 |
| **K近邻** | 用于分类和回归问题 | 图像分类、文本分类 |
| **梯度提升树** | 集成学习方法，用于分类和回归问题 | 客户分群、风险评级 |

#### 3.2 回归模型

| 模型 | 说明 | 适用场景 |
|------|------|----------|
| **线性回归** | 用于回归问题 | 房价预测、销售额预测 |
| **多项式回归** | 用于回归问题 | 非线性关系预测 |
| **岭回归** | 用于回归问题，处理多重共线性 | 房价预测、销售额预测 |
| **Lasso回归** | 用于回归问题，进行特征选择 | 房价预测、销售额预测 |
| **弹性网络回归** | 用于回归问题，结合岭回归和Lasso回归 | 房价预测、销售额预测 |
| **支持向量回归** | 用于回归问题 | 股价预测、销量预测 |

### 五、评估模型

#### 5.1 评估分类模型

**Python代码**：
```python
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, confusion_matrix, classification_report

# 预测测试集
y_pred = model.predict(X_test)

# 计算准确率
accuracy = accuracy_score(y_test, y_pred)
print("准确率：", accuracy)

# 计算精确率
precision = precision_score(y_test, y_pred, average='weighted')
print("精确率：", precision)

# 计算召回率
recall = recall_score(y_test, y_pred, average='weighted')
print("召回率：", recall)

# 计算F1分数
f1 = f1_score(y_test, y_pred, average='weighted')
print("F1分数：", f1)

# 计算混淆矩阵
conf_matrix = confusion_matrix(y_test, y_pred)
print("混淆矩阵：\n", conf_matrix)

# 分类报告
class_report = classification_report(y_test, y_pred)
print("分类报告：\n", class_report)
```

#### 5.2 评估回归模型

**Python代码**：
```python
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

# 预测测试集
y_pred = model.predict(X_test)

# 计算均方误差
mse = mean_squared_error(y_test, y_pred)
print("均方误差：", mse)

# 计算均方根误差
rmse = mean_squared_error(y_test, y_pred, squared=False)
print("均方根误差：", rmse)

# 计算平均绝对误差
mae = mean_absolute_error(y_test, y_pred)
print("平均绝对误差：", mae)

# 计算R2分数
r2 = r2_score(y_test, y_pred)
print("R2分数：", r2)
```

## 示例/应用场景

### 示例1：垃圾邮件分类

**业务问题**：预测邮件是否为垃圾邮件。

**数据**：邮件数据（特征：邮件内容、发件人、主题等，标签：是否为垃圾邮件）

**分析**：

**Python代码**：
```python
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, classification_report

# 读取数据
df = pd.read_csv('email_data.csv')

# 分割数据集
X = df['email_content']
y = df['is_spam']
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

# 特征提取
vectorizer = TfidfVectorizer()
X_train = vectorizer.fit_transform(X_train)
X_test = vectorizer.transform(X_test)

# 创建逻辑回归模型
model = LogisticRegression()

# 训练模型
model.fit(X_train, y_train)

# 预测测试集
y_pred = model.predict(X_test)

# 计算准确率
accuracy = accuracy_score(y_test, y_pred)
print("准确率：", accuracy)

# 分类报告
class_report = classification_report(y_test, y_pred)
print("分类报告：\n", class_report)
```

**洞察与建议**：
- 如果准确率高，说明模型效果好
- 可以应用模型预测新邮件是否为垃圾邮件

## 最佳实践

### 1. 确保数据质量

**不推荐**（使用低质量数据）：
```text
使用缺失值多、异常值多、重复值多的数据训练模型
```

**推荐**（确保数据质量）：
```text
数据清洗：处理缺失值、异常值、重复值
数据转换：将分类变量转换为哑变量，将连续变量离散化
数据分割：将数据集分割为训练集和测试集
```

### 2. 选择合适的模型

**不推荐**（盲目使用一种模型）：
```text
无论什么业务场景，都使用相同的模型
```

**推荐**（根据业务场景，选择合适的模型）：
```text
- 分类问题 → 逻辑回归、决策树、随机森林、支持向量机、朴素贝叶斯、K近邻、梯度提升树
- 回归问题 → 线性回归、多项式回归、岭回归、Lasso回归、弹性网络回归、支持向量回归
```

### 3. 评估模型效果

**不推荐**（不评估模型效果）：
```text
训练模型后，不评估模型效果，直接应用
```

**推荐**（评估模型效果）：
```text
- 分类问题 → 准确率、精确率、召回率、F1分数、混淆矩阵、分类报告
- 回归问题 → 均方误差、均方根误差、平均绝对误差、R2分数
```

### 4. 调参优化模型

**不推荐**（使用默认参数）：
```text
使用模型默认参数，不调参
```

**推荐**（调参优化模型）：
```text
- 使用网格搜索（GridSearchCV）调参
- 使用随机搜索（RandomSearchCV）调参
- 使用交叉验证（Cross Validation）评估调参效果
```

## 常见错误

### 1. 使用低质量数据训练模型

**错误示例**：
```text
使用缺失值多、异常值多、重复值多的数据训练模型
```

**正确做法**：
```text
数据清洗：处理缺失值、异常值、重复值
数据转换：将分类变量转换为哑变量，将连续变量离散化
数据分割：将数据集分割为训练集和测试集
```

### 2. 盲目使用一种模型

**错误示例**：
```text
无论什么业务场景，都使用相同的模型
```

**正确做法**：
```text
根据业务场景，选择合适的模型
```

### 3. 不评估模型效果

**错误示例**：
```text
训练模型后，不评估模型效果，直接应用
```

**正确做法**：
```text
评估模型效果：
- 分类问题 → 准确率、精确率、召回率、F1分数、混淆矩阵、分类报告
- 回归问题 → 均方误差、均方根误差、平均绝对误差、R2分数
```

### 4. 使用默认参数

**错误示例**：
```python
# 使用默认参数
model = LogisticRegression()
```

**正确做法**：
```python
# 调参优化模型
from sklearn.model_selection import GridSearchCV
parameters = {'C': [0.1, 1, 10, 100]}
model = GridSearchCV(LogisticRegression(), parameters)
```

### 5. 过拟合

**错误示例**：
```python
# 过拟合：模型在训练集上表现很好，但在测试集上表现很差
model = DecisionTreeClassifier(max_depth=None)
```

**正确做法**：
```python
# 避免过拟合：限制模型复杂度
model = DecisionTreeClassifier(max_depth=5)
```
