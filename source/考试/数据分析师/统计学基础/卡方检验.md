# 卡方检验

## 定义

卡方检验（Chi-Square Test）是**用于检验两个分类变量是否独立**，或**检验观测频数与期望频数是否有显著差异**的统计方法。

对于数据分析师而言，卡方检验是处理**分类数据**的核心工具。

---

## 核心概念

### 1. 卡方检验的类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **卡方独立性检验（Chi-Square Test of Independence）** | 检验两个分类变量是否独立 | 性别与购买决策是否独立？ |
| **卡方拟合优度检验（Chi-Square Goodness of Fit Test）** | 检验观测频数与期望频数是否有显著差异 | 用户偏好是否符合均匀分布？ |
| **卡方齐性检验（Chi-Square Test of Homogeneity）** | 检验多个总体的分布是否相同 | 三个渠道的用户转化率是否相同？ |

### 2. 卡方统计量

**公式**：

```
χ² = Σ [(观测频数 - 期望频数)² / 期望频数]
```

**解释**：
- 如果χ²值很大，说明观测频数与期望频数差异很大，拒绝原假设
- 如果χ²值很小，说明观测频数与期望频数差异很小，不拒绝原假设

### 3. 卡方检验的步骤

```
1. 提出原假设（H0）和备择假设（H1）
   H0: 两个分类变量独立（或无显著差异）
   H1: 两个分类变量不独立（或有显著差异）
2. 计算卡方统计量（χ²）
3. 确定自由度（df）
4. 确定显著性水平（α）
5. 计算P值
6. 做出统计决策（拒绝或不拒绝H0）
```

### 4. 卡方检验的假设条件

1. **独立性**：每个观测值之间相互独立
2. **样本量**：每个单元格的期望频数 ≥ 5（如果 < 5，需要使用Fisher精确检验）
3. **分类变量**：两个变量都是分类变量（名义变量或有序变量）

## 详细内容

### 一、卡方独立性检验（Chi-Square Test of Independence）

#### 1.1 原理

**目标**：检验两个分类变量是否独立

**示例**：
- 变量1：性别（男、女）
- 变量2：购买决策（购买、不购买）
- 目标：检验性别与购买决策是否独立（即性别是否影响购买决策）

#### 1.2 计算步骤

**Step 1: 建立列联表（Contingency Table）**

| | 购买 | 不购买 | 合计 |
|---|------|--------|------|
| 男 | 40 | 60 | 100 |
| 女 | 60 | 40 | 100 |
| 合计 | 100 | 100 | 200 |

**Step 2: 计算期望频数**

```
期望频数 = (行合计 × 列合计) / 总合计
```

例如：
- 男性购买的期望频数 = (100 × 100) / 200 = 50
- 男性不购买的期望频数 = (100 × 100) / 200 = 50
- 女性购买的期望频数 = (100 × 100) / 200 = 50
- 女性不购买的期望频数 = (100 × 100) / 200 = 50

**Step 3: 计算卡方统计量**

```
χ² = Σ [(观测频数 - 期望频数)² / 期望频数]
   = [(40-50)²/50] + [(60-50)²/50] + [(60-50)²/50] + [(40-50)²/50]
   = 2 + 2 + 2 + 2
   = 8
```

**Step 4: 确定自由度**

```
df = (行数 - 1) × (列数 - 1)
   = (2 - 1) × (2 - 1)
   = 1
```

**Step 5: 计算P值并做出决策**

- 如果P值 ≤ α，则拒绝原假设（两个分类变量不独立）
- 如果P值 > α，则不拒绝原假设（没有足够证据表明两个分类变量不独立）

#### 1.3 Python示例

```python
import scipy.stats as stats
import numpy as np

# 列联表
# 行：性别（男、女）
# 列：购买决策（购买、不购买）
observed = np.array([[40, 60],
                     [60, 40]])

# 卡方独立性检验
chi2_stat, p_value, dof, expected = stats.chi2_contingency(observed)

print(f'卡方统计量: {chi2_stat:.4f}')
print(f'P值: {p_value:.4f}')
print(f'自由度: {dof}')
print(f'期望频数:\n{expected}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：性别与购买决策不独立（性别影响购买决策）')
else:
    print('不拒绝原假设：没有足够证据表明性别与购买决策不独立')
```

### 二、卡方拟合优度检验（Chi-Square Goodness of Fit Test）

#### 2.1 原理

**目标**：检验观测频数与期望频数是否有显著差异

**示例**：
- 变量：用户偏好（产品A、产品B、产品C）
- 目标：检验用户偏好是否符合均匀分布（即33.3%的用户偏好产品A，33.3%偏好产品B，33.3%偏好产品C）

#### 2.2 计算步骤

**Step 1: 提出假设**

```
H0: 观测频数与期望频数无显著差异（用户偏好符合均匀分布）
H1: 观测频数与期望频数有显著差异（用户偏好不符合均匀分布）
```

**Step 2: 计算期望频数**

```
期望频数 = 总样本量 × 期望比例
```

例如：
- 总样本量 = 300
- 期望比例 = 33.3%
- 期望频数 = 300 × 33.3% = 100（每个产品）

**Step 3: 计算卡方统计量**

```
χ² = Σ [(观测频数 - 期望频数)² / 期望频数]
```

**Step 4: 确定自由度**

```
df = 类别数 - 1
   = 3 - 1
   = 2
```

**Step 5: 计算P值并做出决策**

- 如果P值 ≤ α，则拒绝原假设（观测频数与期望频数有显著差异）
- 如果P值 > α，则不拒绝原假设（没有足够证据表明观测频数与期望频数有显著差异）

#### 2.3 Python示例

```python
import scipy.stats as stats
import numpy as np

# 观测频数
observed = np.array([120, 90, 90])  # 产品A:120人，产品B:90人，产品C:90人

# 期望比例（均匀分布）
expected_proportions = np.array([1/3, 1/3, 1/3])

# 卡方拟合优度检验
chi2_stat, p_value = stats.chisquare(observed, expected_proportions * observed.sum())

print(f'卡方统计量: {chi2_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：用户偏好不符合均匀分布')
else:
    print('不拒绝原假设：没有足够证据表明用户偏好不符合均匀分布')
```

### 三、卡方齐性检验（Chi-Square Test of Homogeneity）

#### 3.1 原理

**目标**：检验多个总体的分布是否相同

**示例**：
- 总体1：渠道A的用户（购买、不购买）
- 总体2：渠道B的用户（购买、不购买）
- 总体3：渠道C的用户（购买、不购买）
- 目标：检验三个渠道的用户购买决策分布是否相同

#### 3.2 Python示例

```python
import scipy.stats as stats
import numpy as np

# 列联表
# 行：渠道（A、B、C）
# 列：购买决策（购买、不购买）
observed = np.array([[40, 60],
                     [50, 50],
                     [60, 40]])

# 卡方齐性检验
chi2_stat, p_value, dof, expected = stats.chi2_contingency(observed)

print(f'卡方统计量: {chi2_stat:.4f}')
print(f'P值: {p_value:.4f}')
print(f'自由度: {dof}')
print(f'期望频数:\n{expected}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：三个渠道的用户购买决策分布不相同')
else:
    print('不拒绝原假设：没有足够证据表明三个渠道的用户购买决策分布不相同')
```

## 示例/应用场景

### 示例1：电商用户行为分析

**业务问题**：检验性别与购买决策是否独立（即性别是否影响购买决策）。

**数据**：
- 男性：购买40人，不购买60人
- 女性：购买60人，不购买40人
- 总计200人

**分析**：

```python
import scipy.stats as stats
import numpy as np

# 列联表
observed = np.array([[40, 60],
                     [60, 40]])

# 卡方独立性检验
chi2_stat, p_value, dof, expected = stats.chi2_contingency(observed)

print(f'卡方统计量: {chi2_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：性别与购买决策不独立（性别影响购买决策）')
else:
    print('不拒绝原假设：没有足够证据表明性别与购买决策不独立')
```

**洞察与建议**：
- 如果拒绝原假设，说明性别显著影响购买决策，可以针对不同性别制定差异化营销策略
- 如果不拒绝原假设，说明性别不显著影响购买决策，不需要针对性别制定差异化营销策略

### 示例2：产品偏好分析

**业务问题**：检验用户偏好是否符合均匀分布（即33.3%的用户偏好产品A，33.3%偏好产品B，33.3%偏好产品C）。

**数据**：
- 产品A：120人
- 产品B：90人
- 产品C：90人
- 总计300人

**分析**：

```python
import scipy.stats as stats
import numpy as np

# 观测频数
observed = np.array([120, 90, 90])

# 期望比例（均匀分布）
expected_proportions = np.array([1/3, 1/3, 1/3])

# 卡方拟合优度检验
chi2_stat, p_value = stats.chisquare(observed, expected_proportions * observed.sum())

print(f'卡方统计量: {chi2_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：用户偏好不符合均匀分布')
else:
    print('不拒绝原假设：没有足够证据表明用户偏好不符合均匀分布')
```

**洞察与建议**：
- 如果拒绝原假设，说明用户偏好不符合均匀分布，产品A更受欢迎，可以加大产品A的推广力度
- 如果不拒绝原假设，说明用户偏好符合均匀分布，三个产品受欢迎程度相同，可以平均分配推广资源

### 示例3：广告渠道效果评估

**业务问题**：检验三个广告渠道的转化率是否相同。

**数据**：
- 渠道A：展示1000次，转化40次，转化率4%
- 渠道B：展示1000次，转化50次，转化率5%
- 渠道C：展示1000次，转化60次，转化率6%

**分析**：

```python
import scipy.stats as stats
import numpy as np

# 列联表
# 行：渠道（A、B、C）
# 列：转化决策（转化、未转化）
observed = np.array([[40, 960],
                     [50, 950],
                     [60, 940]])

# 卡方齐性检验
chi2_stat, p_value, dof, expected = stats.chi2_contingency(observed)

print(f'卡方统计量: {chi2_stat:.4f}')
print(f'P值: {p_value:.4f}')

# 决策（α=0.05）
alpha = 0.05
if p_value < alpha:
    print('拒绝原假设：三个渠道的转化率不相同')
else:
    print('不拒绝原假设：没有足够证据表明三个渠道的转化率不相同')
```

**洞察与建议**：
- 如果拒绝原假设，说明三个渠道的转化率有显著差异，可以将预算向转化率高的渠道倾斜
- 如果不拒绝原假设，说明三个渠道的转化率没有显著差异，可以平均分配预算

## 最佳实践

### 1. 检查假设条件（特别是样本量）

**不推荐**（忽略假设条件，直接进行卡方检验）：

```
不进行假设条件检查，直接进行卡方检验。
```

**推荐**（先检查假设条件，再选择适当的检验方法）：

```
1. 检查独立性（每个观测值之间相互独立）
2. 检查样本量（每个单元格的期望频数 ≥ 5）
3. 如果期望频数 < 5，使用Fisher精确检验
```

### 2. 使用正确的卡方检验类型

**不推荐**（混淆卡方检验的类型）：

```
本来要进行卡方独立性检验，却使用了卡方拟合优度检验。
```

**推荐**（根据业务问题选择正确的卡方检验类型）：

```
- 检验两个分类变量是否独立 → 卡方独立性检验
- 检验观测频数与期望频数是否有显著差异 → 卡方拟合优度检验
- 检验多个总体的分布是否相同 → 卡方齐性检验
```

### 3. 报告效应量（Effect Size）

**不推荐**（只报告P值）：

```
P值 < 0.05，所以拒绝原假设。
```

**推荐**（同时报告P值和效应量）：

```
P值 < 0.05，效应量（Cramér's V）= 0.3，说明关联程度中等。
```

### 4. 结合业务背景解释结果

**不推荐**（只报告统计结果，不结合业务背景）：

```
卡方统计量 = 8.0，P值 = 0.005，所以拒绝原假设。
```

**推荐**（结合业务背景解释结果）：

```
卡方统计量 = 8.0，P值 = 0.005，所以拒绝原假设（性别与购买决策不独立）。
说明性别显著影响购买决策，可以针对不同性别制定差异化营销策略。
```

## 常见错误

### 1. 忽略卡方检验的假设条件

**错误示例**：

```
不进行假设条件检查（特别是样本量检查），直接进行卡方检验。
```

**正确做法**：

```
先检查假设条件（独立性、样本量、分类变量），再选择适当的检验方法。
```

### 2. 混淆卡方检验的类型

**错误示例**：

```
本来要进行卡方独立性检验，却使用了卡方拟合优度检验。
```

**正确做法**：

```
根据业务问题选择正确的卡方检验类型。
```

### 3. 当期望频数 < 5时，仍然使用卡方检验

**错误示例**：

```
当期望频数 < 5时，仍然使用卡方检验（会导致结果不准确）。
```

**正确做法**：

```
当期望频数 < 5时，使用Fisher精确检验。
```

### 4. 忽略效应量

**错误示例**：

```
只报告P值，不报告效应量。
```

**正确做法**：

```
同时报告P值和效应量（如Cramér's V、Phi系数等），以评估关联的实际大小。
```

### 5. 不结合业务背景解释结果

**错误示例**：

```
只报告统计结果，不结合业务背景解释结果。
```

**正确做法**：

```
结合业务背景解释结果，提出可落地的业务建议。
```

## 总结

卡方检验是处理分类数据的核心工具，关键要点包括：

1. **掌握卡方检验的类型**：卡方独立性检验、卡方拟合优度检验、卡方齐性检验
2. **熟练计算卡方统计量**：χ² = Σ [(观测频数 - 期望频数)² / 期望频数]
3. **理解卡方检验的步骤**：提出假设、计算卡方统计量、确定自由度、确定显著性水平、计算P值、做出统计决策
4. **理解卡方检验的假设条件**：独立性、样本量（每个单元格的期望频数 ≥ 5）、分类变量
5. **熟练使用卡方检验**：根据业务问题选择正确的卡方检验类型
6. **注意最佳实践**：检查假设条件、使用正确的卡方检验类型、报告效应量、结合业务背景解释结果
7. **避免常见错误**：忽略卡方检验的假设条件、混淆卡方检验的类型、当期望频数 < 5时仍然使用卡方检验、忽略效应量、不结合业务背景解释结果

卡方检验是数据分析师的必备技能，需要在实践中不断积累经验。

## 扩展阅读

### 高级主题

1. **Fisher精确检验**：当期望频数 < 5时，使用Fisher精确检验替代卡方检验
2. **McNemar检验**：用于配对分类数据的检验（如同一组用户在前后的态度变化）
3. **Cochran's Q检验**：用于三个或更多相关样本的比较
4. **对数线性模型（Log-Linear Model）**：用于分析多个分类变量之间的关系

### 实战案例

1. **电商用户行为分析**：性别与购买决策、年龄段与购买决策、地域与购买决策
2. **产品偏好分析**：用户偏好是否符合均匀分布、用户偏好是否符合某种分布
3. **广告渠道效果评估**：多个渠道的转化率是否有显著差异
4. **医疗实验**：治疗方法与疗效是否有显著关联
