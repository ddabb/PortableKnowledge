# 概率分布

## 定义

概率分布是**描述随机变量取各个值的概率**的数学函数。

对于数据分析师而言，概率分布是**理解数据随机性、进行统计推断、建立统计模型**的基础。

---

## 核心概念

### 1. 随机变量

| 类型 | 说明 | 示例 |
|------|------|------|
| **离散随机变量** | 取值有限或可数无限 | 抛硬币次数、客户数量 |
| **连续随机变量** | 取值不可数无限 | 身高、温度、时间 |

### 2. 概率分布类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **离散分布** | 描述离散随机变量的分布 | 伯努利分布、二项分布、泊松分布 |
| **连续分布** | 描述连续随机变量的分布 | 正态分布、均匀分布、指数分布 |

---

## 详细内容

### 一、离散分布

#### 1.1 伯努利分布（Bernoulli Distribution）

**定义**：一次试验中成功（1）或失败（0）的概率分布

**参数**：
- p：成功概率

**概率质量函数**：
```
P(X=1) = p
P(X=0) = 1-p
```

**示例**：
```
抛一枚硬币，正面朝上概率p=0.5
P(X=正面) = 0.5
P(X=反面) = 0.5
```

**应用场景**：
- 用户点击广告（点击/不点击）
- 客户购买商品（购买/不购买）

#### 1.2 二项分布（Binomial Distribution）

**定义**：n次独立伯努利试验中成功次数的概率分布

**参数**：
- n：试验次数
- p：每次试验成功概率

**概率质量函数**：
```
P(X=k) = C(n,k) * p^k * (1-p)^(n-k)
```

**示例**：
```
抛10次硬币，正面朝上的次数X服从二项分布B(10, 0.5)
P(X=5) = C(10,5) * 0.5^5 * 0.5^5 ≈ 0.246
```

**应用场景**：
- 100个用户中点击广告的用户数量
- 1000个产品中次品数量

#### 1.3 泊松分布（Poisson Distribution）

**定义**：单位时间内事件发生次数的概率分布

**参数**：
- λ：单位时间（或单位面积）内事件发生的平均次数

**概率质量函数**：
```
P(X=k) = (λ^k * e^(-λ)) / k!
```

**示例**：
```
某网站每分钟访问次数X服从泊松分布P(20)
P(X=25) = (20^25 * e^(-20)) / 25! ≈ 0.044
```

**应用场景**：
- 网站每分钟访问次数
- 超市每小时顾客到达数量

---

### 二、连续分布

#### 2.1 正态分布（Normal Distribution）

**定义**：对称钟形曲线，最常见的连续分布

**参数**：
- μ：均值
- σ：标准差

**概率密度函数**：
```
f(x) = (1/(σ√(2π))) * e^(-(x-μ)²/(2σ²))
```

**示例**：
```
人群身高X服从正态分布N(170, 10)
P(X>180) = 1 - Φ((180-170)/10) ≈ 1 - 0.841 = 0.159
```

**应用场景**：
- 人群身高、体重
- 考试成绩
- 测量误差

**经验法则**：
- 68%的数据落在μ±σ内
- 95%的数据落在μ±2σ内
- 99.7%的数据落在μ±3σ内

#### 2.2 均匀分布（Uniform Distribution）

**定义**：区间内所有取值概率相等的连续分布

**参数**：
- a：区间下限
- b：区间上限

**概率密度函数**：
```
f(x) = 1/(b-a)  (a≤x≤b)
```

**示例**：
```
公交车到站时间X服从均匀分布U(0, 10)
P(X≤5) = (5-0)/(10-0) = 0.5
```

**应用场景**：
- 公交车到站时间
- 随机数生成

#### 2.3 指数分布（Exponential Distribution）

**定义**：描述事件发生时间间隔的连续分布

**参数**：
- λ：单位时间（或单位面积）内事件发生的平均次数

**概率密度函数**：
```
f(x) = λe^(-λx)  (x≥0)
```

**示例**：
```
网站访问间隔时间X服从指数分布E(0.05)
P(X>10) = e^(-0.05*10) ≈ 0.606
```

**应用场景**：
- 网站访问间隔时间
- 设备寿命
- 客户到达间隔时间

## 示例/应用场景

### 示例1：电商用户点击率分析

**业务问题**：分析电商广告的用户点击情况。

**数据**：用户点击广告数据（0/1）

**分析**：

**Python操作**：
```python
import pandas as pd
import numpy as np
import scipy.stats as stats

# 读取数据
df = pd.read_csv('ad_clicks.csv')

# 计算点击率
click_rate = df['click'].mean()
print(f"点击率: {click_rate}")

# 检验是否服从伯努利分布
# 使用二项分布检验
n = len(df)
k = df['click'].sum()
p = click_rate

# 计算p值
p_value = stats.binom_test(k, n, p)
print(f"p-value: {p_value}")

if p_value > 0.05:
    print("数据服从伯努利分布")
else:
    print("数据不服从伯努利分布")
```

**洞察与建议**：
- 如果点击率稳定，说明广告效果稳定
- 如果点击率波动大，说明广告效果不稳定
- 可以根据点击率优化广告投放策略

### 示例2：电商网站访问量分析

**业务问题**：分析电商网站每分钟访问量。

**数据**：网站每分钟访问量数据

**分析**：

**Python操作**：
```python
import pandas as pd
import numpy as np
import scipy.stats as stats
import matplotlib.pyplot as plt

# 读取数据
df = pd.read_csv('website_traffic.csv')

# 计算平均访问量
lambda_hat = df['visits'].mean()
print(f"平均访问量: {lambda_hat}")

# 检验是否服从泊松分布
# 使用卡方检验
observed = df['visits'].value_counts().sort_index()
expected = stats.poisson.pmf(observed.index, lambda_hat) * len(df)

chi2, p_value = stats.chisquare(observed, expected)

print(f"p-value: {p_value}")

if p_value > 0.05:
    print("数据服从泊松分布")
else:
    print("数据不服从泊松分布")

# 绘制泊松分布图
plt.hist(df['visits'], bins=20, density=True, alpha=0.7)
x = np.arange(0, df['visits'].max())
plt.plot(x, stats.poisson.pmf(x, lambda_hat), 'ro')
plt.xlabel('Visits')
plt.ylabel('Probability')
plt.title('Poisson Distribution')
plt.show()
```

**洞察与建议**：
- 如果访问量服从泊松分布，说明访问过程稳定
- 如果访问量不服从泊松分布，说明访问过程不稳定
- 可以根据访问量分布优化服务器资源配置

### 示例3：电商商品价格分析

**业务问题**：分析电商商品价格分布。

**数据**：商品价格数据

**分析**：

**Python操作**：
```python
import pandas as pd
import numpy as np
import scipy.stats as stats
import matplotlib.pyplot as plt

# 读取数据
df = pd.read_csv('product_prices.csv')

# 计算均值和标准差
mu = df['price'].mean()
sigma = df['price'].std()
print(f"均值: {mu}, 标准差: {sigma}")

# 检验是否服从正态分布
# 使用Shapiro-Wilk检验
stat, p_value = stats.shapiro(df['price'])

print(f"p-value: {p_value}")

if p_value > 0.05:
    print("数据服从正态分布")
else:
    print("数据不服从正态分布")

# 绘制正态分布图
plt.hist(df['price'], bins=20, density=True, alpha=0.7)
x = np.linspace(df['price'].min(), df['price'].max(), 100)
plt.plot(x, stats.norm.pdf(x, mu, sigma), 'r')
plt.xlabel('Price')
plt.ylabel('Density')
plt.title('Normal Distribution')
plt.show()
```

**洞察与建议**：
- 如果价格服从正态分布，说明价格形成机制稳定
- 如果价格不服从正态分布，说明价格形成机制不稳定
- 可以根据价格分布制定定价策略

## 最佳实践

### 1. 根据数据类型，选择合适的概率分布

**不推荐**（盲目使用正态分布）：

```
无论什么数据，都使用正态分布进行建模。
```

**推荐**（根据数据类型，选择合适的概率分布）：

```
- 0/1数据 → 伯努利分布
- 计数数据 → 泊松分布
- 连续数据 → 正态分布（如果对称）
```

### 2. 使用统计检验验证分布假设

**不推荐**（不做检验，直接使用）：

```
假设数据服从正态分布，直接使用正态分布进行建模。
```

**推荐**（使用统计检验验证分布假设）：

```
- 使用Shapiro-Wilk检验验证正态分布
- 使用卡方检验验证泊松分布
- 根据检验结果选择合适的概率分布
```

### 3. 使用可视化辅助分布分析

**不推荐**（只报告统计检验结果）：

```

```

```

```

### 4. 结合业务场景解释分布分析结果

**不推荐**（只报告分布分析结果）：


**推荐**（结合业务场景解释分布分析结果）：

## 常见错误

### 1. 盲目使用正态分布

**错误示例**：

```
假设用户点击数据服从正态分布，使用正态分布进行建模。
```

**正确做法**：

```
用户点击数据是0/1数据，应该使用伯努利分布进行建模。
```

### 2. 不做统计检验，直接使用分布

**错误示例**：

```
假设数据服从正态分布，直接使用正态分布进行建模。
```

**正确做法**：

```
使用Shapiro-Wilk检验验证正态分布，根据检验结果选择合适的概率分布。
```

### 3. 不使用可视化辅助分布分析

**错误示例**：

```
数据服从正态分布（p-value=0.10）。
```

**正确做法**：

```
数据服从正态分布（p-value=0.10）。
[绘制Q-Q图显示正态分布拟合效果]
```

### 4. 不结合业务场景解释分布分析结果

**错误示例**：

```
数据服从正态分布。
```

**正确做法**：

```
数据服从正态分布，说明价格形成机制稳定，可以根据正态分布制定定价策略。
```

### 5. 混淆离散分布和连续分布

**错误示例**：

```
使用正态分布描述用户点击数据（0/1数据）。
```

**正确做法**：

```
用户点击数据是离散数据，应该使用伯努利分布或二项分布进行描述。
```
