# 其他应付款

## 其他应付款的定义

其他应付款是指企业除应付票据、应付账款、预收账款、应付职工薪酬、应交税费、应付利息、应付股利等以外的其他各项应付、暂收的款项。

## 其他应付款的内容

- 应付经营租入固定资产和包装物的租金
- 存入保证金（如收取的包装物押金）
- 应付、暂收所属单位、个人的款项
- 其他应付、暂收款项

## 其他应付款的核算

### 发生其他应付款

```
借：银行存款（或管理费用等）
  贷：其他应付款
```

### 支付其他应付款

```
借：其他应付款
  贷：银行存款
```

## 其他应付款的账务处理示例

### 示例1：存入保证金

1. 企业出租包装物，收取押金2,000元。

   ```
   借：银行存款 2,000
     贷：其他应付款——包装物押金 2,000
   ```

2. 租入方归还包装物，企业退还押金。

   ```
   借：其他应付款——包装物押金 2,000
     贷：银行存款 2,000
   ```

### 示例2：应付经营租入固定资产租金

1. 企业租入管理用设备一台，每月租金1,500元，按季支付。

   ```
   借：管理费用 1,500
     贷：其他应付款——应付租金 1,500
   ```

2. 季度末支付租金。

   ```
   借：其他应付款——应付租金 4,500
     贷：银行存款 4,500
   ```

## 其他应付款的列报

其他应付款应当在资产负债表的流动负债部分列示。
