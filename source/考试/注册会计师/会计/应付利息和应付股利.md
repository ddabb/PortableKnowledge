# 应付利息和应付股利

## 应付利息

### 应付利息的定义

应付利息是指企业按照合同约定应支付的利息，包括短期借款、分期付息到期还本的长期借款、企业债券等应支付的利息。

### 应付利息的核算

#### 计提利息

```
借：财务费用（或在建工程等）
  贷：应付利息
```

#### 支付利息

```
借：应付利息
  贷：银行存款
```

### 应付利息的账务处理示例

1. 企业借入短期借款100,000元，年利率6%，期限3个月，按月计提利息，到期一次还本付息。

   ```
   借：银行存款 100,000
     贷：短期借款 100,000
   ```

2. 每月计提利息。

   ```
   借：财务费用 500（100,000×6%÷12）
     贷：应付利息 500
   ```

3. 到期支付本息。

   ```
   借：短期借款 100,000
       应付利息 1,500
     贷：银行存款 101,500
   ```

## 应付股利

### 应付股利的定义

应付股利是指企业根据股东大会或类似机构审议批准的利润分配方案确定分配给投资者的现金股利或利润。

### 应付股利的核算

#### 确认应付股利

```
借：利润分配——应付现金股利或利润
  贷：应付股利
```

#### 支付股利

```
借：应付股利
  贷：银行存款
```

### 应付股利的账务处理示例

1. 企业股东大会审议批准2025年度利润分配方案，决定向股东分配现金股利500,000元。

   ```
   借：利润分配——应付现金股利或利润 500,000
     贷：应付股利 500,000
   ```

2. 企业向股东支付现金股利。

   ```
   借：应付股利 500,000
     贷：银行存款 500,000
   ```

## 应付利息和应付股利的列报

应付利息和应付股利应当在资产负债表的流动负债部分列示。
