# 应付职工薪酬

## 应付职工薪酬的定义

应付职工薪酬是指企业为获得职工提供的服务或解除劳动关系而给予的各种形式的报酬或补偿。

## 应付职工薪酬的内容

### 短期薪酬
- 职工工资、奖金、津贴和补贴
- 职工福利费
- 医疗保险费、工伤保险费和生育保险费等社会保险费
- 住房公积金
- 工会经费和职工教育经费
- 短期带薪缺勤
- 短期利润分享计划
- 非货币性福利
- 其他短期薪酬

### 离职后福利
- 设定提存计划
- 设定受益计划

### 辞退福利
- 解除劳动关系补偿

### 其他长期职工福利
- 长期带薪缺勤
- 长期残疾福利
- 长期利润分享计划

## 应付职工薪酬的核算

### 确认应付职工薪酬

#### 生产部门人员的职工薪酬

```
借：生产成本
    制造费用
    劳务成本
  贷：应付职工薪酬
```

#### 管理部门人员的职工薪酬

```
借：管理费用
  贷：应付职工薪酬
```

#### 销售部门人员的职工薪酬

```
借：销售费用
  贷：应付职工薪酬
```

#### 在建工程、研发支出人员的职工薪酬

```
借：在建工程
    研发支出
  贷：应付职工薪酬
```

### 发放职工薪酬

#### 支付工资、奖金、津贴和补贴

```
借：应付职工薪酬——工资
  贷：银行存款
    库存现金
    其他应收款（代扣的款项）
    应交税费——应交个人所得税（代扣的个人所得税）
```

#### 支付职工福利费

```
借：应付职工薪酬——职工福利
  贷：银行存款
    库存现金
```

#### 支付社会保险费和住房公积金

```
借：应付职工薪酬——社会保险费
    应付职工薪酬——住房公积金
  贷：银行存款
```

#### 支付工会经费和职工教育经费

```
借：应付职工薪酬——工会经费
    应付职工薪酬——职工教育经费
  贷：银行存款
```

## 应付职工薪酬的账务处理示例

### 示例1：计提和发放工资

1. 企业计提本月工资，其中生产车间工人工资50,000元，车间管理人员工资20,000元，管理部门人员工资30,000元，销售部门人员工资15,000元。

   ```
   借：生产成本 50,000
       制造费用 20,000
       管理费用 30,000
       销售费用 15,000
     贷：应付职工薪酬——工资 115,000
   ```

2. 企业发放本月工资，代扣个人所得税5,000元，代扣社会保险费11,500元，代扣住房公积金8,625元，实发工资89,875元。

   ```
   借：应付职工薪酬——工资 115,000
     贷：银行存款 89,875
         应交税费——应交个人所得税 5,000
         其他应付款——社会保险费 11,500
         其他应付款——住房公积金 8,625
   ```

### 示例2：非货币性福利

1. 企业为管理人员提供免费使用的汽车，每月计提折旧1,000元。

   ```
   借：管理费用 1,000
     贷：应付职工薪酬——非货币性福利 1,000

   借：应付职工薪酬——非货币性福利 1,000
     贷：累计折旧 1,000
   ```

## 应付职工薪酬的列报

应付职工薪酬应当在资产负债表的流动负债部分列示。
