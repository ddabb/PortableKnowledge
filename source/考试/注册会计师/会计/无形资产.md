# 无形资产

## 无形资产的确认

### 无形资产的定义

无形资产是指企业拥有或者控制的没有实物形态的可辨认非货币性资产。

### 无形资产的特征

1. **不具有实物形态**
2. **具有可辨认性**
3. **属于非货币性资产**

### 无形资产的确认条件

1. 与该无形资产有关的经济利益很可能流入企业
2. 该无形资产的成本能够可靠地计量

## 无形资产的初始计量

### 无形资产成本的构成

无形资产应当按照成本进行初始计量。

### 不同方式取得无形资产的成本

#### 外购无形资产
成本=购买价款+相关税费+直接归属于使该项资产达到预定用途所发生的其他支出

#### 自行开发无形资产
成本=自满足资本化条件至达到预定用途前所发生的支出总额

#### 投资者投入无形资产
成本=投资合同或协议约定的价值（但合同或协议约定价值不公允的除外）

## 内部研究开发费用的确认和计量

### 研究阶段和开发阶段的划分

- **研究阶段**：是指为获取新的技术和知识等进行的有计划的调查，具有计划性和探索性
- **开发阶段**：是指在进行商业性生产或使用前，将研究成果或其他知识应用于某项计划或设计，以生产出新的或具有实质性改进的材料、装置、产品等，具有针对性和形成成果的可能性

### 研究阶段和开发阶段的会计处理

#### 研究阶段
研究阶段的支出应当于发生时计入当期损益（管理费用）。

#### 开发阶段
开发阶段的支出，符合资本化条件的，应当资本化；不符合资本化条件的，应当计入当期损益（管理费用）。

### 内部开发无形资产的成本构成

内部开发无形资产的成本包括自满足资本化条件至达到预定用途前所发生的支出总额，包括：
- 开发过程中耗用的材料
- 开发过程中发生的直接人工
- 开发过程中使用的其他专利权和特许权的摊销
- 按照借款费用的处理原则可以资本化的利息支出

## 无形资产的后续计量

### 无形资产的摊销

#### 摊销的范围
使用寿命有限的无形资产应当摊销；使用寿命不确定的无形资产不应摊销。

#### 摊销方法
企业应当根据与无形资产有关的经济利益的预期实现方式，选择合理的摊销方法。无法可靠确定预期实现方式的，应当采用直线法摊销。

#### 摊销期限
使用寿命有限的无形资产，其应摊销金额应当在使用寿命内系统合理摊销。

#### 摊销的核算
```
借：管理费用（自用）
    其他业务成本（出租）
    制造费用（生产产品）
  贷：累计摊销
```

### 无形资产的减值

企业应当在资产负债表日对无形资产的账面价值进行检查，有客观证据表明无形资产发生减值的，应当计提减值准备。

#### 无形资产减值的核算
```
借：资产减值损失
  贷：无形资产减值准备
```

## 无形资产的处置

### 无形资产出售
```
借：银行存款
    累计摊销
    无形资产减值准备
  贷：无形资产
    应交税费——应交增值税（销项税额）
    营业外收入（或借：营业外支出）
```

### 无形资产出租

#### 取得租金收入
```
借：银行存款
  贷：其他业务收入
    应交税费——应交增值税（销项税额）
```

#### 摊销成本
```
借：其他业务成本
  贷：累计摊销
```

### 无形资产报废
```
借：累计摊销
    无形资产减值准备
    营业外支出
  贷：无形资产
```
