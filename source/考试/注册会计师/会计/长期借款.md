# 长期借款

## 长期借款的定义

长期借款是指企业向银行或其他金融机构借入的期限在一年以上（不含一年）的各项借款。

## 长期借款的核算

### 取得长期借款

```
借：银行存款
  贷：长期借款——本金
    长期借款——利息调整（差额，或借）
```

### 计提长期借款利息

#### 资本化的利息

```
借：在建工程（或制造费用等）
  贷：应付利息（分期付息）
    长期借款——应计利息（到期一次还本付息）
```

#### 费用化的利息

```
借：财务费用
  贷：应付利息（分期付息）
    长期借款——应计利息（到期一次还本付息）
```

### 偿还长期借款

#### 分期付息，到期还本

```
借：长期借款——本金
    应付利息
  贷：银行存款
```

#### 到期一次还本付息

```
借：长期借款——本金
    长期借款——应计利息
  贷：银行存款
```

## 长期借款的账务处理示例

### 示例1：分期付息，到期还本

1. 企业于2025年1月1日向银行借入长期借款1,000,000元，年利率8%，期限3年，每年年末支付利息，到期偿还本金。

   ```
   借：银行存款 1,000,000
     贷：长期借款——本金 1,000,000
   ```

2. 2025年末计提并支付利息。

   ```
   借：财务费用 80,000
     贷：应付利息 80,000

   借：应付利息 80,000
     贷：银行存款 80,000
   ```

3. 2026年末计提并支付利息。

   ```
   借：财务费用 80,000
     贷：应付利息 80,000

   借：应付利息 80,000
     贷：银行存款 80,000
   ```

4. 2027年末计提利息并偿还本金。

   ```
   借：财务费用 80,000
     贷：应付利息 80,000

   借：长期借款——本金 1,000,000
       应付利息 80,000
     贷：银行存款 1,080,000
   ```

### 示例2：到期一次还本付息

1. 企业于2025年1月1日向银行借入长期借款500,000元，年利率6%，期限2年，到期一次还本付息。

   ```
   借：银行存款 500,000
     贷：长期借款——本金 500,000
   ```

2. 2025年末计提利息。

   ```
   借：财务费用 30,000
     贷：长期借款——应计利息 30,000
   ```

3. 2026年末计提利息并偿还本息。

   ```
   借：财务费用 30,000
     贷：长期借款——应计利息 30,000

   借：长期借款——本金 500,000
       长期借款——应计利息 60,000
     贷：银行存款 560,000
   ```

## 长期借款的列报

长期借款应当在资产负债表的非流动负债部分列示。如果长期借款在一年内到期，应当在资产负债表的流动负债部分列示。
