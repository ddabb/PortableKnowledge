# 货币资金审计

## 定义

货币资金审计是指注册会计师对企事业单位的现金、银行存款和其他货币资金进行审计，以验证其真实性、完整性、所有权、计价和分摊、列报等审计目标。

## 核心概念

### 1. 货币资金概述

**货币资金的定义：**
货币资金是指企业拥有的现金、银行存款和其他货币资金。

**货币资金的分类：**
- **库存现金**：企业持有的现钞和硬币
- **银行存款**：企业存放在银行或其他金融机构的款项
- **其他货币资金**：企业持有的除现金和银行存款以外的其他货币资金，如外埠存款、银行汇票存款、银行本票存款、信用卡存款、信用证保证金存款、存出投资款等

**货币资金的特点：**
- 流动性最强
- 风险最高
- 最容易被挪用或侵占
- 是企业运营的基础

### 2. 货币资金的内部控制

**内部控制的目标：**
- 确保货币资金的安全和完整
- 确保货币资金的记录准确无误
- 确保货币资金的使用合法合规
- 确保货币资金的收付及时正确

**内部控制的要素：**
1. **控制环境**：企业的治理结构、组织结构和企业文化
2. **风险评估**：企业对货币资金风险的识别和评估
3. **控制活动**：企业为实现控制目标而采取的措施
4. **信息系统与沟通**：企业的信息系统和沟通机制
5. **对控制的监督**：企业对内部控制的监督和评价

**关键内部控制措施：**
- **职责分离**：货币资金收付与记录职责分离、银行存款余额调节表编制与核对职责分离
- **授权审批**：所有货币资金收付必须经过授权审批
- **凭证和记录控制**：所有货币资金收付必须有合法凭证、及时准确记录
- **独立检查**：定期核对银行存款余额调节表、定期盘点库存现金
- **限制接触**：限制无关人员接触货币资金

### 3. 货币资金的审计程序

**风险评估程序：**
1. 了解货币资金的内部控制
2. 评估货币资金的重大错报风险

**控制测试：**
1. 测试货币资金的内部控制
2. 评价内部控制的有效性

**实质性程序：**
1. **库存现金的实质性程序**
   - 监盘库存现金：突击盘点，核对账实是否相符
   - 检查现金日记账：检查现金收支记录是否完整、准确
   - 检查现金收支凭证：检查现金收支是否有合法凭证
   - 检查现金余额调节表：检查现金余额调节表是否及时准确编制

2. **银行存款的实质性程序**
   - 函证银行存款余额：向所有开户银行函证银行存款余额
   - 检查银行对账单：核对银行对账单与企业银行存款日记账
   - 检查银行存款余额调节表：检查银行存款余额调节表编制是否正确、调节事项是否合理
   - 检查银行存款收支凭证：检查银行存款收支是否有合法凭证

3. **其他货币资金的实质性程序**
   - 检查其他货币资金的存在性：检查其他货币资金的证明文件
   - 检查其他货币资金的完整性：检查其他货币资金是否全部入账
   - 检查其他货币资金的计价和分摊：检查其他货币资金的计价是否正确

## 详细内容

### 1. 库存现金审计

**审计目标：**
- 存在性：库存现金是否真实存在
- 完整性：所有库存现金是否全部入账
- 权利和义务：企业是否拥有库存现金的所有权
- 计价和分摊：库存现金的计价是否正确
- 列报：库存现金是否按照会计准则正确列报

**审计程序：**
1. **监盘库存现金**
   - 突击盘点：不进行事先通知
   - 全面盘点：盘点所有库存现金，包括备用金
   - 核对账实：将盘点结果与现金日记账核对
   - 编制库存现金盘点表：记录盘点结果

2. **检查现金日记账**
   - 检查现金日记账记录是否完整
   - 检查现金日记账记录是否准确
   - 检查现金日记账是否及时登记
   - 检查现金日记账是否经过适当审核

3. **检查现金收支凭证**
   - 检查现金收款凭证：检查现金收款是否有合法凭证
   - 检查现金付款凭证：检查现金付款是否有合法凭证、是否经过授权审批
   - 检查现金收支凭证的连续性：检查凭证编号是否连续

4. **检查现金余额调节表**
   - 检查现金余额调节表是否及时编制
   - 检查现金余额调节表编制是否正确
   - 检查调节事项是否合理
   - 检查现金余额调节表是否经过适当审核

**常见错报：**
- 截留现金收入：将现金收入不入账，挪作他用
- 挪用现金：挪用库存现金，用于个人用途
- 白条抵库：用白条（非正式凭证）抵充库存现金
- 虚构现金支出：虚构现金支出，套取现金
- 现金盘点差异：现金日记账余额与盘点结果不符

### 2. 银行存款审计

**审计目标：**
- 存在性：银行存款是否真实存在
- 完整性：所有银行存款是否全部入账
- 权利和义务：企业是否拥有银行存款的所有权
- 计价和分摊：银行存款的计价是否正确
- 列报：银行存款是否按照会计准则正确列报

**审计程序：**
1. **函证银行存款余额**
   - 向所有开户银行函证：包括本期已注销的账户
   - 函证内容包括：银行存款余额、银行贷款余额、担保情况等
   - 直接收取回函：防止企业篡改回函
   - 跟进未回函账户：对未回函账户实施替代程序

2. **检查银行对账单**
   - 获取银行对账单：获取所有银行账户的全年对账单
   - 核对银行对账单与企业银行存款日记账：检查两者是否相符
   - 检查未达账项：检查未达账项是否合理、是否及时清理
   - 检查大额异常收支：检查大额异常收支是否有合理解释

3. **检查银行存款余额调节表**
   - 获取银行存款余额调节表：获取所有银行账户的银行存款余额调节表
   - 检查银行存款余额调节表编制是否正确：重新计算调节表
   - 检查调节事项是否合理：检查调节事项是否有合理解释
   - 检查银行存款余额调节表是否及时编制：检查调节表编制日期
   - 检查银行存款余额调节表是否经过适当审核

4. **检查银行存款收支凭证**
   - 检查银行存款收款凭证：检查银行存款收款是否有合法凭证
   - 检查银行存款付款凭证：检查银行存款付款是否有合法凭证、是否经过授权审批
   - 检查银行存款收支凭证的连续性：检查凭证编号是否连续
   - 检查银行存款收支的分类是否正确：检查收支是否计入正确账户

**常见错报：**
- 截留银行存款收入：将银行存款收入不入账，挪作他用
- 挪用银行存款：挪用银行存款，用于个人用途
- 虚构银行存款支出：虚构银行存款支出，套取银行存款
- 涂改银行对账单：涂改银行对账单，掩盖挪用行为
- 未达账项长期挂账：未达账项长期未清理，可能隐藏问题
- 银行账户出租出借：将银行账户出租出借给他人使用

### 3. 其他货币资金审计

**审计目标：**
- 存在性：其他货币资金是否真实存在
- 完整性：所有其他货币资金是否全部入账
- 权利和义务：企业是否拥有其他货币资金的所有权
- 计价和分摊：其他货币资金的计价是否正确
- 列报：其他货币资金是否按照会计准则正确列报

**审计程序：**
1. **检查其他货币资金的存在性**
   - 检查外埠存款：检查外埠存款的批准文件、使用凭证
   - 检查银行汇票存款：检查银行汇票、收款凭证
   - 检查银行本票存款：检查银行本票、收款凭证
   - 检查信用卡存款：检查信用卡对账单、消费凭证
   - 检查信用证保证金存款：检查信用证、保证金存款凭证
   - 检查存出投资款：检查投资协议、付款凭证

2. **检查其他货币资金的完整性**
   - 检查其他货币资金是否全部入账
   - 检查其他货币资金的变动是否有完整记录

3. **检查其他货币资金的计价和分摊**
   - 检查其他货币资金的计价是否正确
   - 检查其他货币资金是否按照会计准则正确计量

**常见错报：**
- 其他货币资金不入账：将其他货币资金不入账，挪作他用
- 虚构其他货币资金：虚构其他货币资金，套取资金
- 其他货币资金长期挂账：其他货币资金长期挂账，可能已被挪用

## 示例/应用场景

### 示例1：库存现金盘点发现账实不符

**场景描述：**
注册会计师在对某企业进行年度审计时，对库存现金进行突击盘点，发现现金日记账余额为50,000元，但实际盘点金额为45,000元，差异5,000元。

**审计程序：**
1. 重新盘点库存现金，确认差异存在
2. 检查现金日记账记录，查找差异原因
3. 检查现金收支凭证，查找是否有漏记或错记
4. 询问出纳和会计，了解差异原因
5. 检查是否有白条抵库情况

**审计发现：**
经查发现，出纳私自借用现金5,000元，未入账，用白条抵充库存现金。

**审计处理：**
1. 要求出纳立即归还借用的现金
2. 建议企业加强库存现金管理，禁止白条抵库
3. 在审计报告中披露该事项

### 示例2：银行存款函证发现未入账贷款

**场景描述：**
注册会计师在向银行函证银行存款余额时，发现企业某银行账户有未入账的银行贷款1,000,000元。

**审计程序：**
1. 获取银行回函，确认未入账贷款情况
2. 检查银行贷款合同，了解贷款金额、利率、期限等
3. 检查贷款资金流向，了解贷款资金使用情况
4. 检查企业为何未将贷款入账
5. 评估未入账贷款对企业财务状况的影响

**审计发现：**
经查发现，企业为了降低资产负债率，故意未将银行贷款入账。

**审计处理：**
1. 要求企业立即将银行贷款入账
2. 调整财务报表，增加银行存款和短期借款/长期借款
3. 在审计报告中披露该事项，可能发表保留意见或否定意见

### 示例3：其他货币资金-存出投资款长期挂账

**场景描述：**
注册会计师在审计其他货币资金时，发现企业存出投资款科目余额2,000,000元，挂账已达3年，未进行任何投资。

**审计程序：**
1. 检查存出投资款的形成原因：检查投资协议、付款凭证
2. 检查为何长期未进行投资：询问管理层，了解原因
3. 检查存出投资款是否真实存在：向收款方函证
4. 评估存出投资款的可收回性：检查收款方财务状况
5. 检查是否需计提减值准备

**审计发现：**
经查发现，企业原计划进行股权投资，但投资项目因故取消，收款方一直未退还存出投资款，该企业也未积极追讨。

**审计处理：**
1. 建议企业积极追讨存出投资款
2. 评估可收回性，必要时计提减值准备
3. 在审计报告中披露该事项

1. **严格执行突击盘点**
   - 不进行事先通知
   - 盘点所有库存现金
   - 核对账实是否相符

2. **全面函证银行存款**
   - 向所有开户银行函证
   - 包括本期已注销的账户
   - 直接收取回函

3. **认真检查银行存款余额调节表**
   - 重新计算调节表
   - 检查调节事项是否合理
   - 检查调节表是否及时编制和审核

4. **关注异常收支**
   - 关注大额异常收支
   - 关注频繁的大额现金收支
   - 关注与关联方的大额资金往来

5. **保持职业怀疑态度**
   - 对货币资金审计保持高度警惕
   - 对异常情况保持敏感
   - 不轻易相信管理层的解释

## 常见错误

1. **未执行突击盘点**
   - 错误表现：事先通知企业盘点时间，给企业留出准备时间
   - 后果：企业可能利用准备时间掩盖问题
   - 正确做法：严格执行突击盘点，不进行事先通知

2. **未全面函证银行存款**
   - 错误表现：仅函证部分银行账户，或仅函证余额较大的账户
   - 后果：可能遗漏存在重大错报的银行账户
   - 正确做法：向所有开户银行函证，包括本期已注销的账户

3. **未直接收取银行回函**
   - 错误表现：通过企业转交银行回函
   - 后果：企业可能篡改银行回函
   - 正确做法：直接收取银行回函，确保回函的真实性

4. **未认真检查银行存款余额调节表**
   - 错误表现：仅浏览银行存款余额调节表，未重新计算、未检查调节事项
   - 后果：可能未发现银行存款的重大错报
   - 正确做法：重新计算调节表，检查调节事项是否合理

5. **未关注异常收支**
   - 错误表现：未关注大额异常收支、频繁的大额现金收支等
   - 后果：可能未发现货币资金的重大错报
   - 正确做法：关注异常收支，追查至原始凭证

6. **未保持职业怀疑态度**
   - 错误表现：轻易相信管理层的解释，未进一步追查
   - 后果：可能未发现货币资金的重大错报
   - 正确做法：保持职业怀疑态度，对异常情况追查到底

## 总结

货币资金审计是CPA审计的重要章节，也是审计实务中的高风险领域。货币资金具有流动性最强、风险最高的特点，最容易被挪用或侵占。

货币资金审计的核心是对内部控制的了解和测试，以及对实质性程序的执行。注册会计师需要严格执行审计程序，保持职业怀疑态度，关注异常情况，确保审计质量。

在CPA考试中，货币资金审计是高频考点，可能涉及选择题、简答题、综合题。考生应掌握货币资金的内部控制、审计程序、常见错报等内容，能够根据审计准则要求执行审计工作。

对于注册会计师来说，掌握货币资金审计是必备的技能。这不仅关系到审计工作的质量，也关系到注册会计师的职业声誉和法律责任。
