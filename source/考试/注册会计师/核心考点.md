# 注册会计师考试核心考点

## 一、会计

### 长期股权投资

**核心考点**：
- 长期股权投资的初始计量（同一控制、非同一控制）
- 成本法与权益法的适用范围及会计处理
- 长期股权投资减值与处置

**权益法调整公式**：
```
投资收益 = 被投资单位净利润 × 持股比例
需调整事项：内部交易未实现损益、资产公允价值差额摊销
```

### 所得税会计

**核心考点**：
- 资产账面价值与计税基础的差额 → 暂时性差异
- 应纳税暂时性差异 → 递延所得税负债
- 可抵扣暂时性差异 → 递延所得税资产

**所得税费用计算**：
```
所得税费用 = 当期所得税 + 递延所得税
当期所得税 = 应纳税所得额 × 税率
递延所得税 = 递延所得税负债增加 - 递延所得税资产增加
```

### 合并财务报表

**核心考点**：
- 合并范围的确定（控制三要素：权力、可变回报、权力影响回报）
- 内部交易的抵消处理
- 少数股东权益与少数股东损益

**合并调整分录**：
1. 子公司资产增值调整
2. 内部存货交易抵消
3. 内部固定资产交易抵消
4. 内部债权债务抵消

## 二、审计

### 审计证据

**核心考点**：
- 审计证据的充分性与适当性
- 函证程序的设计与实施
- 分析程序的应用场景

**函证要点**：
| 项目 | 函证要求 |
|------|---------|
| 银行存款 | 必须函证 |
| 应收账款 | 应当函证（除非对财务报表不重要或函证无效）|
| 应付账款 | 可选择函证大额供应商 |

### 风险评估与应对

**核心考点**：
- 重大错报风险的识别与评估
- 财务报表层次与认定层次风险的应对
- 特别风险的处理

**风险应对程序**：
- 控制测试：测试内部控制运行有效性
- 实质性程序：发现认定层次的重大错报
- 实质性分析程序：适用于有稳定关系的项目

### 审计报告

**审计意见类型**：
| 意见类型 | 适用情形 |
|---------|---------|
| 无保留意见 | 财务报表在所有重大方面公允反映 |
| 保留意见 | 错报重大但不广泛，或审计范围受限 |
| 否定意见 | 错报重大且广泛 |
| 无法表示意见 | 审计范围受限且影响广泛 |

## 三、财务成本管理

### 财务报表分析

**核心指标**：
```
净资产收益率（ROE）= 销售净利率 × 资产周转率 × 权益乘数
权益乘数 = 1 ÷ (1 - 资产负债率)
```

**杜邦分析体系**：将ROE分解为三个驱动因素，便于分析盈利能力的来源。

### 资本成本

**加权平均资本成本（WACC）**：
```
WACC = 债务成本 × (1 - 税率) × 债务比重 + 权益成本 × 权益比重
```

**权益成本估算**：
- 资本资产定价模型（CAPM）：R = Rf + β × (Rm - Rf)
- 股利增长模型：R = D1 / P0 + g

### 企业价值评估

**评估方法**：
| 方法 | 适用场景 |
|------|---------|
| 现金流折现法 | 稳定增长企业 |
| 相对价值法 | 可比公司较多 |
| 期权定价法 | 高成长、高风险企业 |

## 四、税法

### 增值税

**税率与征收率**：
| 税率 | 适用范围 |
|------|---------|
| 13% | 销售货物、加工修理修配劳务、有形动产租赁 |
| 9% | 交通运输、建筑、不动产租赁、农产品等 |
| 6% | 现代服务、生活服务、金融服务 |
| 3%（征收率） | 小规模纳税人 |
| 1%（征收率） | 小规模纳税人优惠税率 |

**进项税额不得抵扣情形**：
- 用于简易计税项目
- 用于集体福利或个人消费
- 非正常损失的购进货物

### 企业所得税

**应纳税所得额计算**：
```
应纳税所得额 = 收入总额 - 不征税收入 - 免税收入 - 扣除项目 - 以前年度亏损
```

**扣除项目限额**：
| 项目 | 扣除标准 |
|------|---------|
| 职工福利费 | 工资薪金14%以内 |
| 工会经费 | 工资薪金2%以内 |
| 职工教育经费 | 工资薪金8%以内（超限结转） |
| 业务招待费 | 发生额60%与营收5‰孰低 |
| 广告费 | 营收15%（超限结转） |

### 个人所得税

**综合所得**：工资薪金、劳务报酬、稿酬、特许权使用费

**年度汇算公式**：
```
应纳税额 = （综合所得 - 6万元 - 专项扣除 - 专项附加扣除 - 其他扣除）× 税率 - 速算扣除数
```

## 五、经济法

### 民法基础

**民事法律行为**：
- 有效条件：行为人具有民事行为能力、意思表示真实、不违反法律强制性规定
- 无效情形：违反法律强制性规定、违背公序良俗、恶意串通

**诉讼时效**：
- 一般诉讼时效：3年
- 最长保护期：20年

### 公司法

**股东权利**：
| 权利 | 内容 |
|------|------|
| 表决权 | 按出资比例行使（章程另有规定除外）|
| 分红权 | 按实缴出资比例分配 |
| 知情权 | 查阅公司章程、股东会决议、财务报告 |
| 优先购买权 | 股权转让时其他股东享有优先购买权 |

**公司治理结构**：
- 股东会：权力机构
- 董事会：执行机构
- 监事会：监督机构

### 合同法

**合同效力**：
- 有效合同：满足法律规定的生效条件
- 效力待定：限制行为能力人订立、无权代理
- 可撤销合同：欺诈、胁迫、重大误解、显失公平
- 无效合同：违反法律强制性规定

## 六、公司战略与风险管理

### 战略分析

**PEST分析**：
- P（政治）：政策法规、政治环境
- E（经济）：经济增长、利率汇率
- S（社会）：人口结构、消费习惯
- T（技术）：技术创新、技术变革

**SWOT分析**：
| 组合 | 战略选择 |
|------|---------|
| SO（优势-机会）| 增长型战略 |
| WO（劣势-机会）| 扭转型战略 |
| ST（优势-威胁）| 多元化战略 |
| WT（劣势-威胁）| 防御型战略 |

### 战略选择

**公司层战略**：
- 成长型战略：一体化、多元化
- 稳定型战略：维持现状
- 收缩型战略：剥离、清算

**竞争战略（波特三大战略）**：
| 战略 | 特点 |
|------|------|
| 成本领先 | 以低成本获取竞争优势 |
| 差异化 | 提供独特产品或服务 |
| 集中化 | 聚焦特定细分市场 |

### 风险管理

**风险类型**：
- 战略风险：宏观环境变化、产业竞争
- 运营风险：供应链中断、产品质量
- 财务风险：资金链断裂、汇率波动
- 法律合规风险：法规变更、合同纠纷

## 七、备考建议

1. **科目搭配**：会计+税法、审计+经济法、财管+战略
2. **时间分配**：会计、审计、财管需投入更多时间
3. **刷题策略**：历年真题反复练习，尤其是综合题
4. **记忆技巧**：经济法、税法多记忆，会计、审计重理解
5. **机考练习**：熟悉公式输入、表格操作
