# 计算机学科基础：数据结构到网络全解析

## 一、数据结构

### 线性表

| 存储结构 | 特点 |
|---------|------|
| 顺序存储 | 随机访问，插入删除效率低 |
| 链式存储（单链表/双链表/循环链表） | 插入删除效率高，顺序访问 |

### 栈和队列

| 结构 | 特点 | 应用场景 |
|------|------|---------|
| 栈 | 后进先出（LIFO） | 括号匹配、表达式求值、递归 |
| 队列 | 先进先出（FIFO） | 任务调度、层次遍历 |
| 循环队列 | 解决假溢出问题 | - |

### 树与二叉树

**二叉树性质：**
- 第i层最多有2^(i-1)个节点
- 深度为k的二叉树最多有2^k-1个节点
- 度为2的节点数 = 度为0的节点数 - 1

**遍历：**
- 前序：根-左-右
- 中序：左-根-右
- 后序：左-右-根
- 层次：从上到下，从左到右

**平衡二叉树（AVL）：** 左右子树高度差不超过1，需要旋转操作保持平衡。

**哈夫曼树：** 带权路径长度最短的树，用于压缩编码。

### 图

| 存储结构 | 特点 |
|---------|------|
| 邻接矩阵 | 适合稠密图 |
| 邻接表 | 适合稀疏图 |

**关键算法：**
- 最小生成树：Prim算法、Kruskal算法
- 最短路径：Dijkstra算法、Floyd算法
- 拓扑排序：判断有向无环图（DAG）
- 关键路径：最长路径，决定项目工期

### 查找与排序

| 查找算法 | 时间复杂度 | 条件 |
|---------|-----------|------|
| 顺序查找 | O(n) | 无 |
| 折半查找 | O(log n) | 有序顺序表 |
| 二叉搜索树 | O(log n)~O(n) | 有序 |
| 哈希查找 | O(1) | 无冲突 |

| 排序算法 | 时间复杂度 | 空间复杂度 | 稳定性 |
|---------|-----------|-----------|--------|
| 直接插入排序 | O(n²) | O(1) | 稳定 |
| 希尔排序 | O(n^1.3) | O(1) | 不稳定 |
| 冒泡排序 | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(log n) | 不稳定 |
| 简单选择排序 | O(n²) | O(1) | 不稳定 |
| 堆排序 | O(n log n) | O(1) | 不稳定 |
| 归并排序 | O(n log n) | O(n) | 稳定 |
| 基数排序 | O(d(n+r)) | O(r) | 稳定 |

## 二、操作系统

### 进程管理

**进程三种状态：** 就绪状态、运行状态、阻塞状态

**PV操作：**
- P操作（wait）：申请资源，减1
- V操作（signal）：释放资源，加1

**调度算法：** 先来先服务（FCFS）、短作业优先（SJF）、时间片轮转、优先级调度

**死锁四个必要条件：** 互斥条件、请求和保持条件、不剥夺条件、循环等待条件

**银行家算法：** 避免死锁的经典算法

### 内存管理

| 分配方式 | 特点 |
|---------|------|
| 连续分配 | 简单但浪费严重 |
| 分页存储 | 固定大小，减少碎片 |
| 分段存储 | 按逻辑段划分 |
| 段页式存储 | 结合两者优点 |

**虚拟内存：** 页面置换算法：最佳置换（OPT）、先进先出（FIFO）、最近最久未使用（LRU）、时钟置换（CLOCK）

## 三、计算机网络

### OSI七层模型

| 层次 | 功能 | 协议/设备 |
|------|------|---------|
| 物理层 | 比特传输 | 中继器、集线器 |
| 数据链路层 | 可靠传输、帧 | 网桥、交换机 |
| 网络层 | 路由选择 | 路由器、IP、ICMP |
| 传输层 | 端到端可靠传输 | TCP、UDP |
| 应用层 | 为用户提供服务 | HTTP、FTP、DNS |

### TCP vs UDP

| 特性 | TCP | UDP |
|------|-----|-----|
| 连接性 | 面向连接 | 无连接 |
| 可靠性 | 可靠 | 不可靠 |
| 速度 | 较慢 | 快 |
| 应用场景 | 文件传输、邮件 | 视频、语音、DNS |

### HTTP

- HTTP请求方法：GET（获取）、POST（提交）、PUT（更新）、DELETE（删除）
- HTTP响应状态码：200成功、301/302重定向、400请求错误、404未找到、500服务器错误
