# 数据仓库

## 1. 数据仓库定义

数据仓库是一个面向主题的、集成的、随时间变化的、包含汇总和明细的、稳定的历史数据集合。

**四大特征（Inmon）：**
- **面向主题**：围绕主题组织
- **集成**：数据来自多个源
- **随时间变化**：包含历史数据
- **不可更新**：数据稳定，供决策分析

## 2. 数据仓库架构

### 2.1 组成组件

| 组件 | 说明 |
|-----|------|
| 数据源 | 内部信息（业务数据、文档）+外部信息 |
| 存储与管理 | 核心，ETL，按主题组织 |
| OLAP服务器 | 多维分析 |
| 前端工具 | 查询、报表、分析、数据挖掘 |

### 2.2 OLAP类型

| 类型 | 说明 |
|-----|------|
| ROLAP | 关系型OLAP，基本和聚合数据存RDBMS |
| MOLAP | 多维OLAP，数据存多维数据库 |
| HOLAP | 混合型，基本数据在RDBMS，聚合在多维库 |

## 3. 数据标准化

### 3.1 主要内容

| 内容 | 说明 |
|-----|------|
| 元数据标准化 | 元数据格式和定义 |

### 3.2 标准化过程

1. 确定数据需求
2. 制定数据标准

## 4. 数据质量管理

### 4.1 质量指标

| 指标 | 说明 |
|-----|------|
| 完整性 | 数据完整无缺失 |
| 规范性 | 符合标准规范 |
| 一致性 | 数据协调统一 |
| 准确性 | 数据正确无误 |
| 唯一性 | 无重复记录 |
| 及时性 | 数据时效性 |

### 4.2 质量评价过程

```
确定数据质量元素 → 确定度量方法 → 选择评价方法 → 确定结果 → 报告结果
```

### 4.3 质量评价方法

| 方法 | 说明 |
|-----|------|
| 直接评价法 | 与参照信息对比 |
| 间接评价法 | 利用数据相关信息推断 |

### 4.4 质量控制

- **前期控制**：录入前、录入中、录入后控制
- **后期控制**：入库后检测和评价

## 5. 数据模型

### 5.1 三类模型

| 类型 | 说明 |
|-----|------|
| 概念模型 | 按用户观点，信息模型，独立于DBMS |
| 逻辑模型 | 确定数据结构，如关系模型 |
| 物理模型 | 具体技术实现，数据库存储 |

### 5.2 概念模型元素

| 元素 | 说明 |
|-----|------|
| 实体 | 客观事物抽象 |
| 属性 | 实体特性 |
| 域 | 属性取值范围 |
| 键 | 唯一标识实例 |
| 关联 | 实体间关系（一对一、一对多、多对多） |

### 5.3 关系模型

**完整性约束：**
- 实体完整性：主键不为空
- 参照完整性：外键参照完整性
- 用户定义完整性：领域语义约束

## 6. 数据建模过程

1. **数据需求分析**：使用数据流图
2. **概念模型设计**：确定实体和数据关联
3. **逻辑模型设计**：转换为关系模式
4. **物理模型设计**：命名、确定字段类型、存储过程

## 7. 主题库

为便利工作精准快速反映工作对象全貌，建立的多维度数据集合。

**三层架构：**
1. 数据源层：管理表和数据表
2. 构件层：基础构件+组合构件
3. 主题库层：统一访问接口

## 8. 数据资产管理

### 8.1 数据资源化
- 提升数据质量
- 保障数据安全
- 推动数据流通

### 8.2 数据资产化
- 扩大应用范围
- 显性化成本与效益
- 形成良性反馈闭环

### 8.3 数据资产流通

| 模式 | 说明 |
|-----|------|
| 数据共享 | 打通内部壁垒 |
| 数据开放 | 向公众提供数据 |
| 数据交易 | 合同约定交易 |

### 8.4 数据资产运营
- 持续跟踪分析
- 全面评价效果
- 正向反馈闭环

### 8.5 数据价值评估
- 经济效益
- 业务效益
- 投入成本

## 9. 数据资源编目

**三层目录：**
| 目录 | 说明 |
|-----|------|
| 资源目录 | 原始数据资源索引 |
| 资产目录 | 标准化后的数据资产 |
| 服务目录 | 可视化共享数据目录 |

## 10. 关键考点

- 数据仓库四大特征：面向主题、集成、随时间变化、不可更新
- OLAP三种类型：ROLAP、MOLAP、HOLAP
- 数据质量六指标：完整、规范、一致、准确、唯一、及时
- 数据模型三类：概念、逻辑、物理
- 关系模型三大完整性：实体、参照、用户定义
- 数据资产流通三模式：共享、开放、交易
