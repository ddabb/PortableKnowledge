# 数据挖掘

## 1. 数据挖掘概念

数据挖掘是从大量数据中提取或"挖掘"知识的过程。

**定义：** 从不完全、有噪声、模糊、海量的实际数据中，提取隐含的、潜在有用的知识。

**目标：** 将数据从低层次简单查询提升到挖掘知识、提供决策支持的高度。

## 2. 数据挖掘 vs 传统数据分析

| 对比项 | 传统数据分析 | 数据挖掘 |
|-------|-------------|---------|
| 数据量 | 相对较小 | 大量数据 |
| 分析方法 | 统计学方法 | 统计、AI、可视化、并行计算 |
| 分析侧重 | 回顾型、验证型 | 预测型、发现型 |
| 成熟度 | 相当成熟 | 部分仍处发展阶段 |

## 3. 数据挖掘任务

| 任务 | 说明 |
|-----|------|
| 数据总结 | 浓缩数据，总体综合描述 |
| 关联分析 | 找出隐藏的关联网 |
| 分类和预测 | 将数据分派到不同组 |
| 聚类分析 | 按相近程度分成有意义的子集合 |
| 孤立点分析 | 检测数据偏差 |

### 3.1 关联分析
发现数据库中两个或多个变量的取值之间存在某种规律性，生成规则带有置信度。

### 3.2 分类和预测
使用分类函数或模型，根据数据属性将数据分派到不同组，并预测新数据所属组。

### 3.3 聚类分析
按相近程度度量方法，将数据分成有意义的子集合。统计方法基于几何距离，人工智能基于概念描述。

### 3.4 孤立点分析
检测与其它记录存在偏差的异常记录。

## 4. 数据挖掘流程

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│ 确定分析 │ → │ 数据准备 │ → │ 数据挖掘 │ → │ 结果评估 │ → │ 结果应用 │
│   对象   │    │         │    │         │    │         │    │         │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
```

### 4.1 确定分析对象
- 定义清晰的挖掘对象
- 理解数据和业务问题

### 4.2 数据准备

| 内容 | 说明 |
|-----|------|
| 数据选择 | 选出适合挖掘的数据 |
| 数据预处理 | 清理、集成、变换、归约 |

### 4.3 数据挖掘

| 内容 | 说明 |
|-----|------|
| 模型构建 | 选择变量、构建新预示值、转换变量 |
| 挖掘处理 | 算法执行，分析工具自动完成 |

### 4.4 结果评估
解释和评估挖掘结果

### 4.5 结果应用
应用于实践，指导决策

## 5. 数据集成

### 5.1 集成方法

| 方法 | 说明 |
|-----|------|
| 模式集成 | 虚拟视图方法，构建全局模式 |
| 复制集成 | 复制数据到其他数据源，维护一致性 |
| 混合集成 | 保留虚拟视图+提供数据复制 |

### 5.2 数据访问接口

| 接口 | 说明 |
|-----|------|
| ODBC | 数据库访问API，基于SQL |
| JDBC | Java数据库访问 |
| OLE DB | COM数据存储对象 |
| ADO | 应用层接口 |

### 5.3 Web Services技术

**三要素：**

| 要素 | 协议 | 说明 |
|-----|------|------|
| WSDL | Web服务描述语言 | 服务接口定义 |
| SOAP | 简单对象访问协议 | 消息传递格式 |
| UDDI | 统一描述发现集成 | 服务注册发现 |

### 5.4 数据网格技术
分布式海量数据管理与分析的体系结构

**透明性：**
- 分布透明性
- 异构透明性
- 数据位置透明性
- 访问方式透明性

## 7. 数据可视化

### 7.1 可视化类型

| 类型 | 说明 |
|-----|------|
| 一维数据 | 文本、数字表格、源代码 |
| 二维数据 | 平面地图、楼层图、GIS |
| 三维数据 | 立体物体、计算机模型 |
| 多维数据 | 属性超过三维 |
| 时态数据 | 包含时间轴 |

| 网络数据 | 多路径关系 |

### 7.2 技术基础

## 8. 关键考点

- 数据挖掘目标：提取隐含的潜在有用知识
- 挖掘与传统分析区别：数据量、方法、侧重、成熟度
- 挖掘五任务：总结、关联、分类预测、聚类、孤立点
- 挖掘流程五阶段：对象→准备→挖掘→评估→应用
- 集成三方法：模式集成、复制集成、混合集成
- Web Services三要素：WSDL、SOAP、UDDI
- 数据可视化七类：一维、二维、三维、多维、时态、层次、网络
