# 数据治理

## 1. 数据治理概述

数据治理是对数字要素的管控能力，覆盖组织对数据相关活动的统筹、评估、指导和监督等工作。

**核心内容：**
- 元数据管理
- 数据标准化
- 数据质量管理
- 数据模型和建模

## 2. 元数据管理

### 2.1 元数据定义
元数据是关于数据的数据（Data About Data），是信息资源的结构化描述。

### 2.2 元数据体系

| 类型 | 说明 |
|-----|------|
| 内容元数据 | 标记数字对象内容及结构 |
| 专门元数据 | 单一数字对象的内容属性 |
| 资源集合元数据 | 信息资源集合的描述 |
| 管理元数据 | 加工、存档、技术处理信息 |
| 服务元数据 | 服务揭示与表现信息 |
| 元元数据 | 元数据的管理描述 |

### 2.3 元数据作用

| 作用 | 说明 |
|-----|------|
| 描述 | 说明数据内容、格式、质量 |
| 资源发现 | 检索和确认资源 |
| 组织管理 | 动态网页组织 |
| 互操作性 | 数据交换 |
| 归档保存 | 跟踪数字对象来源 |

## 3. 数据标准化

### 3.1 标准化内容

| 内容 | 说明 |
|-----|------|
| 元数据标准化 | 元数据格式和定义规范 |
| 数据元标准化 | 数据元素的规范 |
| 数据模式标准化 | 数据库模式规范 |
| 数据分类与编码标准化 | 分类体系与编码规范 |

### 3.2 标准化过程

```
确定数据需求 → 制定数据标准 → 批准数据标准 → 实施数据标准
```

**各阶段产出：**
- 确定需求：数据需求及元数据、域值文件
- 制定标准：数据字典、成套建议
- 批准标准：扩充或修改数据模型
- 实施标准：各信息系统实施

## 4. 数据质量管理

### 4.1 质量指标

| 指标 | 说明 |
|-----|------|
| 完整性 | 数据完整无缺失 |
| 规范性 | 符合标准规范 |
| 一致性 | 数据协调统一 |
| 准确性 | 数据正确无误 |
| 唯一性 | 无重复记录 |
| 及时性 | 数据时效性 |

### 4.2 质量评价过程

```
第一步：确定适用的数据质量定量元素及范围
    ↓
第二步：确定数据质量度量方法
    ↓
第三步：选择并使用数据质量评价方法
    ↓
第四步：确定数据质量结果
    ↓
第五步：报告数据质量结果
```

### 4.3 评价方法

| 方法 | 说明 |
|-----|------|
| 直接评价法 | 与内部或外部参照信息对比 |
| 间接评价法 | 利用数据相关信息推断 |

### 4.4 质量控制

| 阶段 | 内容 |
|-----|------|
| 前期控制 | 录入前质量控制、录入中实时控制 |
| 后期控制 | 录入完成后的后处理与评价 |

## 5. 数据脱敏

### 5.1 敏感数据
敏感数据密级划分：

| 等级 | 名称 |
|-----|------|
| L1 | 公开 |
| L2 | 保密 |
| L3 | 机密 |
| L4 | 绝密 |
| L5 | 私密 |

### 5.2 脱敏方式

| 类型 | 说明 |
|-----|------|
| 可恢复 | 可通过算法恢复 |
| 不可恢复 | 替换算法、生成算法 |

### 5.3 脱敏原则

| 原则 | 说明 |
|-----|------|
| 算法不可逆 | 防止重建原始数据 |
| 保持数据特征 | 保留分布、格式等特征 |
| 保留引用完整性 | 主键相关引用同步更改 |
| 规避融合风险 | 多源融合可能造成的风险 |
| 脱敏过程自动化 | 规则引导下自动进行 |
| 脱敏结果可重复 | 满足可测性和安全性 |

## 6. 数据分类与分级

### 6.1 数据分类
根据内容属性或特征进行区分和归类

### 6.2 数据分级

**国家数据安全分级：**

| 级别 | 影响对象 |
|-----|---------|
| 核心数据 | 国家安全、公共利益 |
| 重要数据 | 国家安全、社会秩序 |
| 一般数据 | 公共利益、个人权益 |

**影响程度：** 无危害 → 轻微危害 → 一般危害 → 严重危害

## 7. 关键考点

- 数据治理覆盖：统筹、评估、指导、监督
- 元数据类型：内容、专门、资源集合、管理、服务、元元数据
- 元数据作用：描述、发现、管理、互操作、归档
- 数据标准化四内容：元数据、数据元、数据模式、分类编码
- 标准化四阶段：需求→制定→批准→实施
- 数据质量六指标：完整、规范、一致、准确、唯一、及时
- 脱敏五原则：不可逆、特征、引用、融合、自动化
- 数据三级分类：核心、重要、一般
