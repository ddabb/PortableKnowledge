# 软件集成技术

## 1. 基础软件集成

### 1.1 操作系统

**分类：**
- 桌面/服务器/手机/嵌入式操作系统
- 批处理/实时/分时/网络/分布式操作系统

**功能：**
- 进程管理
- 存储管理
- 设备管理
- 文件管理
- 作业管理

### 1.2 数据库

**分布式数据库特点：**
- 地理上分散
- 逻辑上统一
- 注重节点自治性
- 数据分布透明性

### 1.3 中间件

**定义：** 位于操作系统和应用软件之间的系统级软件

**功能：**
- 通信支持
- 应用支持
- 公共服务

**分类：**

| 类型 | 说明 |
|-----|------|
| 事务式中间件 | 联机事务处理，并发控制、事务管理 |
| 过程式中间件 | 远程过程调用（RPC） |
| 消息中间件 | 消息队列、异步通信 |
| 面向对象中间件 | 分布对象计算 |
| 交易中间件 | 联机交易处理系统 |
| Web应用服务器 | J2EE架构 |

## 2. 应用软件集成

### 2.1 集成方式
- 接口方式相互调用
- 功能完全融合
- 单点登录

### 2.2 集成功能
- 界面集成
- 功能集成
- 接口集成
- 数据集成

### 2.3 最佳实践：SOA
面向服务的架构（SOA）是产业界公认的解决应用集成的最佳方式

## 3. 软件构件标准

### 3.1 CORBA
对象管理组织OMG制定的分布式对象计算标准

**组成：**
- ORB（对象请求代理）：核心
- 对象服务：名录、事件、生命周期、关系、事务等15种服务
- 公共功能
- 域接口
- 应用接口

### 3.2 COM/DCOM/COM+
- COM：二进制代码对象，DLL或EXE
- DCOM：分布式扩展，位置透明、网络安全
- COM+：更高层次，与操作系统结合紧密

### 3.3 .NET
- CLR：通用语言运行环境
- 基础类库（BCL）
- ADO.NET：数据库访问
- ASP.NET：网络编程

### 3.4 J2EE
**四层架构：**
1. 客户端层
2. 服务器端组件层（JSP/Servlet）
3. EJB层（商业逻辑）
4. 信息系统层（数据库）

## 4. 数据访问接口

| 接口 | 说明 |
|-----|------|
| ODBC | 数据库访问API，基于SQL |
| JDBC | Java数据库访问 |
| OLE DB | COM数据存储对象 |
| ADO | 应用层接口，VC/VB/Delphi/Web |

## 5. Web Services技术

**三要素：**

| 要素 | 协议 | 说明 |
|-----|------|------|
| WSDL | Web服务描述语言 | 服务接口定义 |
| SOAP | 简单对象访问协议 | 消息传递格式 |
| UDDI | 统一描述发现集成 | 服务注册发现 |

## 6. 关键考点

- 中间件：事务式、消息、面向对象、Web应用服务器
- CORBA：OMG制定，ORB是核心
- COM+：与操作系统结合
- .NET：CLR是基础
- J2EE：EJB层封装商业逻辑
- Web Services三要素：WSDL、SOAP、UDDI
- SOA是应用集成的最佳实践
