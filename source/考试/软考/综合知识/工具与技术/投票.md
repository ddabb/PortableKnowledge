> 投票是集体决策的常用工具，帮助团队在多个选项中做出选择。

---

## 一、投票概述

### 1.1 定义

投票是一种通过收集团队成员意见来支持决策的方法。

### 1.2 投票的价值

| 价值 | 说明 |
|------|------|
| **公平参与** | 每个人都有发言权 |
| **决策透明** | 过程和结果公开 |
| **效率提升** | 比讨论更快达成共识 |
| **可追溯** | 投票记录可追溯 |

---

## 二、投票类型

### 2.1 按投票方式

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| **赞成/反对票** | 简单二选一 | 快速决策 |
| **多选投票** | 选择多个选项 | 优先级排序 |
| **评分投票** | 给选项打分 | 需要区分优先级 |
| **排序投票** | 给选项排序 | 方案排序 |

### 2.2 按投票方式

| 类型 | 说明 |
|------|------|
| **举手投票** | 快速直观 |
| **匿名投票** | 减少政治因素 |
| **电子投票** | 便于统计 |
| **卡片投票** | 便于记录 |

## 四、Dot Voting（点投票）

### 4.1 什么是点投票

点投票是一种快速确定优先级的投票方法，每人有限数量的"点"（如3个点）分配给不同选项。

### 4.2 操作步骤

```
1. 每人获得3个点（或5个）
2. 将点贴在心仪的选项上
3. 可以全给一个选项，也可以分散
4. 统计每个选项的点数
5. 按点数排序确定优先级
```

### 4.3 示例

```
选项        | 张三 | 李四 | 王五 | 总计
----------|------|------|------|------
方案A      | ●●  | ●    | ●    | 4
方案B      | ●    | ●●   | ●●   | 5
方案C      |      |      |      | 0

结论：方案B优先
```

## 五、加权投票

### 5.1 什么是加权投票

不同投票人的票有不同权重，如项目经理的票权重更高。

### 5.2 权重设定

| 人员类型 | 权重 |
|---------|------|
| 项目经理 | 3票 |
| 技术负责人 | 2票 |
| 普通成员 | 1票 |

### 5.3 计算方法

```
方案A得分 = 2×3 + 3×2 + 5×1 = 17分
方案B得分 = 1×3 + 2×2 + 3×1 = 10分
结论：方案A优先
```

## 六、注意事项

| 注意事项 | 说明 |
|---------|------|
| **提前沟通** | 投票前充分讨论 |

| **记录结果** | 便于追溯 |
| **少数服从多数** | 但也要关注少数意见 |
