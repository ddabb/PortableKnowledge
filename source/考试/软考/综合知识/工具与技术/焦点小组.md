> 焦点小组是定性研究的核心方法，通过小组讨论深入了解用户需求、态度和偏好。

---

## 一、什么是焦点小组

### 1.1 定义

焦点小组（Focus Group）是由受过训练的主持人引导，6-10人围绕特定主题进行小组讨论的数据收集方法。

### 1.2 与个别访谈的区别

| 特征 | 焦点小组 | 个别访谈 |
|------|----------|----------|
| 人数 | 6-10人 | 1人 |
| 互动性 | 高（可相互讨论） | 低（单独对话） |
| 深度 | 中等 | 深 |
| 成本 | 较高 | 较低 |
| 数据类型 | 群体观点 | 个人观点 |

---

## 二、焦点小组的优势

| 优势 | 说明 |
|------|------|
| **协同效应** | 参与者互相激发，产生更多创意 |
| **观察真实** | 可见证参与者之间的真实互动 |
| **效率高** | 同时获取多人观点 |
| **深度洞察** | 可追问、深入挖掘 |
| **社交氛围** | 参与者更放松、更诚实 |

---

## 三、准备工作

### 3.1 确定研究目标

| 问题 | 示例 |
|------|------|
| 要回答什么问题？ | 用户对新功能的接受度？ |
| 需要了解什么？ | 用户的决策过程 |
| 预期产出是什么？ | 功能优先级建议 |

### 3.2 参与者筛选

**招募标准：**

| 标准类型 | 内容 |
|---------|------|
| 基本条件 | 年龄、性别、职业 |
| 经验要求 | 使用过相关产品 |
| 态度要求 | 愿意分享观点 |
| 排除条件 | 近期参加过类似研究 |

**招募数量：**
- 每组6-10人
- 通常需要2-3组
- 同质性高的小组更容易讨论

### 3.3 准备讨论大纲

**大纲结构示例：**

```
【开场】（5分钟）
- 欢迎词
- 自我介绍
- 说明规则（录音、保密）

【热身】（10分钟）
- 轻松话题破冰

【核心讨论】（45-60分钟）
- 话题1：使用习惯
- 话题2：痛点需求
- 话题3：改进建议

【总结】（5分钟）
- 关键发现回顾
- 补充提问
```

### 3.4 场地与设备

| 准备项 | 内容 |
|--------|------|
| 场地 | 安静、舒适、中立 |
| 座位 | 圆形或U形，便于交流 |
| 设备 | 录音/录像设备、投影、白板 |
| 材料 | 讨论用的产品原型、图片等 |

## 四、主持技巧

### 4.1 主持人角色

| 角色 | 职责 |
|------|------|
| 引导者 | 控制节奏，引导讨论 |
| 中立者 | 不表达个人意见 |
| 观察者 | 观察非语言反应 |

### 4.2 提问技巧

**好的开场问题：**
- "请介绍一下你们平时是怎么......"
- "大家对这个话题有什么看法？"

**追问技巧：**
- "能详细说说吗？"
- "其他人有不同看法吗？"
- "如果...会怎么样？"

### 4.3 控制讨论

| 情况 | 应对方法 |
|------|----------|
| 有人主导全场 | "我们听听其他人的意见" |
| 有人沉默 | 直接提问，邀请发言 |
| 偏离主题 | "这个问题很有意思，我们回头再聊，回到刚才的话题" |
| 激烈争论 | "两种观点都有道理，我们的目的是..." |

### 4.4 避免的错误

❌ **避免：**
- 暗示正确答案
- 让一个人主导
- 主导参与者意见
- 时间失控

## 五、结果分析

### 5.1 分析方法

| 方法 | 说明 |
|------|------|
| 主题编码 | 提取关键主题 |
| 意见分类 | 按态度分组（正面/负面/中性） |
| 引用提炼 | 提取有代表性的原话 |
| 交叉分析 | 对比不同小组的差异 |

### 5.2 分析步骤

1. **转录整理** - 录音/录像转为文字
2. **阅读熟悉** - 通读全文，把握整体
3. **主题提炼** - 找出反复出现的观点
4. **归类整理** - 按主题分类
5. **洞察提炼** - 从数据上升到洞察

### 5.3 产出报告

| 内容 | 说明 |
|------|------|
| 执行摘要 | 关键发现一览 |
| 方法说明 | 参与者信息、研究过程 |
| 详细发现 | 按主题描述 |
| 引用语录 | 有代表性的原话 |
| 建议 | 基于发现的行动建议 |

---

## 六、注意事项

1. **样本代表性** - 每组选择有代表性的人群
2. **不要过分解读** - 定性研究看趋势，不是统计
3. **多组对比** - 至少2-3组验证一致性
4. **及时整理** - 结束后尽快整理分析
5. **保密原则** - 参与者信息保密

## 八、与头脑风暴的区别

| 对比项 | 焦点小组 | 头脑风暴 |
|--------|----------|----------|
| 目的 | 收集意见 | 生成创意 |
| 主持人 | 必须 | 可选 |
| 问题类型 | 讨论式 | 开放式的创意问题 |
| 结果 | 洞察和观点 | 新想法和方案 |
