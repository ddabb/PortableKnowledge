> 访谈是最重要的定性数据收集方法之一，广泛用于需求获取、用户研究和市场调研。

---

## 一、什么是访谈

### 1.1 定义

访谈是通过与受访者直接交流来获取信息的定性研究方法。

### 1.2 访谈类型

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| **结构化访谈** | 按预设问题提问 | 问卷式调查 |
| **半结构化访谈** | 有大纲但灵活调整 | 深度需求获取 |
| **非结构化访谈** | 自由聊天式 | 探索性研究 |

**项目管理中最常用：半结构化访谈**

---

## 二、准备工作

### 2.1 确定访谈目标

| 问题 | 答案示例 |
|------|----------|
| 要获取什么信息？ | 用户的工作流程、痛点 |
| 访谈对象是谁？ | 一线操作员 |
| 需要多少人？ | 5-8人 |

### 2.2 准备访谈大纲

**大纲结构示例：**

```
1. 开场（5分钟）
   - 自我介绍
   - 说明目的
   - 征得同意录音

2. 基本情况（10分钟）
   - 工作内容
   - 使用系统情况

3. 核心问题（30分钟）
   - 痛点问题
   - 改进建议

4. 总结确认（5分钟）
   - 总结要点
   - 补充提问
```

### 2.3 访谈前准备

| 准备项 | 内容 |
|--------|------|
| 预约时间 | 提前1-3天预约 |
| 确认地点 | 办公室/会议室/线上 |
| 准备设备 | 录音笔/笔记本 |
| 背景资料 | 提前了解受访者情况 |

## 三、提问技巧

### 3.1 开放式提问

**特点：** 不能用是/否回答

**示例：**
- "请描述一下您每天的工作流程"
- "您对这个系统最不满意的地方是什么？"

### 3.2 封闭式提问

**特点：** 可以用是/否或简短回答

**示例：**
- "您每天使用这个系统多少次？"
- "这个问题出现频率高吗？"

### 3.3 追问技巧

| 类型 | 示例 |
|------|------|
| 澄清追问 | "您说的'不方便'具体是指什么？" |
| 深挖追问 | "能举个具体的例子吗？" |
| 假设追问 | "如果是这种情况，您会怎么处理？" |

### 3.4 避免的问题

❌ **避免：**
- 引导性提问（"您应该觉得不好用吧？"）
- 多重问题（"你觉得功能怎么样，贵不贵？"）
- 专业术语（用受访者的语言）

## 四、访谈技巧

### 4.1 倾听技巧

| 技巧 | 说明 |
|------|------|
| 积极倾听 | 点头、眼神交流 |
| 适当沉默 | 给受访者思考时间 |
| 记录关键词 | 不要埋头狂写 |

### 4.2 非语言技巧

| 要素 | 建议 |
|------|------|
| 眼神 | 自然注视，不要盯看 |
| 表情 | 保持中性或微笑 |
| 坐姿 | 身体前倾表示关注 |
| 语速 | 放慢，让受访者跟上 |

### 4.3 应对特殊情况

| 情况 | 应对方法 |
|------|----------|
| 受访者紧张 | 先聊轻松话题 |
| 受访者话多 | 巧妙引导回主题 |
| 受访者抗拒 | 换话题或暂停 |
| 意见分歧 | 记录，不争论 |

## 五、访谈记录

### 5.1 记录要点

| 记录类型 | 内容 |
|---------|------|
| 事实 | 具体的行为、流程 |
| 观点 | 受访者的看法 |
| 情绪 | 表达时的语气、表情 |
| 隐含需求 | 没说但暗示的需求 |

### 5.2 记录方式

| 方式 | 优点 | 缺点 |
|------|------|------|
| 手写笔记 | 快速 | 不完整 |
| 录音 | 完整 | 需要转录 |
| 录音+笔记 | 完整且有重点 | 工作量大 |

**建议：** 录音 + 关键词笔记

## 六、结果分析

### 6.1 分析步骤

1. **转录整理** - 将录音转为文字
2. **分类归纳** - 按主题分类
3. **提炼观点** - 找出核心发现
4. **验证核实** - 与受访者确认

### 6.2 分析方法

| 方法 | 说明 |
|------|------|
| 主题分析 | 找出重复出现的主题 |
| 亲和图 | 将相似观点归类 |
| 编码分析 | 给观点贴标签归类 |

### 6.3 产出文档

| 文档 | 内容 |
|------|------|
| 访谈记录 | 原始对话记录 |
| 访谈摘要 | 关键发现总结 |
| 需求清单 | 提炼出的需求列表 |

---

## 七、注意事项

1. **取得同意** - 开始前说明目的，征得录音同意
2. **保持中立** - 不要引导受访者
3. **多听少说** - 访谈是收集，不是演讲
4. **及时整理** - 访谈后24小时内整理记录
5. **交叉验证** - 多访谈几个人验证一致性

## 八、项目管理应用场景

| 场景 | 访谈目的 |
|------|----------|
| 需求获取 | 了解用户工作流程和痛点 |
| 干系人管理 | 了解相关方期望 |
| 经验教训 | 访谈老员工获取经验 |
| 风险识别 | 访谈专家识别风险 |
