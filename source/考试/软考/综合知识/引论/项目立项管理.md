# 项目立项管理

## 概述

项目立项管理是对拟规划和实施的项目在技术上的先进性、适用性，经济上的合理性、效益性，实施上的可能性、风险性，以及社会价值的有效性、可持续性等方面进行全面科学的综合分析，为项目决策提供客观依据的一种技术经济研究活动。

一般包括三个阶段：
1. 项目建议与立项申请
2. 项目可行性研究
3. 项目评估与决策

## 项目立项流程

```
项目建议与立项申请 → 初步可行性研究 → 详细可行性研究 → 项目评估与决策
```

注意：
- 初步可行性研究和详细可行性研究可以合二为一
- 详细可行性研究是必不可少的
- 升级改造项目只做初步和详细可行性研究
- 小项目一般只进行详细可行性研究

## 项目建议与立项申请

### 概念

立项申请（项目建议书）是项目建设单位向上级主管部门提交项目申请时所必需的文件，是对拟建项目提出的框架性总体设想。

### 核心作用

- 是项目发展周期的初始阶段产物
- 是国家或上级主管部门选择项目的依据
- 是可行性研究的依据
- 涉及利用外资的项目，在获得批准后，方可开展后续工作

### 项目建议书内容

核心内容：
1. 项目的必要性
2. 项目的市场预测
3. 项目预期成果（如产品方案或服务）的市场预测
4. 项目建设必需的条件

## 项目可行性研究

### 定义

可行性研究是在项目建议书被批准后，对技术、经济、社会和人员等方面的条件和情况进行调查研究，对可能的技术方案进行论证，以最终确定整个项目是否可行。

### 特点

- 预见性
- 公正性
- 可靠性
- 科学性

### 可行性研究内容

#### 1. 技术可行性分析

考虑因素：
- **开发风险**：能否设计出预期的系统并实现功能
- **人力资源有效性**：能否建立技术队伍
- **技术能力的可能性**：技术发展是否支持
- **物资可用性**：是否存在可用资源

#### 2. 经济可行性分析

主要包括：
- **支出分析**：
  - 一次性支出（开发费、培训费、差旅费等）
  - 非一次性支出（租金、人员工资福利、水电费等）
- **收益分析**：
  - 直接收益（销售收入）
  - 间接收益（成本降低）
  - 其他收益（知识产权、软件著作权）
- **投资回报分析**：收益投资比、投资回收期
- **敏感性分析**：关键因素变化时的影响估计

#### 3. 社会效益可行性分析

**对组织内部**：
- 品牌效益
- 竞争力效益
- 技术创新效益
- 人员提升收益
- 管理提升效益

**对社会发展**：
- 公共效益
- 文化效益
- 环境效益
- 社会责任感效益
- 其他收益（如国防能力）

#### 4. 运行环境可行性分析

评估因素：
- 用户的管理体制、管理方法
- 规章制度、工作习惯
- 人员素质
- 数据资源积累
- 基础软硬件平台

#### 5. 其他可行性分析

- 法律可行性
- 政策可行性

### 初步可行性研究

#### 目的

衡量、决定是否开始详细可行性研究

#### 回答的问题

- 项目进行投资建设是否具有必要性
- 项目建设的周期是否合理且可接受
- 项目需要的人力、财力资源等是否可接受
- 项目的功能和目标是否可以实现
- 项目的经济效益、社会效益是否可以保证
- 项目从经济上、技术上是否是合理的

#### 主要内容

- 需求与市场预测
- 设备与资源投入分析
- 空间布局
- 项目设计
- 项目进度安排
- 项目投资与成本估算

### 详细可行性研究

#### 依据

- 国民经济和社会发展的长期规划
- 国家和地区的相关政策、法律、法规和制度
- 项目主管部门对项目设计开发建设要求请示的批复
- 项目建议书或批准后签订的意向性协议
- 国家、地区、组织的信息化规划和标准
- 市场调研分析报告
- 技术、产品或工具的有关资料

#### 原则

1. **科学性原则**：按客观规律办事，运用科学方法和认真态度
2. **客观性原则**：坚持从实际出发、实事求是
3. **公正性原则**：站在公正的立场上，不偏不倚

#### 方法

- **投资估算法**：
  - 数量性估算（比例估算法）
  - 研究性估算
  - 预算性估算
  - 投标估算
- **增量净效益法（有无比较法）**：将有无项目时的成本效益进行比较

#### 内容

1. 市场需求预测
2. 部件和投入的选择供应
3. 信息系统架构及技术方案的确定
4. 技术与设备选择
5. 网络物理布局设计
6. 投资、成本估算与资金筹措
7. 经济评价及综合分析

#### 投资估算精度要求

| 阶段 | 精度要求 |
|------|----------|
| 毛估和粗估 | ±30% |
| 初步可行性研究 | ±20% |
| 详细可行性研究 | ±10% |
| 设计开发 | ±5% |

#### 经济评价

- **组织经济评价**：使用静态评价方法（投资收益率、回收期）和动态评价方法（净现值法、内部收益率法）
- **国民经济评价**：从国民经济角度评估

## 项目评估与决策

### 概念

项目评估指在项目可行性研究的基础上，由第三方（国家、银行或有关机构）对拟建项目进行评价、分析和论证，判断其是否可行。

### 目的

审查项目可行性研究的可靠性、真实性和客观性，为银行的贷款决策或行政主管部门的审批决策提供科学依据。

### 依据

- 项目建议书及其批准文件
- 项目可行性研究报告
- 报送组织的申请报告及主管部门的初审意见
- 项目关键建设条件和工程等的协议文件
- 必需的其他文件和资料

### 程序

1. 成立评估小组，制订评估工作计划
2. 开展调查研究，收集数据资料
3. 进行分析与评估
4. 编写、讨论、修改评估报告
5. 召开专家论证会
6. 评估报告定稿并发布

### 主要内容

- 项目与组织概况评估
- 项目建设的必要性评估
- 项目建设规模评估
- 资源、配件、燃料及公用设施条件评估
- 网络物理布局条件和方案评估
- 技术和设备方案评估
- 信息安全评估
- 安装工程标准评估
- 实施进度评估
- 项目组织、劳动定员和人员培训计划评估
- 投资估算和资金筹措
- 项目的财务经济效益评估
- 国民经济效益评估
- 社会效益评估
- 项目风险评估

### 成果

项目评估的最终成果是**项目评估报告**，大纲包括：
1. **项目概况**：包括基本情况、综合评估结论
2. **详细评估意见**
3. **总结和建议**：存在或遗留的重大问题、潜在的风险及建议
