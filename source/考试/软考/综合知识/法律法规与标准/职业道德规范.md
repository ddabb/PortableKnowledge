## 道德与职业道德

### 道德

**道德**是由一定的社会经济关系所决定的特殊意识形态，是自己管自己的一组规矩。

**道德的主要特点**：
- 主要功能是规范人们的思想和行为
- 依靠舆论、信念和习俗等**非强制性手段**起作用
- 以**善恶观念**为标准来评价人们的思想和行为

### 职业道德

职业道德是所有从业人员在职业活动中应该遵循的行为准则，涵盖了从业人员与服务对象、职业与职工、职业与职业之间的关系。

**职业道德主要内容**：
- 爱岗敬业
- 诚实守信
- 办事公道
- 服务群众
- 奉献社会

### 职业道德的特征

| 特征 | 说明 |
|-----|------|
| **职业性** | 必须通过从业者在职业活动中体现 |
| **普遍性** | 从业人员范围广大，决定职业道德具有普遍性 |
| **自律性** | 通过学习和实践产生职业道德意识，形成行为上的高度自觉 |
| **他律性** | 具有影响舆论的特征 |
| **行业性和多样性** | 各行各业都有适合自身特点的职业道德规范 |
| **继承性和稳定性** | 反映职业关系时与社会风俗、民族传统文化相联系 |
| **实践性** | 必须通过职业实践活动表现出来 |

## 项目管理工程师职业道德规范

### 核心行为准则

**基本要求**：
- 爱岗敬业、遵纪守法、诚实守信、办事公道、与时俱进
- 梳理流程、建立体系、量化管理、优化改进、不断积累
- 对项目负管理责任，计划指挥有方，全面全程监控，善于解决问题，沟通及时到位

**价值创造**：
- 为客户创造价值
- 为雇主创造利润
- 为组员创造机会
- 合作多赢

### 工作态度

- 积极进行团队建设
- 公平、公正、无私地对待每位项目团队成员
- 平等与客户相处，与客户协同工作时注重礼仪
- 公务消费应合理并遵守有关标准

## 项目管理工程师岗位职责

### 主要职责

1. **不断提高个人的项目管理能力**：
   - 在工作中表现出诚实正直的态度
   - 主动采用项目管理理念和方法
   - 提升个人的项目管理能力
   - 平衡项目干系人的利益
   - 以合作和职业化方式与团队和项目干系人打交道

2. 贯彻执行国家和项目所在地政府的有关法律、法规和政策
3. 执行所在单位的各项管理制度和有关技术规范标准
4. 对信息系统项目的全生命周期进行有效控制，确保项目质量和工期，努力提高经济效益
5. 严格执行财务制度，加强财务管理，严格控制项目成本
6. 执行所在单位规定的应由项目管理工程师负责履行的各项条款

### 权利

- 组织项目团队
- 组织制订信息系统项目计划，协调管理项目相关的人力、设备等资源
- 协调信息系统项目内外部关系，受委托签署有关合同、协议或其他文件

## 项目管理工程师对项目团队的责任

### 高效项目团队特征

- 建立了明确的项目目标
- 建立了清晰的团队规章制度
- 建立了学习型团队
- 培养团队成员养成严谨细致的工作作风
- 团队成员分工明确
- 建立勇于承担责任、和谐协作的团队文化
- 善于利用项目团队中的非正式组织来提高团队的凝聚力

### 团队价值观

| 价值观 | 说明 |
|-------|------|
| **信任** | 建立团队互信机制 |
| **遵守纪律** | 规范工作行为 |
| **良好沟通** | 建立方便有效的沟通机制与氛围 |
| **求同存异** | 尊重差异 |
| **经验共享** | 鼓励交流与共享 |
| **结果导向** | 关注工作成效 |
| **勇于创新** | 鼓励创新思维 |

## 提升个人道德修养水平

### 道德修养的重要性

道德修养对于工作和生活同样重要。"做事先做人"强调个人道德修养在工作中的重要性。

### 提升途径

1. **以身作则**：公平、公正，乐观、自信，为团队成员起到表率和榜样的作用
2. **严于律己**：要求别人做到的事情，自己首先要做到；己所不欲，勿施于人
3. **主动担当**：积极主动地领导团队、承担责任，表现出"舍我其谁"的工作气魄
4. **持续学习**：善于学习，不断提升自身的道德修养水平
5. **每日反思**：学习传统文化中的"吾日三省吾身"精神

### 传统文化中的道德修养

- **《易经》**："天行健，君子以自强不息"（乾卦）；"地势坤，君子以厚德载物"（坤卦）
- **《论语》**："吾日三省吾身——为人谋而不忠乎？与朋友交而不信乎？传不习乎"
- **《礼记》**："身修而后家齐，家齐而后国治"

### 注意事项

从事系统集成项目管理工作面临的问题包括：
- 项目干系人多
- 需求复杂
- 项目复杂多变
- 人员普遍年轻
- 加班成为家常便饭

在这些特殊环境中，项目管理工程师更应该重视个人道德修养的培养和提升。
