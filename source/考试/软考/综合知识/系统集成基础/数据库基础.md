## 关系型数据库基本概念

- **关系**：二维表
- **元组**：行（记录）
- **属性**：列（字段）
- **主键**：唯一标识一条记录的字段或字段组合，不能为NULL
- **外键**：引用另一张表主键的字段，实现表间关联
- **索引**：提高查询速度，但会降低写入速度

## 三大范式

| 范式 | 要求 | 解决问题 |
|------|------|---------|
| 1NF | 每个属性不可再分（原子性） | 消除重复组 |
| 2NF | 满足1NF + 非主属性完全依赖于主键 | 消除部分依赖 |
| 3NF | 满足2NF + 非主属性不传递依赖于主键 | 消除传递依赖 |

**考点**：范式越高，冗余越少，但查询时JOIN越多，性能下降。实际设计中适当反范式化。

## SQL核心语句

```sql
-- 查询
SELECT 字段 FROM 表 WHERE 条件 GROUP BY 字段 HAVING 条件 ORDER BY 字段;

-- 插入
INSERT INTO 表(字段1, 字段2) VALUES (值1, 值2);

-- 更新
UPDATE 表 SET 字段=值 WHERE 条件;

-- 删除
DELETE FROM 表 WHERE 条件;

-- 创建表
CREATE TABLE 表名 (字段名 类型 约束);
```

## 事务的ACID特性

| 特性 | 说明 |
|------|------|
| **原子性（A）** | 事务中所有操作要么全做，要么全不做 |
| **一致性（C）** | 事务执行前后数据库处于一致状态 |
| **隔离性（I）** | 并发事务互不干扰 |
| **持久性（D）** | 提交后的事务永久保存 |

## 数据库三级模式

- **外模式（用户视图）**：用户看到的局部数据
- **概念模式（逻辑模式）**：全体用户的公共视图，DBA管理
- **内模式（存储模式）**：数据在磁盘上的存储方式

**两级映像**：外模式/概念模式映像（逻辑独立性）、概念模式/内模式映像（物理独立性）

## 数据仓库 vs 数据库

| 对比项 | 数据库（OLTP） | 数据仓库（OLAP） |
|-------|--------------|----------------|
| 面向 | 事务处理 | 分析决策 |
| 数据量 | 当前数据 | 历史数据 |
| 操作 | 增删改查 | 主要是查询 |
| 设计 | 范式化 | 星型/雪花型 |

## 备份策略

- **完全备份**：备份所有数据，恢复简单，耗时最长
- **增量备份**：只备份上次备份后的变化，耗时短，恢复复杂
- **差异备份**：备份上次完全备份后的所有变化，折中方案
