# 数据集成

## 1. 数据集成概述

数据集成是将驻留在不同数据源中的数据进行整合，向用户提供统一的数据视图。

**数据源特点：**
- 存储位置分散
- 数据类型异构
- 数据库产品多样

**目标：**
- 保持数据源自治性
- 维护整体一致性
- 提高共享利用效率

## 2. 数据集成方法

### 2.1 模式集成

**定义：** 又称虚拟视图方法，是最早采用的数据集成方法

**核心思想：**
- 构建全局模式（Global Schema）
- 描述数据源共享数据的结构、语义、操作
- 用户向集成系统提交请求
- 系统转换为数据源本地视图执行

### 2.2 复制集成

**定义：** 将数据复制到相关数据源，维护整体一致性

**特点：**
- 整个数据源或变化数据的复制
- 减少对异构数据源的访问
- 提高系统性能

### 2.3 混合集成

**定义：** 保留虚拟视图+提供数据复制

**策略：**
- 简单访问请求：通过复制方式在本地实现
- 复杂访问请求：使用模式集成方法

## 3. 数据访问接口

### 3.1 ODBC

**定义：** 开放数据库连接，业界广泛接受的数据库访问API

**组成：**
- 应用程序接口
- 驱动程序管理器
- 驱动程序
- 数据源

**基础：** X/Open和ISO/IEC调用接口规范，使用SQL

### 3.2 JDBC

**定义：** Java数据库连接，用于执行SQL语句的Java应用程序接口

**特点：**
- Java语言编写
- 可向任何关系数据库发送SQL
- 与平台和数据库系统无关

### 3.3 OLE DB

**定义：** 基于COM的数据存储对象

**特点：**
- 能操作所有类型数据
- 支持离线数据存取

### 3.4 ADO

**定义：** ActiveX数据对象，应用层接口

**特点：**
- 应用场合广泛
- VC、VB、Delphi、Web开发
- 易于学习使用

## 4. Web Services数据集成

### 4.1 技术架构

**三要素：**

| 要素 | 协议 | 说明 |
|-----|------|------|
| WSDL | Web服务描述语言 | 服务接口、传输方式、方法参数 |
| SOAP | 简单对象访问协议 | 消息传递格式、XML |
| UDDI | 统一描述发现集成 | 服务注册发现目录 |

### 4.2 SOAP协议功能

- 定义传递信息的XML格式
- 远程对象方法调用格式
- 参数类型与XML映射
- 异常处理

### 4.3 UDDI功能
- 集中存放和查找WSDL描述文件
- 服务目录服务器
- 服务注册发布与查找

## 5. 数据网格技术

### 5.1 定义
用于大型数据集的分布式管理与分析的体系结构

### 5.2 目标
- 统一存储、管理、访问、传输与服务
- 透明访问分布异构数据资源
- 解决数据密集型计算问题

### 5.3 透明性特征

| 类型 | 说明 |
|-----|------|
| 分布透明性 | 用户感觉不到数据分布 |
| 异构透明性 | 感觉不到存储、格式、管理不同 |
| 数据位置透明性 | 无须知道数据源位置 |
| 访问方式透明性 | 不同系统访问方式不同但结果相同 |

## 7. ETL技术

### 7.1 ETL定义
数据抽取（Extract）、转换（Transform）、加载（Load）

### 7.2 主要功能
- 从源系统抽取数据
- 数据清洗和转换
- 加载到目标数据仓库

## 8. 关键考点

- 数据集成三方法：模式集成、复制集成、混合集成
- 模式集成核心：构建全局模式
- 复制集成目的：减少访问、提高性能
- ODBC基于SQL，是数据库访问API
- JDBC用于Java，平台无关
- Web Services三要素：WSDL、SOAP、UDDI
- SOAP：消息传递协议，XML格式
- 数据网格四透明性：分布、异构、位置、访问
