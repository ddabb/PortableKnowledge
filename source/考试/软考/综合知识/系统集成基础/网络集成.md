# 网络集成

## 1. 网络系统集成概念

网络系统集成是根据场景化应用需要，运用技术、管理等手段，将网络基础设施、网络设备、网络系统软件、网络基础服务系统及计算机软硬件设备等组织集成为一体的过程。

**目标：** 完整、可靠、经济、安全、高效的计算机网络系统

## 2. 网络集成体系框架

| 子系统 | 说明 |
|-------|------|
| 传输子系统 | 网络信息的"公路"和"血管" |
| 交换子系统 | 局域网、城域网、广域网交换 |
| 网管子系统 | 网络管理，保证良好运行 |
| 安全子系统 | 防火墙、加密、访问控制 |

## 3. 传输子系统

### 3.1 传输介质

**有线传输介质：**
- 双绞线
- 同轴电缆
- 光纤

**无线传输介质：**
- 无线电波
- 微波
- 红外线

## 4. 交换子系统

### 4.1 局域网交换技术

| 类型 | 说明 |
|-----|------|
| 共享式局域网 | 共享高速传输介质（以太网、令牌环、FDDI） |
| 交换式局域网 | 以帧或信元为交换单位，硬件交换电路 |

### 4.2 城域网交换技术
宽带城域网：以IP和ATM电信技术为基础，光纤为传输介质

### 4.3 广域网交换技术

| 技术 | 说明 |
|-----|------|
| 电路交换 | 专用通信线路，恒定速率，时延小，利用率低 |
| 报文交换 | 以报文为单位，存储转发，利用率高，时延大 |
| 分组交换 | 固定长度分组，存储转发，效率高、时延低 |
| 混合交换 | 同时使用电路和分组交换（ATM） |

## 9. 关键考点

- 网络系统集成目标：完整、可靠、经济、安全、高效
- 网络四大子系统：传输、交换、网管、安全
- 局域网技术：共享式vs交换式
- 广域网四技术：电路、报文、分组、混合交换
- 安全三技术：防火墙、加密、访问控制
- 服务器集成考虑因素：CPU、内存、磁盘、容错、网络、软件
- 存储集成考虑因素：RAID、IOPS、冗余
