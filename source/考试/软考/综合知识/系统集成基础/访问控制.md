# 访问控制

## 1. 访问控制概述

### 1.1 定义
访问控制是防止未授权访问的机制，控制主体对客体的访问。

### 1.2 基本要素

| 要素 | 说明 |
|-----|------|
| 主体 | 提出访问请求的实体（用户、进程） |
| 客体 | 被访问的资源（文件、数据、设备） |
| 访问权限 | 读、写、执行、删除等 |

### 1.3 访问控制流程
```
认证主体身份 → 确定访问权限 → 实施访问控制 → 审计记录
```

## 2. 访问控制模型

### 2.1 DAC（自主访问控制）

**特点：** 资源所有者自主决定访问权限

**实现方式：**
- 访问控制列表（ACL）
- 能力表（Cap）

**优点：**
- 灵活性高
- 易于实现

**缺点：**
- 安全性较低
- 权限传播难以控制

### 2.2 MAC（强制访问控制）

**特点：** 系统强制执行访问权限，基于安全标签

**安全标签：**
- 密级（绝密、机密、秘密、公开）
- 范畴（部门、项目）

**规则：**
- 下读：主体级别≥客体级别
- 上写：主体级别≤客体级别

**应用场景：**
- 军事系统
- 政府机密系统

**优点：**
- 安全性高
- 集中管理

**缺点：**
- 灵活性低

### 2.3 RBAC（基于角色的访问控制）

**核心概念：**

| 概念 | 说明 |
|-----|------|
| 用户 | 系统的使用者 |
| 角色 | 职责相关的权限集合 |
| 权限 | 对客体的访问许可 |
| 会话 | 用户激活角色的过程 |

**管理模型：**
```
用户 → 角色分配 → 角色
权限 → 角色分配 → 权限
用户 → 会话 → 激活角色
```

**优点：**
- 简化权限管理
- 最小权限原则
- 职责分离
- 便于审计

**类型：**
- 核心RBAC
- 层次RBAC
- 约束RBAC

### 2.4 ABAC（基于属性的访问控制）

**属性类型：**
| 类型 | 示例 |
|-----|------|
| 主体属性 | 部门、职位、时间 |
| 客体属性 | 所有者、密级 |
| 环境属性 | 时间、地点、风险级别 |
| 操作属性 | 读、写、删除 |

**优点：**
- 灵活性高
- 细粒度控制
- 适应动态环境

**策略语言：**
- XACML
- ALFA

## 3. 访问控制策略

### 3.1 最小权限原则
只授予完成任务所需的最小权限

### 3.2 职责分离原则
分离相互冲突的职责

### 3.3 默认拒绝原则
未明确允许的访问均被拒绝

### 3.4 纵深防御原则
多层访问控制机制

## 4. 常见访问控制机制

### 4.1 访问控制列表（ACL）

| 项目 | 说明 |
|-----|------|
| 定义 | 绑定到客体的权限列表 |
| 内容 | 主体+权限 |
| 应用 | 文件系统、网络设备 |

### 4.2 能力表（Cap）

| 项目 | 说明 |
|-----|------|
| 定义 | 绑定到主体的权限列表 |
| 内容 | 客体+权限 |
| 特点 | 用户持有 |

### 4.3 矩阵模型
行：主体
列：客体
单元格：权限

## 5. 特权管理

### 5.1 特权账号类型
- 超级管理员（root/admin）
- 系统管理员
- 数据库管理员
- 网络管理员

### 5.2 特权访问管理（PAM）
- 特权账号发现
- 密码保管
- 会话监控
- 审计记录

### 5.3 最小特权实践
- Just-in-Time（JIT）访问
- 特权提升
- 临时权限

## 6. 授权与审计

### 6.1 授权管理
- 集中式授权
- 委托式授权
- 基于角色授权

### 6.2 审计追踪
- 访问日志
- 变更日志
- 异常告警

## 7. 关键考点

- 访问控制三要素：主体、客体、权限
- DAC：资源所有者自主决定，ACL/能力表
- MAC：系统强制，基于安全标签，下读上写
- RBAC：基于角色，用户-角色-权限，用户-会话-角色
- ABAC：基于属性，主体/客体/环境/操作属性
- 最小权限原则：只授予最小必要权限
- 职责分离：分离相互冲突职责
- RBAC优点：简化管理、最小权限、职责分离、便于审计
