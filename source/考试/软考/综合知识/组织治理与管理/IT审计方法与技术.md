# IT审计方法与技术

## IT审计风险

### 三种风险类型

| 风险类型 | 理解 | 含义 | 特点 |
|----------|------|------|------|
| **固有风险** | 系统天生自带的风险，如复杂架构 | 不进行相关控制，易导致重大错误的风险 | 只能评估，无法影响和控制；审计人员只能评估 |
| **控制风险** | 内控没拦住的风险，如权限管理漏洞 | 内控体系不能及时预防或检查出存在的重大错误 | 与内控制度有关，与审计无关；只能评估 |
| **检查风险** | 审计没查出来的风险，如工具漏扫 | 通过预定审计程序未能发现重大错误的风险 | 影响因素：IT审计规范不完善、审计人员自身或技术原因 |

> **总体审计风险** = 固有风险 × 控制风险 × 检查风险

### IT审计风险分类

| 分类 | 说明 |
|------|------|
| 组织层面控制 | 整体的内部控制环境 |
| 一般控制 | IT通用控制（系统开发、安全、运维等） |
| 应用控制 | 业务应用层面的控制 |

## IT审计常用方法

| 方法 | 说明 |
|------|------|
| **访谈法** | 与相关人员面谈获取信息 |
| **调查法** | 问卷调查收集信息 |
| **检查法** | 审查文件、记录 |
| **观察法** | 实地查看操作 |
| **测试法** | 验证控制有效性 |
| **程序代码检查法** | 代码级审查 |

> **口诀：** 谈恋爱调情，观察、检查、测试程序

## IT审计常用技术

| 技术 | 说明 |
|------|------|
| **风险评估技术** | SWOT（识别）、定性和定量（分析）、单因素和总体风险（评价）、冗余灾备熔断限流（应对） |
| **审计抽样技术** | 从总体中选取样本进行测试，推断总体特征 |
| **计算机辅助审计技术** | 以计算机为工具执行和完成审计程序 |
| **大数据审计技术** | 运用大数据技术方法和工具，开展数据挖掘与分析 |

> **口诀：** 大抽风机（大数据、抽样、风险评估、计算机辅助）

## IT审计证据

**定义：** 审计机构和审计人员获取的，用于确定所审计实体或数据是否遵循既定标准或目标，形成审计结论的证明材料。

**五大特性：**
1. **充分性** - 证据数量足够
2. **客观性** - 客观存在的事实
3. **相关性** - 与审计目标相关
4. **可靠性** - 可信度高
5. **合法性** - 合法获取

## 审计工作底稿

**定义：** 审计人员对制订的审计计划、实施的审计程序、获取的相关审计证据，以及得出的审计结论做出的记录。

**三大分类：**

| 类型 | 说明 |
|------|------|
| **综合类工作底稿** | 整个审计工作的记录和资料 |
| **业务类工作底稿** | 执行具体程序形成的（实施阶段） |
| **备查类工作底稿** | 仅具有备查作用 |

**作用：**
- 形成审计结论、发表审计意见的直接依据
- 评价考核审计人员的主要依据
- 审计质量控制与监督的基础
- 对未来审计业务具有参考备查作用

## 关键考点

1. IT审计风险：**固有风险、控制风险、检查风险**（不包括审计风险本身）
2. 固有风险是系统**天生自带**的风险
3. 控制风险与**内控制度**有关，与审计无关
4. IT审计常用技术：**风险评估、抽样、计算机辅助、大数据审计**
