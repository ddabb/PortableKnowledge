# IT审计流程

## IT审计四大阶段

> **口诀：** 倒提宝龟

### 1. 审计准备阶段

| 活动 | 说明 |
|------|------|
| 明确审计目的及任务 | 定目的 |
| 组建审计项目组 | 组团队 |
| 搜集相关信息 | 集信息 |
| 编制审计计划等 | 编计划 |

### 2. 审计实施阶段

| 活动 | 说明 |
|------|------|
| 深入调查并调整审计计划 | 调计划 |
| 了解并初步评估IT内部控制 | 评内控 |
| 进行符合性测试 | 测符合 |
| 进行实质性测试 | 测实质 |

### 3. 审计终结阶段

| 活动 | 说明 |
|------|------|
| 整理与复核审计工作底稿 | 稿证据 |
| 整理审计证据 | - |
| 评价相关IT控制目标的实现 | 评目标 |
| 判断并报告审计发现 | 报发现 |
| 沟通审计结果 | - |
| 出具审计报告 | - |
| 归档管理等 | 结报归 |

### 4. 后续审计阶段

检查被审计单位对审计问题和建议是否已采取了适当的纠正措施，并取得了预期效果。

**注意：** 后续审计**不是一次新的审计**，而是前一次审计的有机组成部分。

## IT审计业务分类

### IT内部控制审计

| 类型 | 说明 |
|------|------|
| **组织层面IT控制审计** | 整体内控环境 |
| **一般控制审计** | IT通用控制 |
| **应用控制审计** | 业务应用控制 |

### IT专项审计

| 类型 | 说明 |
|------|------|
| 信息系统生命周期审计 | 开发、运行维护 |
| 信息系统开发过程审计 | 建设阶段 |
| 信息系统运行维护审计 | 运维阶段 |
| 网络与信息安全审计 | 安全相关 |
| 信息系统项目审计 | 项目管理 |
| 数据审计 | 数据质量与安全 |

## 关键考点

1. IT审计四大阶段：**准备、实施、终结、后续审计**
2. 审计实施阶段工作：**深入调查并调整审计计划、了解并初步评估IT内部控制、进行符合性测试、进行实质性测试**
3. 后续审计**不是**一次新的审计
4. IT内部控制审计包括：**组织层面IT控制、一般控制、应用控制**
