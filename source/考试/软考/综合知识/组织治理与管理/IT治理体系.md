# IT治理体系

## IT治理体系框架

IT治理体系回答五个核心问题：

| 问题 | 内容 |
|------|------|
| **做什么？** | IT治理的目标 |
| **由谁来做？** | IT组织架构 |
| **怎么做？** | 统筹、评估、指导、监督 |
| **做的效果如何？** | 内外评价 |
| **关键决策** | 决策、投资、风险、绩效、管理 |

## IT治理体系六大构成

| 构成要素 | 说明 |
|----------|------|
| **IT战略目标** | 针对IT与业务关系、IT决策、IT资源利用、IT风险控制制定的目标 |
| **IT治理组织** | 治理机构（如IT治理委员会）的设置和权限划分 |
| **IT治理机制** | 决策机制、执行机制、风险控制机制、协调机制的综合体 |
| **IT治理域** | 计划、构建、运维与监控，确保信息化"高效做事"、数字化"敏捷决策" |
| **IT治理标准** | 基本规范、实施参照、评价体系、审计方法 |
| **IT绩效目标** | 关注IT价值实现，评价是否满足业务需求 |

> **口诀：** 标域织布机（战略目标、治理域、治理组织、机制、标准、绩效目标）

## 关键的IT治理决策

| 决策类型 | 说明 |
|----------|------|
| **IT原则决策** | 组织高层关于如何使用IT的陈述 |
| **IT架构决策** | 从政策、关系到技术选择中捕获的数据、应用和基础设施的逻辑 |
| **业务应用需求决策** | 为购买或内部开发IT应用确定业务需求 |
| **IT投资和优先顺序决策** | 关于应该在IT的哪些投资以及投资多少的决策 |
| **IT基础设施决策** | 集中协调、共享IT服务可以给组织的IT能力提供基础 |

> **口诀：** 原价也应投鸡舍（原则、架构、需求、投资、基础设施）

## IT治理机制建立原则

| 原则 | 说明 |
|------|------|
| **简单** | 机制应明确地定义特定个人和团体所承担的责任和目标 |
| **透明** | 机制如何工作需要对被治理决策影响的人非常清晰 |
| **适合** | 机制鼓励处于最佳位置的个人去制定特定的决策 |

> **口诀：** 简明透、适合（简单、透明、适合）

## IT治理机制主要经验

| 经验 | 说明 |
|------|------|
| 吸纳非IT人员 | 保持治理的客观性 |
| 严格控制成本 | 谨慎管理组织、降低业务成本 |
| 设计严格流程 | 例外最小化 |
| IT团队集中化 | 共享服务、用流程连接IT投资和需求 |
| 透明 | 设定集中协作和核准的IT投资流程 |
| 费用分摊 | 确保公平 |

## 关键考点

1. IT治理核心是关注**IT定位**和**信息化建设与数字化转型的责权利划分**
2. IT治理机制原则：**简单、透明、适合**（不包括公平）
3. IT治理体系六大构成要素
