## 三大基准值

| 缩写 | 全称 | 说明 | 关联维度 |
|------|------|------|---------|
| **PV** | 计划价值（Planned Value） | 计划在某时间点前应完成工作的预算成本 | 与检查时间点有关 |
| **EV** | 挣值（Earned Value） | 实际已完成工作的预算成本（**最核心**） | 与实际工作量有关 |
| **AC** | 实际成本（Actual Cost） | 实际已完成工作花费的实际成本 | 与支出费用有关 |

**BAC（完工预算）**：项目总预算 = 完工时的 PV 值

> **赶工场景**：如需赶工最低成本，则 **BAC = 预算 + 赶工成本 + 管理成本**

## 偏差计算公式

| 指标 | 公式 | 含义 | 判断 |
|------|------|------|------|
| **CV**（成本偏差） | EV - AC | 成本节约或超支 | CV < 0 则成本超出；CV > 0 则成本节约 |
| **SV**（进度偏差） | EV - PV | 进度超前或滞后 | SV < 0 则进度落后；SV > 0 则进度提前 |
| **CPI**（成本绩效指数） | EV / AC | 每花1元产生多少价值 | CPI < 1 则成本超出；CPI > 1 则成本节约 |
| **SPI**（进度绩效指数） | EV / PV | 实际完成与计划比率 | SPI < 1 则进度落后；SPI > 1 则进度提前 |

**记忆口诀**：
- 偏差 = EV - 对比项（成本偏差 EV-AC，进度偏差 EV-PV）
- 指数 = EV ÷ 对比项（CPI = EV/AC，SPI = EV/PV）

## 完工预测公式

### ETC（完工尚需估算）

| 类型 | 公式 | 说明 |
|------|------|------|
| 非典型偏差 | **ETC = BAC - EV** | 问题已解决，调整后按原计划完成 |
| 典型偏差 | **ETC = (BAC - EV) / CPI** | 按当前效率继续，不调整 |

### EAC（完工估算）

| 类型 | 公式 | 说明 |
|------|------|------|
| 非典型偏差 | **EAC = AC + BAC - EV** | = AC + ETC，知错就改 |
| 典型偏差 | **EAC = BAC / CPI** | 不调整，死不悔改按原典型继续 |

### VAC（完工偏差）

**VAC = BAC - EAC**

### EAC 口诀

> **"死不悔改抓当典型，非典来了知错就改"**
>
> - **死不悔改**：问题不纠正，按典型偏差继续 → EAC = BAC / CPI
> - **非典知错就改**：发现问题并纠正，按非典型 → EAC = AC + BAC - EV

## TCPI（完工尚需绩效指数）

完成剩余工作所需的成本效率：

| 目标 | 公式 | 记忆 |
|------|------|------|
| 按 BAC 完成 | **TCPI = (BAC - EV) / (BAC - AC)** | 按计划（还剩多少事 / 剩多少钱） |
| 按 EAC 完成 | **TCPI = (BAC - EV) / (EAC - AC)** | 按当前完工估算完成 |

> **TCPI > 1**：剩余工作需要比过去更高的效率才能实现目标
> **TCPI < 1**：目标容易达到，还有余量

## EMV（预期货币价值）

**EMV = 每个可能结果的数值 × 其发生概率，相加之后的结果**

适用于风险量化分析，通过计算每个备选方案在不同情景下的期望值来辅助决策。

## CC（沟通渠道）

**CC = N(N - 1) / 2**

N 为项目团队人数。适用于干系人沟通需求分析和沟通渠道数量计算。

## 关键路径法

### 核心时间参数

| 缩写 | 全称 | 说明 |
|------|------|------|
| **ES** | 最早开始时间 |  |
| **EF** | 最早结束时间 |  |
| **LS** | 最晚开始时间 |  |
| **LF** | 最晚结束时间 |  |

### 时差计算

| 类型 | 公式 |
|------|------|
| 总时差（总浮动时间） | **LS - ES = LF - EF** |
| 自由时差（自由浮动时间） | **min{紧后活动 ES} - EF** |

- 关键路径上的活动总时差 = 0
- 总时差为 0 的活动越多，项目进度风险越大

## 三点估算

### 估算时长

| 分布类型 | 公式 |
|---------|------|
| **β分布** | （悲观 + 乐观 + 4 × 最可能）/ 6 |
| **三角分布** | （悲观 + 乐观 + 最可能）/ 3 |

### 标准差

**标准差 = (悲观时间 - 乐观时间) / 6**

### 完工概率

| 标准差倍数 | 完工概率 |
|-----------|---------|
| ±1 个标准差 | 68.26% |
| ±2 个标准差 | 95.43% |
| ±3 个标准差 | 99.73% |
| ±6 个标准差 | 99.99% |

## 成本加激励费用合同（CPIF）

| 情形 | 总款计算公式 |
|------|------------|
| 实际成本 > 目标成本 | **总款 = 目标成本 + 目标费用 + 买方应承担的成本超支** |
| 实际成本 < 目标成本 | **总款 = 目标成本 + 目标费用 - 买方应承担的成本节约** |

## 典型例题

**题目**：某项目总预算BAC=100万元，计划完成60%，实际完成50%，实际花费55万元。求CV、SV、CPI、SPI、EAC。

**解题**：
- PV = 100 × 60% = **60万**
- EV = 100 × 50% = **50万**
- AC = **55万**（题目给出）

计算：
- CV = EV - AC = 50 - 55 = **-5万**（成本超支5万，CV < 0）
- SV = EV - PV = 50 - 60 = **-10万**（进度滞后，SV < 0）
- CPI = EV / AC = 50 / 55 ≈ **0.91**（CPI < 1，成本绩效差）
- SPI = EV / PV = 50 / 60 ≈ **0.83**（SPI < 1，进度落后）
- EAC = BAC / CPI = 100 / 0.91 ≈ **110万**（预计完工总成本）

**结论**：该项目**成本超支、进度滞后**，形势不乐观。

## 快速记忆表

```
三大基准：  PV = 计划值        EV = 挣值          AC = 实际成本
成本相关：  CV = EV - AC       CPI = EV/AC
进度相关：  SV = EV - PV       SPI = EV/PV
完工预测：  EAC = BAC/CPI       ETC = EAC - AC
           非典：EAC=AC+BAC-EV  典型：EAC=BAC/CPI
TCPI：      按BAC：(BAC-EV)/(BAC-AC)
           按EAC：(BAC-EV)/(EAC-AC)

正数/大于1 → 好
负数/小于1 → 不好
```
