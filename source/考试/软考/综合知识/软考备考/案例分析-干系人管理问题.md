# 案例分析 - 干系人管理问题

## 一、常见问题类型

### 1.1 干系人期望管理

**干系人分类**：

| 分类 | 特点 | 管理策略 |
|------|------|---------|
| 权力高-利益高 | 关键人物 | 重点管理、密切合作 |
| 权力高-利益低 | 有影响力 | 满足其需求、保持满意度 |
| 权力低-利益高 | 重要相关方 | 保持沟通、及时通报 |
| 权力低-利益低 | 一般相关方 | 监督即可 |

**答题框架**：

```
【干系人分析】
1. 识别所有干系人
2. 分析其权力/利益程度
3. 评估其当前态度（支持/反对/中立）
4. 制定管理策略

【期望管理】
1. 识别期望：收集干系人需求和期望
2. 分析差距：对比实际与期望
3. 管理期望：通过沟通、调整方案满足合理期望
4. 控制期望：对不合理的期望要引导和说服
```

### 1.2 客户关系问题

**常见客户问题**：

- 客户不配合，需求调研困难
- 客户频繁干预，影响进度
- 客户不满意，验收拖延
- 客户越级指挥，项目经理被动

## 二、典型案例真题

### 案例一：客户不配合项目工作

**背景**：某政务系统项目，客户方存在以下问题：
- 对接人经常不在岗，需求确认拖延
- 客户领导直接干预技术方案
- 关键决策人难以约见

**问题**：
1. 分析干系人管理存在的问题
2. 如何改善与客户的关系？
3. 如何确保项目顺利推进？

**参考答案**：

```
【问题分析】
1. 干系人识别不全：
   - 只关注对接人员，忽视决策层
   - 未识别影响项目的关键人物

2. 沟通机制缺失：
   - 没有建立定期沟通机制
   - 没有明确各层级对接人

3. 期望管理不足：
   - 未充分了解客户期望
   - 未引导客户期望

【改善措施】
1. 完善干系人登记册：
   - 识别所有干系人：领导层、执行层、使用层
   - 分析权力/利益程度
   - 制定不同层级的沟通策略

2. 建立沟通机制：
   - 高层：每月汇报会，汇报整体进展
   - 中层：每周例会，讨论具体问题
   - 执行层：每日工作对接

3. 期望管理：
   - 主动了解客户期望
   - 定期通报项目成果
   - 邀请客户参与评审

【具体行动计划】
1. 周一：向客户领导汇报项目周报
2. 周三：与对接人确认需求细节
3. 周五：系统演示，收集反馈
4. 里程碑：组织正式评审会
```

### 案例二：项目验收拖延

**背景**：某项目开发完成，但客户迟迟不验收：
- 验收标准不明确
- 客户提出新需求
- 内部审批流程长

**问题**：
1. 分析验收拖延的原因
2. 如何推动项目验收？
3. 如何避免类似问题？

**参考答案**：

```
【原因分析】
1. 验收标准不明确：
   - 合同中未明确验收条件
   - 缺少验收标准文档
   - 需求变更未确认

2. 客户配合问题：
   - 客户忙，腾不出时间
   - 内部审批流程复杂
   - 人员变动，交接不清晰

3. 期望差距：
   - 交付成果与客户预期有差距
   - 功能细节未完全满足

【推动验收措施】
1. 明确验收标准：
   - 对照合同条款，整理验收清单
   - 与客户确认每项验收条件
   - 识别未完成项，制定完成计划

2. 主动推动：
   - 预约客户时间进行验收
   - 准备验收材料：测试报告、用户手册
   - 简化验收流程，特事特办

3. 处理新需求：
   - 已承诺的功能：纳入验收范围
   - 新增需求：明确为二期范围
   - 明确验收时间节点

【预防措施】
1. 合同阶段：明确验收标准和流程
2. 项目过程：定期确认交付成果
3. 变更管理：所有需求变更必须确认
4. 收尾阶段：提前准备验收材料
