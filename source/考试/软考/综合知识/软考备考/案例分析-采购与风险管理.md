# 案例分析 - 采购与风险管理

## 一、常见问题类型

### 1.1 采购管理问题

**问题特征**：
- 供应商选择不当
- 合同纠纷
- 交付延期
- 质量问题

**供应商选择评估**：

| 评估维度 | 权重 | 评估内容 |
|---------|------|---------|
| 技术能力 | 30% | 研发能力、技术储备 |
| 价格竞争力 | 25% | 报价合理性、成本优势 |
| 交付能力 | 20% | 交货期、质量保证 |
| 服务能力 | 15% | 响应速度、售后服务 |
| 企业信誉 | 10% | 行业口碑、合作案例 |

**合同管理要点**：

```
【合同关键条款】
1. 范围条款：明确工作内容
2. 进度条款：明确交付时间
3. 质量条款：明确验收标准
4. 费用条款：明确付款方式
5. 违约条款：明确违约责任
6. 验收条款：明确验收流程
```

### 1.2 风险管理问题

**风险处理策略**：

| 策略 | 适用场景 | 措施 |
|------|---------|------|
| 规避 | 高风险、不可接受 | 改变计划、放弃活动 |
| 转移 | 无法控制的风险 | 购买保险、外包 |
| 减轻 | 降低概率或影响 | 制定应急预案 |
| 接受 | 低风险、可承受 | 预留应急储备 |

## 二、典型案例真题

### 案例一：供应商交付延期

**背景**：某项目采购的服务器设备原定第3个月交付：
- 合同约定：第3个月末交付，违约金为合同金额的1%/天
- 实际情况：供应商第4个月末才完成交付，延期30天
- 项目因此延误25天，额外增加人工成本5万元

**问题**：
1. 供应商是否构成违约？应承担多少违约金？
2. 项目经理应该如何处理此次事件？
3. 如何预防供应商延期问题？

**参考答案**：

```
【违约责任分析】
1. 供应商延期交付30天，构成违约
2. 合同约定违约金：1%/天 × 30天 = 30%
3. 合同总金额假设为50万元
4. 违约金：50 × 30% = 15万元

【项目应对措施】
1. 立即措施：
   - 向供应商发函确认延期事实
   - 启动应急预案，租用备用设备
   - 调整项目计划，向客户说明情况

2. 合同处理：
   - 严格按照合同主张违约金
   - 收集延期证据：邮件、验收单
   - 协商解决方案

3. 长期预防：
   - 供应商评估时增加交付能力权重
   - 合同增加分期付款条款
   - 关键设备至少准备两家供应商
   - 建立供应商分级管理机制
```

### 案例二：项目风险应对

**背景**：某软件开发项目存在以下风险：
- 技术风险：新技术不成熟，可能返工
- 人员风险：核心人员可能离职
- 需求风险：客户可能提出重大变更
- 第三方风险：外包模块可能延期

**问题**：
1. 请对上述风险进行分类和优先级排序
2. 制定风险应对计划
3. 说明如何进行风险监控

**参考答案**：

```
【风险分类与优先级】

高优先级（立即处理）：
1. 技术风险 - 新技术不成熟（高概率、高影响）
   → 规避策略：采用成熟技术替代

2. 人员风险 - 核心人员离职（高概率、高影响）
   → 减轻策略：培养备份人员、签订竞业协议

中优先级（重点关注）：
3. 需求风险 - 客户变更（中等概率、高影响）
   → 转移策略：变更条款明确、收取变更费用

低优先级（常规监控）：
4. 第三方风险 - 外包延期（低概率、中等影响）
   → 接受策略：预留应急时间、合同约定延期责任

【风险应对计划】

1. 技术风险应对：
   - 方案A：技术预研，验证可行性
   - 方案B：准备备选技术方案
   - 触发条件：新技术的bug数超过阈值
   - 应急措施：切换到成熟技术

2. 人员风险应对：
   - 关键岗位建立AB角
   - 知识文档化
   - 离职交接期至少2周

【风险监控】
1. 每周检查风险状态
2. 更新风险登记册
3. 触发应急计划时立即执行
4. 项目例会汇报风险情况
```

## 三、采购管理流程

### 3.1 采购流程步骤

```
1. 规划采购管理 → 制定采购计划
2. 实施采购 → 招标、评标、定标
3. 控制采购 → 合同执行、验收
4. 结束采购 → 合同关闭
```

### 3.2 合同类型选择

| 合同类型 | 风险分担 | 适用场景 |
|---------|---------|---------|
| 固定总价合同 | 供应商承担更多风险 | 范围明确、需求稳定 |
| 成本加固定费用 | 客户承担更多风险 | 范围不确定、紧急项目 |
| 时间材料合同 | 双方共担风险 | 研发类、探索性工作 |

## 四、答题要点

### 4.1 采购与风险答题框架

```
【采购问题】
1. 供应商选择：评估标准、招标流程
2. 合同管理：条款审核、违约处理
3. 质量控制：到货验收、定期检查

【风险问题】
1. 风险识别：头脑风暴、SWOT、专家判断
2. 风险评估：概率×影响矩阵
3. 风险应对：规避、转移、减轻、接受
4. 风险监控：定期检查、触发响应
```

### 4.2 常用术语

- 采购管理计划（Procurement Management Plan）
- 工作说明书（SOW）
- 变更控制委员会（CCB）
- 风险登记册（Risk Register）
- 风险应对计划（Risk Response Plan）
- 合同管理（Contract Management）
