# 可交付成果

## 定义

可交付成果（Deliverable）是在某一过程、阶段或项目完成时，必须产出的任何独特并可核实的产品、成果或服务能力。它是项目工作的具体输出，是项目成功与否的关键衡量标准。

## 核心内容

### 1. 可交付成果的特征
- **独特性**：每个可交付成果都是独特的
- **可验证性**：可以测量、验证或确认
- **有形性**：可以是实体的或虚拟的
- **价值性**：为客户或干系人带来价值

### 2. 可交付成果的类型
- **最终可交付成果**：项目最终产品、服务或成果
- **中间可交付成果**：阶段性的输出成果
- **管理可交付成果**：项目管理计划、报告等
- **技术可交付成果**：系统、模块、文档等

### 3. 可交付成果的层级
- **项目可交付成果**：整个项目的最终输出
- **阶段可交付成果**：项目阶段的输出
- **工作包可交付成果**：工作分解结构（WBS）最底层的交付物

## 实施步骤

### 1. 规划阶段
- **识别可交付成果**：在WBS中明确定义
- **制定验收标准**：明确质量要求和验收条件
- **分配责任**：确定负责人和团队
- **估算资源**：评估所需资源和时间

### 2. 执行阶段
- **创建可交付成果**：按照要求执行工作
- **质量检查**：确保符合质量标准
- **文档记录**：记录开发过程和结果
- **版本控制**：管理可交付成果的版本

### 3. 监控阶段
- **跟踪进度**：监控可交付成果完成情况
- **质量控制**：检查可交付成果质量
- **变更管理**：处理变更请求
- **风险监控**：识别影响可交付成果的风险

### 4. 收尾阶段
- **验收验证**：客户或发起人正式验收
- **移交交付**：将可交付成果移交给客户
- **文档归档**：归档所有相关文档
- **经验教训**：总结经验和教训

## 实际应用示例

**示例1：软件开发项目**
- **最终可交付成果**：企业管理系统软件
- **中间可交付成果**：
  - 需求规格说明书
  - 系统设计文档
  - 数据库设计文档
  - 测试报告
  - 用户手册
- **验收标准**：
  - 功能符合需求文档
  - 性能指标达标
  - 无重大缺陷
  - 用户验收测试通过

**示例2：建筑工程项目**
- **最终可交付成果**：竣工的建筑物
- **中间可交付成果**：
  - 设计图纸
  - 基础工程
  - 结构工程
  - 装修工程
  - 竣工验收报告

## 软考考点

### 上午题考点
1. **可交付成果的定义**：独特并可核实的产品、成果或服务能力
2. **可交付成果 vs 工作绩效数据/信息/报告**：区别和关系
3. **可交付成果的验收**：需要正式验收程序
4. **可交付成果的变更**：需要遵循变更控制流程

### 下午题考点
1. **范围管理**：如何定义和控制可交付成果
2. **质量管理**：如何确保可交付成果质量
3. **变更管理**：可交付成果变更的处理
4. **验收管理**：可交付成果的验收流程

### 常见题型
- 选择题：可交付成果的特征、类型
- 判断题：可交付成果与工作绩效数据的区别
- 案例题：如何处理可交付成果的变更请求

## 最佳实践

1. **明确定义**：在WBS中清晰定义每个可交付成果
2. **设定标准**：制定明确的验收标准和质量指标
3. **早期验证**：在开发过程中进行阶段性验证
4. **文档齐全**：保持完整的开发文档和记录
5. **及时沟通**：与干系人及时沟通可交付成果状态
6. **版本控制**：使用配置管理工具控制版本

## 常见错误

1. **定义模糊**：可交付成果描述不清晰
2. **标准缺失**：没有明确的验收标准
3. **缺乏验证**：未及时验证可交付成果质量
4. **变更失控**：未遵循变更控制流程
5. **文档不全**：缺乏必要的开发文档
6. **沟通不足**：未及时通报可交付成果状态

## 配置管理

可交付成果需要使用配置管理工具和程序进行版本控制：

1. **版本控制**：管理可交付成果的不同版本
2. **变更控制**：控制对可交付成果的变更
3. **基线管理**：建立可交付成果基线
4. **状态报告**：报告可交付成果状态

## 验收流程

1. **检查**：验证可交付成果是否符合验收标准
2. **测试**：进行必要的测试和验证
3. **评审**：组织干系人进行评审
4. **验收**：获得正式验收签字
5. **移交**：将可交付成果移交给客户

## 总结

可交付成果是项目管理的核心概念，是项目工作的具体输出。在软考中，需要深入理解可交付成果的定义、特征、类型、生命周期管理，以及与其他项目管理过程的关系。掌握可交付成果的管理方法，对于项目成功至关重要。
