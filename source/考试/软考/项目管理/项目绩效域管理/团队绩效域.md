## 定义

团队绩效域涉及与负责生成项目可交付物以及实现商业成果的人员活动和功能。需要创建文化和环境，使不同个体演变成**高绩效的项目团队**。

> 记忆：**文化领导绩效**（团队文化 + 领导力技能 + 绩效要点）

## 预期成果（3项）

1. **共享责任**
2. **建立高绩效团队**
3. **所有团队成员都展现出相应的领导力和人际关系技能**

## 高绩效项目团队的特征

- 开诚布公的沟通
- 共识 / 共享责任
- 信任 / 协作
- 适应性 / 韧性
- 赋能 / 认可

## 项目团队文化的特征

透明、诚信、尊重、积极讨论、支持、**勇气**、庆祝

## 领导力技能

| 维度 | 内容 |
|-----|------|
| 情商 | 自我意识→自我管理→社交意识→社交技能（四步递进） |
| 冲突管理 | 尊重开诚布公沟通；聚焦问题；聚焦当前和未来；共同寻找备选方案 |
| 领导力特征 | 建立和维护愿景、批判性思维、激励、人际关系技能 |

### 情商四维度

```
自我意识 → 自我管理 → 社交意识 → 社交技能
（了解自己）（控制自己）（理解他人）（影响他人）
```

## 检查指标

| 预期目标 | 检查方法 |
|---------|---------|
| 共享责任 | 所有团队成员了解愿景（目标与责任心） |
| 建立高绩效团队 | 信任与协作程度；适应变化的能力；彼此赋能 |
| 展现领导力 | 管理和领导力风格是否适合项目背景和环境 |

## 考点提示

- 团队绩效域预期成果是**3项**（与干系人的4项区分）
- 情商四维度顺序：自我意识→自我管理→社交意识→社交技能
- 高绩效团队特征中包含"**勇气**"（团队文化中也有）
