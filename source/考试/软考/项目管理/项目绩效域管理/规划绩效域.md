## 定义

规划绩效域涉及整个项目期间**组织与协调**相关的活动和职能，这些活动和职能是最终交付项目和成果所必须的。

> 绩效要点记忆口诀：**因实估量变通团购**（影响因素、实物资源规划、估算、量度指标、变更规划、沟通规划、团队规划、采购规划）

## 预期成果（6项）

1. 项目以有条理、协调一致的方式推进
2. 应用系统的方法交付项目成果
3. 对演变情况进行详细说明
4. 规划投入的时间成本是适当的
5. 规划的内容对管理干系人的需求而言是充分的
6. 可以根据新出现的和不断变化的需求进行调整

## 规划的影响因素

| 因素 | 影响说明 |
|------|---------|
| 开发方法 | 影响如何规划、规划多少及何时规划 |
| 项目可交付物 | 高技术项目可持续适应性规划 |
| 组织需求 | 治理、政策、文化要求特定规划成果 |
| 市场条件 | 竞争激烈时可最低限度前期规划，加快上市 |
| 法律或法规限制 | 合规性要求影响规划内容 |

## 项目估算的四类方法

| 方法 | 说明 |
|------|------|
| **确定性估算** | 点估算，给出一个具体数字 |
| **概率估算** | 区间估算+置信程度+概率分布 |
| **绝对估算** | 使用具体数字 |
| **相对估算** | 基于某一特定基准进行比较 |
| **基于工作流的估算** | 通过周期和产量来计算 |
| **对不确定性的调整估算** | 通过应急储备调整估算 |

> 估算区间随项目进展而缩小；精确度 ≠ 准确度（精确但不准确是常见的）

## 执行效果检查指标

| 预期目标 | 检查方法 |
|---------|---------|
| 以有条理方式推进 | **绩效偏差**（对照基准审查） |
| 系统方法交付 | **规划整体性**（交付进度/资金/资源/采购无差距） |
| 对演变详细说明 | **规划详尽程度** |
| 时间成本适当 | **规划适宜性** |
| 充分满足干系人 | **规划充分性** |
| 可适应变化 | **可适应变化**（变更日志、变更控制委员会） |

## 考点提示

- 预期成果**6项**（不含"对实物资源有效管理"，那是项目工作绩效域）
- "项目以有条理、协调一致的方式推进"对应检查指标是**绩效偏差**
- 过量的规划会增加成本、造成进度延迟——规划要适度
