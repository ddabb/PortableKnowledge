# 采购关闭

## 定义

采购关闭（Procurement Closure）是指买方通过其授权的采购管理员，向卖方发出合同已经完成的正式书面通知的过程。采购关闭确认合同工作已经完成，双方义务已经履行，合同正式结束。

## 核心内容

### 1. 采购关闭的目的
- **正式确认完成**：确认合同工作已全部完成
- **解除双方义务**：除保修条款外，解除双方义务
- **结清款项**：支付所有应付未付款项
- **归档记录**：将采购文件归档保存
- **释放资源**：释放用于采购的资源和人员

### 2. 采购关闭的条件
- **全部可交付成果已验收**：所有合同规定的可交付成果已验收合格
- **无未决索赔**：没有未解决的索赔或争议
- **全部款项已结清**：所有应付未付款项已支付
- **合同履行完毕**：双方都已履行合同义务
- **符合合同条款**：满足合同中约定的关闭条件

### 3. 采购关闭的活动
- **验收可交付成果**：确认所有可交付成果已验收
- **解决未决问题**：解决所有未决的索赔或争议
- **结清财务款项**：支付所有应付款项
- **更新采购文件**：记录采购关闭信息
- **归档采购记录**：将采购文件归档
- **释放资源**：释放用于采购的资源和人员
- **通知卖方**：正式通知卖方合同关闭

## 实施步骤

### 1. 准备采购关闭
- **审查合同要求**：了解合同关闭的条件和程序
- **检查可交付成果**：确认所有可交付成果已验收
- **检查未决问题**：识别所有未决的索赔或争议
- **准备关闭文件**：准备采购关闭所需文件

### 2. 执行采购关闭
- **验收最终可交付成果**：验收最后的可交付成果
- **解决未决索赔**：解决所有未决的索赔或争议
- **结清款项**：支付所有应付未付款项
- **签署关闭文件**：双方签署采购关闭文件
- **发出关闭通知**：买方向卖方发出正式书面通知

### 3. 完成采购关闭
- **更新采购文件**：记录采购关闭信息
- **归档采购记录**：将采购文件归档
- **释放资源**：释放用于采购的资源和人员
- **总结经验教训**：总结采购经验教训

## 实际应用示例

**示例1：软件开发采购**
- **合同内容**：开发企业管理系统
- **可交付成果**：
  - 需求规格说明书
  - 系统 design 文档
  - 软件系统
  - 用户手册
  - 培训材料
- **验收情况**：所有可交付成果已验收合格
- **未决索赔**：无
- **款项结清**：已支付95%合同款，保留5%质保金
- **关闭条件**：质保期（1年）满后关闭
- **关闭程序**：
  1. 检查质保期是否已满
  2. 确认无质量问题
  3. 支付剩余5%质保金
  4. 签署采购关闭文件
  5. 发出正式书面通知

**示例2：设备采购**
- **合同内容**：采购服务器设备
- **可交付成果**：服务器设备、安装调试、培训
- **验收情况**：设备已验收合格，安装调试完成
- **未决索赔**：无
- **款项结清**：已支付100%合同款
- **关闭条件**：设备验收合格，款项结清
- **关闭程序**：
  1. 确认设备验收合格
  2. 确认款项已结清
  3. 签署采购关闭文件
  4. 发出正式书面通知

## 软考考点

### 上午题考点
1. **采购关闭的时机**：合同完成时
2. **采购关闭的条件**：所有可交付成果已验收、无未决索赔、款项结清
3. **采购关闭的活动**：验收、解决索赔、结清款项、归档
4. **谁发出关闭通知**：买方授权的采购管理员

### 下午题考点
1. **采购关闭流程**：如何进行采购关闭
2. **采购关闭条件**：采购关闭需要满足哪些条件
3. **采购关闭文档**：采购关闭需要哪些文档

### 常见题型
- 选择题：采购关闭的条件、活动
- 判断题：采购关闭后，所有义务都解除（错误，保修条款可能仍然有效）
- 案例题：给定采购场景，如何进行采购关闭

## 最佳实践

1. **提前规划**：在采购规划阶段就考虑关闭条件
2. **明确条件**：在采购文件中明确规定关闭条件
3. **及时关闭**：满足条件后及时关闭采购
4. **完整文档**：保持完整的采购文档
5. **总结经验**：总结采购经验教训

## 常见错误

1. **条件不满足就关闭**：可交付成果未完全验收就关闭
2. **未解决索赔**：有未决索赔就关闭采购
3. **款项未结清**：还有应付款项就关闭采购
4. **文档不完整**：采购文档不完整就关闭
5. **未及时关闭**：满足条件后未及时关闭

## 采购审计

采购关闭前通常进行采购审计：

1. **审计目的**：总结采购经验教训
2. **审计内容**：
   - 采购过程是否合规
   - 采购结果是否满意
   - 有何经验教训
3. **审计结果**：形成采购审计报告

## 组织过程资产更新

采购关闭后需要更新组织过程资产：

1. **采购文件归档**：将采购文件归档保存
2. **经验教训登记册**：记录采购经验教训
3. **供应商评估**：评估卖方绩效
4. **合同信息**：记录合同信息供未来参考

## 总结

采购关闭是采购管理的最后一步，通过采购关闭，正式确认采购合同完成，解除双方义务（除保修条款外），结清款项，归档记录。在软考中，需要掌握采购关闭的条件、活动、流程，以及与其他采购管理过程的关系。
