# CMMI与PRINCE2模型

## CMMI模型

### 四大能力域

| 能力域 | 说明 |
|--------|------|
| **行动（Doing）** | 用于生产和提供优秀解决方案的能力域 |
| **管理（Managing）** | 用于策划和管理解决方案实施的能力域 |
| **实现（Enabling）** | 用于支持解决方案实施和交付的能力域 |
| **提高（Improving）** | 用于维持和提高效率效能的能力域 |

> **口诀：** 做管支提（行动、管理、实现、提高）

### CMMI五级模型

| 级别 | 名称 | 特征 |
|------|------|------|
| 第1级 | 初始级 | 无序管理 |
| 第2级 | 管理级（+） | 遵守既定计划和流程，能实现相应管理 |
| 第3级 | 定义级（+） | 管理实现量化，可预测 |
| 第4级 | 量化管理级（+） | 数据驱动，对不符合策划内容进行预防 |
| 第5级 | 优化级 | 稳定且专注持续改进 |

### 基于CMMI的过程改进

1. 定义改进目标（服务于业务目标）
2. 建立改进团队
3. 开展差距分析
4. 导入培训和过程定义
5. 过程部署
6. CMMI评估（基准评估、维持性评估、**评价评估**）

## PRINCE2模型

**全称：** PRojects IN Controlled Environments（受控环境下的项目管理）

### 七大原则

1. 持续的业务验证
2. 吸取经验教训
3. 明确定义的角色和职责
4. 按阶段管理
5. 例外管理
6. 关注产品
7. 根据项目剪裁

**原则特点：**
- **通用性**：可应用于每个项目
- **自我验证性**：多年实践验证
- **自主性**：提高从业人员信心和能力

> 注意：独特性**不属于**PRINCE2原则特点

### 七大主题

1. 商业论证
2. 组织
3. 质量
4. 计划
5. 风险
6. 变更
7. 进展

> **口诀：** 业务明确裁剪，吸收阶段例外产品
> 通自验、明确、裁剪，吸收、阶段、例外、产品

### 七大流程

1. 项目准备流程
2. 项目指导流程
3. 项目启动流程
4. 阶段控制流程
5. 产品交付管理流程
6. 阶段边界管控流程
7. 项目收尾流程

> **口诀：** 指导准备启动，阶段控制交付边界收尾

### 项目环境

组织可以对PRINCE2进行**个性化剪裁**，创建专属的项目管理模式。

## 关键考点

1. CMMI行动能力域用于**生产和提供**优秀解决方案
2. PRINCE2原则特点：**通用性、自我验证性、自主性**（不包括独特性）
3. PRINCE2的7个原则必须**全部应用**才算是"PRINCE2项目"
4. CMMI V2.0评估方法包括**基准评估、维持性评估、评价评估**
