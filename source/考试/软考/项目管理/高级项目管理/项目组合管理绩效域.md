# 项目组合管理绩效域

## 六大绩效域

> **口诀：** 馆治产能价值风险干系人（管治产能价值风险干）

### 1. 项目组合战略管理

确保组合与组织战略对齐：
- 战略一致性
- 战略目标分解
- 资源配置优化

### 2. 项目组合治理

治理≠管理：
- **监管职能**：决策与导向
- **控制职能**：监控、测量和报告
- **整合职能**：战略一致性

### 3. 项目组合产能与能力管理

**产能类别：**
- 人力资本
- 财务成本
- 资产
- 智力资本

**管理内容：**

| 产能管理 | 能力管理 |
|----------|----------|
| 产能规划 | 新能力构建 |
| 供应与需求管理 | 能力评估 |
| 供应与需求优化 | 能力保持和发展 |

### 4. 项目组合价值管理

关键活动：
1. 协商期望的价值
2. 最大化价值
3. 实现价值
4. 测量价值
5. 报告价值

### 5. 项目组合风险管理

**风险管理要素：**
- 定义项目组合风险的允许公差
- 定义项目组合风险过程
- 风险识别（识别风险和责任人）
- 风险评估（概率、影响、重要性、时间表、依赖关系、置信空间、优先级清单、趋势）
- 风险应对（状态与趋势、平衡组合、管理投资选择）

### 6. 项目组合干系人参与

1. 项目组合干系人识别和定义
2. 项目组合干系人分析
3. 项目组合干系人参与规划
4. 项目组合干系人沟通方法的识别
5. 管理项目组合干系人沟通

## 项目组合生命周期

**四阶段：** 启动 → 规划 → 执行 → **优化**

> 注意：项目组合**没有收尾阶段**，因为组合服务战略，需持续优化

### 各阶段活动

| 阶段 | 主要活动 |
|------|----------|
| **启动** | 验证业务和运营战略；识别组件；定义长期路线图 |
| **规划** | 组件范围和管理；预算；依赖关系；风险应对；资源需求；优先排列 |
| **执行** | 组件实施；绩效监控 |
| **优化** | 持续改进；投资优化 |

## 关键考点

1. 组合管理**不需要**识别项目组合组件（属于启动前的工作）
2. 价值管理的关键活动不包括"输出正确价值观"
3. 组合生命周期**无收尾阶段**，是持续存在的
