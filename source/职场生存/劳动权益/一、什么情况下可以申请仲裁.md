## 一、什么情况下可以申请仲裁

| 争议类型 | 示例 |
|----------|------|
| 确认劳动关系 | 没签合同，但实际存在用工关系 |
| 追索劳动报酬 | 拖欠工资、加班费 |
| 经济补偿/赔偿金 | 被违法辞退要求2N赔偿 |
| 工伤待遇 | 公司不认可工伤或拒绝赔偿 |
| 社保/公积金 | 公司未依法缴纳 |
| 竞业限制/培训违约 | 公司主张违约金，劳动者不服 |
| 解除劳动合同争议 | 对解除理由有异议 |
