## 一、看房阶段

### 1. 必须核实的信息

| 信息 | 核实方式 |
|------|----------|
| 房东身份 | 要求看房产证原件 |
| 房东本人 | 核对身份证与房产证姓名 |
| 房屋状态 | 有无抵押、查封 |
| 物业费 | 是否欠费 |
| 水电气费 | 抄表数，确认无欠费 |

### 2. 实地检查清单

**房屋设施：**
- 门窗是否完好
- 水压是否正常
- 电器能否正常使用
- 网络信号如何
- 墙面有无渗水
- 马桶是否通畅

**周边环境：**
- 通勤距离
- 是否吵闹
- 安保情况
- 停车是否方便

### 3. 警惕这些情况

| 情况 | 风险 |
|------|------|
| 房价明显低于市场 | 可能是骗局 |
| 房东不让看房证 | 可能是二房东 |
| 催促立即签约 | 可能有猫腻 |
| 中介费不明确 | 后续可能乱收费 |
