## 三、准备材料

### 1. 必备材料

| 材料 | 说明 |
|------|------|
| 仲裁申请书 | 一式两份（或按被申请人人数+1份） |
| 身份证复印件 | 正反面 |
| 被申请人信息 | 公司名称、地址、法定代表人 |
| 证据清单 | 列明证据名称和证明目的 |

### 2. 证据材料

**证明劳动关系的证据：**

- 劳动合同（最重要）
- 工资条/银行流水
- 社保缴纳记录
- 工作证/工牌
- 考勤记录
- 工作群聊天记录
- 邮件往来记录
- 工服照片

**证明被辞退的证据：**

- 解除劳动合同通知书
- 与HR/领导的沟通记录
- 最后工作日的打卡记录

**证明工资标准的证据：**

- 银行工资流水（至少近12个月）
- 工资条
- 年终奖/绩效发放记录

### 3. 仲裁申请书怎么写

**基本结构：**

```
申请人：姓名、身份证号、地址、电话
被申请人：公司全称、地址、法定代表人

仲裁请求：
1. 被申请人支付违法解除劳动合同赔偿金XXX元
2. 被申请人支付拖欠工资XXX元

事实与理由：
（简述入职时间、岗位、工资、发生争议的过程）

此致
XXX劳动人事争议仲裁委员会

申请人（签名）：_________
日期：_________
```
