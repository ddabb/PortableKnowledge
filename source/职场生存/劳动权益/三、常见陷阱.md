## 三、常见陷阱

### 1. 二房东陷阱

**什么是二房东？**
- 房客把房子转租出去
- 不是真正的产权人

**风险：**
- 大房东不同意转租，合同无效
- 二房东跑路，押金和租金打水漂

**如何避免：**
- 坚持看房产证原件
- 看房东身份证
- 如果是二房东，要求出示大房东的转租授权书

### 2. 黑中介陷阱

| 套路 | 应对 |
|------|------|
| 看房收费 | 正规中介看房免费 |
| 虚假房源 | 先看房再交中介费 |
| 收费后消失 | 选择正规中介公司 |
| 阴阳合同 | 坚持合同一式两份 |

### 3. 合同陷阱

| 套路 | 应对 |
|------|------|
| 模糊条款 | 逐条确认，写清楚 |
| 口头承诺 | 全部写进合同 |
| 附加条款 | 仔细阅读每一行 |
| 空白条款 | 不签空白合同 |
