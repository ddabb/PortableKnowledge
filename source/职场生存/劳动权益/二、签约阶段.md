## 二、签约阶段

### 1. 合同必备条款

**必须写清楚：**

| 条款 | 内容 |
|------|------|
| 租赁期限 | 起止日期 |
| 租金金额 | 每月租金、支付方式 |
| 押金 | 金额、退还条件 |
| 水电气费 | 单价、缴费方式 |
| 维修责任 | 谁负责维修、费用谁承担 |
| 解约条件 | 提前解约的违约金 |
| 转租约定 | 能否转租 |

### 2. 押金条款要明确

**常见押金类型：**

| 类型 | 说明 |
|------|------|
| 押一付三 | 押金1个月，预付3个月租金 |
| 押一付一 | 押金1个月，预付1个月租金 |

**退还条件要写清：**
- 合同到期退还
- 房屋无损坏退还
- 无欠费退还
- 明确退还时间（如退房后7日内）

### 3. 这些条款要警惕

| 条款 | 问题 |
|------|------|
| "违约押金不退" | 不合理，可协商修改 |
| "可随时解约" | 对租客不利 |
| "房屋维修费由租客承担" | 应区分人为损坏和自然损耗 |
| "水电费按人头算" | 应按实际用量计费 |
