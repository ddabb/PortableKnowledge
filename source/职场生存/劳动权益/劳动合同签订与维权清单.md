# 劳动合同签订与维权清单

> 本文是《劳动合同避坑指南》的第12部分，原章节：**十二、操作建议清单**


### 12.1 签合同前

- [ ] 核对用人单位信息是否准确
- [ ] 确认合同期限与试用期是否匹配
- [ ] 明确工作地点和岗位描述
- [ ] 核实工资构成、支付时间、支付方式
- [ ] 确认社保公积金缴纳基数
- [ ] 审查竞业限制条款是否适用
- [ ] 检查培训服务期条款是否合理

### 12.2 签合同时

- [ ] 仔细阅读全文，不要只看薪资
- [ ] 对不合理条款提出异议
- [ ] 要求修改后再签
- [ ] 签署前拍照或复印留底
- [ ] 确保双方各执一份

### 12.3 入职后

- [ ] 保存劳动合同原件
- [ ] 定期核对社保公积金缴纳情况
- [ ] 保留工资条和考勤记录
- [ ] 保留工作沟通记录（微信、邮件）
- [ ] 收集岗位说明书、公司制度等文件

### 12.4 离职时

- [ ] 书面通知，保留证据
- [ ] 不签"自愿离职申请书"
- [ ] 确认工资、年假折算
- [ ] 办理社保公积金转移
- [ ] 索要离职证明
