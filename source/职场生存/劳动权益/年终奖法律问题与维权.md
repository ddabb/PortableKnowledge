# 年终奖法律问题与维权

> 本文是《年终奖与离职补偿》的第7部分，原章节：**七、年终奖的法律问题**


### 7.1 年终奖的性质

年终奖属于劳动报酬的一部分，但与月工资有区别：

- **固定年终奖**：合同或制度明确约定金额，属于劳动报酬
- **绩效年终奖**：根据公司业绩和个人绩效浮动，属于奖金
- ** discretionary bonus（酌情奖金）**：公司自主决定是否发放，法律风险较大

### 7.2 年终奖是否必须发放

**法律现状**：《劳动法》《劳动合同法》未明确规定年终奖必须发放。

**裁判规则**：

1. **合同或制度有约定** → 应当发放

2. **往年惯例形成事实** → 可能被认定为劳动报酬的一部分

3. **明确约定"根据公司业绩决定"** → 公司有权决定是否发放

4. **年终奖制度公示并执行** → 具有约束力

### 7.3 离职时年终奖如何处理

**关键问题**：离职时能否要求按比例发放年终奖？

**裁判观点分歧**：

| 观点 | 理由 |
|------|------|
| 应按比例发放 | 年终奖是劳动报酬的一部分，应按实际工作时间折算 |
| 无权主张 | 年终奖是对全年工作的奖励，中途离职不满足发放条件 |

**实务建议**：
- 审查劳动合同、员工手册中关于年终奖的约定
- 保留历年发放年终奖的证据
- 如约定明确，可主张按比例发放

### 7.4 案例分析

**案情**：小李在某公司工作，合同约定"年终奖为2个月工资"。小李于8月离职，要求按比例发放年终奖。

**分析**：
- 合同明确约定年终奖金额 → 属于劳动报酬
- 按公平原则，应按实际工作时间折算
- 可主张：8/12 × 2个月工资

**风险提示**：如合同约定"在职员工方可享受年终奖"，法院可能不支持离职员工的年终奖主张。
