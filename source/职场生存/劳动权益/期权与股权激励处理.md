# 期权与股权激励处理

> 本文是《年终奖与离职补偿》的第8部分，原章节：**八、期权与股权激励**


### 8.1 期权的法律性质

期权是公司授予员工在未来以约定价格购买公司股票的权利，属于股权激励的一种形式。

**与劳动报酬的区别**：
- 期权属于激励收益，不是法定劳动报酬
- 期权受《公司法》《证券法》及期权协议约束
- 期权纠纷的管辖和适用法律可能与劳动合同不同

### 8.2 离职后期权的处理

**关键条款**：期权协议中通常约定：

1. **vesting（归属）期**：分期归属，通常4年归属完毕
2. **行权窗口期**：离职后需在一定期限内行权，否则作废
3. **回购条款**：公司有权按约定价格回购已归属期权
4. **加速归属条款**：特定情形下（如公司被收购）期权加速归属

### 8.3 常见争议

**争议一**：离职后期权是否作废？

- 未归属期权：通常离职后不再归属
- 已归属期权：可在约定窗口期内行权，公司无正当理由不得剥夺

**争议二**：公司是否有权回购？

- 视协议约定而定
- 回购价格应公平合理，不得显失公平

**争议三**：期权纠纷是否属于劳动争议？

- 多数法院认定为劳动争议，适用劳动仲裁前置
- 部分法院认定为合同纠纷，可直接起诉

### 8.4 实务建议

1. 签署期权协议前仔细阅读条款
2. 关注归属期、行权窗口、回购条款
3. 保留期权授予协议及相关沟通记录
4. 离职时确认已归属期权的处理方式
