# 经济补偿金N的适用情形

> 本文是《年终奖与离职补偿》的第3部分，原章节：**三、"N"适用的情形**


根据《劳动合同法》第四十六条，以下情形用人单位应支付经济补偿（N）：

### 3.1 劳动者解除合同

《劳动合同法》第三十八条情形（劳动者被迫辞职）：

1. 未按照劳动合同约定提供劳动保护或者劳动条件的
2. 未及时足额支付劳动报酬的
3. 未依法为劳动者缴纳社会保险费的
4. 用人单位的规章制度违反法律、法规的规定，损害劳动者权益的
5. 因本法第二十六条第一款第一项规定的情形致使劳动合同无效的
6. 法律、行政法规规定劳动者可以解除劳动合同的其他情形

**重点**：以"未缴社保"、"拖欠工资"等理由离职，可主张经济补偿！

### 3.2 协商解除

《劳动合同法》第三十六条：

> 用人单位向劳动者提出解除劳动合同并与劳动者协商一致解除劳动合同的，用人单位应当向劳动者支付经济补偿。

**关键**：谁先提出？
- 单位先提出 → 有补偿
- 劳动者先提出 → 无补偿

### 3.3 用人单位无过错性解除

《劳动合同法》第四十条情形：

1. 劳动者患病或非因工负伤，医疗期满后不能从事原工作，也不能从事由用人单位另行安排的工作的
2. 劳动者不能胜任工作，经过培训或调整岗位，仍不能胜任的
3. 劳动合同订立时所依据的客观情况发生重大变化，致使合同无法履行，经协商未能就变更达成协议的

### 3.4 经济性裁员

《劳动合同法》第四十一条规定的经济性裁员情形。

### 3.5 合同到期终止

《劳动合同法》第四十四条第一项：

> 除用人单位维持或者提高劳动合同约定条件续订劳动合同，劳动者不同意续订的情形外，依照本法第四十四条第一项规定终止固定期限劳动合同的。

**要点**：合同到期不续签，单位要给补偿；但如果单位提高条件续签而劳动者不愿续签，则无补偿。

### 3.6 用人单位主体资格丧失

《劳动合同法》第四十四条第四项、第五项：

- 用人单位被依法宣告破产
- 用人单位被吊销营业执照、责令关闭、撤销或者用人单位决定提前解散
