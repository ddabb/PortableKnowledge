# 被裁员了怎么办

> 遇到裁员别慌，法律给了你明确的保障

---

## 一、先搞清楚是哪种情况

公司让你走人有几种常见方式，对应不同权益：

| 情形 | 性质 | 补偿 |
|------|------|------|
| 经济性裁员 | 公司经营困难 | N+1 |
| 协商解除 | 双方同意 | 可协商 |
| 合同到期不续签 | 公司不续签 | N |
| 违法解除 | 公司无故辞退 | 2N |
| 主动辞职 | 自己想走 | 无补偿 |

**关键：别主动签"辞职信"，否则可能失去补偿。**

---

## 二、N 是什么？怎么算？

### 1. N 的计算方式

**N = 工作年限 × 月平均工资**

- 工作满1年 = 1个月工资
- 工作满6个月不满1年 = 按1年算
- 工作不满6个月 = 半个月工资

**月平均工资** = 解除合同前12个月的平均工资（含加班费、奖金、津贴等）

### 2. 举例

| 工作年限 | 月薪 | 补偿金额 |
|----------|------|----------|
| 2年 | 10000 | 20000 |
| 2年7个月 | 10000 | 30000（7个月按1年算） |
| 2年4个月 | 10000 | 25000（4个月按半年算） |
| 5年 | 15000 | 75000 |

### 3. +1 是什么？

N+1 中的 "+1" 是**代通知金**，即公司没有提前30天书面通知你，额外支付1个月工资。

注意：协商解除和经济性裁员通常给 N+1，但具体要看协商结果。

### 4. 高收入者的限制

月平均工资超过当地上年度职工月平均工资 **3倍** 的：
- 按3倍计算
- 补偿年限最高不超过 **12年**

## 三、被裁后的正确步骤

### 第1步：不要签任何不了解的文件

- ❌ 不签"个人原因辞职"
- ❌ 不签空白协议
- ❌ 不签放弃补偿的声明
- ✅ 可以签"协商解除劳动合同协议"（看清补偿金额）

### 第2步：索要书面通知

- 要求公司出具**解除劳动合同通知书**
- 载明解除理由和日期
- 这是维权的重要证据

### 第3步：确认补偿方案

- 明确补偿金额（N、N+1 还是协商金额）
- 确认发放时间（法律规定办结工作交接时支付）
- 保留沟通记录（微信、邮件）

### 第4步：办理离职手续

- 完成工作交接
- 结清工资和补偿
- 拿到**离职证明**
- 确认社保、公积金停缴时间

### 第5步：申请失业保险

被裁员（非主动辞职）可以领取失业保险金：
- 累计缴费满1年不足5年：最长12个月
- 累计缴费满5年不足10年：最长18个月
- 累计缴费10年以上：最长24个月

## 四、公司常见的"套路"

| 套路 | 真相 |
|------|------|
| "你绩效不达标，我们辞退你" | 需要证据，否则属于违法解除 |
| "你先签辞职，我们给你补发" | 辞职后补偿就不受法律保护了 |
| "公司经营困难，大家体谅" | 困难不等于可以不给补偿 |
| "你去仲裁也赢不了" | 吓唬你，仲裁胜率并不低 |
| "签字了才有年终奖" | 检查合同约定，该发的必须发 |

## 五、仲裁流程

如果协商不成，可以申请劳动仲裁：

### 1. 时效

自知道权利被侵害之日起 **1年** 内提出。

### 2. 去哪里

公司注册地或实际工作地的**劳动人事争议仲裁委员会**。

### 3. 需要准备的材料

- 仲裁申请书
- 身份证复印件
- 劳动合同
- 工资流水/社保记录
- 解除劳动合同通知书
- 其他相关证据

### 4. 费用

劳动仲裁 **不收费**。

### 5. 流程

1. 提交申请（5日内决定是否受理）
2. 被申请人收到申请书副本（5日内）
3. 开庭审理（45日内结案，可延长15日）
4. 收到裁决书（不服可在15日内向法院起诉）

## 六、被裁后还能做什么

### 1. 申领失业金

- 线上：当地人社局APP或支付宝/微信社保服务
- 线下：就业服务中心

### 2. 职业培训

- 政府提供免费职业技能培训
- 可申请培训补贴

### 3. 税收优惠

- 与解除劳动合同相关的补偿金，在当地上年平均工资3倍以内的部分，**免征个人所得税**

### 4. 重新求职

- 更新简历
- 梳理项目经验
- 利用离职缓冲期学习提升

---

## 七、重要提醒

- **不要拖延**：仲裁时效1年，过了就很难维权
- **保留证据**：聊天记录、邮件、录音都可以作为证据
- **理性协商**：了解自己的权益，但不盲目对抗
- **寻求帮助**：可咨询当地法律援助中心（免费）

---

> 记住：被裁员不是你的错，了解法律才能保护自己。
