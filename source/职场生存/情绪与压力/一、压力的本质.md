## 一、压力的本质

### 1.1 什么是压力

压力 = 身体和心理对挑战或需求的反应

**压力的来源：**
- 工作压力（deadline、绩效、人际关系）
- 生活压力（家庭、经济、健康）
- 成长压力（自我期待、他人期待）

### 1.2 压力的生理反应

**急性压力反应（战斗或逃跑）：**

| 系统 | 反应 |
|------|------|
| 心血管 | 心跳加快、血压升高 |
| 呼吸 | 呼吸急促 |
| 肌肉 | 肌肉紧绷、准备行动 |
| 消化 | 消化减慢 |
| 免疫 | 短期内免疫力下降 |

### 1.3 压力的类型

| 类型 | 说明 | 效果 |
|------|------|------|
| **急性压力** | 短期的明确压力 | 可以是积极的 |
| **慢性压力** | 长期持续的压力 | 对健康有害 |
| **正向压力** | 挑战带来的兴奋感 | 成长机会 |
| **负向压力** | 超出应对能力的压力 | 造成伤害 |
