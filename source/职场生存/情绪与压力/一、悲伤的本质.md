## 一、悲伤的本质

### 1.1 什么是悲伤

悲伤 = 对失去的自然情绪反应

**失去的形式：**
- 亲人离世
- 恋人分手/离婚
- 朋友疏远
- 工作/职位丢失
- 宠物去世
- 身体健康受损
- 理想破灭
- 童年结束

### 1.2 悲伤的生理反应

| 反应 | 说明 |
|------|------|
| 胸口沉重 | 感觉胸口有重量压着 |
| 喉咙紧绷 | 难以吞咽 |
| 四肢无力 | 浑身没劲 |
| 睡眠紊乱 | 失眠或嗜睡 |
| 食欲改变 | 吃不下或暴饮暴食 |
| 免疫下降 | 容易生病 |

### 1.3 悲伤的五个阶段（库伯勒-罗斯模型）

| 阶段 | 说明 | 典型感受 |
|------|------|----------|
| **否认** | "这不是真的" | 震惊、不真实 |
| **愤怒** | "为什么是我" | 怨恨、不公平 |
| **讨价还价** | "如果我...就..." | 幻想改变 |
| **抑郁** | "太痛苦了" | 绝望、无力 |
| **接受** | "我接受了" | 平静、释然 |

**注意：** 这五个阶段不一定是线性的，可能反复跳跃。
