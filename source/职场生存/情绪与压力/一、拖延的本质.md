## 一、拖延的本质

### 1.1 什么是拖延

拖延 = 推迟去做应该做的事

但拖延≠懒惰：
- **懒惰**：没有动力做事
- **拖延**：有动力但无法行动

拖延的本质是**情绪调节失败**——不是因为不想做，而是因为做这件事会引发负面情绪（焦虑、恐惧、无聊），所以大脑选择逃避。

### 1.2 拖延的心理机制

```
触发事件（任务）→ 负面情绪（焦虑/恐惧）→ 逃避（刷手机/拖延）→ 短暂缓解 → 负面情绪加剧（愧疚/自责）→ 更想逃避
```

**拖延的恶性循环：**
1. 任务触发焦虑
2. 大脑想逃避负面情绪
3. 转向轻松活动（刷手机）
4. 短暂开心
5. 愧疚感加剧
6. 下次任务更焦虑
