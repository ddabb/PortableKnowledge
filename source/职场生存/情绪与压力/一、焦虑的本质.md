## 一、焦虑的本质

### 1.1 什么是焦虑

焦虑 = 对未来可能发生的威胁或不确定性的担忧反应

| 对比 | 焦虑 | 恐惧 |
|------|------|------|
| 对象 | 模糊的、未来的 | 具体的、当前的 |
| 程度 | 可轻可重 | 通常强烈 |
| 功能 | 提醒准备 | 逃避危险 |

### 1.2 焦虑的生理反应

| 系统 | 反应 |
|------|------|
| 心血管 | 心跳加快、血压升高 |
| 呼吸 | 呼吸急促、胸闷 |
| 消化 | 胃部不适、恶心 |
| 肌肉 | 肌肉紧绷、颤抖 |
| 神经 | 出汗、头晕、手脚发麻 |

### 1.3 焦虑的心理学机制

```
认知评估 → 危险感知 → 身体反应 → 行为回避 → 短期缓解 → 长期强化
```

**焦虑循环：**
1. 对某事感到不确定
2. 大脑放大危险信号
3. 身体进入"战斗模式"
4. 回避或过度准备
5. 短期缓解
6. 下次更焦虑
