## 一、自我接纳是什么

### 1.1 定义

自我接纳 = 完整地接受自己——包括优点和缺点

### 1.2 自我接纳 vs 自我接纳

| 对比 | 自我接纳 | 自我接纳 |
|------|----------|----------|
| 对缺点 | 接受并改变 | 接受，不一定改变 |
| 对优点 | 欣赏 | 过度依赖 |
| 对评价 | 不依赖外界评价 | 完全取决于外界 |
| 成长 | 基于接受而非逃避 | 基于逃避而非接受 |

### 1.3 自我接纳的标志

| 标志 | 说明 |
|------|------|
| 能承认自己的不足 | 不否认也不夸大 |
| 能欣赏自己的优点 | 不过度谦虚 |
| 不需要完美 | 允许自己犯错 |
| 不过度比较 | 不和别人比较 |
| 能接受批评 | 不过度防御 |
