## 七、什么时候需要专业帮助

### 7.1 警示信号

| 信号 | 说明 |
|------|------|
| 焦虑持续6个月以上 | 可能是焦虑症 |
| 严重影响生活 | 无法正常工作或社交 |
| 出现身体症状 | 心悸、胸闷等持续存在 |
| 有逃避行为 | 回避很多事情 |
| 影响睡眠和食欲 | 严重影响身体健康 |

### 7.2 专业治疗方法

| 方法 | 说明 |
|------|------|
| **认知行为疗法（CBT）** | 改变焦虑的思维模式 |
| **药物治疗** | 抗焦虑药物，需医生处方 |
| **正念疗法** | 培养对当下的觉察 |
| **系统脱敏** | 逐步面对恐惧 |
