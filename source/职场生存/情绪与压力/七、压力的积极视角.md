## 七、压力的积极视角

### 7.1 正向压力

| 类型 | 说明 |
|------|------|
| **挑战感** | 感到兴奋和动力 |
| **意义感** | 感到自己的工作有意义 |
| **成长感** | 感到自己在进步 |

### 7.2 压力转化

| 负向框架 | 正向框架 |
|----------|----------|
| "我被压垮了" | "这是一个挑战" |
| "我做不到" | "我需要学习如何做" |
| "一切都完了" | "这是暂时的困难" |
| "都是我的错" | "我能从中学到什么" |

### 7.3 压力与表现

**耶基斯-多德森定律：**

```
压力水平 → 表现
低压力 → 低表现
最佳压力 → 最佳表现
过高压力 → 表现下降
```

**关键是找到"最佳压力点"。**
