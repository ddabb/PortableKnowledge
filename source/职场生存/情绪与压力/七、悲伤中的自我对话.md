## 七、悲伤中的自我对话

### 7.1 负面的自我对话

| 想法 | 问题 |
|------|------|
| "我应该更快好起来" | 给自己太大压力 |
| "我永远不会快乐了" | 过度悲观 |
| "这是我的错" | 过度自责 |
| "我一个人扛" | 孤立自己 |
| "不应该感到悲伤" | 压抑情绪 |

### 7.2 正面的自我对话

| 想法 | 效果 |
|------|------|
| "悲伤需要时间，我给自己时间" | 允许自己 |
| "我现在很痛苦，但会慢慢好起来" | 保持希望 |
| "这不是我的错" | 减少自责 |
| "我愿意接受帮助" | 开放支持 |
| "即使悲伤，我也能生活" | 继续前行 |
