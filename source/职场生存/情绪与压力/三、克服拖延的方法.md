## 三、克服拖延的方法

### 3.1 两分钟法则

**规则：任何任务，先做2分钟**

为什么有效：
- 打破启动阻力
- 一旦开始，往往会继续
- 2分钟不造成心理负担

**操作：**
1. 看到一个任务
2. 告诉自己：只做2分钟
3. 2分钟后可以选择停止
4. 大多数时候你会继续做

### 3.2 拆解任务

**把大任务拆成小任务**

| 大任务 | 拆解后 |
|--------|--------|
| "写报告" | 1. 打开文档 2. 写标题 3. 列提纲 4. 写第一段... |
| "整理房间" | 1. 收衣服 2. 叠被子 3. 擦桌子... |

**原则：** 每个小任务要具体、可操作、5分钟能完成

### 3.3 改变环境

| 方法 | 说明 |
|------|------|
| **减少干扰** | 手机放到另一个房间 |
| **物理隔离** | 去图书馆/咖啡厅工作 |
| **番茄工作法** | 专注25分钟，休息5分钟 |
| **视觉提醒** | 把任务写下来放在显眼处 |

### 3.4 情绪调节

**先处理情绪，再处理任务**

| 情绪 | 应对方法 |
|------|----------|
| 焦虑任务 | 告诉自己：先做5分钟试试 |
| 害怕失败 | 告诉自己：错误是学习机会 |
| 觉得无聊 | 想象完成后的成就感 |
| 任务太大 | 专注眼前的一小步 |

### 3.5 承诺机制

| 方法 | 说明 |
|------|------|
| **公开承诺** | 告诉别人你要做什么 |
| **设置deadline** | 给自己设截止时间 |
| **预先奖励** | 完成后给自己奖励 |
| **同伴监督** | 找朋友互相监督 |
