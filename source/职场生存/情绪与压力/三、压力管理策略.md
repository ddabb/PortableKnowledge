## 三、压力管理策略

### 3.1 立即减压技术

| 方法 | 操作 | 时长 |
|------|------|------|
| 深呼吸 | 腹式呼吸4-7-8 | 1分钟 |
| 身体放松 | 渐进式肌肉放松 | 10分钟 |
| 暂时离开 | 换个环境5分钟 | 5分钟 |
| 冷水洗脸 | 冷水降低唤醒 | 1分钟 |
| 简短运动 | 快走、拉伸 | 5分钟 |

### 3.2 认知策略

**重新评估压力：**

| 步骤 | 操作 | 示例 |
|------|------|------|
| 识别 | 识别压力的来源 | "我感到压力是因为..." |
| 评估 | 这个压力真的那么可怕吗？ | "最坏的情况是什么？" |
| 重新框架 | 换一种理解方式 | "这是一个挑战，不是威胁" |
| 行动 | 采取行动应对 | "我可以做的是..." |

**压力的ABC模型：**

```
A（事件）→ B（信念）→ C（压力反应）
              ↓
         B'（新的信念）→ C'（新的反应）
```

### 3.3 问题解决策略

| 策略 | 说明 |
|------|------|
| **分解问题** | 把大问题分解成小问题 |
| **优先级** | 确定什么是真正重要的 |
| **寻求帮助** | 不要独自承担 |
| **设定界限** | 学会说不 |
| **时间管理** | 合理安排时间 |
