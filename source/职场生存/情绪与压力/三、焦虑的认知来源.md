## 三、焦虑的认知来源

### 3.1 灾难化思维

| 思维模式 | 示例 |
|----------|------|
| 高估危险 | "我一定会搞砸" |
| 低估应对能力 | "我应对不了这件事" |
| 低估支持 | "没有人会帮我" |
| 过度概括 | "每次都会失败" |

### 3.2 常见的焦虑信念

| 信念 | 问题 |
|------|------|
| "我必须控制一切" | 不可能做到，导致持续焦虑 |
| "担心就是准备" | 过度担心不等于有效准备 |
| "我不能让任何人失望" | 不现实的期望 |
| "坏事一定会发生" | 负面偏见 |
