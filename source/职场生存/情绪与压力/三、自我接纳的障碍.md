## 三、自我接纳的障碍

### 3.1 认知偏差

| 偏差 | 影响 |
|------|------|
| 非黑即白 | 不完美就是失败 |
| 以偏概全 | 一件事做不好就是全盘失败 |
| 负面偏见 | 只看到缺点，看不到优点 |
| 心理过滤 | 只关注负面反馈 |

### 3.2 自我欺骗

| 形式 | 说明 |
|------|------|
| 虚假谦逊 | "我没什么优点" |
| 过度补偿 | "我必须比所有人都好" |
| 假装不在乎 | "我才不在乎" |
| 自我贬低 | "我就是这样差的人" |
