## 三、面对悲伤的方法

### 3.1 允许自己悲伤

| 做法 | 说明 |
|------|------|
| 允许哭泣 | 眼泪是情绪的释放 |
| 不压抑 | 感受悲伤，不要逃避 |
| 不比较 | 每个人悲伤的方式不同 |
| 不设时间限制 | 悲伤需要时间 |

### 3.2 表达悲伤

| 方法 | 说明 |
|------|------|
| 说出来 | 和信任的人倾诉 |
| 写下来 | 写日记、写信 |
| 仪式 | 葬礼、纪念仪式 |
| 艺术表达 | 画画、音乐、舞蹈 |
| 回忆 | 分享和回忆美好时光 |

### 3.3 照顾自己

| 方面 | 具体做法 |
|------|----------|
| **身体** | 尽量保持吃饭和睡觉 |
| **运动** | 轻度运动有助于情绪 |
| **社交** | 不要孤立自己 |
| **作息** | 保持规律生活 |
| **兴趣** | 做一些能让你感到平静的事 |
