## 二、为什么不接纳自己

### 2.1 常见原因

| 原因 | 说明 |
|------|------|
| **成长环境** | 从小被批评多于鼓励 |
| **社会标准** | 用统一标准衡量所有人 |
| **完美主义** | 觉得自己必须完美 |
| **比较心理** | 总和别人比较 |
| **失败经历** | 过去的失败影响自我评价 |
| **过高期望** | 父母/社会/自己的期望太高 |

### 2.2 常见的自我评判

| 自我评判 | 背后信念 |
|---------|----------|
| "我不够好" | "我必须完美才值得被爱" |
| "我很差劲" | "犯错意味着我不合格" |
| "别人都比我强" | "我的价值取决于比别人好" |
| "我不配成功" | "成功不属于我这种人" |
| "我太软弱了" | "强者不需要别人的帮助" |
