## 二、为什么会拖延

### 2.1 常见原因

| 原因 | 说明 | 示例 |
|------|------|------|
| **恐惧失败** | 担心做不好 | "万一写不好怎么办" |
| **恐惧完美** | 害怕做得不够完美 | "等我想清楚再开始" |
| **任务无聊** | 任务本身无聊 | 不想做重复性工作 |
| **任务困难** | 不知道从何下手 | 任务太大太复杂 |
| **缺乏动力** | 不知道做了有什么意义 | "做了也没人看" |
| **即时满足** | 手机更容易获得快感 | 刷视频比工作爽 |

### 2.2 拖延的认知偏差

| 偏差 | 说明 |
|------|------|
| **时间幻觉** | 高估未来自己的动力 |
| **乐观偏差** | "明天一定更有精力" |
| **即时偏好** | 重视当下，轻视未来 |
| **高估自律** | 以为自己能抵抗诱惑 |
