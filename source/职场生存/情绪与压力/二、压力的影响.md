## 二、压力的影响

### 2.1 短期影响

| 方面 | 影响 |
|------|------|
| 认知 | 注意力集中，反应加快 |
| 情绪 | 焦虑、烦躁 |
| 行为 | 攻击性或退缩性 |
| 身体 | 头痛、胃部不适 |

### 2.2 长期影响

| 方面 | 影响 |
|------|------|
| 身体健康 | 心脏病、高血压、免疫下降 |
| 心理健康 | 焦虑症、抑郁症 |
| 认知能力 | 记忆力下降、决策失误 |
| 人际关系 | 易怒、社交退缩 |
| 工作表现 | 效率下降、创造力降低 |
