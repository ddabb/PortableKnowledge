## 二、愤怒的触发因素

### 2.1 常见触发因素

| 类别 | 示例 |
|------|------|
| **被冒犯** | 被侮辱、被冤枉 |
| **被控制** | 被强迫做某事 |
| **被忽视** | 说的话没人听 |
| **失望** | 期望落空 |
| **受挫** | 事情不顺利 |
| **疲惫** | 身体精神状态差 |

### 2.2 愤怒的认知来源

| 认知模式 | 示例 |
|----------|------|
| **绝对化思维** | "他必须尊重我" |
| **过度概括** | "所有人都不理解我" |
| **灾难化** | "完蛋了，一切都完了" |
| **读心术** | "他就是故意针对我" |
