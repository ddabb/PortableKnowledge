## 二、正常悲伤 vs 复杂性悲伤

### 2.1 正常悲伤

| 特点 | 说明 |
|------|------|
| 间歇性 | 悲伤来了又走 |
| 有意义感 | 还能感受到积极情绪 |
| 逐渐好转 | 随着时间慢慢减轻 |
| 保持功能 | 能维持基本生活 |

### 2.2 复杂性悲伤

| 特点 | 说明 |
|------|------|
| 持续强烈 | 悲伤持续超过1年且不减轻 |
| 回避现实 | 拒绝接受失去 |
| 过度沉迷 | 过度沉溺于回忆 |
| 功能受损 | 严重影响生活和工作 |
| 自我伤害 | 有自伤或自杀念头 |

**如果出现复杂性悲伤，建议寻求专业帮助。**
