## 二、焦虑的类型

### 2.1 正常焦虑 vs 焦虑症

| 正常焦虑 | 焦虑症 |
|---------|--------|
| 有具体原因 | 没有明显原因 |
| 程度适当 | 过度强烈 |
| 持续时间短 | 持续时间长 |
| 不影响生活 | 影响日常生活 |
| 可以控制 | 难以控制 |

### 2.2 常见焦虑类型

| 类型 | 表现 |
|------|------|
| **广泛性焦虑** | 持续担心很多事情 |
| **社交焦虑** | 害怕社交场合 |
| **分离焦虑** | 害怕与重要的人分离 |
| **健康焦虑** | 过度担心健康 |
| **考试焦虑** | 考试前过度紧张 |
| **表现焦虑** | 公开演讲/表演时紧张 |
