## 五、对自己温柔一点

### 5.1 接纳拖延

| 态度 | 说明 |
|------|------|
| ❌ 自我批判 | "我怎么这么懒" |
| ✅ 理解自己 | "拖延是因为这个任务让我焦虑" |
| ❌ 完美主义 | "一次不改我就失败了" |
| ✅ 循序渐进 | "每次改善一点就好" |

### 5.2 减少愧疚

| 方法 | 说明 |
|------|------|
| **原谅自己** | 拖延一次不代表失败 |
| **不要比较** | 不要和别人比效率 |
| **关注进步** | 关注今天比昨天好了多少 |
| **保持平衡** | 休息也是生活的一部分 |
