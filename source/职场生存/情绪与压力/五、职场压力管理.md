## 五、职场压力管理

### 5.1 工作中的压力来源

| 来源 | 具体表现 |
|------|----------|
| 工作量 | 任务太多、时间不够 |
| 人际关系 | 领导、同事关系紧张 |
| 职业发展 | 晋升瓶颈、工作不稳定 |
| 工作环境 | 噪音、空间、不适 |
| 工作生活平衡 | 加班太多、没有时间 |

### 5.2 应对策略

| 策略 | 具体做法 |
|------|----------|
| **时间管理** | 优先处理重要的事，使用日程表 |
| **设定界限** | 明确工作时间和休息时间 |
| **有效沟通** | 主动和领导沟通工作负荷 |
| **分解任务** | 把大任务分解成小步骤 |
| **寻求资源** | 利用公司资源，如EAP项目 |
| **定期休息** | 工作中定时休息 |

### 5.3 职场减压技巧

| 技巧 | 操作 |
|------|------|
| **番茄工作法** | 25分钟专注，5分钟休息 |
| **任务清单** | 写下来减少焦虑 |
| **优先级矩阵** | 重要紧急优先处理 |
| **简化工作** | 自动化、委派、删除 |
| **建立仪式** | 上下班的转换仪式 |
