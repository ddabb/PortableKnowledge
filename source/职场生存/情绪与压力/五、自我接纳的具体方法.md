## 五、自我接纳的具体方法

### 5.1 身体层面

| 方法 | 说明 |
|------|------|
| 身体扫描 | 关注身体感受，不评判 |
| 照顾身体 | 运动、睡眠、饮食 |
| 身体语言 | 站直、微笑、自信的姿态 |
| 停止比较 | 不和别人的外表比较 |

### 5.2 心理层面

| 方法 | 说明 |
|------|------|
| 正念冥想 | 觉察当下，接受当下 |
| 自我对话记录 | 记录并纠正负面自我对话 |
| 写给自己的信 | 用朋友的口吻给自己写信 |

### 5.3 关系层面

| 方法 | 说明 |
|------|------|
| 建立支持关系 | 和积极、支持你的人在一起 |
| 设定关系界限 | 远离总是批评你的人 |
| 练习坦诚沟通 | 表达真实感受 |
| 接受帮助 | 允许自己需要帮助 |
