## 五、长期情绪管理

### 5.1 预防愤怒

| 方法 | 说明 |
|------|------|
| **保持充足睡眠** | 疲惫易怒 |
| **规律运动** | 释放压力 |
| **减少刺激物** | 少喝咖啡/酒精 |
| **管理期望** | 不要有太高期望 |
| **学会说不** | 避免过度承诺 |

### 5.2 情绪日记

| 记录内容 | 示例 |
|----------|------|
| 时间 | 下午3点 |
| 触发事件 | 领导在会议上批评了我 |
| 身体感受 | 胸口发热，拳头握紧 |
| 情绪 | 愤怒、委屈 |
| 想法 | "他故意让我难堪" |
| 行为 | 我当场反驳了他 |
| 结果 | 场面很尴尬 |
| 反思 | 下次可以先冷静再回应 |

### 5.3 建立支持系统

| 方法 | 说明 |
|------|------|
| 倾诉 | 和信任的人说说 |
| 专业帮助 | 心理咨询师 |
| 愤怒管理小组 | 互相支持 |
| 放松活动 | 冥想、瑜伽 |
