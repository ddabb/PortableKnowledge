## 五、长期焦虑管理

### 5.1 生活方式

| 方法 | 具体建议 |
|------|----------|
| **规律运动** | 每周3-5次有氧运动 |
| **充足睡眠** | 每晚7-9小时 |
| **减少刺激物** | 少喝咖啡因和酒精 |
| **限制信息摄入** | 控制看新闻时间 |
| **培养爱好** | 做喜欢的事情 |

### 5.2 放松练习

| 方法 | 操作 | 时长 |
|------|------|------|
| **渐进式肌肉放松** | 收紧然后放松每组肌肉 | 20分钟 |
| **冥想** | 关注呼吸或身体感觉 | 10-20分钟 |
| **瑜伽** | 结合呼吸和身体运动 | 30分钟 |
| **太极拳** | 缓慢动作配合呼吸 | 30分钟 |

### 5.3 建立安全感

| 方法 | 说明 |
|------|------|
| **准备清单** | 为可能的问题做准备 |
| **财务规划** | 减少经济不确定性 |
| **社交支持** | 建立支持系统 |
| **自我照顾** | 每天留时间给自己 |
