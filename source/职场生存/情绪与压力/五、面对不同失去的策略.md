## 五、面对不同失去的策略

### 5.1 亲人离世

| 策略 | 说明 |
|------|------|
| **参与仪式** | 葬礼是重要的疗愈过程 |
| **保持联系** | 和逝者的记忆保持连接 |
| **接受反复** | 悲伤会在特殊日子回来 |
| **寻求支持** | 悲伤支持小组 |

### 5.2 分手/离婚

| 策略 | 说明 |
|------|------|
| **允许悲伤** | 失去亲密关系需要时间 |
| **切断联系** | 初期可能需要减少联系 |
| **重新认识自己** | 重新定义单身身份 |
| **展望未来** | 相信会找到新的爱情 |

### 5.3 失业/事业受挫

| 策略 | 说明 |
|------|------|
| **允许沮丧** | 失业影响自尊，需要时间 |
| **保持日常** | 建立新的日常结构 |
| **寻找机会** | 把这当作新开始 |
| **技能提升** | 用时间提升自己 |
