## 八、与焦虑共处

### 8.1 接纳焦虑

| 态度 | 说明 |
|------|------|
| ❌ 消除焦虑 | 不可能完全消除 |
| ✅ 与焦虑共处 | 带着焦虑正常生活 |
| ❌ 恐惧焦虑 | 焦虑本身不可怕 |
| ✅ 允许焦虑存在 | 焦虑是人类正常的反应 |

### 8.2 自我对话

| 焦虑的自我对话 | 健康的自我对话 |
|----------------|----------------|
| "我一定要控制一切" | "有些事情我无法控制，我接受" |
| "我必须完美" | "尽力就好，不完美也没关系" |
| "坏事一定会发生" | "坏事可能发生，但我能应对" |
| "我不够好" | "我不够好，但我可以努力变得更好" |
