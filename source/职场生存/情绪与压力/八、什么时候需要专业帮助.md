## 八、什么时候需要专业帮助

### 8.1 警示信号

| 信号 | 说明 |
|------|------|
| 持续焦虑或抑郁 | 超过2周 |
| 睡眠严重问题 | 长期失眠 |
| 身体症状 | 持续头痛、胃痛等 |
| 物质依赖 | 用酒精或药物应对 |
| 功能受损 | 无法正常工作或社交 |
| 有伤害自己念头 | 紧急情况 |

### 8.2 可寻求的帮助

| 帮助 | 适合情况 |
|------|----------|
| 心理咨询师 | 持续压力、情绪问题 |
| 精神科医生 | 需要药物治疗 |
| EAP项目 | 公司提供的员工帮助项目 |
| 支持小组 | 需要同伴支持 |
| 压力管理课程 | 系统学习压力管理 |
