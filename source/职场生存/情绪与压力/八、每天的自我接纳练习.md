## 八、每天的自我接纳练习

### 8.1 早晨练习

```
1. 起床后，对着镜子说："我是完整的人"
2. 列出今天最重要的3件事
3. 告诉自己："今天我允许自己不完美"
```

### 8.2 晚间练习

```
1. 回顾今天，列出2件做得好的事
2. 列出1件不满意的事，但不要批判
3. 对自己说："我今天尽力了"
4. 感恩自己今天活着、努力着
```

### 8.3 触发练习

当自我批评出现时：
```
1. 停下来，注意到这个想法
2. 问自己："这是事实还是评判？"
3. 问自己："我会对朋友说同样的话吗？"
4. 用更友善的话替换
```
