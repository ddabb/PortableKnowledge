## 六、特定场景的压力应对

### 6.1 截止日期压力

| 策略 | 说明 |
|------|------|
| 提前规划 | 不要等到最后一刻 |
| 分解任务 | 把任务分成小步骤 |
| 设定内部截止日期 | 比真实截止日期早几天 |
| 寻求延期 | 如果真的无法完成，主动沟通 |

### 6.2 人际冲突压力

| 策略 | 说明 |
|------|------|
| 先冷静 | 不要在愤怒时处理 |
| 换位思考 | 理解对方的立场 |
| 有效沟通 | 用非暴力沟通方式 |
| 寻求帮助 | 如果无法解决，寻求调解 |
| 设定界限 | 如果持续被欺负，学会保护自己 |

### 6.3 不确定性压力

| 策略 | 说明 |
|------|------|
| 聚焦可控 | 关注你能控制的 |
| 接受不确定 | 生活中有很多不确定 |
| 做好准备 | 为可能的情况做准备 |
| 保持灵活性 | 计划可以调整 |
| 寻求信息 | 减少因信息不足产生的焦虑 |
