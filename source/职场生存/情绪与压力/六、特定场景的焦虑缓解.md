## 六、特定场景的焦虑缓解

### 6.1 社交焦虑

| 策略 | 说明 |
|------|------|
| 从小事开始 | 先和一两个人聊天 |
| 准备话题 | 提前想好聊天内容 |
| 关注对方 | 把注意力放在对方身上 |
| 接受不完美 | 社交不完美是正常的 |
| 逐步挑战 | 每次进步一点点 |

### 6.2 工作焦虑

| 策略 | 说明 |
|------|------|
| 分解任务 | 把大任务分解成小步骤 |
| 设置优先级 | 聚焦最重要的事 |
| 设定边界 | 工作时间和休息时间分开 |
| 寻求反馈 | 主动和领导沟通 |
| 允许不完美 | 完美主义是焦虑来源 |

### 6.3 健康焦虑

| 策略 | 说明 |
|------|------|
| 限制搜索 | 不要过度搜索症状 |
| 定期体检 | 用数据代替猜测 |
| 相信身体 | 身体有不适会告诉你 |
| 分散注意力 | 关注积极的事情 |
