## 六、特殊情况处理

### 6.1 愤怒即将爆发时

| 行动 | 说明 |
|------|------|
| 离开现场 | "我需要冷静一下" |
| 物理隔离 | 回到自己的房间 |
| 冷水 | 洗把脸 |
| 倒数 | 从10倒数到1 |

### 6.2 后悔说了伤人的话

| 步骤 | 行动 |
|------|------|
| 1 | 冷静后承认错误 |
| 2 | 道歉但不找借口 |
| 3 | 解释你的感受（不是辩解）|
| 4 | 承诺改变行为 |
| 5 | 行动上做出改变 |

### 6.3 面对别人的愤怒

| 方法 | 说明 |
|------|------|
| 保持冷静 | 不要被激怒 |
| 倾听 | 让对方说完 |
| 共情 | "我理解你很生气" |
| 设边界 | "你可以生气，但不能侮辱我" |
