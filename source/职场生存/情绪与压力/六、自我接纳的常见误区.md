## 六、自我接纳的常见误区

### 6.1 误区

| 误区 | 说明 |
|------|------|
| "自我接纳=不求上进" | 接受不等于放弃成长 |
| "自我接纳=自恋" | 接纳不是夸大自己 |
| "我已经定型了" | 人是可以改变的 |
| "必须完全接纳才能行动" | 在行动中学会接纳 |

### 6.2 正确理解

| 理解 | 说明 |
|------|------|
| 接纳≠认可 | 接纳不等于认可现状 |
| 接纳≠放弃 | 接纳是改变的前提 |
| 接纳≠完美 | 接纳允许不完美 |
| 接纳≠立刻做到 | 自我接纳是长期练习 |
