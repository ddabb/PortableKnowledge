## 六、陪伴悲伤中的人

### 6.1 应该做的

| 做法 | 说明 |
|------|------|
| **在场** | 陪伴比说教重要 |
| **倾听** | 让对方说出感受 |
| **共情** | "我能理解你的痛苦" |
| **具体帮助** | 提供实际帮助 |
| **持续关心** | 悲伤会持续很久 |

### 6.2 不应该做的

| ❌ 错误做法 | 问题 |
|-------------|------|
| "你应该快点走出来" | 给压力 |
| "时间会治愈一切" | 轻视痛苦 |
| "我懂你的感受" | 可能不真实 |
| "你要坚强" | 否定悲伤 |
| "比我经历的差远了" | 比较伤害 |
