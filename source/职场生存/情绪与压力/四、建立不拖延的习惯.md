## 四、建立不拖延的习惯

### 4.1 习惯养成

| 步骤 | 说明 |
|------|------|
| 1. 固定时间 | 每天同一时间做同一件事 |
| 2. 从小事开始 | 不要一开始就挑战高难度 |
| 3. 坚持21天 | 形成习惯需要时间 |
| 4. 给自己奖励 | 完成后奖励自己 |

### 4.2 每日计划

```
【每日三件事】
1. 今天最重要的任务（优先完成）
2. 今天第二重要的任务
3. 今天可以完成的小任务

【执行策略】
- 早上先做最难的事
- 每完成一项打勾
- 完不成明天继续
```
