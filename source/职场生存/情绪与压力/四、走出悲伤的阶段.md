## 四、走出悲伤的阶段

### 4.1 短期应对

| 策略 | 说明 |
|------|------|
| **即时减压** | 深呼吸、放松练习 |
| **分散注意力** | 看书、散步 |
| **寻求支持** | 和朋友家人待在一起 |
| **日常routine** | 保持基本生活规律 |

### 4.2 中期调整

| 策略 | 说明 |
|------|------|
| **面对现实** | 接受失去已经发生 |
| **调整生活** | 适应新的生活状态 |
| **建立新联系** | 拓展新的关系 |
| **寻找意义** | 从悲伤中找到成长 |

### 4.3 长期疗愈

| 策略 | 说明 |
|------|------|
| **整合记忆** | 把失去融入生命故事 |
| **延续联系** | 保持与逝者的精神联系 |
| **重建身份** | 适应新的自我认同 |
| **帮助他人** | 用自己的经历帮助别人 |
| **继续前行** | 带着悲伤继续生活 |
