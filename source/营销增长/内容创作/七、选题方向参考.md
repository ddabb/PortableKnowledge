## 七、选题方向参考

### 7.1 高赞选题方向

| 方向 | 示例标题 |
|------|---------|
| **职场晋升** | "领导真正喜欢的员工，都做对了这3点" |
| **人际处理** | "被同事排挤怎么办？过来人教你3招" |
| **认知升级** | "为什么你很努力，却还是穷" |
| **情感关系** | "那个离开你的人，不值得" |
| **学习方法** | "每天1小时，我用3年追上同龄人" |

### 7.2 选题自检清单

- [ ] 这个选题对我有什么价值？
- [ ] 读者读完能得到什么？
- [ ] 为什么现在写这个选题？
- [ ] 有没有其他人写过类似角度？
- [ ] 我的独特视角是什么？
