## 二、标题：决定打开率

### 2.1 标题公式

| 公式 | 示例 |
|------|------|
| **数字+悬念** | "3个方法，让收入翻倍" |
| **痛点+方案** | "总被怼？学会这招反击" |
| **身份+数字** | "30岁前，必须明白的5个道理" |
| **颠覆+好奇** | "努力不一定成功，但这个方法可以" |
| **对比+冲突** | "月薪3千和3万的人差在哪里" |

### 2.2 标题修改检查表

- [ ] 包含数字（人脑对数字敏感）
- [ ] 有情绪词（震惊/绝了/终于等）
- [ ] 有悬念或利益承诺
- [ ] 口语化，读起来顺口
- [ ] 不超过25个字
- [ ] 不是陈述句而是对话感

### 2.3 常见误区

❌ **避免：**
- 标题党（与内容不符）
- 太文艺（读者看不懂）
- 没有信息量（"聊聊xxx"）
- 太泛（"关于xxx的一些思考"）
