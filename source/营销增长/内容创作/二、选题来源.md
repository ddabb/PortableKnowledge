## 二、选题来源

### 2.1 读者反馈

| 来源 | 价值 |
|------|------|
| 后台留言 | 直接知道读者关心什么 |
| 私信问题 | 具体需求，痛点明确 |
| 评论区 | 读者真实想法 |
| 问卷调查 | 系统收集需求 |

### 2.2 竞品分析

| 分析内容 | 方法 |
|---------|------|
| 高赞文章 | 收藏、转发多的文章 |
| 评论区 | 读者讨论的焦点 |
| 更新频率 | 什么类型更新最勤 |
| 标题规律 | 爆款标题的共同点 |

### 2.3 平台数据

| 平台 | 数据来源 |
|------|----------|
| 公众号 | 看看谁的10万+ |
| 知乎 | 热榜、问题收藏量 |
| 小红书 | 爆款笔记分析 |
| 抖音 | 热榜话题 |

### 2.4 日常积累

| 素材 | 来源 |
|------|------|
| 读书笔记 | 书中的观点和案例 |
| 工作经历 | 真实的职场故事 |
| 生活观察 | 对人对事的思考 |
| 行业动态 | 新趋势、新变化 |
| 影视综艺 | 热门内容的观点切入 |
