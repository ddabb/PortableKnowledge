## 八、排版：视觉体验

### 8.1 基础排版

| 项目 | 标准 |
|------|------|
| 正文字号 | 15-16px |
| 行间距 | 1.5-1.8倍 |
| 段间距 | 空一行 |
| 两端缩进 | 8-16px |
| 重点标注 | 加粗/变色 |

### 8.2 配图原则

| 原则 | 说明 |
|------|------|
| 相关性 | 图片要配合内容 |
| 高质量 | 不模糊、不水印 |
| 版权 | 使用免费/原创图片 |
| 数量 | 长文配3-5张图 |

### 8.3 封面图设计

| 要素 | 说明 |
|------|------|
| 文字大 | 封面文字要醒目 |
| 颜色对比 | 背景和文字颜色反差 |
| 留白 | 不要太满 |
| 尺寸 | 900×383像素 |
