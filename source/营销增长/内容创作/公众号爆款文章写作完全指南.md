## 一、选题：爆款的起点

### 1.1 好选题的三个标准

| 标准 | 说明 | 自检问题 |
|------|------|---------|
| **有共鸣** | 触动读者情绪 | 读者会想转发吗？ |
| **有价值** | 提供新认知或实用方法 | 读者能得到什么？ |
| **有独特性** | 差异化角度 | 为什么是你写？ |

### 1.2 选题来源

| 来源 | 说明 | 示例 |
|------|------|------|
| **痛点型** | 解决读者实际问题 | "职场沟通" |
| **热点型** | 蹭当下热点 | 节日/事件/热搜 |
| **颠覆型** | 反常识/反直觉 | "努力没用" |
| **故事型** | 有代入感的故事 | 真实经历 |
| **盘点型** | 信息汇总整理 | 年度总结 |

### 1.3 选题评估矩阵

| 维度 | 1分 | 2分 | 3分 | 4分 | 5分 |
|------|-----|-----|-----|-----|-----|
| 受众广度 | 极窄 | 较窄 | 一般 | 较广 | 很广 |
| 情绪强度 | 无感 | 轻微 | 中等 | 较强 | 很强 |
| 实用价值 | 无 | 较低 | 一般 | 较高 | 很高 |
| 稀缺程度 | 烂大街 | 常见 | 一般 | 较少 | 独家 |

**评分≥15分值得写，≥18分大概率爆款**

## 二、标题：决定打开率

### 2.1 标题公式

| 公式 | 示例 |
|------|------|
| **数字+悬念** | "3个方法，让收入翻倍" |
| **痛点+方案** | "总被怼？学会这招反击" |
| **身份+数字** | "30岁前，必须明白的5个道理" |
| **颠覆+好奇** | "努力不一定成功，但这个方法可以" |
| **对比+冲突** | "月薪3千和3万的人差在哪里" |

### 2.2 标题修改检查表

- [ ] 包含数字（人脑对数字敏感）
- [ ] 有情绪词（震惊/绝了/终于等）
- [ ] 有悬念或利益承诺
- [ ] 口语化，读起来顺口
- [ ] 不超过25个字
- [ ] 不是陈述句而是对话感

### 2.3 常见误区

❌ **避免：**
- 标题党（与内容不符）
- 太文艺（读者看不懂）
- 没有信息量（"聊聊xxx"）
- 太泛（"关于xxx的一些思考"）

## 三、开头：留住读者

### 3.1 黄金5秒法则

读者给你5秒钟决定是否继续读。开头必须：

1. **制造悬念** - 抛出问题或反常识观点
2. **引发好奇** - "你知道吗..."
3. **建立共鸣** - "你是不是也..."

### 3.2 开头模板

```
【痛点共鸣型】
你是不是也...（痛点描述）
但是...（转折，引出下文）

【数据震撼型】
XX数据显示...（惊人数据）
但更惊人的是...

【故事切入型】
我见过一个XX的人...
他/她后来...

【颠覆认知型】
大多数人都错了...
真正的答案是...
```

## 四、结构：让文章可读

### 4.1 经典结构

| 结构 | 适用场景 | 模板 |
|------|---------|------|
| **总-分-总** | 方法论、观点类 | 结论先行→分点论证→总结升华 |
| **是什么-为什么-怎么办** | 概念解读 | 三段式递进 |
| **故事+感悟** | 情感文、经验分享 | 故事叙述→道理提炼 |
| **并列式** | 盘点、干货类 | 多个独立模块串联 |

### 4.2 段落技巧

| 技巧 | 说明 |
|------|------|
| **短段落** | 手机阅读，段落不超过5行 |
| **多空行** | 给读者喘息空间 |
| **小标题** | 长文章必须有，助快速浏览 |
| **图文配合** | 每300-500字配一张图 |

### 4.3 句子技巧

| 技巧 | 示例 |
|------|------|
| **短句** | "他说，我等。" |
| **对话感** | "你有没有想过..." |
| **具体化** | "3个月"比"一段时间"好 |
| **动词优先** | 少用"是、有、成为" |

## 五、金句：让读者想转发

### 5.1 金句的特征

| 特征 | 说明 |
|------|------|
| **简短有力** | 一句话说清 |
| **朗朗上口** | 对仗/押韵 |
| **引发共鸣** | 说到心坎上 |
| **值得收藏** | 读者想截图保存 |

### 5.2 金句模板

| 类型 | 公式 | 示例 |
|------|------|------|
| **观点型** | XX不是XX，XX才是XX | "努力不是加班，加班不是成长" |
| **对比型** | XX和XX之间，差的是XX | "普通和优秀的差距，在于思维" |
| **反问型** | 你有没有想过... | "你有没有想过，为什么总被占便宜" |
| **行动型** | 要XX，不要XX | "要主动表达，不要被动等待" |

### 5.3 放置位置

- **标题下方** - 全文核心观点
- **每个小节后** - 总结要点
- **结尾升华** - 点睛之笔

## 六、结尾：引导行动

### 6.1 结尾类型

| 类型 | 适用 | 示例 |
|------|------|------|
| **总结升华** | 干货文 | "总之..." |
| **情感号召** | 情感文 | "如果你也..." |
| **互动提问** | 所有类型 | "你怎么看？" |
| **系列预告** | 连续内容 | "下期预告..." |

### 6.2 引导关注话术

| 话术 | 场景 |
|------|------|
| "关注我，下期讲..." | 系列内容 |
| "收藏备用，总会用到的" | 干货内容 |
| "转发给你关心的人" | 情感内容 |

## 七、选题方向参考

### 7.1 高赞选题方向

| 方向 | 示例标题 |
|------|---------|
| **职场晋升** | "领导真正喜欢的员工，都做对了这3点" |
| **人际处理** | "被同事排挤怎么办？过来人教你3招" |

| **情感关系** | "那个离开你的人，不值得" |
| **学习方法** | "每天1小时，我用3年追上同龄人" |

### 7.2 选题自检清单

- [ ] 这个选题对我有什么价值？
- [ ] 读者读完能得到什么？
- [ ] 为什么现在写这个选题？
- [ ] 有没有其他人写过类似角度？
- [ ] 我的独特视角是什么？

## 八、排版：视觉体验

### 8.1 基础排版

| 项目 | 标准 |
|------|------|
| 正文字号 | 15-16px |
| 行间距 | 1.5-1.8倍 |
| 段间距 | 空一行 |
| 两端缩进 | 8-16px |
| 重点标注 | 加粗/变色 |

### 8.2 配图原则

| 原则 | 说明 |
|------|------|
| 相关性 | 图片要配合内容 |
| 高质量 | 不模糊、不水印 |
| 版权 | 使用免费/原创图片 |
| 数量 | 长文配3-5张图 |

### 8.3 封面图设计

| 要素 | 说明 |
|------|------|
| 文字大 | 封面文字要醒目 |
| 颜色对比 | 背景和文字颜色反差 |
| 留白 | 不要太满 |
| 尺寸 | 900×383像素 |

## 十一、写作习惯

### 11.1 建立素材库

| 素材 | 来源 |
|------|------|
| 选题库 | 日常灵感和热点记录 |
| 标题库 | 收藏好标题分析 |
| 金句库 | 读书/影视/生活感悟 |
| 故事库 | 自己和身边人的故事 |

### 11.2 写作节奏

| 方法 | 说明 |
|------|------|
| **定时写作** | 固定时间写，培养习惯 |
| **碎片写作** | 手机备忘录随时记录 |
| **批量写作** | 集中时间写多篇 |
| **先完成再完美** | 初稿不追求完美 |

### 11.3 写作检查清单

- [ ] 选题是否吸引人
- [ ] 标题是否有打开欲望
- [ ] 开头是否留住读者
- [ ] 结构是否清晰
- [ ] 金句是否有传播力
- [ ] 结尾是否引导行动
- [ ] 排版是否舒适
