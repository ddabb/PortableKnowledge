## 六、正文写作

### 6.1 正文结构

```
【开头】（50字内）
│ 吸引注意 │ "真的绝了！这个XX我回购了5次"

【正文】（300-800字）
│ 核心内容 │ 介绍产品/经历/方法
│ 细节描述 │ 具体效果、使用体验
│ 个人观点 │ 真实评价

【结尾】（50字内）
│ 行动引导 │ "评论区告诉我你们想看什么"
│ 互动引导 │ "你们有更好的推荐吗"
```

### 6.2 正文技巧

| 技巧 | 说明 |
|------|------|
| **分段清晰** | 每段不超过3行 |
| **emoji适度** | 每段加1-2个emoji |
| **关键词** | 适当植入搜索关键词 |
| **口语化** | 像和朋友聊天 |
| **真实感** | 加入个人真实体验 |

### 6.3 种草文案模板

```
✨产品名称
📍入手价格/渠道
👀使用感受：
① 第一感受...
② 使用效果...
③ 优缺点...

💰性价比：⭐⭐⭐⭐⭐

❌缺点：...
✅总结：适合xx人群，不适合xx人群
```
