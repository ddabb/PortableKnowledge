## 一、选题的本质

### 1.1 什么是好选题

好选题 = 有人想看 + 你能写好 + 对你有价值

| 维度 | 问题 |
|------|------|
| **有人想看** | 目标读者关心这个话题吗？ |
| **你能写好** | 你有独特经历或见解吗？ |
| **对你有价值** | 能强化你的定位或吸引目标读者吗？ |

### 1.2 选题的三个层次

| 层次 | 类型 | 示例 | 效果 |
|------|------|------|------|
| **浅层** | 热点资讯 | 热点事件解读 | 短期流量 |
| **中层** | 方法干货 | 具体技巧和步骤 | 稳定涨粉 |
| **深层** | 认知升级 | 新观点、新角度 | 建立影响力 |

**最佳策略：** 浅层蹭热点+中层给干货+深层建壁垒

## 三、选题评估方法

### 3.1 选题评估矩阵

| 评估维度 | 1分 | 2分 | 3分 | 4分 | 5分 |
|---------|-----|-----|-----|-----|-----|
| **受众广度** | 只有几个人关心 | 小圈子 | 一般 | 较大群体 | 很广泛 |
| **痛点强度** | 可有可无 | 轻微不适 | 一般 | 明显痛点 | 强烈痛点 |
| **情绪调动** | 平静 | 轻微波动 | 中等 | 较强情绪 | 强烈共鸣 |
| **实用价值** | 无实际用处 | 有点用 | 一般 | 较实用 | 非常实用 |
| **稀缺程度** | 到处都有 | 常见 | 一般 | 较少见 | 独家角度 |

**评分标准：**
- ≥18分：必写，大概率爆款
- 15-17分：值得写
- 12-14分：可写可不写
- <12分：不写

### 3.2 选题自检问题

| 问题 | 判断标准 |
|------|----------|
| 这篇文章读者看完会得到什么？ | 能说清楚才写 |
| 读者会转发给谁？ | 有转发理由才写 |
| 这篇文章和已有文章有什么不同？ | 有差异化才写 |
| 我为什么能写好这个选题？ | 有独特优势才写 |
| 现在是写这个选题的好时机吗？ | 时机合适才写 |

## 四、选题库建设

### 4.1 选题库结构

```
选题库/
├── 选题池（待评估）
├── 选题清单（已评估待写）
├── 写作计划（本周/本月）
└── 已发布文章
```

### 4.2 选题记录格式

| 字段 | 说明 | 示例 |
|------|------|------|
| 选题名称 | 简短描述 | 职场沟通技巧 |
| 选题类型 | 热点/干货/情感 | 干货 |
| 目标读者 | 谁会读 | 职场新人 |
| 核心观点 | 文章要表达什么 | 主动汇报很重要 |
| 差异化角度 | 和别人有什么不同 | 领导视角分析 |
| 预计字数 | 预估长度 | 2000字 |
| 预估难度 | 1-5分 | 3分 |
| 截止日期 | 什么时候写 | 下周三 |

### 4.3 选题库维护

| 动作 | 频率 | 内容 |
|------|------|------|
| 日常积累 | 随时 | 发现灵感立即记录 |
| 周度整理 | 每周 | 筛选、评估选题 |
| 月度复盘 | 每月 | 复盘已发布文章，调整方向 |

## 六、选题执行流程

### 6.1 日常选题发现

```
Step 1: 灵感记录（3分钟）
└── 看到/听到/想到什么，立即记录

Step 2: 初步评估（1分钟）
└── 问自己：这个值得写吗？

Step 3: 入选题池
└── 值得写 → 加入选题库
```

### 6.2 周度选题会

| 环节 | 时长 | 内容 |
|------|------|------|
| 数据复盘 | 10分钟 | 上周文章数据 |
| 热点讨论 | 10分钟 | 本周热点 |
| 选题筛选 | 20分钟 | 从选题库选本周选题 |
| 任务分配 | 10分钟 | 确定写作者和时间 |

### 6.3 写前准备

| 时间 | 任务 |
|------|------|
| 写前1天 | 确定大纲和素材 |
| 写前2小时 | 再次确认选题方向 |
| 写作中 | 按大纲写，不偏离 |
| 写完后 | 检查是否扣题 |

## 七、选题常见问题

### 7.1 不知道写什么

| 解决方案 | 操作方法 |
|---------|---------|
| 建立选题库 | 日常积累灵感 |
| 拆解竞品 | 看高赞文章找方向 |
| 回答问题 | 从读者问题中找选题 |
| 热点延伸 | 蹭热点找角度 |

### 7.2 选题太宽泛

❌ 错误："职场发展"
✅ 正确："工作3年还没晋升，可能是这3个原因"

### 7.3 选题同质化

| 问题 | 解决方案 |
|------|----------|
| 别人写过了 | 换角度/加案例/加数据 |
| 没有差异化 | 找到自己的独特经历 |
| 没有新观点 | 深挖一层，找本质 |

## 八、选题时间管理

### 8.1 批量写作流程

| 步骤 | 时间 | 内容 |
|------|------|------|
| 1. 集中选题 | 2小时 | 一次想好10个选题 |
| 2. 集中大纲 | 2小时 | 把大纲都列出来 |
| 3. 集中写作 | 4-6小时 | 批量写完 |
| 4. 排版发布 | 1小时 | 排版+发布 |

### 8.2 日常选题习惯

| 习惯 | 说明 |
|------|------|
| 看到好内容就记录 | 备忘录随时记录 |
| 定期翻看选题库 | 避免灵感流失 |
| 每周新增10个选题 | 保持选题池充足 |
| 定期清理选题库 | 删除过时选题 |

## 九、选题复盘

### 9.1 数据复盘维度

| 数据 | 分析问题 |
|------|----------|
| 阅读量 | 选题是否吸引人 |
| 打开率 | 标题是否好 |
| 分享率 | 是否有传播点 |
| 收藏率 | 是否有实用价值 |
| 评论 | 读者反馈如何 |

### 9.2 复盘问题

| 问题 | 后续行动 |
|------|----------|
| 阅读量低 | 重新评估选题方向 |
| 打开率低 | 优化标题 |
| 分享率低 | 增强金句和情绪 |
| 收藏率低 | 增加实用内容 |
