## 十、数据复盘

### 10.1 关键指标

| 指标 | 说明 | 达标值 |
|------|------|--------|
| 打开率 | 打开/推送人数 | >5% |
| 分享率 | 分享/阅读人数 | >3% |
| 收藏率 | 收藏/阅读人数 | >2% |
| 读完率 | 读完全文比例 | >50% |

### 10.2 复盘维度

| 维度 | 问题 |
|------|------|
| 选题 | 话题是否足够吸引 |
| 标题 | 是否有吸引力 |
| 开头 | 跳出率是否过高 |
| 结构 | 读者是否读完 |
| 金句 | 是否有传播点 |
