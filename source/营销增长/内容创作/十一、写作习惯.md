## 十一、写作习惯

### 11.1 建立素材库

| 素材 | 来源 |
|------|------|
| 选题库 | 日常灵感和热点记录 |
| 标题库 | 收藏好标题分析 |
| 金句库 | 读书/影视/生活感悟 |
| 故事库 | 自己和身边人的故事 |

### 11.2 写作节奏

| 方法 | 说明 |
|------|------|
| **定时写作** | 固定时间写，培养习惯 |
| **碎片写作** | 手机备忘录随时记录 |
| **批量写作** | 集中时间写多篇 |
| **先完成再完美** | 初稿不追求完美 |

### 11.3 写作检查清单

- [ ] 选题是否吸引人
- [ ] 标题是否有打开欲望
- [ ] 开头是否留住读者
- [ ] 结构是否清晰
- [ ] 金句是否有传播力
- [ ] 结尾是否引导行动
- [ ] 排版是否舒适
