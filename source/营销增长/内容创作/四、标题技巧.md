## 四、标题技巧

### 4.1 标题公式

| 公式 | 示例 |
|------|------|
| **人群标签+痛点/爽点** | "微胖女生闭眼入，显瘦神裤" |
| **数字+效果** | "坚持21天，法令纹真的淡了" |
| **疑问句制造悬念** | "这件单品凭什么火10年？" |
| **感叹句表达情绪** | "太好用了！后悔没早点买" |
| **对比反差** | "30块和300块的口红有什么区别" |

### 4.2 标题关键词

| 关键词类型 | 示例词 |
|-----------|--------|
| 人群词 | 学生党、宝妈、上班族、微胖 |
| 效果词 | 显瘦、显白、显高级、显脸小 |
| 情绪词 | 绝了、太好看了、YYDS、哭死 |
| 引导词 | 闭眼入、冲、必买、都给我买 |
| 数字词 | 3招、10件、100元、30天 |

### 4.3 标题检查清单

- [ ] 包含人群词（精准触达）
- [ ] 包含效果/情绪词（引发共鸣）
- [ ] 有数字（增加可信度）
- [ ] 有悬念或利益点（引发点击）
- [ ] 不超过20个字
