## 四、结构：让文章可读

### 4.1 经典结构

| 结构 | 适用场景 | 模板 |
|------|---------|------|
| **总-分-总** | 方法论、观点类 | 结论先行→分点论证→总结升华 |
| **是什么-为什么-怎么办** | 概念解读 | 三段式递进 |
| **故事+感悟** | 情感文、经验分享 | 故事叙述→道理提炼 |
| **并列式** | 盘点、干货类 | 多个独立模块串联 |

### 4.2 段落技巧

| 技巧 | 说明 |
|------|------|
| **短段落** | 手机阅读，段落不超过5行 |
| **多空行** | 给读者喘息空间 |
| **小标题** | 长文章必须有，助快速浏览 |
| **图文配合** | 每300-500字配一张图 |

### 4.3 句子技巧

| 技巧 | 示例 |
|------|------|
| **短句** | "他说，我等。" |
| **对话感** | "你有没有想过..." |
| **具体化** | "3个月"比"一段时间"好 |
| **动词优先** | 少用"是、有、成为" |
