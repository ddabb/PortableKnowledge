## 一、小红书平台特性

### 1.1 平台定位

| 特性 | 说明 |
|------|------|
| **用户画像** | 18-35岁女性为主，追求品质生活 |
| **内容调性** | 真实、精致、有生活气息 |
| **核心价值** | 种草、分享、发现美好生活 |

### 1.2 内容形式

| 形式 | 特点 | 适用场景 |
|------|------|---------|
| **图文笔记** | 9宫格图片+正文 | 好物分享、攻略 |
| **视频笔记** | 1-5分钟视频 | 教程、vlog |
| **直播** | 实时互动 | 带货、答疑 |

### 1.3 流量机制

| 流量池 | 说明 |
|--------|------|
| 初始流量 | 200-500曝光 |
| 初级流量池 | 2000-5000曝光 |
| 中级流量池 | 1万-10万曝光 |
| 高级流量池 | 10万+曝光 |
| 爆款笔记 | 100万+曝光 |

**触发升级条件：** 点赞/收藏/评论/分享数据好

## 二、账号定位

### 2.1 定位三问

| 问题 | 答案 |
|------|------|
| 你是谁？ | 个人标签 |
| 你做什么？ | 内容领域 |
| 为什么关注你？ | 独特价值 |

### 2.2 常见定位方向

| 方向 | 示例 | 内容类型 |
|------|------|---------|
| **美妆护肤** | 口红试色、护肤心得 | 测评、好物推荐 |
| **穿搭时尚** | 每日穿搭、单品搭配 | 搭配、购物分享 |
| **美食探店** | 餐厅推荐、食谱分享 | 探店、食谱 |
| **旅行攻略** | 目的地分享、出行tips | 攻略、vlog |
| **家居生活** | 家居好物、收纳技巧 | 分享、教程 |
| **母婴育儿** | 育儿经验、好物分享 | 经验、好物 |
| **职场成长** | 职场技巧、自我提升 | 干货、vlog |
| **知识干货** | 技能分享、学习方法 | 教程、干货 |

### 2.3 账号信息设置

| 项目 | 要求 | 示例 |
|------|------|------|
| **头像** | 清晰、有辨识度 | 真人照片/品牌logo |
| **昵称** | 好记、体现定位 | "XX爱穿搭" |

## 四、标题技巧

### 4.1 标题公式

| 公式 | 示例 |
|------|------|
| **人群标签+痛点/爽点** | "微胖女生闭眼入，显瘦神裤" |
| **数字+效果** | "坚持21天，法令纹真的淡了" |
| **疑问句制造悬念** | "这件单品凭什么火10年？" |
| **感叹句表达情绪** | "太好用了！后悔没早点买" |
| **对比反差** | "30块和300块的口红有什么区别" |

### 4.2 标题关键词

| 关键词类型 | 示例词 |
|-----------|--------|
| 人群词 | 学生党、宝妈、上班族、微胖 |
| 效果词 | 显瘦、显白、显高级、显脸小 |
| 情绪词 | 绝了、太好看了、YYDS、哭死 |
| 引导词 | 闭眼入、冲、必买、都给我买 |
| 数字词 | 3招、10件、100元、30天 |

### 4.3 标题检查清单

- [ ] 包含人群词（精准触达）
- [ ] 包含效果/情绪词（引发共鸣）
- [ ] 有数字（增加可信度）
- [ ] 有悬念或利益点（引发点击）
- [ ] 不超过20个字

## 六、正文写作

### 6.1 正文结构

```
【开头】（50字内）
│ 吸引注意 │ "真的绝了！这个XX我回购了5次"

【正文】（300-800字）
│ 核心内容 │ 介绍产品/经历/方法
│ 细节描述 │ 具体效果、使用体验
│ 个人观点 │ 真实评价

【结尾】（50字内）
│ 行动引导 │ "评论区告诉我你们想看什么"
│ 互动引导 │ "你们有更好的推荐吗"
```

### 6.2 正文技巧

| 技巧 | 说明 |
|------|------|
| **分段清晰** | 每段不超过3行 |
| **emoji适度** | 每段加1-2个emoji |
| **关键词** | 适当植入搜索关键词 |
| **口语化** | 像和朋友聊天 |
| **真实感** | 加入个人真实体验 |

### 6.3 种草文案模板

```
✨产品名称
📍入手价格/渠道
👀使用感受：
① 第一感受...
② 使用效果...
③ 优缺点...

💰性价比：⭐⭐⭐⭐⭐

❌缺点：...
✅总结：适合xx人群，不适合xx人群
```

## 九、数据分析

### 9.1 关键指标

| 指标 | 说明 | 达标值 |
|------|------|--------|
| 点击率 | 点击/曝光 | >5% |
| 点赞率 | 点赞/点击 | >5% |
| 收藏率 | 收藏/点击 | >5% |
| 评论率 | 评论/点击 | >1% |

### 9.2 数据诊断

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 点击低 | 封面/标题不吸引 | 优化封面图和标题 |
| 点赞低 | 内容不够好 | 提升内容质量 |
| 收藏低 | 实用价值不够 | 增加干货内容 |
| 评论低 | 互动引导不够 | 增加互动问题 |

## 十一、常见问题

### 11.1 数据不好怎么办

| 问题 | 分析 | 解决 |
|------|------|------|
| 小眼睛（曝光）少 | 账号权重低/话题冷门 | 优化话题，增加互动 |
| 点击率低 | 封面/标题不吸引 | 参考爆款封面和标题 |
| 收藏少 | 内容不够干货 | 增加实用信息 |
| 涨粉慢 | 人设不够鲜明 | 强化个人定位 |

### 11.2 账号初期建议

| 建议 | 说明 |
|------|------|
| 垂直深耕 | 专注一个领域 |
| 日更养成 | 前期多更新培养手感 |
| 参考爆款 | 分析高赞笔记 |
| 真实分享 | 做真实的自己 |
