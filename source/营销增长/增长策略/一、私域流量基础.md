## 一、私域流量基础

### 1.1 什么是私域流量

| 概念 | 说明 |
|------|------|
| **公域流量** | 平台分配的流量（抖音推荐、公众号推送）|
| **私域流量** | 可反复触达的用户（微信好友、社群、公众号粉丝）|

### 1.2 私域 vs 公域

| 对比 | 公域 | 私域 |
|------|------|------|
| 触达 | 被动，等平台分配 | 主动，可直接触达 |
| 费用 | 持续付费 | 一次性投入 |
| 稳定性 | 不稳定 | 稳定 |
| 用户关系 | 浅 | 深 |

### 1.3 私域价值

| 价值 | 说明 |
|------|------|
| **反复触达** | 随时发消息，用户能看到 |
| **深度运营** | 建立信任，提升转化 |
| **降低成本** | 减少对付费流量的依赖 |
| **数据资产** | 用户数据沉淀在自己手里 |
| **变现路径** | 直接向用户卖产品/服务 |
