## 七、内容涨粉

### 7.1 涨粉内容类型

| 类型 | 涨粉效果 | 特点 |
|------|----------|------|
| **系列文章** | 高 | 引导持续关注 |
| **独家内容** | 高 | 只有这里有 |
| **深度长文** | 中 | 展示专业能力 |
| **实用清单** | 中高 | 收藏后关注 |
| **观点鲜明** | 中 | 引发认同关注 |

### 7.2 文内涨粉技巧

| 位置 | 技巧 |
|------|------|
| **文章开头** | "关注我，每周..." |
| **文章中间** | "限于篇幅，关注后私信XX" |
| **文章结尾** | "如果对你有用，点个关注" |
| **金句旁边** | 金句处放引导 |

### 7.3 关注引导话术

| 话术 | 场景 |
|------|------|
| "关注我，下期讲..." | 系列内容预告 |
| "关注公众号，回复XX获取..." | 资料引流 |
| "如果对你有用，点个关注" | 真诚引导 |
| "关注不亏，每周更新..." | 价值承诺 |
