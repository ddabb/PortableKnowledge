## 三、激活（Activation）

### 3.1 什么是激活

让用户完成"aha moment"——首次感受到产品价值

| 产品类型 | aha moment |
|---------|------------|
| 公众号 | 读到第一篇有价值内容 |
| 社群 | 第一次获得有用信息 |
| 工具产品 | 第一次完成核心功能 |
| 电商 | 第一次下单成功 |

### 3.2 激活率计算

| 指标 | 计算 |
|------|------|
| 激活率 | 激活用户数 / 访问用户数 |

### 3.3 提升激活率

| 方法 | 说明 |
|------|------|
| **降低门槛** | 简化注册流程 |
| **引导体验** | 新手引导 |
| **价值前置** | 让用户快速感受到价值 |
| **减少干扰** | 减少无关内容 |
