## 九、私域避坑指南

### 9.1 常见误区

| 误区 | 后果 |
|------|------|
| **只发广告** | 被拉黑/退群 |
| **频繁骚扰** | 用户流失 |
| **虚假宣传** | 信任崩塌 |
| **过度打扰** | 被举报/封号 |
| **无差异化** | 没有竞争优势 |

### 9.2 正确做法

| 做法 | 说明 |
|------|------|
| **价值先行** | 先给价值再变现 |
| **真诚互动** | 真诚对待每个用户 |
| **持续输出** | 持续提供优质内容 |
| **用户分层** | 分层运营，提升效率 |
| **长期主义** | 私域是长期资产 |
