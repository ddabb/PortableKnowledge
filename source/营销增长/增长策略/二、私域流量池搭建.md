## 二、私域流量池搭建

### 2.1 私域载体层级

```
【第一层】公众号
│ 价值：内容沉淀，粉丝积累
│ 转化路径：关注→阅读→了解→信任

【第二层】微信好友
│ 价值：深度连接，直接触达
│ 转化路径：添加→互动→信任→成交

【第三层】社群
│ 价值：批量运营，用户激活
│ 转化路径：进群→活跃→信任→转化

【第四层】企业微信
│ 价值：高效管理，批量运营
│ 转化路径：添加→标签→分层运营
```

### 2.2 引流私域路径

| 引流来源 | 操作方法 |
|---------|----------|
| **公众号** | 文末引导加微信/进群 |
| **短视频** | 评论区引导/主页介绍 |
| **小红书** | 简介放微信号 |
| **知乎** | 简介/文末引导 |
| **线下活动** | 扫码进群 |
| **电商包裹** | 卡片引流 |

### 2.3 引流话术

| 场景 | 话术 |
|------|------|
| **公众号引流** | "点击下方卡片，添加我的微信，回复XX领取..." |
| **短视频引流** | "评论区扣1，我拉你进群" |
| **社群引流** | "扫码进群，XX福利免费送" |
| **私信引流** | "你好，感兴趣可以加我微信..." |
