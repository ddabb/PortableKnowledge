## 五、用户分层运营

### 5.1 用户分层

| 层级 | 定义 | 特征 | 运营策略 |
|------|------|------|----------|
| **潜在用户** | 未成交 | 有需求 | 培育引导 |
| **新用户** | 刚成交 | 观望中 | 建立信任 |
| **活跃用户** | 经常互动 | 认同你 | 深度运营 |
| **核心用户** | 高复购/高价值 | 铁粉 | VIP服务 |
| **流失用户** | 沉默/取关 | 已流失 | 召回 |

### 5.2 用户标签管理

| 标签维度 | 标签示例 |
|---------|---------|
| **来源** | 公众号/抖音/小红书 |
| **属性** | 性别/年龄/地区 |
| **行为** | 购买/未购买/活跃 |
| **偏好** | 产品类型/价格敏感度 |
| **价值** | 高价值/普通/待激活 |

### 5.3 分层运营策略

| 层级 | 运营策略 |
|------|----------|
| **潜在用户** | 持续提供价值，转化为购买 |
| **新用户** | 发送使用指南，增强信任 |
| **活跃用户** | 邀请参与活动，培养KOC |
| **核心用户** | 专属福利，VIP服务 |
| **流失用户** | 发送召回活动 |
