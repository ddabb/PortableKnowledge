## 六、多平台引流

### 6.1 平台选择

| 平台 | 特点 | 引流效果 |
|------|------|----------|
| 知乎 | 长图文，搜索流量大 | 中 |
| 今日头条 | 算法推荐，流量大 | 高 |
| 百家号 | 百度收录，搜索流量 | 中 |
| 企鹅号 | 腾讯分发 | 低 |
| 小红书 | 年轻女性为主 | 高 |

### 6.2 多平台分发技巧

| 技巧 | 说明 |
|------|------|
| **平台适配** | 根据平台调整内容形式 |
| **资料引流** | 个人简介放公众号名 |
| **文内引导** | 文章末尾引导关注公众号 |
| **平台规则** | 遵守各平台规则，避免限流 |

### 6.3 引流注意事项

| 注意事项 | 说明 |
|---------|------|
| 避免硬广 | 软性引导更有效 |
| 价值交换 | 先给价值，再引流 |
| 持续输出 | 各平台都需要持续更新 |
| 平台规则 | 遵守规则，避免被封 |
