## 十、增长避坑

### 10.1 常见误区

| 误区 | 后果 |
|------|------|
| **只关注获客** | 留不住用户 |
| **忽视留存** | 获客越多，流失越多 |
| **过早变现** | 用户还没信任 |
| **忽视数据** | 不知道问题在哪 |
| **追求短期** | 牺牲长期价值 |

### 10.2 正确做法

| 做法 | 说明 |
|------|------|
| **留存优先** | 先留住用户 |
| **价值为本** | 持续提供价值 |
| **数据驱动** | 用数据指导决策 |
| **长期主义** | 追求可持续增长 |
