## 三大基准值

| 缩写 | 全称 | 说明 |
|------|------|------|
| **PV** | 计划价值（Planned Value） | 计划在某时间点前应完成工作的预算成本 |
| **EV** | 挣值（Earned Value） | 实际已完成工作的预算成本（**最核心**） |
| **AC** | 实际成本（Actual Cost） | 实际已完成工作花费的实际成本 |

**另外**：
- **BAC**（完工预算）：项目总预算

## 偏差计算公式

| 指标 | 公式 | 含义 | 判断 |
|------|------|------|------|
| **CV**（成本偏差） | EV - AC | 成本节约或超支 | >0节约，<0超支 |
| **SV**（进度偏差） | EV - PV | 进度超前或滞后 | >0超前，<0滞后 |
| **CPI**（成本绩效指数） | EV / AC | 每花1元产生多少价值 | >1节约，<1超支 |
| **SPI**（进度绩效指数） | EV / PV | 实际完成与计划比率 | >1超前，<1滞后 |

**记忆口诀**：
- 偏差 = EV - 对比项（成本偏差 EV-AC，进度偏差 EV-PV）
- 指数 = EV ÷ 对比项（CPI = EV/AC，SPI = EV/PV）

## 完工预测公式

| 指标 | 公式（常用） | 说明 |
|------|------------|------|
| **ETC**（完工尚需估算） | (BAC - EV) / CPI | 按当前效率，还需要花多少钱 |
| **EAC**（完工估算） | AC + ETC = BAC / CPI | 项目完成时的预计总成本 |
| **VAC**（完工偏差） | BAC - EAC | 完工时节约/超支多少 |

## 典型例题

**题目**：某项目总预算BAC=100万元，计划完成60%，实际完成50%，实际花费55万元。求CV、SV、CPI、SPI、EAC。

**解题**：
- PV = 100 × 60% = **60万**
- EV = 100 × 50% = **50万**
- AC = **55万**（题目给出）

计算：
- CV = EV - AC = 50 - 55 = **-5万**（成本超支5万）
- SV = EV - PV = 50 - 60 = **-10万**（进度滞后）
- CPI = EV / AC = 50 / 55 ≈ **0.91**（每花1元只产出0.91元价值）
- SPI = EV / PV = 50 / 60 ≈ **0.83**（只完成计划的83%）
- EAC = BAC / CPI = 100 / 0.91 ≈ **110万**（预计完工总成本）

**结论**：该项目**成本超支、进度滞后**，形势不乐观。

## TCPI（完工绩效指数）

完成剩余工作所需的成本效率：

- 按照BAC完成：**TCPI = (BAC - EV) / (BAC - AC)**
- 按照EAC完成：**TCPI = (BAC - EV) / (EAC - AC)**

TCPI > 1：剩余工作需要比过去更高的效率才能实现目标  
TCPI < 1：目标容易达到，还有余量

## 快速记忆表

```
成本相关：   CV = EV - AC     CPI = EV/AC
进度相关：   SV = EV - PV     SPI = EV/PV
完工预测：   EAC = BAC/CPI    ETC = EAC - AC

正数/大于1 → 好
负数/小于1 → 不好
```
