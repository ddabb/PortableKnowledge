## 习得性无助的发现：为什么被电击的狗不再逃跑？

### 1.1 实验设计

1967年，心理学家Martin Seligman设计了一个实验：

| 组别 | 处理方式 |
|------|---------|
| 第一组 | 电击，但用鼻子碰隔板可停止（可控） |
| 第二组 | 电击，无法逃避（不可控） |
| 第三组 | 对照组，不遭受电击 |

### 1.2 令人震惊的结果

后续测试中，三组狗都被放在一个可以跳过隔板逃脱电击的环境中：

| 组别 | 反应 |
|------|------|
| 第一组 | 迅速学会跳过隔板逃脱 |
| 第三组 | 也很快学会逃脱 |
| **第二组** | **放弃挣扎，趴在原地承受电击** |

**第二组的狗不是不能逃脱，而是不再尝试。**

### 1.3 为什么？

| 心理过程 | 说明 |
|---------|------|
| 反复不可控 | 电击开始→尝试逃跑→没用→再试→还是没用 |
| 形成信念 | "我的行为无法改变结果" |
| 泛化 | 即使换了环境（可以逃脱），信念仍然存在 |
| 行为结果 | 放弃尝试，被动承受 |

### 1.4 实验的伦理争议

| 质疑 | 回应 |
|------|------|
| 对动物残忍 | 实验确实引发了动物伦理讨论 |
| 能否推广到人类 | 后续大量人类实验证实同样现象 |
| 是否必要 | 这个发现催生了抑郁理论和积极心理学 |

### 1.5 这个发现的影响

| 领域 | 贡献 |
|------|------|
| 抑郁理论 | 习得性无助→现代抑郁理论的重要基础 |
| 积极心理学 | Seligman后来转向研究"如何变得乐观" |
| 教育 | 帮助识别和预防学生的"放弃"行为 |
| 职场 | 理解员工的"躺平"心理 |

---

**本节要点：**
- 不可控电击组的狗在可以逃脱时也不尝试
- 原因：形成了"我的行为无法改变结果"的信念
- 信念会泛化到新环境，即使条件已改变
- 催生了抑郁理论、积极心理学等多个领域
