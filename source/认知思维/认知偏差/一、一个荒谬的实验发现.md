## 达克效应的荒诞起源：涂了柠檬汁去抢银行劫匪

### 1.1 一个真实的荒诞故事

1995年，美国匹兹堡发生了一起匪夷所思的抢劫案：

**McArthur Wheeler**在光天化日之下，抢了两家银行——**没有戴面具，没有任何伪装**。

监控摄像头清晰地拍下了他的脸。

被捕后，警方给他看监控录像，Wheeler的反应令人震惊：

> "可是我脸上涂了柠檬汁啊！我以为自己是隐形的！"

他真的相信柠檬汁可以让他在摄像头前隐形——因为柠檬汁可以当"隐形墨水"用。

### 1.2 不是精神病，是"不知道自己不知道"

Wheeler不是精神病患者：
- 他有正常的社交能力
- 他有犯罪计划
- 他只是**真的不知道自己有多蠢**

他缺的不是智商，而是**元认知能力**——评估自己能力的能力。

### 1.3 从劫匪到诺贝尔奖

这个荒诞案例引起了心理学家**David Dunning**和**Justin Kruger**的注意：

> **一个能力不足的人，能否正确评估自己的能力？**

他们开始研究，结果令人震惊：

| 发现 | 说明 |
|------|------|
| 底部25%的人 | 高估自己56个百分点 |
| 顶部25%的人 | 低估自己13个百分点 |
| 能力越低 | 自信越高 |
| 能力越高 | 反而越谦虚 |

**这就是邓宁-克鲁格效应（Dunning-Kruger Effect）。**

### 1.4 为什么这个发现重要？

| 影响 | 说明 |
|------|------|
| 解释了日常生活 | 为什么"半瓶水晃荡" |
| 揭示了认知盲区 | 最无知的人最不知道自己无知 |
| 提供了改善路径 | 元认知能力可以通过训练提升 |
| 预防危险决策 | 无知的自信可能导致灾难 |

### 1.5 Wheeler后来怎样了？

Wheeler因抢劫罪被判入狱。

但他的故事催生了一个改变心理学的理论——虽然他永远不会知道这一点。
