## 可得性启发：为什么你总觉得飞机比汽车危险？

### 什么是可得性启发？

**可得性启发（Availability Heuristic）** 由Tversky和Kahneman在1974年提出：

> 人们倾向于根据信息的**易获取程度**来判断事件的概率或频率——越容易被想起的事件，就越被认为更可能发生。

它是"启发式与偏误"研究的三大发现之一（另外两个是锚定效应和代表性启发）。

### 1.1 为什么大脑要用这个捷径？

| 大脑的现实 | 解决方案 |
|-----------|---------|
| 信息太多，无法全部处理 | 用"容易想到"代替"精确计算" |
| 大多数时候 shortcuts 是有效的 | 最近发生的事确实概率更高 |
| 节省认知资源 | 快速判断，省脑力 |

**问题在于**：有些事情"容易想到"不是因为概率高，而是因为**记忆更深刻**。

### 1.2 经典案例

**飞机 vs 汽车**：

| 数据 | 实际情况 | 人们的感觉 |
|------|---------|-----------|
| 汽车事故 | 每年全球135万人死亡 | "还好吧" |
| 飞机事故 | 每年全球约500人死亡 | "太危险了！" |
| 死亡率 | 开车是坐飞机的约100倍 | 反过来了 |

**为什么？** 飞机事故新闻铺天盖地（画面震撼），汽车事故每天发生（习以为常）。

**其他例子**：

| 事件 | 实际概率 | 感知概率 | 原因 |
|------|---------|---------|------|
| 鲨鱼袭击 | 极低（全球年死约10人） | 很高 | 电影《大白鲨》印象深刻 |
| 被狗咬 | 较高（全球年死约6万人） | 一般 | 不太报道 |
| 恐怖袭击 | 极低 | 很高 | 新闻反复播放 |
| 心脏病 | 极高（全球头号杀手） | 一般 | 不够戏剧化 |
| 中彩票 | 约1/1400万 | 觉得有希望 | 总有人中奖的新闻 |

### 1.3 影响可得性的因素

| 因素 | 举例 |
|------|------|
| **媒体的报道频率** | 新闻多的→觉得更常见 |
| **情绪的强度** | 恐惧、愤怒的→记忆更深 |
| **个人的亲身经历** | 自己遇到过→觉得概率高 |
| **生动性** | 有画面、有故事的→更容易想起 |
| **近期性** | 最近发生的→更容易想到 |

### 1.4 可得性启发的商业应用

| 应用场景 | 策略 |
|---------|------|
| 保险销售 | 先讲惨痛案例（提高可得性）再推销保险 |
| 公益广告 | 用真实故事（比数据更有说服力） |
| 产品营销 | 让用户想象使用场景（提高可得性） |
| 健康教育 | 用患者真实故事而非统计数据 |

---

**本节要点：**
- 可得性启发：用"容易想到"代替"精确计算"来判断概率
- 飞机比汽车"感觉危险"，实际安全100倍
- 媒体报道、情绪强度、亲身经历→影响可得性
- 商业中广泛利用：保险、公益、营销、健康教育
