## 破窗效应的起源：一个警察局局长的直觉改变了整个纽约

### 1.1 理论的提出

1982年，犯罪学家**James Wilson**和**George Kelling**在《The Atlantic》发表文章，提出了著名的"破窗理论"：

> 如果一栋建筑有一扇窗户破了而没有修理，其他的窗户也会很快被打破。原因是：**破窗传递了一个信号——这里没有人管，破坏规则是可以接受的。**

### 1.2 核心观点

| 层次 | 说明 |
|------|------|
| **表面** | 一扇破窗 → 更多破窗 |
| **深层** | 轻微失序 → 严重犯罪 |
| **机制** | 环境信号 → 降低规范遵从 → 失序扩散 |

### 1.3 纽约地铁的实践

1990年代，纽约交通局长**David Gunn**和警察局长**William Bratton**将破窗理论付诸实践：

| 措施 | 效果 |
|------|------|
| 清理地铁涂鸦 | 列车不带着涂鸦出站，涂鸦者失去"展示舞台" |
| 严厉打击逃票 | 从最小违规开始执法 |
| 逮捕轻微违法者 | 管控行乞、酗酒、随地大小便 |
| 清理地铁站环境 | 灯光变亮、垃圾清走 |

**结果**：

| 指标 | 变化 |
|------|------|
| 重罪案件 | 1990-2000年下降约50% |
| 地铁犯罪 | 1990-2000年下降约75% |
| 乘客体验 | 显著改善，地铁重新成为安全出行方式 |

### 1.4 从"破窗"到"零容忍"

纽约的经验被推广为**"零容忍"（Zero Tolerance）**政策，影响了全球多个城市的治安策略：

| 城市 | 采纳情况 |
|------|---------|
| 洛杉矶 | 部分采纳 |
| 伦敦 | 借鉴经验 |
| 东京 | 本身秩序良好，但理论被研究 |
| 中国城市 | 部分城市借鉴（如城管执法逻辑） |

### 1.5 后续争议

虽然纽约的数据很亮眼，但学术界对破窗理论的解释力有争议（详见"警惕破窗效应的滥用"一节）：

- 犯罪率下降可能是多种因素共同作用
- 轻微犯罪和严重犯罪的因果关系可能被简化
- "零容忍"可能被滥用为侵犯公民自由的工具

- 后续有争议，但理论本身在微观层面仍有价值
