## 锚定效应是怎么被发现的？转盘实验揭示惊人真相

### 1.1 经典实验

1974年，Tversky和Kahneman做了一个惊人的实验：

**实验设计**：
1. 让两组受试者转动一个0-100的数字转盘
2. 问：非洲国家占联合国的比例是多少？

**结果**：

| 转盘数字 | 平均估计值 |
|----------|-----------|
| 10以下 | 25% |
| 65以上 | 45% |

**转盘数字和真实答案完全无关，但显著影响了人们的判断。**

### 1.2 更惊人的发现

| 尝试 | 结果 |
|------|------|
| 告知"转盘是随机的" | 锚定效应依然存在 |
| 告诉专家 | 效应没有减弱 |
| 给金钱激励 | 效应依然存在 |

**锚定效应极其顽固**——即使完全理解这个效应，也无法完全消除。

### 1.3 为什么这个实验重要？

| 发现 | 意义 |
|------|------|
| 第一个数字决定判断 | 揭示了人类判断的系统性偏差 |
| 无关信息也有影响 | 说明大脑会自动使用任何可用信息 |
| 无法通过意志力消除 | 不是简单的"不够理性"，而是认知系统的特征 |

### 1.4 后续研究

| 变体实验 | 发现 |
|---------|------|
| 用身份证号作锚点 | 同样有效 |
| 用当前年份作锚点 | 同样有效 |
| 让受试者自己生成锚点 | 自己生成的锚点同样影响判断 |

**结论**：锚定效应是普遍存在的，与锚点的来源无关。

### 1.5 对现实世界的启示

| 场景 | 应用 |
|------|------|
| 谈判 | 先报价的人掌握锚点优势 |
| 定价 | 原价作为锚点让现价显得划算 |
| 营销 | 高价产品让中等价位显得合理 |
| 自我呈现 | 先说高数字锚定对方印象 |

---

**本节要点：**
- 1974年转盘实验：随机数字10vs65，估计值差20个百分点
- 即使知道是随机的、给金钱激励、专家参与，效应依然存在
- 锚定效应是认知系统的系统性特征，无法完全消除
- 可以战略性利用：谈判、定价、营销、自我呈现
