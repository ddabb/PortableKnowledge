## 可得性启发的5个生活陷阱：择业误判、投资跟风、风险感知偏差、社会问题判断、择偶偏见

### 3.1 择业和创业的误判

| 常见判断 | 真相 |
|---------|------|
| "我听说某某行业很赚钱" | 基于小圈子，非全行业数据 |
| "好多人都进去了" | 信息传播需要时间，你可能是最后一批 |
| "风口来了" | 当你听说时，可能已经是红利尾声 |

### 3.2 投资决策

| 陷阱 | 真相 |
|------|------|
| "新闻老提到这只股票" | 媒体曝光≠基本面好 |
| "最近涨了很多" | 涨了才报道→报道时可能已是尾声 |
| "大家都在买" | 可得性≠可靠性 |

### 3.3 风险感知偏差

| 你的感知 | 实际数据 |
|---------|---------|
| 坐飞机很危险 | 飞机是最安全的交通工具之一 |
| 汽车还行 | 汽车事故年死135万人 |
| 飞机年死亡 | 通常数百人（2019年289人） |
| **开车比坐飞机危险约100倍** | 但你的感知反过来了 |

**原因**：飞机事故每次都有大篇幅报道，汽车事故太常见没人报。

### 3.4 社会问题判断

| 感知 | 真相 |
|------|------|
| "社会越来越乱了" | 很多类别犯罪率在持续下降 |
| "诈骗越来越多了" | 报道多了≠实际发生率升高 |
| "食品安全没救了" | 整体合格率在提升 |

**原因**：你的信息渠道（微博、新闻）大量推送负面事件→可得性升高→感知偏移。

### 3.5 择偶和社交判断

| 陷阱 | 真相 |
|------|------|
| "他看起来很靠谱" | 可能只是符合你脑海中"靠谱"的刻板印象 |
| "她应该很好相处" | 基于外在表现，非实际相处 |
| "大家说他很好" | 别人的评价≠你的体验 |

---

**本节要点：**
- 择业：听说赚钱≠还赚钱，可能已是红利尾声
- 投资：新闻多≠好，涨了才报≠还会涨
- 风险：飞机安全100倍但觉得危险
- 社会问题：新闻推送多≠实际发生率高
- 择偶：刻板印象≠真实观察
