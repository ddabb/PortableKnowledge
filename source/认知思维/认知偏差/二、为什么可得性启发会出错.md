## 可得性启发为什么会出错？4个原因：媒体放大、生动性效应、近期效应、个人经历权重过高

### 2.1 媒体放大效应

| 原理 | 说明 |
|------|------|
| 新闻偏好极端 | 飞机失事、恐怖袭击、鲨鱼袭击有故事性 |
| 罕见=高新闻价值 | 越罕见的事越被报道 |
| 观众错觉 | 大量报道→觉得"这种事很常见" |

**核心衡量标准**：一件事在媒体上出现的频率 ≠ 它在现实中发生的频率。

### 2.2 生动性效应

生动、情绪化的信息比抽象统计数据更容易被记住。

| 生动信息 | 抽象数据 | 效果差异 |
|---------|---------|---------|
| "电梯坠落，1人死亡" | "电梯事故死亡率0.00001%" | 故事比数字影响大100倍 |
| "鲨鱼咬断了游客的腿" | "全球年约10人被鲨鱼攻击致死" | 画面感>统计感 |
| "这个药治好了我朋友的病" | "该药临床有效率62%" | 个人故事>群体数据 |

### 2.3 近期效应

最近发生的事件比很久以前的更容易被想起。

| 时间 | 可得性 | 影响 |
|------|--------|------|
| 刚看完金融诈骗电影 | 高 | 暂时高估被诈骗概率 |
| 几个月后 | 低 | 感知自然消退 |
| 刚经历地震 | 极高 | 系统性高估地震风险 |
| 一年后 | 中等 | 逐渐回归理性 |

### 2.4 个人经历权重过高

你自己的亲身经历，在认知中权重极高，远超统计数字。

| 个人经历 | 统计数字 | 你的权重分配 |
|---------|---------|------------|
| 朋友30岁得罕见病 | 该病发病率0.01% | 个人经历>>统计 |
| 自己投资亏过一次 | 该策略年化收益8% | 亏损记忆>>收益数据 |
| 同事被裁员 | 行业失业率3% | 身边案例>>宏观数据 |

### 2.5 四个原因的叠加

```
媒体放大 → 极端事件被过度报道
  + 生动性 → 故事比数据更有记忆点
    + 近期性 → 最近的事最容易想到
      + 个人经历 → 亲身经历的权重极高
        = 可得性启发严重失真
```

---

**本节要点：**
- 媒体放大：罕见=有新闻价值→大量报道→觉得常见
- 生动性：故事比数据影响大100倍
- 近期性：最近的事最容易想到
- 个人经历：一次亲身经历压过统计数字
- 四个原因叠加→可得性严重失真
