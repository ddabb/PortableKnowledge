## 沉没成本为什么能绑架你的决策？3个心理机制揭秘

### 2.1 机制一：损失厌恶（最核心）

损失厌恶是沉没成本谬误的**底层驱动力**：

| 心理过程 | 说明 |
|---------|------|
| 放弃项目 | = "正式确认"投入全部损失 |
| 继续投入 | = "还有翻盘的可能"（哪怕很小） |
| 情感反应 | 确认损失的痛苦 >> 继续投入的不确定性 |

**核心**：放弃等于"确认损失"，大脑极度厌恶这种确认感。即使理性上知道继续更亏，情感上仍然选择"不确认"。

### 2.2 机制二：自我辩护

人有强烈的心理需求维护"我是一个理性的人"的自我形象。

| 心理过程 | 说明 |
|---------|------|
| 承认错误 | 触发认知失调（"我很理性" + "我做了错误决策"） |
| 减少失调 | 合理化继续投入："坚持下去才有意义" |
| 结果 | 越陷越深 |

**举例**：
- "我已经在这个岗位干了5年" → "离开等于承认5年白干了" → 继续待着
- "我在这段关系投入了这么多" → "分手等于这些感情白费了" → 不分手

### 2.3 机制三：承诺升级

沉没成本谬误的**极端形式**——不仅继续，还追加更多投入：

```
小投入 → 亏损 → 加码"翻盘" → 亏更多 → 再加码 → ……
```

**商业历史上的经典案例**：

| 案例 | 沉没成本 | 承诺升级 | 最终损失 |
|------|---------|---------|---------|
| Concorde协和客机 | 已投数十亿 | 继续追加到完工 | 亏损严重 |
| 某公司收购项目 | 已付定金 | 对方违约还继续谈 | 多付数百万 |
| 个人股票 | 亏5万 | 补仓"摊薄成本" | 亏20万 |

### 2.4 三个机制的关系

```
损失厌恶
  → 放弃太痛苦
    → 自我辩护
      → 合理化继续投入
        → 承诺升级
          → 追加投入
            → 更多沉没成本
              → 更难放弃
                → 循环……
```

**打破循环的关键**：在"自我辩护"阶段介入——承认"我错了"不等于"我这个人不行"。

---

**本节要点：**
- 损失厌恶：放弃=确认损失，太痛苦
- 自我辩护：承认错误威胁自我形象，所以合理化继续
- 承诺升级：不仅继续还追加，越亏越加
- 三个机制形成恶性循环，关键是在"自我辩护"阶段打破
