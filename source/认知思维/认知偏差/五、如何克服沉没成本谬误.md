## 如何克服沉没成本谬误？5个方法：预设退出标准、零基思考、重新定义损失、决策日志、接受失误

### 5.1 预先设定退出标准

在做任何持续投入的决策前，提前设定"止损线"：

| 场景 | 止损线 |
|------|--------|
| 创业项目 | "A轮后6个月用户没达X就转向" |
| 股票投资 | "下跌超过Y%自动卖出" |
| 感情 | "如果再次出现X行为就分手" |
| 学技能 | "3个月没有明显进步就换方向" |

**关键**：在冷静时设定，情绪激动时执行。

### 5.2 零基思考

每次做继续/放弃的决策时，假设从零开始：

> **"如果我今天才有机会选择，我会开始吗？"**

- 不会 → 应该停止
- 会 → 可以继续

### 5.3 重新定义"损失"

| 常见看法 | 重新定义 |
|---------|---------|
| 放弃 = 损失 | 放弃 = 避免更大的损失 |
| 止损 = 亏了 | 止损 = 解放剩余资源 |
| 承认失败 = 我不行 | 承认失败 = 信息变了，不是我笨 |

**止损不是损失，是止损收益**——把时间、金钱、精力解放出来用于更有价值的地方。

### 5.4 记录决策日志

| 步骤 | 做法 |
|------|------|
| 决策时 | 写下依据的假设 |
| 发展不如预期 | 回看决策日志 |
| 假设合理但环境变了 | 外部原因，不需要为沉没成本辩护 |
| 假设本身有误 | 承认，调整，继续前进 |

### 5.5 接受"决策失误是正常的"

| 误区 | 真相 |
|------|------|
| "放弃=我之前判断错了" | 信息有限时做决策，错误率必然>0 |
| "我不能让之前的决定看起来是错的" | 决定在当时信息下是合理的，错误是因为信息变了 |
| "继续下去才能证明我没做错" | 继续做错的事，只会让错误更大 |

---

**本节要点：**
- 预设退出标准：冷静时设好，触发就执行
- 零基思考："如果今天才选，我会开始吗？"
- 重新定义：放弃=止损收益，不是损失
- 决策日志：回看假设，区分环境变化和判断失误
- 接受失误：错误是正常的，继续做错才是问题
