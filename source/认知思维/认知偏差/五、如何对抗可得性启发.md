## 如何对抗可得性启发？4个方法：查数据、质疑来源、考虑基准概率、标注信息类型

### 5.1 主动寻找统计数据

当直觉告诉你"这件事很常见/很危险"时，**主动找官方数据来校正**。

| 直觉 | 数据校正 |
|------|---------|
| "飞机很危险" | 飞机是最安全的交通工具 |
| "这个病很常见" | 查发病率，可能只有0.01% |
| "这个行业很赚钱" | 查行业平均利润率，可能只有5%" |
| "现在犯罪率很高" | 查官方统计，可能持续下降 |

**特别是风险判断**（医疗、航空、安全），数据往往与直觉相反。

### 5.2 质疑信息来源

问自己：**这条信息是通过什么渠道进入我脑海的？**

| 来源 | 质疑 |
|------|------|
| 媒体报道 | 报道是因为"常见"还是"罕见但有新闻价值"？ |
| 朋友讲述 | 朋友圈是普通样本还是选择偏差的小圈子？ |
| 社交媒体 | 算法推送是因为"普遍"还是"高互动"？ |
| 个人经历 | 一次经历能代表整体吗？ |

### 5.3 考虑基准概率

评估事件可能性时，先问：**在没有其他信息时，这种事的基准概率是多少？**

| 评估 | 正确流程 |
|------|---------|
| "某行业创业成功率" | 先查行业平均成功率→再考虑自己情况 |
| "某种疾病风险" | 先查人群发病率→再考虑个人因素 |
| "投资回报预期" | 先看市场平均收益→再评估具体项目 |

### 5.4 标注信息类型

在接收信息时，脑中标注：**这是什么类型的信息？**

| 类型 | 可信度 | 代表性 |
|------|--------|--------|
| "媒体报道" | 中等 | 偏极端 |
| "个人经历分享" | 低 | 样本量=1 |
| "统计数据" | 高 | 代表整体 |
| "专家意见" | 中高 | 看是否基于数据 |

---

**本节要点：**
- 查数据：用统计校正直觉
- 质疑来源：媒体报道≠常见，朋友圈≠代表性
- 基准概率：先查平均概率再判断
- 标注类型：媒体/个人/统计，可信度不同
