## 认知失调与自我辩护：为什么你永远觉得自己是对的

### 5.1 核心驱动：维护自尊和自我形象

人类无法轻易接受"我是一个做了错误决定的人"——这太伤害自尊了。

所以大脑会自动进行**辩护**：通过调整信念来保护自我认知的一致性。

| 现实 | 大脑的辩护 |
|------|-----------|
| 投资亏了 | "长期持有总会涨回来" |
| 选错了人 | "其实TA也有很多优点" |
| 做了错误决策 | "当时信息不完整，换了谁都会这样" |
| 被骗了 | "这是个学习机会" |

### 5.2 自我辩护的3个典型场景

**① 投资决策**：

| 阶段 | 表现 |
|------|------|
| 买入 | "我做了充分研究" |
| 亏损 | "只是暂时回调" |
| 深度亏损 | "别人也亏了，大环境不好" |
| 拒绝止损 | "现在卖就是真的亏了" |

**② 亲密关系**：

| 阶段 | 表现 |
|------|------|
| 开始 | "TA就是我要找的人" |
| 出现问题 | "每对情侣都有矛盾" |
| 严重问题 | "其实是我不够好" |
| 分手后 | "至少我们曾经爱过" |

**③ 政治立场**：

| 阶段 | 表现 |
|------|------|
| 最初支持 | "这个政策方向是对的" |
| 出现负面 | "执行有问题，不是方向的问题" |
| 严重负面 | "其他方案会更糟" |
| 越走越极端 | "反对者都是被洗脑的" |

### 5.3 自我辩护的陷阱

| 陷阱 | 说明 |
|------|------|
| 越辩护越坚定 | 每次辩护都在强化原有信念 |
| 选择性注意 | 只看到支持自己的信息 |
| 沉没成本累积 | 辩护越多，放弃的心理成本越高 |
| 错误放大 | 小错误→辩护→中错误→辩护→大错误 |

### 5.4 如何打破自我辩护？

| 方法 | 做法 |
|------|------|
| 承认"我可能错了" | 定期问自己"有没有可能我的判断是错的？" |
| 记录当初的理由 | 把决策时的理由写下来，事后对照 |
| 寻求反面证据 | 主动找不支持自己观点的信息 |
| 区分"人"和"决定" | 做了错误决定 ≠ 我这个人不行 |

---

**本节要点：**
- 认知失调的核心驱动：维护自尊和自我形象
- 投资亏损、关系破裂、政治极端→都是自我辩护的表现
- 陷阱：越辩护越坚定、选择性注意、错误放大
- 破解：承认可能错了、记录理由、寻求反证、区分人和决定
