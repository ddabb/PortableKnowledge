## 如何克服习得性无助？5个方法重建"我能行"的信念

### 6.1 识别并挑战"全或无"思维

| 全或无思维 | 替代思维 |
|-----------|---------|
| "我做什么都没用" | "这个方法不适合，可以试别的" |
| "我永远也学不会" | "我现在还没学会，不代表永远学不会" |
| "我彻底失败了" | "这次失败了，但失败是暂时的" |
| "我什么都做不好" | "这件事没做好，其他事可以做好" |

### 6.2 建立微型成功体验

Seligman后来发现，让个体体验"**我的行为确实有影响**"的感觉，是解药。

| 步骤 | 做法 | 举例 |
|------|------|------|
| 选小事 | 选择可以立即看到结果的任务 | 整理桌面、做5分钟运动 |
| 做完它 | 执行并完成 | 做完后桌面变整洁了 |
| 记录 | 写下"我的行动产生了什么结果" | "我整理了桌面→桌面变整洁了" |
| 积累 | 重复这个过程，扩大任务范围 | 从整理桌面到整理房间到整理生活 |

### 6.3 区分暂时失败和永久失败

当失败发生时，有意识地问自己：

| 问题 | 目的 |
|------|------|
| 这件事是永远不会变好的吗？ | 区分暂时vs永久 |
| 还有哪些因素我没考虑到？ | 找到被忽略的可控因素 |
| 如果换个方法，结果会不同吗？ | 打开可能性 |
| 以前有没有类似情况后来成功了？ | 回忆成功经验 |

### 6.4 重新归因训练

| 无助归因 | 重新归因 | 维度变化 |
|---------|---------|---------|
| "我天生不是学这个的" | "我用的方法可能不对" | 内在→外在 |
| "我永远都做不好" | "这次没做好，下次可以调整" | 稳定→不稳定 |
| "我什么都做不好" | "这件事没做好，其他事可以" | 普遍→特定 |

**目标**：从"内在+稳定+普遍"的归因，转向"外在+不稳定+特定"的归因。

### 6.5 寻求外部支持

| 支持来源 | 作用 |
|---------|------|
| 导师/教练 | 提供具体反馈和方向 |
| 心理咨询师 | 帮助识别和重塑归因模式 |
| 支持小组 | 与有类似经历的人互相鼓励 |
| 信任的朋友 | 提供情感支持和客观视角 |

---

**本节要点：**
- 挑战全或无思维：用"方法不对"替代"我不行"
- 微型成功：从小事做起，积累"我能影响结果"的体验
- 区分暂时vs永久：大部分失败是暂时的
- 重新归因：内在+稳定+普遍→外在+不稳定+特定
- 寻求支持：导师、咨询师、朋友都可以帮助重建信念
