## 锚定效应为什么这么难摆脱？3个心理学机制

### 4.1 机制一：首因效应与初始编码

第一个接收到的数字在记忆中占据**优先位置**，成为后续判断的参照基准。

| 过程 | 说明 |
|------|------|
| 接收锚点 | 第一个数字被优先编码和存储 |
| 建立框架 | 后续信息在这个框架内被处理 |
| 参照依赖 | 所有调整都基于这个初始锚点 |

**类比**：就像画画的底稿——第一笔决定了整体构图，后面都是在底稿上修改。

### 4.2 机制二：不充分的调整

人们确实会从锚点出发进行调整，但调整往往**不充分**。

| 研究发现 | 数据 |
|---------|------|
| 调整幅度 | 通常只占锚点与真实值差距的30%-50% |
| 方向 | 调整方向通常正确（向真实值靠拢） |
| 程度 | 但远远不够，最终判断仍然偏向锚点 |

**举例**：
- 锚点 = 100（实际值 = 30）
- 差距 = 70
- 典型调整 = 70 × 35% = 24.5
- 最终估计 = 100 - 24.5 = **75.5**（实际是30，还是差很多）

### 4.3 机制三：可及性启发

锚点通过提高相关记忆的**可及性**来影响判断：

| 过程 | 说明 |
|------|------|
| 锚点激活相关记忆 | 听到"100元"→激活"贵的东西"的记忆 |
| 被激活的信息权重过高 | 这些容易想到的信息在判断中占比过大 |
| 被忽略的信息权重过低 | 不容易想到的信息被低估 |

**举例**：
- 房东报价8000 → 你想到"8000能租什么品质"的相关记忆
- 这些记忆被激活后，你的心理价位就偏向8000了
- 而同小区其他房源的真实价格信息没有被激活

### 4.4 三个机制的叠加效应

| 单独 | 叠加后 |
|------|--------|
| 首因效应：锚点优先 | 锚点被优先编码 |
| + 不充分调整：只调整30-50% | 从锚点出发，调整远远不够 |
| + 可及性启发：相关记忆被激活 | 支持锚点的信息更容易想到 |
| **= 锚定效应非常顽固** | 即使知道这个效应，也很难完全避免 |

### 4.5 如何对抗锚定效应？

| 方法 | 做法 |
|------|------|
| **先想自己的数字** | 在看到对方的数字之前，先独立估值 |
| **考虑锚点的合理性** | "这个数字是怎么来的？有依据吗？" |
| **主动寻找反锚点** | 故意看一组偏低/偏高的数据 |
| **使用锚点-反锚点平均** | 综合多个参考值，不依赖单一锚点 |

---

**本节要点：**
- 首因效应：第一个数字占据优先位置
- 不充分调整：只调整差距的30-50%，远远不够
- 可及性启发：锚点激活相关记忆，权重过高
- 三个机制叠加 → 锚定效应极其顽固
- 对抗：先想自己的数字、质疑锚点、综合多个参考
