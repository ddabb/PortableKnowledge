## 锚定效应总结：第一个数字决定了你的所有判断

### 锚定效应无处不在

| 场景 | 锚点 | 影响 |
|------|------|------|
| 买东西 | 原价/折扣价 | 觉得"赚了" |
| 谈薪资 | HR先报的范围 | 被拉低预期 |
| 买房子 | 房东报价 | 还价被锚定 |
| 做投资 | 买入价格 | 不舍得止损 |
| 看体检报告 | "正常范围"数字 | 觉得"还好" |

### 核心认知

1. **第一个数字最关键**：无论是否相关，它都会影响你的判断
2. **调整永远不充分**：从锚点出发调整，只到差距的30-50%
3. **知道也没用**：即使完全理解这个效应，也无法完全消除
4. **可以被利用**：谈判、定价、自我呈现都可以战略性使用

### 实用建议

| 策略 | 做法 |
|------|------|
| **识别锚定** | 当有人先抛出数字时，意识到这可能是锚点 |
| **设定自己的锚** | 在被锚定之前，先想好自己的数字 |
| **质疑锚点** | "这个数字怎么来的？依据是什么？" |
| **综合多锚** | 不依赖单一参考，收集多个数据点 |
| **战略性使用** | 谈判先报价、定价设锚点SKU |

### 最终提醒

> **在谈判桌上，锚点决定权力。**

锚定效应不是缺陷，而是人类认知的系统性特征。与其试图"完全消除"它，不如**有意识地管理它**——主动选择你自己的锚点，而不是被动接受他人设置的锚。

*延伸阅读：[[可得性启发]]——什么信息最容易被想起，就觉得什么最可能发生；[[确认偏误]]——一旦锚定在某一点，我们会主动寻找支持这个锚点的证据*
