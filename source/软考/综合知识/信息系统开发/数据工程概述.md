# 数据工程概述

## 1. 数据工程概念

数据工程是信息系统的基础工程，围绕数据的生命周期及管理要求，研究数据从采集清洗到应用服务的全过程。

**核心目标：**
- 为信息系统运行提供可靠的数据基础
- 为数据共享提供安全、高效的保障
- 为系统互连互通互操作提供支撑

## 2. 数据采集

### 2.1 数据类型

| 类型 | 说明 |
|-----|------|
| 结构化数据 | 关系型数据库表管理 |
| 半结构化数据 | 日志文件、XML文档、E-mail等 |
| 非结构化数据 | 文本、图片、HTML、音频/视频等 |

### 2.2 采集方法

| 方法 | 说明 |
|-----|------|
| 传感器采集 | 感知信息并转换为电信号 |
| 系统日志采集 | 读取、收集日志文件变化 |
| 网络采集 | API或网络爬虫获取数据 |
| 其他方式 | 与数据服务商合作 |

**网络爬虫类型：**
- 通用网络爬虫
- 聚焦网络爬虫
- 增量式网络爬虫
- 深层网络爬虫

## 3. 数据预处理

### 3.1 预处理流程

```
数据分析 → 数据检测 → 数据修正
```

### 3.2 预处理方法

| 问题类型 | 处理方法 |
|---------|---------|
| 数据缺失 | 删除缺失值、均值填补法、热卡填补法 |
| 异常数据 | 分箱法、回归法 |
| 不一致数据 | 人工修改、数据变换（ETL工具） |
| 重复数据 | Excel、VBA、Python去除 |
| 格式不符 | 格式统一调整 |

### 3.3 缺失数据处理

| 方法 | 说明 |
|-----|------|
| 删除缺失值 | 样本多、缺失比例小时有效 |
| 均值填补法 | 按相关属性分组计算均值 |
| 热卡填补法 | 找相似对象填充 |

## 4. 数据存储

### 4.1 存储介质

| 介质 | 特点 |
|-----|------|
| 磁带 | 成本低、容量大、速度慢 |
| 光盘 | 只读、不受电磁影响、易复制 |
| 磁盘 | RAID提高性能和安全性 |
| 内存 | 速度快、断电丢失 |
| 闪存 | 访问速度+存储持久性 |
| 云存储 | 可扩展、异地访问 |

### 4.2 存储形式

| 形式 | 说明 |
|-----|------|
| 文件存储 | 层级目录结构 |
| 块存储 | 固定大小块，编号标识 |
| 对象存储 | 非结构化数据，Web内容 |

### 4.3 存储管理

| 管理方面 | 内容 |
|---------|------|
| 资源调度管理 | 添加/删除节点、网络设备控制 |
| 存储资源管理 | 监控、容量、事件报警 |
| 负载均衡管理 | 避免浪费和瓶颈 |
| 安全管理 | 防攻击、防窃取 |

## 5. 数据备份与容灾

### 5.1 备份策略

| 类型 | 说明 |
|-----|------|
| 完全备份 | 每次全备份，占用资源多 |
| 差分备份 | 相对上次完全备份的变化 |
| 增量备份 | 相对上次备份后的变化 |

### 5.2 容灾指标

| 指标 | 说明 |
|-----|------|
| RPO | 恢复点目标，允许丢失的数据量 |
| RTO | 恢复时间目标，系统恢复时间 |

### 5.3 容灾技术
- 远程镜像技术
- 快照技术

## 6. 元数据

元数据是关于数据的数据（Data About Data）

**作用：**
- 描述：说明数据内容、格式、质量
- 资源发现：检索定位
- 组织管理：动态网页组织
- 互操作性：数据交换
- 归档保存：跟踪数字对象

**元数据类型：**
- 内容元数据
- 专门元数据
- 资源集合元数据
- 管理元数据
- 服务元数据
- 元元数据

## 7. 关键考点

- 数据三种类型：结构化、半结构化、非结构化
- 预处理三步：数据分析→检测→修正
- 存储介质：磁带、光盘、磁盘、内存、闪存、云存储
- 存储形式：文件、块、对象存储
- 备份策略：完全、差分、增量
- 容灾指标：RPO、RTO
- 元数据作用：描述、发现、管理、互操作、归档
