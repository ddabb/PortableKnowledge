# 软件设计

## 1. 软件设计概述

软件设计是根据需求分析结果，完成软件构建的过程：
- **需求阶段**：解决"做什么"的问题
- **设计阶段**：解决"怎么做"的问题

软件设计是系统实施的基础，分为结构化设计与面向对象设计。

## 2. 结构化设计（SD）

面向数据流的方法，确定软件结构。自顶向下、逐层分解、模块化。

### 2.1 模块结构

**模块特性：**
- 功能：模块"做什么"
- 逻辑：描述内部"怎么做"
- 状态：使用时的环境和条件

**模块原则：**
- **信息隐藏**：封装实现细节，模块接口尽量简单
- **抽象**：抽取事物最基本的特性和行为

### 2.2 耦合类型（从低到高）

| 耦合类型 | 说明 |
|---------|------|
| 非直接耦合 | 无直接联系，通过上级模块控制 |
| 数据耦合 | 通过参数表传递简单数据 |
| 标记耦合 | 传递记录等复杂信息（数据结构） |
| 控制耦合 | 传递控制信息 |
| 通信耦合 | 共用输入或输出 |
| 公共耦合 | 共用全局数据结构 |
| 内容耦合 | 直接访问内部数据，多入口 |

### 2.3 内聚类型（从高到低）

| 内聚类型 | 说明 |
|---------|------|
| 功能内聚 | 完成单一功能，缺一不可 |
| 顺序内聚 | 处理元素相关，顺序执行 |
| 通信内聚 | 集中在一个数据结构区域 |
| 过程内聚 | 按特定次序执行 |
| 时间内聚 | 同一时间间隔内执行 |
| 逻辑内聚 | 逻辑上相关的一组任务 |
| 偶然内聚 | 无关系或松散关系的任务 |

**设计原则：高内聚、低耦合**

- 功能的实现
- 模块之间的联系与通信
- 层次结构

## 3. 面向对象设计（OOD）

基本思想：抽象、封装、可扩展性（继承和多态）

### OOD原则

| 原则 | 说明 |
|-----|------|
| 单职原则 | 只有一个引起变化的原因 |
| 开闭原则 | 对扩展开放，对修改封闭 |
| 里氏替换原则 | 子类扩展父类功能，不改变父类功能 |
| 依赖倒置原则 | 依赖抽象，不依赖具体实现 |
| 接口隔离原则 | 使用多个专门接口 |
| 组合重用原则 | 尽量使用组合而非继承 |
| 迪米特原则 | 对其他对象尽可能少了解 |

### 类类型

| 类型 | 说明 |
|-----|------|
| 实体类 | 保存需要永久存储的信息 |
| 控制类 | 控制用例工作，通常无属性有方法 |
| 边界类 | 封装系统内外流动的信息 |

## 4. 统一建模语言（UML）

### UML结构
- **构造块**：事物、关系、图
- **规则**：命名、范围、可见性、完整性
- **公共机制**：规格说明、修饰、分类、扩展

### UML关系
- 依赖：语义关系
- 关联：对象之间的联系
- 泛化：一般与特殊关系
- 实现：类之间的契约

### UML2.0图（14种）

| 类型 | 用途 |
|-----|------|
| 类图 | 静态结构 |
| 对象图 | 实例快照 |
| 构件图 | 组件结构 |
| 组合结构图 | 内部构造 |
| 用例图 | 需求建模 |
| 顺序图 | 消息时序 |
| 通信图 | 协作结构 |
| 定时图 | 时间约束 |
| 状态图 | 状态行为 |
| 活动图 | 流程控制 |
| 部署图 | 硬件配置 |
| 制品图 | 物理文件 |
| 包图 | 模型组织 |
| 交互概览图 | 活动+顺序 |

### UML视图
- 逻辑视图（设计视图）

- 实现视图（物理代码）

- 用例视图（外部视角）

## 5. 设计模式

### 按处理范围
- **类模式**：编译时刻确定，静态关系
- **对象模式**：运行时刻变化，动态关系

### 按目的分类

| 类型 | 模式 |
|-----|------|
| 创建型 | 工厂方法、抽象工厂、原型、单例、建造者 |
| 结构型 | 适配器、桥接、组合、装饰、外观、享元、代理 |
| 行为型 | 职责链、命令、解释器、迭代器、中介者、备忘录、观察者、状态、策略、模板方法、访问者 |

## 6. 详细设计

详细设计任务：设计每个模块的实现算法和局部数据结构

**表示工具：**
- **图形工具**：业务流程图、程序流程图、PAD图、NS流程图
- **表格工具**：描述操作和条件
- **语言工具**：伪码/PDL

## 7. 关键考点

- SD设计原则：高内聚、低耦合
- 耦合类型（7种）：非直接耦合→数据→标记→控制→通信→公共→内容
- 内聚类型（7种）：功能内聚最高，偶然内聚最低
- OOD七大原则
- UML14种图
- 设计模式分类：创建型、结构型、行为型
