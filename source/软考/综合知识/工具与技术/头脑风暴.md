> 头脑风暴是最经典的团队创意激发方法，广泛用于需求收集、问题分析和方案设计。

---

## 一、什么是头脑风暴

### 1.1 定义

头脑风暴（Brainstorming）是一种通过集体自由讨论来激发创意的方法，由Alex Osborn于1940年代提出。

### 1.2 核心原则

| 原则 | 说明 |
|------|------|
| **数量优先** | 创意数量越多越好 |
| **禁止批评** | 自由发言，不批评不评价 |
| **自由发散** | 鼓励大胆、疯狂的创意 |
| **组合改进** | 在他人创意上改进 |

---

## 二、头脑风暴的类型

### 2.1 常规头脑风暴

**适用场景：**
- 问题解决
- 需求收集
- 创意生成

**流程：**
1. 明确问题
2. 轮流发言或自由发言
3. 记录所有想法
4. 归类整理
5. 评估筛选

### 2.2 逆向头脑风暴

**核心思想：** 从反面思考问题

**示例：**
- 常规：如何提高用户留存？
- 逆向：如何让用户立刻离开？

详见「名义小组技术」词条

## 三、操作流程

### 3.1 准备阶段

| 准备项 | 内容 |
|--------|------|
| 确定议题 | 清晰、具体、可讨论 |
| 人员选择 | 5-12人，多元背景 |
| 场地布置 | 白板/便利贴/白纸 |
| 时间安排 | 30-60分钟为宜 |

### 3.2 热身阶段（5分钟）

- 轻松话题预热
- 明确规则
- 消除顾虑

### 3.3 正式讨论（20-40分钟）

| 阶段 | 时间 | 任务 |
|------|------|------|
| 自由发散 | 15分钟 | 记录所有想法 |
| 补充完善 | 10分钟 | 在他人基础上补充 |
| 初步归类 | 10分钟 | 分类整理 |

### 3.4 评估阶段（10分钟）

**常用评估方法：**
- 投票法
- 打分法
- 矩阵评估

## 四、实用技巧

### 4.1 激发创意

| 技巧 | 说明 |
|------|------|
| 曼陀罗思考 | 从中心向四周发散 |
| 强制联想 | 随机词+问题组合 |
| SCAMPER | 替代/组合/改编/修改/其他用途/消除/逆转 |
| 六顶思考帽 | 详见专门词条 |

### 4.2 提高参与度

| 技巧 | 效果 |
|------|------|
| 匿名想法 | 减少顾虑 |
| 卡片法 | 每人写想法再讨论 |
| 角色扮演 | 从用户角度思考 |

---

## 五、常见误区

| 误区 | 正确做法 |
|------|---------|
| 边讨论边批评 | 先发散后收敛 |
| 只让领导发言 | 轮流或匿名 |
| 时间太长 | 控制在1小时内 |
| 没有记录 | 指定专人记录 |
| 直接决策 | 需要后续评估 |

---

## 六、应用场景

| 场景 | 目的 |
|------|------|
| 产品需求收集 | 收集用户痛点 |
| 项目问题分析 | 识别风险原因 |
| 营销方案策划 | 生成推广创意 |
| 技术方案设计 | 讨论实现路径 |

---

## 七、注意事项

1. **禁止当场否定**任何想法
2. 鼓励**疯狂**的想法，有时疯狂=创新
3. 记录要**完整**，不要遗漏
4. 人数控制在**5-12人**效果最好
5. 讨论结束后**及时整理**成果
