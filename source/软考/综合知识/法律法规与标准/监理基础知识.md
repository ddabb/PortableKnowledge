## 监理的意义和作用

### 监理的地位和作用

信息系统监理在业主单位和承建单位之间形成系统的工作关系，在**保障工程质量、进度、投资控制和合同管理、信息管理，协调双方关系**中处于重要地位。

**核心作用**：
- 为业主单位提供信息系统工程相关的**技术建议**
- 代表业主单位对项目实施过程进行**全程跟踪和监督管理**
- 保证项目交付成果的**质量**
- 协调项目干系人关系，促进项目信息**全面有效共享**

### 监理的重要性（6个原因）

1. 信息系统工程关系到国家、企业、单位的重要业务
2. 需求不明确时即付诸实施，实施中需不断修改
3. 用户需求变化，存在不能按预定进度执行的问题和风险
4. 投资相对较大，管理不善会造成较大浪费
5. 实施过程存在隐蔽工程，可视性差，易产生工程隐患
6. 存在"重建设，轻管理"问题，需要专业技术人员进行监督管理

### 监理对象

信息系统工程监理对象包括**五个方面**：
- 信息网络系统
- 信息资源系统
- 信息应用系统
- 信息安全
- 运行维护

## 监理技术参考模型

监理技术参考模型由**四部分**组成：

| 组成部分 | 说明 |
|---------|------|
| **监理支撑要素** | 监理法规及管理文件、监理及相关服务合同、监理及相关服务能力 |
| **监理运行周期** | 规划设计、部署实施、运行维护 |
| **监理对象** | 信息应用系统、信息资源系统、信息网络系统 |
| **监理内容** | 质量、进度、投资控制；合同、项目文档、资料、工作关系管理 |

### 监理支撑要素——服务能力

监理服务能力由**人员、技术、资源、流程**四部分组成：

**人员**：
- 总监理工程师、总监理工程师代表
- 监理工程师、监理员
- 外部技术协作体系、人力资源管理体系

**技术**：
- 监理工作体系、业务流程研究能力
- 监理技术规范、质量管理体系
- 监理大纲、监理规划、监理实施细则

**资源**：
- 监理机构、监理设施
- 监理知识库及监理案例库
- 检测分析工具及仪器设备
- 企业管理信息系统

**流程**：
- 项目管理体系、客户服务体系
- 监理及相关服务的制度和流程

### 监理活动内容——"三控、两管、一协调"

| 内容 | 说明 |
|-----|------|
| **三控** | 质量控制、进度控制、投资控制 |
| **两管** | 合同管理、信息管理 |
| **一协调** | 协调有关单位及人员间的工作关系 |

## 监理相关概念

### 主要概念定义

| 概念 | 定义 |
|-----|------|
| **信息系统工程监理** | 受业主单位委托，依据国家有关法律法规、技术标准和监理合同，对信息系统工程项目实施的监督管理 |
| **监理单位** | 具有独立企业法人资格，具备规定数量监理工程师和注册资金，完善管理制度和质量保证体系的单位 |
| **业主单位** | 具有发包主体资格和支付工程价款能力的单位 |
| **承建单位** | 具有独立企业法人资格，具有承接信息系统工程建设能力的单位 |
| **监理机构** | 负责履行监理合同的组织机构 |

### 监理人员职责

| 人员 | 职责 |
|-----|------|
| **总监理工程师** | 法定代表人书面授权，全面负责监理及相关服务合同履行，主持监理机构工作 |
| **总监理工程师代表** | 总监理工程师书面授权，代表其行使部分职责和权力 |
| **监理工程师** | 监理单位正式聘任，取得监理工程师资格证书的专业技术人员 |
| **监理员** | 经过培训，具有同类工程相关专业知识，从事具体监理服务工作 |

### 监理资料

| 资料 | 说明 |
|-----|------|
| **监理大纲** | 投标阶段编制的纲领性文件，用于取得监理合同 |
| **监理规划** | 总监理工程师主持编制，指导监理机构全面开展监理工作 |
| **监理实施细则** | 针对工程建设中某一方面或某一专业监理工作的操作性文件 |
| **监理意见** | 监理过程中以书面形式向业主单位或承建单位提出的见解和主张 |
| **监理报告** | 对监理阶段性进展情况、专项问题的书面陈述 |

### 监理过程

| 类型 | 说明 |
|-----|------|
| **全过程监理** | 包括招标、设计、实施、验收及运行维护全过程 |
| **里程碑监理** | 对工程里程碑产生的结果进行确认 |
| **阶段监理** | 开展某个或某些特定阶段的监理工作 |

### 监理形式

| 形式 | 说明 |
|-----|------|
| **监理例会** | 定期召开，针对质量、进度、投资控制和合同、文档管理及协调 |
| **签认** | 工程建设或运维管理任何一方签署并认可其他方所提供文件的活动 |
| **现场** | 开展项目所有监理及相关服务活动的地点 |
| **旁站** | 在关键部位或关键工序施工过程中，由监理人员进行的监督或见证活动 |

## 各阶段监理内容

### 规划阶段

- 协助业主单位构建信息系统架构
- 提供项目规划设计相关服务，为决策提供依据
- 对项目需求、项目计划和初步设计方案进行审查
- 协助业主单位策划招标方法

### 招标阶段

- 参与招标前的准备工作，协助编制项目工作计划
- 参与招标文件编制，提出监理意见
- 协助业主单位进行招标工作
- 提供招投标咨询服务
- 参与承建合同签订过程

### 设计阶段

- 审查设计方案、测试验收方案、计划方案
- 审查设计内容的完整性、正确性和合理性
- 协助承建单位完善方案
- 变更方案和文档资料的管理

### 实施阶段

- 现场监督、核查、记录和协调
- 质量控制、进度控制、投资控制
- 合同管理、文档资料管理
- 协调工作

### 验收阶段

- 审核测试验收方案的符合性及可行性
- 协调承建单位配合第三方测试机构进行系统测评
- 促使项目最终功能和性能符合合同、法规和标准要求
- 促使技术、管理文档内容和种类符合相关标准
