# 数据流程图

## 一、定义

**数据流程图（DFD，Data Flow Diagram）** 是一种描述系统数据流程的主要工具，它用一组符号来描述整个系统中信息的全貌，综合地反映出信息在系统中的流动、处理和存储情况，帮助人们理解数据在整个流程中的传递和转换过程。

## 二、四个基本符号

### 2.1 数据流（Data Flow）

**表示数据在系统或业务流程中的传递和流动。**

| 属性 | 说明 |
|------|------|
| 表示方式 | 用带箭头的线段表示 |
| 方向 | 箭头指向表示数据流动方向 |
| 内容 | 箭头上标注数据名称 |

数据流连接各个处理过程、数据存储和外部实体，表明数据的来源和去向。

### 2.2 处理（Process）

**表示对数据进行处理或转换的操作或活动。**

| 属性 | 说明 |
|------|------|
| 表示方式 | 用圆或椭圆（泡泡图）表示 |
| 内容 | 标注处理过程的名称和编号 |
| 功能 | 对输入数据流进行加工、计算、转换后输出 |

每个处理过程至少有一个输入数据流和一个输出数据流。

### 2.3 数据存储（Data Store）

**表示数据的存储位置。**

| 属性 | 说明 |
|------|------|
| 表示方式 | 用矩形框（开口）或双线表示 |
| 内容 | 标注数据存储的名称 |
| 示例 | 数据库、文件、表格等 |

数据存储通常用矩形框表示，并与数据流相连。数据流可以从数据存储流入（读操作）或流出（写操作）。

### 2.4 外部实体（External Entity）

**表示与系统或业务流程交互的外部组织、人员或系统。**

| 属性 | 说明 |
|------|------|
| 表示方式 | 用矩形表示 |
| 内容 | 标注外部实体名称 |
| 特点 | 位于系统边界之外，不属于系统本身 |

外部实体是数据的来源或数据的终点，如客户、供应商、其他系统等。

## 三、数据流程图的特征

### 3.1 抽象性

把具体的**组织机构、工作场所、物质流**都去掉，只剩下：
- 信息和数据
- 数据存储
- 数据的流动和使用
- 数据的加工情况

这是数据流程图区别于业务流程图的核心特征——它剥离了物理实体，专注于信息流。

### 3.2 概括性

把系统对各种业务的处理过程联系起来考虑，形成一个**总体视图**。

DFD 不是孤立地描述单个业务，而是站在全局角度，描述：
- 数据在哪些处理过程之间流转
- 数据存储了哪些信息
- 系统与外部环境如何交换数据

## 四、DFD的分层结构

在实际应用中，数据流程图通常采用分层结构：

| 层次 | 说明 |
|------|------|
| 顶层DFD（Context Diagram） | 描述系统的范围和边界，只有一个处理过程，显示所有外部实体和数据流 |
| 0层DFD | 将顶层中的处理过程分解为多个主要处理过程和数据存储 |
| N层DFD | 进一步分解各处理过程，直到达到所需的详细程度 |

**分层原则：**
- 上层图中的每个处理过程可以在下层图中进一步展开
- 子图的输入/输出必须与父图保持一致（平衡原则）
- 分解到足够详细，便于编程实现为止

## 五、数据流程图的作用

| 作用 | 说明 |
|------|------|
| 理解系统数据流 | 直观展示数据从哪里来、到哪里去、经过什么处理 |
| 发现数据问题 | 识别数据冗余、缺失、不一致等问题 |
| 系统设计依据 | 为数据库设计、程序模块划分提供基础 |
| 沟通工具 | 技术人员与业务人员之间的共同语言 |

## 六、软考答题要点

### 考题形式一：DFD的四个基本符号

```
【题目关键词】"数据流程图的符号""DFD的组成"

【标准答案】
数据流程图有四个基本符号：
1. 数据流（Data Flow）：用带箭头的线段表示，表示数据流动
2. 处理（Process）：用圆或椭圆表示，表示对数据的加工处理
3. 数据存储（Data Store）：用矩形框表示，表示数据存储位置
4. 外部实体（External Entity）：用矩形表示，表示系统外部的相关方
```

### 考题形式二：DFD的特征

```
【题目关键词】"数据流程图的特征""DFD特点"

【标准答案】
1. 抽象性：去掉具体的组织机构、工作场所、物质流，只保留信息和数据
2. 概括性：把系统对各种业务处理过程联系起来，形成总体视图

【对比记忆】
  特征         业务流程图           数据流程图
抽象性        不抽象（面向业务）    抽象（面向数据）
概括性        单一业务流程           系统整体数据流
```
