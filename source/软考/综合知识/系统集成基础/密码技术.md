# 密码技术

## 1. 密码学基础

### 1.1 基本概念

| 术语 | 说明 |
|-----|------|
| 明文 | 原始信息 |
| 密文 | 加密后的信息 |
| 加密 | 将明文转换为密文 |
| 解密 | 将密文恢复为明文 |
| 密钥 | 加密/解密使用的参数 |

### 1.2 密码体制分类

```
密码体制
├── 对称密码体制（私钥密码）
└── 非对称密码体制（公钥密码）
```

## 2. 对称加密

### 2.1 特点
- 加密和解密使用相同密钥
- 算法：DES、3DES、AES、IDEA
- 优点：速度快、效率高
- 缺点：密钥分发困难

### 2.2 DES算法
- 数据加密标准
- 56位密钥
- 已被破解，逐渐淘汰

### 2.3 AES算法
- 高级加密标准
- 128/192/256位密钥
- 目前最广泛使用的对称加密

## 3. 非对称加密

### 3.1 特点
- 使用公钥和私钥一对密钥
- 公钥加密，私钥解密（或相反）
- 算法：RSA、ECC、DSA
- 优点：密钥分配简单
- 缺点：速度慢

### 3.2 RSA算法
- 基于大数分解难题
- 密钥长度：1024-4096位
- 用途：加密、数字签名、密钥交换

### 3.3 密钥交换过程
```
1. A获取B的公钥
2. A用B的公钥加密会话密钥
3. 发送给B
4. B用私钥解密获取会话密钥
5. 双方用会话密钥进行对称加密通信
```

## 4. 数字签名

### 4.1 目的
- 消息认证：确认发送者身份
- 完整性：验证消息未被修改
- 不可否认：发送者不能否认发送

### 4.2 签名过程
```
发送方：
1. 对消息进行Hash计算
2. 用私钥对Hash值加密 = 数字签名
3. 将签名附在消息后发送

接收方：
1. 用发送方公钥解密签名
2. 对消息再次Hash计算
3. 比较两个Hash值
```

### 4.3 常用算法
- RSA签名
- DSA（数字签名算法）
- ECDSA（椭圆曲线数字签名）

## 5. PKI（公钥基础设施）

### 5.1 组成

| 组件 | 说明 |
|-----|------|
| CA | 证书颁发机构 |
| RA | 注册机构 |
| 证书库 | 存储证书 |
| 密钥管理 | 密钥生成、分发、更新 |
| 证书撤销列表 | 存储已撤销证书 |

### 5.2 PKI功能
- 证书颁发与管理
- 密钥管理
- 身份认证
- 完整性保护
- 不可否认性

## 6. CA认证中心

### 6.1 CA职责
- 颁发数字证书
- 吊销过期证书
- 发布证书撤销列表（CRL）
- 管理密钥

### 6.2 数字证书
- 证书内容：
  - 证书持有者信息
  - 持有者公钥
  - CA签名
  - 有效期
  - 序列号

### 6.3 证书验证
```
1. 检查证书有效期
2. 检查证书颁发者CA可信
3. 检查证书未被撤销（CRL）
4. 验证CA签名
5. 验证持有者信息
```

## 7. 混合加密体制

**实际应用中的加密方案：**

```
对称加密 + 非对称加密
     ↓
1. 用非对称加密交换对称密钥
2. 用对称加密加密实际数据
```

**优点：**
- 兼顾效率和安全
- 解决密钥分配问题

## 8. 哈希函数

### 8.1 特点
- 单向函数
- 固定长度输出
- 抗碰撞性

### 8.2 常用算法
- MD5：128位，已不安全
- SHA-1：160位，逐渐淘汰
- SHA-256/SHA-3：安全

## 9. 关键考点

- 对称加密：DES、AES，同钥加密，速度快
- 非对称加密：RSA，公钥私钥对，用于加密和签名
- 数字签名：用私钥签名，公钥验证
- PKI组成：CA、RA、证书库、密钥管理、CRL
- CA职责：颁发证书、吊销证书、发布CRL
- 混合加密：非对称交换密钥+对称加密数据
- 哈希函数：MD5、SHA-1、SHA-256
