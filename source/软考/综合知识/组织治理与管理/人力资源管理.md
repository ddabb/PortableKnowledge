# 人力资源管理

## 人力资源管理目标

1. 建立员工招聘和选择体系，获得最符合组织需要的员工
2. 充分挖掘每个员工的潜能，使其服务于组织发展目标
3. 留住通过工作绩效助力组织实现目标的员工
4. 确保组织遵守人力资源方面的法律法规

## 人力资源管理内容

> **口诀：** 规招维提评（规划、招聘、维护、提升、评价）

| 内容 | 说明 |
|------|------|
| **规划** | 确认组织中的工作要求，工作分析岗位策划 |
| **招聘** | 根据工作需要，确定最合适的人选 |
| **维护** | 维护员工工作的积极性，维护健康环境 |
| **提升** | 提高员工知识、技能和经验等能力 |
| **评价** | 评价员工工作结果和工作表现 |

## 工作分析

**定义：** 对组织分工和分工内容进行清晰界定，让任职者清楚工作内容。

**分析方法：**

| 类型 | 方法 |
|------|------|
| 定性方法 | 工作实践法、直接观察法、面谈法、问卷法、典型事例法 |
| 定量方法 | 职位分析问卷法、管理岗位描述问卷法、功能性工作分析法 |

**过程：**
1. 明确工作分析范围
2. 确定工作分析方法
3. 工作信息收集和分析
4. 评价工作分析方法

> 注意：直接观察法**不适用于**对脑力劳动要求较高的工作

## 岗位设计

**主要内容：**

| 内容 | 说明 |
|------|------|
| **工作内容设计** | 广度、深度、完整性、自主性、反馈性（重点） |
| **工作职责设计** | 责任、权利、方法、沟通 |
| **工作关系设计** | 协作关系、监督关系 |

**工作内容设计五特性：**
1. **广度** - 工作的多样性
2. **深度** - 从易到难，增强挑战性
3. **完整性** - 员工有成就感
4. **自主性** - 适当的自主权增加责任感
5. **反馈性** - 同事/上级反馈和工作本身的反馈

## 战略性人力资源管理

**两个部分：** 人力资源战略 + 人力资源管理系统

**两个阶段：** 战略制定 → 战略执行

## 人力资源供需

| 情况 | 措施 |
|------|------|
| **供求适应** | 正常管理 |
| **供大于求** | 减少加班、鼓励退休、转让给合作伙伴、裁员 |
| **供小于求** | 增加录用人员、提高工作时间 |

## 薪酬管理

### 薪酬体系

| 类别 | 内容 |
|------|------|
| **直接报酬** | 基本薪酬、绩效加酬 |
| **间接报酬** | 保护项目、非工作报酬、服务与津贴、激励薪酬、延期支付 |

### 薪酬调整类型

| 调整类型 | 内容 |
|----------|------|
| **薪酬水平调整** | 主动型/被动型；奖励性、生活指数性、年资性、效益型 |
| **薪酬结构调整** | 纵向（等级结构）、横向（构成调整） |

> 注意：**薪酬等级调整不属于**薪酬调整内容

### 不同员工激励

| 员工类型 | 激励方式 |
|----------|----------|
| 操作人员 | 计件制 |
| 销售人员 | 佣金制和底薪制 |
| 专业技术人员 | 非金钱奖励（设备、管理风格） |
| 高级管理人员 | 基本薪酬、短期奖励、长期奖励、正常福利、特殊津贴 |

## 关键考点

1. 人力资源管理内容：**规划、招聘、维护、提升、评价**
2. 直接观察法**不适用于**脑力劳动要求较高的工作
3. 薪酬调整包括**薪酬水平调整和薪酬结构调整**，不包括薪酬等级调整
4. 招聘成本中**管理层参与面试**属于隐性成本
