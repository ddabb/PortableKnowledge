# 流程管理

## 流程基础

### 流程特点

- **目标性** - 明确的业务目标
- **内在性** - 内在的活动流
- **整体性** - 各活动相互作用
- **层次性** - 可分解为子流程

### 流程基本要素

1. 流程的输入资源
2. 流程中的若干活动
3. 活动的相互作用
4. 输出结果
5. 客户
6. 最终流程创造的价值

### 组织战略执行保障体系

| 层级 | 构成 | 作用 |
|------|------|------|
| **战略控制层** | 会议管理、运行分析、**预算考核** | 建立组织发展计划 |
| **流程执行层** | 业务流程、岗位描述、绩效测评 | **战略执行落地的核心枢纽，承上启下** |
| **系统支撑层** | ERP、CRM、PDM等 | 信息技术应用 |

## 流程规划

### 流程分类

| 类型 | 说明 |
|------|------|
| **战略流程** | 面向未来，提供发展方向和整体管理 |
| **运行流程** | 以战略流程为导向，直接为业务对象创造价值 |
| **支持流程** | 为运行流程提供支持服务（决策支持、后勤支持、风险控制） |

**运行流程逻辑顺序：** 战略 → 业务模式 → 运行流程

### 流程分级

| 级别 | 别名 | 说明 |
|------|------|------|
| **一级流程** | 域 | 高阶流程，端到端流程 |
| **二级流程** | 域过程 | 中阶流程 |
| **三级流程** | - | 低阶流程，对域过程的细分 |

**端到端流程的本质：** 从目的出发而非任务出发，关注最终结果；追求整体最优

## 流程执行保障措施

1. 理解流程是执行流程的前提
2. 做好流程变更后的推广
3. 新员工入职流程制度培训
4. 找对流程执行负责人
5. 流程审计及监控
6. 把流程固化到信息系统中
7. 把流程固化到制度中
8. 流程文化宣导

> 注意：**流程设计及优化不属于**流程管理有效执行保障措施

## 流程评价

### 常见检查方法

- 流程稽查
- 流程绩效评估
- 满意度评估
- 流程审计

### 流程评价应用

- 绩效考核
- 过程控制
- 纠正措施
- 战略调整

## 流程持续改进

### 流程优化过程

| 阶段 | 说明 |
|------|------|
| 1.0 立项 | 确定优化项目 |
| 2.0 现状分析及诊断 | 分析问题 |
| 3.0 目标流程及配套方案设计 | 设计方案 |
| 4.0 IT方案设计与开发 | 技术实现 |
| 5.0 新旧流程切换 | 切换上线 |
| 6.0 项目关闭 | 总结归档 |

### 优化目标来源

1. 找实现组织战略要求的目标
2. 找组织需要解决的问题

## 关键考点

1. 组织战略执行保障体系**核心枢纽**是流程执行层
2. 预算考核属于**战略控制层**
3. 运行流程逻辑顺序：**战略→业务模式→运行流程**
4. 流程管理有效执行保障措施**不包括**流程设计及优化
5. 流程评价检查方法：**流程稽查、流程绩效评估、满意度评估、流程审计**
