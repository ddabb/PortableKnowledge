# 组织战略基础

## 组织战略概述

### 战略目标

- 组织在一定战略期内**总体发展的总水平、总任务**
- 决定了主要行动方向，是组织战略的**核心**
- 多元化：经济和非经济目标、定量和定性目标
- 明确对象和范围，定量和定性相结合，短、中、长期目标衔接

### 战略类型

| 类型 | 说明 |
|------|------|
| **发展型战略** | 从现有战略基础水平向更高一级的目标发展 |
| **稳定型战略** | 在整个战略期内基本保持战略起点的运行绩效范围和水平，风险较低 |
| **紧缩型战略** | 从当前战略运行领域和基础水平收缩和撤退，短期过渡性战略 |
| **其他类型** | 复合型、联盟、成本领先、差异化、集中化战略 |

### 战略特性

**七大特性：** 全局性、长远性、纲领性、指导性、竞争性、风险性、相对稳定性

## 组织定位

组织定位包括：

### 组织愿景

- 明确说明组织的定位
- 清晰表达组织目标
- 表述应尽量**鲜明和形象化**，使其可靠且易于传达

### 组织使命

包括：
- 产品和服务
- 客户和服务对象
- 行业和领域
- 公众形象
- 自我认知

### 组织文化

**两个基本特征：**
1. 具有浓厚的文化属性和良好的执行性
2. 提出了组织发展涉及的制度、行为等措施

### 组织战略目标

| 要素 | 说明 |
|------|------|
| 战略 | 为实现愿景的手段和途径 |
| 使命 | 组织较长期的业务发展的总方向和总特征 |
| 愿景 | 企业未来的样子 |

> **关系：** 使命是较长期的业务发展方向，愿景是企业未来的目标，战略是实现愿景的途径

## 组织环境分析

### 外部环境分析 - PESTLE

| 因素 | 说明 |
|------|------|
| **P**政治 | Political |
| **E**经济 | Economic |
| **S**社会 | Social |
| **T**技术 | Technological |
| **L**法律 | Legal |
| **E**环境 | Environmental |

### 内部环境分析 - SWOT

| 分析维度 | 说明 |
|----------|------|
| 优势（Strengths） | 组织内部优势 |
| 劣势（Weaknesses） | 组织内部劣势 |
| 机会（Opportunities） | 外部机会 |
| 威胁（Threats） | 外部威胁 |

## 组织能力确认

| 能力类型 | 内容 |
|----------|------|
| **核心能力** | 管理、领导力、组织结构、信息技术 |
| **人才战略** | 技术密集型、成本导向型、目标动态型 |

**能力分析：**
- 产品服务能力
- 技术开发能力
- 生产服务能力
- 营销能力
- 产品服务增值能力

## 关键考点

1. 组织战略特性：**全局性、长远性、纲领性、指导性、竞争性、风险性、相对稳定性**
2. 组织定位包括**使命、愿景、价值观、组织文化、业务单元定位战略**
3. PESTLE：**政治、经济、社会、技术、法律、环境**
4. 组织文化**很难复制**，能提供长期竞争优势
