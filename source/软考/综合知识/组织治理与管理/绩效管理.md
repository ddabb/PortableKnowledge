# 绩效管理

## 绩效计划

**定义：** 组织管理者和员工之间就需要达成的工作绩效进行沟通后最终落实为正式书面约定的过程。

### 三大要素

| 要素 | 说明 |
|------|------|
| **绩效内容** | 工作方向和范围（工作业绩、工作能力、工作态度） |
| **绩效标准** | 每项目标任务要达到的绩效要求 |
| **绩效目标** | 衡量标准，客观评价绩效 |

### 绩效计划分类

| 维度 | 类型 |
|------|------|
| 责任主体 | 组织绩效计划、部门绩效计划、个人绩效计划 |
| 时间期限 | 年度、季度、月度绩效计划 |

## 绩效实施

**关键点：**
1. **统一思维** - 形成一致的价值观
2. **引发热情** - 明确为什么要做，勾画愿景
3. **训练能力** - 持续深入的学习与实践

**核心：** 持续沟通式的绩效辅导

**内容：**
- 持续不断的绩效沟通
- 绩效信息的记录和收集

## 绩效治理

**定义：** 采用科学的方式，通过对员工的行为表现、劳动态度、工作业绩及综合素养的全面监测、考核、评估、分析，充分调动员工积极性的活动进程。

**八步骤：**
1. 统一组织目标
2. 明确职位职责
3. 提炼绩效考核指标
4. 设定职位考核指标值
5. 执行中的跟踪、监督和指导
6. 绩效评估
7. 分析问题和建议方法
8. 绩效反馈

## 绩效评估

### 六大因素

1. 被评估者
2. 评估者
3. 评估时间和周期
4. 评价指标
5. 评定形式
6. 绩效评估数据的收集

### 三大内容

1. 回顾及评估上一周期内实际绩效
2. 为下一周期制订或改进绩效标准、目标和内容
3. 确定报酬调整和奖励方案

### 三种类型

| 类型 | 重点 | 适用对象 |
|------|------|----------|
| **效果主导型** | 结果而非过程 | 管理型或事务型员工 |
| **品质主导型** | 人员品质和能力 | 评估管理型员工的潜力 |
| **行为主导型** | 工作过程而非结果 | 管理型或事务型员工 |

### 六种方法

1. 排序法
2. 硬性分布法
3. 尺度评价表法
4. 关键事件法
5. **平衡计分卡法**
6. 目标管理法

> 平衡计分卡：**财务、客户、内部运营、学习与成长**四个角度

## 绩效评价结果反馈

1. 通报被评估人当期绩效评估结果
2. 分析被评估人的绩效差距与确定改进措施
3. 沟通协商下一个绩效评估周期的工作任务与目标
4. 确定与工作任务和目标相匹配的资源配置

## 绩效评价结果应用

| 应用类型 | 具体内容 |
|----------|----------|
| **价值评价** | 人事调动、薪酬调整、员工奖励 |
| **绩效改进** | 培训、职业生涯规划 |

## 关键考点

1. 绩效实施核心是**持续沟通式的绩效辅导**
2. 绩效实施内容包括**绩效沟通和绩效信息的记录和收集**
3. 平衡计分卡四个维度：**财务、客户、内部运营、学习与成长**
4. 价值评价包括**奖惩、薪酬调整、人事调动**；绩效改进包括**培训和职业生涯规划**
