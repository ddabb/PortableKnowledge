# 相关方参与评估矩阵

## 一、概念定义

相关方参与度评估矩阵是将每个相关方的**当前参与水平（C列）**与**期望参与水平（D列）**进行对比的可视化工具，是"规划相关方参与"过程的核心工具。

- **C（Current）**：相关方当前的参与程度
- **D（Desired）**：项目成功所需的相关方参与程度

通过比较 C 和 D，可以发现差距，进而制定针对性的沟通和干预策略，将相关方从当前状态调整到期望状态。

## 二、参与度五级定义

| 级别 | 名称 | 英文 | 行为特征 |
|------|------|------|---------|
| 1 | 不了解型 | Unaware | 不知道项目的存在，也不知道项目对其的影响 |
| 2 | 抵制型 | Resistant | 知道项目存在，但抵制项目带来的变化，不支持项目成果 |
| 3 | 中立型 | Neutral | 知道项目存在，但对项目既不支持也不反对 |
| 4 | 支持型 | Supportive | 知道项目及其影响，愿意支持项目工作和成果 |
| 5 | 领导型 | Leading | 深刻理解项目，主动推动项目成功，积极发挥影响力 |

> **记忆技巧**：从"不知道"到"领导"，用"不抵中立支持领"谐音"不抵中立支持领"（不抵抗，支持领导）来记忆五级顺序。

## 三、矩阵格式

### 基础矩阵（表格形式）

| 相关方 | 当前参与水平（C） | 期望参与水平（D） | 差距 | 优先级 |
|--------|-----------------|-----------------|------|--------|
| 客户方项目经理 | 支持型（4） | 领导型（5） | 1 | 高 |
| 终端用户代表 | 中立型（3） | 支持型（4） | 1 | 中 |
| 监理方 | 中立型（3） | 支持型（4） | 1 | 中 |
| 第三方供应商 | 不了解型（1） | 中立型（3） | 2 | 高 |
| 高级管理层 | 抵制型（2） | 支持型（4） | 2 | 高 |

### 矩阵图示（坐标轴形式）

```
          期望参与水平
          D（高）
            ↑
            │
      支持型│    目标区
      (4)   │
            │
    中立型  │    关注区
      (3)   │
            │
  不了解型  │    危险区
      (1)   │
            └──────────────→ 当前参与水平 C（高）
              不了解 抵制 中立 支持 领导
               (1)   (2)  (3)  (4)  (5)
```

## 四、差距分析步骤

### 步骤一：逐一评估当前状态（C）

根据观察、访谈、历史记录，判断每个相关方目前属于哪一级。

### 步骤二：确定期望状态（D）

根据项目需求，确定项目成功需要该相关方达到哪一级参与水平。

### 步骤三：计算差距 |D - C|

差距越大，潜在风险越高，需要优先干预。

### 步骤四：制定干预策略

| 差距级别 | 风险程度 | 干预策略 |
|---------|---------|---------|
| |D-C| = 0 | 维持现状 | 正常沟通即可 |
| |D-C| = 1 | 中等风险 | 加强沟通，邀请参与评审 |
| |D-C| ≥ 2 | 高风险 | 制定专项干预计划，高层介入 |

### 步骤五：实施并监控

在项目执行过程中持续更新矩阵，跟踪干预效果。

## 五、针对不同类型差距的应对策略

### 策略一：从不了解型（1）到支持型（4）——|D-C| = 3

**常见场景**：第三方供应商、外部监管机构、项目初期未纳入的部分用户。

**干预措施**：
- 召开项目介绍会，传达项目愿景和对其的影响
- 发送项目简报，定期通报进展
- 邀请参加里程碑评审活动
- 明确项目对其的价值和收益

### 策略二：从抵制型（2）到支持型（4）——|D-C| = 2

**常见场景**：业务流程变革中受影响的部门、担心被替代的技术人员。

**干预措施**：
- 深入了解抵制的原因（担心失去利益/不了解价值/过往失败经历）
- 针对根本原因制定专项沟通方案
- 展示成功案例，消除顾虑
- 让其参与部分决策，增强掌控感
- 寻求支持者帮助影响

### 策略三：从中立型（3）到领导型（5）——|D-C| = 2

**常见场景**：项目经理希望关键干系人从被动知道到主动推动。

**干预措施**：
- 明确说明项目成功的关键依赖其领导力
- 提供数据和事实说明项目重要性
- 赋予更多参与权和决策权
- 邀请担任项目指导委员会成员

### 策略四：从支持型（4）到领导型（5）——|D-C| = 1

**常见场景**：已有一定参与度，需要其发挥更大影响力。

**干预措施**：
- 认可其已有的贡献
- 提供更多影响力场合（汇报会、评审会）
- 请其帮助影响其他抵制型干系人

## 六、软考案例分析答题框架

当题目中出现以下关键词时，应优先使用参与度评估矩阵分析：
- "干系人态度消极"
- "部分人员不配合"
- "用户参与度不高"
- "有人抵制项目变更"
- "需要推动相关方参与"

### 框架一：矩阵分析法（推荐用于所有干系人类题目）

```
【识别】
1. 列出所有相关方
2. 评估其当前参与水平（C）
3. 确定期望参与水平（D）

【分析】
4. 计算差距 |D-C|
5. 按差距排序，识别高风险相关方
6. 分析差距原因：
   - 不了解：信息传递不到位
   - 抵制：利益受损/过往经历
   - 中立：未感受到项目价值

【策略制定】
7. 针对每个高风险相关方制定干预措施
8. 将干预措施纳入沟通管理计划
9. 在干系人参与计划中明确行动

【实施与监控】
10. 在项目执行中持续跟踪参与度变化
11. 定期更新评估矩阵
```

### 框架二：差距应对法（用于明确出现"参与度差距"的情形）

```
【差距识别】
- 找出 |D-C| 最大的相关方
- 如：第三方供应商当前=不了解(1)，期望=中立(3)，差距=2，高优先级

【原因分析】
- 为何不了解？→ 信息传递渠道缺失
- 为何抵制？→ 担心利益受损/工作量增加

【应对措施】
- 信息传递：建立定期通报机制
- 消除顾虑：说明项目对其的正向影响
- 参与机制：邀请参加评审，提供反馈渠道
- 监控：每周更新参与度评分

【预防措施】
- 在干系人识别时即评估期望参与水平
- 将参与度评估纳入项目状态报告
```

## 七、高频考点汇总

### 考点1：五级名称与顺序（选择题/判断题）

**题目常见形式**：
- "相关方参与度评估矩阵中，从低到高依次是？不了解型→抵制型→中立型→支持型→领导型"
- "某相关方当前不了解项目，且抵制变化，其当前参与水平为？"答案：抵制型（2级）

### 考点2：C/D对比的含义（选择题）

- C>D（当前参与度 > 期望参与度）：相关方参与程度超出必要，可能浪费资源，但不必强制降低
- C<D（当前参与度 < 期望参与度）：需要加强参与度，存在风险——**这是最常见考察点**
- C=D：参与度与项目需求匹配，维持现状

### 考点3：差距应对措施（案例分析题）

**标准答题要点**：
1. 重新识别相关方，明确所有人的当前和期望参与水平
2. 分析差距原因（不了解/抵制/中立）
3. 制定针对性的沟通策略
4. 更新沟通管理计划和干系人参与计划
5. 在项目执行中持续监控并调整

### 考点4：与权力利益方格的结合使用

| 分析工具 | 分析维度 | 适用场景 |
|---------|---------|---------|
| 权力利益方格 | 权力（职权）+ 利益（关注程度） | 确定管理优先级 |
| 参与度评估矩阵 | 当前水平 + 期望水平 | 制定干预策略 |

两者通常结合使用：
- 先用权力利益方格判断"管谁优先"
- 再用参与度矩阵判断"如何引导"

## 八、记忆口诀

> **"不抵中立支持领，五级顺序要记清；C是现状D是期望，C小于D有风险。"**

解读：
- 不了解型 → 抵制型 → 中立型 → 支持型 → 领导型（从低到高）
- C（Current）小于 D（Desired）= 差距 = 风险 = 需要干预
