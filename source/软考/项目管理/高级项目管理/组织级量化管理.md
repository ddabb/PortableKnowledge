# 组织级量化管理

## 组织级量化管理体系内容

建立组织级量化管理体系主要包括：

1. 定义组织量化过程性能目标
2. 识别关键过程
3. 建立度量体系及数据收集
4. 建立过程性能基线
5. 建立过程性能模型

## 1. 定义组织量化过程性能目标

**目标类型：**
- 质量目标
- 过程性能目标（交付缺陷、交付工期偏差、生产率、客户满意度等）

**CPK判定标准：**

| CPK值 | 风险等级 | 说明 |
|-------|----------|------|
| < 0.67 | 较大风险 | 不能满足目标能力要求 |
| 0.67~1 | 一定风险 | 存在不稳定性 |
| 1~1.33 | 一般 | 可满足但状态一般 |
| > 1.33 | 良好 | 满足要求，状态稳定 |

> 目标定义后需**评审确认**方可正式发布

## 2. 识别关键过程

**关键过程选择准则：**

| 类型 | 特征 |
|------|------|
| 技术过程 | 需求开发、软件设计、编码实现、产品集成 |
| 验证性活动 | 技术评审、代码走查、测试类 |
| 选择标准 | 工作量大、对工期影响大、关注缺陷移除、对交付质量影响大 |

**触发检查条件：**
- 业务目标、组织质量及过程性能目标变化
- 基本的质量与过程性能变化
- 组织的过程结构及过程内容变化

## 3. 建立度量体系及数据收集

- 关注过程能力的**"结果数据"**
- 重点识别对过程能力结果产生潜在影响的**"过程数据"**
- 可使用**思维导图**识别过程数据

## 4. 建立过程性能基线

**步骤：**
1. 获取所需数据（建立组织度量数据库）
2. 分析数据特征（验证能力数据特征，判断是否需要分组）
3. 建立过程性能基线（使用**控制图**方式）
4. 发布和维护过程性能基线（经评审达成共识后正式发布）

> 若能力有分层情况，**必须分组**，分别建立基线

## 5. 建立过程性能模型

**步骤：**
1. **识别建模因子**：识别质量与过程性能目标作为模型输出；使用鱼骨图、德尔菲法或头脑风暴识别因子
2. **建立过程性能模型**：采用**多层模型**分而治之；必须包含**可控因子**
3. **检验过程性能模型**：使用多元回归方式；通过残差验证可靠性
4. **评审和发布过程性能模型**

### 相关性判定标准

| 相关系数范围 | 相关性强度 |
|--------------|------------|
| 0.8~1 | 强相关 |
| 0.5~0.8 | 中度相关 |
| 0.3~0.5 | 弱相关 |
| 0~0.3 | 基本不相关 |

> 注意：因子之间**不可存在较高相关性**（多重共线问题）

## 关键考点

1. 量化管理工作的**前提**：组织已定义组织级标准过程
2. CPK < 0.67 表示**较大风险**
3. 建立基线时若能力有分层，**必须分组**
4. 相关性系数0.8表示**强相关**，但两个强相关因子**不能同时**用于建模
