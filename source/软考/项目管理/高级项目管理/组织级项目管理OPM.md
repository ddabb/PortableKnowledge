# 组织级项目管理（OPM）

## OPM定义

**组织级项目管理（OPM）** 是通过整合项目组合、项目集和项目管理，连接其与组织驱动因素（结构、文化、技术或人力资源实践）和组织流程来提升组织能力，从而实现战略目标。

## OPM框架四大关键要素

| 要素 | 说明 |
|------|------|
| **OPM方法论** | 实践、技术、程序和规则构成的体系 |
| **人才管理** | 跟踪项目管理群体的职业化发展 |
| **知识管理** | 绩效改进、创新、经验教训分享 |
| **OPM治理** | 高管治理、OPM治理实体、组合/项目集治理 |

### 1. OPM方法论

- 针对组织内从事项目管理人员使用的**实践、技术、程序和规则**所构成的体系
- 作用：建立共同工作方式、标准化项目结构、提供共同语言、促进协作、传播最佳实践
- 所有OPM方法论都需要**裁剪**

### 2. 人才管理

- 跟踪项目管理群体的职业化发展
- 晋升评审流程与工作角色和级别同步
- 与项目组合、项目集、项目经理的职业化发展保持一致

### 3. 知识管理

- 侧重于绩效改进、创新、经验教训分享
- 记录最佳实践、流程整合和持续改进
- 涵盖全生命周期
- 关注增加OPM知识所需文档和资源

### 4. OPM治理

| 治理层级 | 职责 |
|----------|------|
| 高管治理实体 | 高级管理人员和董事会 |
| OPM治理实体 | 在OPM方法或架构使战略面临风险时进行干预 |
| 组合/项目集治理实体 | 项目组合和项目集经理报告问题、冲突及收益 |
| 项目管理治理实体 | 可由OPM或项目组合/项目集负责人执行 |

## OPM成熟度模型

组织以**可预测、可控制和可靠**的方式交付期望战略成果的能力水平。

| 级别 | 名称 | 特征 |
|------|------|------|
| **第1级** | 初始或临时的OPM | OPM流程是临时的或无序的 |
| **第2级** | 项目层级采用OPM | 未从组织角度统一，存在项目差异 |
| **第3级** | 组织定义的OPM | 绩效是可预测的，在组织上是标准化的、可测量的、可控制的 |
| **第4级** | 量化管理的OPM | 决策和流程管理是由数据驱动的 |
| **第5级** | 持续优化的OPM | 组织稳定且专注于持续改进 |

> **注意：** 量化级都是**第4级**

## 关键考点

1. OPM框架要素：**治理、方法论、知识管理、人才管理**（不包括OPM战略或风险管理）
2. OPM方法论构成：**实践、技术、程序和规则**
3. 成熟度模型量化级是**第4级**
4. OPM治理实体与高管治理实体通常是**同一实体**
