# 远离黄赌毒

> 健康人生，远离毒品；文明生活，拒绝赌博；阳光心态，远离色情

---

## 一、毒品防范

### 1. 认识毒品

**什么是毒品？**

毒品是指鸦片、海洛因、甲基苯丙胺（冰毒）、吗啡、大麻、可卡因以及国家规定管制的其他能够使人形成瘾癖的麻醉药品和精神药品。

**毒品的分类：**

| 类型 | 代表性毒品 | 危害 |
|------|------------|------|
| 鸦片类 | 鸦片、海洛因 | 严重损害身体，导致死亡 |
| 兴奋剂 | 冰毒、麻古 | 损坏神经系统，产生幻觉 |
| 致幻剂 | 摇头丸、K他命 | 导致精神障碍 |
| 大麻类 | 大麻、麻烟 | 损害大脑功能 |

### 2. 毒品危害

**对个人的危害：**
- 身体：器官损害、免疫力下降、死亡
- 精神：幻觉、焦虑、抑郁
- 生活：倾家荡产、家庭破裂

**对家庭的危害：**
- 经济负担沉重
- 家人受到伤害
- 家庭支离破碎

**对社会的危害：**
- 犯罪率上升
- 社会风气败坏
- 公共安全受到威胁

### 3. 如何远离毒品

**防范要点：**

| 场景 | 正确做法 |
|------|----------|
| 娱乐场所 | 不接受陌生人递给的饮料/香烟 |
| 聚会 | 离开视线的饮品不再喝 |
| 求职 | 警惕高薪诱惑，了解用工单位 |
| 上网 | 不点击陌生链接，不下载未知软件 |

**遇到毒品侵害：**

1. 坚决拒绝："我不碰这个"
2. 迅速离开现场
3. 及时告诉信任的人
4. 拨打110报警

### 4. 相关法律

**《中华人民共和国刑法》规定：**

- 制造、贩卖、运输毒品：最高可判处死刑
- 持有毒品：处三年以下有期徒刑
- 容留他人吸毒：处三年以下有期徒刑

## 二、赌博防范

### 1. 认识赌博

**什么是赌博？**

赌博是指以财物作注比输赢的行为，包括网络赌博、线下赌博等各种形式。

**常见赌博形式：**

- 传统赌博：麻将、扑克、牌九
- 电子赌博：老虎机、捕鱼机
- 网络赌博：时时彩、赌球、线上赌场
- 新型赌博：红包赌博、直播竞猜

### 2. 赌博危害

**十赌九输：**
- 赢是过程，输是结果
- 庄家永远赚钱
- 没有人能全身而退

**危害清单：**

| 方面 | 具体危害 |
|------|----------|
| 经济 | 倾家荡产、债台高筑 |
| 心理 | 焦虑、抑郁、失眠 |
| 家庭 | 离婚、家庭暴力 |
| 工作 | 无心工作、失业 |
| 法律 | 触犯刑法，身陷囹圄 |

### 3. 赌博误区

**❌ 这些想法要不得：**

- "我能控制自己" — 赌徒都这么说
- "就玩一把" — 一把就上瘾
- "上次赢了" — 赢是让你继续输
- "运气会回来" — 越陷越深
- "赢了就不玩了" — 永远不会有那一天

### 4. 远离赌博

**健康生活方式：**

- 培养积极兴趣爱好
- 适度运动锻炼身体
- 多参与社交活动
- 合理规划财务

**遇到赌博诱惑：**

- 坚决拒绝
- 及时报警
- 劝阻他人

### 5. 相关法律

**《治安管理处罚法》规定：**

- 参与赌博：处五日以下拘留或五百元以下罚款
- 为赌博提供条件：处十日至十五日拘留

**《刑法》规定：**

- 开设赌场：处五年以下有期徒刑
- 聚众赌博：处三年以下有期徒刑

## 三、色情防范

### 1. 认识不良色情内容

**包含内容：**

- 色情网站/APP
- 黄色小说/漫画
- 裸聊/援交
- 色情直播

### 2. 色情危害

**对心理健康：**
- 价值观扭曲
- 性观念错位
- 产生性焦虑

**对生活影响：**
- 沉迷网络，荒废学业/事业
- 经济损失（付费、色情诈骗）
- 隐私泄露风险

**法律风险：**
- 传播色情内容违法
- 观看未成年人色情内容违法

### 3. 远离色情

**自我管理：**

- 不点击陌生链接
- 不安装未知软件
- 培养健康兴趣爱好
- 合理安排时间

**保护自己：**

- 不在公共场合浏览
- 不与陌生人裸聊
- 不拍摄/传播隐私内容

**遇到色情骚扰：**

- 立即终止
- 拉黑举报
- 告知家人

### 4. 健康性观念

**正确态度：**

- 性是自然的，不需要逃避

- 性是成熟的，需要责任
- 性是美好的，需要等待

**成长建议：**
