# 呼吸系统健康：保护你的肺

人每分钟呼吸12-20次，一天呼吸约2万次。呼吸系统健康，关系着全身的氧气供应。

## 一、认识呼吸系统

### 呼吸系统组成

- **上呼吸道**：鼻、咽、喉
- **下呼吸道**：气管、支气管、肺

### 呼吸系统的作用

- 吸入氧气，排出二氧化碳
- 过滤空气中的有害物质
- 调节体温和湿度

## 二、影响呼吸健康的因素

### 1. 吸烟

- 吸烟是肺癌、慢阻肺的首要危险因素
- 二手烟同样危害健康
- 戒烟是保护肺最好的方式

### 2. 空气污染

| 类型 | 来源 | 危害 |
|------|------|------|
| **PM2.5** | 工业排放、汽车尾气 | 进入肺泡，引发炎症 |
| **PM10** | 扬尘、建筑 | 刺激呼吸道 |
| **臭氧** | 光化学烟雾 | 刺激眼睛和呼吸道 |
| **二氧化硫** | 燃煤 | 引发呼吸道疾病 |

### 3. 职业暴露

- 粉尘（矿工、建筑工人）
- 化学物质（化工、印刷）
- 生物因子（农业、养殖）

### 4. 感染

- 流感病毒
- 肺炎链球菌
- 结核杆菌

## 三、常见呼吸系统疾病

### 1. 哮喘

**症状**：喘息、咳嗽、胸闷、呼吸困难

**诱因**：
- 过敏原（花粉、尘螨、宠物毛发）
- 冷空气
- 运动
- 情绪激动

**管理要点**：
- 避免过敏原
- 规律用药（吸入激素+支气管扩张剂）
- 随身携带急救药物
- 制定哮喘行动计划

### 2. 慢阻肺

**症状**：慢性咳嗽、咳痰、活动后气短

**高危人群**：
- 长期吸烟者
- 职业粉尘暴露者
- 反复呼吸道感染者

**管理要点**：
- 戒烟（最重要）
- 规律用药
- 肺康复训练
- 预防感染

### 3. 肺炎

**症状**：发热、咳嗽、咳痰、胸痛

**高危人群**：
- 老年人
- 慢性病患者
- 免疫力低下者

**预防要点**：
- 接种肺炎疫苗
- 接种流感疫苗
- 增强免疫力
- 及时治疗感染

### 4. 过敏性鼻炎

**症状**：打喷嚏、流鼻涕、鼻塞、鼻痒

**诱因**：
- 花粉（春季）
- 尘螨（常年）
- 宠物毛发
- 霉菌

**管理要点**：
- 避免过敏原
- 鼻腔冲洗
- 抗过敏药物
- 脱敏治疗

## 四、保护呼吸系统的方法

### 1. 戒烟

- 戒烟后肺功能会逐渐恢复
- 戒烟10年，肺癌风险降低50%
- 任何时候戒烟都不晚

### 2. 改善空气质量

| 场景 | 建议 |
|------|------|
| **室外** | 空气质量差时戴口罩、减少户外活动 |
| **室内** | 保持通风、使用空气净化器 |
| **厨房** | 使用油烟机、减少煎炸 |
| **卧室** | 定期更换床品、控制尘螨 |

### 3. 增强肺功能

- **有氧运动**：快走、慢跑、游泳
- **呼吸训练**：腹式呼吸、缩唇呼吸
- **唱歌**：锻炼呼吸肌

### 4. 预防感染

- 勤洗手
- 接种流感疫苗
- 接种肺炎疫苗（高危人群）
- 避免去人群密集场所

## 五、呼吸系统检查建议

| 检查项目 | 适用人群 | 频率 |
|----------|----------|------|
| **胸片** | 常规体检 | 每年 |
| **肺部CT** | 高危人群（长期吸烟） | 每年 |
| **肺功能检查** | 40岁以上、高危人群 | 每1-2年 |
| **过敏原检测** | 过敏性鼻炎、哮喘患者 | 视情况 |

## 小结

保护呼吸系统，记住这几点：

- **戒烟**：保护肺的第一步
- **关注空气质量**：雾霾天戴口罩、少出门
- **增强肺功能**：规律运动、呼吸训练
- **预防感染**：接种疫苗、勤洗手
- **定期检查**：高危人群做肺部CT

**肺是呼吸的"发动机"，保护好它。**
