# 社保公积金综合指南

## 一、公积金篇

### 1. 公积金是什么

住房公积金是单位和职工共同缴存的长期住房储金，属于职工个人所有。

**缴存比例：**
- 单位缴存：工资的 5%-12%
- 个人缴存：工资的 5%-12%
- 合计：工资的 10%-24%

### 2. 可以提取的情形

#### 购房提取

| 情形 | 说明 |
|------|------|
| 购买商品房 | 提取金额不超过房价 |
| 购买二手房 | 提取金额不超过房价 |
| 购买公有住房 | 提取金额不超过房价 |

#### 还贷提取

- 偿还公积金贷款
- 偿还商业住房贷款
- 可按年提取或按月冲还贷

#### 租房提取

- 无房职工可提取公积金支付房租
- 提取限额各地不同（如每年 1.5-2 万元）

#### 其他情形

| 情形 | 说明 |
|------|------|
| 离退休 | 可全额提取 |
| 完全丧失劳动能力 | 可全额提取 |
| 出境定居 | 可全额提取 |
| 死亡 | 继承人可提取 |
| 重大疾病 | 部分地区支持 |
| 装修 | 部分地区支持 |

### 3. 提取方式

#### 线上提取（推荐）

**渠道：**
- 公积金中心APP或小程序
- 政务服务平台（如"浙里办"、"粤省事"）
- 支付宝/微信城市服务

**流程：**
1. 登录公积金账户
2. 选择提取类型
3. 填写信息、上传材料
4. 审核通过后到账

#### 线下提取

**流程：**
1. 携带材料到公积金中心
2. 填写提取申请表
3. 提交材料审核
4. 审核通过后转账

### 4. 各类提取所需材料

#### 购房提取

| 材料 | 说明 |
|------|------|
| 身份证 | 原件 |
| 购房合同/房产证 | 原件或复印件 |
| 购房发票/契税发票 | 原件 |
| 银行卡 | 本人名下 |
| 配偶提取需结婚证 | 原件 |

#### 租房提取

| 材料 | 说明 |
|------|------|
| 身份证 | 原件 |
| 无房证明 | 线上可查 |
| 银行卡 | 本人名下 |

*部分地区租房提取无需材料，直接线上申请*

#### 还贷提取

| 材料 | 说明 |
|------|------|
| 身份证 | 原件 |
| 贷款合同 | 首次需提供 |
| 还款明细 | 近期还款记录 |
| 银行卡 | 本人名下 |

#### 离退休提取

| 材料 | 说明 |
|------|------|
| 身份证 | 原件 |
| 退休证/退休审批表 | 原件 |
| 银行卡 | 本人名下 |

### 5. 提取额度

#### 购房提取

- 提取金额不超过购房总价
- 可多次提取，累计不超过房价

#### 租房提取

- 每年提取限额各地不同
- 如北京：每年最高 24000 元
- 如上海：每月最高 3000 元

#### 还贷提取

- 每年提取金额不超过年还款额
- 可按月冲还贷（自动扣款）

### 6. 常见问题

#### Q1：离职后公积金怎么处理？

- 可提取（部分地区需封存满6个月）
- 可转移至新单位继续缴存
- 可保留账户，等退休后提取

#### Q2：公积金贷款和提取冲突吗？

- 账户余额可用于还贷
- 申请贷款时余额会影响贷款额度
- 部分地区贷款后不能提取全部余额

#### Q3：异地购房可以提取吗？

可以。异地购房提取公积金需要：
- 购房所在地本人或配偶户籍地
- 或本人工作地
- 部分地区放宽至全国

#### Q4：夫妻可以互提吗？

可以。夫妻双方可提取各自的公积金用于：
- 共同购房
- 共同还贷
- 需提供结婚证

#### Q5：提取后影响贷款额度吗？

会影响。公积金贷款额度通常与账户余额挂钩：
- 如上海：贷款额度 = 余额 × 30
- 如北京：贷款额度与余额和缴存年限相关

### 7. 公积金贷款优势

- **利率低**：比商业贷款低 1-2 个百分点
- **额度高**：最高可贷 100-120 万元（各地不同）
- **期限长**：最长可贷 30 年
- **还款灵活**：可选择等额本息或等额本金

## 二、医保篇

### 1. 医保是什么

医保是**基本医疗保险**的简称，分为两类：

| 类型 | 参保对象 | 特点 |
|------|----------|------|
| 职工医保 | 在职员工、灵活就业人员 | 报销比例高，有个人账户 |
| 居民医保 | 学生、儿童、无业居民 | 缴费低，无个人账户 |

### 2. 医保报销范围

#### 基本医疗保险报销范围

- **药品**：甲类药品全额报销，乙类药品部分报销
- **诊疗项目**：符合医保目录的诊疗项目
- **医疗服务设施**：住院床位费等

#### 不予报销的项目

- 美容整形
- 自购药品
- 交通意外
- 医疗事故
- 境外就医

### 3. 报销比例

#### 门诊报销

| 医院等级 | 起付线 | 报销比例 |
|----------|--------|----------|
| 社区医院 | 1800元/年 | 90% |
| 二级医院 | 1800元/年 | 80% |
| 三级医院 | 1800元/年 | 70% |

*注：具体比例各地略有差异*

#### 住院报销

| 医院等级 | 起付线 | 报销比例 |
|----------|--------|----------|
| 一级医院 | 300元 | 90% |
| 二级医院 | 600元 | 87% |
| 三级医院 | 1300元 | 85% |

*注：起付线可多次住院累计计算*

### 4. 报销流程

#### 门诊报销

- 持医保卡直接结算
- 超过起付线部分按比例报销

#### 住院报销

- 持医保卡办理住院手续
- 出院时直接结算
- 个人只需支付自付部分

### 5. 医保缴费标准

#### 职工医保

- 单位缴费：工资总额的 6%-10%
- 个人缴费：工资的 2%

#### 居民医保

- 各地标准不同
- 一般每年 300-500 元（政府补贴后）
- 每年 9-12 月集中缴费

### 6. 医保个人账户

#### 职工医保个人账户

- 个人缴存部分全部计入
- 单位缴存部分按比例计入
- 可用于支付门诊费用、药店购药

### 5. 省钱小技巧

- 选择医保定点医院
- 优先使用甲类药品
- 合理使用个人账户
- 参加补充医疗保险

### 6. 医保常见问题

#### Q1：医保卡丢失怎么办？

- 立即挂失
- 携带身份证到社保中心补办
- 可先使用电子医保卡

#### Q2：异地就医如何报销？

- 办理异地就医备案
- 可直接结算或回参保地报销
- 报销比例可能略低

#### Q3：断缴后医保待遇受影响吗？

- 断缴期间无法享受医保待遇
- 重新缴费后有 3-6 个月等待期
- 个人账户余额可继续使用

## 三、实用技巧

### 1. 社保公积金查询

- **线上查询**：社保/公积金APP、支付宝、微信
- **线下查询**：社保中心、公积金中心
- **电话查询**：12333（社保）、公积金热线

### 2. 社保公积金转移

- 跨市转移：办理转移手续
- 跨省转移：通过全国社保转移平台
- 公积金转移：新单位开具接收函

### 3. 注意事项

- 按时缴费，避免断缴
- 保留好相关凭证
- 及时更新个人信息
- 了解当地政策变化

社保和公积金是我们的重要福利，合理利用可以为我们的生活提供有力保障。希望这份指南能帮助你更好地了解和使用社保公积金，让它们成为你生活中的得力助手！
