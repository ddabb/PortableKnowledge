# 实用思维工具：SWOT分析与决策矩阵

## 1. SWOT分析法

**定义**：SWOT分析是一种战略规划工具，通过分析优势（Strengths）、劣势（Weaknesses）、机会（Opportunities）和威胁（Threats）来评估一个项目或决策。

**操作步骤：**
1. 列出项目的优势
2. 列出项目的劣势
3. 列出项目的机会
4. 列出项目的威胁
5. 分析优势与机会的结合点
6. 分析劣势与威胁的应对策略

**应用场景：**
- 个人职业规划
- 项目评估
- 企业战略制定
- 产品开发

## 2. 决策矩阵分析法

**定义**：决策矩阵是一种通过量化评估多个选项的不同因素来做出决策的工具。

**操作步骤：**
1. 确定决策的目标
2. 列出可能的选项
3. 确定评估因素
4. 为每个因素分配权重
5. 为每个选项在每个因素上打分
6. 计算每个选项的总分
7. 根据总分做出决策

**应用场景：**
- 职业选择
- 购买决策
- 项目优先级排序
- 资源分配

## 3. 思维导图

**定义**：思维导图是一种可视化的思维工具，通过层级结构展示信息之间的关系。

**应用场景：**
- 知识整理
- 创意生成
- 问题分析
- 演讲准备
- 学习笔记

**绘制技巧：**
- 从中心主题开始
- 使用关键词
- 使用颜色和图像
- 保持层级清晰
- 鼓励自由联想
